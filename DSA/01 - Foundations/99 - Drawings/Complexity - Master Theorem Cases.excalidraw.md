Master Theorem: where is the work in the recursion tree? ^Dk3ueYOR

Each bar = total work on one level (root at the top, leaves at the bottom). ^QW68mM4f

Case 1: leaves dominate ^JAvVFUrJ

T(n) = Θ(n^(log_b a)) ^oDwf2vBF

2T(n/2) + 1  →  Θ(n)
7T(n/2) + n²  →  Θ(n^2.81) ^VsahQw55

Case 2: all levels equal ^k2TGs6IO

T(n) = Θ(n^(log_b a) · log n) ^PrcmTl1L

2T(n/2) + n  →  Θ(n log n)
T(n/2) + 1  →  Θ(log n) ^7WRJKQRu

Case 3: root dominates ^RcABMImN

T(n) = Θ(f(n)) ^5Jzy6r81

2T(n/2) + n²  →  Θ(n²)
T(n/2) + n  →  Θ(n) ^OYKD6t0M

2T(n/2) + n/log n falls in the gap between cases 1 and 2, and no case applies (answer: Θ(n log log n)). ^yubLkU2G
