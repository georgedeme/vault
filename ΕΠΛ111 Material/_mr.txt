===== PAGE 17 =====
                 Μέθοδοι Αποδείξεων

1. Ευθεία απόδειξη (direct proof): P → Q
2. Έμμεση απόδειξη (indirect proof): ¬Q → ¬P
3. Απόδειξη με αντίφαση (proof by contradiction): με εικασία P, υποθέτουμε ότι

    ¬P είναι αληθής και φτάνουμε σε κάποια αντίφαση, άρα P είναι αληθής
4. Απόδειξη με ανάλυση περιπτώσεων (proof by cases): με εικασία της μορφής

    P1 ∨ P2 ∨ ⋯ ∨ Pν → Q αρκεί να δείξουμε ότι Pj → Q για 1 ≤ j ≤ ν

5. Επαγωγική απόδειξη (inductive proof) – ειδική θεματική ενότητα

           Ευθεία Απόδειξη (Direct Proof)

Πρόταση: Αν το α είναι άρτιος ακέραιος, τότε α2 είναι επίσης άρτιος ακέραιος.

Απόδειξη:  α άρτιος ⇒ α = 2β για ακέραιο β
Απόδειξη:  α άρτιος ⇒ α2 = 4β2
Απόδειξη:  α άρτιος ⇒ α2 = 2(2β2)
Απόδειξη:  α άρτιος ⇒ α2 είναι άρτιος αφού 2β2 είναι ακέραιος

           Ευθεία Απόδειξη (Direct Proof)

Απόδειξη:  α περιττός ⇒ α2 = (2β+1)2 = 4β2 + 4β + 1
Απόδειξη:  α περιττός ⇒ α2 = 2(2β2 + 2β) + 1
Απόδειξη:  α περιττός ⇒ α2 είναι περιττός αφού 2β2 + 2β είναι ακέραιος

===== PAGE 24 =====
           Ευθεία Απόδειξη (Direct Proof)

Πρόταση: Έστω α,β και γ ακέραιοι αριθμοί. Αν ο α διαιρεί τον β και ο β διαιρεί τον γ,
τότε ο α διαιρεί τον γ.

Απόδειξη:  α διαιρεί τον β ⇒ β = δα για ακέραιο δ
Απόδειξη:  β διαιρεί τον γ ⇒ γ = εβ για ακέραιο ε
Απόδειξη:
           Επομένως, ισχύει ότι γ = εβ = ε(δα) = (εδ)α.
           Αφού εδ είναι ακέραιος, ισχύει ότι ο α διαιρεί τον γ

===== PAGE 28 =====
       Έμμεση Απόδειξη (Indirect Proof)

Πρόταση: Έστω α ακέραιος. Αν 3α + 2 είναι περιττός, τότε α είναι περιττός.
Απόδειξη: 3α + 2 είναι περιττός ⇒ 3α + 2 = 2β + 1 για ακέραιο β

                                       ⇒ 3α + 1 = 2β ;;;;
              αποτυχημένη προσπάθεια μέσω ευθείας απόδειξης

===== PAGE 29 =====
       Έμμεση Απόδειξη (Indirect Proof)

Πρόταση: Έστω α ακέραιος. Αν 3α + 2 είναι περιττός, τότε α είναι περιττός.

Απόδειξη: Υποθέστε ότι α είναι άρτιος. Πρέπει να δείξουμε ότι 3α + 2 είναι
άρτιος (μέσω ευθείας απόδειξης).

            α άρτιος ⇒ α = 2β για ακέραιο β
            α άρτιος ⇒ 3α + 2 = 3(2β) + 2 = 6β + 2 = 2(3β + 1)
            α άρτιος ⇒ 3α + 2 είναι άρτιος αφού 3β + 1 είναι ακέραιος

===== PAGE 30 =====
           Έμμεση Απόδειξη (Indirect Proof)

Πρόταση: Έστω α και β ακέραιοι. Αν αβ είναι άρτιος, τότε ο α ή ο β είναι άρτιος.
Απόδειξη: Υποθέστε ότι δεν ισχύει ότι ο α και ο β είναι άρτιοι, δηλ. ο α και ο β είναι
περιττοί. Πρέπει να δείξουμε ότι ο αβ είναι περιττός (μέσω ευθείας απόδειξης).

            α και β περιττοί ⇒ αβ = (2δ + 1)(2ε + 1) για ακέραιους δ και ε
            α και β περιττοί ⇒ αβ = 4δε + 2δ + 2ε + 1
            α και β περιττοί ⇒ αβ = 2(δε + δ + ε) + 1
            α και β περιττοί ⇒ αβ είναι περιττός αφού δε + δ + ε είναι ακέραιος

===== PAGE 31 =====
         Έμμεση Απόδειξη (Indirect Proof)

Πρόταση: Έστω α ακέραιος. Αν α2 είναι άρτιος, τότε ο α είναι άρτιος.
Απόδειξη: Υποθέστε ότι δεν ισχύει ότι ο α είναι άρτιος, δηλ. ο α είναι περιττός.
Πρέπει να δείξουμε ότι ο α2 είναι περιττός (μέσω ευθείας απόδειξης).

                         α περιττός ⇒ α = 2β + 1 για ακέραιο β
                         α περιττός ⇒ α2 = (2β + 1)2 = 4β2 + 4β + 1
                         α περιττός ⇒ α2 = 2(2β2 + 2β) + 1
                         α περιττός ⇒ α2 είναι περιττός αφού 2β2 + 2β ακέραιος

   Απόδειξη με Αντίφαση (Proof by Contradiction)

1. Θέλουμε να αποδείξουμε την πρόταση P

2. Υποθέτουμε ότι P είναι ψευδής, δηλαδή ¬P είναι αληθής, και προχωρούμε να
    καταλήξουμε σε κάποιο συμπέρασμα Q που είναι ψευδές (γενικώς ή σύμφωνα με
    την υπόθεση ότι ¬P είναι αληθής)

3. Άρα ¬P → Q είναι αληθής και Q ψευδής

4. Η μόνη περίπτωση να συμβαίνει αυτό είναι αν η ¬P είναι ψευδής, δηλαδή P αληθής

5. Αφού P ∧ ¬P είναι αντίφαση, συμπεραίνουμε ότι η αρχική υπόθεση ότι ¬P είναι
    αληθής είναι εσφαλμένη, δηλαδή P είναι αληθής

===== PAGE 34 =====
Απόδειξη με Αντίφαση (Proof by Contradiction)

 Πρόταση: Δεν υπάρχουν ακέραιοι α και β τ.ω. 14α + 20β = 101.
 Απόδειξη: Υποθέτουμε ότι υπάρχουν ακέραιοι α και β τ.ω. 14α + 20β = 101.
 Επομένως, 2(7α + 10β) = 101. Ο αριθμός 7α + 10β είναι ακέραιος και άρα το
 101 είναι άρτιος, που οδηγεί σε αντίφαση.

===== PAGE 35 =====
Απόδειξη με Αντίφαση (Proof by Contradiction)

Πρόταση: Δεν υπάρχει ακέραιος που είναι άρτιος και περιττός.
Απόδειξη: Υποθέτουμε ότι υπάρχει ακέραιος α που είναι άρτιος και περιττός.

            α άρτιος και περιττός ⇒ α = 2κ = 2λ + 1 για ακέραιους κ και λ
            α άρτιος και περιττός ⇒ 2κ – 2λ = 1
            α άρτιος και περιττός ⇒ 2(κ – λ) = 1
            α άρτιος και περιττός ⇒ κ – λ = 1/2

Άρα κ – λ δεν είναι ακέραιος που οδηγεί σε αντίφαση αφού η διαφορά δύο
ακεραίων είναι ακέραιος.

===== PAGE 36 =====
Απόδειξη με Αντίφαση (Proof by Contradiction)

Πρόταση: 2 είναι άρρητος.

Απόδειξη: Υποθέτουμε ότι 2 είναι ρητός αριθμός. Επομένως, 2 = α/β για
ακέραιους α και β που δεν έχουν κοινό παράγοντα. Άρα,

                                      ⇒ 2 = α2 / β2
                                      ⇒ 2β2 = α2
                                      ⇒ α2 είναι άρτιος
                                      ⇒ α είναι άρτιος.
Επομένως, α = 2γ για κάποιο ακέραιο γ, και άρα
                                      ⇒ 2β2 = 4γ2
                                      ⇒ β2 = 2γ2
                                      ⇒ β2 είναι άρτιος
                                      ⇒ β είναι άρτιος.
Άρα α και β έχουν κοινό παράγοντα το 2, που οδηγεί σε αντίφαση.

===== PAGE 37 =====
Απόδειξη με Αντίφαση (Proof by Contradiction)

 Πρόταση: Έστω α ακέραιος. Αν 3α + 2 είναι περιττός, τότε α είναι περιττός.
 Απόδειξη: Υποθέτουμε ότι 3α + 2 είναι περιττός και α είναι άρτιος.

              α άρτιος ⇒ α = 2β για ακέραιο β
              α άρτιος ⇒ 3α + 2 = 3(2β) + 2 = 6β + 2 = 2(3β + 1)
              α άρτιος ⇒ 3α + 2 είναι άρτιος αφού 3β + 1 είναι ακέραιος
 το οποίο οδηγεί σε αντίφαση αφού υποθέσαμε ότι 3α + 2 είναι περιττός.

                 Μέθοδοι Αποδείξεων

1. Ευθεία απόδειξη (direct proof): P → Q
2. Έμμεση απόδειξη (indirect proof): ¬Q → ¬P
3. Απόδειξη με αντίφαση (proof by contradiction): με εικασία P, υποθέτουμε ότι

    ¬P είναι αληθής και φτάνουμε σε κάποια αντίφαση, άρα P είναι αληθής

===== PAGE 40 =====
Απόδειξη με Ανάλυση Περιπτώσεων (Proof by Cases)

      (P1 ∨ P2 ∨ ⋯ ∨ Pν) → Q ≡ (P1 → Q) ∧ (P2 → Q) ∧ ⋯ ∧ (Pν → Q)

       1. Θέλουμε να αποδείξουμε την πρόταση P → Q
       2. Γράφουμε την υπόθεση P ως μια ισοδύναμη διάζευξη P1 ∨ P2 ∨ ⋯ ∨ Pν
       3. Αποδεικνύουμε την πρόταση Pj → Q για κάθε 1 ≤ j ≤ ν

===== PAGE 41 =====
Απόδειξη με Ανάλυση Περιπτώσεων (Proof by Cases)

  Πρόταση: Έστω α πραγματικός αριθμός. Αν α ≠ 0, τότε α2 > 0.
  Απόδειξη: α ≠ 0 αν και μόνο αν (α > 0) ή (α < 0). Επομένως, αρκεί να δείξουμε τις
  πιο κάτω προτάσεις:

                    αν α > 0, τότε α2 > 0 και αν α < 0, τότε α2 > 0.
  Και οι δύο προτάσεις ισχύουν από τον ορισμό του πολλαπλασιασμού πραγματικών
  αριθμών. Επομένως, α ≠ 0 συνεπάγεται α2 > 0.

===== PAGE 42 =====
 Απόδειξη με Ανάλυση Περιπτώσεων (Proof by Cases)

Πρόταση: Αν α,β και γ ακέραιοι αριθμοί, τότε max{max{α,β}, γ} = max{α, max{β,γ}}.

Απόδειξη: Παραθέτουμε όλες τις περιπτώσεις:
(α ≥ β ≥ γ) ή (α ≥ γ ≥ β) ή (β ≥ α ≥ γ) ή (β ≥ γ ≥ α) ή (γ ≥ α ≥ β) ή (γ ≥ β ≥ α)

1. α ≥ β ≥ γ. max{α,β} = α, max{α,γ} = α και max{β,γ} = β. Επομένως, max{max{α,β}, γ} =
    α = max{α, max{β,γ}}.

2. (α ≥ γ ≥ β). max{α,β} = α, max{α,γ} = α και max{β,γ} = γ. Επομένως, max{max{α,β}, γ} =
    α = max{α, max{β,γ}}.

      …με παρόμοιο τρόπο μπρούμε να δείξουμε ότι σε όλες τις περιπτώσεις ισχύει ότι
                                 max{max{α,β}, γ} = max{α, max{β,γ}}

===== PAGE 43 =====
Απόδειξη με Ανάλυση Περιπτώσεων (Proof by Cases)

Πρόταση: Έστω α ακέραιος. Αν α > 3 και α δεν διαιρείται με το 3, τότε α2 mod 3 = 1.
Απόδειξη: Υπάρχουν δύο περιπτώσεις:
1. α mod 3 = 1. Άρα α = 3κ + 1 για κάποιο ακέραιο κ > 0. Επομένως, α2 = 9κ2 + 6κ + 1 =

    3(3κ2 + 2κ) + 1. Συνεπώς, α2 mod 3 = 1.
2. α mod 3 = 2. Άρα α = 3κ + 2 για κάποιο ακέραιο κ > 0. Επομένως, α2 = 9κ2 + 12κ + 4 =

    3(3κ2 + 4κ + 1) + 1. Συνεπώς, α2 mod 3 = 1.

Απόδειξη με Ανάλυση Περιπτώσεων (Proof by Cases)

Πρόταση: Αν α και β πραγματικοί αριθμοί, τότε |αβ| = |α|⋅|β|.

Απόδειξη: Υπάρχουν 4 περιπτώσεις:                              |γ| =  γ αν γ ≥ 0
1. α ≥ 0 και β ≥ 0. |αβ| = αβ και |α|⋅|β| = αβ.                       -γ αν γ < 0

2. α < 0 και β < 0. |αβ| = αβ και |α|⋅|β| = (-α)(-β) = αβ.

3. α ≥ 0 και β < 0. |αβ| = -(αβ) και |α|⋅|β| = α(-β) = -(αβ).

4. α < 0 και β ≥ 0. |αβ| = -(αβ) και |α|⋅|β| = (-α)β = -(αβ). (συμμετρική με την περίπτωση 3)

Απόδειξη με Ανάλυση Περιπτώσεων (Proof by Cases)

Πρόταση: Αν α και β πραγματικοί αριθμοί, τότε |α| + |β| ≥ |α + β|.

Απόδειξη: Υπάρχουν 4 περιπτώσεις:  |γ| =                            γ αν γ ≥ 0
                                                                    -γ αν γ < 0

1. α ≥ 0 και β ≥ 0. |α| + |β| = α + β και |α + β| = α + β .
2. α < 0 και β < 0. |α| + |β| = -α + (-β) = -(α + β) και |α + β| = -(α + β).
3. α ≥ 0 και β < 0. |α| + |β| = α + (-β). Τώρα υπάρχουν δύο υποπεριπτώσεις:

      i. α ≥ -β. Αφού β < 0, ισχύει ότι -β > β και άρα |α| + |β| = α + (-β) > α + β = |α + β|.
      ii. α < -β. Αφού α ≥ 0, ισχύει ότι α ≥ -α και άρα |α| + |β| = α + (-β) ≥ -α + (-β) = -(α + β)

            = |α + β|.
4. α < 0 και β ≥ 0. Συμμετρική με την περίπτωση 3.

===== PAGE 47 =====
                     Απόδειξη Ισοδυναμιών

                               P ↔ Q ≡ (P → Q) ∧ (Q → P)
P ↔ Q ↔ R ≡ (P ↔ Q) ∧ (Q ↔ R) ≡ (P → Q) ∧ (Q → P) ∧ (Q → R) ∧ (R → Q)

   P1 ↔ P2 ↔ ⋯ ↔ Pν ≡ (P1 → P2) ∧ (P2 → P3) ∧ ⋯ ∧ (Pν-1 → Pν) ∧ (Pν → P1)

           Πολύ πιο αποδοτική μέθοδος από το να αποδείξουμε ότι Pi → Pj για κάθε i ≠ j
          με 1 ≤ i ≤ ν και 1 ≤ j ≤ ν – πρέπει να θεωρήσουμε ν αντί 2(ν – 1) συνεπαγωγές

===== PAGE 48 =====
                     Απόδειξη Ισοδυναμιών

Πρόταση: Αποδείξτε ότι οι πιο κάτω προτάσεις είναι ισοδύναμες:
1. α είναι άρτιος ακέραιος
2. α – 1 είναι περιττός ακέραιος
3. α2 είναι άρτιος ακέραιος

Απόδειξη:
(1) → (2). Αφού α είναι άρτιος, τότε α = 2β για κάποιο ακέραιο β. Επομένως, α – 1 = 2β – 1 =
2(β – 1) + 1. Άρα, α – 1 είναι περιττός.

(2) → (3). Αφού α – 1 είναι περιττός, τότε α – 1 = 2β + 1 για κάποιο ακέραιο β. Επομένως, α =
2β + 2, και άρα α2 = (2β + 2)2 = 4β2 + 4β + 4 = 2(2β2 + 2β + 2), δηλαδή α2 είναι άρτιος.

(3) → (1). Υποθέτουμε ότι α είναι περιττός, και πρέπει να δείξουμε ότι α2 είναι περιττός.
Αφού α είναι περιττός, τότε α = 2β + 1 για κάποιο ακέραιο β. Επομένως, α2 = (2β + 1)2 = 4β2 +
4β + 1 = 2(2β2 + 2β) + 1, και άρα α2 είναι περιττός.

===== PAGE 52 =====
    Κατασκευαστική Απόδειξη (Constructive Proof)

Πρόταση: Για κάθε θετικό ακέραιο α, υπάρχουν α διαδοχικοί σύνθετοι (δηλ. μη πρώτοι)
θετικοί αριθμοί.
Απόδειξη: Θέτουμε κ = (α + 1)! + 1, και θεωρούμε τους θετικούς ακεραίους

                                            κ + 1, κ+2, …, κ + α.
Παρατηρούμε ότι j + 1 διαιρεί το κ + j = (α + 1)! + (j + 1) για όλα τα 1 ≤ j ≤ α. Άρα, βρήκαμε
α διαδοχικούς σύνθετους ακεραίους.

===== PAGE 53 =====
Μη-Κατασκευαστική Απόδειξη (Non-constructive Proof)

Πρόταση: Για κάθε θετικό ακέραιο α, υπάρχει ένας πρώτος αριθμός μεγαλύτερος από α.

Απόδειξη:
• Θεωρήστε τον ακέραιο αριθμό α! + 1.
• Αφού κάθε ακέραιος αριθμός μπορεί να γραφεί ως το γινόμενο πρώτων παραγόντων,

    υπάρχει κάποιος πρώτος αριθμός β που να διαιρεί το α! + 1.
• Παρατηρούμε ότι δεν υπάρχει αριθμός μεγαλύτερος από το 1 και μικρότερος ή ίσος

    από το α που να διαιρεί το α! + 1.
• Επομένως, ο πρώτος αριθμός β είναι μεγαλύτερος από α.

===== PAGE 54 =====
Μη-Κατασκευαστική Απόδειξη (Non-constructive Proof)

  Πρόταση: Υπάρχουν άρρητοι αριθμοί α και β τ.ω. αβ είναι ρητός.
  Απόδειξη: Ξέρουμε ότι 2 είναι άρρητος. Θεωρήστε τον αριθμό 2^ 2. Υπάρχουν
  δύο περιπτώσεις:
  • 𝟐^ 𝟐 είναι ρητός. Άρα έχουμε τελειώσει με α = 2 και β = 2.
  • 𝟐^ 𝟐 είναι αρρητός. Θέτουμε α = 2^ 2 και β = 2. Άρα, αβ = ( 2^ 2)^ 2 =

         2^( 2 × 2) = ( 2)2 = 2.
  Επομένως, η πρόταση ισχύει με α = 2 και β = 2 ή με α = 2^ 2 και β = 2.

===== PAGE 56 =====
   Αποδείξεις Μοναδικότητας (Uniqueness Proofs)

Πρόταση: Για κάθε θετικό ακέραιο α, υπάρχει ακριβώς ένας ακέραιος β τ.ω. α + β = 0.

Απόδειξη:
• Παρατηρήστε ότι α – α = 0. Επομένως, υπάρχει ακέραιος β τέτοιος ώστε α + β = 0,

    δηλαδή β = -α.
• Μένει να δείξουμε ότι β = -α είναι ο μοναδικός τέτοιος ακέραιος. Υποθέστε ότι

    υπάρχει ακέραιος γ τέτοιος ώστε γ ≠ β και α + γ = 0. Επομένως, α + β = α + γ και άρα
    β = γ το οποίο οδηγεί σε αντίφαση.
