# 02 - Τύποι Δεδομένων, Μεταβλητές και Ανάθεση

Τι είναι «τύπος δεδομένων», ποιοι βασικοί τύποι υπάρχουν στη Java και πώς δηλώνουμε/αναθέτουμε μεταβλητές (διαφάνειες II-2 … II-7).

## 1. Τύπος Δεδομένων

> [!note] Ορισμός (II-4)
> **Τύπος Δεδομένων** (data type): ένα **σύνολο τιμών** (values) και ένα **σύνολο λειτουργιών** (operations) που ορίζονται σε αυτές τις τιμές.

Κάθε γλώσσα παρέχει έναν αριθμό **βασικών (ενσωματωμένων)** τύπων (π.χ. `double`, `int`, `char`) και τη δυνατότητα να ορίζει ο χρήστης **νέους** τύπους.

| Τύπος | Σύνολο τιμών | Κυριολεκτικές τιμές | Λειτουργίες |
|---|---|---|---|
| `char` | χαρακτήρες | `'A'` `'@'` | σύγκριση (compare) |
| `String` | ακολουθίες χαρακτήρων | `"Hello World"` `"CS is fun"` | συνένωση (concatenate) |
| `int` | ακέραιοι | `17` `12345` | `+` `-` `*` `/` `%` |
| `double` | αριθμοί κινητής υποδιαστολής | `3.1415` `6.022e23` | `+` `-` `*` `/` |
| `boolean` | τιμές αληθείας | `true` `false` | and, or, not |

## 2. Βασικοί (βαθμωτοί – scalar) τύποι

> [!note] Ορισμός (II-3)
> **Βασικοί ή βαθμωτοί** (scalar) τύποι: αυτοί των οποίων οι τιμές **δεν μπορούν να διασπαστούν** σε απλούστερα στοιχεία.
> Στη Java: **`byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`** (8 τύποι).

- Η μεγάλη δύναμη της Java είναι οι **τύποι αναφοράς** (reference types), δηλαδή τα **αντικείμενα**, που επιτρέπουν στον προγραμματιστή να ορίζει νέους τύπους.
- Όλα τα δεδομένα αναπαριστούνται στη μνήμη ως σειρές **δυαδικών ψηφίων (bits)**.

| Τύπος | Μέγεθος | Κατηγορία | Προεπιλεγμένη τιμή (σε πίνακα) ➕ |
|---|---|---|---|
| `byte` | 8 bit | ακέραιος | `0` |
| `short` | 16 bit | ακέραιος | `0` |
| `int` | 32 bit | ακέραιος | `0` |
| `long` | 64 bit | ακέραιος | `0L` |
| `float` | 32 bit | πραγματικός | `0.0f` |
| `double` | 64 bit | πραγματικός | `0.0` |
| `char` | 16 bit ➕ | χαρακτήρας | `'\u0000'` |
| `boolean` | — | λογικός | `false` |

> [!important] Το `String` ΔΕΝ είναι βασικός τύπος
> Το `String` γράφεται με κεφαλαίο γιατί είναι **κλάση** (τύπος αναφοράς). Συμπεριφέρεται «σχεδόν» σαν βασικός τύπος (έχει κυριολεκτικά `"..."` και τελεστή `+`), αλλά π.χ. η σύγκριση με `==` **δεν** κάνει αυτό που περιμένεις – βλ. [[05 - String και char]].

## 3. Μεταβλητή, δήλωση, ανάθεση

> [!note] Βασικοί Ορισμοί (II-5)
> - **Μεταβλητή** (variable): μια ονομασία που αναφέρεται σε μια τιμή.
> - **Εντολή ανάθεσης** (assignment statement): συσχετίζει μια τιμή με μια μεταβλητή.

```java
int a, b;          // declaration statement (δήλωση)
a = 1234;          // assignment statement – το 1234 είναι literal (κυριολεκτική τιμή)
b = 99;
int c = a + b;     // combined declaration and assignment statement
```

| Όρος | Στο παράδειγμα |
|---|---|
| Εντολή δήλωσης | `int a, b;` |
| Όνομα μεταβλητής | `a`, `b`, `c` |
| Κυριολεκτική τιμή (literal) | `1234`, `99` |
| Εντολή ανάθεσης | `a = 1234;` |
| Συνδυασμένη δήλωση και ανάθεση | `int c = a + b;` |

> [!important] Το `=` είναι ανάθεση, όχι ισότητα
> `x = x + 1;` σημαίνει «υπολόγισε `x + 1` και **βάλ' το** στο `x`». Αριστερά του `=` πρέπει να υπάρχει **μεταβλητή**: `x + 1 = 5;` ✗ compile error.
> Η ισότητα ελέγχεται με `==` → [[06 - boolean και Συγκριτικοί Τελεστές]].

## 4. Ίχνος (Trace)

> [!note] Ορισμός (II-7)
> **Ίχνος** (trace): πίνακας με τις τιμές των μεταβλητών **μετά από κάθε εντολή**.

> [!example]- Παράδειγμα ίχνους: ανταλλαγή τιμών (swap)
> ```java
> int a, b;
> a = 1234;
> b = 99;
> int t = a;
> a = b;
> b = t;
> ```
>
> | Εντολή | `a` | `b` | `t` |
> |---|---|---|---|
> | `int a, b;` | — | — | |
> | `a = 1234;` | 1234 | — | |
> | `b = 99;` | 1234 | 99 | |
> | `int t = a;` | 1234 | 99 | 1234 |
> | `a = b;` | **99** | 99 | 1234 |
> | `b = t;` | 99 | **1234** | 1234 |
>
> Χωρίς τη βοηθητική `t`, το `a = b; b = a;` αφήνει **και τις δύο** ίσες με 99 – η αρχική τιμή του `a` χάνεται.

## 5. Ειδικές περιπτώσεις

> [!warning] Μη αρχικοποιημένες μεταβλητές (➕)
> Μια **τοπική** μεταβλητή πρέπει να έχει πάρει τιμή πριν τη διαβάσεις:
> ```java
> int x;
> System.out.println(x);            // ✗ compile: variable x might not have been initialized
>
> int y;
> if (args.length > 0) y = 1;
> System.out.println(y);            // ✗ ίδιο σφάλμα – ο compiler δεν ξέρει αν το if εκτελέστηκε
> ```

> [!warning] Πολλαπλή δήλωση: ποιος αρχικοποιείται;
> `int k = 5, m = 4, n;` → μόνο τα `k`, `m` έχουν τιμή. Το `n` είναι **μη αρχικοποιημένο** (II-47).
> `int a, b = 5;` → **μόνο** το `b` είναι 5, όχι και το `a`.

> [!warning] Εμβέλεια (scope) ➕
> Μια μεταβλητή ζει από τη δήλωσή της **μέχρι το τέλος του μπλοκ `{ }`** όπου δηλώθηκε.
> - Δεν μπορείς να ξαναδηλώσεις το ίδιο όνομα σε εσωτερικό μπλοκ: `int i = 0; for (int i = 0; ...)` ✗ «already defined».
> - Μεταβλητή δηλωμένη μέσα σε `for`/`{ }` δεν υπάρχει μετά: `for (int i = 0; i < 3; i++) {}  System.out.println(i);` ✗ «cannot find symbol».

> [!tip] Σταθερές με `final` ➕
> `final int SUITS = 4;` → κάθε μεταγενέστερη ανάθεση (`SUITS = 5;`) είναι compile error. Χρησιμοποίησέ τες αντί για «μαγικούς» αριθμούς (βλ. «αποφυγή hardwired σταθερών», IV-24).

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Χρήση μεταβλητής **πριν** τη δήλωση ή χωρίς αρχικοποίηση.
> - Δήλωση **δύο φορές** (`int x = 1; int x = 2;`) – η δεύτερη φορά θέλει μόνο `x = 2;`.
> - Αντιμετάθεση σε ανάθεση: `5 = x;` ✗.
> - Σύγχυση `=` (ανάθεση) με `==` (σύγκριση).
