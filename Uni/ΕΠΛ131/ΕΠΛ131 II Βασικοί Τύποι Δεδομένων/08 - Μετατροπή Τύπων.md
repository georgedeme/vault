# 08 - Μετατροπή Τύπων

Πότε η Java μετατρέπει μόνη της έναν τύπο σε άλλο, πότε πρέπει να το κάνουμε εμείς (casting) και ποιες μέθοδοι βοηθούν (διαφάνειες II-46 … II-50).

## 1. Τα δύο είδη μετατροπής (II-46)

| Είδος | Πώς | Παραδείγματα |
|---|---|---|
| **Αυτόματη** | χωρίς απώλεια ακρίβειας | `int` → `double` |
| | με strings | `int` → `String` στο `"" + 5` |
| **Ρητή** | casting | `(int) 3.7` |
| | μέθοδος | `Integer.parseInt("123")`, `Math.round(2.7)` |

## 2. Αυτόματη μετατροπή (II-47)

> [!important] Η «σκάλα» της διεύρυνσης (widening) ➕
> `byte → short → int → long → float → double`, και `char → int`
> Προς τα **δεξιά** η μετατροπή γίνεται **αυτόματα**. Προς τα **αριστερά** χρειάζεται **cast**.
> Σε πράξη με δύο διαφορετικούς τύπους, ο «μικρότερος» μετατρέπεται στον «μεγαλύτερο» **πριν** την πράξη.

```java
int k = 5, m = 4, n;
double x = 1.5, y = 2.1, z;
```

| Εντολή | Τι γίνεται |
|---|---|
| `k + x` → `6.5` | Η τιμή του `k` μετατρέπεται σε `double` **πριν** την εφαρμογή του `+` |
| `z = k / m;` | Πρώτα αποτιμάται η `k / m` (ακέραια!) → `1`, και **μετά** μετατρέπεται σε `double` `1.0` για ανάθεση στη `z` |
| `n = x * y;` | Η διαφάνεια: πρώτα `x * y` → `3.15`, μετά μετατροπή σε `int` `3` στη `n`. **Βλ. ⚠️** |

> [!warning] ⚠️ Σημείωση: το `n = x * y;` ΔΕΝ κάνει compile στη Java
> Η Java **δεν** μετατρέπει αυτόματα `double` → `int` (θα χανόταν πληροφορία). Το `javac` δίνει:
> `error: incompatible types: possible lossy conversion from double to int`
> Σωστά: **`n = (int) (x * y);`** → `3`. Η περιγραφή της διαφάνειας ισχύει σε γλώσσες όπως η C, όχι στη Java.

## 3. Ρητή μετατροπή – casting (II-48)

> [!note] Ορισμός
> Η **ρητή μετατροπή** τύπων ονομάζεται **casting**: `(τύπος) έκφραση`.
> Το cast έχει **υψηλή προτεραιότητα** – εφαρμόζεται μόνο στον **αμέσως επόμενο** τελεστέο.

```java
int n1 = 2, d1 = 4;
double frac = (double) n1 / (double) d1;   // 2.0 / 4.0 = 0.5
```

| Εντολή | Τιμή `frac` | Εξήγηση |
|---|---|---|
| `frac = (double) n1 / (double) d1;` | `0.5` | διαίρεση πραγματικών |
| `frac = (double) n1 / d1;` | `0.5` | συνδυασμός ρητής και αυτόματης: το `d1` γίνεται `double` αυτόματα |
| `frac = n1 / (double) d1;` | `0.5` | ομοίως |
| `frac = (double) (n1 / d1);` | **`0.0`** | πρώτα `2/4 = 0` (ακέραια), μετά `0.0` |
| `frac = n1 / d1;` | **`0.0`** | ισοδύναμο με το προηγούμενο (αυτόματη μετατροπή) |

> [!important] Κανόνας
> Για να πάρεις πραγματική διαίρεση από ακεραίους, **ένας τουλάχιστον** τελεστέος πρέπει να γίνει `double` **πριν** τη διαίρεση.

## 4. Ο πίνακας της διαφάνειας II-49

| Έκφραση | Τύπος | Τιμή |
|---|---|---|
| `"1234" + 99` | `String` | `"123499"` |
| `Integer.parseInt("123")` | `int` | `123` |
| `(int) 2.71828` | `int` | `2` |
| `Math.round(2.71828)` | `long` | `3` |
| `(int) Math.round(2.71828)` | `int` | `3` |
| `(int) Math.round(3.14159)` | `int` | `3` |
| `11 * 0.3` | `double` | `3.3` |
| `(int) 11 * 0.3` | `double` | `3.3` |
| `11 * (int) 0.3` | `int` | `0` |
| `(int) (11 * 0.3)` | `int` | `3` |

> [!example]- Γιατί `(int) 11 * 0.3` είναι `double`;
> Το cast δένει πιο σφιχτά από το `*`: `((int) 11) * 0.3` = `11 * 0.3` = `3.3` (`double`). Το cast εφαρμόστηκε στο `11`, που ήταν ήδη `int` – δεν έκανε τίποτα.
> Στο `11 * (int) 0.3` το cast κόβει το `0.3` σε `0` → `11 * 0 = 0`.

## 5. Πώς «κόβει» και πώς «στρογγυλεύει» ➕

| Έκφραση | Τιμή | Κανόνας |
|---|---|---|
| `(int) 3.99` | `3` | το cast **κόβει** (truncation), δεν στρογγυλεύει |
| `(int) -2.7` | `-2` | κόβει **προς το μηδέν** (όχι −3) |
| `Math.round(2.5)` | `3` | στρογγυλοποίηση |
| `Math.round(-2.5)` | `-2` | το .5 πάει «προς τα πάνω» (προς +∞) |
| `(int) Math.floor(-2.7)` | `-3` | `floor` = προς τα κάτω |
| `(byte) 200` | `-56` | εκτός πεδίου → «τυλίγεται» (200 − 256) |
| `(int) 3e10` | `2147483647` | `double` πολύ μεγάλο → κολλάει στο `Integer.MAX_VALUE` |
| `(int) 'A'` / `(char) 65` | `65` / `'A'` | `char` ↔ `int` |

> [!warning] Τι ΔΕΝ μπορεί να γίνει με cast
> - `(int) "5"` ✗ και `(String) 5` ✗ → για `String` ↔ αριθμό χρησιμοποιείς **μεθόδους**: `Integer.parseInt("5")`, `"" + 5` ή `String.valueOf(5)`.
> - `(int) true` ✗, `(boolean) 1` ✗ → το `boolean` δεν μετατρέπεται σε τίποτα.

## 6. Μετατροπή με μεθόδους

| Από → Σε | Μέθοδος | Παράδειγμα |
|---|---|---|
| `String` → `int` | `Integer.parseInt(s)` | `Integer.parseInt("-42")` → `-42` |
| `String` → `double` | `Double.parseDouble(s)` | `Double.parseDouble("5")` → `5.0` |
| `double` → `long` (στρογγ.) | `Math.round(x)` | `Math.round(2.7)` → `3L` |
| οτιδήποτε → `String` | `"" + x` ή `String.valueOf(x)` | `"" + 3.5` → `"3.5"` |
| `String` → `char` | `s.charAt(0)` | `"abc".charAt(0)` → `'a'` |

> [!warning] `parseInt` είναι αυστηρό
> `Integer.parseInt("5.0")` → `NumberFormatException` · `Integer.parseInt(" 5")` → `NumberFormatException` (κενό!) · `Integer.parseInt("")` → `NumberFormatException`.

## 7. Παράδειγμα: Τυχαίος ακέραιος μεταξύ 0 και N−1 (II-50)

```java
public class RandomInt {
    public static void main(String[] args) {
        int N = Integer.parseInt(args[0]);   // String to int (method)
        double r = Math.random();            // double between 0.0 and 1.0 but < 1.0
        int n = (int) (r * N);               // int to double (automatic), double to int (cast)
        System.out.println("random integer is " + n);   // int to String (automatic)
    }
}
```
```
% java RandomInt 6       → random integer is 3
% java RandomInt 6       → random integer is 0
% java RandomInt 10000   → random integer is 3184
```

> [!important] Γενικός τύπος ➕
> Τυχαίος ακέραιος στο **[a, b]** (και τα δύο άκρα): **`a + (int) (Math.random() * (b - a + 1))`**
> - Ζάρι: `1 + (int) (Math.random() * 6)` → 1…6
> - Στο **[i, N−1]** (ανακάτεμα τράπουλας, IV-23): `i + (int) (Math.random() * (N - i))`

> [!warning] Η παρένθεση μετράει
> `(int) Math.random() * N` → **πάντα 0**! Το cast εφαρμόζεται πρώτα στο `Math.random()` (που είναι < 1 → 0), και `0 * N = 0`.

## 8. Σιωπηρό cast στους σύνθετους τελεστές ➕

```java
int i = 5;
i = i + 2.7;    // ✗ compile: double → int
i += 2.7;       // ✓ !!  ισοδυναμεί με  i = (int) (i + 2.7);  → i = 7
```
Οι σύνθετοι τελεστές (`+=`, `-=`, `*=`, …) περιέχουν **κρυφό cast** στον τύπο της μεταβλητής. Βολικό για `short`/`char`, επικίνδυνο γιατί κρύβει απώλεια ακρίβειας.

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - `double avg = sum / count;` με `int` `sum`, `count` → ακέραια διαίρεση. Σωστά: `(double) sum / count`.
> - `(double) (sum / count)` → **πολύ αργά**, η διαίρεση έχει ήδη γίνει.
> - `int x = Math.round(y);` → `round` επιστρέφει `long`.
> - `(int) Math.random() * N` → πάντα 0.
> - Να περιμένεις ότι το `(int)` στρογγυλεύει: `(int) 2.99 = 2`.
