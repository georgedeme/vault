# 10 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα II. Για την τελευταία ώρα πριν το διαγώνισμα.

## 1. Οι βασικοί τύποι

| Τύπος | Μέγεθος | Πεδίο / Ακρίβεια | Κυριολεκτικά |
|---|---|---|---|
| `byte` | 8 bit | −128 … 127 | |
| `short` | 16 bit | −32.768 … 32.767 | |
| `int` | 32 bit | −2³¹ … 2³¹−1 (≈ ±2,1 δισ.) | `17`, `-32` |
| `long` | 64 bit | ≈ ±9,2 × 10¹⁸ | `3000000000L` |
| `float` | 32 bit | 10⁻³⁷ … 10³⁸, 6 ψηφία | `1.5f` |
| `double` | 64 bit | 10⁻³⁰⁷ … 10³⁰⁸, 15 ψηφία | `3.14`, `6.022e23`, `.5` |
| `char` | 16 bit | `'\u0000'` … `'￿'` | `'A'`, `'\n'` |
| `boolean` | — | `true`, `false` | |
| `String` | *(κλάση)* | ακολουθία χαρακτήρων | `"Hi"`, `""` |

**Τύπος δεδομένων** = σύνολο τιμών + σύνολο λειτουργιών. **Βαθμωτοί** = τιμές που δεν διασπώνται. **Απαριθμητοί** (`int`, `char`) = έχουν προκάτοχο/διάδοχο.

## 2. Αριθμητική

| Κανόνας | Παράδειγμα |
|---|---|
| `int / int` = **ακέραιο** πηλίκο (κόβει προς το 0) | `7/2 = 3`, `-7/2 = -3`, `2/4 = 0` |
| `%` παίρνει το πρόσημο του **αριστερού** | `-7%2 = -1`, `7%-2 = 1` |
| Ταυτότητα | `a == (a/b)*b + a%b` |
| Αν ένας τελεστέος είναι `double` → `double` | `7/2.0 = 3.5` |
| `int` ÷ 0 | `ArithmeticException` |
| `double` ÷ 0 | `Infinity` · `0.0/0.0 = NaN` |
| Υπερχείλιση `int` | τυλίγεται: `MAX_VALUE + 1 = MIN_VALUE` |
| Περιττός | `n % 2 != 0` (όχι `== 1`!) |

## 3. Προτεραιότητα και εταιρικότητα

| Προτ. | Τελεστές | Εταιρικότητα |
|---|---|---|
| 1 | `( )`, κλήσεις μεθόδων | |
| 2 | μοναδιαίοι `+ -`, `!`, `++ --`, cast `(τύπος)` | δεξιά → αριστερά |
| 3 | `* / %` | αριστερά → δεξιά |
| 4 | δυαδικοί `+ -` (και συνένωση `String`) | αριστερά → δεξιά |
| 5 | `< <= > >=` | |
| 6 | `== !=` | |
| 7 | `&&` | |
| 8 | `\|\|` | |
| 9 | `=`, `+=`, `-=`, … | δεξιά → αριστερά |

## 4. Μετατροπές

| Θέλω | Γράφω | Προσοχή |
|---|---|---|
| `int` → `double` | αυτόματα | |
| `double` → `int` | `(int) x` | **κόβει**: `(int) -2.7 = -2` |
| στρογγυλοποίηση | `(int) Math.round(x)` | `round` → `long` · `round(-2.5) = -2` |
| πραγματική διαίρεση ακεραίων | `(double) a / b` | ✗ `(double)(a / b)` |
| `String` → `int` / `double` | `Integer.parseInt(s)` / `Double.parseDouble(s)` | `NumberFormatException` |
| οτιδήποτε → `String` | `"" + x` | |
| `char` ↔ `int` | `(int) 'A' = 65`, `(char) 65 = 'A'` | `'a' + 1` είναι **int** |
| ψηφίο-χαρακτήρας → αριθμός | `ch - '0'` | |
| τυχαίο στο [a, b] | `a + (int) (Math.random() * (b - a + 1))` | ✗ `(int) Math.random() * N` = 0 |

**Διεύρυνση (αυτόματα):** `byte → short → int → long → float → double`, `char → int`. Αντίθετα θέλει cast (εκτός από `+=` κτλ., που κάνουν σιωπηρό cast).

## 5. `String` και `char`

| Έκφραση | Τιμή |
|---|---|
| `1 + 2 + "3"` | `"33"` |
| `"1" + 2 + 3` | `"123"` |
| `'a' + 'b'` | `195` |
| `"" + 'a' + 'b'` | `"ab"` |
| `'7' - '0'` | `7` |

ASCII: `' '` = 32 · `'0'` = 48 · `'A'` = 65 · `'a'` = 97 · `'~'` = 126 · μικρό − κεφαλαίο = 32 · κεφαλαία **πριν** τα μικρά.
`s.length()` · `s.charAt(i)` · `s.equals(t)` (όχι `==`).

## 6. `boolean`

| `a` | `b` | `!a` | `a && b` | `a \|\| b` |
|---|---|---|---|---|
| F | F | T | F | F |
| F | T | T | F | T |
| T | F | F | F | T |
| T | T | F | **T** | T |

Δίσεκτο: `(year % 4 == 0) && (year % 100 != 0 || year % 400 == 0)` · ✗ `1 <= x <= 10` → ✓ `1 <= x && x <= 10`

## 7. `Math`

`abs` `max` `min` `sqrt` `pow` (→ `double`) `exp` `log` (= ln) `sin/cos/tan` (ακτίνια) `round` (→ `long`) `random` ([0, 1)) `floor` `ceil` · σταθερές `Math.PI`, `Math.E` · **Δεν υπάρχει** τελεστής δύναμης (`^` = XOR).

## 8. Ανακρίβειες

| Σφάλμα | Τι είναι | Παράδειγμα |
|---|---|---|
| Αναπαράστασης / στρογγυλοποίησης | πεπερασμένα bits | `0.1 + 0.2 != 0.3` |
| Ακύρωσης | ο μικρός τελεστέος χάνεται | `1 + 1e-17 == 1` |
| Υπορροής | πολύ μικρό → 0 | `1e-200 * 1e-200 = 0.0` |
| Υπερχείλισης | πολύ μεγάλο | `MAX_VALUE + 1 < 0`, `1e308*10 = Infinity` |

Σύγκριση `double`: `Math.abs(a - b) < EPS` · συνθήκη βρόχου με `<=`, ποτέ `!=`.

> [!warning] Οι «παγίδες» σε μια ματιά
> - `5 / 2` = **2** · `1 / 2 * x` = **0** · `(a + b) / 2` με ints κόβει
> - `n = x * y;` (`int` = `double`) **δεν κάνει compile** (⚠️ αντίθετα με τη διαφάνεια II-47)
> - `float f = 1.5;` ✗ · `long L = 3000000000;` ✗ · `c = c + 1;` (με `char c`) ✗ · `int r = Math.round(x);` ✗
> - `"Sum: " + a + b` → συνένωση, όχι άθροισμα
> - `6 ^ 4` = **2** (XOR), όχι 1296
> - `010` = **8** (οκταδικό)
> - `Math.sqrt(-1)` = `NaN` σιωπηλά · `NaN == NaN` είναι `false`
> - `int` υπερχειλίζει **χωρίς** μήνυμα
