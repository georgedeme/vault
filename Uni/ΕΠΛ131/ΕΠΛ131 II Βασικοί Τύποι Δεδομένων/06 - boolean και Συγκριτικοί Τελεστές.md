# 06 - boolean και Συγκριτικοί Τελεστές

Ο τύπος `boolean`, οι λογικοί τελεστές, οι συγκριτικοί τελεστές και το παράδειγμα του δίσεκτου έτους (διαφάνειες II-26 … II-34).

## 1. Ο τύπος `boolean`

> [!note] Τύπος δεδομένων `boolean` για λογικές τιμές (II-26)
> - Χρησιμεύει στον **έλεγχο της λογικής και της ροής** του προγράμματος.
> - Σύνολο τιμών: **`true`, `false`**
> - Λειτουργίες: **σύζευξη** (λογικό και), **διάζευξη** (λογικό ή), **άρνηση**
> - Τελεστές: **`&&`** · **`||`** · **`!`**

### Πίνακες αληθείας (II-27)

| `a` | `!a` |
|---|---|
| `true` | `false` |
| `false` | `true` |

| `a` | `b` | `a && b` | `a \|\| b` |
|---|---|---|---|
| `false` | `false` | `false` | `false` |
| `false` | `true` | `false` | `true` |
| `true` | `false` | `false` | `true` |
| `true` | `true` | **`true`** | `true` |

> [!tip] Σύνδεση με το ΕΠΛ111
> Είναι ακριβώς οι `¬`, `∧`, `∨` της προτασιακής λογικής – βλ. [[Uni/ΕΠΛ111/ΕΠΛ111 Προτασιακή-Κατηγορική Λογική/01 - Προτάσεις και Λογικοί Τελεστές|01 - Προτάσεις και Λογικοί Τελεστές]]. Το `→` δεν υπάρχει ως τελεστής στη Java· γράφεται `!p || q`.

## 2. Συγκριτικοί (σχεσιακοί) τελεστές (II-28, II-29)

> [!note] Ορισμός
> Λαμβάνουν τελεστέους **ενός** τύπου και δίνουν αποτέλεσμα τύπου **`boolean`**.

| Τελεστής | Σημασία | `true` | `false` |
|---|---|---|---|
| `==` | ίσο | `2 == 2` | `2 == 3` |
| `!=` | διάφορο | `3 != 2` | `2 != 2` |
| `<` | μικρότερο | `2 < 13` | `2 < 2` |
| `<=` | μικρότερο ή ίσο | `2 <= 2` | `3 <= 2` |
| `>` | μεγαλύτερο | `13 > 2` | `2 > 13` |
| `>=` | μεγαλύτερο ή ίσο | `3 >= 2` | `2 >= 3` |

| Ερώτηση | Έκφραση Java |
|---|---|
| Μη αρνητική διακρίνουσα; | `(b*b - 4.0*a*c) >= 0.0` |
| Αρχή αιώνα; | `(year % 100) == 0` |
| Έγκυρος μήνας; | `(month >= 1) && (month <= 12)` |

> [!warning] Παγίδες σύγκρισης ➕
> - **`1 <= month <= 12`** ✗ compile error: το `1 <= month` δίνει `boolean` και μετά `boolean <= 12` δεν ορίζεται. Σωστά: `1 <= month && month <= 12`.
> - **`=` αντί `==`**: `if (x = 5)` ✗ compile (το `x = 5` είναι `int`). **Αλλά** `if (done = true)` με `boolean done` **κάνει compile** και είναι **πάντα αληθές** – ύπουλο λογικό λάθος.
> - Τα `=<`, `=>`, `<>` **δεν υπάρχουν** · γράφεται `<=`, `>=`, `!=`.
> - Σε `boolean` δεν υπάρχει μετατροπή σε αριθμό (όχι όπως στη C): `boolean b = 1;` ✗, `if (x)` με `int x` ✗.
> - `if (found == true)` δουλεύει αλλά είναι περιττό – γράψε `if (found)`· αντίστοιχα `if (!found)` αντί `found == false`.

## 3. Παράδειγμα: Είναι δεδομένο έτος δίσεκτο; (II-30)

> [!note] Ο κανόνας
> Ένα έτος είναι δίσεκτο εάν **είτε** (i) διαιρείται με το 400, **ή** (ii) διαιρείται με το 4 **αλλά όχι** με το 100.
> Εναλλακτική διατύπωση: (i) διαιρείται με το 4, **και** (ii) **εάν** διαιρείται με το 100, τότε πρέπει να διαιρείται **και** με το 400.

| Έτος | `% 4 == 0` | `% 100 != 0` | `% 400 == 0` | Δίσεκτο; |
|---|---|---|---|---|
| 2004 | ✓ | ✓ | ✗ | **true** |
| 1900 | ✓ | ✗ | ✗ | **false** |
| 2000 | ✓ | ✗ | ✓ | **true** |
| 2023 | ✗ | ✓ | ✗ | **false** |

### Πρώτος ορισμός (II-31)

```java
public class LeapYear {
    public static void main(String[] args) {
        int year = Integer.parseInt(args[0]);
        boolean isLeapYear;

        // divisible by 4 but not 100
        isLeapYear = (year % 4 == 0) && (year % 100 != 0);

        // or divisible by 400
        isLeapYear = isLeapYear || (year % 400 == 0);

        System.out.println(isLeapYear);
    }
}
```

### Δεύτερος ορισμός (II-32)

```java
// divisible by 4 and
// if divisible by 100, it should also be divisible by 400
// (not divisible by 100 or divisible by 400)
isLeapYear = (year % 4 == 0) &&
             (year % 100 != 0 || year % 400 == 0);
```

> [!info]- Γιατί «αν Α τότε Β» γίνεται «όχι Α ή Β»
> Η υπο-συνθήκη «**εάν** διαιρείται με το 100, **τότε** διαιρείται με το 400» είναι συνεπαγωγή `P → Q` με `P = year % 100 == 0`, `Q = year % 400 == 0`. Από το ΕΠΛ111: `P → Q ≡ ¬P ∨ Q`, δηλαδή `year % 100 != 0 || year % 400 == 0`. Αυτή ακριβώς είναι η παρένθεση του δεύτερου ορισμού.

### Άρθρωση και Επαναχρησιμοποίηση (II-33)

```java
public class LeapYear {
    public static boolean isLeapYear(int year) {
        return (year % 4 == 0) &&
               (year % 100 != 0 || year % 400 == 0);
    }

    public static void main(String[] args) {
        int year = Integer.parseInt(args[0]);
        System.out.println(isLeapYear(year));
    }
}
```
```
% java LeapYear 2004     → true
% java LeapYear 1900     → false
% java LeapYear 2000     → true
```

**Ροή δεδομένων (II-34):** `args[0] = "2018"` → `Integer.parseInt` → `year = 2018` → `isLeapYear` → `System.out.println` → έξοδος στο standard channel.

> [!tip] Πρώτη γνωριμία με μεθόδους ➕
> - `public static boolean isLeapYear(int year)`: **τύπος επιστροφής** `boolean`, **παράμετρος** `int year`.
> - Το `return` επιστρέφει την τιμή στον καλούντα· στη `main` η κλήση `isLeapYear(year)` «αντικαθίσταται» από αυτή την τιμή.
> - Είναι εφαρμογή των αρχών **αφαιρετικότητας** και **επαναχρησιμοποίησης** → [[Uni/ΕΠΛ131/ΕΠΛ131 V Αρχές Ορθού Προγραμματισμού/01 - Αφαιρετικότητα, DRY και Απλότητα|Ενότητα V]].

## 4. Άλλοι λογικοί τελεστές ➕

| Τελεστής | Όνομα | Διαφορά |
|---|---|---|
| `&&`, `\|\|` | λογικό και/ή **short-circuit** | δεν αποτιμούν τον δεξιό τελεστέο αν δεν χρειάζεται |
| `&`, `\|` | λογικό και/ή **χωρίς** short-circuit | αποτιμούν **πάντα** και τους δύο |
| `^` | αποκλειστικό ή (XOR, ⊕) | `true ^ true` → `false` |

Η σημασία του short-circuit εξηγείται στο [[Uni/ΕΠΛ131/ΕΠΛ131 III Επιλογή και Επανάληψη/01 - Συνθήκες και Λογικές Εκφράσεις|III – Συνθήκες]].

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Αλυσιδωτή σύγκριση `a < b < c` ✗.
> - `=` αντί για `==` (ειδικά με `boolean`).
> - Λάθος δίσεκτο: `year % 4 == 0 && year % 100 != 0` μόνο → το 2000 βγαίνει λάθος (`false`).
> - `&` / `|` αντί για `&&` / `||` → κάνει compile, αλλά χάνεις το short-circuit (και μπορεί να «σκάσει» π.χ. σε διαίρεση με 0).
