# 04 - Παράδειγμα Τράπουλα

Κατασκευή, ανακάτεμα και εκτύπωση μιας τράπουλας με πίνακες `String` – και η μετατροπή του προγράμματος σε αρθρωτό (διαφάνειες IV-14 … IV-31).

## 1. Το πρόβλημα (IV-14)

> [!note] Αναπαράσταση
> 4 × 13 = **52 χαρτιά** (4 φύλλα – suits, 13 σειρές – ranks).
> Πίνακας με **52 θέσεις**, όπου η κάθε θέση αναπαριστά ένα **μοναδικό χαρτί** με `String` (π.χ. `"Queen of Hearts"`).

**Διάσπαση προβλήματος σε υπο-προβλήματα (IV-15):** (1) επιλογή τυχαίου χαρτιού, (2) δημιουργία τράπουλας, (3) ανακάτεμα, (4) εκτύπωση.

## 2. Επιλογή και εκτύπωση ενός τυχαίου χαρτιού (IV-15)

```java
String[] rank = { "2", "3", "4", "5", "6", "7", "8", "9", "10",
                  "Jack", "Queen", "King", "Ace" };
String[] suit = { "Clubs", "Diamonds", "Hearts", "Spades" };

int i = (int) (Math.random() * 13);   // between 0 and 12
int j = (int) (Math.random() * 4);    // between 0 and 3
System.out.println(rank[i] + " of " + suit[j]);
```
Οι πίνακες `rank`/`suit` λειτουργούν ως **πίνακες αντιστοίχισης**: αριθμός → όνομα.

## 3. Δημιουργία και εκτύπωση τράπουλας (IV-16)

```java
String[] deck = new String[rank.length * suit.length];
for (int i = 0; i < suit.length; i++)
    for (int j = 0; j < rank.length; j++)
        deck[i*rank.length + j] = rank[j] + " of " + suit[i];
for (int i = 0; i < 52; i++)
    System.out.println(deck[i]);
```

### Σε ποια σειρά εκτυπώνεται η τράπουλα;

- **A.** 2 of Clubs, 2 of Diamonds, 2 of Hearts, 2 of Spades, 3 of Clubs, …
- **B.** 2 of Clubs, 3 of Clubs, 4 of Clubs, 5 of Clubs, 6 of Clubs, …

> [!success]- Απάντηση
> **B.** Ο **εξωτερικός** βρόχος είναι στα φύλλα (`i` = suit), ο **εσωτερικός** στις σειρές (`j` = rank). Για `i = 0` (Clubs) γεμίζουν οι θέσεις `0 … 12` με όλες τις σειρές των Clubs, μετά `13 … 25` Diamonds κ.ο.κ.
>
> | Θέση | 0 | 1 | … | 12 | 13 | … | 51 |
> |---|---|---|---|---|---|---|---|
> | Χαρτί | 2 of Clubs | 3 of Clubs | … | Ace of Clubs | 2 of Diamonds | … | Ace of Spades |

> [!important] Ο τύπος του δείκτη
> Όταν γεμίζεις μονοδιάστατο πίνακα με δύο φωλιασμένους βρόχους: **θέση = εξωτερικός × (μέγεθος εσωτερικού) + εσωτερικός**.
> - Εδώ: `i * rank.length + j` = `i * 13 + j` → κάθε `i` «πηδάει» 13 θέσεις.
> - Αντίστροφα (➕): το χαρτί στη θέση `k` έχει φύλλο `suit[k / 13]` και σειρά `rank[k % 13]`.

## 4. Ανακάτεμα της τράπουλας (IV-18 … IV-23)

> [!note] Στόχος
> Να μπουν τα στοιχεία του πίνακα που αντιπροσωπεύει την τράπουλα σε **τυχαία σειρά** (κάθε διάταξη εξίσου πιθανή).

### Αλγόριθμος (ψευδοκώδικας)

```
Αλγόριθμος για το ανακάτεμα της τράπουλας deck (N χαρτιά):
for i ← 0 to N−1:
    r ← τυχαίος ακέραιος στο [i, N−1]          // επιλογή από το ΑΝΑΚΑΤΕΥΤΟ τμήμα deck[i..N−1]
    αντάλλαξε deck[i] και deck[r]
```

«Σε κάθε επανάληψη `i`, επέλεξε ένα τυχαίο χαρτί από το τμήμα της τράπουλας `deck[i]` μέχρι `deck[N-1]`. Αντάλλαξε το χαρτί αυτό με εκείνο που βρίσκεται στη θέση `deck[i]`.» Είναι ο αλγόριθμος **Fisher–Yates** (Knuth shuffle).

### Υλοποίηση (IV-22, IV-23)

```java
int N = deck.length;
for (int i = 0; i < N; i++) {
    int r = i + (int) (Math.random() * (N-i));   // τυχαίο ανάμεσα σε i και N-1
    String t = deck[r];                           // εναλλαγή
    deck[r] = deck[i];
    deck[i] = t;
}
```

| `i` | `(int) (Math.random() * (N-i))` | `i + (int) (Math.random() * (N-i))` |
|---|---|---|
| 0 | 0..51 | 0..51 |
| 1 | 0..50 | 1..51 |
| 2 | 0..49 | 2..51 |
| … | … | … |
| 50 | 0..1 | 50..51 |
| 51 | 0..0 | 51..51 |

> [!example]- Γιατί δουλεύει
> Μετά την επανάληψη `i`, οι θέσεις `0 … i` είναι «τελικές»: στη θέση `i` μπήκε ένα χαρτί διαλεγμένο **ομοιόμορφα** από όσα **δεν** έχουν ήδη τοποθετηθεί. Η 1η θέση έχει 52 επιλογές, η 2η 51, … → 52! εξίσου πιθανές διατάξεις.
> Η τελευταία επανάληψη (`i = 51`) ανταλλάσσει το χαρτί με τον εαυτό του – άχρηστη αλλά αβλαβής (θα αρκούσε `i < N-1`).

> [!warning] Η «αφελής» εκδοχή είναι **μεροληπτική** ➕
> ```java
> int r = (int) (Math.random() * N);   // τυχαίο σε ΟΛΗ την τράπουλα
> ```
> Φαίνεται εξίσου «τυχαίο», αλλά δίνει Nᴺ ισοπίθανες ακολουθίες επιλογών για N! διατάξεις. Επειδή το Nᴺ δεν διαιρείται ακριβώς με το N!, κάποιες διατάξεις βγαίνουν **πιο συχνά** από άλλες. Το `i + …(N-i)` είναι απαραίτητο.

## 5. Το πλήρες πρόγραμμα (IV-24)

«Βάζουμε τα διάφορα τμήματα μαζί για να συνθέσουμε ολόκληρο το πρόγραμμα»:

```java
public class Deck {
    public static void main(String[] args) {
        String[] suit = { "Clubs", "Diamonds", "Hearts", "Spades" };
        String[] rank = { "2", "3", "4", "5", "6", "7", "8", "9",
                          "10", "Jack", "Queen", "King", "Ace" };
        int SUITS = suit.length;          // αποφυγή "hardwired" σταθερών
        int RANKS = rank.length;
        int N = SUITS * RANKS;

        String[] deck = new String[N];    // κτίσιμο τράπουλας
        for (int i = 0; i < RANKS; i++)
            for (int j = 0; j < SUITS; j++)
                deck[SUITS*i + j] = rank[i] + " of " + suit[j];

        for (int i = 0; i < N; i++) {     // ανακάτεμα τράπουλας
            int r = i + (int) (Math.random() * (N-i));
            String t = deck[r];
            deck[r] = deck[i];
            deck[i] = t;
        }

        for (int i = 0; i < N; i++)       // εκτύπωση ανακατεμένης τράπουλας
            System.out.println(deck[i]);
    }
}
```

> [!note] Διαφορά από τη IV-16
> Εδώ ο εξωτερικός βρόχος είναι στις **σειρές** και ο εσωτερικός στα **φύλλα**, με θέση `SUITS*i + j`. Πριν το ανακάτεμα η σειρά είναι η **A**: 2 of Clubs, 2 of Diamonds, 2 of Hearts, 2 of Spades, 3 of Clubs, … Μετά το ανακάτεμα η αρχική σειρά δεν έχει σημασία.

> [!tip] «Αποφυγή hardwired σταθερών»
> `SUITS`, `RANKS`, `N` υπολογίζονται από τα `length`. Αν προσθέσεις ένα φύλλο ή αφαιρέσεις σειρές (π.χ. τράπουλα 32 φύλλων), αλλάζεις **μόνο** τους πίνακες `suit`/`rank`. (Η IV-16 χρησιμοποιεί ακόμα `i < 52` – κακή πρακτική.)

**Δοκιμή (IV-25):** κάθε εκτέλεση δίνει διαφορετική σειρά:
```
% java Deck          % java Deck
5 of Clubs           10 of Diamonds
Jack of Hearts       King of Spades
9 of Spades          2 of Spades
...                  ...
```

## 6. Εισάγοντας άρθρωση και επαναχρησιμοποίηση (IV-26, IV-27)

```java
public class Deck {
    public static String[] createDeck() {
        String[] suit = { "Clubs", "Diamonds", "Hearts", "Spades" };
        String[] rank = { "2", "3", "4", "5", "6", "7", "8", "9",
                          "10", "Jack", "Queen", "King", "Ace" };
        int SUITS = suit.length;
        int RANKS = rank.length;
        int N = SUITS * RANKS;
        String[] deck = new String[N];
        for (int i = 0; i < RANKS; i++)
            for (int j = 0; j < SUITS; j++)
                deck[SUITS*i + j] = rank[i] + " of " + suit[j];
        return deck;
    }

    public static void shuffleDeck(String[] deck) {
        int N = deck.length;
        for (int i = 0; i < N; i++) {
            int r = i + (int) (Math.random() * (N-i));
            String t = deck[r];
            deck[r] = deck[i];
            deck[i] = t;
        }
    }

    public static void displayDeck(String[] deck) {
        for (String s : deck)            // Νέα μορφή for – διέρχεται των στοιχείων του πίνακα
            System.out.println(s);
    }

    public static void main(String[] args) {
        String[] deck = createDeck();    // Δημιουργία
        shuffleDeck(deck);               // Επεξεργασία
        displayDeck(deck);               // Παρουσίαση
    }
}
```

> [!important] Τι κερδίσαμε
> - Η `main` διαβάζεται σαν περίληψη: **Δημιουργία → Επεξεργασία → Παρουσίαση**.
> - Κάθε μέθοδος έχει **μία ευθύνη** και μπορεί να **επαναχρησιμοποιηθεί** (π.χ. `shuffleDeck` για οποιονδήποτε πίνακα `String`).
> - Η `shuffleDeck` είναι `void` αλλά **αλλάζει** τον πίνακα του καλούντα – επειδή οι πίνακες είναι αναφορές ([[03 - Πίνακες ως Αναφορές και Μέθοδοι]]).
> - Οι εναλλακτικές διεπαφές (`createDeck()` που επιστρέφει vs `createDeck(String[] deck)` που γεμίζει) αναλύονται στο [[03 - Πίνακες ως Αναφορές και Μέθοδοι#4. Πίνακες ως παράμετροι και τιμές επιστροφής (IV-26 … IV-31)|03 §4]].

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Λάθος τύπος θέσης: `deck[i + j]` → γράφει πολλά χαρτιά στην **ίδια** θέση και αφήνει άλλες `null`.
> - `r = (int) (Math.random() * N)` – μεροληπτικό ανακάτεμα.
> - `r = i + (int) Math.random() * (N-i)` – το cast εφαρμόζεται μόνο στο `Math.random()` → πάντα `r = i` → **κανένα** ανακάτεμα.
> - Ανταλλαγή χωρίς βοηθητική μεταβλητή (`deck[r] = deck[i]; deck[i] = deck[r];`) → χάνεται ένα χαρτί και διπλασιάζεται άλλο.
> - `i < 52` αντί `i < deck.length`.
