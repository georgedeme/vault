# 02 - Εντολή if και if-else

Οι βασικές εντολές επιλογής: `if` και `if-else`, μπλοκ εντολών και η «κενή» εντολή (διαφάνειες III-14 … III-16).

## 1. Εντολή `if` (III-14)

> [!note] Σύνταξη και σημασιολογία
> ```
> if (συνθήκη) εντολή          if (C) S
> ```
> Αν η `C` είναι `true`, εκτελείται η `S`· αλλιώς η `S` **παρακάμπτεται** και η εκτέλεση συνεχίζει μετά το `if`.

```
      ┌────┐  ναι   ┌───┐
 ──►  │ C? │ ─────► │ S │ ──┐
      └────┘        └───┘   │
        │ όχι               ▼
        └──────────────────►●──►
```

```java
if (i == 1) N = N / 10;

if (i == 1) {              // μπλοκ: πολλές εντολές ως μία
    D = N % 10;
    N = N / 10;
}
```

> [!important] Το σώμα είναι **μία** εντολή
> Χωρίς `{ }`, στο `if` ανήκει **μόνο η αμέσως επόμενη εντολή**. Για περισσότερες, χρειάζεται **μπλοκ** `{ … }`.
> ```java
> if (i == 1)
>     D = N % 10;
>     N = N / 10;      // ✗ εκτελείται ΠΑΝΤΑ – η εσοχή δεν σημαίνει τίποτα για τη Java
> ```

## 2. Εντολή `if-else` (III-15)

> [!note] Σύνταξη και σημασιολογία
> ```
> if (συνθήκη) εντολή1 else εντολή2          if (C) S1 else S2
> ```
> Αν η `C` είναι `true` εκτελείται η `S1`, αλλιώς η `S2`. **Ακριβώς μία** από τις δύο εκτελείται.

```
          ┌────┐
  ┌──όχι──│ C? │──ναι──┐
  ▼       └────┘       ▼
┌────┐              ┌────┐
│ S2 │              │ S1 │
└────┘              └────┘
  └────────►●◄─────────┘
```

```java
if (x == 0) D = 0; else D = D / x;

if (x > 0.0) { y = Math.sqrt(x); z = Math.sqrt(y); }
else         { y = 0.0;          z = 0.0; }
```

## 3. Κενή εντολή και κενό `else` (III-16)

> [!note] Κενή εντολή (null statement)
> Ένα σκέτο `;` είναι έγκυρη εντολή που **δεν κάνει τίποτα** («do nothing»).

| Γράφεις | Ισοδυναμεί με | Σχόλιο |
|---|---|---|
| `if (x == 0); /* do nothing */ else y = 1/x;` | `if (x != 0) y = 1/x;` | |
| `if (x > 5) y = x * 2; else ; /* do nothing */` | `if (x > 5) y = x * 2;` | |
| **Γενικά:** `if (C); else S` | `if (!C) S` | Χρησιμοποιείται εάν είναι **πιο φυσικό** να εκφραστεί η `C` παρά η άρνησή της |
| **Γενικά:** `if (C) S else;` | `if (C) S` | **Δεν έχει νόημα** να υπάρχει κενό `else` |

> [!warning] Το «αθώο» ερωτηματικό ➕
> ```java
> if (x > 0);            // ← το σώμα του if είναι η ΚΕΝΗ εντολή
> {
>     System.out.println("θετικό");   // εκτελείται ΠΑΝΤΑ (απλό μπλοκ)
> }
> ```
> Κάνει compile χωρίς προειδοποίηση. Το ίδιο λάθος στο `while (…);` προκαλεί **άπειρο βρόχο** → [[05 - Εντολή while και Σύνθετοι Τελεστές Ανάθεσης]].
> Επίσης: `if (x > 0); else …` είναι ✓ (το `else` ανήκει στο `if` με κενό σώμα), αλλά `if (x > 0); y = 1; else …` ✗ compile («else without if»).

## 4. Ειδικές περιπτώσεις ➕

> [!warning] `=` αντί `==`
> - `if (x = 5)` με `int x` → ✗ compile (`int` δεν είναι `boolean`).
> - `if (done = true)` με `boolean done` → ✓ compile, **πάντα** `true`, και αλλάζει το `done`! Γράψε απλά `if (done)`.

> [!warning] Μεταβλητή που δηλώνεται μέσα στο `if`
> ```java
> if (x > 0) { int y = 1; }
> System.out.println(y);    // ✗ cannot find symbol – το y ζει μόνο μέσα στο { }
>
> int y;
> if (x > 0) y = 1;
> System.out.println(y);    // ✗ might not have been initialized
>
> int y;
> if (x > 0) y = 1; else y = 2;
> System.out.println(y);    // ✓ ο compiler βλέπει ότι ανατίθεται σε κάθε κλάδο
> ```

> [!tip] Ο τριαδικός τελεστής `? :`
> Για απλή επιλογή **τιμής**: `max = (a > b) ? a : b;` ισοδυναμεί με `if (a > b) max = a; else max = b;`.
> Είναι **έκφραση** (επιστρέφει τιμή), όχι εντολή. Δεν εμφανίζεται στις διαφάνειες – χρησιμοποίησέ τον με μέτρο.

> [!tip] Καλή πρακτική
> Βάζε **πάντα** `{ }`, ακόμη και για μία εντολή. Γλιτώνεις το λάθος της §1 όταν αργότερα προσθέσεις δεύτερη εντολή, και το «κρεμάμενο else» της [[03 - Φώλιασμα Επιλογών]].

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Παράλειψη `{ }` για πολλές εντολές (η εσοχή «ξεγελάει»).
> - `;` αμέσως μετά το `if (…)`.
> - Παράλειψη των παρενθέσεων γύρω από τη συνθήκη: `if x > 0` ✗.
> - Σύγχυση `if` με `while`: το `if` εκτελεί το σώμα **το πολύ μία** φορά (III-73).
