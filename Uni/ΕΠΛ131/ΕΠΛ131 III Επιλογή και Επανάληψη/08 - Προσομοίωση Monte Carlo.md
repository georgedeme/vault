# 08 - Προσομοίωση Monte Carlo

Επίλυση προβλημάτων πιθανοτήτων με **επαναλαμβανόμενα τυχαία πειράματα** – το παράδειγμα της καταστροφής του τζογαδόρου, και η σύνοψη των μοτίβων επανάληψης (διαφάνειες III-68 … III-80).

## 1. Η ιδέα

> [!note] Προσομοίωση Monte Carlo
> Αντί να λύσουμε ένα πρόβλημα πιθανοτήτων αναλυτικά, **το προσομοιώνουμε**: «στρίβουμε ψηφιακά κέρματα» (`Math.random()`), παρατηρούμε τι συμβαίνει, **επαναλαμβάνουμε πολλές φορές** και υπολογίζουμε **στατιστικές**.

Νόμισμα: `Math.random() < 0.5` → `true` με πιθανότητα 1/2.

## 2. Παράδειγμα: Η Καταστροφή του Τζογαδόρου (III-69)

> [!note] Το πρόβλημα
> Ο τζογαδόρος αρχίζει με ποσό **€stake** και βάζει στοιχήματα του **€1** (κερδίζει ή χάνει με πιθανότητα 1/2) μέχρις ότου **είτε** να εξαντλήσει το ποσό (€0) **ή** να φτάσει τον στόχο του **€goal**.
> - Τι πιθανότητες έχει να **κερδίσει**;
> - Πόσα στοιχήματα πρέπει να **παίξει**;

### Ψευδοκώδικας

```
wins ← 0
repeat trials times:                       // εξωτερικός βρόχος: πειράματα
    t ← stake
    while 0 < t < goal:                    // εσωτερικός βρόχος: ένα πείραμα
        if coin flip is heads: t ← t + 1
        else:                  t ← t − 1
    if t = goal: wins ← wins + 1
print wins, "wins of", trials
```

### Υλοποίηση (III-70)

```java
public class Gambler {
    public static void main(String[] args) {
        int stake  = Integer.parseInt(args[0]);
        int goal   = Integer.parseInt(args[1]);
        int trials = Integer.parseInt(args[2]);
        int wins = 0;

        // repeat experiment N times
        for (int i = 0; i < trials; i++) {
            // do one gambler's ruin experiment
            int t = stake;
            while (t > 0 && t < goal) {
                // flip coin and update
                if (Math.random() < 0.5) t++;
                else                     t--;
            }
            if (t == goal) wins++;
        }
        System.out.println(wins + " wins of " + trials);
    }
}
```

> [!important] Δομή: `for` μέσα στο οποίο υπάρχει `while`
> - **`for`** για τα πειράματα: ξέρουμε **πόσα** (`trials`) → απαριθμητή επανάληψη.
> - **`while`** για ένα πείραμα: **δεν** ξέρουμε πόσα στοιχήματα θα χρειαστούν → επανάληψη υπό συνθήκη.
> - Το `int t = stake;` είναι **μέσα** στο `for` – κάθε πείραμα ξεκινά από την αρχή. Αν ήταν έξω, το 2ο πείραμα θα ξεκινούσε με `t = 0` ή `t = goal` και δεν θα έμπαινε καν στο `while`.
> - Το `0 < t < goal` του ψευδοκώδικα **δεν** γράφεται έτσι σε Java· γράφεται `t > 0 && t < goal`.

### Εκτελέσεις (III-71)

```
% java Gambler 5 25 1000        → 191 wins of 1000
% java Gambler 5 25 1000        → 203 wins of 1000
% java Gambler 500 2500 1000    → 197 wins of 1000     (μετά από αρκετή ώρα…)
```

> [!note] Τα μαθηματικά γεγονότα
> - **Πιθανότητα νίκης = stake ÷ goal** (5/25 = 500/2500 = 20% – ταιριάζει με τα ~200/1000).
> - **Αναμενόμενος αριθμός στοιχημάτων = stake × επιθυμητό κέρδος** = stake × (goal − stake).
> - Παράδειγμα: 20% πιθανότητα να μετατρέψεις τα €500 σε €2500, αλλά αναμένεις να κάνεις **500 × (2500 − 500) = 1 εκατομμύριο** στοιχήματα του €1 – γι' αυτό η 3η εκτέλεση αργεί.
> - Κάθε εκτέλεση δίνει **διαφορετικό** αποτέλεσμα (τυχαιότητα)· με περισσότερα `trials` η εκτίμηση πλησιάζει την πραγματική πιθανότητα.

## 3. Με άρθρωση: η μέθοδος `Win` (III-72)

```java
public class Gambler {
    private static boolean Win(int s, int g) {
        while (s > 0 && s < g) {
            if (Math.random() < 0.5) s++;
            else                     s--;
        }
        return s == g;
    }

    public static void main(String[] args) {
        int stake  = Integer.parseInt(args[0]);
        int goal   = Integer.parseInt(args[1]);
        int trials = Integer.parseInt(args[2]);
        int wins = 0;
        for (int i = 0; i < trials; i++) {
            if (Win(stake, goal)) wins++;
        }
        System.out.println(wins + " wins of " + trials);
    }
}
```

> [!tip] Τι κερδίσαμε
> - Η `main` διαβάζεται σαν περιγραφή: «για κάθε πείραμα, αν κερδίσει, μέτρα». Ένα πείραμα = μία κλήση (**αφαιρετικότητα**, **μία ευθύνη** – Ενότητα V).
> - `private`: η `Win` είναι βοηθητική, δεν χρειάζεται να τη βλέπουν άλλες κλάσεις (**απόκρυψη λεπτομερειών**).
> - `return s == g;` επιστρέφει απευθείας την τιμή της σύγκρισης – όχι `if (s == g) return true; else return false;`.

> [!info]- Γιατί η `Win` μπορεί να αλλάζει το `s` χωρίς να «χαλάει» το `stake`; ➕
> Στη Java οι παράμετροι βασικών τύπων περνούν **με τιμή** (pass by value): το `s` είναι **αντίγραφο** του `stake`. Οι αλλαγές στο `s` δεν επηρεάζουν το `stake` της `main`, οπότε κάθε κλήση ξεκινά πάλι από το αρχικό ποσό.
> Με **πίνακες** τα πράγματα διαφέρουν – βλ. [[Uni/ΕΠΛ131/ΕΠΛ131 IV Πίνακες Μιας Διάστασης/03 - Πίνακες ως Αναφορές και Μέθοδοι|IV – 03 Πίνακες ως αναφορές]].
> ⚠️ Μικρή παρατήρηση στυλ: κατά σύμβαση οι μέθοδοι ξεκινούν με **μικρό** (`win`), όχι `Win`.

## 4. Σύνοψη Παραδειγμάτων Επανάληψης (III-78)

| Σκοπός | Κώδικας |
|---|---|
| Εκτύπωση δυνάμεων του 2 | `int v = 1;`<br>`for (int i = 0; i <= N; i++) {`<br>`    System.out.println(i + " " + v);`<br>`    v = 2*v;`<br>`}` |
| Μεγαλύτερη δύναμη του 2 που είναι ≤ N | `int v = 1;`<br>`while (v <= N/2)`<br>`    v = 2*v;`<br>`System.out.println(v);` |
| Πεπερασμένο άθροισμα (1 + 2 + … + N) | `int sum = 0;`<br>`for (int i = 1; i <= N; i++)`<br>`    sum += i;`<br>`System.out.println(sum);` |
| Πεπερασμένο γινόμενο (N! = 1 × 2 × … × N) | `int product = 1;`<br>`for (int i = 1; i <= N; i++)`<br>`    product *= i;`<br>`System.out.println(product);` |
| Πίνακας τιμών συνάρτησης | `for (int i = 0; i <= N; i++)`<br>`    System.out.println(i + " " + 2*Math.PI*i/N);` |
| Η συνάρτηση της ρήγας | `String ruler = " ";`<br>`for (int i = 1; i <= N; i++)`<br>`    ruler = ruler + i + ruler;`<br>`System.out.println(ruler);` |

> [!warning] Ψιλά γράμματα στη σύνοψη ➕
> - **Άθροισμα:** αρχική τιμή **0**. **Γινόμενο:** αρχική τιμή **1** (με 0 βγαίνει πάντα 0).
> - **Παραγοντικό σε `int`** υπερχειλίζει από το 13! και μετά – χρησιμοποίησε `long` (έως 20!).
> - **Πίνακας τιμών:** `2*Math.PI*i/N` – εδώ δουλεύει επειδή το `2*Math.PI` είναι ήδη `double`. Το `i/N*2*Math.PI` θα έδινε 0 για `i < N` (ακέραια διαίρεση πρώτα).
> - **Δυνάμεις του 2:** `v` σε `int` υπερχειλίζει για `N ≥ 31`.
