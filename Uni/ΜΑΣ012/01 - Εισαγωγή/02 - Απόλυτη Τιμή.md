# 02 - Απόλυτη Τιμή

Η απόλυτη τιμή μετράει **απόσταση**. Με αυτή τη ματιά λύνονται οι περισσότερες εξισώσεις και ανισώσεις, και πάνω της χτίζεται αργότερα ο ορισμός του ορίου.

## 1. Ορισμός

> [!note] Ορισμός
> $$\lvert x\rvert = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}$$
> **Γεωμετρικά:** $\lvert x\rvert$ = απόσταση του $x$ από το $0$ · $\lvert a - b\rvert$ = απόσταση των $a$ και $b$ στην ευθεία.

> [!important] $\sqrt{x^2} = \lvert x\rvert$
> **Όχι** $x$. Για $x = -3$: $\sqrt{(-3)^2} = \sqrt9 = 3 = \lvert -3\rvert$.
> Το $-x$ στον ορισμό **δεν** είναι αρνητικός αριθμός: για $x < 0$, το $-x$ είναι θετικό.

## 2. Ιδιότητες

| Ιδιότητα | Σχόλιο |
|---|---|
| $\lvert x\rvert \ge 0$ και $\lvert x\rvert = 0 \Leftrightarrow x = 0$ | |
| $\lvert -x\rvert = \lvert x\rvert$ | |
| $\lvert xy\rvert = \lvert x\rvert\,\lvert y\rvert$ | |
| $\left\lvert \dfrac{x}{y}\right\rvert = \dfrac{\lvert x\rvert}{\lvert y\rvert}$, $y \ne 0$ | |
| $\lvert x\rvert^2 = x^2$ | αλλά $\lvert x^3\rvert \neq x^3$ γενικά |
| $\lvert a + b\rvert \le \lvert a\rvert + \lvert b\rvert$ | **τριγωνική ανισότητα**· ισότητα ⇔ $ab \ge 0$ |
| $\big\lvert \lvert a\rvert - \lvert b\rvert \big\rvert \le \lvert a - b\rvert$ | αντίστροφη τριγωνική |

> [!warning] Η απόλυτη τιμή ΔΕΝ «μοιράζεται» στην πρόσθεση
> $\lvert 3 + (-5)\rvert = 2$, ενώ $\lvert 3\rvert + \lvert -5\rvert = 8$. Επίσης $\lvert a - b\rvert \le \lvert a\rvert + \lvert b\rvert$ (με **συν**, όχι $\lvert a\rvert - \lvert b\rvert$).

## 3. Εξισώσεις και ανισώσεις

> [!important] Βασικές ισοδυναμίες ($k > 0$)
> | Μορφή | Ισοδύναμο | Γεωμετρικά |
> |---|---|---|
> | $\lvert x\rvert = k$ | $x = k$ ή $x = -k$ | απόσταση από 0 ίση με $k$ |
> | $\lvert x\rvert < k$ | $-k < x < k$ | κοντά στο 0 |
> | $\lvert x\rvert > k$ | $x < -k$ ή $x > k$ | μακριά από το 0 |
> | $\lvert x - a\rvert < \delta$ | $a - \delta < x < a + \delta$ | $x$ σε απόσταση $< \delta$ από το $a$ |
> | $\lvert A\rvert = \lvert B\rvert$ | $A = B$ ή $A = -B$ | |

> [!tip] Προεπισκόπηση ορίων
> Το $0 < \lvert x - a\rvert < \delta$ σημαίνει: $x \in (a - \delta, a) \cup (a, a + \delta)$, δηλαδή «κοντά στο $a$ **αλλά όχι ίσο** με $a$». Είναι ακριβώς αυτό που γράφει ο ορισμός του ορίου.

### Ειδικές περιπτώσεις: όταν το $k$ δεν είναι θετικό

| | $k > 0$ | $k = 0$ | $k < 0$ |
|---|---|---|---|
| $\lvert x\rvert = k$ | $x = \pm k$ | $x = 0$ | $\varnothing$ |
| $\lvert x\rvert < k$ | $(-k, k)$ | $\varnothing$ | $\varnothing$ |
| $\lvert x\rvert \le k$ | $[-k, k]$ | $\{0\}$ | $\varnothing$ |
| $\lvert x\rvert > k$ | $(-\infty,-k) \cup (k,\infty)$ | $\mathbb R \setminus \{0\}$ | $\mathbb R$ |

> [!example]- Παράδειγμα 1: $\lvert 2x - 3\rvert \le 5$
> $-5 \le 2x - 3 \le 5 \Rightarrow -2 \le 2x \le 8 \Rightarrow -1 \le x \le 4$.
> Λύση: $[-1, 4]$.

> [!example]- Παράδειγμα 2: $\lvert x + 2\rvert > 3$
> $x + 2 < -3$ ή $x + 2 > 3 \Rightarrow x < -5$ ή $x > 1$.
> Λύση: $(-\infty, -5) \cup (1, \infty)$.
> Γεωμετρικά: $\lvert x - (-2)\rvert > 3$, σημεία σε απόσταση πάνω από 3 από το $-2$.

> [!example]- Παράδειγμα 3 (παγίδα): $\lvert x - 1\rvert = 2x + 1$
> Το δεξί μέλος περιέχει $x$, άρα **μπορεί να είναι αρνητικό**. Μια απόλυτη τιμή δεν ισούται ποτέ με αρνητικό, οπότε κάθε λύση χρειάζεται έλεγχο.
> - $x - 1 = 2x + 1 \Rightarrow x = -2$. Έλεγχος: $2(-2) + 1 = -3 < 0$ ⇒ **απορρίπτεται**.
> - $x - 1 = -(2x + 1) \Rightarrow 3x = 0 \Rightarrow x = 0$. Έλεγχος: $\lvert 0 - 1\rvert = 1 = 2\cdot0 + 1$ ✓
>
> Λύση: $x = 0$.

> [!example]- Παράδειγμα 4: δύο απόλυτες, $\lvert x - 1\rvert + \lvert x + 2\rvert = 5$
> Σημεία αλλαγής: $x = -2$ και $x = 1$. Σπάω σε περιπτώσεις:
>
> | Διάστημα | Εξίσωση χωρίς απόλυτα | Λύση | Δεκτή; |
> |---|---|---|---|
> | $x < -2$ | $-(x - 1) - (x + 2) = 5 \Rightarrow -2x - 1 = 5$ | $x = -3$ | ✓ ($-3 < -2$) |
> | $-2 \le x < 1$ | $-(x - 1) + (x + 2) = 5 \Rightarrow 3 = 5$ | καμία | — |
> | $x \ge 1$ | $(x - 1) + (x + 2) = 5 \Rightarrow 2x + 1 = 5$ | $x = 2$ | ✓ |
>
> Λύση: $x \in \{-3, 2\}$.
> **Γεωμετρικά:** άθροισμα αποστάσεων από το $1$ και το $-2$ ίσο με 5. Τα δύο σημεία απέχουν 3, άρα κάθε σημείο **ανάμεσά** τους δίνει άθροισμα ακριβώς 3.
> Γι' αυτό η $\lvert x - 1\rvert + \lvert x + 2\rvert = 3$ έχει λύση **ολόκληρο το $[-2, 1]$** και η $\lvert x - 1\rvert + \lvert x + 2\rvert = 2$ **καμία**.

> [!example]- Παράδειγμα 5 (παγίδα): $\dfrac{1}{\lvert x - 2\rvert} > 3$
> Πρέπει $x \neq 2$. Τότε $\lvert x - 2\rvert > 0$, οπότε μπορώ να αντιστρέψω (ομόσημοι): $\lvert x - 2\rvert < \frac13$.
> $\Rightarrow \frac53 < x < \frac73$, **αλλά** $x \neq 2$.
> Λύση: $\left(\frac53, 2\right) \cup \left(2, \frac73\right)$.

## 4. Συχνά Λάθη

> [!warning] Προσοχή
> - $\sqrt{x^2} = x$: σωστό είναι $\lvert x\rvert$. Άρα και $\sqrt{(x-3)^2} = \lvert x - 3\rvert$.
> - $\lvert x\rvert < k$ ⇒ «$x < \pm k$»: δεν έχει νόημα. Γράψε $-k < x < k$.
> - Στο $\lvert x\rvert > k$ οι λύσεις ενώνονται με **ή** (δύο κομμάτια), όχι με διπλή ανισότητα: το «$-k > x > k$» είναι κενό.
> - Λύσεις της $\lvert A\rvert = B$ χωρίς έλεγχο $B \ge 0$ (Παράδειγμα 3).
> - Ξεχνάς το $x \ne a$ όταν η απόλυτη τιμή είναι σε παρονομαστή (Παράδειγμα 5).
