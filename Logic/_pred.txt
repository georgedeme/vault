Κατηγορική Λογική (Predicate Logic)

Πρόταση: μια δήλωση που είναι αληθής (true) ή ψευδής (false),
              αλλά όχι αληθής και ψευδής ταυτόχρονα

x>3  x = y + 3  x+ y= z

• Δηλώσεις που εμπλέκουν μεταβλητές εμφανίζονται συχνά σε μαθηματικά επιχειρήματα

• Αλλά δεν είναι λογικές προτάσεις αφού δεν είναι ούτε αληθής ούτε ψευδής – η τιμή
    αληθείας τους εξαρτάται από την τιμή των μεταβλητών

• Χρειαζόμαστε εργαλεία πέραν της Προτασιακής Λογικής → Κατηγορική Λογική

===== PAGE 3 =====
          Κατηγορική Λογική (Predicate Logic)

Η δήλωση “x είναι μεγαλύτερο του 3” αποτελείται από δύο μέρη:
1. Τη μεταβλητή x – το αντικείμενο της δήλωσης
2. Το κατηγόρημα “είναι μεγαλύτερο του 3” το οποίο αναφέρεται σε κάποια ιδιότητα

    που έχει το αντικείμενο της δήλωσης

                                  P(x) : x είναι μεγαλύτερο του 3
                                                    ή

                                               P(x) : x > 3

===== PAGE 4 =====
   Κατηγορική Λογική (Predicate Logic)

Μπορούμε να έχουμε δηλώσεις με περισσότερες από μία μεταβλητές
                                 Q(x,y) : x = y + 3
                                R(x,y,z) : x + y = z

      P(x1,…,xκ) : δήλωση η οποία εμπλέκει τις μεταβλητές x1,…,xκ

===== PAGE 5 =====
    Δέσμευση Μεταβλητών (Binding Variables)

• Η δήλωση P(x1,…,xκ) γίνεται πρόταση όταν οι μεταβλητές x1,…,xκ δεσμευτούν

• Υπάρχουν δύο τρόποι με τους οποίους μπορεί να δεσμευτεί μία μεταβλητή
      1. Αναθέτοντας συγκεκριμένη τιμή στη μεταβλητή
      2. Χρησιμοποιώντας ποσοδείκτες (quantifiers)

• Πεδίο ορισμού (universe of discourse ή domain) – τιμές που μπορούν να
    πάρουν οι μεταβλητές

===== PAGE 6 =====
Ανάθεση Τιμής σε Μεταβλητή

Πεδίο ορισμού: όλοι οι ακέραιοι αριθμοί

P(x) : x > 3  Q(x,y) : x = y + 3  R(x,y,z) : x + y = z

P(4) : 4 > 3  Q(3,0) : 3 = 0 + 3  R(1,2,3) : 1 + 2 = 3
P(2) : 2 > 3  Q(1,2) : 1 = 2 + 3  R(0,0,1) : 0 + 0 = 1

P(4) ∨ P(2) P(4) ⨁ R(1,2,3) R(0,0,1) → R(1,2,3)

            Ποσοδείκτες (Quantifiers)

Καθολικός Ποσοδείκτης (Universal Quantifier)
Η P(x) είναι αληθής για κάθε τιμή που μπορεί να πάρει η μεταβλητή x από
το πεδίο ορισμού και συμβολίζεται ως ∀x P(x)

                             ∀ – καθολικός ποσοδείκτης
                   ∀x P(x) – για κάθε x, P(x) / για όλα τα x, P(x)

              Άρνηση και Ποσοδείκτες

                 P(x) : x έχει πάρει το μάθημα των Διακριτών Δομών

                                            ∀x P(x)
            Κάθε φοιτητής έχει πάρει το μάθημα των Διακριτών Δομών

                                           ¬∀x P(x)
   Δεν ισχύει ότι κάθε φοιτητής έχει πάρει το μάθημα των Διακριτών Δομών

                                           ∃x ¬P(x)
Υπάρχει κάποιος φοιτητής που δεν έχει πάρει το μάθημα των Διακριτών Δομών

                           ¬∀x P(x) ≡ ∃x ¬P(x)

Για κάθε x και y,αν x είναι θετικός και y είναι θετικός, τότε υπάρχει z τ.ω. z είναι θετικός

                                               και x + y = z

                          ∀x∀y ((x > 0) ∧ (y > 0) → ∃z (z > 0 ∧ x + y = z))
