# 07 - Τυπολόγιο

Το Κεφάλαιο 2 σε μία σελίδα.

## 1. Συναρτήσεις

| Βλέπεις | Απαιτείς |
|---|---|
| $A/B$ | $B \neq 0$ |
| $\sqrt{A}$ | $A \ge 0$ |
| $1/\sqrt{A}$ | $A > 0$ |
| $\ln A$ | $A > 0$ |
| $\tan A$ | $A \neq \frac\pi2 + k\pi$ |
| $\sin^{-1}A$, $\cos^{-1}A$ | $-1 \le A \le 1$ |

- Ίσες συναρτήσεις ⇔ **ίδιο πεδίο** και ίδιες τιμές · απλοποίηση **δεν** αλλάζει το πεδίο
- Βοήθημα: **μονοσήμαντη** = συνάρτηση · **αμφιμονοσήμαντη** = 1-1 · «πεδίο τιμών» στις ασκήσεις = σύνολο τιμών · $\Gamma_f = \{(x, y) : y = f(x)\}$
- Σύνολο τιμών: λύσε $y = f(x)$ ως προς $x$, ή χτίσε από μέσα προς τα έξω ($-1 \le \cos x \le 1 \Rightarrow \dots$)
- Ακέραιο μέρος $[x]$: μεγαλύτερος ακέραιος $\le x$ · $[-0.4] = -1$ · $x - [x] \in [0, 1)$, περίοδος 1
- **Άρτια** $f(-x) = f(x)$ (άξονας $y$) · **Περιττή** $f(-x) = -f(x)$ (αρχή) · χρειάζεται **συμμετρικό πεδίο** · περιττή με $0 \in D_f$ ⇒ $f(0) = 0$
- Γινόμενο: άρτια·άρτια = περιττή·περιττή = **άρτια** · άρτια·περιττή = περιττή · $f = \frac{f(x) + f(-x)}{2} + \frac{f(x) - f(-x)}{2}$
- **Περιοδική:** $f(x + T) = f(x)$ για **κάθε** $x$ (και $x \pm T \in D_f$) · $\sin, \cos$: $2\pi$ · $\tan$: $\pi$ · $\sin^2$, $\lvert\sin\rvert$: $\pi$ · $f(Bx)$: $T/\lvert B\rvert$ · άθροισμα με $T/S = p/q$: $qT = pS$ (όχι πάντα θεμελιώδης) · $T/S$ άρρητος ⇒ όχι περιοδική · σταθερή: καμία θεμελιώδης

**Είδη συναρτήσεων**

- Σταθερή $c$ ⊂ μονώνυμο $ax^n$ ($n \in \mathbb N$) ⊂ πολυώνυμο ⊂ ρητή $\frac{p}{q}$ ⊂ αλγεβρική (+ ρίζες) · **υπερβατική** = μη αλγεβρική ($\sin$, $e^x$, $\ln$, $\sinh$, $x^{\sqrt2}$, $x^x$)
- Εκθέτης στο $x^r$: $r \in \mathbb N$ μονώνυμο · αρνητικός ακέραιος ρητή · ρητός αλγεβρική · άρρητος ή με μεταβλητή υπερβατική · ο **συντελεστής** μπορεί να είναι οτιδήποτε ($\sqrt2\,x^3$, $\frac{x^2}{5}$ μονώνυμα)
- Πεδίο: πολυώνυμο $\mathbb R$ · ρητή $q(x) \ne 0$ · **απλοποίησε πριν κατατάξεις, αλλά κράτα το πεδίο** ($\sin^2 + \cos^2 = 1$ σταθερή · $\frac{x^2 - 4}{x - 2}$ ρητή, όχι πολυώνυμο · $\sqrt{x^2} = \lvert x\rvert$ αλγεβρική)
- $\deg(pq) = \deg p + \deg q$ · $\deg(p + q) \le \max$ · $\deg(p \circ q) = \deg p \cdot \deg q$ · άπειρες ρίζες ⇒ μηδενικό πολυώνυμο
- Αλγεβρική $\pm, \times, \div$ υπερβατική ⇒ υπερβατική · συνεχής μη σταθερή περιοδική ⇒ υπερβατική
- **Λυμένη** $y = f(x)$ · **πεπλεγμένη** $F(x, y) = 0$ · τρόπος γραφής, όχι είδος · μπορεί να ορίζει 0, 1 ή πολλές συναρτήσεις

## 2. Πράξεις

- $f \pm g$, $fg$: $D_f \cap D_g$ · $f/g$: επιπλέον $g(x) \ne 0$
- $(f \circ g)(x) = f(g(x))$ · $D_{f \circ g} = \{x \in D_g : g(x) \in D_f\}$ · **πεδίο πριν την απλοποίηση** · $f \circ g \neq g \circ f$ · $f \circ (g \circ h) = (f \circ g) \circ h$
- $f^2(x) = (f(x))^2 \ne f(f(x))$ · $f^{-1} \ne \frac1f$
- Άγνωστη εσωτερική: λύσε $f(g(x)) = \dots$ ως προς $g(x)$ · άγνωστη εξωτερική: $u = g(x)$, $x$ συναρτήσει $u$ (π.χ. $f(x + 1) = \dots \Rightarrow x \to x - 1$)

| $f(x) + c$ | $f(x - c)$ | $-f(x)$ | $f(-x)$ | $cf(x)$ | $f(cx)$ |
|---|---|---|---|---|---|
| πάνω | **δεξιά** | ανάκλαση στον $x$ | ανάκλαση στον $y$ | κατακόρυφο τέντωμα | οριζόντια **συμπίεση** |

## 3. Αντίστροφη

- 1-1: $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$ · οριζόντια ευθεία το πολύ 1 σημείο · γνησίως μονότονη ⇒ 1-1
- $D_{f^{-1}} = R_f$ · $R_{f^{-1}} = D_f$ · γράφημα συμμετρικό ως προς $y = x$
- Βήματα: 1-1; → $y = f(x)$ → λύσε ως προς $x$ → $x \leftrightarrow y$ → **πεδίο**
- $f^{-1}(x) \neq 1/f(x)$ · εναλλακτικά: λύσε $f(f^{-1}(x)) = x$ ως προς $f^{-1}(x)$
- $f^{-1}(x) = c \iff x = f(c)$ (χωρίς τύπο) · κλαδική: αντίστρεψε κάθε κλάδο με πεδίο το σύνολο τιμών του
- $f$ συνεχής στο $[\alpha, \beta]$ ⇒ $f^{-1}$ συνεχής στο διάστημα με άκρα $f(\alpha), f(\beta)$

## 4. Τριγωνομετρικές

| $\theta$ | $0$ | $\frac\pi6$ | $\frac\pi4$ | $\frac\pi3$ | $\frac\pi2$ |
|---|---|---|---|---|---|
| $\sin$ | $0$ | $\frac12$ | $\frac{\sqrt2}{2}$ | $\frac{\sqrt3}{2}$ | $1$ |
| $\cos$ | $1$ | $\frac{\sqrt3}{2}$ | $\frac{\sqrt2}{2}$ | $\frac12$ | $0$ |
| $\tan$ | $0$ | $\frac{\sqrt3}{3}$ | $1$ | $\sqrt3$ | — |

- $180° = \pi$ · πρόσημα: Ι όλες, ΙΙ $\sin$, ΙΙΙ $\tan$, IV $\cos$
- $\sin^2 + \cos^2 = 1$ · $1 + \tan^2 = \sec^2$ · $1 + \cot^2 = \csc^2$
- $\sin(a \pm b) = \sin a\cos b \pm \cos a\sin b$ · $\cos(a \pm b) = \cos a\cos b \mp \sin a\sin b$
- $\sin 2\theta = 2\sin\theta\cos\theta$ · $\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$
- $\cos^2\theta = \frac{1 + \cos2\theta}{2}$ · $\sin^2\theta = \frac{1 - \cos2\theta}{2}$
- $\sin x = c$: $x = \sin^{-1}c + 2k\pi$ **ή** $\pi - \sin^{-1}c + 2k\pi$ · $\cos x = c$: $\pm\cos^{-1}c + 2k\pi$ · $\tan x = c$: $\tan^{-1}c + k\pi$
- $A\sin(Bx - C) + D$: πλάτος $\lvert A\rvert$, περίοδος $2\pi/\lvert B\rvert$, μετατόπιση $C/B$

| | Πεδίο | Σύνολο τιμών |
|---|---|---|
| $\sin^{-1}$ | $[-1, 1]$ | $[-\frac\pi2, \frac\pi2]$ |
| $\cos^{-1}$ | $[-1, 1]$ | $[0, \pi]$ |
| $\tan^{-1}$ | $\mathbb R$ | $(-\frac\pi2, \frac\pi2)$ |
| $\cot^{-1}$ | $\mathbb R$ | $(0, \pi)$ |
| $\sec^{-1}$ (Βοήθημα) | $\lvert x\rvert \ge 1$ | $[0, \frac\pi2) \cup [\pi, \frac{3\pi}{2})$ |
| $\csc^{-1}$ (Βοήθημα) | $\lvert x\rvert \ge 1$ | $(0, \frac\pi2] \cup (\pi, \frac{3\pi}{2}]$ |

- $\sin^{-1}(\sin x) = x$ **μόνο** στο $[-\frac\pi2, \frac\pi2]$ · $\cos(\sin^{-1}x) = \sqrt{1 - x^2}$ · $\sin^{-1}x + \cos^{-1}x = \frac\pi2$ · $\tan^{-1}x + \cot^{-1}x = \frac\pi2$
- $\cot^{-1}x = \tan^{-1}\frac1x$, $\sec^{-1}x = \cos^{-1}\frac1x$: **μόνο** για $x > 0$ / $x \ge 1$
- $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\frac{x + y}{1 - xy}$ αν το άθροισμα $\in (-\frac\pi2, \frac\pi2)$

## 5. Εκθετική και λογαριθμική

- $b^x$: $b > 0$, $b \ne 1$ · πεδίο $\mathbb R$ · τιμές $(0, \infty)$ · από το $(0, 1)$
- $\log_b x$: πεδίο $(0, \infty)$ · τιμές $\mathbb R$ · από το $(1, 0)$ · $y = \log_b x \Leftrightarrow b^y = x$
- $e^{\ln x} = x$ ($x > 0$) · $\ln e^x = x$ · $\ln 1 = 0$ · $\ln e = 1$
- $\ln(xy) = \ln x + \ln y$ · $\ln(x/y) = \ln x - \ln y$ · $\ln x^r = r\ln x$ · $\log_b x = \frac{\ln x}{\ln b}$ · $b^x = e^{x\ln b}$
- $\ln(x^2) = 2\ln\lvert x\rvert$ · $\ln(x + y)$: **κανένας** κανόνας · $\log_a c = \frac{\log_b c}{\log_b a}$ · $\log_a b\cdot\log_b a = 1$
- Εξισώσεις: $u = e^x > 0$ · λογαριθμικές: **έλεγχος πεδίου** στο τέλος · $\ln x^2 = c \Rightarrow x = \pm e^{c/2}$
- Βοήθημα: $\log x = \log_{10}x$ · $\ln x = \int_1^x \frac{dt}{t}$ · $e^{-x}$: ανάκλαση της $e^x$ στον άξονα $y$

## 6. Υπερβολικές

- $\sinh x = \frac{e^x - e^{-x}}{2}$ · $\cosh x = \frac{e^x + e^{-x}}{2}$ · $\tanh x = \frac{\sinh x}{\cosh x}$
- $\cosh x \ge 1$ (άρτια) · $\sinh$ περιττή, τιμές $\mathbb R$ · $\tanh \in (-1, 1)$
- $\cosh^2 x - \sinh^2 x = 1$ · $1 - \tanh^2 x = \operatorname{sech}^2 x$
- $\sinh 2x = 2\sinh x\cosh x$ · $\cosh 2x = \cosh^2 x + \sinh^2 x$
- $\cosh(x \pm y) = \cosh x\cosh y \pm \sinh x\sinh y$ (**ίδιο** πρόσημο)
- $\cosh x + \sinh x = e^x$
- $\cosh^2 x = \frac{1 + \cosh 2x}{2}$ · $\sinh^2 x = \frac{\cosh 2x - 1}{2}$ · $\tanh(x + y) = \frac{\tanh x + \tanh y}{1 + \tanh x\tanh y}$ · $(\cosh x + \sinh x)^n = \cosh nx + \sinh nx$
- $\coth$: τιμές $\lvert y\rvert > 1$ · $\operatorname{sech}$: $(0, 1]$ · $\operatorname{csch}$: $y \ne 0$
- $\sinh^{-1}x = \ln(x + \sqrt{x^2 + 1})$ · $\cosh^{-1}x = \ln(x + \sqrt{x^2 - 1})$, $x \ge 1$ · $\tanh^{-1}x = \frac12\ln\frac{1 + x}{1 - x}$, $\lvert x\rvert < 1$
- $\coth^{-1}x = \frac12\ln\frac{x + 1}{x - 1}$, $\lvert x\rvert > 1$ · $\operatorname{sech}^{-1}x = \ln\frac{1 + \sqrt{1 - x^2}}{x}$, $0 < x \le 1$ · $\operatorname{csch}^{-1}x = \ln\left(\frac1x + \frac{\sqrt{1 + x^2}}{\lvert x\rvert}\right)$
- $\cosh x = c > 1$ ⇒ **δύο** λύσεις $\pm\cosh^{-1}c$
