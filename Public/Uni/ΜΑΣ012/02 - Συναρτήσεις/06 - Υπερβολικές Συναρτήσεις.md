# 06 - Υπερβολικές Συναρτήσεις

Συνδυασμοί των $e^x$ και $e^{-x}$ που μοιάζουν πολύ με τις τριγωνομετρικές. Προσοχή όμως: μερικά πρόσημα είναι διαφορετικά.

## 1. Ορισμοί

> [!note] Ορισμοί
> $$\sinh x = \frac{e^x - e^{-x}}{2} \qquad \cosh x = \frac{e^x + e^{-x}}{2}$$
> $$\tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$
> $$\coth x = \frac{\cosh x}{\sinh x}\ (x \neq 0) \qquad \operatorname{sech} x = \frac{1}{\cosh x} \qquad \operatorname{csch} x = \frac{1}{\sinh x}\ (x \neq 0)$$
> Διαβάζονται «υπερβολικό ημίτονο, συνημίτονο, εφαπτομένη».

| | $\sinh x$ | $\cosh x$ | $\tanh x$ |
|---|---|---|---|
| Πεδίο ορισμού | $\mathbb R$ | $\mathbb R$ | $\mathbb R$ |
| Σύνολο τιμών | $\mathbb R$ | $[1, \infty)$ | $(-1, 1)$ |
| Τιμή στο 0 | $0$ | $1$ | $0$ |
| Συμμετρία | περιττή | άρτια | περιττή |
| Μονοτονία | αύξουσα (1-1) | φθίνουσα στο $(-\infty, 0]$, αύξουσα στο $[0, \infty)$ | αύξουσα (1-1) |
| Ασύμπτωτες | — | — | $y = \pm1$ |

| | $\coth x$ | $\operatorname{sech} x$ | $\operatorname{csch} x$ |
|---|---|---|---|
| Πεδίο ορισμού | $\mathbb R - \{0\}$ | $\mathbb R$ | $\mathbb R - \{0\}$ |
| Σύνολο τιμών | $(-\infty, -1) \cup (1, \infty)$ | $(0, 1]$ | $\mathbb R - \{0\}$ |
| Συμμετρία | περιττή | άρτια | περιττή |
| Ασύμπτωτες | $x = 0$, $y = \pm1$ | $y = 0$ | $x = 0$, $y = 0$ |

Γράφημα της $\cosh x$: το «άθροισμα» των $\frac12 e^x$ και $\frac12 e^{-x}$ (σχήμα «U», ελάχιστο $1$ στο $0$). Της $\sinh x$: η **διαφορά** $\frac12 e^x - \frac12 e^{-x}$ (περνά από την αρχή). Για μεγάλα $\lvert x\rvert$ και οι δύο μοιάζουν με $\pm\frac12 e^{\lvert x\rvert}$.

![[c2-06-hyperbolic.svg]]

*Σχήμα: Η $\cosh x$ είναι το άθροισμα των $\frac12 e^x$ και $\frac12 e^{-x}$ (ελάχιστο $1$ στο $0$), η $\sinh x$ η διαφορά τους (περνά από την αρχή), και η $\tanh x$ είναι φραγμένη ανάμεσα στις ασύμπτωτες $y = \pm1$.*

> [!note] Η $\tanh$ είναι φραγμένη (Βοήθημα, άσκ. 31)
> $$-1 < \tanh x < 1 \ \ \forall x, \qquad \lim_{x \to +\infty}\tanh x = 1, \qquad \lim_{x \to -\infty}\tanh x = -1$$
> Γιατί: $\tanh x = \dfrac{e^x - e^{-x}}{e^x + e^{-x}}$ και $\lvert e^x - e^{-x}\rvert < e^x + e^{-x}$. Για το όριο διαίρεσε με $e^x$: $\dfrac{1 - e^{-2x}}{1 + e^{-2x}} \to 1$.

> [!tip] Γιατί «υπερβολικές»
> Όπως το $(\cos t, \sin t)$ βρίσκεται στον κύκλο $x^2 + y^2 = 1$, το $(\cosh t, \sinh t)$ βρίσκεται στην **υπερβολή** $x^2 - y^2 = 1$ (δεξιός κλάδος).
> Εφαρμογή: ένα καλώδιο που κρέμεται ανάμεσα σε δύο στύλους έχει σχήμα $y = a\cosh(x/a)$ (**αλυσοειδής**).

![[c2-06-hyperbola.svg]]

*Σχήμα: Το $(\cos t, \sin t)$ κινείται στον κύκλο $x^2 + y^2 = 1$, το $(\cosh t, \sinh t)$ στον δεξιό κλάδο της υπερβολής $x^2 - y^2 = 1$ (ασύμπτωτες $y = \pm x$).*

> [!note] Κάθε συνάρτηση = άρτια + περιττή
> Σε συμμετρικό πεδίο: $f(x) = \underbrace{\frac{f(x) + f(-x)}{2}}_{\text{άρτια}} + \underbrace{\frac{f(x) - f(-x)}{2}}_{\text{περιττή}}$.
> Για $f(x) = e^x$ αυτό δίνει ακριβώς $e^x = \cosh x + \sinh x$.

## 2. Ταυτότητες

> [!important] Οι βασικές
> | Υπερβολική | Τριγωνομετρική (σύγκριση) |
> |---|---|
> | $\cosh^2 x - \sinh^2 x = 1$ | $\cos^2 x + \sin^2 x = 1$ |
> | $1 - \tanh^2 x = \operatorname{sech}^2 x$ | $1 + \tan^2 x = \sec^2 x$ |
> | $\coth^2 x - 1 = \operatorname{csch}^2 x$ | $1 + \cot^2 x = \csc^2 x$ |
> | $\sinh(x \pm y) = \sinh x\cosh y \pm \cosh x\sinh y$ | ίδιο πρόσημο |
> | $\cosh(x \pm y) = \cosh x\cosh y \pm \sinh x\sinh y$ | **αντίθετο** πρόσημο |
> | $\sinh 2x = 2\sinh x\cosh x$ | ίδιο |
> | $\cosh 2x = \cosh^2 x + \sinh^2 x = 2\cosh^2 x - 1 = 1 + 2\sinh^2 x$ | πρόσημα αλλάζουν |
> | $\cosh x + \sinh x = e^x$ · $\cosh x - \sinh x = e^{-x}$ | — |
> | $\cosh^2 x = \frac12(1 + \cosh 2x)$ · $\sinh^2 x = \frac12(\cosh 2x - 1)$ | $\cos^2 x = \frac12(1 + \cos 2x)$ · $\sin^2 x = \frac12(1 - \cos 2x)$ |
> | $\tanh(x + y) = \dfrac{\tanh x + \tanh y}{1 + \tanh x\tanh y}$ | $\tan(x + y) = \dfrac{\tan x + \tan y}{1 - \tan x\tan y}$ |

> [!example]- Παράδειγμα 1β: $(\sinh x + \cosh x)^n = \sinh nx + \cosh nx$ (Βοήθημα, άσκ. 32)
> $\sinh x + \cosh x = e^x$, άρα $(\sinh x + \cosh x)^n = e^{nx} = \sinh nx + \cosh nx$.
> Είναι το υπερβολικό ανάλογο του τύπου De Moivre. Για $\cosh x - \sinh x = e^{-x}$ βγαίνει $(\cosh x - \sinh x)^n = \cosh nx - \sinh nx$.

> [!example]- Παράδειγμα 1γ: απόδειξη του τύπου της $\tanh(x + y)$ (Βοήθημα)
> $$\tanh(x + y) = \frac{\sinh(x + y)}{\cosh(x + y)} = \frac{\sinh x\cosh y + \cosh x\sinh y}{\cosh x\cosh y + \sinh x\sinh y}$$
> Διαιρώ αριθμητή και παρονομαστή με $\cosh x\cosh y$ ($> 0$, άρα επιτρέπεται):
> $$= \frac{\tanh x + \tanh y}{1 + \tanh x\tanh y}$$

> [!tip] Κανόνας Osborn: από τριγωνομετρική σε υπερβολική ταυτότητα
> Άλλαξε $\sin \to \sinh$, $\cos \to \cosh$, και **άλλαξε πρόσημο** σε κάθε όρο που περιέχει **γινόμενο δύο** $\sinh$ (και στο $\tanh^2 = \sinh^2/\cosh^2$).
> Π.χ. $\cos 2x = 1 - 2\sin^2 x \ \to\ \cosh 2x = 1 + 2\sinh^2 x$.
> Είναι μνημονικός κανόνας· στο διαγώνισμα **απόδειξε** την ταυτότητα από τους ορισμούς.

> [!example]- Παράδειγμα 1: απόδειξη της $\cosh^2 x - \sinh^2 x = 1$
> $$\cosh^2 x - \sinh^2 x = \frac{(e^x + e^{-x})^2 - (e^x - e^{-x})^2}{4}$$
> $$= \frac{(e^{2x} + 2 + e^{-2x}) - (e^{2x} - 2 + e^{-2x})}{4} = \frac{4}{4} = 1$$
> (Χρησιμοποιήσαμε $e^x \cdot e^{-x} = 1$.)

> [!example]- Παράδειγμα 2: αν $\sinh x = \frac34$, βρες $\cosh x$, $\tanh x$ και $x$
> $\cosh^2 x = 1 + \sinh^2 x = 1 + \frac{9}{16} = \frac{25}{16}$, άρα $\cosh x = \frac54$.
> **Μόνο το θετικό**, γιατί $\cosh x \ge 1$ πάντα. Εδώ **δεν** υπάρχει αμφισημία $\pm$ όπως στις τριγωνομετρικές.
> $\tanh x = \dfrac{3/4}{5/4} = \dfrac35$.
> $e^x = \cosh x + \sinh x = \frac54 + \frac34 = 2 \Rightarrow x = \ln 2$.

> [!example]- Παράδειγμα 2β (Βοήθημα): αν $\sinh x = -\frac12$, βρες τις υπόλοιπες
> $\cosh x = \sqrt{1 + \frac14} = \frac{\sqrt5}{2}$ (θετικό, όσο αρνητικό κι αν είναι το $\sinh$).
> $\tanh x = \dfrac{-1/2}{\sqrt5/2} = -\dfrac{1}{\sqrt5}$ · $\coth x = -\sqrt5$ · $\operatorname{sech} x = \dfrac{2}{\sqrt5}$ · $\operatorname{csch} x = -2$.
> **Εναλλακτικά** από τον ορισμό: $\frac{e^x - e^{-x}}{2} = -\frac12 \Rightarrow (e^x)^2 + e^x - 1 = 0 \Rightarrow e^x = \frac{-1 + \sqrt5}{2}$ (η αρνητική ρίζα απορρίπτεται) και μετά $\cosh x = \frac{e^x + e^{-x}}{2} = \frac{\sqrt5}{2}$. Ο πρώτος τρόπος είναι πολύ πιο γρήγορος.

## 3. Αντίστροφες υπερβολικές

Επειδή οι υπερβολικές ορίζονται με εκθετικές, οι αντίστροφές τους γράφονται με **λογαρίθμους**.

> [!important] Τύποι
> | Συνάρτηση | Τύπος | Πεδίο ορισμού |
> |---|---|---|
> | $\sinh^{-1} x$ | $\ln\left(x + \sqrt{x^2 + 1}\right)$ | $\mathbb R$ |
> | $\cosh^{-1} x$ | $\ln\left(x + \sqrt{x^2 - 1}\right)$ | $[1, \infty)$ |
> | $\tanh^{-1} x$ | $\dfrac12\ln\left(\dfrac{1 + x}{1 - x}\right)$ | $(-1, 1)$ |
> | $\coth^{-1} x$ | $\dfrac12\ln\left(\dfrac{x + 1}{x - 1}\right)$ | $\lvert x\rvert > 1$ |
> | $\operatorname{sech}^{-1} x$ | $\ln\left(\dfrac{1 + \sqrt{1 - x^2}}{x}\right)$ | $(0, 1]$ |
> | $\operatorname{csch}^{-1} x$ | $\ln\left(\dfrac1x + \dfrac{\sqrt{1 + x^2}}{\lvert x\rvert}\right)$ | $x \neq 0$ |
>
> Η $\cosh$ δεν είναι 1-1, οπότε **περιορίζεται στο $[0, \infty)$**. Άρα $\cosh^{-1} x \ge 0$ πάντα. Το ίδιο και η $\operatorname{sech}$ (άρτια): $\operatorname{sech}^{-1}x \ge 0$.
> Ορισμός με ισοδυναμία (Βοήθημα §10.8): $y = \cosh^{-1}x \iff x = \cosh y$, $x \ge 1$, $y \ge 0$ · $y = \sinh^{-1}x \iff x = \sinh y$ (χωρίς περιορισμό).

> [!example]- Παραγωγή του τύπου για τη $\sinh^{-1}$
> $y = \sinh^{-1}x \iff x = \sinh y = \dfrac{e^y - e^{-y}}{2}$.
> Πολλαπλασιάζω με $2e^y$: $2xe^y = e^{2y} - 1 \Rightarrow (e^y)^2 - 2x\,e^y - 1 = 0$.
> Δευτεροβάθμια ως προς $u = e^y$: $u = x \pm \sqrt{x^2 + 1}$.
> Επειδή $\sqrt{x^2 + 1} > \lvert x\rvert$, το $x - \sqrt{x^2 + 1}$ είναι **αρνητικό** και απορρίπτεται ($e^y > 0$).
> $e^y = x + \sqrt{x^2 + 1} \Rightarrow y = \ln\left(x + \sqrt{x^2 + 1}\right)$.

> [!example]- Παραγωγή του τύπου για τη $\cosh^{-1}$ (παγίδα στο πρόσημο)
> $x = \cosh y = \frac{e^y + e^{-y}}{2} \Rightarrow (e^y)^2 - 2x e^y + 1 = 0 \Rightarrow e^y = x \pm \sqrt{x^2 - 1}$.
> Εδώ **και οι δύο** ρίζες είναι θετικές, οπότε το «$e^y > 0$» **δεν** αρκεί για να απορρίψεις τη μία. Χρειάζεται ο περιορισμός $y \ge 0$, δηλαδή $e^y \ge 1$: και $x - \sqrt{x^2 - 1} \le 1$ (είναι το αντίστροφο του $x + \sqrt{x^2 - 1} \ge 1$, αφού το γινόμενό τους είναι $1$). Άρα κρατάμε το $+$: $\cosh^{-1}x = \ln\left(x + \sqrt{x^2 - 1}\right)$.

> [!example]- Παραγωγή του τύπου για τη $\coth^{-1}$ (Βοήθημα)
> $x = \coth y = \frac{e^y + e^{-y}}{e^y - e^{-y}} \Rightarrow x e^y - x e^{-y} = e^y + e^{-y} \Rightarrow e^y(x - 1) = e^{-y}(x + 1)$
> $\Rightarrow e^{2y} = \dfrac{x + 1}{x - 1} \Rightarrow y = \dfrac12\ln\dfrac{x + 1}{x - 1}$, $\lvert x\rvert > 1$.
> Σύγκρινε με $\tanh^{-1}x = \frac12\ln\frac{1 + x}{1 - x}$ για $\lvert x\rvert < 1$: ίδιος τύπος «ανάποδα», σε **συμπληρωματικά** πεδία.

> [!example]- Παράδειγμα 2γ (Βοήθημα): τιμές και μια ταυτότητα
> - $\cosh^{-1}3 = \ln\left(3 + \sqrt{9 - 1}\right) = \ln\left(3 + \sqrt8\right) = \ln\left(3 + 2\sqrt2\right)$.
> - $\tanh^{-1}\frac34 = \frac12\ln\dfrac{1 + 3/4}{1 - 3/4} = \frac12\ln 7$.
> - $\sinh^{-1}\frac34 + \sinh^{-1}\frac{5}{12} - \sinh^{-1}\frac43 = 0$:
> $\ln\left(\frac34 + \frac54\right) + \ln\left(\frac5{12} + \frac{13}{12}\right) - \ln\left(\frac43 + \frac53\right) = \ln 2 + \ln\frac32 - \ln 3 = \ln\dfrac{2\cdot\frac32}{3} = \ln 1 = 0$.
> (Κόλπο: οι αριθμοί είναι από πυθαγόρεια τρίγωνα, $\sqrt{1 + \frac{9}{16}} = \frac54$ κ.λπ., γι' αυτό οι ρίζες βγαίνουν ρητές.)

> [!example]- Παράδειγμα 3 (παγίδα): λύσε $\cosh x = 2$
> Η $\cosh$ είναι **άρτια**, άρα αν $x$ είναι λύση, είναι και το $-x$.
> $\cosh^{-1} 2 = \ln(2 + \sqrt3)$ δίνει **μόνο τη θετική**.
> Λύσεις: $x = \pm\ln(2 + \sqrt3)$. (Ισοδύναμα $-\ln(2 + \sqrt3) = \ln(2 - \sqrt3)$.)
> Αντίθετα, η $\cosh x = \frac12$ **δεν έχει λύση**, γιατί $\cosh x \ge 1$.

## 4. Συχνά Λάθη

> [!warning] Προσοχή
> - $\cosh^2 x + \sinh^2 x = 1$: **λάθος**, είναι **μείον**. Το άθροισμα ισούται με $\cosh 2x$.
> - $\cosh(x + y) = \cosh x\cosh y - \sinh x\sinh y$: λάθος πρόσημο, είναι **συν**.
> - $\pm$ στο $\cosh x = \pm\sqrt{1 + \sinh^2 x}$: το $\cosh$ είναι πάντα θετικό.
> - Μία μόνο λύση στο $\cosh x = c > 1$ (Παράδειγμα 3).
> - Γράφεις $\cosh^{-1}$ για $x < 1$ ή $\tanh^{-1}$ για $\lvert x\rvert \ge 1$: δεν ορίζονται. Αντίθετα, η $\coth^{-1}$ ορίζεται **μόνο** για $\lvert x\rvert > 1$.
> - Στην παραγωγή της $\cosh^{-1}$ απορρίπτεις ρίζα «επειδή $e^y > 0$»: και οι δύο είναι θετικές· ο λόγος είναι το $y \ge 0$.
> - $\tanh(x + y)$ με **μείον** στον παρονομαστή (όπως η $\tan$): είναι **συν**.
