### Άσκηση 1 — Πεδίο ορισμού και πεδίο τιμών

Να βρεθούν τα πεδία ορισμού και τιμών των συναρτήσεων:
(α) $h(x) = \dfrac{3}{2 - \cos x}$ · (β) $g(x) = \sqrt{x^2 - 3}$ · (γ) $\varphi(x) = \sqrt{3 - \sqrt x}$ 🪤 · (δ) $f(x) = \lvert x\rvert + \sqrt x$ 🪤 · (ε) $h(x) = \dfrac{1}{x - 3}$

Θεωρία: [[01 - Συναρτήσεις μιας Μεταβλητής#2. Φυσικό πεδίο ορισμού]] · [[01 - Συναρτήσεις μιας Μεταβλητής#3. Σύνολο τιμών]].

> [!note] Ορολογία
> «Πεδίο τιμών» στο φυλλάδιο = **σύνολο τιμών** $R_f = \{f(x) : x \in D_f\}$, όχι το σύνολο-στόχος.

> [!success]- Λύση (α)
> **Πεδίο:** $2 - \cos x \ge 2 - 1 = 1 > 0$, άρα ο παρονομαστής δεν μηδενίζεται ποτέ: $D_h = \mathbb R$.
> **Τιμές:** χτίζω από μέσα προς τα έξω.
> $-1 \le \cos x \le 1 \Rightarrow 1 \le 2 - \cos x \le 3 \Rightarrow \dfrac13 \le \dfrac{1}{2 - \cos x} \le 1 \Rightarrow 1 \le h(x) \le 3$.
> (Στη δεύτερη συνεπαγωγή αλλάζει η φορά, γιατί αντιστρέφω **θετικούς**.)
> Και τα δύο άκρα πιάνονται: $h(0) = \frac{3}{2 - 1} = 3$, $h(\pi) = \frac{3}{2 + 1} = 1$. Αφού ο $\cos x$ παίρνει **κάθε** τιμή του $[-1, 1]$, η $h$ παίρνει κάθε τιμή ανάμεσα.
> $R_h = [1, 3]$.

> [!success]- Λύση (β)
> **Πεδίο:** $x^2 - 3 \ge 0 \iff x^2 \ge 3 \iff \lvert x\rvert \ge \sqrt3$.
> $D_g = (-\infty, -\sqrt3] \cup [\sqrt3, \infty)$. Μην ξεχάσεις τον αρνητικό κλάδο: το $x^2 \ge 3$ **δεν** είναι το $x \ge \sqrt3$.
> **Τιμές:** στο $D_g$ η παράσταση $x^2 - 3$ παίρνει **κάθε** τιμή του $[0, \infty)$ (π.χ. για $c \ge 0$, το $x = \sqrt{c + 3}$ δίνει $x^2 - 3 = c$). Άρα $R_g = [0, \infty)$.

> [!success]- Λύση (γ) 🪤
> **Πεδίο:** δύο ρίζες, άρα δύο περιορισμοί:
> - εσωτερική: $x \ge 0$
> - εξωτερική: $3 - \sqrt x \ge 0 \iff \sqrt x \le 3 \iff x \le 9$ (τετραγωνίζω μη αρνητικά)
>
> $D_\varphi = [0, 9]$. Η παγίδα: σταματάς στο $x \ge 0$ και ξεχνάς την εξωτερική ρίζα.
> **Τιμές:** $0 \le x \le 9 \Rightarrow 0 \le \sqrt x \le 3 \Rightarrow 0 \le 3 - \sqrt x \le 3 \Rightarrow 0 \le \varphi(x) \le \sqrt3$.
> $\varphi(9) = 0$, $\varphi(0) = \sqrt3$. $R_\varphi = [0, \sqrt3]$.

> [!success]- Λύση (δ) 🪤
> **Πεδίο:** το $\lvert x\rvert$ ορίζεται παντού, το $\sqrt x$ θέλει $x \ge 0$. $D_f = [0, \infty)$.
> **Η παγίδα:** στο $D_f$ είναι $x \ge 0$, άρα $\lvert x\rvert = x$ και $f(x) = x + \sqrt x$. Η απόλυτη τιμή είναι «διακοσμητική». Μην σπάσεις σε κλάδους $x < 0$: εκεί η $f$ **δεν ορίζεται**.
> **Τιμές:** $f(0) = 0$ και η $f$ είναι γνησίως αύξουσα (άθροισμα αυξουσών), με $f(x) \to \infty$.
> Αυστηρά: για $y \ge 0$, θέτω $u = \sqrt x \ge 0$: $u^2 + u - y = 0 \Rightarrow u = \dfrac{-1 + \sqrt{1 + 4y}}{2} \ge 0$ ✓, άρα υπάρχει $x = u^2$.
> $R_f = [0, \infty)$.

> [!success]- Λύση (ε)
> $D_h = \mathbb R \setminus \{3\}$.
> $y = \dfrac{1}{x - 3} \Rightarrow x - 3 = \dfrac1y \Rightarrow x = 3 + \dfrac1y$, που ορίζεται για κάθε $y \ne 0$. Το $y = 0$ δεν πιάνεται ποτέ (κλάσμα με αριθμητή $1$).
> $R_h = \mathbb R \setminus \{0\}$.

### Άσκηση 2 — Απαλοιφή απόλυτων τιμών και γράφημα

Να οριστούν τμηματικά, απαλείφοντας τις απόλυτες τιμές, και να γίνουν οι γραφικές παραστάσεις:
(α) $f(x) = \lvert x\rvert + 3x + 1$ · (β) $g(x) = 3\lvert x - 2\rvert - \lvert x + 1\rvert$

Θεωρία: [[01 - Συναρτήσεις μιας Μεταβλητής#4. Κλαδικές συναρτήσεις]].

> [!success]- Λύση (α)
> Μία απόλυτη τιμή, που μηδενίζεται στο $0$:
> - $x \ge 0$: $\lvert x\rvert = x \Rightarrow f(x) = 4x + 1$
> - $x < 0$: $\lvert x\rvert = -x \Rightarrow f(x) = 2x + 1$
>
> $$f(x) = \begin{cases} 2x + 1, & x < 0 \\ 4x + 1, & x \ge 0 \end{cases}$$
> **Γράφημα:** δύο ημιευθείες που συναντώνται στο $(0, 1)$ (και οι δύο τύποι δίνουν $1$ στο $0$), με κλίση $2$ αριστερά και $4$ δεξιά.
> **Ρίζα** 🪤: $2x + 1 = 0 \Rightarrow x = -\frac12 < 0$ ✓. Ο άλλος κλάδος δίνει $4x + 1 = 0 \Rightarrow x = -\frac14$, που **απορρίπτεται** (ο κλάδος ισχύει μόνο για $x \ge 0$). Κάθε λύση πρέπει να ελέγχεται απέναντι στο διάστημα του κλάδου της.
> Η $f$ είναι γνησίως αύξουσα (και οι δύο κλίσεις θετικές), με $R_f = \mathbb R$.

> [!success]- Λύση (β)
> Μηδενισμοί: $x = -1$ και $x = 2$. Τρία διαστήματα:
>
> | Διάστημα | $x + 1$ | $x - 2$ | $g(x)$ |
> |---|---|---|---|
> | $x < -1$ | − | − | $3(2 - x) + (x + 1) = 7 - 2x$ |
> | $-1 \le x < 2$ | + | − | $3(2 - x) - (x + 1) = 5 - 4x$ |
> | $x \ge 2$ | + | + | $3(x - 2) - (x + 1) = 2x - 7$ |
>
> $$g(x) = \begin{cases} 7 - 2x, & x < -1 \\ 5 - 4x, & -1 \le x < 2 \\ 2x - 7, & x \ge 2 \end{cases}$$
> **Έλεγχος στα σημεία αλλαγής:** $x = -1$: $7 + 2 = 9$ και $5 + 4 = 9$ ✓ · $x = 2$: $5 - 8 = -3$ και $4 - 7 = -3$ ✓. Οι γειτονικοί τύποι πρέπει να συμφωνούν, γιατί ένας συνδυασμός απόλυτων τιμών δεν έχει «άλματα». Αν δεν συμφωνούν, έχεις κάνει λάθος πρόσημο.
> **Γράφημα:** σημεία-γωνίες $(-1, 9)$ και $(2, -3)$· κλίσεις $-2$, $-4$, $2$.
> Ρίζες: $5 - 4x = 0 \Rightarrow x = \frac54 \in [-1, 2)$ ✓ · $2x - 7 = 0 \Rightarrow x = \frac72$ ✓ · $7 - 2x = 0 \Rightarrow x = \frac72 \not< -1$ ✗.
> Ελάχιστη τιμή $-3$ στο $x = 2$, άρα $R_g = [-3, \infty)$.

![[c2-09-abs-graphs.png|740]]

*Σχήμα: (α) Δύο ημιευθείες που ενώνονται στο $(0, 1)$· η μόνη ρίζα είναι το $-\frac12$. (β) Τρία ευθύγραμμα κομμάτια με γωνίες στα $(-1, 9)$ και $(2, -3)$, ρίζες $\frac54$ και $\frac72$.*

### Άσκηση 3 — Άρτιες, περιττές, περιοδικές

Να εξεταστεί αν είναι άρτιες ή περιττές ή/και περιοδικές (και να βρεθεί η περίοδος):
(α) $f(x) = \lvert x\rvert$ · (β) $f(x) = x^5 + 1$ 🪤 · (γ) $f(x) = \sin x + \sin 2x$ 🪤

Θεωρία: [[01 - Συναρτήσεις μιας Μεταβλητής#5. Συμμετρία: άρτιες και περιττές|§5 Συμμετρία]] · [[01 - Συναρτήσεις μιας Μεταβλητής#7. Περιοδικές συναρτήσεις|§7 Περιοδικές]].

> [!success]- Λύση (α)
> $D = \mathbb R$ (συμμετρικό). $f(-x) = \lvert -x\rvert = \lvert x\rvert = f(x)$ ⇒ **άρτια**. Περιττή όχι: $f(-1) = 1 \ne -1 = -f(1)$.
> **Περιοδική όχι:** αν υπήρχε περίοδος $T > 0$, τότε $f(0 + T) = f(0)$, δηλαδή $T = 0$, άτοπο.

> [!success]- Λύση (β) 🪤
> $f(-x) = -x^5 + 1$. Ένα αντιπαράδειγμα αρκεί: $f(1) = 2$, $f(-1) = 0$.
> - $f(-1) \ne f(1)$ ⇒ **όχι** άρτια
> - $f(-1) \ne -f(1) = -2$ ⇒ **όχι** περιττή
>
> Η $x^5$ είναι περιττή, αλλά η **σταθερά** $+1$ χαλάει την περιττότητα (μια περιττή με $0 \in D$ πρέπει να έχει $f(0) = 0$, ενώ εδώ $f(0) = 1$).
> **Περιοδική όχι:** η $f$ είναι γνησίως αύξουσα, άρα $f(x + T) > f(x)$ για κάθε $T > 0$.

> [!success]- Λύση (γ) 🪤
> **Συμμετρία:** $\sin(-x) + \sin(-2x) = -\sin x - \sin 2x = -f(x)$ ⇒ **περιττή** (περιττή + περιττή).
> **Περίοδος:** η $\sin x$ έχει $2\pi$, η $\sin 2x$ έχει $\pi$. Λόγος $\frac{2\pi}{\pi} = 2$, άρα το $2\pi$ **είναι** περίοδος: $f(x + 2\pi) = \sin x + \sin(2x + 4\pi) = f(x)$.
> **Είναι η θεμελιώδης;** Ο κανόνας «ΕΚΠ» δίνει μόνο **μια** περίοδο, οπότε πρέπει να αποκλείσεις μικρότερες. Έστω περίοδος $0 < T < 2\pi$.
> 1. Με $x = 0$: $f(T) = f(0) = 0$, άρα το $T$ είναι **ρίζα** της $f$.
> 2. $f(x) = \sin x + 2\sin x\cos x = \sin x\,(1 + 2\cos x)$, με ρίζες στο $(0, 2\pi)$: $\frac{2\pi}{3}$, $\pi$, $\frac{4\pi}{3}$.
> 3. Με $x = \frac\pi2$: πρέπει $f\left(\frac\pi2 + T\right) = f\left(\frac\pi2\right) = 1$. Όμως
>
> | $T$ | $\frac\pi2 + T$ | $f\left(\frac\pi2 + T\right)$ |
> |---|---|---|
> | $\frac{2\pi}{3}$ | $\frac{7\pi}{6}$ | $-\frac12 + \frac{\sqrt3}{2} \approx 0.37$ |
> | $\pi$ | $\frac{3\pi}{2}$ | $-1 + 0 = -1$ |
> | $\frac{4\pi}{3}$ | $\frac{11\pi}{6}$ | $-\frac12 - \frac{\sqrt3}{2} \approx -1.37$ |
>
> Κανένα δεν δίνει $1$. Άρα η **θεμελιώδης περίοδος είναι $2\pi$**.
> Οι ρίζες στο $[0, 2\pi]$ ($0, \frac{2\pi}{3}, \pi, \frac{4\pi}{3}, 2\pi$) έχουν **άνισα** κενά ($\frac{2\pi}{3}, \frac\pi3, \frac\pi3, \frac{2\pi}{3}$): το μοτίβο επαναλαμβάνεται μόνο μετά από $2\pi$.

![[c2-09-sin-sum.png|586]]

*Σχήμα: Η $\sin x + \sin 2x$ είναι περιττή (συμμετρική ως προς την αρχή) και επαναλαμβάνεται κάθε $2\pi$. Το $\pi$ δεν είναι περίοδος: $f(\frac\pi2) = 1$ αλλά $f(\frac{3\pi}{2}) = -1$.*

### Άσκηση 4 — Απλοποίηση και πεδίο ορισμού 🪤

Να απλοποιηθεί η συνάρτηση και να βρεθεί το πεδίο ορισμού της απλοποιημένης συνάρτησης:
(α) $f(x) = \dfrac{x + \sqrt x}{\sqrt x}$ · (β) $f(x) = \dfrac{x + 1 + \sqrt{x + 1}}{\sqrt{x + 1}}$ · (γ) $f(x) = \dfrac{x^3 + 2x^2 - 3x}{(x - 1)(x + 3)}$

Θεωρία: [[01 - Συναρτήσεις μιας Μεταβλητής#2. Φυσικό πεδίο ορισμού]] (Παράδειγμα 3) · [[02 - Πράξεις με Συναρτήσεις#1. Αριθμητικές πράξεις]] (Παράδειγμα 1β).

> [!important] Ο κανόνας
> Η απλοποίηση αλλάζει τον **τύπο**, όχι τη **συνάρτηση**. Το πεδίο βρίσκεται από τον **αρχικό** τύπο και κρατιέται και μετά την απλοποίηση.

> [!success]- Λύση (α)
> **Πεδίο (από τον αρχικό τύπο):** $\sqrt x$ θέλει $x \ge 0$, και ως παρονομαστής $\sqrt x \ne 0$. Άρα $x > 0$.
> **Απλοποίηση:** για $x > 0$, $\dfrac{x}{\sqrt x} = \dfrac{(\sqrt x)^2}{\sqrt x} = \sqrt x$, οπότε $f(x) = \sqrt x + 1$.
> $f(x) = \sqrt x + 1$, $D_f = (0, \infty)$. **Όχι** $[0, \infty)$: το $0$ μένει έξω, παρόλο που το $\sqrt0 + 1$ «βγαίνει».

> [!success]- Λύση (β)
> Ίδια δομή με το (α), με $x + 1$ στη θέση του $x$: πεδίο $x + 1 > 0 \iff x > -1$.
> $f(x) = \sqrt{x + 1} + 1$, $D_f = (-1, \infty)$.
> (Γεωμετρικά είναι η συνάρτηση του (α) μετατοπισμένη **αριστερά** κατά $1$.)

> [!success]- Λύση (γ)
> **Πεδίο:** $(x - 1)(x + 3) \ne 0 \Rightarrow x \ne 1,\ x \ne -3$.
> **Παραγοντοποίηση αριθμητή:** $x^3 + 2x^2 - 3x = x(x^2 + 2x - 3) = x(x - 1)(x + 3)$.
> $f(x) = \dfrac{x(x - 1)(x + 3)}{(x - 1)(x + 3)} = x$.
> $f(x) = x$, $D_f = \mathbb R \setminus \{-3, 1\}$. Γράφημα: η ευθεία $y = x$ με **δύο τρύπες**, στα $(-3, -3)$ και $(1, 1)$.
>
> ⚠️ *Σημείωση: η διατύπωση «πεδίο ορισμού της απλοποιημένης συνάρτησης» μπορεί να διαβαστεί και ως «πεδίο του νέου τύπου μόνου του» ($[0, \infty)$, $[-1, \infty)$, $\mathbb R$). Η απλοποιημένη συνάρτηση όμως είναι **η ίδια** συνάρτηση, άρα το σωστό είναι το αρχικό πεδίο. Αν θες να είσαι καλυμμένος στην εξέταση, γράψε $f(x) = x$ **για $x \ne -3, 1$** και εξήγησε σε μία γραμμή.*

### Άσκηση 5 — Πράξεις και σύνθεση με ρίζες 🪤

Να βρεθούν οι $(f_1 + f_2)(x)$, $(f_1 - f_2)(x)$, $(f_1f_2)(x)$, $\left(\frac{f_1}{f_2}\right)(x)$, $(f_1 \circ f_2)(x)$, $(f_2 \circ f_1)(x)$ και τα πεδία ορισμού τους, όταν $f_1(x) = \sqrt{x - 2}$, $f_2(x) = \sqrt{x - 3}$.

Θεωρία: [[02 - Πράξεις με Συναρτήσεις]].

> [!success]- Λύση
> $D_{f_1} = [2, \infty)$, $D_{f_2} = [3, \infty)$, τομή $[3, \infty)$.
>
> | Συνάρτηση | Τύπος | Πεδίο | Γιατί |
> |---|---|---|---|
> | $f_1 + f_2$ | $\sqrt{x - 2} + \sqrt{x - 3}$ | $[3, \infty)$ | τομή |
> | $f_1 - f_2$ | $\sqrt{x - 2} - \sqrt{x - 3}$ | $[3, \infty)$ | τομή |
> | $f_1f_2$ | $\sqrt{(x - 2)(x - 3)}$ | $[3, \infty)$ | τομή (**όχι** το πεδίο του $\sqrt{x^2 - 5x + 6}$) |
> | $\frac{f_1}{f_2}$ | $\dfrac{\sqrt{x - 2}}{\sqrt{x - 3}}$ | $(3, \infty)$ | τομή **και** $f_2(x) \ne 0$ |
> | $f_1 \circ f_2$ | $\sqrt{\sqrt{x - 3} - 2}$ | $[7, \infty)$ | βλ. κάτω |
> | $f_2 \circ f_1$ | $\sqrt{\sqrt{x - 2} - 3}$ | $[11, \infty)$ | βλ. κάτω |
>
> **Παγίδα στο γινόμενο:** η $\sqrt{x^2 - 5x + 6}$ μόνη της ορίζεται και στο $(-\infty, 2]$ (εκεί $(x - 2)(x - 3) \ge 0$). Π.χ. στο $x = 0$ δίνει $\sqrt6$, όμως ούτε το $f_1(0)$ ούτε το $f_2(0)$ υπάρχουν.
> **Παγίδα στο πηλίκο:** παρόμοια, η $\sqrt{\frac{x - 2}{x - 3}}$ ορίζεται και στο $(-\infty, 2]$· το πηλίκο $\frac{f_1}{f_2}$ όχι.
>
> **Σύνθεση $f_1 \circ f_2$:** $D = \{x \in D_{f_2} : f_2(x) \in D_{f_1}\}$:
> $x \ge 3$ **και** $\sqrt{x - 3} \ge 2 \iff x - 3 \ge 4 \iff x \ge 7$. Άρα $[7, \infty)$.
> **Σύνθεση $f_2 \circ f_1$:** $x \ge 2$ **και** $\sqrt{x - 2} \ge 3 \iff x - 2 \ge 9 \iff x \ge 11$. Άρα $[11, \infty)$.
> Έλεγχος: $(f_1 \circ f_2)(7) = f_1(2) = 0$ ✓ · $(f_2 \circ f_1)(11) = f_2(3) = 0$ ✓.
> Οι δύο συνθέσεις έχουν **διαφορετικό** τύπο **και** διαφορετικό πεδίο: $f_1 \circ f_2 \ne f_2 \circ f_1$.

### Άσκηση 6 — Παραστάσεις με την $f(x) = \dfrac{3 - x}{x}$ 🪤

Να βρεθούν: (I) $f(x^2) - [f(x)]^2$ · (II) $f(x + 3) - [f(x) + f(3)]$ · (III) $f\left(\dfrac1x\right) - \dfrac{1}{f(x)}$ · (IV) $(f \circ f)(x)$, όταν $f(x) = \dfrac{3 - x}{x}$.

Θεωρία: [[02 - Πράξεις με Συναρτήσεις#2. Σύνθεση]].

⚠️ *Σημείωση: στο Βοήθημα η ίδια άσκηση έχει $f(x) = \sqrt{3 - x}$ (λυμένη στην [[Uni/ΜΑΣ012/02 - Συναρτήσεις/08 - Ασκήσεις|08 - Ασκήσεις]], Άσκηση 31). Το φυλλάδιο δίνει τη ρητή $f(x) = \frac{3 - x}{x}$. Παρακάτω λύνεται η εκδοχή του φυλλαδίου, με τα πεδία ορισμού (το φυλλάδιο δεν τα ζητά ρητά, αλλά χωρίς αυτά οι απαντήσεις είναι ελλιπείς).*

> [!tip] Χρήσιμη μορφή
> $f(x) = \dfrac{3 - x}{x} = \dfrac3x - 1$, με $D_f = \mathbb R \setminus \{0\}$. Επίσης $f(x) = 0 \iff x = 3$.

> [!success]- Λύση (I)
> $f(x^2) = \dfrac{3 - x^2}{x^2}$ (θέλει $x^2 \ne 0$) · $[f(x)]^2 = \dfrac{(3 - x)^2}{x^2}$.
> $$f(x^2) - [f(x)]^2 = \frac{3 - x^2 - (9 - 6x + x^2)}{x^2} = \frac{-2x^2 + 6x - 6}{x^2} = -\frac{2(x^2 - 3x + 3)}{x^2}, \quad x \ne 0$$
> Παρατήρηση: $x^2 - 3x + 3$ έχει $\Delta = 9 - 12 < 0$, άρα είναι πάντα θετικό. Επομένως $f(x^2) < [f(x)]^2$ για **κάθε** $x \ne 0$: το $f(x^2)$ και το $[f(x)]^2$ δεν είναι ποτέ ίσα.
> Έλεγχος με $x = 1$: $f(1) = 2$, άρα $2 - 4 = -2$ · τύπος: $-\frac{2(1 - 3 + 3)}{1} = -2$ ✓.

> [!success]- Λύση (II)
> $f(x + 3) = \dfrac{3 - (x + 3)}{x + 3} = \dfrac{-x}{x + 3}$ (θέλει $x \ne -3$) · $f(3) = \dfrac{0}{3} = 0$.
> $$f(x + 3) - [f(x) + f(3)] = \frac{-x}{x + 3} - \frac{3 - x}{x} = \frac{-x^2 - (3 - x)(3 + x)}{x(x + 3)} = \frac{-x^2 - 9 + x^2}{x(x + 3)} = -\frac{9}{x(x + 3)}$$
> Πεδίο: $x \ne 0$ (για το $f(x)$) **και** $x \ne -3$ (για το $f(x + 3)$): $\mathbb R \setminus \{-3, 0\}$.
> 🪤 Αφού $f(3) = 0$, ίσως σκεφτείς «$f(x + 3) = f(x) + f(3) = f(x)$». Όχι: η $f$ δεν είναι γραμμική ($f(a + b) \ne f(a) + f(b)$ γενικά), και η διαφορά βγαίνει $-\frac{9}{x(x + 3)} \ne 0$.
> Έλεγχος με $x = 1$: $f(4) - [f(1) + 0] = -\frac14 - 2 = -\frac94$ · τύπος: $-\frac{9}{1 \cdot 4}$ ✓.

> [!success]- Λύση (III)
> $f\left(\frac1x\right) = \dfrac{3 - \frac1x}{\frac1x} = \left(3 - \frac1x\right)x = 3x - 1$, για $x \ne 0$ (για να ορίζεται το $\frac1x$).
> $\dfrac{1}{f(x)} = \dfrac{x}{3 - x}$, για $x \ne 0$ **και** $f(x) \ne 0 \iff x \ne 3$.
> $$f\left(\frac1x\right) - \frac{1}{f(x)} = 3x - 1 - \frac{x}{3 - x} = \frac{(3x - 1)(3 - x) - x}{3 - x} = \frac{-3x^2 + 9x - 3}{3 - x} = \frac{3(x^2 - 3x + 1)}{x - 3}$$
> Πεδίο: $\mathbb R \setminus \{0, 3\}$. Το $0$ μένει έξω, αν και ο τελικός τύπος ορίζεται εκεί.
> 🪤 $f\left(\frac1x\right) \ne \frac{1}{f(x)}$: το πρώτο είναι «βάλε $\frac1x$ μέσα», το δεύτερο «αντίστρεψε το αποτέλεσμα».
> Έλεγχος με $x = 1$: $f(1) - \frac{1}{f(1)} = 2 - \frac12 = \frac32$ · τύπος: $\frac{3(1 - 3 + 1)}{1 - 3} = \frac{-3}{-2} = \frac32$ ✓.

> [!success]- Λύση (IV)
> $D_{f \circ f} = \{x \in D_f : f(x) \in D_f\} = \{x \ne 0 : f(x) \ne 0\} = \mathbb R \setminus \{0, 3\}$.
> $$f(f(x)) = \frac{3}{f(x)} - 1 = \frac{3x}{3 - x} - 1 = \frac{3x - 3 + x}{3 - x} = \frac{4x - 3}{3 - x}, \quad x \ne 0, 3$$
> 🪤 Ο τελικός τύπος $\frac{4x - 3}{3 - x}$ ορίζεται στο $0$ (δίνει $-1$), αλλά το $f(f(0))$ **δεν** ορίζεται, γιατί δεν ορίζεται ούτε το $f(0)$. Το πεδίο βγαίνει **πριν** την απλοποίηση.
> Έλεγχος με $x = 1$: $f(1) = 2$, $f(2) = \frac12$ · τύπος: $\frac{4 - 3}{3 - 1} = \frac12$ ✓.

### Άσκηση 7 — Πεδίο τιμών τετραγωνικής

Να βρεθεί το πεδίο τιμών της $f(x) = -3x^2 + 12x - 7$.

Θεωρία: [[01 - Συναρτήσεις μιας Μεταβλητής#3. Σύνολο τιμών]] · [[Uni/ΜΑΣ012/01 - Εισαγωγή/04 - Ευθεία, Κύκλος και Παραβολή#3. Παραβολή|Παραβολή]].

> [!success]- Λύση
> **1ος τρόπος (συμπλήρωση τετραγώνου):**
> $-3x^2 + 12x - 7 = -3(x^2 - 4x) - 7 = -3\big[(x - 2)^2 - 4\big] - 7 = -3(x - 2)^2 + 5$.
> Αφού $(x - 2)^2 \ge 0$, είναι $f(x) \le 5$, με ισότητα στο $x = 2$. Και καθώς $\lvert x\rvert \to \infty$ η $f \to -\infty$.
> **2ος τρόπος (λύνω ως προς $x$):** $3x^2 - 12x + (7 + y) = 0$ έχει πραγματική λύση $\iff \Delta = 144 - 12(7 + y) = 60 - 12y \ge 0 \iff y \le 5$.
> $R_f = (-\infty, 5]$. Παραβολή που ανοίγει **κάτω** ($a = -3 < 0$), κορυφή $(2, 5)$ = **μέγιστο**.
> Συχνό λάθος: $[5, \infty)$, από συνήθεια με παραβολές που ανοίγουν πάνω. Κοίτα πρώτα το πρόσημο του $a$.

### Άσκηση 8 — Σύνθεση γραμμικών

Δίνονται $f_1(x) = 3x + 6$ και $f_2(x) = 4x + k$. (α) Να βρεθεί το $k$ ώστε $(f_1 \circ f_2)(x) = (f_2 \circ f_1)(x)$. (β) Να δειχθεί ότι $(f_1 \circ f_1 \circ f_1)(x) = 27x + 78$.

Θεωρία: [[02 - Πράξεις με Συναρτήσεις#2. Σύνθεση]] (Παράδειγμα 3ε).

> [!success]- Λύση
> **(α)** $(f_1 \circ f_2)(x) = 3(4x + k) + 6 = 12x + 3k + 6$ · $(f_2 \circ f_1)(x) = 4(3x + 6) + k = 12x + 24 + k$.
> Οι συντελεστές του $x$ είναι ίδιοι ($12$), οπότε η ισότητα **για κάθε $x$** απαιτεί ίσους σταθερούς όρους:
> $3k + 6 = 24 + k \iff 2k = 18 \iff k = 9$.
> Έλεγχος: $f_2(x) = 4x + 9$, και τότε $f_1 \circ f_2 = 12x + 33 = f_2 \circ f_1$ ✓.
> Η ισότητα πρέπει να ισχύει για **κάθε** $x$· δεν λύνεις ως προς $x$.
>
> **(β)** Από μέσα προς τα έξω:
> $f_1(f_1(x)) = 3(3x + 6) + 6 = 9x + 24$ · $f_1(9x + 24) = 3(9x + 24) + 6 = 27x + 78$ ✓.
> **Γιατί $78$:** κάθε εφαρμογή πολλαπλασιάζει επί $3$ και προσθέτει $6$, οπότε ο σταθερός όρος είναι $6(1 + 3 + 9) = 78$ και ο συντελεστής $3^3 = 27$.
