# 05 - Τυπολόγιο

Το Κεφάλαιο 1 σε μία σελίδα.

## 1. Πραγματικοί αριθμοί

- $\mathbb N \subset \mathbb Z \subset \mathbb Q \subset \mathbb R$ · ρητός ⇔ δεκαδικό **τερματίζει ή είναι περιοδικό**
- ρητός + άρρητος = **άρρητος** · άρρητος + άρρητος = **οτιδήποτε**
- $0.\overline{9} = 1$ · $1.72\overline9 = 1.73$
- Περιοδικός → κλάσμα: $k$ ψηφία πριν την περίοδο, περίοδος $p$ ψηφίων ⇒ $(10^{k+p} - 10^k)x$ = ακέραιος

## 2. Ανισότητες

| Κάνω | Φορά |
|---|---|
| $+c$ σε όλα | ίδια |
| $\times c$, $c > 0$ | ίδια |
| $\times c$, $c < 0$ | **αλλάζει** |
| αντίστροφα, **ομόσημα** μέλη | **αλλάζει** |
| τετράγωνο, μέλη $\ge 0$ | ίδια |

> [!important] Πίνακας προσήμων
> Όλα σε ένα μέλος → ένα κλάσμα → παραγοντοποίηση → πρόσημα ανά διάστημα.
> Ρίζες παρονομαστή: **πάντα έξω**. Διπλή ρίζα: **δεν** αλλάζει πρόσημο.
> **Ποτέ** πολλαπλασιασμός/διαίρεση με παράσταση που περιέχει $x$.

- 3ου βαθμού: ακέραιες ρίζες **διαιρούν τον σταθερό όρο** → Horner → τριώνυμο
- Τριώνυμο: ομόσημο του $a$ **έξω** από τις ρίζες · $\Delta < 0$ ⇒ ομόσημο του $a$ παντού

## 3. Απόλυτη τιμή

| | |
|---|---|
| $\lvert x\rvert = x$ αν $x \ge 0$, $-x$ αν $x < 0$ | $\sqrt{x^2} = \lvert x\rvert$ |
| $\lvert x\rvert < k \Leftrightarrow -k < x < k$ | $\lvert x\rvert > k \Leftrightarrow x < -k$ ή $x > k$ |
| $\lvert x - a\rvert < \delta \Leftrightarrow a - \delta < x < a + \delta$ | $\lvert A\rvert = \lvert B\rvert \Leftrightarrow A = \pm B$ |
| $\lvert xy\rvert = \lvert x\rvert\lvert y\rvert$ | $\lvert a + b\rvert \le \lvert a\rvert + \lvert b\rvert$ |
| $\lvert A\rvert = B$: **έλεγξε $B \ge 0$** | $k<0$: $\lvert x\rvert<k$ κενό, $\lvert x\rvert>k$ όλο το $\mathbb R$ |
| $\lvert A\rvert \le \lvert B\rvert \Leftrightarrow (A - B)(A + B) \le 0$ | $\left\lvert \frac AB\right\rvert \le k \Leftrightarrow \lvert A\rvert \le k\lvert B\rvert$, $B \ne 0$ |
| $u = \lvert x - a\rvert$ με **$u \ge 0$** | $\frac{1}{\lvert A\rvert} < \frac{1}{\lvert B\rvert} \Leftrightarrow \lvert B\rvert < \lvert A\rvert$ (+ εξαιρέσεις) |

## 4. Συντεταγμένες

- Απόσταση: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ · Μέσο: $\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$
- Πολικές → καρτεσιανές: $x = r\cos\theta$, $y = r\sin\theta$
- Καρτεσιανές → πολικές: $r^2 = x^2 + y^2$, $\tan\theta = y/x$ **+ έλεγχος τεταρτημορίου** ($x < 0 \Rightarrow +\pi$)
- $(r, \theta) = (r, \theta + 2k\pi) = (-r, \theta + \pi)$ · πόλος: $(0, \theta)$ για κάθε $\theta$

| Πολική | Καρτεσιανή |
|---|---|
| $r = a$ | $x^2 + y^2 = a^2$ |
| $\theta = \theta_0$ | $y = (\tan\theta_0)x$ |
| $r = 2a\cos\theta$ | $(x - a)^2 + y^2 = a^2$ |
| $r = 2a\sin\theta$ | $x^2 + (y - a)^2 = a^2$ |

## 5. Ευθεία

- $m = \dfrac{y_2 - y_1}{x_2 - x_1} = \tan\varphi$ · κατακόρυφη: **χωρίς** κλίση
- $y - y_1 = m(x - x_1)$ · $y = mx + b$ · $Ax + By + C = 0$ · $\frac xa + \frac yb = 1$
- **Τεταγμένη επί την αρχή** = τομή με τον $y$ ($x = 0$) · **τετμημένη επί την αρχή** = τομή με τον $x$ ($y = 0$)
- Παράλληλες: $m_1 = m_2$ · Κάθετες: $m_1 m_2 = -1$ · ίδιο $m$ **και** ίδιο $b$ ⇒ **ταυτίζονται**
- $Ax + By + C = 0$: $m = -\frac AB$ · παράλληλη: $Ax + By = \text{σταθ.}$ · κάθετη: $Bx - Ay = \text{σταθ.}$
- Απόσταση σημείου–ευθείας: $\dfrac{\lvert Ax_0 + By_0 + C\rvert}{\sqrt{A^2 + B^2}}$

## 6. Κύκλος

- $(x - h)^2 + (y - k)^2 = r^2$ · κέντρο $(h, k)$
- Συμπλήρωση τετραγώνου: $x^2 + Dx = \left(x + \frac D2\right)^2 - \frac{D^2}{4}$
- Δεξί μέλος $c$: $>0$ κύκλος · $=0$ σημείο · $<0$ κενό
- Εφαπτομένη ⊥ ακτίνα
- Από 3 σημεία: αντικατάσταση στη γενική μορφή → σύστημα για $D, E, F$ (συνευθειακά ⇒ κανένας κύκλος)
- Γεωμ. τόπος: τύπος απόστασης → ανάπτυξη → συμπλήρωση τετραγώνου · $PA^2 + PB^2 = S$: κύκλος με κέντρο το μέσο του $AB$

## 7. Παραβολή

- $y = ax^2 + bx + c$: κορυφή $x_0 = -\dfrac{b}{2a}$ · $a>0$ πάνω · $\Delta = b^2 - 4ac$
- $y = a(x - h)^2 + k$: κορυφή $(h, k)$
- $x^2 = 4py$: εστία $(0, p)$, διευθετούσα $y = -p$
- $y^2 = 4px$: εστία $(p, 0)$, διευθετούσα $x = -p$
- Ευθεία εφάπτεται σε παραβολή ⇔ η εξίσωση τομής έχει $\Delta = 0$
