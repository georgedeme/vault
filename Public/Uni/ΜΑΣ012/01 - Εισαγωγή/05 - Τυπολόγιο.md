# 05 - Τυπολόγιο

Το Κεφάλαιο 1 σε μία σελίδα.

## 0. Σύνολα

- $A \subseteq B \iff (x \in A \Rightarrow x \in B)$ · $A = B \iff A \subseteq B$ και $B \subseteq A$ · $A \subset B$: **γνήσιο** ($A \subseteq B$, $A \ne B$)
- $A \cup B$: στο ένα **ή** στο άλλο · $A \cap B$: και στα δύο · $A - B$: στο $A$ **και όχι** στο $B$ · ξένα: $A \cap B = \varnothing$
- $A \subseteq B \iff A \cup B = B \iff A \cap B = A$ · $\varnothing \subseteq A$ · $A - B \neq B - A$ · $\{\varnothing\} \neq \varnothing$
- $A \times B = \{(x, y) : x \in A, y \in B\}$ · $(x_1, y_1) = (x_2, y_2) \iff x_1 = x_2,\ y_1 = y_2$
- Τομή διαστημάτων: άκρο μένει αν ανήκει **και στα δύο** · ένωση: αν ανήκει **σε ένα** · $(0,2) \cup (2,5) \ne (0,5)$

## 1. Πραγματικοί αριθμοί

- $\mathbb N = \{1, 2, \dots\}$ · $\mathbb N_0 = \{0, 1, 2, \dots\}$ · $\mathbb R^+$ θετικοί · $\mathbb R_0^+$ μη αρνητικοί · άρρητοι $= \mathbb R - \mathbb Q$
- $\mathbb N \subset \mathbb Z \subset \mathbb Q \subset \mathbb R \subset \mathbb C$ · ρητός ⇔ δεκαδικό **τερματίζει ή είναι περιοδικό**
- ρητός + άρρητος = **άρρητος** · άρρητος + άρρητος = **οτιδήποτε**
- $0.\overline{9} = 1$ · $1.72\overline9 = 1.73$
- Περιοδικός → κλάσμα: $k$ ψηφία πριν την περίοδο, περίοδος $p$ ψηφίων ⇒ $(10^{k+p} - 10^k)x$ = ακέραιος

## 2. Ανισότητες

| Κάνω | Φορά |
|---|---|
| $+c$ σε όλα | ίδια |
| $\times c$, $c > 0$ | ίδια |
| $\times c$, $c < 0$ | **αλλάζει** |
| αντίστροφα, **ομόσημα** μέλη | **αλλάζει** |
| τετράγωνο, μέλη $\ge 0$ | ίδια |

> [!important] Πίνακας προσήμων
> Όλα σε ένα μέλος → ένα κλάσμα → παραγοντοποίηση → πρόσημα ανά διάστημα.
> Ρίζες παρονομαστή: **πάντα έξω**. Διπλή ρίζα: **δεν** αλλάζει πρόσημο.
> **Ποτέ** πολλαπλασιασμός/διαίρεση με παράσταση που περιέχει $x$.

- Διαίρεση: $P = \delta\cdot\pi + \upsilon$, σταματάς όταν $\deg\upsilon < \deg\delta$ · υπόλοιπο με $(x - \rho)$ $= P(\rho)$ · $\rho$ ρίζα $\iff (x - \rho) \mid P$
- 3ου βαθμού: ακέραιες ρίζες **διαιρούν τον σταθερό όρο** → Horner → τριώνυμο
- 4ου βαθμού: Horner **δύο φορές** (ρίζα, μετά ρίζα του πηλίκου) · διτετράγωνο $ax^4 + bx^2 + c$: $y = x^2$, και **γύρνα στο $x$** στο τέλος
- Τριώνυμο: ομόσημο του $a$ **έξω** από τις ρίζες · $\Delta < 0$ ⇒ ομόσημο του $a$ παντού

## 3. Απόλυτη τιμή

| | |
|---|---|
| $\lvert x\rvert = x$ αν $x \ge 0$, $-x$ αν $x < 0$ | $\sqrt{x^2} = \lvert x\rvert$ |
| $\lvert x\rvert < k \Leftrightarrow -k < x < k$ | $\lvert x\rvert > k \Leftrightarrow x < -k$ ή $x > k$ |
| $\lvert x - a\rvert < \delta \Leftrightarrow a - \delta < x < a + \delta$ | $\lvert A\rvert = \lvert B\rvert \Leftrightarrow A = \pm B$ |
| $\lvert xy\rvert = \lvert x\rvert\lvert y\rvert$ | $\lvert a + b\rvert \le \lvert a\rvert + \lvert b\rvert$ |
| $\lvert A\rvert = B$: **έλεγξε $B \ge 0$** | $k<0$: $\lvert x\rvert<k$ κενό, $\lvert x\rvert>k$ όλο το $\mathbb R$ |
| $\lvert A\rvert \le \lvert B\rvert \Leftrightarrow (A - B)(A + B) \le 0$ | $\left\lvert \frac AB\right\rvert \le k \Leftrightarrow \lvert A\rvert \le k\lvert B\rvert$, $B \ne 0$ |
| $u = \lvert x - a\rvert$ με **$u \ge 0$** | $\frac{1}{\lvert A\rvert} < \frac{1}{\lvert B\rvert} \Leftrightarrow \lvert B\rvert < \lvert A\rvert$ (+ εξαιρέσεις) |
| $-\lvert x\rvert \le x \le \lvert x\rvert$ | $\big\lvert\lvert a\rvert - \lvert b\rvert\big\rvert \le \lvert a - b\rvert \le \lvert a\rvert + \lvert b\rvert$ |

> [!important] Φράγμα $\lvert f(x)\rvert \le M$ σε $[a, b]$
> Γενικευμένη τριγωνική: $\lvert \sum a_k x^k\rvert \le \sum \lvert a_k\rvert\lvert x\rvert^k$, με $\lvert x\rvert \le \max\{\lvert a\rvert, \lvert b\rvert\}$.
> Κλάσμα: αριθμητής **από πάνω**, παρονομαστής **από κάτω** ($\lvert h\rvert \ge H > 0$).

- Κλασματική ανίσωση: $\frac AB > 0 \iff AB > 0$ ($B \ne 0$), δηλαδή πολλαπλασιασμός με $B^2 > 0$

## 4. Συντεταγμένες

- Απόσταση: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ · Μέσο: $\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$
- Διαίρεση σε λόγο $\frac{AM}{MB} = \lambda$: $M\left(\frac{x_1 + \lambda x_2}{1 + \lambda}, \frac{y_1 + \lambda y_2}{1 + \lambda}\right)$
- Πολικές → καρτεσιανές: $x = r\cos\theta$, $y = r\sin\theta$
- Καρτεσιανές → πολικές: $r^2 = x^2 + y^2$, $\tan\theta = y/x$ **+ έλεγχος τεταρτημορίου** ($x < 0 \Rightarrow +\pi$)
- $(r, \theta) = (r, \theta + 2k\pi) = (-r, \theta + \pi)$ · πόλος: $(0, \theta)$ για κάθε $\theta$

| Πολική | Καρτεσιανή |
|---|---|
| $r = a$ | $x^2 + y^2 = a^2$ |
| $\theta = \theta_0$ | $y = (\tan\theta_0)x$ |
| $r = 2a\cos\theta$ | $(x - a)^2 + y^2 = a^2$ |
| $r = 2a\sin\theta$ | $x^2 + (y - a)^2 = a^2$ |

## 5. Ευθεία

- $m = \dfrac{y_2 - y_1}{x_2 - x_1} = \tan\varphi$ · κατακόρυφη: **χωρίς** κλίση
- $y - y_1 = m(x - x_1)$ · $y = mx + b$ · $Ax + By + C = 0$ · $\frac xa + \frac yb = 1$
- **Τεταγμένη επί την αρχή** = τομή με τον $y$ ($x = 0$) · **τετμημένη επί την αρχή** = τομή με τον $x$ ($y = 0$)
- Παράλληλες: $m_1 = m_2$ · Κάθετες: $m_1 m_2 = -1$ · ίδιο $m$ **και** ίδιο $b$ ⇒ **ταυτίζονται**
- $Ax + By + C = 0$: $m = -\frac AB$ · παράλληλη: $Ax + By = \text{σταθ.}$ · κάθετη: $Bx - Ay = \text{σταθ.}$
- Απόσταση σημείου–ευθείας: $\dfrac{\lvert Ax_0 + By_0 + C\rvert}{\sqrt{A^2 + B^2}}$
- Από συντελεστές: $\frac{A_1}{A_2} = \frac{B_1}{B_2}$ παράλληλες (αν και $= \frac{\Gamma_1}{\Gamma_2}$, ταυτίζονται) · κάθετες ⇔ $A_1A_2 + B_1B_2 = 0$
- Γωνία: $\tan\varphi = \dfrac{m_2 - m_1}{1 + m_1 m_2}$ · οξεία με $\lvert\cdot\rvert$ · γωνία τριγώνου μπορεί να είναι $\pi - \theta$ (αμβλεία)

## 6. Κύκλος

- $(x - h)^2 + (y - k)^2 = r^2$ · κέντρο $(h, k)$ · παραμετρικά: $x = h + r\cos\theta$, $y = k + r\sin\theta$
- $x^2 + y^2 + Ax + By + \Gamma = 0$: $A^2 + B^2 - 4\Gamma$ $>0$ κύκλος, κέντρο $\left(-\frac A2, -\frac B2\right)$, $R = \frac{\sqrt{A^2 + B^2 - 4\Gamma}}{2}$ · $=0$ σημείο · $<0$ κενό
- Συμπλήρωση τετραγώνου: $x^2 + Ax = \left(x + \frac A2\right)^2 - \frac{A^2}{4}$
- Δεξί μέλος $c$: $>0$ κύκλος · $=0$ σημείο · $<0$ κενό
- Εφαπτομένη ⊥ ακτίνα
- Από 3 σημεία: αντικατάσταση στη γενική μορφή → σύστημα για $A, B, \Gamma$ (συνευθειακά ⇒ κανένας κύκλος)
- Γεωμ. τόπος: τύπος απόστασης → ανάπτυξη → συμπλήρωση τετραγώνου · $PA^2 + PB^2 = S$: κύκλος με κέντρο το μέσο του $AB$ · $PA = k\,PB$ ($k \ne 1$): κύκλος · $\widehat{APB} = 90°$: κύκλος διαμέτρου $AB$ χωρίς τα $A, B$

## 7. Παραβολή

- $y = ax^2 + bx + c$: κορυφή $\left(-\dfrac{b}{2a}, -\dfrac{\Delta}{4a}\right)$ · $a>0$ πάνω · $\Delta = b^2 - 4ac$
- $y = a(x - h)^2 + k$: κορυφή $(h, k)$
- $x^2 = 4py$: εστία $(0, p)$, διευθετούσα $y = -p$
- $y^2 = 4px$: εστία $(p, 0)$, διευθετούσα $x = -p$
- Ευθεία εφάπτεται σε παραβολή ⇔ η εξίσωση τομής έχει $\Delta = 0$
