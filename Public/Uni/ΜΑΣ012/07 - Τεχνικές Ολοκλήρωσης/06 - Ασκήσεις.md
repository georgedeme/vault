# 06 - Ασκήσεις

Ασκήσεις για το Κεφάλαιο 7. **Λύσε πρώτα, άνοιξε μετά**: κάθε λύση είναι κρυμμένη σε αναδιπλούμενο πλαίσιο. Οι ασκήσεις με 🪤 έχουν παγίδα. Έλεγχε πάντα την αρχική σου **παραγωγίζοντας** το αποτέλεσμα!

> [!tip] Πώς να το χρησιμοποιήσεις
> Κάνε ένα πλήρες πέρασμα χωρίς να ανοίξεις λύση — ειδικά το **Μέρος Ε (Μικτό Σετ)**, όπου δεν ξέρεις εκ των προτέρων ποια τεχνική χρειάζεται (ακριβώς όπως στις εξετάσεις).

---

## Μέρος Α — Αντικατάσταση, Συμπλήρωση Τετραγώνου & Συμμετρία

### Άσκηση 1

Υπολόγισε $\displaystyle\int \frac{e^{\sqrt{x}}}{\sqrt{x}}\,dx$.

> [!success]- Λύση
> Θέτουμε $u = \sqrt{x} \implies du = \dfrac{dx}{2\sqrt{x}} \implies \dfrac{dx}{\sqrt{x}} = 2\,du$:
> $$\int \frac{e^{\sqrt{x}}}{\sqrt{x}}\,dx = 2\int e^u\,du = 2e^{\sqrt{x}} + C$$

### Άσκηση 2

Υπολόγισε $\displaystyle\int \frac{dx}{1 + \sqrt[3]{x}}$.

> [!success]- Λύση
> Θέτουμε $u = \sqrt[3]{x} \implies x = u^3,\; dx = 3u^2\,du$:
> $$\begin{aligned}
> \int \frac{dx}{1 + \sqrt[3]{x}} &= 3\int \frac{u^2}{u + 1}\,du = 3\int \left(u - 1 + \frac{1}{u + 1}\right)du \\
> &= \frac{3}{2}u^2 - 3u + 3\ln\lvert u + 1\rvert + C = \frac{3}{2}x^{2/3} - 3x^{1/3} + 3\ln\lvert x^{1/3} + 1\rvert + C
> \end{aligned}$$

### Άσκηση 3 🪤

Υπολόγισε το ορισμένο ολοκλήρωμα $\displaystyle\int_0^3 \frac{x}{\sqrt{1 + x}}\,dx$.

> [!success]- Λύση
> Θέτουμε $u = 1 + x \implies x = u - 1,\; dx = du$.
> **Νέα όρια:** $x = 0 \mapsto u = 1$, και $x = 3 \mapsto u = 4$ (🪤 μην κρατήσεις τα $0, 3$ και μην ξαναγυρίσεις στο $x$!).
> $$\int_1^4 \frac{u - 1}{\sqrt{u}}\,du = \int_1^4 \left(u^{1/2} - u^{-1/2}\right)du = \left[\frac{2}{3}u^{3/2} - 2u^{1/2}\right]_1^4 = \left(\frac{16}{3} - 4\right) - \left(\frac{2}{3} - 2\right) = \frac{8}{3}$$

### Άσκηση 4

Υπολόγισε $\displaystyle\int \frac{3x - 1}{x^2 + 4x + 13}\,dx$.

> [!success]- Λύση
> Συμπλήρωση τετραγώνου: $x^2 + 4x + 13 = (x + 2)^2 + 9$.
> Θέτουμε $u = x + 2 \implies x = u - 2,\; 3x - 1 = 3u - 7,\; dx = du$:
> $$\begin{aligned}
> \int \frac{3u - 7}{u^2 + 9}\,du &= \frac{3}{2}\int \frac{2u}{u^2 + 9}\,du - 7\int \frac{du}{u^2 + 9} \\
> &= \frac{3}{2}\ln(u^2 + 9) - \frac{7}{3}\tan^{-1}\frac{u}{3} + C = \frac{3}{2}\ln(x^2 + 4x + 13) - \frac{7}{3}\tan^{-1}\frac{x + 2}{3} + C
> \end{aligned}$$

### Άσκηση 5 🪤 (Βοήθημα, άσκ. 36β)

Απόδειξε ότι $\displaystyle\int_0^{\pi/2} \frac{\sin^2 x}{\sin x + \cos x}\,dx = \frac{1}{\sqrt{2}}\ln(1 + \sqrt{2})$.

> [!success]- Λύση
> Θέτουμε $u = \frac{\pi}{2} - x$ (ιδιότητα του Βασιλιά): $\sin(\frac{\pi}{2} - u) = \cos u$, $\cos(\frac{\pi}{2} - u) = \sin u$, άρα
> $$I = \int_0^{\pi/2} \frac{\cos^2 x}{\sin x + \cos x}\,dx$$
> Προσθέτουμε τα δύο ολοκληρώματα:
> $$2I = \int_0^{\pi/2} \frac{\sin^2 x + \cos^2 x}{\sin x + \cos x}\,dx = \int_0^{\pi/2} \frac{dx}{\sin x + \cos x}$$
> Γράφουμε $\sin x + \cos x = \sqrt{2}\sin\!\left(x + \frac{\pi}{4}\right)$ και θέτουμε $w = x + \frac{\pi}{4}$:
> $$\begin{aligned}
> 2I &= \frac{1}{\sqrt{2}}\int_{\pi/4}^{3\pi/4} \csc w\,dw = \frac{1}{\sqrt{2}}\Big[-\ln\lvert\csc w + \cot w\rvert\Big]_{\pi/4}^{3\pi/4} \\
> &= \frac{1}{\sqrt{2}}\Big(-\ln(\sqrt{2} - 1) + \ln(\sqrt{2} + 1)\Big) = \frac{1}{\sqrt{2}}\ln\frac{\sqrt{2} + 1}{\sqrt{2} - 1} = \frac{1}{\sqrt{2}}\ln(\sqrt{2} + 1)^2 = \sqrt{2}\ln(1 + \sqrt{2})
> \end{aligned}$$
> Διαιρώντας με $2$: $I = \dfrac{1}{\sqrt{2}}\ln(1 + \sqrt{2})$. ✓

## Μέρος Β — Ολοκλήρωση κατά Παράγοντες

### Άσκηση 6

Υπολόγισε $\displaystyle\int x^2\ln x\,dx$.

> [!success]- Λύση
> Κατά LIATE: $u = \ln x,\; dv = x^2\,dx \implies du = \frac{1}{x}\,dx,\; v = \frac{1}{3}x^3$.
> $$\int x^2\ln x\,dx = \frac{1}{3}x^3\ln x - \frac{1}{3}\int x^2\,dx = \frac{1}{3}x^3\ln x - \frac{1}{9}x^3 + C$$

### Άσκηση 7

Υπολόγισε $\displaystyle\int \cos^{-1}(2x)\,dx$.

> [!success]- Λύση
> «Κρυμμένο $1$»: $u = \cos^{-1}(2x),\; dv = dx \implies du = -\dfrac{2}{\sqrt{1 - 4x^2}}\,dx,\; v = x$.
> $$\int \cos^{-1}(2x)\,dx = x\cos^{-1}(2x) + \int \frac{2x}{\sqrt{1 - 4x^2}}\,dx = x\cos^{-1}(2x) - \frac{1}{2}\sqrt{1 - 4x^2} + C$$
> *(Στο τελευταίο: $w = 1 - 4x^2 \implies dw = -8x\,dx \implies 2x\,dx = -\frac{1}{4}\,dw$.)*

### Άσκηση 8 🪤 (Βοήθημα, άσκ. 23δ)

Υπολόγισε $\displaystyle\int e^{\sqrt{x}}\,dx$.

> [!success]- Λύση
> 🪤 Αν πας κατευθείαν παραγοντική, δυσκολεύει. Κάνε **πρώτα** αντικατάσταση $w = \sqrt{x} \implies x = w^2,\; dx = 2w\,dw$:
> $$\int e^{\sqrt{x}}\,dx = 2\int w e^w\,dw = 2\big(w e^w - e^w\big) + C = 2(\sqrt{x} - 1)e^{\sqrt{x}} + C$$

### Άσκηση 9

Υπολόγισε $\displaystyle\int e^{-2x}\sin(3x)\,dx$.

> [!success]- Λύση
> Κυκλική παραγοντική (2 φορές, κρατώντας $u = e^{-2x}$ και τις δύο φορές):
> 1η: $I = -\frac{1}{3}e^{-2x}\cos 3x - \frac{2}{3}\int e^{-2x}\cos 3x\,dx$.
> 2η: $I = -\frac{1}{3}e^{-2x}\cos 3x - \frac{2}{3}\left[\frac{1}{3}e^{-2x}\sin 3x + \frac{2}{3}I\right] = -\frac{1}{3}e^{-2x}\cos 3x - \frac{2}{9}e^{-2x}\sin 3x - \frac{4}{9}I$.
> Άρα $\dfrac{13}{9}I = -\dfrac{e^{-2x}}{9}(2\sin 3x + 3\cos 3x) \implies I = -\dfrac{e^{-2x}}{13}(2\sin 3x + 3\cos 3x) + C$.

### Άσκηση 10 🪤 (Βοήθημα, άσκ. 5στ)

Υπολόγισε $\displaystyle\int \cos(\ln x)\,dx$.

> [!success]- Λύση
> Πρώτα $w = \ln x \implies x = e^w,\; dx = e^w\,dw$ (ή απευθείας κυκλική παραγοντική δύο φορές με $dv = dx$):
> $$\int \cos(\ln x)\,dx = \int e^w\cos w\,dw = \frac{e^w}{2}(\cos w + \sin w) + C = \frac{x}{2}\big(\cos(\ln x) + \sin(\ln x)\big) + C$$

### Άσκηση 11

Υπολόγισε $\displaystyle\int_0^{\pi/2} \cos^6 x\,dx$ με αναγωγικό τύπο (ή Wallis).

> [!success]- Λύση
> Με τους τύπους του Wallis ($n = 6$ άρτιος):
> $$\int_0^{\pi/2} \cos^6 x\,dx = \frac{1\cdot 3\cdot 5}{2\cdot 4\cdot 6}\cdot\frac{\pi}{2} = \frac{5\pi}{32}$$

## Μέρος Γ — Τριγωνομετρικά, Τριγωνομετρικές/Υπερβολικές Αντικαταστάσεις & Weierstrass

### Άσκηση 12

Υπολόγισε $\displaystyle\int \sin^3 x\cos^4 x\,dx$.

> [!success]- Λύση
> Περιττός εκθέτης στο $\sin x$ ⇒ κράτα $\sin x\,dx$ και θέσε $u = \cos x$ ($du = -\sin x\,dx$):
> $$\int (1 - \cos^2 x)\cos^4 x\sin x\,dx = -\int (u^4 - u^6)\,du = -\frac{1}{5}\cos^5 x + \frac{1}{7}\cos^7 x + C$$

### Άσκηση 13

Υπολόγισε $\displaystyle\int \tan^3 x\sec^4 x\,dx$.

> [!success]- Λύση
> Εδώ δουλεύουν **και οι δύο** περιπτώσεις ($m = 3$ περιττός ΚΑΙ $n = 4$ άρτιος)!
> - Με $u = \tan x$ ($du = \sec^2 x\,dx$): $\int \tan^3 x(1 + \tan^2 x)\sec^2 x\,dx = \frac{1}{4}\tan^4 x + \frac{1}{6}\tan^6 x + C_1$.
> - Με $u = \sec x$ ($du = \sec x\tan x\,dx$): $\int (\sec^2 x - 1)\sec^3 x\,(\sec x\tan x\,dx) = \frac{1}{6}\sec^6 x - \frac{1}{4}\sec^4 x + C_2$.
> *(Οι δύο απαντήσεις είναι ισοδύναμες — διαφέρουν κατά τη σταθερά $\frac{1}{12}$!)*

### Άσκηση 14

Υπολόγισε $\displaystyle\int \frac{dx}{x^2\sqrt{x^2 + 25}}$ (δοκίμασε υπερβολική αντικατάσταση!).

> [!success]- Λύση
> Θέτουμε $x = 5\sinh t \implies dx = 5\cosh t\,dt,\; \sqrt{x^2 + 25} = 5\cosh t$:
> $$\int \frac{5\cosh t\,dt}{25\sinh^2 t\cdot 5\cosh t} = \frac{1}{25}\int \operatorname{csch}^2 t\,dt = -\frac{1}{25}\coth t + C = -\frac{\sqrt{x^2 + 25}}{25x} + C$$
> *(Αφού $\sinh t = \frac{x}{5}$ και $\cosh t = \frac{\sqrt{x^2 + 25}}{5}$.)*

### Άσκηση 15 🪤

Υπολόγισε $\displaystyle\int_{-4}^{-2} \frac{\sqrt{x^2 - 4}}{x}\,dx$.

> [!success]- Λύση
> 🪤 Προσοχή: εδώ $x \le -2 < 0$, άρα η υπό ολοκλήρωση συνάρτηση είναι **αρνητική**!
> Θέτουμε $x = 2\sec\theta$ με $\theta \in \left[\pi, \frac{3\pi}{2}\right)$ ώστε $\tan\theta \ge 0$ και $\sqrt{x^2 - 4} = 2\tan\theta$.
> Όρια: $x = -4 \implies \cos\theta = -\frac{1}{2} \implies \theta = \frac{4\pi}{3}$· $x = -2 \implies \cos\theta = -1 \implies \theta = \pi$.
> $$\int_{4\pi/3}^{\pi} \frac{2\tan\theta}{2\sec\theta}\cdot 2\sec\theta\tan\theta\,d\theta = 2\int_{4\pi/3}^{\pi} (\sec^2\theta - 1)\,d\theta = 2\Big[\tan\theta - \theta\Big]_{4\pi/3}^{\pi} = 2\left(-\pi - \sqrt{3} + \frac{4\pi}{3}\right) = \frac{2\pi}{3} - 2\sqrt{3}$$
> *(Έλεγχος προσήμου: $\frac{2\pi}{3} - 2\sqrt{3} \approx -1.37 < 0$ ✓.)*

### Άσκηση 16 (Βοήθημα, άσκ. 23στ)

Υπολόγισε $\displaystyle\int \frac{dx}{2 + \sin x}$.

> [!success]- Λύση
> Με Weierstrass $t = \tan\frac{x}{2}$ ($\sin x = \frac{2t}{1 + t^2},\; dx = \frac{2\,dt}{1 + t^2}$):
> $$\begin{aligned}
> \int \frac{dx}{2 + \sin x} &= \int \frac{2\,dt}{2(1 + t^2) + 2t} = \int \frac{dt}{t^2 + t + 1} = \int \frac{dt}{\left(t + \frac{1}{2}\right)^2 + \frac{3}{4}} \\
> &= \frac{2}{\sqrt{3}}\tan^{-1}\!\left(\frac{2t + 1}{\sqrt{3}}\right) + C = \frac{2}{\sqrt{3}}\tan^{-1}\!\left(\frac{2\tan\frac{x}{2} + 1}{\sqrt{3}}\right) + C
> \end{aligned}$$

### Άσκηση 17 🪤

Υπολόγισε $\displaystyle\int_0^{2\pi} \frac{dx}{5 + 3\cos x}$.

> [!success]- Λύση
> 🪤 Μην εφαρμόσεις $t = \tan\frac{x}{2}$ κατευθείαν από $0$ ως $2\pi$ (υπάρχει ασύμπτωτη στο $x = \pi$ και θα πάρεις λάθος $0$)!
> Λόγω συμμετρίας του $\cos x$ γύρω από το $\pi$:
> $$\int_0^{2\pi} \frac{dx}{5 + 3\cos x} = 2\int_0^{\pi} \frac{dx}{5 + 3\cos x}$$
> Τώρα $t = \tan\frac{x}{2} \in [0, +\infty)$:
> $$2\int_0^{+\infty} \frac{\frac{2\,dt}{1 + t^2}}{5 + 3\frac{1 - t^2}{1 + t^2}} = 4\int_0^{+\infty} \frac{dt}{8 + 2t^2} = 2\int_0^{+\infty} \frac{dt}{t^2 + 4} = \left[\tan^{-1}\frac{t}{2}\right]_0^{+\infty} = \frac{\pi}{2}$$

## Μέρος Δ — Ανάλυση σε Μερικά Κλάσματα

### Άσκηση 18 🪤

Υπολόγισε $\displaystyle\int \frac{x^3 + x}{x^2 - 1}\,dx$.

> [!success]- Λύση
> 🪤 Πρώτα ευκλείδεια διαίρεση ($\deg P = 3 \ge 2 = \deg Q$):
> $$\frac{x^3 + x}{x^2 - 1} = x + \frac{2x}{x^2 - 1}$$
> Το $\frac{2x}{x^2 - 1}$ έχει ήδη τη μορφή $\frac{u'}{u}$ (δεν χρειάζονται καν μερικά κλάσματα!):
> $$\int \frac{x^3 + x}{x^2 - 1}\,dx = \frac{1}{2}x^2 + \ln\lvert x^2 - 1\rvert + C$$

### Άσκηση 19

Υπολόγισε $\displaystyle\int \frac{x + 5}{x^2 - x - 2}\,dx$.

> [!success]- Λύση
> $x^2 - x - 2 = (x - 2)(x + 1)$. Με κάλυψη Heaviside:
> $A = \dfrac{2 + 5}{2 + 1} = \dfrac{7}{3}$,\; $B = \dfrac{-1 + 5}{-1 - 2} = -\dfrac{4}{3}$.
> $$\int \frac{x + 5}{x^2 - x - 2}\,dx = \frac{7}{3}\ln\lvert x - 2\rvert - \frac{4}{3}\ln\lvert x + 1\rvert + C$$

### Άσκηση 20

Υπολόγισε $\displaystyle\int \frac{dx}{x(x^2 + 1)^2}$.

> [!success]- Λύση
> Ανάλυση: $\dfrac{1}{x(x^2 + 1)^2} = \dfrac{A}{x} + \dfrac{Bx + C}{x^2 + 1} + \dfrac{Dx + E}{(x^2 + 1)^2}$.
> Βρίσκουμε $A = 1,\; B = -1,\; C = 0,\; D = -1,\; E = 0$ *(γρήγορο κόλπο: $\frac{1}{x(x^2+1)^2} = \frac{(x^2+1) - x^2}{x(x^2+1)^2} = \frac{1}{x(x^2+1)} - \frac{x}{(x^2+1)^2} = \frac{1}{x} - \frac{x}{x^2+1} - \frac{x}{(x^2+1)^2}$)*.
> $$\int \frac{dx}{x(x^2 + 1)^2} = \ln\lvert x\rvert - \frac{1}{2}\ln(x^2 + 1) + \frac{1}{2(x^2 + 1)} + C$$

### Άσκηση 21

Υπολόγισε $\displaystyle\int \frac{e^x}{e^{2x} - 4}\,dx$.

> [!success]- Λύση
> Θέτουμε $u = e^x \implies du = e^x\,dx$:
> $$\int \frac{du}{u^2 - 4} = \frac{1}{4}\int \left(\frac{1}{u - 2} - \frac{1}{u + 2}\right)du = \frac{1}{4}\ln\left\lvert\frac{e^x - 2}{e^x + 2}\right\rvert + C$$

## Μέρος Ε — Μικτό Σετ: «Αναγνώρισε την Τεχνική» 🪤

Έξι ολοκληρώματα που **μοιάζουν σχεδόν ίδια**, αλλά το καθένα απαιτεί διαφορετική τεχνική! Πριν υπολογίσεις, ονόμασε πρώτα τη μέθοδο.

### Άσκηση 22 🪤

Υπολόγισε και τα έξι:
(α) $\displaystyle\int \frac{dx}{x^2 + 4}$ · (β) $\displaystyle\int \frac{x\,dx}{x^2 + 4}$ · (γ) $\displaystyle\int \frac{x^2\,dx}{x^2 + 4}$ · (δ) $\displaystyle\int \frac{dx}{x^2 - 4}$ · (ε) $\displaystyle\int \frac{dx}{\sqrt{x^2 + 4}}$ · (στ) $\displaystyle\int \frac{dx}{(x^2 + 4)^2}$

> [!success]- Λύση
> - **(α) Άμεσος τύπος $\tan^{-1}$:** $\dfrac{1}{2}\tan^{-1}\dfrac{x}{2} + C$
> - **(β) Άμεση $u$-αντικατάσταση** ($u = x^2 + 4$): $\dfrac{1}{2}\ln(x^2 + 4) + C$
> - **(γ) Ευκλείδεια διαίρεση** ($\frac{x^2}{x^2 + 4} = 1 - \frac{4}{x^2 + 4}$): $x - 2\tan^{-1}\dfrac{x}{2} + C$
> - **(δ) Μερικά κλάσματα** ($x^2 - 4 = (x - 2)(x + 2)$): $\dfrac{1}{4}\ln\left\lvert\dfrac{x - 2}{x + 2}\right\rvert + C$
> - **(ε) Υπερβολική αντικατάσταση** ($x = 2\sinh t$): $\sinh^{-1}\dfrac{x}{2} + C = \ln\!\left(x + \sqrt{x^2 + 4}\right) + C'$
> - **(στ) Τριγωνομετρική αντικατάσταση** ($x = 2\tan\theta$): $\dfrac{1}{16}\tan^{-1}\dfrac{x}{2} + \dfrac{x}{8(x^2 + 4)} + C$
