# 04 - Ανάλυση σε Μερικά Κλάσματα

Κάθε <span class="hl-blue">ρητή συνάρτηση</span> $\dfrac{P(x)}{Q(x)}$ (πηλίκο δύο πολυωνύμων) μπορεί να ολοκληρωθεί στοιχειωδώς, διασπώντας την σε άθροισμα απλούστερων κλασμάτων.

## 1. Απαραίτητο Πρώτο Βήμα: Ευκλείδεια διαίρεση

> [!warning] Παγίδα 🪤 — Πάντα έλεγχε πρώτα τους βαθμούς!
> Η ανάλυση σε μερικά κλάσματα εφαρμόζεται **μόνο σε γνήσια ρητές συναρτήσεις**, δηλαδή όταν $\deg P < \deg Q$.
> Αν $\deg P \ge \deg Q$, **πρέπει πρώτα να κάνεις ευκλείδεια διαίρεση πολυωνύμων**:
> $$\frac{P(x)}{Q(x)} = \Pi(x) + \frac{Y(x)}{Q(x)}, \qquad \deg Y < \deg Q$$
> Το πηλίκο $\Pi(x)$ είναι πολυώνυμο (ολοκληρώνεται αμέσως) και αναλύεις σε μερικά κλάσματα **μόνο** το γνήσιο κλάσμα $\dfrac{Y(x)}{Q(x)}$.
> *Αν προσπαθήσεις να αναλύσεις π.χ. το $\dfrac{x^2}{x^2 - 1}$ ως $\dfrac{A}{x - 1} + \dfrac{B}{x + 1}$ χωρίς διαίρεση, θα πάρεις $x^2 = A(x + 1) + B(x - 1)$ — αδύνατο!*

> [!example]- Παράδειγμα 1: διαίρεση πριν τα μερικά κλάσματα (Βοήθημα §1.6, Παρ. 5)
> Υπολόγισε $\displaystyle\int \frac{x^3 - 2x}{x^2 + 3x + 2}\,dx$.
> Αφού $\deg P = 3 \ge 2 = \deg Q$, κάνουμε διαίρεση:
> $$\frac{x^3 - 2x}{x^2 + 3x + 2} = x - 3 + \frac{5x + 6}{x^2 + 3x + 2}$$
> Παραγοντοποιούμε $x^2 + 3x + 2 = (x + 1)(x + 2)$ και αναλύουμε το υπόλοιπο:
> $$\frac{5x + 6}{(x + 1)(x + 2)} = \frac{1}{x + 1} + \frac{4}{x + 2}$$
> Επομένως:
> $$\int \frac{x^3 - 2x}{x^2 + 3x + 2}\,dx = \int \left(x - 3 + \frac{1}{x + 1} + \frac{4}{x + 2}\right)dx = \frac{1}{2}x^2 - 3x + \ln\lvert x + 1\rvert + 4\ln\lvert x + 2\rvert + C$$

## 2. Οι 4 περιπτώσεις παραγοντοποίησης του παρονομαστή

Κάθε πολυώνυμο $Q(x)$ με πραγματικούς συντελεστές παραγοντοποιείται σε γινόμενο **γραμμικών** παραγόντων $(ax + b)$ και **ανάγωγων τετραγωνικών** $(ax^2 + bx + c)$ (με $\Delta = b^2 - 4ac < 0$). Κάθε παράγοντας του $Q(x)$ συνεισφέρει τους εξής όρους στην ανάλυση:

| # | Παράγοντας στον $Q(x)$ | Αντίστοιχοι όροι στα μερικά κλάσματα |
|---|---|---|
| **1** | **Διακεκριμένος γραμμικός** $ax + b$ | $\dfrac{A}{ax + b}$ |
| **2** | **Επαναλαμβανόμενος γραμμικός** $(ax + b)^m$ | $\dfrac{A_1}{ax + b} + \dfrac{A_2}{(ax + b)^2} + \dots + \dfrac{A_m}{(ax + b)^m}$ |
| **3** | **Διακεκριμένος ανάγωγος τετραγωνικός** $ax^2 + bx + c$ ($\Delta < 0$) | $\dfrac{Ax + B}{ax^2 + bx + c}$ |
| **4** | **Επαναλαμβανόμενος ανάγωγος τετραγωνικός** $(ax^2 + bx + c)^m$ | $\dfrac{A_1x + B_1}{ax^2 + bx + c} + \dfrac{A_2x + B_2}{(ax^2 + bx + c)^2} + \dots + \dfrac{A_mx + B_m}{(ax^2 + bx + c)^m}$ |

![[c7-04-partial-fractions.png|539]]
*Διάγραμμα απόφασης για την ανάλυση ρητής συνάρτησης σε μερικά κλάσματα: πρώτα έλεγχος βαθμού, έπειτα αντιστοίχιση των 4 τύπων παραγόντων του παρονομαστή.*

> [!note] Γρήγορος έλεγχος αριθμού αγνώστων
> Ο συνολικός αριθμός των άγνωστων σταθερών ($A, B, C, \dots$) είναι **πάντα ίσος με τον βαθμό του $Q(x)$**. Π.χ. για $Q(x) = x^2(x - 1)(x^2 + 4)^2$ ο βαθμός είναι $2 + 1 + 4 = 7$, άρα πρέπει να έχεις ακριβώς $7$ αγνώστους:
> $$\frac{A}{x} + \frac{B}{x^2} + \frac{C}{x - 1} + \frac{Dx + E}{x^2 + 4} + \frac{Fx + G}{(x^2 + 4)^2}$$

## 3. Εύρεση των σταθερών: Μέθοδος κάλυψης (Heaviside) vs Προσδιοριστέοι συντελεστές

Αφού γράψουμε τη μορφή της ανάλυσης, πολλαπλασιάζουμε και τα δύο μέλη με τον $Q(x)$ ώστε να έχουμε μια πολυωνυμική ταυτότητα. Έχουμε δύο τρόπους να βρούμε τις σταθερές (στην πράξη τους **συνδυάζουμε**!):

1. **Μέθοδος αντικατάστασης ριζών / Κάλυψης (Heaviside cover-up):**
   - Για κάθε **απλή ρίζα** $r$ του $Q(x)$ (παράγοντας $x - r$): για να βρεις τον αριθμητή $A$ του $\dfrac{A}{x - r}$, «κάλυψε» (σβήσε) τον παράγοντα $(x - r)$ στον παρονομαστή του $\dfrac{P(x)}{Q(x)}$ και αντικατάστησε $x = r$ στο υπόλοιπο!
   - Για **επαναλαμβανόμενο γραμμικό** $(x - r)^m$: η κάλυψη δίνει άμεσα τον συντελεστή της **μέγιστης δύναμης** $A_m$ (αντικαθιστώντας $x = r$).
2. **Εξίσωση συντελεστών (προσδιοριστέοι συντελεστές):**
   - Αναπτύσσουμε τις δυνάμεις του $x$ και εξισώνουμε τους συντελεστές των $x^k$ στα δύο μέλη. (Συχνά αρκεί να δώσεις 1–2 «βολικές» τιμές του $x$, όπως $x = 0, 1, -1$, αφού βρεις πρώτα όσες σταθερές δίνει η κάλυψη!)

> [!example]- Παράδειγμα 2: διακεκριμένοι γραμμικοί με Heaviside (Βοήθημα §1.6, Παρ. 2)
> Υπολόγισε $\displaystyle\int \frac{dx}{(x + 1)(x + 2)(x + 3)}$.
> Γράφουμε $\dfrac{1}{(x + 1)(x + 2)(x + 3)} = \dfrac{A}{x + 1} + \dfrac{B}{x + 2} + \dfrac{C}{x + 3}$.
> Με τη μέθοδο κάλυψης (σε 5 δευτερόλεπτα, χωρίς σύστημα $3\times 3$!):
> - $A$ (κάλυψε $x + 1$, βάλε $x = -1$): $A = \dfrac{1}{(-1 + 2)(-1 + 3)} = \dfrac{1}{2}$
> - $B$ (κάλυψε $x + 2$, βάλε $x = -2$): $B = \dfrac{1}{(-2 + 1)(-2 + 3)} = -1$
> - $C$ (κάλυψε $x + 3$, βάλε $x = -3$): $C = \dfrac{1}{(-3 + 1)(-3 + 2)} = \dfrac{1}{2}$
>
> Επομένως:
> $$\int \frac{dx}{(x + 1)(x + 2)(x + 3)} = \frac{1}{2}\ln\lvert x + 1\rvert - \ln\lvert x + 2\rvert + \frac{1}{2}\ln\lvert x + 3\rvert + C$$

> [!example]- Παράδειγμα 3: επαναλαμβανόμενος γραμμικός (Βοήθημα §1.6, Παρ. 3)
> Υπολόγισε $\displaystyle\int \frac{x^2 + 2x + 4}{(x + 1)^3}\,dx$.
> **Τρόπος 1 (μερικά κλάσματα):**
> $$\frac{x^2 + 2x + 4}{(x + 1)^3} = \frac{A}{x + 1} + \frac{B}{(x + 1)^2} + \frac{C}{(x + 1)^3}$$
> Άρα $x^2 + 2x + 4 = A(x + 1)^2 + B(x + 1) + C = Ax^2 + (2A + B)x + (A + B + C)$.
> Βρίσκουμε $A = 1,\; B = 0,\; C = 3$, οπότε:
> $$\int \frac{x^2 + 2x + 4}{(x + 1)^3}\,dx = \int \left(\frac{1}{x + 1} + \frac{3}{(x + 1)^3}\right)dx = \ln\lvert x + 1\rvert - \frac{3}{2(x + 1)^2} + C$$
> **Τρόπος 2 (γρήγορο κόλπο όταν υπάρχει μόνο μία ρίζα):** θέσε $u = x + 1 \implies x = u - 1$:
> $$\frac{(u - 1)^2 + 2(u - 1) + 4}{u^3} = \frac{u^2 + 3}{u^3} = \frac{1}{u} + \frac{3}{u^3}$$
> Τελειώνει σε μία γραμμή χωρίς σύστημα!

## 4. Ολοκλήρωση των κομματιών (ειδικά των ανάγωγων τετραγωνικών)

Αφού βρούμε τις σταθερές, κάθε κομμάτι ολοκληρώνεται ως εξής:
- $\displaystyle\int \frac{A}{ax + b}\,dx = \frac{A}{a}\ln\lvert ax + b\rvert + C$
- $\displaystyle\int \frac{A}{(ax + b)^k}\,dx = \frac{A}{a(1 - k)(ax + b)^{k - 1}} + C$ ($k \ge 2$)
- $\displaystyle\int \frac{Ax + B}{ax^2 + bx + c}\,dx$: **συμπλήρωση τετραγώνου** (βλ. [[01 - Ολοκλήρωση με Αντικατάσταση|Κεφ. 01 §4]]) → σπάει σε $\ln(ax^2 + bx + c)$ + $\tan^{-1}$.
- $\displaystyle\int \frac{Ax + B}{(ax^2 + bx + c)^2}\,dx$: σπάσε τον αριθμητή ώστε να εμφανιστεί η παράγωγος $(2ax + b)$ (δίνει απλή δύναμη $-\frac{1}{ax^2 + bx + c}$) συν έναν σταθερό όρο $\displaystyle\int \frac{du}{(u^2 + k^2)^2}$, που λύνεται με τριγωνομετρική αντικατάσταση $u = k\tan\theta$:
  $$\int \frac{du}{(u^2 + k^2)^2} = \frac{1}{2k^3}\tan^{-1}\frac{u}{k} + \frac{u}{2k^2(u^2 + k^2)} + C$$

⚠️ *Σημείωση για το Βοήθημα (`Chapter11.pdf`, σελ. 1.43): στην υποσημείωση στο κάτω μέρος της σελίδας γράφει $\int \frac{du}{1 + u^2} = \frac{1}{2}\left[\tan^{-1} u + \frac{u}{1 + u^2}\right] + C$ — τυπογραφικό: λείπει το τετράγωνο στον παρονομαστή, το σωστό είναι $\int \frac{du}{(1 + u^2)^2}$.*

> [!example]- Παράδειγμα 4: μεικτός παρονομαστής $x^2(x^2 + 9)$ (Βοήθημα §1.6, Παρ. 6)
> Υπολόγισε $\displaystyle\int \frac{x + 3}{x^4 + 9x^2}\,dx$.
> Παραγοντοποιούμε $x^4 + 9x^2 = x^2(x^2 + 9)$:
> $$\frac{x + 3}{x^2(x^2 + 9)} = \frac{A}{x} + \frac{B}{x^2} + \frac{Cx + D}{x^2 + 9}$$
> Πολλαπλασιάζουμε με $x^2(x^2 + 9)$:
> $$x + 3 = Ax(x^2 + 9) + B(x^2 + 9) + (Cx + D)x^2 = (A + C)x^3 + (B + D)x^2 + 9Ax + 9B$$
> Εξισώνοντας συντελεστές: $9B = 3 \implies B = \frac{1}{3}$, $9A = 1 \implies A = \frac{1}{9}$, $C = -A = -\frac{1}{9}$, $D = -B = -\frac{1}{3}$.
> $$\begin{aligned}
> \int \frac{x + 3}{x^4 + 9x^2}\,dx &= \int \left(\frac{1/9}{x} + \frac{1/3}{x^2} - \frac{1}{9}\cdot\frac{x}{x^2 + 9} - \frac{1}{3}\cdot\frac{1}{x^2 + 9}\right)dx \\
> &= \frac{1}{9}\ln\lvert x\rvert - \frac{1}{3x} - \frac{1}{18}\ln(x^2 + 9) - \frac{1}{9}\tan^{-1}\frac{x}{3} + C
> \end{aligned}$$

> [!example]- Παράδειγμα 5: επαναλαμβανόμενος ανάγωγος τετραγωνικός (Βοήθημα §1.6, Παρ. 4)
> Υπολόγισε $\displaystyle\int \frac{x^2}{(x^2 + 4)^2}\,dx$.
> Παρατηρούμε αμέσως (ή με μερικά κλάσματα):
> $$\frac{x^2}{(x^2 + 4)^2} = \frac{(x^2 + 4) - 4}{(x^2 + 4)^2} = \frac{1}{x^2 + 4} - \frac{4}{(x^2 + 4)^2}$$
> Για το πρώτο: $\int \frac{dx}{x^2 + 4} = \frac{1}{2}\tan^{-1}\frac{x}{2}$.
> Για το δεύτερο, με $x = 2\tan\theta$ (ή τον τύπο με $k = 2$):
> $$\int \frac{dx}{(x^2 + 4)^2} = \frac{1}{16}\tan^{-1}\frac{x}{2} + \frac{x}{8(x^2 + 4)} + C_1$$
> Συνδυάζοντας:
> $$\int \frac{x^2}{(x^2 + 4)^2}\,dx = \frac{1}{2}\tan^{-1}\frac{x}{2} - 4\left[\frac{1}{16}\tan^{-1}\frac{x}{2} + \frac{x}{8(x^2 + 4)}\right] + C = \frac{1}{4}\tan^{-1}\frac{x}{2} - \frac{x}{2(x^2 + 4)} + C$$

## 5. Ρητοποιητικές αντικαταστάσεις (πριν τα μερικά κλάσματα)

Πολλά μη ρητά ολοκληρώματα (με $e^x$, $\sqrt{x}$, $\sin x, \cos x$) μετατρέπονται σε **ρητές συναρτήσεις** με μια κατάλληλη αντικατάσταση και μετά λύνονται με μερικά κλάσματα!

> [!example]- Παράδειγμα 6: $\displaystyle\int \frac{dx}{1 + e^x}$ (Βοήθημα, άσκ. 20στ)
> Θέτουμε $u = e^x \implies du = e^x\,dx = u\,dx \implies dx = \dfrac{du}{u}$:
> $$\begin{aligned}
> \int \frac{dx}{1 + e^x} &= \int \frac{du}{u(1 + u)} = \int \left(\frac{1}{u} - \frac{1}{1 + u}\right)du \\
> &= \ln\lvert u\rvert - \ln\lvert 1 + u\rvert + C = x - \ln(1 + e^x) + C
> \end{aligned}$$
> *(Γρήγορη εναλλακτική: πολλαπλασίασε αριθμητή και παρονομαστή με $e^{-x}$ → $\int \frac{e^{-x}}{e^{-x} + 1}\,dx = -\ln(1 + e^{-x}) + C$, που είναι ταυτόσημο!)*

> [!example]- Παράδειγμα 7: $\displaystyle\int \frac{\cos\theta}{\sin^2\theta + 4\sin\theta - 5}\,d\theta$ (Βοήθημα, άσκ. 20ε)
> Θέτουμε $u = \sin\theta \implies du = \cos\theta\,d\theta$:
> $$\int \frac{du}{u^2 + 4u - 5} = \int \frac{du}{(u - 1)(u + 5)} = \frac{1}{6}\int \left(\frac{1}{u - 1} - \frac{1}{u + 5}\right)du = \frac{1}{6}\ln\left\lvert\frac{\sin\theta - 1}{\sin\theta + 5}\right\rvert + C$$

## 6. Συχνά Λάθη

> [!warning] Προσοχή
> - **Ξεχνάς τη διαίρεση όταν $\deg P \ge \deg Q$:** η #1 παγίδα των εξετάσεων!
> - **Παραλείπεις τις ενδιάμεσες δυνάμεις** σε επαναλαμβανόμενο παράγοντα: για $(x - 1)^3$ χρειάζεσαι **και** τους τρεις όρους $\frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{C}{(x - 1)^3}$ (όχι μόνο $\frac{A}{(x - 1)^3}$).
> - **Βάζεις σταθερά $A$ αντί για $Ax + B$** πάνω από ανάγωγο τετραγωνικό $x^2 + 4$.
> - **Δεν παραγοντοποιείς πλήρως τον $Q(x)$:** π.χ. το $x^2 - 4 = (x - 2)(x + 2)$ **δεν** είναι ανάγωγο ($\Delta > 0$)· το $x^4 - 1 = (x - 1)(x + 1)(x^2 + 1)$· ακόμα και το $x^4 + 1$ παραγοντοποιείται ως $(x^2 - \sqrt{2}\,x + 1)(x^2 + \sqrt{2}\,x + 1)$ (Βοήθημα, άσκ. 21)!
> - **Χρησιμοποιείς μερικά κλάσματα όταν αρκεί $\frac{u'}{u}$:** π.χ. για $\int \frac{2x + 3}{x^2 + 3x + 2}\,dx$, η παράγωγος του παρονομαστή είναι ήδη στον αριθμητή → $\ln\lvert x^2 + 3x + 2\rvert + C$ κατευθείαν!
