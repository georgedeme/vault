# 03 - Τριγωνομετρικά Ολοκληρώματα και Αντικαταστάσεις

Τέσσερα εργαλεία που συνδέονται στενά: (Α) γινόμενα και δυνάμεις τριγωνομετρικών, (Β) τριγωνομετρικές αντικαταστάσεις για ριζικά $\sqrt{a^2 \pm x^2}, \sqrt{x^2 - a^2}$, (Γ) υπερβολικές αντικαταστάσεις (συχνά πολύ πιο γρήγορες!), και (Δ) η καθολική αντικατάσταση Weierstrass $t = \tan\frac{x}{2}$.

## 1. Μέρος Α — Τριγωνομετρικά ολοκληρώματα

### 1.1 Μορφή $\displaystyle\int \sin^m x\cos^n x\,dx$

| Περίπτωση | Στρατηγική | Ταυτότητα |
|---|---|---|
| **$m$ περιττός** ($m = 2k + 1$) | Κράτα ένα $\sin x\,dx$, θέσε $u = \cos x$ ($du = -\sin x\,dx$) | $\sin^2 x = 1 - \cos^2 x$ |
| **$n$ περιττός** ($n = 2k + 1$) | Κράτα ένα $\cos x\,dx$, θέσε $u = \sin x$ ($du = \cos x\,dx$) | $\cos^2 x = 1 - \sin^2 x$ |
| **$m, n$ και οι δύο άρτιοι** | Υποβιβασμός δύναμης (ή αναγωγικός τύπος) | $\sin^2 x = \dfrac{1 - \cos 2x}{2}$, $\cos^2 x = \dfrac{1 + \cos 2x}{2}$, $\sin x\cos x = \dfrac{1}{2}\sin 2x$ |

> [!tip] Κλασματικοί ή αρνητικοί εκθέτες
> Η μέθοδος «κράτα ένα $\sin x$ ή $\cos x$» δουλεύει **ακόμα κι αν ο άλλος εκθέτης δεν είναι ακέραιος**! Π.χ. στο $\int \sin^3 x\sqrt{\cos x}\,dx$ ο εκθέτης του $\sin x$ είναι περιττός ($3$), οπότε με $u = \cos x$:
> $$\int \sin^3 x\sqrt{\cos x}\,dx = \int (1 - \cos^2 x)\cos^{1/2}x\sin x\,dx = -\int (u^{1/2} - u^{5/2})\,du = -\frac{2}{3}\cos^{3/2}x + \frac{2}{7}\cos^{7/2}x + C$$

> [!example]- Παράδειγμα 1: και οι δύο εκθέτες άρτιοι — $\displaystyle\int \sin^2 x\cos^2 x\,dx$ (Βοήθημα §1.4, Παρ. 4)
> Χρησιμοποιούμε $\sin x\cos x = \frac{1}{2}\sin 2x$:
> $$\begin{aligned}
> \int \sin^2 x\cos^2 x\,dx &= \frac{1}{4}\int \sin^2 2x\,dx = \frac{1}{4}\int \frac{1 - \cos 4x}{2}\,dx \\
> &= \frac{1}{8}x - \frac{1}{32}\sin 4x + C
> \end{aligned}$$

### 1.2 Μορφή $\displaystyle\int \tan^m x\sec^n x\,dx$ (και ανάλογα $\cot^m x\csc^n x$)

Πρώτα θυμόμαστε τα δύο βασικά λογαριθμικά ολοκληρώματα:
$$\int \sec x\,dx = \ln\lvert\sec x + \tan x\rvert + C \qquad\qquad \int \csc x\,dx = -\ln\lvert\csc x + \cot x\rvert + C = \ln\lvert\csc x - \cot x\rvert + C$$
*(Η $\int \sec x\,dx$ βγαίνει πολλαπλασιάζοντας αριθμητή και παρονομαστή με $\sec x + \tan x$.)*

| Περίπτωση | Στρατηγική | Ταυτότητα |
|---|---|---|
| **$n$ άρτιος** ($n \ge 2$) | Κράτα $\sec^2 x\,dx$, θέσε $u = \tan x$ ($du = \sec^2 x\,dx$) | $\sec^2 x = 1 + \tan^2 x$ |
| **$m$ περιττός** ($m \ge 1,\; n \ge 1$) | Κράτα $\sec x\tan x\,dx$, θέσε $u = \sec x$ ($du = \sec x\tan x\,dx$) | $\tan^2 x = \sec^2 x - 1$ |
| **$m$ άρτιος και $n$ περιττός** | Μετάτρεψε τα $\tan^2 x$ σε $\sec^2 x - 1$ → δυνάμεις της $\sec x$ → παραγοντική / αναγωγικός τύπος | $\tan^2 x = \sec^2 x - 1$ |

*(Για $\int \cot^m x\csc^n x\,dx$ ισχύει ακριβώς το ίδιο με $\csc^2 x = 1 + \cot^2 x$ και μείον στα διαφορικά.)*

> [!example]- Παράδειγμα 2: $\int \tan^5 x\sec^5 x\,dx$ και $\int \tan^2 x\sec x\,dx$ (Βοήθημα §1.4, Παρ. 7 & 9)
> **(α)** $m = 5$ περιττός ⇒ $u = \sec x,\; du = \sec x\tan x\,dx$:
> $$\begin{aligned}
> \int \tan^5 x\sec^5 x\,dx &= \int (\sec^2 x - 1)^2\sec^4 x\,(\sec x\tan x\,dx) \\
> &= \int (u^8 - 2u^6 + u^4)\,du = \frac{1}{9}\sec^9 x - \frac{2}{7}\sec^7 x + \frac{1}{5}\sec^5 x + C
> \end{aligned}$$
>
> **(β)** $m = 2$ άρτιος, $n = 1$ περιττός ⇒ μετατρέπουμε σε $\sec x$:
> $$\int \tan^2 x\sec x\,dx = \int (\sec^2 x - 1)\sec x\,dx = \int \sec^3 x\,dx - \int \sec x\,dx$$
> Από το [[02 - Ολοκλήρωση κατά Παράγοντες|Κεφ. 02]] ($\int \sec^3 x\,dx = \frac{1}{2}\sec x\tan x + \frac{1}{2}\ln\lvert\sec x + \tan x\rvert$):
> $$\int \tan^2 x\sec x\,dx = \frac{1}{2}\sec x\tan x - \frac{1}{2}\ln\lvert\sec x + \tan x\rvert + C$$

### 1.3 Γινόμενα με διαφορετικές συχνότητες: $\sin(mx)\cos(nx)$, $\sin(mx)\sin(nx)$, $\cos(mx)\cos(nx)$

Χρησιμοποιούμε τις ταυτότητες **γινομένου σε άθροισμα**:
$$\begin{aligned}
\sin A\cos B &= \frac{1}{2}\big[\sin(A - B) + \sin(A + B)\big] \\
\sin A\sin B &= \frac{1}{2}\big[\cos(A - B) - \cos(A + B)\big] \\
\cos A\cos B &= \frac{1}{2}\big[\cos(A - B) + \cos(A + B)\big]
\end{aligned}$$

> [!example]- Παράδειγμα 3: $\displaystyle\int \sin(3x)\cos(5x)\,dx$
> $$\begin{aligned}
> \int \sin(3x)\cos(5x)\,dx &= \frac{1}{2}\int \big[\sin(-2x) + \sin(8x)\big]\,dx = \frac{1}{2}\int \big[-\sin(2x) + \sin(8x)\big]\,dx \\
> &= \frac{1}{4}\cos(2x) - \frac{1}{16}\cos(8x) + C
> \end{aligned}$$

## 2. Μέρος Β — Τριγωνομετρικές αντικαταστάσεις

Όταν το ολοκλήρωμα περιέχει ριζικό (ή κλασματική δύναμη) της μορφής $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$ ή $\sqrt{x^2 - a^2}$ ($a > 0$), η κατάλληλη τριγωνομετρική αντικατάσταση εξαφανίζει τη ρίζα μέσω των Πυθαγόρειων ταυτοτήτων.

| Παράσταση | Αντικατάσταση | Περιορισμός $\theta$ | Ταυτότητα & Ριζικό |
|---|---|---|---|
| $\sqrt{a^2 - x^2}$ | $x = a\sin\theta$,\; $dx = a\cos\theta\,d\theta$ | $-\dfrac{\pi}{2} \le \theta \le \dfrac{\pi}{2}$ | $\sqrt{a^2\cos^2\theta} = a\cos\theta$ (αφού $\cos\theta \ge 0$) |
| $\sqrt{a^2 + x^2}$ | $x = a\tan\theta$,\; $dx = a\sec^2\theta\,d\theta$ | $-\dfrac{\pi}{2} < \theta < \dfrac{\pi}{2}$ | $\sqrt{a^2\sec^2\theta} = a\sec\theta$ (αφού $\sec\theta > 0$) |
| $\sqrt{x^2 - a^2}$ | $x = a\sec\theta$,\; $dx = a\sec\theta\tan\theta\,d\theta$ | $0 \le \theta < \dfrac{\pi}{2}$ ($x \ge a$)<br>$\pi \le \theta < \dfrac{3\pi}{2}$ ($x \le -a$) | $\sqrt{a^2\tan^2\theta} = a\tan\theta$ (αφού $\tan\theta \ge 0$) |

*(Αν το ριζικό βρίσκεται στον παρονομαστή, οι ανισότητες γίνονται αυστηρές ώστε να μη μηδενίζεται.)*

![[c7-03-trigsub.png|800]]
*Τα τρία ορθογώνια τρίγωνα αναφοράς για την επιστροφή από τη γωνία $\theta$ στη μεταβλητή $x$ στις τριγωνομετρικές αντικαταστάσεις.*

> [!warning] Παγίδα 🪤 — Το πρόσημο $\lvert\tan\theta\rvert$ όταν $x < -a$!
> Προσοχή στον περιορισμό της $x = a\sec\theta$:
> - Για $x \ge a$, επιλέγουμε $\theta \in [0, \frac{\pi}{2})$ (Α' τεταρτημόριο), όπου $\tan\theta \ge 0$.
> - Για $x \le -a$, αν επιλέξουμε $\theta \in [\pi, \frac{3\pi}{2})$ (Γ' τεταρτημόριο, όπως στο Βοήθημα), τότε πάλι $\tan\theta \ge 0$, άρα $\sqrt{a^2\tan^2\theta} = a\tan\theta$.
> - **Αν όμως** επιλέξεις $\theta \in (\frac{\pi}{2}, \pi]$ (Β' τεταρτημόριο, όπως η συνήθης $\sec^{-1}$), τότε $\tan\theta \le 0$, οπότε $\sqrt{a^2\tan^2\theta} = a\lvert\tan\theta\rvert = \boldsymbol{-}a\tan\theta$!
> Σε ορισμένα ολοκληρώματα με $x < -a$ (π.χ. $\int_{-4}^{-2}\frac{\sqrt{x^2 - 4}}{x}\,dx$), ένα χαμένο πρόσημο αλλάζει ολόκληρη την απάντηση!

> [!tip] Πώς γυρίζεις πίσω στο $x$
> 1. Σχεδίασε το **ορθογώνιο τρίγωνο** από την αρχική σχέση (π.χ. $\sin\theta = \frac{x}{a} = \frac{\text{απέναντι}}{\text{υποτείνουσα}}$).
> 2. Βρες την τρίτη πλευρά με Πυθαγόρειο θεώρημα (είναι πάντα το αρχικό ριζικό!).
> 3. Διάβασε όποιον τριγωνομετρικό αριθμό χρειάζεσαι. Για διπλές γωνίες ($\sin 2\theta, \cos 2\theta$) χρησιμοποίησε **πρώτα** τις ταυτότητες $\sin 2\theta = 2\sin\theta\cos\theta$ και $\cos 2\theta = 1 - 2\sin^2\theta$.

> [!example]- Παράδειγμα 4: $\displaystyle\int \frac{x^2}{\sqrt{9 - x^2}}\,dx$ (Βοήθημα §1.5, Παρ. 1)
> Θέτουμε $x = 3\sin\theta$ ($-\frac{\pi}{2} < \theta < \frac{\pi}{2}$), $dx = 3\cos\theta\,d\theta$, $\sqrt{9 - x^2} = 3\cos\theta$:
> $$\begin{aligned}
> \int \frac{x^2}{\sqrt{9 - x^2}}\,dx &= \int \frac{9\sin^2\theta}{3\cos\theta}\cdot 3\cos\theta\,d\theta = 9\int \sin^2\theta\,d\theta \\
> &= \frac{9}{2}\int (1 - \cos 2\theta)\,d\theta = \frac{9}{2}\theta - \frac{9}{4}\sin 2\theta + C \\
> &= \frac{9}{2}\theta - \frac{9}{2}\sin\theta\cos\theta + C
> \end{aligned}$$
> Από το τρίγωνο ($\sin\theta = \frac{x}{3}$, $\cos\theta = \frac{\sqrt{9 - x^2}}{3}$):
> $$\int \frac{x^2}{\sqrt{9 - x^2}}\,dx = \frac{9}{2}\sin^{-1}\frac{x}{3} - \frac{1}{2}x\sqrt{9 - x^2} + C$$

> [!example]- Παράδειγμα 5: συνδυασμός με συμπλήρωση τετραγώνου (Βοήθημα §1.5, Παρ. 7)
> Υπολόγισε $\displaystyle\int \frac{dx}{(x^2 + 8x + 25)^{3/2}}$.
> Συμπλήρωση τετραγώνου: $x^2 + 8x + 25 = (x + 4)^2 + 9$.
> Θέτουμε $x + 4 = 3\tan\theta \implies dx = 3\sec^2\theta\,d\theta$ και $\big[(x + 4)^2 + 9\big]^{3/2} = (9\sec^2\theta)^{3/2} = 27\sec^3\theta$:
> $$\int \frac{dx}{\big[(x + 4)^2 + 9\big]^{3/2}} = \int \frac{3\sec^2\theta\,d\theta}{27\sec^3\theta} = \frac{1}{9}\int \cos\theta\,d\theta = \frac{1}{9}\sin\theta + C$$
> Από το τρίγωνο με $\tan\theta = \frac{x + 4}{3}$ έχουμε υποτείνουσα $\sqrt{(x + 4)^2 + 9} = \sqrt{x^2 + 8x + 25}$, άρα:
> $$\int \frac{dx}{(x^2 + 8x + 25)^{3/2}} = \frac{x + 4}{9\sqrt{x^2 + 8x + 25}} + C$$

## 3. Μέρος Γ — Υπερβολικές αντικαταστάσεις

Για τα ίδια τρία ριζικά μπορούμε να χρησιμοποιήσουμε **υπερβολικές** αντικαταστάσεις, βασισμένες στις ταυτότητες $\cosh^2 t - \sinh^2 t = 1$ και $1 - \tanh^2 t = \operatorname{sech}^2 t$.

| Παράσταση | Υπερβολική αντικατάσταση | Περιορισμός $t$ | Ταυτότητα & Ριζικό |
|---|---|---|---|
| $\sqrt{a^2 + x^2}$ | $x = a\sinh t$,\; $dx = a\cosh t\,dt$ | $t \in \mathbb{R}$ | $\sqrt{a^2\cosh^2 t} = a\cosh t$ (πάντα $> 0$!) |
| $\sqrt{x^2 - a^2}$ | $x = a\cosh t$,\; $dx = a\sinh t\,dt$ | $t \ge 0$ ($x \ge a$) | $\sqrt{a^2\sinh^2 t} = a\sinh t$ (αφού $\sinh t \ge 0$) |
| $\sqrt{a^2 - x^2}$ | $x = a\tanh t$,\; $dx = a\operatorname{sech}^2 t\,dt$ | $t \in \mathbb{R}$ ($\lvert x\rvert < a$) | $\sqrt{a^2\operatorname{sech}^2 t} = a\operatorname{sech} t$ (πάντα $> 0$!) |

> [!tip] Γιατί οι υπερβολικές αντικαταστάσεις είναι συχνά ΠΟΛΥ πιο γρήγορες!
> - Στο $\displaystyle\int \frac{dx}{\sqrt{x^2 + a^2}}$: η τριγωνομετρική $x = a\tan\theta$ οδηγεί στο $\int \sec\theta\,d\theta$, ενώ η υπερβολική $x = a\sinh t$ δίνει **κατευθείαν** $\int dt = t + C = \sinh^{-1}\frac{x}{a} + C = \ln\!\left(x + \sqrt{x^2 + a^2}\right) + C'$!
> - Στο $\displaystyle\int \sqrt{x^2 + a^2}\,dx$ ή $\displaystyle\int \sqrt{x^2 - a^2}\,dx$: η τριγωνομετρική οδηγεί στο $\int \sec^3\theta\,d\theta$, ενώ η υπερβολική οδηγεί στο πανεύκολο $\int \cosh^2 t\,dt$ ή $\int \sinh^2 t\,dt$ (με $\cosh^2 t = \frac{\cosh 2t + 1}{2}$, $\sinh^2 t = \frac{\cosh 2t - 1}{2}$)!
> - Επιπλέον, η $\cosh t > 0$ για **κάθε** $t \in \mathbb{R}$, οπότε δεν ανησυχείς ποτέ για απόλυτες τιμές στη $\sqrt{x^2 + a^2}$.

⚠️ *Σημείωση για το Βοήθημα (`Chapter11.pdf`, σελ. 1.33–1.34): στη σελ. 1.33 γράφει $x = \cosh u$ (εννοεί $x = a\cosh u$) και $a^2 - a^2\tanh^2 u = \operatorname{sech}^2 u$ (λείπει το $a^2$ δεξιά: σωστό $a^2\operatorname{sech}^2 u$). Στη σελ. 1.34 γράφει $a^2\cosh^2\theta - a^2 = \sinh^2\theta$ (σωστό $a^2\sinh^2\theta$).*

> [!example]- Παράδειγμα 6: $\displaystyle\int \sqrt{x^2 - 1}\,dx$ ($x \ge 1$) με υπερβολική αντικατάσταση (Βοήθημα, άσκ. 18γ)
> Θέτουμε $x = \cosh t$ ($t \ge 0$), $dx = \sinh t\,dt$, $\sqrt{x^2 - 1} = \sinh t$:
> $$\begin{aligned}
> \int \sqrt{x^2 - 1}\,dx &= \int \sinh^2 t\,dt = \frac{1}{2}\int (\cosh 2t - 1)\,dt = \frac{1}{4}\sinh 2t - \frac{1}{2}t + C \\
> &= \frac{1}{2}\sinh t\cosh t - \frac{1}{2}t + C \\
> &= \frac{1}{2}x\sqrt{x^2 - 1} - \frac{1}{2}\cosh^{-1} x + C
> \end{aligned}$$
> *(Θυμήσου: $\cosh^{-1} x = \ln\!\left(x + \sqrt{x^2 - 1}\right)$ για $x \ge 1$ — ταυτίζεται πλήρως με το αποτέλεσμα της τριγωνομετρικής αντικατάστασης $x = \sec\theta$, αλλά σε 3 γραμμές!)*

> [!example]- Παράδειγμα 7: $\displaystyle\int \frac{dx}{x^2\sqrt{9 + x^2}}$ με υπερβολική αντικατάσταση (Βοήθημα §1.5, Παρ. 5)
> Θέτουμε $x = 3\sinh t \implies dx = 3\cosh t\,dt$ και $\sqrt{9 + x^2} = 3\cosh t$:
> $$\int \frac{dx}{x^2\sqrt{9 + x^2}} = \int \frac{3\cosh t\,dt}{9\sinh^2 t\cdot 3\cosh t} = \frac{1}{9}\int \operatorname{csch}^2 t\,dt = -\frac{1}{9}\coth t + C$$
> Αφού $\sinh t = \frac{x}{3}$ και $\cosh t = \sqrt{1 + \sinh^2 t} = \frac{\sqrt{9 + x^2}}{3}$, έχουμε $\coth t = \frac{\cosh t}{\sinh t} = \frac{\sqrt{9 + x^2}}{x}$, άρα:
> $$\int \frac{dx}{x^2\sqrt{9 + x^2}} = -\frac{\sqrt{9 + x^2}}{9x} + C$$

## 4. Μέρος Δ — Καθολική αντικατάσταση Weierstrass ($t = \tan\frac{x}{2}$)

Κάθε **ρητή συνάρτηση** των $\sin x$ και $\cos x$ — όπως $\dfrac{1}{2 + \sin x}$ ή $\dfrac{1}{a\sin x + b\cos x + c}$ — μετατρέπεται σε ρητή συνάρτηση του $t$ (που λύνεται με μερικά κλάσματα) μέσω της αντικατάστασης:

> [!important] Αντικατάσταση Weierstrass (εφαπτομένη μισής γωνίας)
> Θέτουμε $t = \tan\dfrac{x}{2}$ για $-\pi < x < \pi$. Τότε:
> $$\sin x = \frac{2t}{1 + t^2}, \qquad \cos x = \frac{1 - t^2}{1 + t^2}, \qquad \tan x = \frac{2t}{1 - t^2}, \qquad dx = \frac{2\,dt}{1 + t^2}$$

> [!info]- Απόδειξη σε 3 γραμμές
> Από $t = \tan\frac{x}{2}$ έχουμε $x = 2\tan^{-1} t \implies dx = \dfrac{2\,dt}{1 + t^2}$.
> Επίσης $\cos^2\frac{x}{2} = \dfrac{1}{1 + \tan^2\frac{x}{2}} = \dfrac{1}{1 + t^2}$, οπότε:
> $$\sin x = 2\sin\frac{x}{2}\cos\frac{x}{2} = 2\tan\frac{x}{2}\cos^2\frac{x}{2} = \frac{2t}{1 + t^2}, \qquad \cos x = 2\cos^2\frac{x}{2} - 1 = \frac{2}{1 + t^2} - 1 = \frac{1 - t^2}{1 + t^2}$$

> [!example]- Παράδειγμα 8: $\displaystyle\int \frac{dx}{2 + 2\sin x + \cos x}$ (Βοήθημα §1.7, Παρ. 1)
> Με $t = \tan\frac{x}{2}$:
> $$\begin{aligned}
> \int \frac{dx}{2 + 2\sin x + \cos x} &= \int \frac{\frac{2\,dt}{1 + t^2}}{2 + \frac{4t}{1 + t^2} + \frac{1 - t^2}{1 + t^2}} = \int \frac{2\,dt}{2(1 + t^2) + 4t + (1 - t^2)} \\
> &= \int \frac{2\,dt}{t^2 + 4t + 3} = \int \frac{2\,dt}{(t + 1)(t + 3)} = \int \left(\frac{1}{t + 1} - \frac{1}{t + 3}\right)dt \\
> &= \ln\left\lvert\frac{t + 1}{t + 3}\right\rvert + C = \ln\left\lvert\frac{1 + \tan\frac{x}{2}}{3 + \tan\frac{x}{2}}\right\rvert + C
> \end{aligned}$$

> [!warning] Παγίδα 🪤 — Ορισμένα ολοκληρώματα που διασχίζουν το $x = \pi$!
> Η αντικατάσταση $t = \tan\frac{x}{2}$ έχει **κατακόρυφη ασύμπτωτη** στο $x = \pi$ (εκεί $\tan\frac{x}{2} \to \pm\infty$).
> Αν υπολογίσεις το $\displaystyle\int_0^{2\pi} \frac{dx}{2 + \cos x}$ βάζοντας τυφλά $t(0) = 0$ και $t(2\pi) = 0$, θα βγάλεις **$0$** — ενώ η υπό ολοκλήρωση συνάρτηση είναι αυστηρά θετική!
> **Σωστός τρόπος:** χρησιμοποίησε τη συμμετρία $\int_0^{2\pi} \frac{dx}{2 + \cos x} = 2\int_0^{\pi} \frac{dx}{2 + \cos x}$, όπου $t \in [0, +\infty)$:
> $$2\int_0^{+\infty} \frac{\frac{2\,dt}{1 + t^2}}{2 + \frac{1 - t^2}{1 + t^2}} = 4\int_0^{+\infty} \frac{dt}{3 + t^2} = \frac{4}{\sqrt{3}}\left[\tan^{-1}\frac{t}{\sqrt{3}}\right]_0^{+\infty} = \frac{4}{\sqrt{3}}\cdot\frac{\pi}{2} = \frac{2\pi}{\sqrt{3}}$$

## 5. Συχνά Λάθη

> [!warning] Προσοχή
> - **Ξεχνάς το $dx$ στην τριγωνομετρική/υπερβολική αντικατάσταση:** π.χ. αντικαθιστάς $x = 3\sin\theta$ αλλά ξεχνάς το $3\cos\theta\,d\theta$.
> - **Κάνεις τριγωνομετρική αντικατάσταση εκεί που αρκεί απλή $u$-αντικατάσταση:** π.χ. για $\int \frac{x}{\sqrt{9 - x^2}}\,dx$ ή $\int \frac{x}{x^2 + 4}\,dx$ (Βοήθημα, άσκ. 17), η $u = 9 - x^2$ (ή $u = x^2 + 4$) τελειώνει σε 2 δευτερόλεπτα!
> - **Αφήνεις $\sin(2\theta)$ στο αποτέλεσμα χωρίς να το μετατρέψεις σε $x$:** γράψε πρώτα $\sin(2\theta) = 2\sin\theta\cos\theta$ και μετά διάβασε από το τρίγωνο.
> - **Αγνοείς το πρόσημο της $\sqrt{\tan^2\theta} = \lvert\tan\theta\rvert$** όταν $x < -a$.
> - **Ξεχνάς να ελέγξεις ασυνέχεια στο $x = \pi$** όταν χρησιμοποιείς $t = \tan\frac{x}{2}$ σε ορισμένο ολοκλήρωμα.
