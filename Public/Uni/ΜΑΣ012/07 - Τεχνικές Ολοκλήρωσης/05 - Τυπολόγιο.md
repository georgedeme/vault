# 05 - Τυπολόγιο

Το Κεφάλαιο 7 σε μία σελίδα — με **οδηγό στρατηγικής** για να διαλέγεις γρήγορα την κατάλληλη τεχνική.

## 1. Οδηγός Στρατηγικής — «Ποια τεχνική διαλέγω;»

Ακολούθησε τα βήματα με αυτή τη σειρά:

> [!tip] Τα 3 πρώτα δευτερόλεπτα
> 1. **Απλοποίησε** πρώτα αλγεβρικά/τριγωνομετρικά (σπάσε κλάσματα, νόμοι δυνάμεων/λογαρίθμων, ταυτότητες).
> 2. **Έλεγξε για άμεση $u$-αντικατάσταση** (φαίνεται η παράγωγος μιας εσωτερικής έκφρασης;).
> 3. **Αναγνώρισε τη μορφή** από τον παρακάτω πίνακα.

| Τι βλέπεις στο ολοκλήρωμα | Πρώτη επιλογή | Εναλλακτική / Προσοχή 🪤 |
|---|---|---|
| $f(g(x))\,g'(x)$ ή $\dfrac{g'(x)}{g(x)}$ | **Άμεση $u$-αντικατάσταση** ($u = g(x)$) | Σε ορισμένο: άλλαξε τα όρια (μην τα αλλάξεις διπλά!) |
| $\sqrt[n]{ax + b}$ ή πολλαπλές ρίζες $\sqrt{x}, \sqrt[3]{x}$ | **Ριζική αντικατάσταση** $u = (ax + b)^{1/n}$ ή $u = x^{1/\text{ΕΚΠ}}$ | Μετατρέπει σε πολυώνυμο ή ρητή |
| $\dfrac{Ax + B}{ax^2 + bx + c}$ (με $\Delta < 0$) ή $\dfrac{Ax + B}{\sqrt{ax^2 + bx + c}}$ | **Συμπλήρωση τετραγώνου** → σπάσιμο σε $\ln/\sqrt{\cdot}$ + $\tan^{-1}/\sin^{-1}$ | 🪤 Προσοχή στο πρόσημο όταν $-x^2$ |
| $\int_0^\pi x\,f(\sin x)\,dx$ ή συμμετρικό στο $[0, \frac{\pi}{2}]$ | **Ιδιότητα του Βασιλιά** $u = a + b - x$ | $\int_0^\pi x f(\sin x)\,dx = \frac{\pi}{2}\int_0^\pi f(\sin x)\,dx$ |
| Γινόμενο ανόμοιων (π.χ. $x^n e^x$, $x^n\sin x$, $x^n\ln x$, $e^{ax}\cos bx$) | **Κατά παράγοντες** ($\int u\,dv = uv - \int v\,du$) + **LIATE** | Πίνακας $D$-$I$ για $P(x)\cdot g(x)$ · 🪤 $x^3 e^{x^2}$: πρώτα $w = x^2$ |
| Μόνο $\ln x$, $\tan^{-1} x$, $\sin^{-1} x$, $(\ln x)^n$ | **Κατά παράγοντες με «κρυμμένο $1$»** ($dv = dx$) | $\int \ln x\,dx = x\ln x - x + C$ |
| $\sin^m x\cos^n x$ | Περιττός εκθέτης → κράτα έναν παράγοντα · και οι δύο άρτιοι → $\sin^2 = \frac{1 - \cos 2x}{2}$ | Ή αναγωγικός τύπος / Wallis στο $[0, \frac{\pi}{2}]$ |
| $\tan^m x\sec^n x$ | $n$ άρτιος → $u = \tan x$ · $m$ περιττός → $u = \sec x$ · $m$ άρτιος, $n$ περιττός → $\sec^k x$ | $\int \sec^3 x\,dx$ = κυκλική παραγοντική |
| $\sin(mx)\cos(nx)$ κ.λπ. | **Γινόμενο σε άθροισμα** | |
| $\sqrt{a^2 - x^2}$ | $x = a\sin\theta$ ($-\frac{\pi}{2} \le \theta \le \frac{\pi}{2}$) | Ή $x = a\tanh t$ · 🪤 αν υπάρχει $x\,dx$, απλή $u$-αντικατάσταση! |
| $\sqrt{a^2 + x^2}$ | $x = a\sinh t$ (γρήγορο!) ή $x = a\tan\theta$ ($-\frac{\pi}{2} < \theta < \frac{\pi}{2}$) | $\cosh t > 0$ πάντα (χωρίς απόλυτες τιμές) |
| $\sqrt{x^2 - a^2}$ | $x = a\cosh t$ ($t \ge 0$) ή $x = a\sec\theta$ | 🪤 Για $x < -a$: $\theta \in [\pi, \frac{3\pi}{2})$ ώστε $\tan\theta \ge 0$ |
| Ρητή των $\sin x, \cos x$ (π.χ. $\dfrac{1}{2 + \sin x}$) | **Weierstrass** $t = \tan\frac{x}{2}$ | 🪤 Ασύμπτωτη στο $x = \pi$ σε ορισμένο! |
| Ρητή $\dfrac{P(x)}{Q(x)}$ | **1) Διαίρεση αν $\deg P \ge \deg Q$** · **2) Μερικά κλάσματα** | Heaviside για απλές ρίζες + προσδιοριστέοι συντελεστές |

## 2. Βασικά & χρήσιμα ολοκληρώματα ($a > 0$)

| Ολοκλήρωμα | Αποτέλεσμα | Ολοκλήρωμα | Αποτέλεσμα |
|---|---|---|---|
| $\displaystyle\int \tan x\,dx$ | $-\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C$ | $\displaystyle\int \cot x\,dx$ | $\ln\lvert\sin x\rvert + C$ |
| $\displaystyle\int \sec x\,dx$ | $\ln\lvert\sec x + \tan x\rvert + C$ | $\displaystyle\int \csc x\,dx$ | $-\ln\lvert\csc x + \cot x\rvert + C$ |
| $\displaystyle\int \ln x\,dx$ | $x\ln x - x + C$ | $\displaystyle\int \sec^3 x\,dx$ | $\dfrac{1}{2}\sec x\tan x + \dfrac{1}{2}\ln\lvert\sec x + \tan x\rvert + C$ |
| $\displaystyle\int \frac{dx}{x^2 + a^2}$ | $\dfrac{1}{a}\tan^{-1}\dfrac{x}{a} + C$ | $\displaystyle\int \frac{dx}{x^2 - a^2}$ | $\dfrac{1}{2a}\ln\left\lvert\dfrac{x - a}{x + a}\right\rvert + C$ |
| $\displaystyle\int \frac{dx}{\sqrt{a^2 - x^2}}$ | $\sin^{-1}\dfrac{x}{a} + C$ | $\displaystyle\int \frac{dx}{x\sqrt{x^2 - a^2}}$ | $\dfrac{1}{a}\sec^{-1}\dfrac{\lvert x\rvert}{a} + C$ |
| $\displaystyle\int \frac{dx}{\sqrt{x^2 + a^2}}$ | $\sinh^{-1}\dfrac{x}{a} + C = \ln\!\left(x + \sqrt{x^2 + a^2}\right) + C'$ | $\displaystyle\int \frac{dx}{\sqrt{x^2 - a^2}}$ | $\ln\left\lvert x + \sqrt{x^2 - a^2}\right\rvert + C$ |
| $\displaystyle\int e^{ax}\cos(bx)\,dx$ | $\dfrac{e^{ax}}{a^2 + b^2}(a\cos bx + b\sin bx) + C$ | $\displaystyle\int e^{ax}\sin(bx)\,dx$ | $\dfrac{e^{ax}}{a^2 + b^2}(a\sin bx - b\cos bx) + C$ |
| $\displaystyle\int \frac{du}{(u^2 + a^2)^2}$ | $\dfrac{1}{2a^3}\tan^{-1}\dfrac{u}{a} + \dfrac{u}{2a^2(u^2 + a^2)} + C$ | $\displaystyle\int \sqrt{a^2 - x^2}\,dx$ | $\dfrac{1}{2}x\sqrt{a^2 - x^2} + \dfrac{a^2}{2}\sin^{-1}\dfrac{x}{a} + C$ |

## 3. Αναγωγικοί τύποι & Wallis

- $\displaystyle\int \sin^n x\,dx = -\frac{1}{n}\sin^{n-1}x\cos x + \frac{n - 1}{n}\int \sin^{n-2}x\,dx$
- $\displaystyle\int \cos^n x\,dx = \frac{1}{n}\cos^{n-1}x\sin x + \frac{n - 1}{n}\int \cos^{n-2}x\,dx$
- $\displaystyle\int \tan^n x\,dx = \frac{\tan^{n-1}x}{n - 1} - \int \tan^{n-2}x\,dx$ ($n \ge 2$)
- $\displaystyle\int \sec^n x\,dx = \frac{1}{n - 1}\sec^{n-2}x\tan x + \frac{n - 2}{n - 1}\int \sec^{n-2}x\,dx$ ($n \ge 2$)
- $\displaystyle\int x^n e^x\,dx = x^n e^x - n\int x^{n-1}e^x\,dx$ · $\displaystyle\int (\ln x)^n\,dx = x(\ln x)^n - n\int (\ln x)^{n-1}\,dx$
- **Wallis** ($\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx$): άρτιος $n \ge 2 \Rightarrow \dfrac{1\cdot 3\cdots(n - 1)}{2\cdot 4\cdots n}\cdot\dfrac{\pi}{2}$ · περιττός $n \ge 3 \Rightarrow \dfrac{2\cdot 4\cdots(n - 1)}{3\cdot 5\cdots n}$

## 4. Τριγωνομετρικές, υπερβολικές & Weierstrass ταυτότητες

- **Υποβιβασμός:** $\sin^2 x = \dfrac{1 - \cos 2x}{2}$ · $\cos^2 x = \dfrac{1 + \cos 2x}{2}$ · $\sinh^2 t = \dfrac{\cosh 2t - 1}{2}$ · $\cosh^2 t = \dfrac{\cosh 2t + 1}{2}$
- **Γινόμενο σε άθροισμα:**
  $\sin A\cos B = \frac{1}{2}[\sin(A - B) + \sin(A + B)]$ · $\sin A\sin B = \frac{1}{2}[\cos(A - B) - \cos(A + B)]$ · $\cos A\cos B = \frac{1}{2}[\cos(A - B) + \cos(A + B)]$
- **Weierstrass** ($t = \tan\frac{x}{2}$, $-\pi < x < \pi$): $\sin x = \dfrac{2t}{1 + t^2}$ · $\cos x = \dfrac{1 - t^2}{1 + t^2}$ · $\tan x = \dfrac{2t}{1 - t^2}$ · $dx = \dfrac{2\,dt}{1 + t^2}$
