# 08 - Τυπολόγιο

Το Κεφάλαιο 5 σε μία σελίδα.

## 1. Σχετικοί ρυθμοί & Γραμμική προσέγγιση

- **Σχετικοί ρυθμοί:** $F(x(t), y(t)) = 0 \xrightarrow{\frac{d}{dt}} \text{σχέση με } \frac{dx}{dt}, \frac{dy}{dt}$ · αύξηση: $> 0$, μείωση: $< 0$ · 🪤 **αντικατάσταση στιγμιαίων τιμών ΜΟΝΟ ΜΕΤΑ την παραγώγιση**
- **Γραμμικοποίηση στο $a$:** $L(x) = f(a) + f'(a)(x - a)$ · $f'' > 0 \Rightarrow L(x) < f(x)$ (υποεκτίμηση) · $f'' < 0 \Rightarrow L(x) > f(x)$ (υπερεκτίμηση)
- **Διαφορικό:** $dy = f'(x)\,dx \approx \Delta y = f(x + \Delta x) - f(x)$
- **Σφάλματα:** απόλυτο $|dy|$ · σχετικό $\dfrac{|dy|}{|y|}$ · ποσοστιαίο $\dfrac{|dy|}{|y|}\cdot 100\%$ · για $y = cx^k$: $\dfrac{dy}{y} = k\dfrac{dx}{x}$
- **Κλασικές προσεγγίσεις ($x \approx 0$):** $\sin x \approx x$, $\tan x \approx x$, $e^x \approx 1 + x$, $\ln(1 + x) \approx x$, $(1 + x)^k \approx 1 + kx$

## 2. Κανόνες L'Hôpital

$$\lim_{x\to a}\frac{f(x)}{g(x)} \overset{\text{L'H}}{=} \lim_{x\to a}\frac{f'(x)}{g'(x)} \qquad \text{(μόνο για }\frac00\text{ ή }\frac\infty\infty\text{, αν το δεξί όριο υπάρχει)}$$

| Μορφή | Μετατροπή |
|---|---|
| $0\cdot\infty$ | $f\cdot g = \dfrac{f}{1/g}$ (κατέβασε την απλούστερη) |
| $\infty - \infty$ | Ομώνυμα, κοινός παράγοντας ή συζυγής |
| $0^0,\; 1^\infty,\; \infty^0$ | $\ln y = g\ln f \to L \implies y \to e^L$ |

- **Ιεραρχία στο $+\infty$:** $\ln x \ll x^p \ll a^x$ ($p > 0, a > 1$)
- 🪤 Έλεγχε $\frac00$ ή $\frac\infty\infty$ **πριν από ΚΑΘΕ εφαρμογή** · όχι κανόνας πηλίκου · αν $\lim\frac{f'}{g'}$ δεν υπάρχει, το αρχικό όριο μπορεί να υπάρχει ($\frac{x + \sin x}{x}$)

## 3. Rolle & Θεώρημα Μέσης Τιμής

- **Rolle:** $f$ συνεχής στο $[a, b]$, παραγωγίσιμη στο $(a, b)$, $f(a) = f(b) \implies \exists c \in (a, b): f'(c) = 0$
- **Θ.Μ.Τ. (Lagrange):** $f$ συνεχής στο $[a, b]$, παραγωγίσιμη στο $(a, b) \implies \exists c \in (a, b): f'(c) = \dfrac{f(b) - f(a)}{b - a}$
- **Cauchy:** $[f(b) - f(a)]g'(c) = [g(b) - g(a)]f'(c)$
- **Πορίσματα (σε διάστημα!):** $f' = 0 \Rightarrow f = c$ · $f' = g' \Rightarrow f - g = c$ · $f' > 0 \Rightarrow f \nearrow$ · $f' < 0 \Rightarrow f \searrow$

## 4. Μονοτονία, Κυρτότητα, Ακρότατα, Ασύμπτωτες & Newton

- **Κρίσιμα σημεία:** $x_0 \in D_f$ με $f'(x_0) = 0$ (στάσιμο) **ή** $\nexists f'(x_0)$
- **1η παράγωγος:** $+$ σε $-$ ⇒ τοπ. μέγιστο · $-$ σε $+$ ⇒ τοπ. ελάχιστο · ίδιο πρόσημο ⇒ κανένα
- **2η παράγωγος (μόνο για $f'(x_0) = 0$):** $f''(x_0) > 0$ ⇒ τοπ. ελάχιστο · $f''(x_0) < 0$ ⇒ τοπ. μέγιστο · $f''(x_0) = 0$ ⇒ **αμφίβολο** ($x^4, -x^4, x^3$)
- **Κυρτότητα & Σ.Κ.:** $f'' > 0 \Rightarrow \cup$ · $f'' < 0 \Rightarrow \cap$ · Σ.Κ.: $x_0 \in D_f$ όπου η $f''$ **αλλάζει πρόσημο** ($f'' = 0$ ή $\nexists f''$)
- **Απόλυτα ακρότατα:** σε $[a, b]$ ⇒ σύγκρινε κρίσιμα στο $(a, b)$ + άκρα $f(a), f(b)$ · σε ανοιχτό/άπειρο ⇒ έλεγξε όρια στα άκρα
- **Ασύμπτωτες:** κατακόρυφη $x = x_0$ ($\lim_{x\to x_0^\pm} = \pm\infty$) · οριζόντια $y = y_0$ ($\lim_{x\to\pm\infty} = y_0$) · πλάγια $y = ax + b$: $a = \lim\frac{f(x)}{x} \ne 0$, $b = \lim(f(x) - ax)$
- **Μέθοδος Newton ($f(x) = 0$):** $x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)}$ · αποτυγχάνει αν $f'(x_n) = 0$, σε κύκλο, ή απόκλιση

| Γραμμική προσέγγιση $f(x)$ | διάλεξε κοντινό $a$ → $L(x) = f(a) + f'(a)(x - a)$ → έλεγξε $f''(a)$ για υπερεκτίμηση ($<0$) / υποεκτίμηση ($>0$) · 🪤 μοίρες $\to$ rad | Ασκ. 4, 5 |

### Όρια L'Hôpital

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| $\frac00$ ή $\frac\infty\infty$ | επιβεβαίωσε τη μορφή → $\frac{f'}{g'}$ → απλοποίησε → επανάλαβε μόνο αν μένει $\frac00$ ή $\frac\infty\infty$ · 🪤 όχι σε μη απροσδιόριστη! | Ασκ. 7, 9 |
| $0\cdot\infty$ ή $\infty - \infty$ | μετατροπή σε κλάσμα (ομώνυμα / $1/g$) → L'Hôpital | Ασκ. 8 |
| $1^\infty, 0^0, \infty^0$ | $\ln y = g\ln f \to L \implies y \to e^L$ · 🪤 μην ξεχάσεις το $e^L$ | Ασκ. 8 |
| Πότε αποτυγχάνει L'Hôpital | κύκλος ($\frac{x}{\sqrt{x^2+1}}$) ή $\lim\frac{f'}{g'}$ δεν υπάρχει ($\frac{x + \sin x}{x}$) → αλγεβρικός υπολογισμός | Ασκ. 10 |

### Rolle, Θ.Μ.Τ., Ακρότατα, Γραφική & Newton

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| Έλεγχος Rolle / Θ.Μ.Τ. & εύρεση $c$ | έλεγξε συνέχεια στο $[a, b]$, παραγωγισιμότητα στο $(a, b)$ (και $f(a) = f(b)$ για Rolle) → λύσε $f'(c) = \frac{f(b)-f(a)}{b-a}$ → κράτα $c \in (a, b)$ | Ασκ. 11, 12 |
| Απόδειξη ανισότητας | Θ.Μ.Τ. σε κατάλληλη $f$ στο $[x, y]$ και φράγμα για $f'(c)$ — ή μονοτονία της $h(x) = f(x) - g(x)$ | Ασκ. 13 |
| Ακριβές πλήθος ριζών | Bolzano (ύπαρξη) + Rolle/μονοτονία (μοναδικότητα) | Ασκ. 14 |
| Μονοτονία, κυρτότητα, ακρότατα, Σ.Κ. | πεδίο → $f'$ (κρίσιμα: $f'=0$ **και** $\nexists f'$) → πίνακας $f'$ → $f''$ → πίνακας $f''$ · 🪤 όχι $\cup$ πάνω από ασυνέχεια | Ασκ. 15, 16, 17 |
| Απόλυτα ακρότατα σε $[a, b]$ | κρίσιμα στο $(a, b)$ + άκρα $a, b$ → σύγκρινε τιμές $f$ | Ασκ. 18 |
| Ασύμπτωτες & γραφική παράσταση | πεδίο → συμμετρία → άξονες → ασύμπτωτες (🪤 $\sqrt{x^2} = -x$ για $x \to -\infty$) → πίνακας $f', f''$ → διάγραμμα | Ασκ. 19, 20 |
| Βελτιστοποίηση | αντικειμενική σε 1 μεταβλητή → πεδίο → $f' = 0$ → **επαλήθευσε ολικό ακρότατο** (άκρα ή όρια) | Ασκ. 21, 22 |
| Μέθοδος Newton | γράψε $f(x) = 0$ → εντόπισε ρίζα (Bolzano) → $x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$ → 🪤 έλεγξε $f'(x_n) \ne 0$ | Ασκ. 23, 24 |
