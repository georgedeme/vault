# 08 - Ασκήσεις

Ασκήσεις για το Κεφάλαιο 4. **Λύσε πρώτα, άνοιξε μετά**: κάθε λύση είναι κρυμμένη σε αναδιπλούμενο πλαίσιο. Οι ασκήσεις με 🪤 έχουν παγίδα.

> [!tip] Πώς να το χρησιμοποιήσεις
> Κάνε ένα πλήρες πέρασμα χωρίς να ανοίξεις λύση. Όπου κόλλησες, γύρνα στη σχετική σημείωση, όχι στη λύση.

---

## Μέρος Α — Ορισμός και εφαπτομένες

### Άσκηση 1

Βρες από τον ορισμό την παράγωγο της $f(x) = \dfrac{1}{x + 1}$.

> [!success]- Λύση
> $$\frac{\frac{1}{x + h + 1} - \frac{1}{x + 1}}{h} = \frac{(x + 1) - (x + h + 1)}{h(x + h + 1)(x + 1)} = \frac{-1}{(x + h + 1)(x + 1)} \to -\frac{1}{(x + 1)^2}$$

### Άσκηση 2

Βρες την εφαπτομένη της $y = \sqrt x$ στο $x = 4$.

> [!success]- Λύση
> $y' = \frac{1}{2\sqrt x}$ ⇒ $y'(4) = \frac14$. Σημείο $(4, 2)$: $y - 2 = \frac14(x - 4) \Rightarrow y = \frac14 x + 1$.

### Άσκηση 3 🪤

Είναι η $f(x) = \lvert x - 3\rvert$ συνεχής στο 3; Παραγωγίσιμη;

> [!success]- Λύση
> **Συνεχής** ναι: $\lim_{x\to3}\lvert x - 3\rvert = 0 = f(3)$.
> **Παραγωγίσιμη** όχι: $\frac{\lvert h\rvert}{h}$ έχει πλευρικά όρια $-1$ και $+1$ (γωνία).

### Άσκηση 4 🪤

Βρες $a, b$ ώστε η $f$ να είναι παραγωγίσιμη στο 2:
$$f(x) = \begin{cases} ax^2 + b, & x < 2 \\ 4x - 1, & x \ge 2 \end{cases}$$

> [!success]- Λύση
> **Συνέχεια:** $4a + b = 7$. **Πλευρικές παράγωγοι:** $2ax\big|_{x=2} = 4a$ και $4$ ⇒ $a = 1$.
> Άρα $b = 3$. (Μόνο η συνθήκη της παραγώγου δεν αρκεί.)

## Μέρος Β — Κανόνες παραγώγισης

### Άσκηση 5

Παραγώγισε $y = 4x^5 - \dfrac{3}{x^2} + \sqrt x$.

> [!success]- Λύση
> $y = 4x^5 - 3x^{-2} + x^{1/2}$ ⇒ $y' = 20x^4 + 6x^{-3} + \dfrac{1}{2\sqrt x}$.

### Άσκηση 6

Παραγώγισε $y = \dfrac{x}{x^2 + 1}$ και $y = \dfrac{\sin x}{1 + \cos x}$.

> [!success]- Λύση
> - $y' = \dfrac{(x^2 + 1) - x\cdot2x}{(x^2 + 1)^2} = \dfrac{1 - x^2}{(x^2 + 1)^2}$
> - $y' = \dfrac{\cos x(1 + \cos x) - \sin x(-\sin x)}{(1 + \cos x)^2} = \dfrac{\cos x + \cos^2 x + \sin^2 x}{(1 + \cos x)^2} = \dfrac{1 + \cos x}{(1 + \cos x)^2} = \dfrac{1}{1 + \cos x}$

### Άσκηση 7

Βρες τα σημεία όπου η $y = xe^{-x}$ έχει οριζόντια εφαπτομένη.

> [!success]- Λύση
> $y' = e^{-x} + x\cdot(-e^{-x}) = e^{-x}(1 - x) = 0$. Αφού $e^{-x} > 0$: $x = 1$. Σημείο $\left(1, \frac1e\right)$.

### Άσκηση 8 🪤

Βρες $\dfrac{d^{100}}{dx^{100}}[\cos x]$.

> [!success]- Λύση
> Κύκλος ανά 4: $\cos \to -\sin \to -\cos \to \sin \to \cos$. $100 = 4\cdot25$ ⇒ $\cos x$.

## Μέρος Γ — Κανόνας αλυσίδας

### Άσκηση 9

Παραγώγισε: (α) $(3x^2 - 5)^7$ (β) $\cos(e^{2x})$ (γ) $\sqrt{x^2 + \tan x}$ (δ) $\sin^3(4x)$

> [!success]- Λύση
> (α) $7(3x^2 - 5)^6\cdot6x = 42x(3x^2 - 5)^6$
> (β) $-\sin(e^{2x})\cdot e^{2x}\cdot2 = -2e^{2x}\sin(e^{2x})$
> (γ) $\dfrac{2x + \sec^2 x}{2\sqrt{x^2 + \tan x}}$
> (δ) $3\sin^2(4x)\cdot\cos(4x)\cdot4 = 12\sin^2(4x)\cos(4x)$

### Άσκηση 10 🪤

Αν $h(x) = f(g(x))$, $g(3) = 5$, $g'(3) = 2$, $f'(3) = 4$, $f'(5) = -1$, βρες $h'(3)$.

> [!success]- Λύση
> $h'(3) = f'(g(3))\cdot g'(3) = f'(5)\cdot2 = -2$. Το $f'(3) = 4$ είναι **παραπλανητικό** δεδομένο.

### Άσκηση 11

Παραγώγισε $\cosh(x^2)$ και $\tanh(3x)$.

> [!success]- Λύση
> $2x\sinh(x^2)$ (χωρίς μείον) · $3\operatorname{sech}^2(3x)$.

## Μέρος Δ — Πλεγμένη παραγώγιση

### Άσκηση 12

Βρες την κλίση της $x^2y + y^3 = 10$ στο $(1, 2)$.

> [!success]- Λύση
> Έλεγχος: $2 + 8 = 10$ ✓
> $2xy + x^2y' + 3y^2y' = 0 \Rightarrow y' = -\dfrac{2xy}{x^2 + 3y^2}$. Στο $(1, 2)$: $y' = -\frac{4}{13}$.

### Άσκηση 13

Βρες $y'$ αν $e^y = x + y$.

> [!success]- Λύση
> $e^y y' = 1 + y' \Rightarrow y'(e^y - 1) = 1 \Rightarrow y' = \dfrac{1}{e^y - 1}$.

### Άσκηση 14 🪤

Βρες τα σημεία της $x^2 - xy + y^2 = 3$ με οριζόντια εφαπτομένη.

> [!success]- Λύση
> $2x - y - xy' + 2yy' = 0 \Rightarrow y' = \dfrac{y - 2x}{2y - x}$.
> Οριζόντια ⇔ $y = 2x$. **Πρέπει και να ανήκει στην καμπύλη:** $x^2 - 2x^2 + 4x^2 = 3x^2 = 3 \Rightarrow x = \pm1$.
> Σημεία $(1, 2)$ και $(-1, -2)$ (παρονομαστής $2y - x = \pm3 \ne 0$ ✓).

## Μέρος Ε — Αντίστροφη, λογάριθμοι, λογαριθμική παραγώγιση

### Άσκηση 15

$f(x) = x^5 + 2x - 1$. Βρες $(f^{-1})'(2)$.

> [!success]- Λύση
> $f(1) = 1 + 2 - 1 = 2$ ⇒ $f^{-1}(2) = 1$. $f'(x) = 5x^4 + 2$ ⇒ $f'(1) = 7$. Άρα $(f^{-1})'(2) = \frac17$.

### Άσκηση 16

Παραγώγισε: (α) $\ln(x^2 + 4x)$ (β) $\log_2(3x)$ (γ) $5^{x^2}$

> [!success]- Λύση
> (α) $\dfrac{2x + 4}{x^2 + 4x}$
> (β) $\dfrac{3}{3x\ln2} = \dfrac{1}{x\ln2}$
> (γ) $5^{x^2}\ln5\cdot2x$

### Άσκηση 17

Παραγώγισε $\tan^{-1}(\sqrt x)$ και $\sin^{-1}\left(\frac x2\right)$.

> [!success]- Λύση
> - $\dfrac{1}{1 + x}\cdot\dfrac{1}{2\sqrt x} = \dfrac{1}{2\sqrt x(1 + x)}$
> - $\dfrac{1/2}{\sqrt{1 - x^2/4}} = \dfrac{1/2}{\frac12\sqrt{4 - x^2}} = \dfrac{1}{\sqrt{4 - x^2}}$, για $\lvert x\rvert < 2$

### Άσκηση 18 🪤

Παραγώγισε $y = x^{1/x}$ ($x > 0$).

> [!success]- Λύση
> Μεταβλητή βάση **και** εκθέτης ⇒ λογαριθμική παραγώγιση.
> $\ln y = \dfrac{\ln x}{x} \Rightarrow \dfrac{y'}{y} = \dfrac{\frac1x\cdot x - \ln x}{x^2} = \dfrac{1 - \ln x}{x^2}$
> $y' = x^{1/x}\cdot\dfrac{1 - \ln x}{x^2}$.

### Άσκηση 19 🪤

Παραγώγισε $y = (\sin x)^x$ για $0 < x < \pi$.

> [!success]- Λύση
> $\ln y = x\ln(\sin x) \Rightarrow \dfrac{y'}{y} = \ln(\sin x) + x\cdot\dfrac{\cos x}{\sin x}$
> $y' = (\sin x)^x\big(\ln(\sin x) + x\cot x\big)$.

### Άσκηση 20

Βρες την παράγωγο της $y = \ln\sqrt{\dfrac{1 + x}{1 - x}}$ ($\lvert x\rvert < 1$).

> [!success]- Λύση
> Πρώτα νόμοι λογαρίθμων: $y = \frac12\big[\ln(1 + x) - \ln(1 - x)\big]$.
> $y' = \frac12\left[\dfrac{1}{1 + x} + \dfrac{1}{1 - x}\right] = \frac12\cdot\dfrac{2}{1 - x^2} = \dfrac{1}{1 - x^2}$.
> (Είναι η $\tanh^{-1}x$, σε συμφωνία με τον πίνακα.)
