# 07 - Τυπολόγιο

Το Κεφάλαιο 4 σε μία σελίδα.

## 1. Ορισμός

$$f'(x) = \lim_{h \to 0}\frac{f(x + h) - f(x)}{h} \qquad \text{εφαπτομένη: } y - f(a) = f'(a)(x - a)$$

- Μέσος ρυθμός = κλίση τέμνουσας · στιγμιαίος ρυθμός = $f'(a)$ · $s' = v$, $s'' = a$
- **Παραγωγίσιμη ⇒ συνεχής** (όχι αντίστροφα: $\lvert x\rvert$)
- Χωρίς παράγωγο: γωνία · ακίδα · κατακόρυφη εφαπτομένη · ασυνέχεια
- Κλαδική παραγωγίσιμη στο $a$: **συνέχεια** + ίσες πλευρικές παράγωγοι
- Βοήθημα: γωνιακό σημείο ($f'_- \ne f'_+$) · κατακόρυφη εφαπτομένη/σημείο καμπής ($f'_\pm$ ίδιο άπειρο) · σημείο ανάκαμψης ($-\infty$ και $+\infty$) · μόνο για **συνεχείς**
- Κάθετη ευθεία: $y - f(a) = -\frac{1}{f'(a)}(x - a)$
- Όριο $\lim_{h\to0}\frac{f(a + h) - f(a)}{h}$ = $f'(a)$: π.χ. $\lim\frac{10^h - 1}{h} = \ln 10$, $\lim_{x\to0}\frac{\sqrt{9 + x} - 3}{x} = \frac16$

## 2. Κανόνες

| | |
|---|---|
| $(c)' = 0$ | $(x^r)' = rx^{r-1}$ |
| $(cf)' = cf'$ | $(f \pm g)' = f' \pm g'$ |
| $(fg)' = f'g + fg'$ | $\left(\dfrac fg\right)' = \dfrac{f'g - fg'}{g^2}$ |
| $\big(f(g(x))\big)' = f'(g(x))\,g'(x)$ | $(f^{-1})'(x) = \dfrac{1}{f'(f^{-1}(x))}$ |
| $\frac{d}{dx}f(-x) = -f'(-x)$ | άρτια$'$ = περιττή · περιττή$'$ = άρτια |
| $(fg)^{(n)} = \sum_{k=0}^n\binom nk f^{(n-k)}g^{(k)}$ (Leibniz) | $(fg)'' = f''g + 2f'g' + fg''$ |

## 3. Πίνακας παραγώγων

| $f$ | $f'$ | $f$ | $f'$ |
|---|---|---|---|
| $\sin x$ | $\cos x$ | $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ | $\cot x$ | $-\csc^2 x$ |
| $\sec x$ | $\sec x\tan x$ | $\csc x$ | $-\csc x\cot x$ |
| $e^x$ | $e^x$ | $b^x$ | $b^x\ln b$ |
| $\ln\lvert x\rvert$ | $\frac1x$ | $\log_b x$ | $\frac{1}{x\ln b}$ |
| $\sin^{-1}x$ | $\frac{1}{\sqrt{1 - x^2}}$ | $\cos^{-1}x$ | $-\frac{1}{\sqrt{1 - x^2}}$ |
| $\tan^{-1}x$ | $\frac{1}{1 + x^2}$ | $\sec^{-1}x$ | $\frac{1}{\lvert x\rvert\sqrt{x^2 - 1}}$ |
| $\sinh x$ | $\cosh x$ | $\cosh x$ | $\sinh x$ |
| $\tanh x$ | $\operatorname{sech}^2 x$ | $\coth x$ | $-\operatorname{csch}^2 x$ |
| $\sinh^{-1}x$ | $\frac{1}{\sqrt{x^2 + 1}}$ | $\cosh^{-1}x$ | $\frac{1}{\sqrt{x^2 - 1}}$ |
| $\tanh^{-1}x$ | $\frac{1}{1 - x^2}$ | $\coth^{-1}x$ | $\frac{1}{1 - x^2}$ ($\lvert x\rvert > 1$) |
| $\cot^{-1}x$ | $-\frac{1}{1 + x^2}$ | $\csc^{-1}x$ | $-\frac{1}{\lvert x\rvert\sqrt{x^2 - 1}}$ |
| $\operatorname{sech}^{-1}x$ | $-\frac{1}{x\sqrt{1 - x^2}}$ | $\operatorname{csch}^{-1}x$ | $-\frac{1}{\lvert x\rvert\sqrt{1 + x^2}}$ |

- Βοήθημα Κεφ. 10: $\sec^{-1}$, $\csc^{-1}$ **χωρίς** απόλυτη τιμή ($\frac{1}{x\sqrt{x^2 - 1}}$), λόγω άλλου συνόλου τιμών· ίδιο για $x > 1$

**Με κανόνα αλυσίδας** ($u = u(x)$): $(u^n)' = nu^{n-1}u'$ · $(\sqrt u)' = \frac{u'}{2\sqrt u}$ · $(e^u)' = e^u u'$ · $(\ln u)' = \frac{u'}{u}$ · $(\sin u)' = u'\cos u$ · $(a^u)' = a^u\ln a\,u'$

**$n$-οστές:** $(x^m)^{(n)} = \frac{m!}{(m - n)!}x^{m - n}$ · $(e^{kx})^{(n)} = k^ne^{kx}$ · $(\ln x)^{(n)} = (-1)^{n+1}\frac{(n - 1)!}{x^n}$ · $(\sin x)^{(n)} = \sin\left(x + \frac{n\pi}{2}\right)$ · $\left(\frac{1}{1 - x}\right)^{(n)} = \frac{n!}{(1 - x)^{n+1}}$

## 4. Πλεγμένη παραγώγιση

- Παραγώγισε και τα δύο μέλη ως προς $x$ · $(y^n)' = ny^{n-1}y'$ · $(xy)' = y + xy'$ · λύσε ως προς $y'$
- $y' = A/B$: οριζόντια εφαπτομένη $A = 0$ · κατακόρυφη $B = 0$ · το σημείο **στην καμπύλη**
- $\frac{dy}{dx} = \frac{1}{dx/dy}$ · **παραμετρική:** $\frac{dy}{dx} = \frac{\dot y}{\dot x}$, $\frac{d^2y}{dx^2} = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{\dot x}$ (όχι $\frac{\ddot y}{\ddot x}$)

## 5. Αντίστροφη και λογαριθμική παραγώγιση

- $(f^{-1})'(a)$: βρες $b = f^{-1}(a)$ λύνοντας $f(b) = a$ → $\frac{1}{f'(b)}$
- $f'(b) = 0$ ⇒ κατακόρυφη εφαπτομένη της $f^{-1}$
- σταθ.$^{\text{σταθ.}}$ → 0 · $x^n$ → δύναμη · $b^x$ → $b^x\ln b$ · $x^x$ → **$\ln$ και στα δύο μέλη**
- $(x^x)' = x^x(\ln x + 1)$

| Τύπος | Βήματα | Π.χ. |

| Παράγωγος από τον ορισμό | $\frac{f(x + h) - f(x)}{h}$ → ομώνυμα / συζυγής / ανάπτυξη → απλοποίησε το $h$ → $h \to 0$ · 🪤 όχι $h = 0$ πριν την απλοποίηση | Ασκ. 1 |
| Εφαπτομένη στο $x = a$ | $f(a)$ → $f'(a)$ (αριθμός) → $y - f(a) = f'(a)(x - a)$ | Ασκ. 2 |
| Κάθετη ευθεία στο $x = a$ | κλίση $-\frac{1}{f'(a)}$ · $f'(a) = 0$: κατακόρυφη $x = a$ | |
| Εφαπτομένη με δοσμένη κλίση ή παράλληλη σε ευθεία | $f'(x) = m$ → $x$ → σημεία → εφαπτομένες | |
| Εφαπτομένη από σημείο **εκτός** καμπύλης | σημείο επαφής $(x_1, f(x_1))$ άγνωστο → εφαπτομένη εκεί → περνά από το δοσμένο σημείο → λύσε για $x_1$ | |
| Οριζόντιες εφαπτομένες | $f'(x) = 0$ → σημεία $(x, f(x))$ · με παραμέτρους: πλήθος ριζών της $f'$ μέσω $\Delta$ · 🪤 χωριστά ο εκφυλισμένος βαθμός ($a = 0$) | Ασκ. 7, 24α, 25 |
| Παράμετροι από σημείο και κλίση | δύο εξισώσεις: $f(x_0) = y_0$ και $f'(x_0) = m$ | Ασκ. 24β |
| Μέσος/στιγμιαίος ρυθμός, ταχύτητα | μέσος: $\frac{f(b) - f(a)}{b - a}$ · στιγμιαίος: $f'(a)$ · $v = s'$, επιτάχυνση $= v'$ · μονάδες «του $y$ ανά μονάδα του $x$» | |
| Όριο που κρύβει παράγωγο | αναγνώρισε $\lim_{h\to0}\frac{f(a + h) - f(a)}{h}$ → $f'(a)$ | |

### Παραγωγισιμότητα

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| Συνεχής; Παραγωγίσιμη; | συνέχεια → πλευρικές παράγωγοι (από τον ορισμό, ή από τους τύπους των κλάδων αφού είναι συνεχής) → ίσες ⇒ παραγωγίσιμη | Ασκ. 3, 21α |
| Παράμετροι για παραγωγισιμότητα | (1) συνέχεια (2) ίσες πλευρικές παράγωγοι → σύστημα · 🪤 η (2) μόνη της δεν αρκεί· μερικές φορές η (1) ισχύει για κάθε τιμή | Ασκ. 4, 21β |
| Χαρακτηρισμός σημείου μη παραγωγισιμότητας | $\frac{f(a + h) - f(a)}{h}$ πλευρικά: διαφορετικά πεπερασμένα → γωνία · ίδιο $\pm\infty$ → κατακόρυφη εφαπτομένη (καμπή) · αντίθετα άπειρα → ανάκαμψη (ακίδα) | Ασκ. 22 |
| Δίνεται όριο με $f'$, ζητείται $f''(a)$ | παρονομαστής $\to 0$ ⇒ αριθμητής $\to 0$ ⇒ $f'(a)$ → γράψε $\frac{f'(x) - f'(a)}{x - a}$ ως άθροισμα γνωστών ορίων | Ασκ. 26 |

### Πλεγμένη και παραμετρική παραγώγιση

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| $y'$ πλεγμένα | παραγώγισε και τα δύο μέλη (το $y$ ως $y(x)$: $(y^n)' = ny^{n-1}y'$, $(xy)' = y + xy'$) → μάζεψε τους όρους με $y'$ → λύσε | Ασκ. 13 |
| Κλίση/εφαπτομένη σε σημείο | έλεγξε ότι το σημείο **ανήκει** στην καμπύλη → $y'$ → αντικατάσταση | Ασκ. 12 |
| Οριζόντιες/κατακόρυφες εφαπτομένες | $y' = \frac AB$ → $A = 0$ (οριζόντια) ή $B = 0$ (κατακόρυφη) → σύστημα με την καμπύλη | Ασκ. 14 |

| $y''$ πλεγμένα | παραγώγισε το $y'$ (πηλίκο, το $y$ είναι συνάρτηση του $x$) → αντικατέστησε το $y'$ → απλοποίησε με την **αρχική** εξίσωση | |

### Αντίστροφη, λογάριθμοι, λογαριθμική παραγώγιση

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| $(f^{-1})'(a)$ | λύσε $f(b) = a$ (δοκίμασε μικρούς ακέραιους) → $f'(b)$ → $\frac{1}{f'(b)}$ · $f'(b) = 0$: κατακόρυφη εφαπτομένη της $f^{-1}$ | Ασκ. 15 |
| Λογάριθμοι και εκθετικές | πρώτα **νόμοι λογαρίθμων** → $(\ln u)' = \frac{u'}{u}$, $(a^u)' = a^u\ln a\cdot u'$, $(\log_b u)' = \frac{u'}{u\ln b}$ | Ασκ. 16, 20 |
| Αντίστροφες τριγωνομετρικές/υπερβολικές | τύπος του πίνακα με όρισμα $u$ × $u'$ → απλοποίηση της ρίζας · δώσε και το πεδίο | Ασκ. 17 |

| Πολύπλοκα γινόμενα, πηλίκα, ρίζες | $\ln\lvert y\rvert$ → άθροισμα λογαρίθμων → παραγώγισε → πολλαπλασίασε με $y$ | |
