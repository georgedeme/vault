# 06 - Ασκήσεις

Ασκήσεις για το Κεφάλαιο 6. **Λύσε πρώτα, άνοιξε μετά**: κάθε λύση είναι κρυμμένη σε αναδιπλούμενο πλαίσιο. Οι ασκήσεις με 🪤 έχουν παγίδα.

> [!tip] Πώς να το χρησιμοποιήσεις
> Κάνε ένα πλήρες πέρασμα χωρίς να ανοίξεις λύση. Όπου κόλλησες, γύρνα στη σχετική σημείωση, όχι στη λύση.

## Μέρος Α — Αόριστο ολοκλήρωμα και βασικά ολοκληρώματα

### Άσκηση 1

Υπολόγισε τα αόριστα ολοκληρώματα:
(α) $\displaystyle\int \left(4x^3 - \frac{3}{x^2} + 2\sqrt x - \frac{5}{x}\right)dx$ $\quad$ (β) $\displaystyle\int \frac{x^4 - 3x^2 + 1}{x^2}\,dx$ $\quad$ (γ) $\displaystyle\int \frac{x^2}{x^2 + 1}\,dx$

> [!success]- Λύση
> (α) $\displaystyle\int \left(4x^3 - 3x^{-2} + 2x^{1/2} - \frac{5}{x}\right)dx = x^4 + \frac{3}{x} + \frac{4}{3}x^{3/2} - 5\ln\lvert x\rvert + C$.
> (β) Χωρίζουμε τον αριθμητή: $\displaystyle\int (x^2 - 3 + x^{-2})\,dx = \frac{x^3}{3} - 3x - \frac{1}{x} + C$.
> (γ) $\displaystyle\int \frac{(x^2 + 1) - 1}{x^2 + 1}\,dx = \int \left(1 - \frac{1}{x^2 + 1}\right)dx = x - \tan^{-1}x + C$.

### Άσκηση 2

Υπολόγισε με τριγωνομετρικές αναδιατάξεις:
(α) $\displaystyle\int \tan^2 x\,dx$ $\quad$ (β) $\displaystyle\int \frac{\sin x}{\cos^2 x}\,dx$ $\quad$ (γ) $\displaystyle\int \frac{dx}{\sin^2 x\cos^2 x}$ $\quad$ (δ) $\displaystyle\int \cos^2 x\,dx$

> [!success]- Λύση
> (α) $\displaystyle\int (\sec^2 x - 1)\,dx = \tan x - x + C$.
> (β) $\displaystyle\int \sec x\tan x\,dx = \sec x + C$.
> (γ) $\displaystyle\int \frac{\sin^2 x + \cos^2 x}{\sin^2 x\cos^2 x}\,dx = \int (\sec^2 x + \csc^2 x)\,dx = \tan x - \cot x + C$ (ισοδύναμα $-2\cot 2x + C$).
> (δ) $\displaystyle\int \frac{1 + \cos 2x}{2}\,dx = \frac{x}{2} + \frac{\sin 2x}{4} + C$.

### Άσκηση 3

Υπολόγισε:
(α) $\displaystyle\int \left(3e^{2x} - 5^x + \sinh x\right)dx$ $\quad$ (β) $\displaystyle\int \frac{dx}{\sqrt{9 - x^2}}$ $\quad$ (γ) $\displaystyle\int \frac{dx}{4 + x^2}$ $\quad$ (δ) $\displaystyle\int \left(\operatorname{sech}^2 x + \frac{2}{\sqrt{x^2 + 1}}\right)dx$

> [!success]- Λύση
> (α) $\dfrac{3}{2}e^{2x} - \dfrac{5^x}{\ln 5} + \cosh x + C$.
> (β) $a = 3$: $\sin^{-1}\!\left(\dfrac{x}{3}\right) + C$.
> (γ) $a = 2$: $\dfrac{1}{2}\tan^{-1}\!\left(\dfrac{x}{2}\right) + C$.
> (δ) $\tanh x + 2\sinh^{-1}x + C = \tanh x + 2\ln\big(x + \sqrt{x^2 + 1}\big) + C$.

### Άσκηση 4 🪤

(α) Αν $\displaystyle\int f(x)\,dx = \frac{1}{\sqrt{4 - x^2}} + C$, βρες την $f(x)$.
(β) Η συνάρτηση $F(x) = \begin{cases} \ln(-x) + 3, & x < 0 \\ \ln x - 7, & x > 0 \end{cases}$ είναι παράγουσα της $f(x) = \frac{1}{x}$ στο $\mathbb R \setminus \{0\}$; Γιατί δεν διαφέρει από τη $\ln\lvert x\rvert$ κατά μία μόνο σταθερά;

> [!success]- Λύση
> (α) Παραγωγίζουμε: $f(x) = \dfrac{d}{dx}\big[(4 - x^2)^{-1/2}\big] = -\dfrac{1}{2}(4 - x^2)^{-3/2}(-2x) = \dfrac{x}{(4 - x^2)^{3/2}}$.
> (β) **Ναι!** Για $x > 0$: $F'(x) = \frac{1}{x}$. Για $x < 0$: $F'(x) = \frac{-1}{-x} = \frac{1}{x}$.
> Το θεώρημα μοναδικότητας έως σταθερά ισχύει μόνο σε **διάστημα**. Το $\mathbb R \setminus \{0\} = (-\infty, 0) \cup (0, +\infty)$ αποτελείται από **δύο ξένα διαστήματα**, οπότε η παράγουσα μπορεί να έχει ανεξάρτητες σταθερές $C_1, C_2$ σε καθένα από αυτά.

## Μέρος Β — Προβλήματα αρχικών τιμών & απλές Δ.Ε.

### Άσκηση 5

(α) Βρες την $f(x)$ αν $f'(x) = 6 - 5\sin 2x$ και $f(0) = 3$.
(β) Βρες την $f(x)$ αν $f''(x) = 12x^2 - 6x$, $f'(1) = 4$ και $f(1) = 2$.

> [!success]- Λύση
> (α) $f(x) = 6x + \frac{5}{2}\cos 2x + C$. Από $f(0) = 3$: $\frac{5}{2} + C = 3 \Rightarrow C = \frac{1}{2}$. Άρα $f(x) = 6x + \frac{5}{2}\cos 2x + \frac{1}{2}$.
> (β) $f'(x) = 4x^3 - 3x^2 + C_1$. Από $f'(1) = 4$: $4 - 3 + C_1 = 4 \Rightarrow C_1 = 3$.
> $f(x) = x^4 - x^3 + 3x + C_2$. Από $f(1) = 2$: $1 - 1 + 3 + C_2 = 2 \Rightarrow C_2 = -1$.
> Τελικά $f(x) = x^4 - x^3 + 3x - 1$.

### Άσκηση 6 🪤

Λύσε τη διαφορική εξίσωση $\dfrac{dy}{dx} = y^2\cos x$ (βρες **όλες** τις λύσεις).

> [!success]- Λύση
> Για $y \ne 0$: $\dfrac{dy}{y^2} = \cos x\,dx \implies -\dfrac{1}{y} = \sin x + C \implies y = -\dfrac{1}{\sin x + C}$.
> **Παγίδα:** διαιρέσαμε με $y^2$, άρα ελέγχουμε χωριστά την $y \equiv 0$. Πράγματι, $0' = 0^2\cos x \iff 0 = 0$ ✓.
> Άρα οι λύσεις είναι $y = -\dfrac{1}{\sin x + C}$ ($C \in \mathbb R$) **και** η σταθερή λύση $y \equiv 0$.

## Μέρος Γ — Αθροίσματα Riemann, γεωμετρία, όρια και ιδιότητες

### Άσκηση 7

(α) Για τη $f(x) = \frac{1}{x}$ στο $[1, 9]$ με ισομερή διαμέριση σε $n = 4$ υποδιαστήματα, βρες το κάτω άθροισμα $L_4$ και το άνω άθροισμα $U_4$.
(β) Για τη $f(x) = x^2$ στο $[-2, 4]$ με διαμέριση $\Delta x_1 = 2, \Delta x_2 = 1, \Delta x_3 = 3$ και σημεία $x_1^* = -1, x_2^* = 0, x_3^* = 3$, βρες το $\|P\|$ και το άθροισμα Riemann.

> [!success]- Λύση
> (α) $\Delta x = \frac{9 - 1}{4} = 2$, σημεία $1, 3, 5, 7, 9$. Επειδή η $\frac{1}{x}$ είναι γνησίως **φθίνουσα**:
> - Ελάχιστο στο δεξί άκρο: $L_4 = 2\left(\frac{1}{3} + \frac{1}{5} + \frac{1}{7} + \frac{1}{9}\right) = 2\cdot\frac{248}{315} = \frac{496}{315} \approx 1{,}57$.
> - Μέγιστο στο αριστερό άκρο: $U_4 = 2\left(1 + \frac{1}{3} + \frac{1}{5} + \frac{1}{7}\right) = 2\cdot\frac{176}{105} = \frac{352}{105} \approx 3{,}35$.
> *(Ακριβής τιμή: $\ln 9 \approx 2{,}20$, όντως ανάμεσα στα $L_4$ και $U_4$.)*
> (β) $\|P\| = \max\{2, 1, 3\} = 3$.
> $S_R^3 = f(-1)\cdot 2 + f(0)\cdot 1 + f(3)\cdot 3 = 1\cdot 2 + 0\cdot 1 + 9\cdot 3 = 29$. *(Σύγκρινε: στο Βοήθημα σελ. 8.13 υπήρχε $f(x) = x^2$ με $1\cdot 2 + 0 + 9\cdot 3 = 29$ — στο Βοήθημα γράφτηκε εκ παραδρομής $14$!)*

### Άσκηση 8

Υπολόγισε **γεωμετρικά** (χωρίς παράγουσα):
(α) $\displaystyle\int_{-2}^{2} \sqrt{4 - x^2}\,dx$ $\quad$ (β) $\displaystyle\int_{0}^{6} (2 - x)\,dx$ και το **ολικό εμβαδό** μεταξύ της $y = 2 - x$ και του άξονα $x$ στο $[0, 6]$.

> [!success]- Λύση
> (α) Άνω ημικύκλιο ακτίνας $r = 2$: $\frac{1}{2}\pi\cdot 2^2 = 2\pi$.
> (β) Στο $[0, 2]$ τρίγωνο πάνω από τον άξονα με βάση $2$, ύψος $2$ ⇒ $E_+ = 2$. Στο $[2, 6]$ τρίγωνο κάτω από τον άξονα με βάση $4$, ύψος $4$ ⇒ $E_- = 8$.
> - Ορισμένο ολοκλήρωμα (προσημασμένο): $2 - 8 = -6$.
> - Ολικό εμβαδό: $2 + 8 = 10$.

### Άσκηση 9

Υπολόγισε τα όρια μετατρέποντάς τα σε ορισμένα ολοκληρώματα:
(α) $\displaystyle\lim_{n\to\infty}\frac{1^4 + 2^4 + \dots + n^4}{n^5}$ $\quad$ (β) $\displaystyle\lim_{n\to\infty}\sum_{k=1}^n \frac{\sin(k\pi/n)}{n}$

> [!success]- Λύση
> (α) $\displaystyle\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^n \left(\frac{k}{n}\right)^4 = \int_0^1 x^4\,dx = \left[\frac{x^5}{5}\right]_0^1 = \frac{1}{5}$.
> (β) $\displaystyle\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^n \sin\!\left(\pi\cdot\frac{k}{n}\right) = \int_0^1 \sin(\pi x)\,dx = \left[-\frac{\cos(\pi x)}{\pi}\right]_0^1 = \frac{1 - (-1)}{\pi} = \frac{2}{\pi}$.

### Άσκηση 10 🪤

Υπολόγισε το όριο $\displaystyle\lim_{n\to\infty}\sum_{k=1}^{3n} \frac{1}{n + k}$.

> [!success]- Λύση
> Γράφουμε $\displaystyle\frac{1}{n}\sum_{k=1}^{3n} \frac{1}{1 + k/n}$. Εδώ $\Delta x = \frac{1}{n}$ και $x_k = \frac{k}{n}$ τρέχει από $\frac{1}{n} \to 0$ έως $\frac{3n}{n} = 3$ (**όχι** $1$!).
> Άρα το όριο είναι:
> $$\int_0^3 \frac{dx}{1 + x} = \Big[\ln(1 + x)\Big]_0^3 = \ln 4 - \ln 1 = \ln 4 = 2\ln 2$$

### Άσκηση 11

(α) Αν $\displaystyle\int_0^1 f(x)\,dx = -2$ και $\displaystyle\int_0^5 f(x)\,dx = 1$, βρες $\displaystyle\int_5^1 \big(3f(x) + 2\big)\,dx$.
(β) Δείξε χωρίς να υπολογίσεις το ολοκλήρωμα ότι $\displaystyle\frac{1}{2} \le \int_0^1 \frac{dx}{1 + x^3} \le 1$.

> [!success]- Λύση
> (α) $\int_1^5 f = \int_0^5 f - \int_0^1 f = 1 - (-2) = 3$, άρα $\int_5^1 f = -3$.
> Επίσης $\int_5^1 2\,dx = 2(1 - 5) = -8$. Τελικά $3(-3) + (-8) = -17$.
> (β) Για $x \in [0, 1]$: $0 \le x^3 \le 1 \implies 1 \le 1 + x^3 \le 2 \implies \dfrac{1}{2} \le \dfrac{1}{1 + x^3} \le 1$.
> Ολοκληρώνοντας στο $[0, 1]$ (μήκος $1$): $\dfrac{1}{2}\cdot 1 \le \displaystyle\int_0^1 \frac{dx}{1 + x^3} \le 1\cdot 1$. ∎

### Άσκηση 12 🪤

Υπολόγισε ή εξήγησε γιατί δεν ορίζεται:
(α) $\displaystyle\int_{-\pi/2}^{\pi/2} \left(x^3\cos x + x^2\sin x + 2\cos x\right)dx$ $\quad$ (β) $\displaystyle\int_{-1}^{1} \frac{x}{x^2}\,dx$

> [!success]- Λύση
> (α) Το διάστημα $[-\frac{\pi}{2}, \frac{\pi}{2}]$ είναι συμμετρικό και η συνάρτηση συνεχής.
> - $x^3\cos x$ περιττή ⇒ ολοκλήρωμα $0$.
> - $x^2\sin x$ περιττή ⇒ ολοκλήρωμα $0$.
> - $2\cos x$ άρτια ⇒ $2\displaystyle\int_0^{\pi/2} 2\cos x\,dx = 4\big[\sin x\big]_0^{\pi/2} = 4$.
> (β) **Παγίδα:** $\frac{x}{x^2} = \frac{1}{x}$ είναι περιττή, **αλλά** είναι **μη φραγμένη** στο $[-1, 1]$ (άπειρη ασυνέχεια στο $0$). Άρα το ορισμένο ολοκλήρωμα Riemann **δεν υπάρχει** — **δεν** είναι $0$!

## Μέρος Δ — Θεμελιώδη Θεωρήματα (ΘΘΟΛ)

### Άσκηση 13

Βρες την παράγωγο ως προς $x$:
(α) $\displaystyle\frac{d}{dx}\int_x^5 \sqrt{1 + t^4}\,dt$ $\quad$ (β) $\displaystyle\frac{d}{dx}\int_1^{\sin x} \frac{dt}{1 + t^2}$ $\quad$ (γ) $\displaystyle\frac{d}{dx}\int_{x^2}^{e^x} \cos(t^2)\,dt$

> [!success]- Λύση
> (α) Αντιστροφή ορίων: $-\dfrac{d}{dx}\displaystyle\int_5^x \sqrt{1 + t^4}\,dt = -\sqrt{1 + x^4}$.
> (β) $\dfrac{1}{1 + \sin^2 x}\cdot\cos x = \dfrac{\cos x}{1 + \sin^2 x}$.
> (γ) $\cos(e^{2x})\cdot e^x - \cos(x^4)\cdot 2x$.

### Άσκηση 14 🪤

Βρες τη $F'(x)$ αν $\displaystyle F(x) = \int_0^x x\,e^{t^2}\,dt$.

> [!success]- Λύση
> **Παγίδα:** το $x$ βρίσκεται και **μέσα** στο ολοκλήρωμα! Επειδή ολοκληρώνουμε ως προς $t$, το $x$ είναι σταθερά και βγαίνει έξω:
> $$F(x) = x\int_0^x e^{t^2}\,dt$$
> Τώρα εφαρμόζουμε **κανόνα γινομένου** + 1ο ΘΘΟΛ:
> $$F'(x) = 1\cdot\int_0^x e^{t^2}\,dt + x\cdot e^{x^2} = \int_0^x e^{t^2}\,dt + x e^{x^2}$$

### Άσκηση 15 🪤

(α) Σε ποιο μέγιστο ανοικτό διάστημα η $\displaystyle F(x) = \int_1^x \frac{dt}{t^2 - 9}$ είναι παράγουσα της $f(x) = \frac{1}{x^2 - 9}$; Πού τέμνει το γράφημα της $F$ τον άξονα $x$;
(β) Υπολόγισε $\displaystyle\lim_{x\to 0}\frac{\int_0^{x^2} \cos(t^3)\,dt}{x^2}$.

> [!success]- Λύση
> (α) Η $f(t) = \frac{1}{t^2 - 9}$ είναι ασυνεχής στα $t = \pm 3$. Το μέγιστο ανοικτό διάστημα που περιέχει το κάτω όριο $a = 1$ χωρίς ασυνέχειες είναι το **$(-3, 3)$**.
> Τέμνει τον άξονα $x$ στο $x = 1$, γιατί $F(1) = \int_1^1 \frac{dt}{t^2 - 9} = 0$.
> (β) Μορφή $\frac{0}{0}$ (στο $x = 0$ ο αριθμητής είναι $\int_0^0 = 0$). Με L'Hôpital και 1ο ΘΘΟΛ:
> $$\lim_{x\to 0}\frac{\cos(x^6)\cdot 2x}{2x} = \lim_{x\to 0}\cos(x^6) = 1$$

### Άσκηση 16 🪤

Τι λάθος υπάρχει στους παρακάτω υπολογισμούς;
(α) $\displaystyle\int_{-1}^{1} \frac{1}{x^2}\,dx = \left[-\frac{1}{x}\right]_{-1}^{1} = -2$ $\quad$ (β) $\displaystyle\int_0^{\pi} \sec^2 x\,dx = \big[\tan x\big]_0^\pi = 0$

> [!success]- Λύση
> Και στα δύο παραβιάζεται η βασική υπόθεση του 2ου ΘΘΟΛ: **συνέχεια στο $[a, b]$**.
> (α) Η $\frac{1}{x^2}$ έχει άπειρη ασυνέχεια στο $x = 0 \in [-1, 1]$ (μη φραγμένη ⇒ μη ολοκληρώσιμη κατά Riemann· το γενικευμένο ολοκλήρωμα αποκλίνει στο $+\infty$).
> (β) Η $\sec^2 x = \frac{1}{\cos^2 x}$ έχει άπειρη ασυνέχεια στο $x = \frac{\pi}{2} \in [0, \pi]$ (επίσης μη φραγμένη ⇒ το 2ο ΘΘΟΛ δεν εφαρμόζεται).

### Άσκηση 17

Υπολόγισε:
(α) $\displaystyle\int_0^2 \lvert x^2 - 1\rvert\,dx$ $\quad$ (β) $\displaystyle\int_{-2}^3 f(x)\,dx$ όπου $f(x) = \begin{cases} x^2, & x < 0 \\ -x, & x \ge 0 \end{cases}$

> [!success]- Λύση
> (α) Στο $[0, 1]$: $x^2 - 1 \le 0$ ⇒ $\lvert x^2 - 1\rvert = 1 - x^2$. Στο $[1, 2]$: $x^2 - 1 \ge 0$ ⇒ $x^2 - 1$.
> $$\int_0^1 (1 - x^2)\,dx + \int_1^2 (x^2 - 1)\,dx = \left[x - \frac{x^3}{3}\right]_0^1 + \left[\frac{x^3}{3} - x\right]_1^2 = \frac{2}{3} + \left(\frac{2}{3} - \left(-\frac{2}{3}\right)\right) = 2$$
> (β) Χωρίζουμε στο $x = 0$:
> $$\int_{-2}^0 x^2\,dx + \int_0^3 (-x)\,dx = \left[\frac{x^3}{3}\right]_{-2}^0 + \left[-\frac{x^2}{2}\right]_0^3 = \frac{8}{3} - \frac{9}{2} = -\frac{11}{6}$$

### Άσκηση 18

Σώμα κινείται σε ευθεία με ταχύτητα $v(t) = 3t^2 - 12$ (m/s) για $t \in [0, 3]$. Βρες (α) τη **μετατόπιση** και (β) την **ολική διανυθείσα απόσταση**.

> [!success]- Λύση
> (α) Μετατόπιση: $\displaystyle\int_0^3 (3t^2 - 12)\,dt = \big[t^3 - 12t\big]_0^3 = 27 - 36 = -9\text{ m}$.
> (β) $v(t) = 3(t^2 - 4) = 0 \iff t = 2 \in [0, 3]$ ($v \le 0$ στο $[0, 2]$, $v \ge 0$ στο $[2, 3]$):
> $$\text{Απόσταση} = \int_0^2 (12 - 3t^2)\,dt + \int_2^3 (3t^2 - 12)\,dt = \big[12t - t^3\big]_0^2 + \big[t^3 - 12t\big]_2^3 = 16 + (-9 - (-16)) = 23\text{ m}$$

## Μέρος Ε — Μέση τιμή & Θ.Μ.Τ. για ολοκληρώματα

### Άσκηση 19

Βρες τη μέση τιμή $f_{\text{avg}}$ και **όλα** τα σημεία $c \in [a, b]$ του Θ.Μ.Τ. για:
(α) $f(x) = \dfrac{1}{x^2}$ στο $[1, 3]$ $\quad$ (β) $f(x) = \cos x$ στο $[0, \pi]$

### Άσκηση 21

(Βοήθημα 8.17) (α) Με την αντικατάσταση $u = a - x$, δείξε ότι για κάθε συνεχή $f$ με $f(x) + f(a - x) \ne 0$:
$$I = \int_0^a \frac{f(x)}{f(x) + f(a - x)}\,dx = \frac{a}{2}$$
(β) Υπολόγισε άμεσα τα $\displaystyle\int_0^3 \frac{\sqrt x}{\sqrt x + \sqrt{3 - x}}\,dx$ και $\displaystyle\int_0^{\pi/2} \frac{\sin x}{\sin x + \cos x}\,dx$.

> [!success]- Λύση
> (α) Θέτουμε $u = a - x \implies x = a - u,\ dx = -du$, όρια $0 \to a$ και $a \to 0$:
> $$I = \int_a^0 \frac{f(a - u)}{f(a - u) + f(u)}(-du) = \int_0^a \frac{f(a - x)}{f(x) + f(a - x)}\,dx$$
> Προσθέτουμε τις δύο εκφράσεις του $I$:
> $$2I = \int_0^a \frac{f(x) + f(a - x)}{f(x) + f(a - x)}\,dx = \int_0^a 1\,dx = a \implies I = \frac{a}{2} \quad \blacksquare$$
> (β) Εφαρμόζοντας το (α):
> - Με $a = 3,\ f(x) = \sqrt x$: $\dfrac{3}{2}$.
> - Με $a = \frac{\pi}{2},\ f(x) = \sin x$ (αφού $\sin(\frac{\pi}{2} - x) = \cos x$): $\dfrac{\pi}{4}$.

### Άσκηση 22 🪤

(Βοήθημα 8.32) Δείξε ότι η συνάρτηση
$$F(x) = \int_0^x \frac{dt}{1 + t^2} + \int_0^{1/x} \frac{dt}{1 + t^2}$$
είναι **σταθερή** στο $(0, +\infty)$ και βρες τη σταθερή της τιμή. Τι συμβαίνει στο $(-\infty, 0)$;

> [!success]- Λύση
> Παραγωγίζουμε με το 1ο ΘΘΟΛ και τον κανόνα αλυσίδας (για $x \ne 0$):
> $$F'(x) = \frac{1}{1 + x^2} + \frac{1}{1 + (1/x)^2}\cdot\left(-\frac{1}{x^2}\right) = \frac{1}{1 + x^2} - \frac{1}{x^2 + 1} = 0$$
> Επειδή το $(0, +\infty)$ είναι διάστημα, η $F$ είναι σταθερή εκεί:
> $$F(x) = F(1) = 2\int_0^1 \frac{dt}{1 + t^2} = 2\big[\tan^{-1}t\big]_0^1 = 2\cdot\frac{\pi}{4} = \frac{\pi}{2}$$
> **Παγίδα:** στο $(-\infty, 0)$ ισχύει επίσης $F'(x) = 0$, αλλά η σταθερά είναι **διαφορετική** (μη συνεκτικό πεδίο!): $F(-1) = 2\int_0^{-1} \frac{dt}{1 + t^2} = -\dfrac{\pi}{2}$! *(Αυτό αποδεικνύει τη γνωστή ταυτότητα $\tan^{-1}x + \tan^{-1}\frac{1}{x} = \pm\frac{\pi}{2}$.)*

### Άσκηση 23

(Βοήθημα 8.18) Δείξε ότι για κάθε $n \in \mathbb N^*$:
$$\int_0^{2\pi} \left\lvert \frac{\sin\pi x}{x^2 + n^2} \right\rvert dx \le \frac{2\pi}{n^2}$$

> [!success]- Λύση
> Για κάθε $x \in [0, 2\pi]$ ισχύει $\lvert\sin\pi x\rvert \le 1$ και $x^2 + n^2 \ge n^2 > 0$, οπότε:
> $$\left\lvert \frac{\sin\pi x}{x^2 + n^2} \right\rvert \le \frac{1}{n^2}$$
> Ολοκληρώνοντας από $0$ έως $2\pi$ (αφού $0 < 2\pi$):
> $$\int_0^{2\pi} \left\lvert \frac{\sin\pi x}{x^2 + n^2} \right\rvert dx \le \int_0^{2\pi} \frac{1}{n^2}\,dx = \frac{2\pi}{n^2} \quad \blacksquare$$
