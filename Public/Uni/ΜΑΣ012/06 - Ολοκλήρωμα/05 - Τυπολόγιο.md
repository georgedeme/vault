# 05 - Τυπολόγιο

Το Κεφάλαιο 6 σε μία σελίδα.

## 1. Αόριστο ολοκλήρωμα

$$\int f(x)\,dx = F(x) + C \iff F'(x) = f(x)$$

- **Αντίστροφες πράξεις:** $\dfrac{d}{dx}\left[\displaystyle\int f(x)\,dx\right] = f(x)$ · $\displaystyle\int F'(x)\,dx = F(x) + C$
- **Γραμμικότητα:** $\displaystyle\int [c_1 f + c_2 g]\,dx = c_1\int f\,dx + c_2\int g\,dx$
- **ΔΕΝ ισχύουν:** $\int fg \ne (\int f)(\int g)$ · $\int \frac{f}{g} \ne \frac{\int f}{\int g}$ · μεταβλητή **δεν** βγαίνει έξω
- **Παγίδα 🪤:** σε μη συνεκτικό πεδίο (π.χ. $1/x$ στο $(-\infty, 0) \cup (0, +\infty)$) οι σταθερές $C_1, C_2$ μπορεί να διαφέρουν

## 2. Πίνακας βασικών ολοκληρωμάτων (πάντα $+C$)

| $\int f(x)\,dx$ | Αποτέλεσμα | $\int f(x)\,dx$ | Αποτέλεσμα |
|---|---|---|---|
| $\int k\,dx$ | $kx$ | $\int x^n\,dx$ ($n \ne -1$) | $\dfrac{x^{n + 1}}{n + 1}$ |
| $\int \frac{1}{x}\,dx$ | $\ln\lvert x\rvert$ | $\int \sqrt x\,dx$ · $\int \frac{dx}{\sqrt x}$ | $\frac{2}{3}x^{3/2}$ · $2\sqrt x$ |
| $\int e^x\,dx$ | $e^x$ | $\int b^x\,dx$ ($b > 0, b \ne 1$) | $\dfrac{b^x}{\ln b}$ |
| $\int \sin x\,dx$ | $-\cos x$ | $\int \cos x\,dx$ | $\sin x$ |
| $\int \sec^2 x\,dx$ | $\tan x$ | $\int \csc^2 x\,dx$ | $-\cot x$ |
| $\int \sec x\tan x\,dx$ | $\sec x$ | $\int \csc x\cot x\,dx$ | $-\csc x$ |
| $\int \frac{dx}{\sqrt{1 - x^2}}$ | $\sin^{-1}x$ | $\int \frac{dx}{1 + x^2}$ | $\tan^{-1}x$ |
| $\int \frac{dx}{\lvert x\rvert\sqrt{x^2 - 1}}$ | $\sec^{-1}\lvert x\rvert$ | $\int \frac{dx}{\sqrt{x^2 + 1}}$ | $\sinh^{-1}x = \ln(x + \sqrt{x^2 + 1})$ |
| $\int \sinh x\,dx$ | $\cosh x$ | $\int \cosh x\,dx$ | $\sinh x$ |
| $\int \operatorname{sech}^2 x\,dx$ | $\tanh x$ | $\int \operatorname{csch}^2 x\,dx$ | $-\coth x$ |
| $\int \operatorname{sech}x\tanh x\,dx$ | $-\operatorname{sech}x$ | $\int \operatorname{csch}x\coth x\,dx$ | $-\operatorname{csch}x$ |

**Κλιμακώσεις ($a > 0$):** $\int f(ax + b)\,dx = \frac{1}{a}F(ax + b) + C$ · $\int \frac{dx}{\sqrt{a^2 - x^2}} = \sin^{-1}\!\left(\frac{x}{a}\right)$ · $\int \frac{dx}{a^2 + x^2} = \frac{1}{a}\tan^{-1}\!\left(\frac{x}{a}\right)$ · $\int \frac{dx}{x\sqrt{x^2 - a^2}} = \frac{1}{a}\sec^{-1}\!\left(\frac{\lvert x\rvert}{a}\right)$

## 3. Ορισμένο ολοκλήρωμα (Riemann) και αθροίσματα

$$\int_a^b f(x)\,dx = \lim_{\|P\| \to 0}\sum_{k = 1}^{n} f(x_k^*)\,\Delta x_k, \qquad \|P\| = \max_k \Delta x_k, \qquad L_n \le S_R^n \le U_n$$

- **Ολοκληρωσιμότητα:** συνεχής ⇒ ολοκληρώσιμη · φραγμένη με πεπερασμένες ασυνέχειες ⇒ ολοκληρώσιμη · **μη φραγμένη ⇒ ΜΗ ολοκληρώσιμη**
- **Εμβαδό:** $\int_a^b f = E_+ - E_-$ (**προσημασμένο**) · **ολικό εμβαδό** $= \int_a^b \lvert f\rvert = E_+ + E_-$
- **Τύποι $\Sigma$:** $\sum_{k=1}^n c = nc$ · $\sum k = \frac{n(n+1)}{2}$ · $\sum k^2 = \frac{n(n+1)(2n+1)}{6}$ · $\sum k^3 = \left[\frac{n(n+1)}{2}\right]^2$
- **Όριο αθροίσματος:** $\displaystyle\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^n f\!\left(\frac{k}{n}\right) = \int_0^1 f(x)\,dx$ · $\displaystyle\lim_{n\to\infty}\frac{b - a}{n}\sum_{k=1}^n f\!\left(a + k\frac{b - a}{n}\right) = \int_a^b f(x)\,dx$

## 4. Ιδιότητες ορισμένου ολοκληρώματος

| | |
|---|---|
| $\int_a^a f = 0$ | $\int_b^a f = -\int_a^b f$ |
| $\int_a^b f = \int_a^c f + \int_c^b f$ (κάθε $c$) | $\int_a^b [c_1 f + c_2 g] = c_1\int_a^b f + c_2\int_a^b g$ |
| $f \le g \implies \int_a^b f \le \int_a^b g$ ($a \le b$) | $m(b - a) \le \int_a^b f \le M(b - a)$ ($a \le b$) |
| $\left\lvert\int_a^b f\right\rvert \le \int_a^b \lvert f\rvert$ ($a \le b$) | Περιοδική ($T$): $\int_a^{a+T} f = \int_0^T f$ |
| Άρτια: $\int_{-a}^a f = 2\int_0^a f$ | Περιττή: $\int_{-a}^a f = 0$ (μόνο αν ολοκληρώσιμη!) |
| King's property: $\int_a^b f(x)\,dx = \int_a^b f(a + b - x)\,dx$ | Ειδικά: $\int_0^a \frac{f(x)}{f(x) + f(a - x)}\,dx = \frac{a}{2}$ |

## 5. Θεμελιώδη Θεωρήματα (ΘΘΟΛ)

- **1ο ΘΘΟΛ** ($f$ συνεχής στο $I$, $a \in I$): $\dfrac{d}{dx}\displaystyle\int_a^x f(t)\,dt = f(x)$
- **Με μεταβλητά όρια (Leibniz):** $\dfrac{d}{dx}\displaystyle\int_{g(x)}^{h(x)} f(t)\,dt = f(h(x))\,h'(x) - f(g(x))\,g'(x)$
- **2ο ΘΘΟΛ (Newton–Leibniz):** αν $f$ **συνεχής** στο $[a, b]$ και $F' = f$, τότε $\displaystyle\int_a^b f(x)\,dx = F(b) - F(a)$
- **Καθαρή μεταβολή:** $\displaystyle\int_a^b F'(t)\,dt = F(b) - F(a)$ (μετατόπιση $\int v$, ολική απόσταση $\int \lvert v\rvert$)

## 6. Θεώρημα Μέσης Τιμής για ολοκληρώματα

$$f_{\text{avg}} = \bar f = \frac{1}{b - a}\int_a^b f(x)\,dx, \qquad \exists c \in [a, b]:\ f(c) = f_{\text{avg}} \iff \int_a^b f(x)\,dx = f(c)(b - a)$$

- Απαιτεί **$f$ συνεχή** στο $[a, b]$ · $\int_a^b (f(x) - \bar f)\,dx = 0$ · **σταθμισμένο** ($g$ σταθερού προσήμου): $\int_a^b fg = f(c)\int_a^b g$

Κάθε συνηθισμένος τύπος άσκησης του κεφαλαίου, με τα βήματα σε συντομία. Στη στήλη «Π.χ.»: Ασκ. = [[Uni/ΜΑΣ012/06 - Ολοκλήρωμα/06 - Ασκήσεις|06 - Ασκήσεις]]. 🪤 = συνηθισμένη παγίδα.

> [!tip] Πριν ολοκληρώσεις
> Απλοποίησε πρώτα: δυνάμεις, άνοιγμα γινομένων, χωρισμός αριθμητή, τριγωνομετρικές ταυτότητες ($\tan^2 x = \sec^2 x - 1$). Για ορισμένο ολοκλήρωμα, έλεγξε **συνέχεια στο $[a, b]$** και **συμμετρία** πριν κάνεις πράξεις!

### Αόριστο ολοκλήρωμα & Π.Α.Τ.

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| Βασικό ολοκλήρωμα με αναδιάταξη | δυνάμεις / χωρισμός κλάσματος / $\tan^2 = \sec^2 - 1$ → πίνακας → $+C$ · έλεγχος με παραγώγιση | Ασκ. 1–3 |
| Δίνεται $\int f(x)\,dx = G(x) + C$, ζητείται $f$ | παραγώγισε το $G(x)$ | Ασκ. 4α |
| Πρόβλημα αρχικών τιμών ($f'$ και $f(x_0) = y_0$) | ολοκλήρωσε ($+C$) → αντικατάστησε $(x_0, y_0)$ → βρες $C$ (για $f''$: δύο φορές, $C_1, C_2$) | Ασκ. 5 |
| Απλή χωριζόμενη Δ.Ε. | χώρισε $g(y)\,dy = h(x)\,dx$ → ολοκλήρωσε → 🪤 έλεγξε χωριστά τις σταθερές λύσεις που χάθηκαν στη διαίρεση ($g(y) = 0$) | Ασκ. 6 |

### Αθροίσματα Riemann & ιδιότητες

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| Κάτω/άνω άθροισμα $L_n, U_n$ | βρες $\Delta x_k$ → σε κάθε υποδιάστημα βρες $\min f$ και $\max f$ (εύκολο αν $f$ μονότονη) → άθροισε | Ασκ. 7 |
| Υπολογισμός με γεωμετρία | σχεδίασε → τρίγωνα, τραπέζια, ημικύκλιο → 🪤 πρόσημο κάτω από τον άξονα $x$ | Ασκ. 8 |
| Όριο αθροίσματος ως ολοκλήρωμα | βγάλε $\frac{1}{n}$ έξω → γράψε ως συνάρτηση του $\frac{k}{n}$ → όρια $\lim\frac{k_{\min}}{n}$ έως $\lim\frac{k_{\max}}{n}$ · 🪤 προσοχή στο $2n$ | Ασκ. 9, 10 |
| Απόδειξη ανισότητας / φράγματα | σύγκρινε $f(x) \le g(x)$ στο $[a, b]$ (ή $m \le f \le M$, ή $\lvert\int f\rvert \le \int\lvert f\rvert$) → ολοκλήρωσε · 🪤 μόνο για $a \le b$ | Ασκ. 11, 23 |
| Συμμετρία στο $[-a, a]$ | έλεγξε $f(-x)$: περιττή ⇒ $0$, άρτια ⇒ $2\int_0^a$ · 🪤 πρώτα έλεγξε ότι είναι ολοκληρώσιμη! | Ασκ. 12 |
| Ανάκλαση $u = a - x$ (King's property) | γράψε $I = \int_0^a f(a - x)\,dx$ → πρόσθεσε $2I$ → απλοποιείται | Ασκ. 21 |

### Θεμελιώδη Θεωρήματα & Θ.Μ.Τ.

| Τύπος | Βήματα | Π.χ. |
|---|---|---|
| Παραγώγιση $\int_{g(x)}^{h(x)} f(t)\,dt$ | $f(h(x))h'(x) - f(g(x))g'(x)$ · 🪤 κάτω όριο με μείον · 🪤 αν υπάρχει $x$ μέσα, βγάλ' το έξω (κανόνας γινομένου) | Ασκ. 13, 14 |
| Πεδίο παράγουσας $\int_a^x f(t)\,dt$ | βρες τις ασυνέχειες της $f$ → πάρε το μέγιστο ανοικτό διάστημα που περιέχει το $a$ | Ασκ. 15α |
| Όριο με $\int_a^{h(x)} f(t)\,dt$ | έλεγξε μορφή $\frac{0}{0}$ → L'Hôpital + 1ο ΘΘΟΛ | Ασκ. 15β |
| Ορισμένο με ασυνέχεια / απόλυτη / κλαδική | έλεγξε άπειρες ασυνέχειες (🪤 αν υπάρχει μέσα στο $[a, b]$, το 2ο ΘΘΟΛ αποτυγχάνει!) · για άλμα ή $\lvert\cdot\rvert$: χώρισε το διάστημα | Ασκ. 16, 17 |
| Μετατόπιση vs ολική απόσταση | μετατόπιση $= \int_a^b v(t)\,dt$ · απόσταση $= \int_a^b \lvert v(t)\rvert\,dt$ (βρες ρίζες της $v$) | Ασκ. 18 |
| Μέση τιμή & σημείο $c$ του Θ.Μ.Τ. | $\bar f = \frac{1}{b-a}\int_a^b f$ → λύσε $f(c) = \bar f$ → κράτα **μόνο** τα $c \in [a, b]$ · 🪤 όχι $\frac{f(a)+f(b)}{2}$ | Ασκ. 19, 20 |
| Απόδειξη ότι $F(x)$ είναι σταθερή | δείξε $F'(x) = 0$ σε **διάστημα** (με 1ο ΘΘΟΛ) → βρες την τιμή σε ένα βολικό $x_0$ | Ασκ. 22 |
