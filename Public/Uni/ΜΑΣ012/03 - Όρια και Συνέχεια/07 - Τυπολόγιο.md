# 07 - Τυπολόγιο

Το Κεφάλαιο 3 σε μία σελίδα.

## 1. Όριο

- $\lim_{x \to a} f(x)$ **δεν** εξαρτάται από το $f(a)$
- $\lim_{x\to a} f = L \iff \lim_{x\to a^-} f = \lim_{x\to a^+} f = L$
- Δεν υπάρχει όριο: άλμα · απειρισμός · ταλάντωση ($\sin\frac1x$)
- Κατακόρυφη ασύμπτωτη $x = a$: κάποιο πλευρικό όριο $= \pm\infty$
- Βοήθημα: «υπάρχει» = πεπερασμένο · $+\infty$ = «απειρίζεται θετικά» (το όριο **δεν** υπάρχει) · το όριο είναι **μοναδικό**

## 2. Υπολογισμός

| Αντικατάσταση δίνει | Κάνε |
|---|---|
| $k/m$, $m \neq 0$ | τέλος |
| $k/0$, $k \neq 0$ | πρόσημο από κάθε πλευρά ⇒ $\pm\infty$ |
| $0/0$ | παραγοντοποίηση · συζυγής · ομώνυμα |

- Κανόνες ορίων (άθροισμα, γινόμενο, πηλίκο με $L_2 \ne 0$) **μόνο αν τα επιμέρους όρια υπάρχουν**
- Απόλυτες τιμές, κλαδικές: **πλευρικά όρια**
- $L + \infty = \infty$ · $L\cdot\infty = \pm\infty$ αν $L \gtrless 0$ · $0\cdot\infty$ απροσδιοριστία · $\frac{L}{\infty} = 0$
- $\displaystyle\lim_{x\to1}\frac{x^m - 1}{x - 1} = m$ · πολυώνυμο με ρίζα $a$ ⇒ Horner με το $a$
- Μετά την απλοποίηση: ο $(x - a)$ φεύγει ⇒ **τρύπα** · μένει στον παρονομαστή ⇒ **ασύμπτωτη**

## 3. Στο άπειρο

- $\frac{1}{x^n} \to 0$ · πολυώνυμο ~ μεγιστοβάθμιος όρος
- Ρητή: $\deg p < \deg q \Rightarrow 0$ · $\deg p = \deg q \Rightarrow$ λόγος συντελεστών · $\deg p > \deg q \Rightarrow \pm\infty$ · ενιαία: $\frac{c_n}{d_m}\lim x^{n - m}$
- $\sqrt{x^2 + ax} - x \to \frac a2$ ($x \to +\infty$) · στο $-\infty$ το ίδιο $\to +\infty$ (όχι απροσδιοριστία)
- $x \to -\infty$: $\sqrt{x^2} = -x$
- $\infty - \infty$ με ρίζες: **συζυγής**
- Απροσδιόριστες: $\frac00$, $\frac\infty\infty$, $\infty - \infty$, $0\cdot\infty$, $1^\infty$, $0^0$, $\infty^0$

## 4. Ορισμός $\varepsilon$–$\delta$

$$\forall\varepsilon > 0\ \exists\delta > 0:\ 0 < \lvert x - a\rvert < \delta \Rightarrow \lvert f(x) - L\rvert < \varepsilon$$

- Γραμμική $mx + b$: $\delta = \varepsilon/\lvert m\rvert$
- Μη γραμμική: περιόρισε $\delta \le 1$, φράξε τον παράγοντα, $\delta = \min\{1, \varepsilon/C\}$
- Στο άπειρο: $\forall\varepsilon\ \exists N: x > N \Rightarrow \lvert f(x) - L\rvert < \varepsilon$ · άπειρο όριο: $\forall M\ \exists\delta: \ldots \Rightarrow f(x) > M$
- Ρίζα: $\lvert\sqrt x - \sqrt a\rvert = \frac{\lvert x - a\rvert}{\sqrt x + \sqrt a} \le \frac{\lvert x - a\rvert}{\sqrt a}$ · συγκεκριμένο $\varepsilon$: λύσε την ανίσωση, $\delta$ = **μικρότερη** απόσταση
- Βοήθημα Ορ. 3.3.1: λείπει το $0 <$· γράφε πάντα $0 < \lvert x - a\rvert < \delta$

## 5. Συνέχεια

- Συνεχής στο $c$: $f(c)$ ορίζεται · $\lim_{x\to c} f$ υπάρχει · **είναι ίσα**
- Ασυνέχειες: άρσιμη (όριο υπάρχει) · άλμα · άπειρη · ταλάντωση
- Βοήθημα: **πρώτου είδους** (πλευρικά υπάρχουν): διορθώσιμη ή πεπερασμένο πήδημα $\lvert L^- - L^+\rvert$ · **δευτέρου είδους**: κάποιο πλευρικό δεν υπάρχει
- Βοήθημα: σημεία εκτός πεδίου (π.χ. ρίζες παρονομαστή) **μετράνε** ως σημεία ασυνέχειας
- Συνεχής στο $c$ ⇔ αριστερά **και** δεξιά συνεχής · ισοδύναμα $\lim_{h\to0}f(c + h) = f(c)$
- $\lim f(g(x)) = f(\lim g(x))$ αν η $f$ συνεχής στο $\lim g$
- **ΘΕΤ:** $f$ συνεχής στο $[a, b]$, $k$ ανάμεσα στα $f(a), f(b)$ ⇒ $\exists c: f(c) = k$
- **Bolzano:** $f(a)f(b) < 0$ ⇒ ρίζα στο $(a, b)$ · χρειάζεται **συνέχεια** · ρητή με πόλους στα άκρα: πρώτα ομώνυμα

## 6. Βασικά όρια

| | |
|---|---|
| $\displaystyle\lim_{x\to0}\frac{\sin x}{x} = 1$ | $\displaystyle\lim_{x\to0}\frac{1 - \cos x}{x} = 0$ |
| $\displaystyle\lim_{x\to0}\frac{\sin kx}{x} = k$ | $\displaystyle\lim_{x\to0}\frac{1 - \cos x}{x^2} = \frac12$ |
| $\displaystyle\lim_{x\to\infty}\frac{\sin x}{x} = 0$ | $\displaystyle\lim_{x\to0}\frac{\tan x}{x} = 1$ |
| $\displaystyle\lim_{x\to\pm\infty}\left(1 + \frac kx\right)^x = e^k$ | $\displaystyle\lim_{x\to0}(1 + x)^{1/x} = e$ |
| $e^x$: $\to +\infty$ ($x\to+\infty$), $\to 0$ ($x\to-\infty$) | $\ln x$: $\to +\infty$ ($x\to+\infty$), $\to -\infty$ ($x\to0^+$) |
| $\tan^{-1}x \to \pm\frac\pi2$ ($x \to \pm\infty$) | $\tanh x \to \pm1$ ($x \to \pm\infty$) |

- **Κριτήριο παρεμβολής:** $g \le f \le h$, $g, h \to L$ ⇒ $f \to L$ · φραγμένη × (→0) = →0
- $f \le g$ ⇒ $\lim f \le \lim g$ · από $f < g$ **μόνο** $\le$
- Αλλαγή μεταβλητής: $t$ = αυτό που πάει στο $0$ (π.χ. $t = \pi - x$, $t = \frac1x$)
- $\ln x \ll x^n \ll e^x$ ($x \to +\infty$) · $x^n\ln x \to 0$ ($x \to 0^+$) · $\ln x < \sqrt x$
