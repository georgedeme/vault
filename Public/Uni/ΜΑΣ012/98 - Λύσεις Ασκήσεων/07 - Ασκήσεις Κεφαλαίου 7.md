# 07 - Ασκήσεις Κεφαλαίου 7

Αναλυτικές λύσεις για όλες τις ασκήσεις του φυλλαδίου [[Uni/ΜΑΣ012/99 - Material/Ασκήσεις Κεφαλαίου 7.pdf|Ασκήσεις Κεφαλαίου 7]] (Κεφάλαιο 7 — Αόριστο Ολοκλήρωμα, μέθοδος αντικατάστασης, αρχικές συναρτήσεις με αρχική συνθήκη και απλές διαφορικές εξισώσεις χωριζομένων μεταβλητών).

> [!tip] Πώς να το χρησιμοποιήσεις
> Προσπάθησε πρώτα να υπολογίσεις κάθε ολοκλήρωμα μόνος σου και έλεγξε το αποτέλεσμά σου παραγωγίζοντάς το — αυτή είναι η πιο αξιόπιστη επαλήθευση στον ολοκληρωτικό λογισμό. Άνοιξε το αντίστοιχο `Λύση` μόνο για επιβεβαίωση ή αν κολλήσεις.

## Άσκηση 1

Να βρεθούν τα παρακάτω ολοκληρώματα και να επαληθευτούν με παραγώγιση:
- **(α)** $\displaystyle\int x^2\,dx$.
- **(β)** $\displaystyle\int \sqrt[3]{x^2}\,dx$.
- **(γ)** $\displaystyle\int \dfrac{dx}{2x^3}$.
- **(δ)** $\displaystyle\int (u^3 - 2u + 7)\,du$.
- **(ε)** $\displaystyle\int \left(x^{-3} + \sqrt{x} - 3x^{1/4} + x^2\right)\,dx$.
- **(στ)** $\displaystyle\int (1 + x^2)(2 - x)\,dx$.
- **(ζ)** $\displaystyle\int \dfrac{x^5 + 2x^2 - 1}{x^4}\,dx$.
- **(η)** $\displaystyle\int \dfrac{\sin x}{\cos^2 x}\,dx$.
- **(θ)** $\displaystyle\int \left(\varphi + \dfrac{2}{\sin^2\varphi}\right)\,d\varphi$.
- **(ι)** $\displaystyle\int \dfrac{x^2\sin x + 2\sin x}{2 + x^2}\,dx$.

> [!success]- Λύση (α)
> $$\int x^2\,dx = \boxed{\dfrac{x^3}{3} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(\dfrac{x^3}{3} + C\right) = \dfrac{3x^2}{3} = x^2$ ✓.

> [!success]- Λύση (β)
> $$\int \sqrt[3]{x^2}\,dx = \int x^{2/3}\,dx = \dfrac{x^{2/3 + 1}}{2/3 + 1} + C = \boxed{\dfrac{3}{5}x^{5/3} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(\dfrac{3}{5}x^{5/3} + C\right) = \dfrac{3}{5}\cdot\dfrac{5}{3}x^{2/3} = \sqrt[3]{x^2}$ ✓.

> [!success]- Λύση (γ)
> $$\int \dfrac{dx}{2x^3} = \dfrac{1}{2}\int x^{-3}\,dx = \dfrac{1}{2}\cdot\dfrac{x^{-2}}{-2} + C = \boxed{-\dfrac{1}{4x^2} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(-\dfrac{1}{4}x^{-2} + C\right) = -\dfrac{1}{4}(-2)x^{-3} = \dfrac{1}{2x^3}$ ✓.

> [!success]- Λύση (δ)
> $$\int (u^3 - 2u + 7)\,du = \boxed{\dfrac{u^4}{4} - u^2 + 7u + C}.$$
> *Επαλήθευση:* $\dfrac{d}{du}\left(\dfrac{u^4}{4} - u^2 + 7u + C\right) = u^3 - 2u + 7$ ✓.

> [!success]- Λύση (ε)
> $$\int \left(x^{-3} + x^{1/2} - 3x^{1/4} + x^2\right)\,dx = \dfrac{x^{-2}}{-2} + \dfrac{x^{3/2}}{3/2} - 3\cdot\dfrac{x^{5/4}}{5/4} + \dfrac{x^3}{3} + C = \boxed{-\dfrac{1}{2x^2} + \dfrac{2}{3}x^{3/2} - \dfrac{12}{5}x^{5/4} + \dfrac{x^3}{3} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(-\dfrac{1}{2}x^{-2} + \dfrac{2}{3}x^{3/2} - \dfrac{12}{5}x^{5/4} + \dfrac{x^3}{3} + C\right) = x^{-3} + x^{1/2} - 3x^{1/4} + x^2$ ✓.

> [!success]- Λύση (στ)
> Πολλαπλασιάζουμε πρώτα τους παράγοντες: $(1 + x^2)(2 - x) = 2 - x + 2x^2 - x^3$.
> $$\int (2 - x + 2x^2 - x^3)\,dx = \boxed{2x - \dfrac{x^2}{2} + \dfrac{2x^3}{3} - \dfrac{x^4}{4} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(2x - \dfrac{x^2}{2} + \dfrac{2x^3}{3} - \dfrac{x^4}{4} + C\right) = 2 - x + 2x^2 - x^3 = (1 + x^2)(2 - x)$ ✓.
>
> 🪤 **Παγίδα:** Το ολοκλήρωμα γινομένου **δεν** είναι το γινόμενο των ολοκληρωμάτων! Πάντα αναπτύσσουμε το γινόμενο πολυωνύμων πριν ολοκληρώσουμε.

> [!success]- Λύση (ζ)
> Χωρίζουμε το κλάσμα σε άθροισμα δυνάμεων του $x$:
> $$\int \dfrac{x^5 + 2x^2 - 1}{x^4}\,dx = \int \left(x + 2x^{-2} - x^{-4}\right)\,dx = \dfrac{x^2}{2} + 2\cdot\dfrac{x^{-1}}{-1} - \dfrac{x^{-3}}{-3} + C = \boxed{\dfrac{x^2}{2} - \dfrac{2}{x} + \dfrac{1}{3x^3} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(\dfrac{x^2}{2} - 2x^{-1} + \dfrac{1}{3}x^{-3} + C\right) = x + 2x^{-2} - x^{-4} = \dfrac{x^5 + 2x^2 - 1}{x^4}$ ✓.

> [!success]- Λύση (η)
> Γράφουμε $\dfrac{\sin x}{\cos^2 x} = \dfrac{1}{\cos x}\cdot\dfrac{\sin x}{\cos x} = \sec x\tan x$:
> $$\int \dfrac{\sin x}{\cos^2 x}\,dx = \int \sec x\tan x\,dx = \boxed{\sec x + C = \dfrac{1}{\cos x} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left((\cos x)^{-1} + C\right) = -(\cos x)^{-2}(-\sin x) = \dfrac{\sin x}{\cos^2 x}$ ✓.

> [!success]- Λύση (θ)
> Επειδή $(\cot\varphi)' = -\dfrac{1}{\sin^2\varphi}$:
> $$\int \left(\varphi + \dfrac{2}{\sin^2\varphi}\right)\,d\varphi = \boxed{\dfrac{\varphi^2}{2} - 2\cot\varphi + C}.$$
> *Επαλήθευση:* $\dfrac{d}{d\varphi}\left(\dfrac{\varphi^2}{2} - 2\cot\varphi + C\right) = \varphi - 2\left(-\dfrac{1}{\sin^2\varphi}\right) = \varphi + \dfrac{2}{\sin^2\varphi}$ ✓.

> [!success]- Λύση (ι)
> Παραγοντοποιούμε τον αριθμητή (και σημειώνουμε ότι $2 + x^2 > 0$ για κάθε $x \in \mathbb{R}$):
> $$\int \dfrac{x^2\sin x + 2\sin x}{2 + x^2}\,dx = \int \dfrac{(x^2 + 2)\sin x}{2 + x^2}\,dx = \int \sin x\,dx = \boxed{-\cos x + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}(-\cos x + C) = \sin x = \dfrac{(x^2 + 2)\sin x}{2 + x^2}$ ✓.

## Άσκηση 2

Να βρεθεί η $g(t)$ αν:
- **(α)** $\displaystyle\int g(t)\,dt = 5t^3 - 3t + C$.
- **(β)** $\displaystyle\int g(t)\,dt = \dfrac{1}{\sqrt{4 - t^2}} + C$.

> [!success]- Λύση (α)
> Από τον ορισμό του αόριστου ολοκληρώματος, η $g(t)$ είναι η παράγωγος του δεξιού μέλους:
> $$g(t) = \dfrac{d}{dt}\left(5t^3 - 3t + C\right) = \boxed{15t^2 - 3}.$$

> [!success]- Λύση (β)
> Παραγωγίζουμε το δεξί μέλος (για $\lvert t\rvert < 2$):
> $$g(t) = \dfrac{d}{dt}\left((4 - t^2)^{-1/2} + C\right) = -\dfrac{1}{2}(4 - t^2)^{-3/2}(-2t) = \boxed{\dfrac{t}{(4 - t^2)^{3/2}}}.$$

## Άσκηση 3

Να υπολογιστούν τα ολοκληρώματα:
- **(α)** $\displaystyle\int \tan^2 x\,dx$.
- **(β)** $\displaystyle\int \cot^2 x\,dx$.

> [!success]- Λύση (α)
> Χρησιμοποιούμε τη βασική τριγωνομετρική ταυτότητα $\tan^2 x = \sec^2 x - 1$:
> $$\int \tan^2 x\,dx = \int (\sec^2 x - 1)\,dx = \boxed{\tan x - x + C}.$$
> *Επαλήθευση:* $(\tan x - x + C)' = \sec^2 x - 1 = \tan^2 x$ ✓.

> [!success]- Λύση (β)
> Χρησιμοποιούμε την ταυτότητα $\cot^2 x = \csc^2 x - 1 = \dfrac{1}{\sin^2 x} - 1$:
> $$\int \cot^2 x\,dx = \int \left(\dfrac{1}{\sin^2 x} - 1\right)\,dx = \boxed{-\cot x - x + C}.$$
> *Επαλήθευση:* $(-\cot x - x + C)' = \dfrac{1}{\sin^2 x} - 1 = \cot^2 x$ ✓.

## Άσκηση 4

Να υπολογιστούν τα παρακάτω ολοκληρώματα κάνοντας την αντίστοιχη αντικατάσταση:
- **(α)** $\displaystyle\int 2x(x^2 + 1)^{23}\,dx, \quad u = x^2 + 1$.
- **(β)** $\displaystyle\int \dfrac{3x}{\sqrt{4x^2 + 5}}\,dx, \quad u = 4x^2 + 5$.
- **(γ)** $\displaystyle\int (1 + \sin t)^9\cos t\,dt, \quad u = 1 + \sin t$.

> [!success]- Λύση (α)
> Θέτουμε $u = x^2 + 1 \implies du = 2x\,dx$:
> $$\int 2x(x^2 + 1)^{23}\,dx = \int u^{23}\,du = \dfrac{u^{24}}{24} + C = \boxed{\dfrac{(x^2 + 1)^{24}}{24} + C}.$$

> [!success]- Λύση (β)
> Θέτουμε $u = 4x^2 + 5 \implies du = 8x\,dx \implies x\,dx = \dfrac{du}{8}$:
> $$\int \dfrac{3x}{\sqrt{4x^2 + 5}}\,dx = \dfrac{3}{8}\int u^{-1/2}\,du = \dfrac{3}{8}\cdot 2u^{1/2} + C = \boxed{\dfrac{3}{4}\sqrt{4x^2 + 5} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(\dfrac{3}{4}(4x^2 + 5)^{1/2}\right) = \dfrac{3}{4}\cdot\dfrac{8x}{2\sqrt{4x^2 + 5}} = \dfrac{3x}{\sqrt{4x^2 + 5}}$ ✓.

> [!success]- Λύση (γ)
> Θέτουμε $u = 1 + \sin t \implies du = \cos t\,dt$:
> $$\int (1 + \sin t)^9\cos t\,dt = \int u^9\,du = \dfrac{u^{10}}{10} + C = \boxed{\dfrac{(1 + \sin t)^{10}}{10} + C}.$$

## Άσκηση 5

Να υπολογιστούν τα παρακάτω ολοκληρώματα:
- **(α)** $\displaystyle\int (3x - 1)^5\,dx$.
- **(β)** $\displaystyle\int \cos(8x)\,dx$.
- **(γ)** $\displaystyle\int \dfrac{x^2}{\sqrt{x^3 + 1}}\,dx$.
- **(δ)** $\displaystyle\int \dfrac{\sin(5/x)}{x^2}\,dx$.
- **(ε)** $\displaystyle\int \dfrac{\sin(2\theta)}{(5 + \cos(2\theta))^3}\,d\theta$.
- **(στ)** $\displaystyle\int \sin(\sin\theta)\cos\theta\,d\theta$.
- **(ζ)** $\displaystyle\int \sqrt[n]{ax + b}\,dx, \quad a \neq 0$.
- **(η)** $\displaystyle\int \sec^2(\cos(3\theta))\sin(3\theta)\,d\theta$.

> [!success]- Λύση (α)
> Θέτουμε $u = 3x - 1 \implies du = 3\,dx \implies dx = \dfrac{du}{3}$:
> $$\int (3x - 1)^5\,dx = \dfrac{1}{3}\int u^5\,du = \dfrac{u^6}{18} + C = \boxed{\dfrac{(3x - 1)^6}{18} + C}.$$

> [!success]- Λύση (β)
> Θέτουμε $u = 8x \implies dx = \dfrac{du}{8}$:
> $$\int \cos(8x)\,dx = \dfrac{1}{8}\int \cos u\,du = \boxed{\dfrac{\sin(8x)}{8} + C}.$$

> [!success]- Λύση (γ)
> Θέτουμε $u = x^3 + 1 \implies du = 3x^2\,dx \implies x^2\,dx = \dfrac{du}{3}$:
> $$\int \dfrac{x^2}{\sqrt{x^3 + 1}}\,dx = \dfrac{1}{3}\int u^{-1/2}\,du = \dfrac{2}{3}u^{1/2} + C = \boxed{\dfrac{2}{3}\sqrt{x^3 + 1} + C}.$$

> [!success]- Λύση (δ)
> Θέτουμε $u = \dfrac{5}{x} \implies du = -\dfrac{5}{x^2}\,dx \implies \dfrac{dx}{x^2} = -\dfrac{du}{5}$:
> $$\int \dfrac{\sin(5/x)}{x^2}\,dx = -\dfrac{1}{5}\int \sin u\,du = \dfrac{1}{5}\cos u + C = \boxed{\dfrac{1}{5}\cos\!\left(\dfrac{5}{x}\right) + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(\dfrac{1}{5}\cos\dfrac{5}{x}\right) = \dfrac{1}{5}\left(-\sin\dfrac{5}{x}\right)\left(-\dfrac{5}{x^2}\right) = \dfrac{\sin(5/x)}{x^2}$ ✓.

> [!success]- Λύση (ε)
> Θέτουμε $u = 5 + \cos(2\theta) \implies du = -2\sin(2\theta)\,d\theta \implies \sin(2\theta)\,d\theta = -\dfrac{du}{2}$:
> $$\int \dfrac{\sin(2\theta)}{(5 + \cos(2\theta))^3}\,d\theta = -\dfrac{1}{2}\int u^{-3}\,du = -\dfrac{1}{2}\cdot\dfrac{u^{-2}}{-2} + C = \boxed{\dfrac{1}{4(5 + \cos(2\theta))^2} + C}.$$

> [!success]- Λύση (στ)
> Θέτουμε $u = \sin\theta \implies du = \cos\theta\,d\theta$:
> $$\int \sin(\sin\theta)\cos\theta\,d\theta = \int \sin u\,du = -\cos u + C = \boxed{-\cos(\sin\theta) + C}.$$

> [!success]- Λύση (ζ)
> Θέτουμε $u = ax + b \implies du = a\,dx \implies dx = \dfrac{du}{a}$ (με $a \neq 0$):
> $$\int \sqrt[n]{ax + b}\,dx = \dfrac{1}{a}\int u^{1/n}\,du = \dfrac{1}{a}\cdot\dfrac{u^{\frac{1}{n} + 1}}{\frac{1}{n} + 1} + C = \boxed{\dfrac{n}{a(n + 1)}(ax + b)^{\frac{n + 1}{n}} + C}.$$

> [!success]- Λύση (η)
> Θέτουμε $u = \cos(3\theta) \implies du = -3\sin(3\theta)\,d\theta \implies \sin(3\theta)\,d\theta = -\dfrac{du}{3}$:
> $$\int \sec^2(\cos(3\theta))\sin(3\theta)\,d\theta = -\dfrac{1}{3}\int \sec^2 u\,du = -\dfrac{1}{3}\tan u + C = \boxed{-\dfrac{1}{3}\tan(\cos(3\theta)) + C}.$$
> *Επαλήθευση:* $\dfrac{d}{d\theta}\left(-\dfrac{1}{3}\tan(\cos 3\theta)\right) = -\dfrac{1}{3}\sec^2(\cos 3\theta)\cdot(-3\sin 3\theta) = \sec^2(\cos(3\theta))\sin(3\theta)$ ✓.

## Άσκηση 6

Να υπολογιστούν τα παρακάτω ολοκληρώματα:
- **(α)** $\displaystyle\int (4x^2 - 12x + 9)^{2/3}\,dx$.
- **(β)** $\displaystyle\int x\sqrt{x - 3}\,dx$.
- **(γ)** $\displaystyle\int x^2\sqrt{2 - x}\,dx$.
- **(δ)** $\displaystyle\int \dfrac{y}{\sqrt{y + 1}}\,dy$.
- **(ε)** $\displaystyle\int \sin^3(2\theta)\,d\theta$.
- **(στ)** $\displaystyle\int \tan^2(3\theta)\,d\theta$.
- **(ζ)** $\displaystyle\int \sqrt{1 + x^{-2/3}}\,dx, \quad x > 0$.
- **(η)** $\displaystyle\int \tan^3(5x)\sec^2(5x)\,dx$.

> [!success]- Λύση (α)
> Παρατηρούμε ότι το τριώνυμο είναι τέλειο τετράγωνο: $4x^2 - 12x + 9 = (2x - 3)^2$.
> Άρα $(4x^2 - 12x + 9)^{2/3} = \bigl((2x - 3)^2\bigr)^{2/3} = (2x - 3)^{4/3}$.
> Θέτουμε $u = 2x - 3 \implies dx = \dfrac{du}{2}$:
> $$\int (2x - 3)^{4/3}\,dx = \dfrac{1}{2}\int u^{4/3}\,du = \dfrac{1}{2}\cdot\dfrac{3}{7}u^{7/3} + C = \boxed{\dfrac{3}{14}(2x - 3)^{7/3} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}\left(\dfrac{3}{14}(2x - 3)^{7/3}\right) = \dfrac{3}{14}\cdot\dfrac{7}{3}(2x - 3)^{4/3}\cdot 2 = (2x - 3)^{4/3} = (4x^2 - 12x + 9)^{2/3}$ για κάθε $x \in \mathbb{R}$ ✓.

> [!success]- Λύση (β)
> Θέτουμε $u = x - 3 \implies x = u + 3$ και $dx = du$:
> $$\int x\sqrt{x - 3}\,dx = \int (u + 3)u^{1/2}\,du = \int \left(u^{3/2} + 3u^{1/2}\right)\,du = \dfrac{2}{5}u^{5/2} + 2u^{3/2} + C = \boxed{\dfrac{2}{5}(x - 3)^{5/2} + 2(x - 3)^{3/2} + C}.$$

> [!success]- Λύση (γ)
> Θέτουμε $u = 2 - x \implies x = 2 - u$ και $dx = -du$:
> $$\int x^2\sqrt{2 - x}\,dx = -\int (2 - u)^2 u^{1/2}\,du = -\int \left(4u^{1/2} - 4u^{3/2} + u^{5/2}\right)\,du$$
> $$= -\left(\dfrac{8}{3}u^{3/2} - \dfrac{8}{5}u^{5/2} + \dfrac{2}{7}u^{7/2}\right) + C = \boxed{-\dfrac{8}{3}(2 - x)^{3/2} + \dfrac{8}{5}(2 - x)^{5/2} - \dfrac{2}{7}(2 - x)^{7/2} + C}.$$
> *Επαλήθευση:* Παραγωγίζοντας: $4(2-x)^{1/2} - 4(2-x)^{3/2} + (2-x)^{5/2} = (2-x)^{1/2}\bigl[4 - 4(2-x) + (2-x)^2\bigr] = x^2\sqrt{2-x}$ ✓.

> [!success]- Λύση (δ)
> Θέτουμε $u = y + 1 \implies y = u - 1$ και $dy = du$:
> $$\int \dfrac{y}{\sqrt{y + 1}}\,dy = \int \dfrac{u - 1}{u^{1/2}}\,du = \int \left(u^{1/2} - u^{-1/2}\right)\,du = \dfrac{2}{3}u^{3/2} - 2u^{1/2} + C = \boxed{\dfrac{2}{3}(y + 1)^{3/2} - 2\sqrt{y + 1} + C}.$$

> [!success]- Λύση (ε)
> Γράφουμε $\sin^3(2\theta) = \sin^2(2\theta)\sin(2\theta) = \bigl(1 - \cos^2(2\theta)\bigr)\sin(2\theta)$.
> Θέτουμε $u = \cos(2\theta) \implies du = -2\sin(2\theta)\,d\theta \implies \sin(2\theta)\,d\theta = -\dfrac{du}{2}$:
> $$\int \sin^3(2\theta)\,d\theta = -\dfrac{1}{2}\int (1 - u^2)\,du = -\dfrac{1}{2}\left(u - \dfrac{u^3}{3}\right) + C = \boxed{-\dfrac{1}{2}\cos(2\theta) + \dfrac{1}{6}\cos^3(2\theta) + C}.$$

> [!success]- Λύση (στ)
> Χρησιμοποιούμε την ταυτότητα $\tan^2(3\theta) = \sec^2(3\theta) - 1$:
> $$\int \tan^2(3\theta)\,d\theta = \int \bigl(\sec^2(3\theta) - 1\bigr)\,d\theta = \boxed{\dfrac{1}{3}\tan(3\theta) - \theta + C}.$$

> [!success]- Λύση (ζ)
> Επειδή $x > 0$, έχουμε $\sqrt{x^{2/3}} = x^{1/3} > 0$, οπότε:
> $$\sqrt{1 + x^{-2/3}} = \sqrt{\dfrac{x^{2/3} + 1}{x^{2/3}}} = \dfrac{\sqrt{x^{2/3} + 1}}{x^{1/3}} = x^{-1/3}\sqrt{x^{2/3} + 1}.$$
> Θέτουμε $u = x^{2/3} + 1 \implies du = \dfrac{2}{3}x^{-1/3}\,dx \implies x^{-1/3}\,dx = \dfrac{3}{2}\,du$:
> $$\int \sqrt{1 + x^{-2/3}}\,dx = \dfrac{3}{2}\int u^{1/2}\,du = \dfrac{3}{2}\cdot\dfrac{2}{3}u^{3/2} + C = \boxed{(x^{2/3} + 1)^{3/2} + C}.$$
> *Επαλήθευση:* $\dfrac{d}{dx}(x^{2/3} + 1)^{3/2} = \dfrac{3}{2}(x^{2/3} + 1)^{1/2}\cdot\dfrac{2}{3}x^{-1/3} = x^{-1/3}\sqrt{x^{2/3} + 1} = \sqrt{1 + x^{-2/3}}$ (για $x > 0$) ✓.
>
> 🪤 **Παγίδα:** Το κλειδί εδώ είναι να κάνεις ομώνυμα μέσα στη ρίζα και να βγάλεις το $x^{-1/3}$ έξω (χρησιμοποιώντας $x > 0$) ώστε να εμφανιστεί ακριβώς η παράγωγος του $x^{2/3} + 1$!

> [!success]- Λύση (η)
> Θέτουμε $u = \tan(5x) \implies du = 5\sec^2(5x)\,dx \implies \sec^2(5x)\,dx = \dfrac{du}{5}$:
> $$\int \tan^3(5x)\sec^2(5x)\,dx = \dfrac{1}{5}\int u^3\,du = \dfrac{u^4}{20} + C = \boxed{\dfrac{1}{20}\tan^4(5x) + C}.$$

## Άσκηση 7

Να βρεθεί η $f(x)$ αν
$$f'(x) = \sqrt{3x + 1} \qquad \text{και} \qquad f(1) = 5.$$

> [!success]- Λύση
> Ολοκληρώνουμε με αντικατάσταση $u = 3x + 1$ ($dx = \dfrac{du}{3}$):
> $$f(x) = \int \sqrt{3x + 1}\,dx = \dfrac{1}{3}\int u^{1/2}\,du = \dfrac{2}{9}(3x + 1)^{3/2} + C.$$
> Χρησιμοποιούμε την αρχική συνθήκη $f(1) = 5$:
> $$\dfrac{2}{9}(3\cdot 1 + 1)^{3/2} + C = 5 \implies \dfrac{2}{9}\cdot 8 + C = 5 \implies C = 5 - \dfrac{16}{9} = \dfrac{29}{9}.$$
> Συνεπώς:
> $$\boxed{f(x) = \dfrac{2}{9}(3x + 1)^{3/2} + \dfrac{29}{9}}.$$

## Άσκηση 8

Να βρεθεί η $f(x)$ αν
$$f'(x) = 6 - 5\sin(2x) \qquad \text{και} \qquad f(0) = 3.$$

> [!success]- Λύση
> Ολοκληρώνουμε:
> $$f(x) = \int \bigl(6 - 5\sin(2x)\bigr)\,dx = 6x + \dfrac{5}{2}\cos(2x) + C.$$
> Από την αρχική συνθήκη $f(0) = 3$:
> $$6(0) + \dfrac{5}{2}\cos(0) + C = 3 \implies \dfrac{5}{2} + C = 3 \implies C = \dfrac{1}{2}.$$
> Συνεπώς:
> $$\boxed{f(x) = 6x + \dfrac{5}{2}\cos(2x) + \dfrac{1}{2}}.$$
> *Επαλήθευση:* $f'(x) = 6 - 5\sin(2x)$ και $f(0) = \dfrac{5}{2} + \dfrac{1}{2} = 3$ ✓.

## Άσκηση 9

Να λυθούν οι διαφορικές εξισώσεις:
- **(α)** $e^x\dfrac{dy}{dx} + 1 = 0$.
- **(β)** $y^2\dfrac{dy}{dx} + \dfrac{1}{x} = 0$.
- **(γ)** $\dfrac{dy}{dx} + y = 0$.

> [!success]- Λύση (α)
> Απομονώνουμε την παράγωγο (αφού $e^x > 0$ παντού):
> $$\dfrac{dy}{dx} = -e^{-x} \implies y = \int (-e^{-x})\,dx = \boxed{e^{-x} + C}.$$
> *Επαλήθευση:* $e^x(-e^{-x}) + 1 = -1 + 1 = 0$ ✓.

> [!success]- Λύση (β)
> Χωρίζουμε τις μεταβλητές (για $x \neq 0$):
> $$y^2\,dy = -\dfrac{1}{x}\,dx \implies \int y^2\,dy = -\int \dfrac{1}{x}\,dx \implies \dfrac{y^3}{3} = -\ln\lvert x\rvert + C.$$
> Λύνοντας ως προς $y$ (θέτοντας $K = 3C \in \mathbb{R}$):
> $$\boxed{y = \sqrt[3]{-3\ln\lvert x\rvert + K}} \quad (x \neq 0).$$
>
> 🪤 **Παγίδα:** Μην ξεχάσεις την απόλυτη τιμή στο $\int \dfrac{dx}{x} = \ln\lvert x\rvert + C$, ώστε η λύση να ισχύει και για $x < 0$!

> [!success]- Λύση (γ)
> Παρατηρούμε πρώτα ότι η μηδενική συνάρτηση $y \equiv 0$ είναι προφανώς λύση.
> Για $y \neq 0$, χωρίζουμε τις μεταβλητές:
> $$\dfrac{dy}{y} = -dx \implies \int \dfrac{dy}{y} = -\int dx \implies \ln\lvert y\rvert = -x + C_1 \implies \lvert y\rvert = e^{C_1}e^{-x} \implies y = \pm e^{C_1}e^{-x}.$$
> Θέτοντας $C = \pm e^{C_1} \neq 0$ και συμπεριλαμβάνοντας και την $C = 0$ (που δίνει την $y \equiv 0$), η γενική λύση είναι:
> $$\boxed{y = Ce^{-x}, \quad C \in \mathbb{R}}.$$
>
> 🪤 **Παγίδα:** Όταν διαιρείς με το $y$ για να χωρίσεις μεταβλητές, πρέπει πάντα να ελέγχεις ξεχωριστά την $y = 0$!

## Άσκηση 10

Να βρεθεί η $f(x)$ αν:
- **(α)** $f'(x) = x^4$ και $f(3) = -2$.
- **(β)** $f'(x) = x^4$ και $f(-1) = 5$.

> [!success]- Λύση (α)
> Ολοκληρώνουμε: $f(x) = \dfrac{x^5}{5} + C$.
> Από $f(3) = -2$:
> $$\dfrac{3^5}{5} + C = -2 \implies \dfrac{243}{5} + C = -2 \implies C = -2 - \dfrac{243}{5} = -\dfrac{253}{5}.$$
> Άρα $\boxed{f(x) = \dfrac{x^5 - 253}{5}}$.

> [!success]- Λύση (β)
> Ολοκληρώνουμε: $f(x) = \dfrac{x^5}{5} + C$.
> Από $f(-1) = 5$:
> $$\dfrac{(-1)^5}{5} + C = 5 \implies -\dfrac{1}{5} + C = 5 \implies C = \dfrac{26}{5}.$$
> Άρα $\boxed{f(x) = \dfrac{x^5 + 26}{5}}$.

## Συχνά Λάθη

> [!warning] Τι να προσέχεις στο Κεφάλαιο 7
> - **Η σταθερά ολοκλήρωσης $+ C$:** Μην την παραλείπεις ποτέ σε αόριστα ολοκληρώματα — είναι απαραίτητη και για τον προσδιορισμό της μοναδικής λύσης όταν δίνεται αρχική συνθήκη.
> - **Γινόμενα & πηλίκα:** Δεν ισχύει $\int f\cdot g = (\int f)(\int g)$ ούτε $\int \frac{f}{g} = \frac{\int f}{\int g}$. Αναπτύσσουμε/απλοποιούμε αλγεβρικά πρώτα (Άσκηση 1στ, 1ζ, 1ι).
> - **Ξεχασμένος παράγοντας $du$:** Στην αντικατάσταση $u = ax + b$, πάντα διαιρούμε με τον συντελεστή $a$ (π.χ. $\int \cos(8x)\,dx = \frac{1}{8}\sin(8x) + C$, όχι $\sin(8x) + C$).
> - **Απόλυτη τιμή στο λογάριθμο:** $\int \dfrac{dx}{x} = \ln\lvert x\rvert + C$ (Άσκηση 9β).
> - **Μηδενικές λύσεις σε διαφορικές εξισώσεις:** Όταν χωρίζεις μεταβλητές διαιρώντας με $y$, έλεγχε πάντα αν η $y \equiv 0$ είναι λύση (Άσκηση 9γ).
