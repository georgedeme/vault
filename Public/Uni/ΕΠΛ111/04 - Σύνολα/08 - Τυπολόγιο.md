# 08 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Βασικές έννοιες

**Σύνολο** = συλλογή **αταξινόμητων** αντικειμένων · **α ∈ A** ανήκει · **α ∉ A** δεν ανήκει · **∅ = { }** κενό · **U** καθολικό σύνολο

**Περιγραφή:** παράθεση {1, 3, 5} · κατηγόρημα {x | P(x)} ή {x : P(x)} · διάγραμμα Venn

| Σύνολο | Στοιχεία |
|---|---|
| **N** | {0, 1, 2, 3, …} (το **0 ∈ N**) |
| **Z** | {…, −2, −1, 0, 1, 2, …} |
| **Z⁺** | {1, 2, 3, …} (το **0 ∉ Z⁺**) |
| **Q** | {α/β \| α ∈ Z, β ∈ Z και β ≠ 0} |
| **R** | {x \| x είναι πραγματικός αριθμός} |

Z⁺ ⊂ N ⊂ Z ⊂ Q ⊂ R

## 2. Σχέσεις μεταξύ συνόλων

| Σχέση | Ορισμός | Άρνηση |
|---|---|---|
| **A = B** | ∀x (x ∈ A ↔ x ∈ B) | ∃x ((x ∈ A ∧ x ∉ B) ∨ (x ∈ B ∧ x ∉ A)) |
| **A ⊆ B** | ∀x (x ∈ A → x ∈ B) | ∃x (x ∈ A ∧ x ∉ B) |
| **A ⊂ B** | A ⊆ B ∧ A ≠ B ≡ ∀x (x ∈ A → x ∈ B) ∧ ∃x (x ∈ B ∧ x ∉ A) | |

**Θεωρήματα:** ∅ ⊆ A · A ⊆ A · **A = B ⇔ A ⊆ B ∧ B ⊆ A** · A ⊆ B ∧ B ⊆ C ⇒ A ⊆ C (το ∈ **δεν** είναι μεταβατικό)

**∈ vs ⊆:** X ∈ S = «το X είναι **ένα** από τα στοιχεία του S» · X ⊆ S = «**κάθε** στοιχείο του X είναι στο S» · **α ∈ S ⇔ {α} ⊆ S**

| α ∈ {α} | {α} ⊆ {α} | {α} ∈ {α} | {α} ∈ {{α}} | ∅ ⊆ {α} | ∅ ∈ {α} | ∅ ∈ {∅} | ∅ ∈ ∅ |
|---|---|---|---|---|---|---|---|
| ✓ | ✓ | ✗ | ✓ | ✓ | ✗ | ✓ | ✗ |

## 3. Πληθικός αριθμός και δυναμοσύνολο

**|A|** = πλήθος **διαφορετικών** στοιχείων (μόνο τα άμεσα) · πεπερασμένο αν |A| ∈ N, αλλιώς άπειρο

A = B ⇒ |A| = |B| · A ⊆ B ⇒ |A| ≤ |B| · A ⊂ B ⇒ |A| < |B| (**μόνο πεπερασμένα**) · αντίστροφα ✗

**P(A) = {X | X ⊆ A}** · **X ∈ P(A) ⇔ X ⊆ A** · ∅ ∈ P(A), A ∈ P(A) · **|P(A)| = 2^|A|**

| P(∅) | P({∅}) | P({∅, {∅}}) | \|P(P(∅))\| |
|---|---|---|---|
| {∅} | {∅, {∅}} | {∅, {∅}, {{∅}}, {∅, {∅}}} | 2 |

**Russell:** A = {B | B ∉ B} ⇒ A ∈ A ↔ A ∉ A: αντίφαση → όχι «κάθε κατηγόρημα ορίζει σύνολο»

## 4. Πράξεις

| Πράξη | Ορισμός | Λογική |
|---|---|---|
| **A ∪ B** | {x \| x ∈ A ∨ x ∈ B} | ∨ |
| **A ∩ B** | {x \| x ∈ A ∧ x ∈ B} | ∧ |
| **A ∖ B** (= A − B) | {x \| x ∈ A ∧ x ∉ B} = A ∩ B̄ | ∧ ¬ |
| **Ā** | {x \| x ∉ A} = U ∖ A (**εξαρτάται από το U**) | ¬ |
| **A ⊕ B** | {x \| x ∈ A ⊕ x ∈ B} = (A ∖ B) ∪ (B ∖ A) | ⊕ |
| **⋃ᵢ₌₁ᵛ Aᵢ** | {x \| x ∈ A₁ ∨ ⋯ ∨ x ∈ Aᵥ} (**τουλάχιστον ένα**) | ∃i |
| **⋂ᵢ₌₁ᵛ Aᵢ** | {x \| x ∈ A₁ ∧ ⋯ ∧ x ∈ Aᵥ} (**όλα**) | ∀i |

**Ξένα:** A ∩ B = ∅ · **|A ∪ B| = |A| + |B| − |A ∩ B|** · |A ∖ B| = |A| − |A ∩ B|

## 5. Ταυτότητες

| Ταυτότητα | Όνομα |
|---|---|
| A ∪ ∅ = A · A ∩ U = A | Ταυτότητας |
| A ∪ U = U · A ∩ ∅ = ∅ | Κυριαρχίας |
| A ∪ A = A · A ∩ A = A | Ταυτοδυναμίας |
| $\overline{(\overline{A})} = A$ | Συμπλήρωσης |
| A ∪ B = B ∪ A · A ∩ B = B ∩ A | Αντιμεταθετικότητας |
| (A ∪ B) ∪ C = A ∪ (B ∪ C) · (A ∩ B) ∩ C = A ∩ (B ∩ C) | Προσεταιριστικότητας |
| A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) · A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) | Επιμεριστικότητας |
| $\overline{A \cup B} = \overline{A} \cap \overline{B}$ · $\overline{A \cap B} = \overline{A} \cup \overline{B}$ | De Morgan |
| A ∪ (A ∩ B) = A · A ∩ (A ∪ B) = A | Απορρόφησης (επιπλέον) |
| A ∪ Ā = U · A ∩ Ā = ∅ | Συμπληρώματος (επιπλέον) |

**Γενικευμένοι:** A ∪ (⋂ Bᵢ) = ⋂ (A ∪ Bᵢ) · A ∩ (⋃ Bᵢ) = ⋃ (A ∩ Bᵢ) · $\overline{A_1 \cup \cdots \cup A_\nu} = \overline{A_1} \cap \cdots \cap \overline{A_\nu}$ · $\overline{A_1 \cap \cdots \cap A_\nu} = \overline{A_1} \cup \cdots \cup \overline{A_\nu}$

**ΔΕΝ ισχύουν:** A ∖ B = B ∖ A · A ∖ (B ∖ C) = (A ∖ B) ∖ C · A ∪ B = A ∪ C ⇒ B = C · A ∩ B = A ∩ C ⇒ B = C · $\overline{A \cup B} = \overline{A} \cup \overline{B}$

## 6. Αποδείξεις

| Μέθοδος | Πώς |
|---|---|
| **Διπλός εγκλεισμός** | Έστω α ∈ X (αυθαίρετο) ⇒ … ⇒ α ∈ Y· **και** ανάποδα |
| **Κατασκευή συνόλου** | X = {x \| …} = … = Y, κάθε βήμα ⇔ (ορισμός ή λογικός νόμος) |
| **Πίνακας συμμετοχής** | T = ανήκει· **2^ν** γραμμές· ίδιες στήλες ⇒ ίσα |
| **Ταυτότητες** | ένας νόμος σε κάθε γραμμή· πρώτα A ∖ B → A ∩ B̄ |
| **Με υποθέσεις** | αντίφαση (για «x ∉ …»), περιπτώσεις (x ∈ C ή x ∉ C), έμμεση (A ≠ B δίνει μάρτυρα) |
| **Κατάρριψη** | γραμμή του πίνακα που διαφέρει → σύνολα με ένα στοιχείο εκεί (π.χ. A = {1}, B = C = ∅) |

## 7. Καρτεσιανό γινόμενο

**(α₁, …, αᵥ) = (β₁, …, βᵥ) ⇔ αᵢ = βᵢ για κάθε i** · (1, 2) ≠ (2, 1) ενώ {1, 2} = {2, 1}

**A × B = {(α, β) | α ∈ A ∧ β ∈ B}** · **|A × B| = |A| · |B|** · A × ∅ = ∅ × A = ∅

**A × B = B × A ⇔ A = B ∨ A = ∅ ∨ B = ∅** (διαφάνειες: ⇐ · αντίστροφο: επέκταση)

**A₁ × ⋯ × Aᵥ = {(α₁, …, αᵥ) | αᵢ ∈ Aᵢ για κάθε 1 ≤ i ≤ ν}** · |A₁ × ⋯ × Aᵥ| = |A₁| ⋯ |Aᵥ| · Aᵛ = A × ⋯ × A

## 8. Οι 10 παγίδες

1. **α ≠ {α}**, **∅ ≠ {∅}**, **0 ≠ ∅**
2. **∅ ⊆ A πάντα**, **∅ ∈ A όχι πάντα**
3. **P(∅) = {∅}**, όχι ∅
4. |{α, {α}, {α, {α}}}| = **3** (μόνο άμεσα στοιχεία)
5. {x | x > x²} = ∅ στους **ακέραιους**, (0, 1) στους **πραγματικούς**
6. **Ā εξαρτάται από το U**· το A ∖ B όχι
7. **De Morgan αλλάζει ∪ ↔ ∩**
8. **Δεν διαγράφουμε:** A ∪ B = A ∪ C ⇏ B = C
9. **A ⊂ B ⇒ |A| < |B| μόνο για πεπερασμένα** (Z⁺ ⊂ N, και τα δύο άπειρα)
10. **A × B ≠ B × A** (εκτός αν A = B ή κάποιο = ∅)
