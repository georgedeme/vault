# 05 - Ταυτότητες Συνόλων

Οι νόμοι που ισχύουν για **κάθε** σύνολο: είναι οι λογικοί κανόνες του [[Uni/ΕΠΛ111/ΕΠΛ111 Προτασιακή-Κατηγορική Λογική/03 - Ισοδυναμίες|03 - Ισοδυναμίες]] «μεταφρασμένοι» σε σύνολα. Τους χρησιμοποιούμε για να απλοποιούμε εκφράσεις και να αποδεικνύουμε νέες ταυτότητες ([[06 - Αποδείξεις με Σύνολα|06]]).

## 1. Ο πίνακας των ταυτοτήτων

> [!important] Ταυτότητες Συνόλων
>
> | Ταυτότητα | Όνομα | Λογική ισοδυναμία |
> |---|---|---|
> | A ∪ ∅ = A<br>A ∩ U = A | **Νόμοι ταυτότητας** (identity laws) | P ∨ F ≡ P<br>P ∧ T ≡ P |
> | A ∪ U = U<br>A ∩ ∅ = ∅ | **Νόμοι κυριαρχίας** (domination laws) | P ∨ T ≡ T<br>P ∧ F ≡ F |
> | A ∪ A = A<br>A ∩ A = A | **Νόμοι ταυτοδυναμίας** (idempotent laws) | P ∨ P ≡ P<br>P ∧ P ≡ P |
> | $\overline{(\overline{A})} = A$ | **Νόμος συμπλήρωσης** (complementation law) | ¬(¬P) ≡ P |
> | A ∪ B = B ∪ A<br>A ∩ B = B ∩ A | **Νόμοι αντιμεταθετικότητας** (commutative laws) | P ∨ Q ≡ Q ∨ P<br>P ∧ Q ≡ Q ∧ P |
> | (A ∪ B) ∪ C = A ∪ (B ∪ C)<br>(A ∩ B) ∩ C = A ∩ (B ∩ C) | **Νόμοι προσεταιριστικότητας** (associative laws) | (P ∨ Q) ∨ R ≡ P ∨ (Q ∨ R)<br>(P ∧ Q) ∧ R ≡ P ∧ (Q ∧ R) |
> | A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)<br>A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) | **Νόμοι επιμεριστικότητας** (distributive laws) | P ∨ (Q ∧ R) ≡ (P ∨ Q) ∧ (P ∨ R)<br>P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R) |
> | $\overline{A \cup B} = \overline{A} \cap \overline{B}$<br>$\overline{A \cap B} = \overline{A} \cup \overline{B}$ | **Νόμοι De Morgan** (De Morgan's laws) | ¬(P ∨ Q) ≡ ¬P ∧ ¬Q<br>¬(P ∧ Q) ≡ ¬P ∨ ¬Q |

Η αντιστοιχία είναι μηχανική: **∪ ↔ ∨**, **∩ ↔ ∧**, **συμπλήρωμα ↔ ¬**, **U ↔ T**, **∅ ↔ F**, **= ↔ ≡**.

> [!info]- 🧠 Γιατί κάθε ταυτότητα «κληρονομείται» από τη λογική
> Πάρε π.χ. τον πρώτο νόμο De Morgan. Για τυχαίο x:
>
> x ∈ $\overline{A \cup B}$ ⇔ ¬(x ∈ A ∨ x ∈ B) ⇔ (¬ x ∈ A) ∧ (¬ x ∈ B) ⇔ x ∈ Ā ∧ x ∈ B̄ ⇔ x ∈ Ā ∩ B̄.
>
> Το μεσαίο βήμα είναι **ο λογικός** νόμος De Morgan με P = «x ∈ A», Q = «x ∈ B». Τα υπόλοιπα είναι απλώς οι ορισμοί των πράξεων. Με τον ίδιο τρόπο αποδεικνύεται **κάθε** γραμμή του πίνακα ([[06 - Αποδείξεις με Σύνολα#3. Μέθοδος 2: συμβολισμός κατασκευής συνόλου|μέθοδος 2 του 06]]).

## 2. Οι νόμοι De Morgan σε εικόνα

Το συμπλήρωμα «γυρίζει» την ένωση σε τομή και την τομή σε ένωση:

![[Ταυτότητες - De Morgan σε Venn.excalidraw|800]]

> [!tip] Πώς θυμάμαι τον De Morgan
> «Σπάσε τη γραμμή, άλλαξε το σύμβολο»: η μεγάλη γραμμή του συμπληρώματος πάνω από το A ∪ B «σπάει» σε δύο μικρές (Ā, B̄) και το ∪ γίνεται ∩. Ίδιο με το ¬(P ∨ Q) ≡ ¬P ∧ ¬Q.

## 3. Γενικευμένοι νόμοι

**Γενικευμένοι νόμοι επιμεριστικότητας:**

$$A \cup \left(\bigcap_{i=1}^{\nu} B_i\right) = \bigcap_{i=1}^{\nu} (A \cup B_i) \qquad A \cap \left(\bigcup_{i=1}^{\nu} B_i\right) = \bigcup_{i=1}^{\nu} (A \cap B_i)$$

**Γενικευμένοι νόμοι De Morgan:**

$$\overline{A_1 \cup A_2 \cup \cdots \cup A_\nu} = \overline{A_1} \cap \overline{A_2} \cap \cdots \cap \overline{A_\nu} \qquad \overline{A_1 \cap A_2 \cap \cdots \cap A_\nu} = \overline{A_1} \cup \overline{A_2} \cup \cdots \cup \overline{A_\nu}$$

> [!example]- Γιατί ισχύει ο γενικευμένος De Morgan
> x ∉ A₁ ∪ ⋯ ∪ Aᵥ ⇔ ¬∃i (x ∈ Aᵢ) ⇔ ∀i (x ∉ Aᵢ) ⇔ x ∈ Ā₁ ∩ ⋯ ∩ Āᵥ.
>
> Είναι η **άρνηση ποσοδείκτη** (¬∃ ≡ ∀¬) από την [[Uni/ΕΠΛ111/ΕΠΛ111 Προτασιακή-Κατηγορική Λογική/05 - Κατηγορική Λογική και Ποσοδείκτες#5. Άρνηση και Ποσοδείκτες|Κατηγορική Λογική]]: «δεν είναι σε **κανένα**» = «είναι έξω από **όλα**».

## 4. Επιπλέον ταυτότητες (εκτός διαφανειών)

Οι παρακάτω δεν είναι στον πίνακα των διαφανειών, αλλά τις χρησιμοποιούμε συνεχώς (οι δύο πρώτες είναι στον πίνακα των νεότερων εκδόσεων του Rosen):

| Ταυτότητα | Όνομα | Λογική |
|---|---|---|
| A ∪ (A ∩ B) = A<br>A ∩ (A ∪ B) = A | **Νόμοι απορρόφησης** (absorption laws) | P ∨ (P ∧ Q) ≡ P<br>P ∧ (P ∨ Q) ≡ P |
| A ∪ Ā = U<br>A ∩ Ā = ∅ | **Νόμοι συμπληρώματος** (complement laws) | P ∨ ¬P ≡ T<br>P ∧ ¬P ≡ F |
| Ū = ∅<br>∅̄ = U | συμπλήρωμα U και ∅ | ¬T ≡ F<br>¬F ≡ T |
| **A ∖ B = A ∩ B̄** | διαφορά με συμπλήρωμα | P ∧ ¬Q |
| A ∖ (B ∪ C) = (A ∖ B) ∩ (A ∖ C)<br>A ∖ (B ∩ C) = (A ∖ B) ∪ (A ∖ C) | De Morgan για τη διαφορά | |
| (A ∪ B) ∖ C = (A ∖ C) ∪ (B ∖ C)<br>(A ∩ B) ∖ C = (A ∖ C) ∩ (B ∖ C) | επιμεριστικότητα διαφοράς | |
| A ⊕ B = (A ∖ B) ∪ (B ∖ A) = (A ∪ B) ∖ (A ∩ B) | συμμετρική διαφορά | P ⊕ Q ≡ (P ∧ ¬Q) ∨ (¬P ∧ Q) |

> [!tip] Πρώτη κίνηση: διώξε τη διαφορά
> Όπως στη λογική διώχνουμε πρώτα το → (P → Q ≡ ¬P ∨ Q), στα σύνολα διώχνουμε πρώτα το ∖ με **A ∖ B = A ∩ B̄**. Μετά δουλεύουν οι νόμοι του πίνακα, που έχουν μόνο ∪, ∩ και συμπλήρωμα.

> [!example]- Απόδειξη με ταυτότητες: A ∖ (B ∪ C) = (A ∖ B) ∩ (A ∖ C)
> | Βήμα | Αιτιολόγηση |
> |---|---|
> | A ∖ (B ∪ C) = A ∩ $\overline{B \cup C}$ | διαφορά με συμπλήρωμα |
> | = A ∩ (B̄ ∩ C̄) | De Morgan |
> | = (A ∩ A) ∩ (B̄ ∩ C̄) | ταυτοδυναμία (A = A ∩ A) |
> | = (A ∩ B̄) ∩ (A ∩ C̄) | αντιμεταθετικότητα και προσεταιριστικότητα τομής |
> | = (A ∖ B) ∩ (A ∖ C) | διαφορά με συμπλήρωμα |
>
> **Κόλπο:** το βήμα με την ταυτοδυναμία «διπλασιάζει» το A ώστε να υπάρχει ένα A για κάθε κομμάτι.

## 5. Αρχή του δυϊσμού

> [!info]- 🧠 Δυϊσμός (duality)
> Αν σε μια ταυτότητα που περιέχει μόνο ∪, ∩, συμπλήρωμα, ∅, U **ανταλλάξεις ∪ ↔ ∩ και ∅ ↔ U**, παίρνεις **πάλι ταυτότητα** (τη **δυϊκή** της). Γι' αυτό ο πίνακας έχει τους νόμους **σε ζευγάρια**:
> - A ∪ ∅ = A ⟷ A ∩ U = A
> - A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) ⟷ A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
> - A ∪ (A ∩ B) = A ⟷ A ∩ (A ∪ B) = A
>
> **Προσοχή:** ο δυϊσμός ισχύει για **ταυτότητες** (= που ισχύουν πάντα), όχι για προτάσεις που ισχύουν για συγκεκριμένα σύνολα. Και αν υπάρχει ∖, πρώτα τη γράφεις ως A ∩ B̄.

## 6. Μοιάζουν με ταυτότητες, αλλά δεν είναι

Η άλγεβρα των συνόλων **δεν** συμπεριφέρεται σε όλα όπως η άλγεβρα των αριθμών. Τα πιο συχνά «ψεύτικα» βήματα:

### 6.1 Η διαφορά δεν είναι προσεταιριστική (ούτε αντιμεταθετική)

![[Ταυτότητες - Η Διαφορά δεν είναι Προσεταιριστική.excalidraw|800]]

Η σωστή ταυτότητα: **A ∖ (B ∖ C) = (A ∖ B) ∪ (A ∩ C)**, ενώ **(A ∖ B) ∖ C = A ∖ (B ∪ C)**.

### 6.2 Δεν «διαγράφουμε» στην ένωση ή στην τομή

Στους αριθμούς, α + β = α + γ ⇒ β = γ. Στα σύνολα **όχι**:

![[Ταυτότητες - Δεν Διαγράφουμε.excalidraw|800]]

> [!example]- Απόδειξη: αν A ∪ B = A ∪ C και A ∩ B = A ∩ C, τότε B = C
> Δείχνουμε B ⊆ C (το C ⊆ B είναι συμμετρικό). Έστω x ∈ B. Δύο περιπτώσεις:
> - **x ∈ A.** Τότε x ∈ A ∩ B = A ∩ C, άρα x ∈ C.
> - **x ∉ A.** Αφού x ∈ B, x ∈ A ∪ B = A ∪ C. Αφού x ∉ A, πρέπει x ∈ C.
>
> Σε κάθε περίπτωση x ∈ C. ∎ (Απόδειξη με [[Uni/ΕΠΛ111/ΕΠΛ111 Μαθηματικός Συλλογισμός/09 - Απόδειξη με Ανάλυση Περιπτώσεων|ανάλυση περιπτώσεων]].)

### 6.3 Άλλα κλασικά λάθη

| «Ταυτότητα» | Ισχύει; | Αντιπαράδειγμα / σωστή μορφή |
|---|---|---|
| $\overline{A \cup B} = \overline{A} \cup \overline{B}$ | ✗ | A = {1}, B = {2}, U = {1, 2}: αριστερά ∅, δεξιά {1, 2}. Σωστό: Ā **∩** B̄ |
| A ∪ (B ∩ C) = (A ∪ B) ∩ C | ✗ | A = {1}, B = C = ∅ ([[06 - Αποδείξεις με Σύνολα#8. Πώς καταρρίπτω μια «ταυτότητα»|06]]). Σωστό: (A ∪ B) ∩ (A ∪ C) |
| A ∖ B = B ∖ A | ✗ | {1} ∖ ∅ = {1}, ∅ ∖ {1} = ∅ |
| (A ∖ B) ∪ B = A | ✗ | A = ∅, B = {1}: αριστερά {1}. Σωστό: (A ∖ B) ∪ B = A ∪ B |
| (A ∪ B) ∖ B = A | ✗ | A = B = {1}: αριστερά ∅. Σωστό: (A ∪ B) ∖ B = A ∖ B |
| A ∩ (B ∖ C) = (A ∩ B) ∖ (A ∩ C) | ✓ | (A ∩ B) ∖ C δίνει το ίδιο |
| A ∪ (B ∖ C) = (A ∪ B) ∖ (A ∪ C) | ✗ | A = {1}, B = C = ∅: αριστερά {1}, δεξιά ∅ |

> [!tip] Πριν πιστέψεις μια «ταυτότητα», δοκίμασε τα μικρά σύνολα
> Τα περισσότερα ψεύτικα βήματα «σπάνε» με σύνολα όπως ∅, {1}, και U = {1, 2}. Αν δεν σπάσει, κάνε [[06 - Αποδείξεις με Σύνολα#4. Μέθοδος 3: πίνακες συμμετοχής|πίνακα συμμετοχής]]: είναι πλήρης έλεγχος.

## 7. Συχνά Λάθη

> [!warning] Προσοχή στο τεστ
> - **De Morgan χωρίς αλλαγή συμβόλου.** $\overline{A \cup B}$ = Ā **∩** B̄, όχι Ā ∪ B̄.
> - **Επιμεριστικότητα «μισή».** A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ **C**): το A μπαίνει **και** στα δύο κομμάτια.
> - **Διαγραφή.** A ∪ B = A ∪ C δεν δίνει B = C (ούτε με ∩).
> - **Προσεταιριστικότητα στη διαφορά.** A ∖ (B ∖ C) ≠ (A ∖ B) ∖ C. Βάζε πάντα παρενθέσεις.
> - **Ξεχνάς το όνομα του νόμου** σε απόδειξη με ταυτότητες. Κάθε γραμμή χρειάζεται αιτιολόγηση, όπως στη Λογική.
> - **Νόμος συμπλήρωσης vs νόμοι συμπληρώματος.** Ο πρώτος (διαφάνειες): $\overline{(\overline{A})}$ = A. Οι δεύτεροι (επιπλέον): A ∪ Ā = U, A ∩ Ā = ∅.
