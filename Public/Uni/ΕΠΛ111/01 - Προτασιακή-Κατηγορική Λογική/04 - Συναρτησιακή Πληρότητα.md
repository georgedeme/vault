# 04 - Συναρτησιακή Πληρότητα

Χρειάζονται όλοι οι λογικοί τελεστές που είδαμε μέχρι τώρα; Όχι – φτάνουν τρεις. Ή και δύο.

## 1. Το ερώτημα

Ήδη ξέρουμε από τη [[03 - Ισοδυναμίες|Μέθοδο Α]] ότι οι «περίεργοι» τελεστές γράφονται με ¬, ∧, ∨:

| | |
|---|---|
| P ⊕ Q | ≡ (P ∧ ¬Q) ∨ (¬P ∧ Q) |
| P → Q | ≡ ¬P ∨ Q |
| P ↔ Q | ≡ (¬P ∨ Q) ∧ (P ∨ ¬Q) |

> [!note] Ορισμός
> Μία συλλογή λογικών τελεστών **Σ** είναι **συναρτησιακά πλήρης** (functionally complete) όταν **κάθε** σύνθετη πρόταση είναι ισοδύναμη με μία άλλη σύνθετη πρόταση η οποία χρησιμοποιεί **μόνο** τελεστές από τη συλλογή Σ.

**Είναι η συλλογή { ¬, ∧, ∨ } συναρτησιακά πλήρης;**

## 2. Από πίνακες αληθείας σε λογικές προτάσεις με μόνο ¬, ∧, ∨

Αν μπορούμε να φτιάξουμε τύπο με ¬, ∧, ∨ για **οποιονδήποτε** πίνακα αληθείας, τότε η συλλογή είναι συναρτησιακά πλήρης – γιατί κάθε σύνθετη πρόταση **είναι** ένας πίνακας αληθείας.

### Το παράδειγμα S των διαφανειών

| P | Q | R | S | Σύζευξη για τη γραμμή |
|---|---|---|---|---|
| T | T | T | **T** | P ∧ Q ∧ R |
| T | T | F | F | |
| T | F | T | **T** | P ∧ ¬Q ∧ R |
| T | F | F | F | |
| F | T | T | F | |
| F | T | F | F | |
| F | F | T | **T** | ¬P ∧ ¬Q ∧ R |
| F | F | F | F | |

**S ≡ (P ∧ Q ∧ R) ∨ (P ∧ ¬Q ∧ R) ∨ (¬P ∧ ¬Q ∧ R)**

> [!important] Ο κανόνας – μία σύζευξη ανά γραμμή T
> 1. Κοίτα **μόνο** τις γραμμές όπου η πρόταση είναι **T**. Τις γραμμές F τις αγνοείς.
> 2. Για **κάθε** τέτοια γραμμή φτιάξε μία **σύζευξη** και των Ν μεταβλητών:
>    - αν η μεταβλητή είναι **T** στη γραμμή → γράψ' την **σκέτη** (P)
>    - αν η μεταβλητή είναι **F** στη γραμμή → γράψ' την **αρνημένη** (¬P)
> 3. Ένωσε όλες τις συζεύξεις με **∨**.
>
> Κάθε σύζευξη γίνεται T **μόνο** στη δική της γραμμή ⇒ η διάζευξή τους γίνεται T **ακριβώς** στις γραμμές που θέλαμε.

> [!note] Έλεγχος
> Ο αριθμός των συζεύξεων = ο αριθμός των **T** στη στήλη. Εδώ 3 γραμμές T → 3 συζεύξεις. Κάθε σύζευξη έχει **ακριβώς Ν** όρους (εδώ 3: P, Q, R).

⇒ **Ναι, η { ¬, ∧, ∨ } είναι συναρτησιακά πλήρης.**

## 3. Γιατί αρκούν και δύο τελεστές

### Είναι η συλλογή { ¬, ∧ } συναρτησιακά πλήρης;

Από **De Morgan** και **διπλή άρνηση** γνωρίζουμε ότι

**P ∨ Q ≡ ¬(¬P ∧ ¬Q)**

Άρα το ∨ είναι περιττό: όπου το χρειαζόμαστε, το αντικαθιστούμε. ⇒ **Ναι.**

### Είναι η συλλογή { ¬, ∨ } συναρτησιακά πλήρης;

Από **De Morgan** και **διπλή άρνηση** γνωρίζουμε ότι

**P ∧ Q ≡ ¬(¬P ∨ ¬Q)**

Άρα το ∧ είναι περιττό. ⇒ **Ναι.**

> [!important] Η αλυσίδα του επιχειρήματος
> { ¬, ∧, ∨ } πλήρης *(από τον πίνακα αληθείας)* → διώχνω το ∨ με De Morgan → **{ ¬, ∧ } πλήρης**.
> { ¬, ∧, ∨ } πλήρης → διώχνω το ∧ με De Morgan → **{ ¬, ∨ } πλήρης**.

## 4. Συχνά Λάθη

> [!warning] Προσοχή στο τεστ
> - **Χτίζεις από τις γραμμές F.** Ο κανόνας «μία σύζευξη ανά γραμμή» δουλεύει με τις γραμμές **T**.
> - **Ανακατεύεις ∧ και ∨.** *Μέσα* σε κάθε γραμμή → **∧**. *Ανάμεσα* στις γραμμές → **∨**.
> - **Παραλείπεις μεταβλητή από μια σύζευξη.** Κάθε σύζευξη πρέπει να αναφέρει **όλες** τις μεταβλητές, αλλιώς γίνεται T και σε άλλες γραμμές.
> - **Ξεχνάς το ¬ στις F μεταβλητές.** Στη γραμμή `F F T` ο όρος είναι `¬P ∧ ¬Q ∧ R`, όχι `P ∧ Q ∧ R`.
> - **{ ∧, ∨ } χωρίς ¬ δεν είναι πλήρης.** Το ¬ είναι απαραίτητο και στις δύο δυάδες.
> - Αν η στήλη είναι **παντού F**, δεν υπάρχει καμία γραμμή T → η πρόταση είναι **αντίφαση** (δες [[03 - Ισοδυναμίες]]).
