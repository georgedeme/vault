# 01 - Ορισμός Αριθμησιμότητας

Ένα σύνολο είναι **αριθμήσιμο** αν μπορούμε να «μετρήσουμε» τα στοιχεία του: πρώτο, δεύτερο, τρίτο, … Για πεπερασμένα σύνολα αυτό είναι το γνωστό μέτρημα. Για άπειρα σύνολα, το «μέτρημα» γίνεται αυστηρό με μια **ένα-προς-ένα αντιστοιχία** με το Z⁺. (διαφάνειες 2–6)

## 1. Η ιδέα: απαρίθμηση

> [!note] Αριθμησιμότητα (Countability), άτυπα
> Ένα (πεπερασμένο ή άπειρο) σύνολο είναι **αριθμήσιμο** αν μπορούμε να **απαριθμήσουμε** τα στοιχεία του.

«Απαριθμώ» = γράφω τα στοιχεία σε μια **λίστα**, το καθένα **μία φορά**. Παραδείγματα της διαφάνειας 2:

| Σύνολο | Μια απαρίθμηση |
|---|---|
| {9, 2, 3, 1, 5, 4, 7, 6, 8} | 1, 2, 3, 4, 5, 6, 7, 8, 9 |
| {Μαρία, Χρήστος, Αλίκη, Γιώργος} | Αλίκη, Γιώργος, Μαρία, Χρήστος |
| {η, ε, α, γ, ζ, β, δ, κ, θ, ι} | α, β, γ, δ, ε, ζ, η, θ, ι, κ |

Η σειρά της λίστας **δεν** χρειάζεται να είναι «φυσική» (αριθμητική, αλφαβητική). Οποιαδήποτε σειρά κάνει, αρκεί κάθε στοιχείο να εμφανίζεται **ακριβώς μία φορά**.

## 2. Πεπερασμένα σύνολα

> [!important] Κάθε πεπερασμένο σύνολο είναι αριθμήσιμο
> Κάθε σύνολο A με πληθικό αριθμό ν, για κάποιο ακέραιο ν ≥ 0, είναι **αριθμήσιμο** (**countable**), αφού πάντοτε υπάρχει μια 1-1 αντιστοιχία από το σύνολο {1, 2, …, ν} στο σύνολο A.

Η απαρίθμηση **είναι** η αντιστοιχία: «το στοιχείο στη θέση 1», «το στοιχείο στη θέση 2», … Στο παράδειγμα της διαφάνειας 4: 1 ↦ Αλίκη, 2 ↦ Γιώργος, 3 ↦ Μαρία, 4 ↦ Χρήστος.

![[Ορισμός - Πεπερασμένη και Άπειρη Απαρίθμηση.png|800]]

> [!info]- Η περίπτωση ν = 0
> Για ν = 0 το {1, 2, …, ν} είναι το **κενό** σύνολο, και A = ∅. Η μόνη συνάρτηση ∅ → ∅ είναι η κενή συνάρτηση (κανένα ζεύγος), που είναι **κενά** 1-1 και επί: δεν υπάρχει x για να παραβιάσει κάτι. Άρα το **∅ είναι αριθμήσιμο**. Αυτό μετράει σε ασκήσεις όπου ένα σύνολο μπορεί να βγει κενό (π.χ. [[11 - Λύσεις Άσκησης 5#3.1 Για πεπερασμένο A, το $ bigcup_{ kappa>1} A^ kappa$ είναι αριθμήσιμο|Άσκηση 5, 3.1]] με A = ∅).

## 3. Άπειρα σύνολα και ℵ₀

Τι μπορούμε να πούμε για άπειρα σύνολα; Μια λίστα άπειρου συνόλου δεν τελειώνει ποτέ. Οι «θέσεις» της είναι οι **θετικοί ακέραιοι** 1, 2, 3, …

> [!note] Αριθμήσιμο άπειρο σύνολο
> Ένα άπειρο σύνολο A είναι **αριθμήσιμο** (**countable**) αν υπάρχει μια **1-1 αντιστοιχία** από το σύνολο **Z⁺** στο σύνολο A.
>
> Δηλαδή, ένα άπειρο σύνολο A είναι αριθμήσιμο αν **|A| = |Z⁺| = ℵ₀** (ℵ, «άλεφ», είναι το πρώτο γράμμα του εβραϊκού αλφαβήτου· ℵ₀: «άλεφ μηδέν»).

> [!important] Ο ορισμός σε μία γραμμή
> **A αριθμήσιμο ⇔ A πεπερασμένο ή |A| = |Z⁺|**
>
> Ισοδύναμα: τα στοιχεία του A γράφονται σε λίστα a₁, a₂, a₃, … (πεπερασμένη ή άπειρη) όπου **κάθε** στοιχείο εμφανίζεται **ακριβώς μία φορά** σε **πεπερασμένη** θέση. Η αντιστοιχία είναι f(n) = aₙ.

> [!warning] «1-1 αντιστοιχία» ≠ «1-1 συνάρτηση»
> Στις διαφάνειες, **1-1 αντιστοιχία** σημαίνει ένα-προς-ένα **και** επί (bijection, [[Uni/ΕΠΛ111/04 - Συναρτήσεις/04 - Αντιστοιχία και Αντίστροφη|Συναρτήσεις 04]]), ενώ «1-1» σκέτο σημαίνει μόνο ένα-προς-ένα. Μια f : Z⁺ → A που είναι μόνο 1-1 **δεν** αρκεί: π.χ. f(n) = 2n είναι 1-1 προς το Z, αλλά δεν «απαριθμεί» το Z (λείπουν οι περιττοί και οι αρνητικοί).

**Ορολογία:**

| Όρος | Σημασία |
|---|---|
| **αριθμήσιμο** (countable) | πεπερασμένο **ή** \|A\| = ℵ₀ |
| **αριθμήσιμα άπειρο** (countably infinite) | άπειρο **και** \|A\| = ℵ₀ (επέκταση, Rosen) |
| **μη αριθμήσιμο** (uncountable) | **δεν** υπάρχει καμία τέτοια λίστα (π.χ. R, [[06 - Μη Αριθμήσιμα Σύνολα|06]]) |

> [!tip] Άλλα βιβλία
> Κάποια βιβλία λένε «αριθμήσιμο» μόνο για τα **άπειρα** (και «το πολύ αριθμήσιμο» για πεπερασμένο ή αριθμήσιμο άπειρο). Στο μάθημα, όπως στο Rosen, **και τα πεπερασμένα είναι αριθμήσιμα** (διαφάνεια 3).

## 4. Ίδιος πληθικός αριθμός (επέκταση)

Η ιδέα «ίδιο μέγεθος» γενικεύεται σε όλα τα σύνολα:

> [!note] |A| = |B|
> Τα A και B έχουν **τον ίδιο πληθικό αριθμό** αν υπάρχει **ένα-προς-ένα αντιστοιχία** f : A → B.

Για πεπερασμένα σύνολα συμφωνεί με το γνωστό πλήθος ([[Uni/ΕΠΛ111/03 - Σύνολα/03 - Πληθικός Αριθμός και Δυναμοσύνολο|Σύνολα 03]]). Τρεις ιδιότητες που χρησιμοποιούμε συνέχεια:

| Ιδιότητα | Γιατί |
|---|---|
| \|A\| = \|A\| | η ταυτοτική ι_A είναι αντιστοιχία |
| \|A\| = \|B\| ⇒ \|B\| = \|A\| | η **αντίστροφη** αντιστοιχίας είναι αντιστοιχία ([[Uni/ΕΠΛ111/04 - Συναρτήσεις/04 - Αντιστοιχία και Αντίστροφη#5. Ιδιότητες της αντίστροφης\|Συναρτήσεις 04 §5]]) |
| \|A\| = \|B\| και \|B\| = \|C\| ⇒ \|A\| = \|C\| | η **σύνθεση** αντιστοιχιών είναι αντιστοιχία ([[Uni/ΕΠΛ111/04 - Συναρτήσεις/05 - Σύνθεση Συναρτήσεων#7. Σύνθεση και κατηγορίες (επέκταση)\|Συναρτήσεις 05 §7]]) |

> [!tip] Συνέπεια για τις ασκήσεις
> - Η αντιστοιχία μπορεί να πηγαίνει **και ανάποδα**: μια αντιστοιχία g : A → Z⁺ αρκεί (η g⁻¹ : Z⁺ → A είναι αντιστοιχία).
> - Αρκεί αντιστοιχία με **οποιοδήποτε** γνωστό αριθμήσιμο άπειρο σύνολο: N, Z, οι άρτιοι, … Π.χ. αν A ↔ Z και Z ↔ Z⁺, τότε A ↔ Z⁺.

## 5. Το άπειρο δεν συμπεριφέρεται σαν το πεπερασμένο

Σε πεπερασμένο σύνολο, ένα **γνήσιο** υποσύνολο έχει πάντα **λιγότερα** στοιχεία. Στα άπειρα σύνολα αυτό **δεν** ισχύει:

![[Ορισμός - Γνήσιο Υποσύνολο ίδιου Μεγέθους.png|800]]

- f : Z⁺ → {2, 4, 6, …}, f(n) = 2n είναι αντιστοιχία, άρα οι θετικοί άρτιοι έχουν **τον ίδιο** πληθικό αριθμό με το Z⁺, αν και είναι «τα μισά».
- **Ξενοδοχείο του Hilbert:** ένα ξενοδοχείο με δωμάτια 1, 2, 3, … είναι γεμάτο. Έρχεται νέος πελάτης: όποιος είναι στο n πάει στο n + 1, και ο νέος μπαίνει στο 1. Η g(n) = n + 1 είναι αντιστοιχία Z⁺ → Z⁺ ∖ {1}.

> [!example]- Ακόμα πιο «παράξενα» (ξενοδοχείο Hilbert)
> - **ν νέοι πελάτες:** όποιος είναι στο n πάει στο n + ν· οι νέοι στα 1, …, ν. Έτσι δείχνεται ότι το Z⁺ ∪ {0, −1, …, −(ν−1)} είναι αριθμήσιμο ([[02 - Αριθμήσιμα Άπειρα Σύνολα#2. Το Z⁺ ∪ {0, −1, …, −ν}|02 §2]]).
> - **Άπειροι νέοι πελάτες** (ένα λεωφορείο με θέσεις 1, 2, 3, …): όποιος είναι στο n πάει στο **2n**, και ο επιβάτης της θέσης k στο **2k − 1**. Έτσι δείχνεται ότι η ένωση δύο αριθμήσιμων είναι αριθμήσιμη ([[05 - Υποσύνολα και Ενώσεις|05]]).
> - **Άπειρα λεωφορεία:** χρειάζεται η ιδέα των διαγωνίων ([[03 - Οι Ρητοί Αριθμοί|03]]).
> - **Ένα λεωφορείο με έναν επιβάτη για κάθε πραγματικό του (0, 1):** **δεν** χωράει. Αυτό είναι το θεώρημα του Cantor ([[06 - Μη Αριθμήσιμα Σύνολα|06]]).

> [!warning] Για πεπερασμένα σύνολα ισχύει το αντίθετο
> Αν A πεπερασμένο και B ⊊ A, τότε |B| < |A| και **δεν** υπάρχει αντιστοιχία A → B (περιστερώνας, [[Uni/ΕΠΛ111/04 - Συναρτήσεις/03 - Ένα-προς-ένα και Επί#6. Πεπερασμένα σύνολα: το μέγεθος μετράει|Συναρτήσεις 03 §6]]). Επίσης, για πεπερασμένα σύνολα ίδιου μεγέθους, 1-1 ⇔ επί. Για άπειρα **όχι**: η g(n) = n + 1 στο Z⁺ → Z⁺ είναι 1-1 αλλά όχι επί.

## 6. Συνταγή: πώς δείχνω ότι ένα άπειρο σύνολο είναι αριθμήσιμο

> [!important] Τέσσερα βήματα
> 1. **Όρισε** f : Z⁺ → A με τύπο (ή με περιπτώσεις). Βοηθάει να γράψεις πρώτα τη λίστα f(1), f(2), f(3), … και να βρεις το μοτίβο.
> 2. **Καλά ορισμένη:** για κάθε n ∈ Z⁺, f(n) ∈ A.
> 3. **Ένα-προς-ένα:** «Έστω f(x) = f(y)» → … → «x = y».
> 4. **Επί:** «Έστω y ∈ A αυθαίρετο»· βρες x **∈ Z⁺** με f(x) = y.
>
> Συνταγές για 1-1 και επί: [[Uni/ΕΠΛ111/04 - Συναρτήσεις/03 - Ένα-προς-ένα και Επί|Συναρτήσεις 03]]. Λυμένα παραδείγματα: [[02 - Αριθμήσιμα Άπειρα Σύνολα|02]].

Για το «μη αριθμήσιμο» δεν αρκεί να μη βρεις λίστα· πρέπει να αποδείξεις ότι **καμία** λίστα δεν υπάρχει ([[06 - Μη Αριθμήσιμα Σύνολα|06]]).

## 7. Συχνά Λάθη

> [!warning] Προσοχή
> - **«Άπειρο ⇒ μη αριθμήσιμο».** Λάθος: τα Z⁺, Z, Q είναι άπειρα **και** αριθμήσιμα.
> - **«Πεπερασμένο ⇒ δεν είναι αριθμήσιμο».** Λάθος: κάθε πεπερασμένο (και το ∅) είναι αριθμήσιμο.
> - **Μόνο 1-1 ή μόνο επί.** Η αντιστοιχία θέλει **και τα δύο**.
> - **Πεδίο ορισμού N αντί για Z⁺.** Ο ορισμός μιλά για **Z⁺** = {1, 2, …}. Αν χρησιμοποιήσεις N = {0, 1, 2, …}, συνδύασε με την αντιστοιχία N → Z⁺, n ↦ n + 1 (ή ξεκίνα από το 1).
> - **«Γνήσιο υποσύνολο ⇒ μικρότερο».** Ισχύει μόνο για πεπερασμένα σύνολα.
> - **Λίστα με επαναλήψεις.** Αν ένα στοιχείο εμφανίζεται δύο φορές, η f δεν είναι 1-1. Οι επαναλήψεις **παραλείπονται** ([[03 - Οι Ρητοί Αριθμοί|03]]).
> - **Στοιχείο σε «άπειρη» θέση.** «Πρώτα όλοι οι θετικοί, μετά οι αρνητικοί» δεν είναι λίστα: κανένας αρνητικός δεν παίρνει θέση n ∈ Z⁺ ([[02 - Αριθμήσιμα Άπειρα Σύνολα|02]]).
