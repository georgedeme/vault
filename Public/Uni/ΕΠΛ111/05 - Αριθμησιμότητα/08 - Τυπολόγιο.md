# 08 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Ορισμοί

**A αριθμήσιμο ⇔ A πεπερασμένο ή υπάρχει 1-1 αντιστοιχία Z⁺ → A** (δηλ. |A| = |Z⁺| = ℵ₀)

- **1-1 αντιστοιχία** = ένα-προς-ένα **και** επί (bijection). Μπορεί και A → Z⁺ (αντίστροφη).
- Πεπερασμένο με |A| = ν: αντιστοιχία {1, …, ν} → A· το ∅ (ν = 0) είναι αριθμήσιμο.
- **Λίστα:** a₁, a₂, a₃, …, κάθε στοιχείο **ακριβώς μία φορά**, σε **πεπερασμένη** θέση.
- **|A| = |B|** ⇔ υπάρχει αντιστοιχία A → B (ανακλαστική, συμμετρική, μεταβατική).
- **Μη αριθμήσιμο:** **καμία** τέτοια λίστα δεν υπάρχει.

## 2. Συνταγή αντιστοιχίας Z⁺ → A

1. **Όρισε** f (γράψε πρώτα f(1), f(2), f(3), …)
2. **f(x) ∈ A** για κάθε x ∈ Z⁺
3. **1-1:** f(x) = f(y) ⇒ x = y (σε τύπους με περιπτώσεις: και η **μικτή** περίπτωση)
4. **Επί:** για y ∈ A, βρες x **και έλεγξε x ∈ Z⁺**

## 3. Αντιστοιχίες των διαφανειών

| Σύνολο | f : Z⁺ → A | Λίστα |
|---|---|---|
| θετικοί περιττοί | 2x − 1 | 1, 3, 5, 7, … |
| Z⁺ ∪ {0, −1, …, −ν} | x − ν − 1 | −ν, …, −1, 0, 1, 2, … |
| Z | −x/2 (x άρτιος), (x − 1)/2 (x περιττός) | 0, −1, 1, −2, 2, … |
| Q⁺ | διαγώνιοι α + β = 2, 3, …, χωρίς διπλότυπα | 1, 1/2, 2, 3, 1/3, 1/4, 2/3, 3/2, 4, … |
| Σ* (Σ = {α, β, γ}) | κατά μήκος, μετά λεξικογραφικά | ε, α, β, γ, αα, αβ, … |

**Τέσσερα σχήματα λίστας:** μετατόπιση (πεπερασμένα μπροστά) · ζιγκ-ζαγκ (δύο ουρές) · διαγώνιοι (ζεύγη) · κατά μήκος (συμβολοσειρές). **Κοινή ιδέα:** πεπερασμένα κομμάτια, παράλειψη διπλών.

## 4. Κανόνες

| Αν… | τότε… |
|---|---|
| S ⊆ T, T αριθμήσιμο | S αριθμήσιμο |
| S ⊆ T, S μη αριθμήσιμο | T μη αριθμήσιμο |
| g : A → B **1-1**, B αριθμήσιμο | A αριθμήσιμο |
| h : A → B **επί**, A αριθμήσιμο | B αριθμήσιμο |
| A, B αριθμήσιμα | A ∪ B, A ∩ B, A ∖ B, A × B αριθμήσιμα |
| A₁, A₂, … αριθμήσιμα (αριθμήσιμα πολλά) | ⋃ Aᵢ αριθμήσιμο (διαγώνιοι) |
| A μη αριθμήσιμο, B αριθμήσιμο | **A ∖ B μη αριθμήσιμο** (διαφάνεια 24) |
| A, C μη αριθμήσιμα | A ∖ C: **οτιδήποτε** |

**Διαφάνεια 24:** A = (A ∖ B) ∪ (A ∩ B)· A ∩ B ⊆ B αριθμήσιμο· ένωση δύο αριθμήσιμων αριθμήσιμη ⇒ A αριθμήσιμο, αντίφαση.

## 5. Ποιο σύνολο είναι τι

| Πεπερασμένα | Αριθμήσιμα άπειρα (ℵ₀) | Μη αριθμήσιμα |
|---|---|---|
| ∅, {1, …, ν}, Aᵏ (A πεπερ.) | N, Z⁺, Z, άρτιοι, πρώτοι | R, (0, 1), (a, b), [0, 1] |
| P(A) για πεπερ. A | Q⁺, Q, Z⁺ × Z⁺, Z × Z | R ∖ Z, R ∖ Q (άρρητοι) |
| | Σ* (Σ πεπερ., ≠ ∅), προγράμματα | άπειρες δυαδικές ακολουθίες |
| | υπολογίσιμοι αριθμοί | P(Z⁺), συναρτήσεις Z⁺ → {0, …, 9} |

## 6. Διαγώνιο επιχείρημα (R μη αριθμήσιμο)

1. Υπόθεσε ότι το (0, 1) απαριθμείται: ρ₁, ρ₂, …, με ρ_μ = 0.δ_μ1 δ_μ2 …
2. Κατασκεύασε x = 0.δ₁δ₂… με **δᵥ ≠ δᵥᵥ** (διαφάνεια: δᵥ = 1 αν δᵥᵥ = 0, αλλιώς 0)
3. x ≠ ρᵥ για κάθε ν (διαφέρουν στο ν-οστό ψηφίο) ⇒ αντίφαση

**⚠️ Κενά:** (α) 0.0999… = 0.1: διάλεξε μορφές χωρίς ουρά από 9. (β) Ο κανόνας 0/1 μπορεί να δώσει x = 0 ∉ (0, 1): χρησιμοποίησε [0, 1) ή ψηφία 4/5 (Rosen).

**Το x πρέπει να ανήκει στο σύνολο:** γι' αυτό το διαγώνιο **δεν** «αποδεικνύει» ότι το Q ή το Z⁺ είναι μη αριθμήσιμα.

## 7. Υπολογισιμότητα

- **Υπολογίσιμος α ∈ (0, 1):** πρόγραμμα που για είσοδο ν > 0 δίνει το ν-οστό ψηφίο. (1/3: «τύπωσε 3»)
- **Υπολογίσιμη συνάρτηση:** υπάρχει πρόγραμμα που την υπολογίζει.
- Προγράμματα **αριθμήσιμα** (⊆ Σ*), κάθε πρόγραμμα → το πολύ ένας αριθμός/μία συνάρτηση.
- (0, 1) και {f : Z⁺ → {0, …, 9}} **μη αριθμήσιμα** (ρ ↦ f_ρ, f_ρ(x) = δₓ, είναι 1-1).
- ⇒ **υπάρχουν** μη υπολογίσιμοι αριθμοί και συναρτήσεις (μη κατασκευαστικά).

## 8. Οι 10 παγίδες

1. **Άπειρο ≠ μη αριθμήσιμο** (Z, Q). **Πυκνό ≠ μη αριθμήσιμο** (Q).
2. Τα **πεπερασμένα** (και το ∅) **είναι** αριθμήσιμα.
3. **«1-1 αντιστοιχία»** = 1-1 **και** επί.
4. Στο «επί», το x πρέπει να ανήκει στο **Z⁺** (π.χ. (β + 1)/2 με β περιττό).
5. **Καμία άπειρη ουρά πριν από άλλα στοιχεία** («πρώτα θετικοί, μετά αρνητικοί» ✗, γραμμή-γραμμή ✗, καθαρά λεξικογραφικά ✗).
6. **Διπλότυπα** (2/4 = 1/2, επικαλύψεις σε ενώσεις): παράλειψη, αλλιώς όχι 1-1.
7. **Υποσύνολο μη αριθμήσιμου** μπορεί να είναι αριθμήσιμο (Z ⊆ R).
8. **A ∖ C** με C μη αριθμήσιμο: οτιδήποτε.
9. **Διαγώνιο:** δύο μορφές (0.0999… = 0.1), x = 0, x εκτός συνόλου.
10. **Γνήσιο υποσύνολο** άπειρου μπορεί να έχει το ίδιο μέγεθος (άρτιοι ↔ Z⁺).
