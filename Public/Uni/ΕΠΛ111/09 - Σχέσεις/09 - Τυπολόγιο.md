# 09 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Ορισμοί

| Έννοια | Ορισμός |
|---|---|
| Σχέση από A στο B | Σ ⊆ A × B · γράφουμε (α,β) ∈ Σ ή α Σ β |
| Σχέση πάνω στο A | Σ ⊆ A × A |
| Συνάρτηση | σχέση όπου κάθε α ∈ A έχει **ακριβώς ένα** ζεύγος (α, ·) |
| Διαγώνια Δ_A | {(α,α) \| α ∈ A} |
| Αντίστροφη Σ⁻¹ | {(β,α) \| (α,β) ∈ Σ} · στον πίνακα: ανάστροφος |
| Σύνθεση Σ₁ ∘ Σ₂ | {(α,γ) \| ∃β: (α,β) ∈ Σ₁ ∧ (β,γ) ∈ Σ₂} · **πρώτα Σ₁** (σύμβαση διαφανειών) |
| Δυνάμεις | Σ¹ = Σ, Σᵛ⁺¹ = Σᵛ ∘ Σ · (α,β) ∈ Σᵛ ⇔ μονοπάτι μήκους ν |
| Σ⁺ (συνδετικότητα) | ⋃_{κ≥1} Σᵏ = Σ ∪ Σ² ∪ ⋯ ∪ Σ^{\|A\|} (πεπερασμένο A) |

## 2. Οι τέσσερις ιδιότητες

| Ιδιότητα | Τύπος | Πίνακας | Γράφημα | Αντιπαράδειγμα = |
|---|---|---|---|---|
| Αυτοπαθής | ∀x (x,x) ∈ Σ | διαγώνιος όλο 1 | βρόχος παντού | ένα α με (α,α) ∉ Σ |
| Συμμετρική | (x,y) ∈ Σ → (y,x) ∈ Σ | M = Mᵀ | κάθε βέλος έχει επιστροφή | (α,β) ∈ Σ, (β,α) ∉ Σ |
| Αντισυμμετρική | (x,y),(y,x) ∈ Σ → x = y | εκτός διαγωνίου ποτέ 1 και στα δύο | κανένα πήγαινε-έλα | (α,β),(β,α) ∈ Σ με α ≠ β |
| Μεταβατική | (x,y),(y,z) ∈ Σ → (x,z) ∈ Σ | Σ² ⊆ Σ | κάθε 2-βήμα έχει συντόμευση | (α,β),(β,γ) ∈ Σ, (α,γ) ∉ Σ |

| Σχέση | Αυτοπ. | Συμμ. | Αντισ. | Μεταβ. |
|---|---|---|---|---|
| = | ✓ | ✓ | ✓ | ✓ |
| ≤ , \| (Z⁺), ⊆ | ✓ | ✗ | ✓ | ✓ |
| < | ✗ | ✗ | ✓ | ✓ |
| ≠ | ✗ | ✓ | ✗ | ✗ |
| mod ν, «ίδιο f(α)» | ✓ | ✓ | ✗ | ✓ |
| \| (Z) | ✗ | ✗ | ✗ | ✓ |
| ∅ (A ≠ ∅) | ✗ | ✓ | ✓ | ✓ |

## 3. Μετρήσεις (|A| = ν)

| Σχέσεις | Πλήθος | ν = 3 |
|---|---|---|
| όλες πάνω στο A / από A (μ) στο B (ν) | 2^(ν²) / 2^(μν) | 512 |
| αυτοπαθείς (διαφάνεια 19) | 2^(ν(ν−1)) | 64 |
| συμμετρικές | 2^(ν(ν+1)/2) | 64 |
| αντισυμμετρικές | 2^ν · 3^(ν(ν−1)/2) | 216 |
| αυτοπαθείς και συμμετρικές | 2^(ν(ν−1)/2) | 8 |
| ισοδυναμίας (= διαμερισμοί, Bell) | 1, 2, 5, 15, 52 | 5 |
| ολικές διατάξεις | ν! | 6 |
| μεταβατικές / μερικές διατάξεις | χωρίς τύπο: 2, 13, 171 / 1, 3, 19 | 171 / 19 |

## 4. Θεωρήματα

| Θεώρημα | Διαφάνεια |
|---|---|
| Σ₁, Σ₂ συμμετρικές ⇒ Σ₁ ∪ Σ₂ συμμετρική | 23 |
| Σ₁, Σ₂ μεταβατικές ⇏ Σ₁ ∪ Σ₂ μεταβατική ({(1,2)} ∪ {(2,1)}) | 22 |
| Σ μεταβατική ⇔ Σᵛ ⊆ Σ για κάθε ν ≥ 1 (⇔ Σ² ⊆ Σ) | 29–30 |
| Αυτοπαθής κλειστότητα = Σ ∪ Δ_A | 39 |
| Συμμετρική κλειστότητα = Σ ∪ Σ⁻¹ | 42 |
| Μονοπάτι μήκους ν από α σε β ⇔ (α,β) ∈ Σᵛ | 47 |
| Μεταβατική κλειστότητα = Σ⁺ | 49–50 |
| \|A\| = ν: μονοπάτι ⇒ μονοπάτι μήκους ≤ ν (περιστερώνας + αφαίρεση κύκλου) | 52–54 |
| Για σχέση ισοδυναμίας: (α,β) ∈ Σ ⇔ [α] = [β] ⇔ [α] ∩ [β] ≠ ∅ | 66 |
| Κλάσεις ισοδυναμίας ↔ διαμερισμοί | 65–70 |
| Το απόλυτα μέγιστο/ελάχιστο είναι μοναδικό (αν υπάρχει) | 79 |

**Τι διατηρείται** (και οι δύο έχουν την ιδιότητα): η **τομή** διατηρεί όλες. Ένωση: αυτοπ. ✓, συμμ. ✓, αντισ. ✗, μεταβ. ✗. Διαφορά: αυτοπ. ✗, συμμ. ✓, αντισ. ✓, μεταβ. ✗. Αντίστροφη: όλες ✓.

## 5. Κλειστότητες

| Ιδιότητα | Κλειστότητα | Πώς |
|---|---|---|
| Αυτοπαθής | Σ ∪ Δ_A | πρόσθεσε **όλα** τα (α,α), ακόμα και για α που δεν εμφανίζονται |
| Συμμετρική | Σ ∪ Σ⁻¹ | γύρνα κάθε βέλος |
| Μεταβατική | Σ⁺ = Σ ∪ ⋯ ∪ Σ^{\|A\|} | πρόσθεσε συντομεύσεις **μέχρι να μην αλλάζει τίποτα**, ή Warshall |
| Αντισυμμετρική | **δεν υπάρχει** | μόνο προσθέτουμε, δεν διορθώνεται |
| Ισοδυναμίας | (Σ ∪ Σ⁻¹ ∪ Δ_A)⁺ | η μεταβατική **τελευταία** |

**Warshall:** για κ = 1…ν: κάθε γραμμή i με 1 στη στήλη κ γίνεται γρ. i ∨ γρ. κ.

## 6. Ισοδυναμία, διαμερισμοί, διατάξεις

| Έννοια | Ορισμός |
|---|---|
| Σχέση ισοδυναμίας | αυτοπαθής + **συμμετρική** + μεταβατική |
| Κλάση [α]_Σ | {β \| (α,β) ∈ Σ} · α ∈ [α] · κάθε στοιχείο της είναι αντιπρόσωπος |
| Διαμερισμός του A | {Aᵢ}: Aᵢ ≠ ∅, ανά δύο ξένα, ένωση = A |
| Σχέση από διαμερισμό | ⋃ (Aᵢ × Aᵢ) · Σνᵢ² ζεύγη |
| Μερική διάταξη | αυτοπαθής + **αντισυμμετρική** + μεταβατική · poset (A, ≼) |
| α ≺ β | α ≼ β και α ≠ β |
| Μη συγκρίσιμα | ούτε α ≼ β ούτε β ≼ α |
| Ολική διάταξη | μερική + κάθε δύο συγκρίσιμα |
| Μέγιστο (maximal) | **κανένα** β με α ≺ β · 0, 1 ή πολλά |
| Ελάχιστο (minimal) | **κανένα** β με β ≺ α |
| Απόλυτα μέγιστο (greatest) | β ≼ α για **κάθε** β · το πολύ ένα |
| Απόλυτα ελάχιστο (least) | α ≼ β για **κάθε** β |

**Λυμένα παραδείγματα:** [α] για «α = ±β» = {α, −α} (και [0] = {0}) · [κ]_{Σ₄} = υπόλοιπο κ mod 4, 4 κλάσεις · ({2,4,5,10,12,20}, |): μέγιστα 12, 20, ελάχιστα 2, 5, κανένα απόλυτο · (P({1,2,3}), ⊆): απόλυτα μέγιστο {1,2,3}, απόλυτα ελάχιστο ∅.

## 7. Οι 12 παγίδες

1. **Σειρά στο ζεύγος:** (α,β) ∈ Σ ⇏ (β,α) ∈ Σ.
2. **Αυτοπάθεια εξαρτάται από το A:** {(1,1),(2,2)} όχι αυτοπαθής στο {1,2,3}.
3. **Αντισυμμετρική ≠ όχι συμμετρική:** η = είναι και τα δύο, το {(1,2),(2,1),(1,3)} κανένα.
4. **Μεταβατική με x = z:** {(1,2),(2,1)} θέλει (1,1) και (2,2).
5. **Κενή αλήθεια:** {(1,2)} και ∅ είναι μεταβατικές.
6. **Συμμετρική + μεταβατική ⇏ αυτοπαθής** (στοιχεία χωρίς ζεύγη).
7. **Σύνθεση:** στις διαφάνειες Σ₁ ∘ Σ₂ = πρώτα Σ₁. Η διαφάνεια 26 έχει τα αποτελέσματα ανάποδα (⚠️).
8. **Σ⁺ = ένωση δυνάμεων**, όχι η τελευταία· και μία προσθήκη ζευγών δεν αρκεί.
9. **(α,α) στη μεταβατική κλειστότητα** μόνο αν το α είναι σε κύκλο.
10. **[0] = {0}** στο «α = ±β»· **−3 ∈ [1]** mod 4.
11. **< και | (στο Z) δεν είναι μερικές διατάξεις.**
12. **Μέγιστο ≠ απόλυτα μέγιστο**· και ο ορισμός του απόλυτα μέγιστου θέλει ≼, όχι ≺ (⚠️ διαφάνεια 79).
