# 05 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Ο πίνακας

Διαλέγω **μ** από **ν** διαφορετικά αντικείμενα:

| | **Διατεταγμένη** (η σειρά μετράει) | **Μη-διατεταγμένη** (η σειρά δεν μετράει) |
|---|---|---|
| **Χωρίς επανατοποθέτηση** | P(ν,μ) = ν!/(ν−μ)! = ν(ν−1)⋯(ν−μ+1) | C(ν,μ) = ν!/(μ!(ν−μ)!) |
| **Με επανατοποθέτηση** | ν^μ | C(ν+μ−1, μ) = (ν+μ−1)!/((ν−1)! μ!) |
| Γράφεται | (α, β, γ) — πλειάδα | {α, β, γ} — σύνολο / πολυσύνολο |
| Παράδειγμα | μετάλλια, κωδικοί | επιτροπές, φρούτα |

**Οι δύο ερωτήσεις:** (1) αν ανταλλάξω δύο επιλογές, αλλάζει το αποτέλεσμα; → σειρά. (2) μπορεί το ίδιο να επιλεγεί δύο φορές; → επανάληψη.

## 2. Ταυτότητες

| Ταυτότητα | Σημείωση |
|---|---|
| 0! = 1 · P(ν, ν) = ν! · P(ν, 0) = 1 | |
| P(ν, μ) = C(ν, μ) · μ! | απόδειξη του τύπου του C (διαφάνειες 10–11) |
| C(ν, 0) = C(ν, ν) = 1 · C(ν, 1) = ν | |
| C(ν, μ) = C(ν, ν − μ) | μέσα ↔ έξω |
| C(ν, μ) = C(ν−1, μ−1) + C(ν−1, μ) | Pascal |
| Σ_{μ=0}^{ν} C(ν, μ) = 2^ν | όλα τα υποσύνολα |
| P(ν, μ) = C(ν, μ) = 0 αν μ > ν | δεν φτάνουν τα αντικείμενα |

**Υπολογισμός:** C(ν,μ) = [μ παράγοντες ν(ν−1)⋯] / μ!. C(11,4) = 11·10·9·8/24 = 330.

**Τρίγωνο Pascal:** 1 · 1 1 · 1 2 1 · 1 3 3 1 · 1 4 6 4 1 · 1 5 10 10 5 1 · 1 6 15 20 15 6 1

## 4. Τεχνικές

| Τεχνική | Πότε | Παράδειγμα |
|---|---|---|
| **Κολλημένο κομμάτι** | «περιέχει το ΑΒΓ», «Α και Β δίπλα» | ΑΒΓ ως ένα στοιχείο: 6!· με ελεύθερη εσωτερική σειρά × 3! |
| **Συμπλήρωμα** | «τουλάχιστον ένα», «όχι δίπλα» | ≥ 1 γυναίκα: C(15,3) − C(6,3) = 435 |
| **Πρώτα «ποια», μετά «με ποια σειρά»** | μισο-διατεταγμένα (επιτροπή με πρόεδρο) | C(10,3) · 3 = 360 |
| **Γινόμενο συνδυασμών** | «α από την ομάδα 1 **και** β από την ομάδα 2» | C(11,4) · C(9,3) |
| **Άθροισμα συνδυασμών** | «ή» με ξένες περιπτώσεις | C(9,3) + C(6,3) |
| **Θέσεις = υποσύνολο** | συμβολοσειρές με ακριβώς μ από κάτι | C(ν,μ) |
| **Ίδια αντικείμενα σε σειρά** | λέξεις με επαναλαμβανόμενα γράμματα | ΑΝΑΝΑΣ: 6!/(3!2!1!) = 60 |
| **Αστέρια και μπάρες** | ίδια αντικείμενα σε διαφορετικά κουτιά, x₁ + ⋯ + xᵥ = μ | C(ν+μ−1, μ) |
| **Κάτω φράγματα** | xᵢ ≥ κᵢ | μ′ = μ − Σκᵢ, μετά αστέρια και μπάρες |
| **Θετικοί ακέραιοι** | όλα ≥ 1 | C(μ − 1, ν − 1) |
| **Άνω φράγματα** | xᵢ ≤ κ | όλα − (όσα έχουν xᵢ ≥ κ + 1) |

## 5. Οι 10 παγίδες

1. **Σειρά:** επιτροπή = συνδυασμός, ρόλοι/μετάλλια/θέσεις = διάταξη. Ίδια βραβεία = συνδυασμός.
2. **P(ν, μ):** ο τελευταίος παράγοντας είναι ν − μ + 1, μ παράγοντες συνολικά.
3. **ν^μ:** βάση = επιλογές, εκθέτης = θέσεις.
4. **Σταθερή θέση** (αφετηρία, πρώτο ψηφίο ≠ 0): βγάλ' την πριν εφαρμόσεις τύπο. Πόλεις: 7!, όχι 8!.
5. **«Τουλάχιστον ένα»:** συμπλήρωμα, όχι «ένας υποχρεωτικός × C(υπόλοιποι)» (819 ≠ 435).
6. **«και» = ·, «ή» = +.** C(11,4) · C(9,3) ≠ C(20,7).
7. **Κολλημένα κομμάτια** που μοιράζονται γράμμα (ΑΒ και ΒΓ) = ένα κομμάτι ΑΒΓ.
8. **Αστέρια/μπάρες:** ν − 1 μπάρες· C(ν+μ−1, μ), όχι C(ν+μ−1, ν).
9. **Κάτω φράγματα:** αφαίρεσε από το δεξί μέλος πρώτα (11 − 6 = 5).
10. **Ίδια ή διαφορετικά αντικείμενα;** Διαφορετικές μπάλες σε κουτιά: ν^μ. Ίδιες: C(ν+μ−1, μ).
