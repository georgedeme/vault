# 12 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Βασικές έννοιες

**Εικασία** → (απόδειξη) → **Θεώρημα** · **Λήμμα** = βοηθητικό θεώρημα · **Αξίωμα** = δεκτό χωρίς απόδειξη · **Κανόνας συμπερασμού** = ταυτολογία της μορφής P₁ ∧ ⋯ ∧ Pₙ → Q

**Έγκυρο επιχείρημα:** όποτε όλες οι υποθέσεις T, και το συμπέρασμα T. Αποτυγχάνει **μόνο** αν υπάρχει γραμμή «υποθέσεις T, συμπέρασμα F».

## 2. Κανόνες συμπερασμού (Προτασιακή Λογική)

| Υποθέσεις | Συμπέρασμα | Όνομα |
|---|---|---|
| P | P ∨ Q | Πρόσθεση |
| P ∧ Q | P | Απλοποίηση |
| P, Q | P ∧ Q | Σύζευξη |
| P, P → Q | Q | **Modus ponens** |
| ¬Q, P → Q | ¬P | **Modus tollens** |
| P → Q, Q → R | P → R | Υποθετικός συλλογισμός |
| P ∨ Q, ¬P | Q | Διαζευκτικός συλλογισμός |

**Πλάνες (ΔΕΝ είναι ταυτολογίες)** – και οι δύο «σπάνε» στο P = F, Q = T:

| Υποθέσεις | «Συμπέρασμα» | Όνομα |
|---|---|---|
| P → Q, Q | P ❌ | Επιβεβαίωση του Συμπεράσματος |
| P → Q, ¬P | ¬Q ❌ | Άρνηση της Υπόθεσης |
| P ∨ Q, P | ¬Q ❌ | (το ∨ είναι εγκλειστικό) |

## 3. Κανόνες με ποσοδείκτες

| Από | Παίρνω | Όνομα | Προσοχή |
|---|---|---|---|
| ∀x P(x) | P(α), α αυθαίρετο | Καθολική εξειδίκευση | — |
| P(α), α **αυθαίρετο** | ∀x P(x) | Καθολική γενίκευση | όχι από συγκεκριμένο ή από «κάποιο» α |
| ∃x P(x) | P(α), για **κάποιο** α | Υπαρξιακή εξειδίκευση | **νέο** όνομα κάθε φορά |
| P(α), για κάποιο α | ∃x P(x) | Υπαρξιακή γενίκευση | — |

Σειρά: **Υπαρξιακή εξειδίκευση πρώτα**, μετά Καθολική· βγάλε ποσοδείκτες → Προτασιακή Λογική → ξαναβάλε.

## 4. Μέθοδοι αποδείξεων

| Μέθοδος | Υποθέτω | Δείχνω | Πότε |
|---|---|---|---|
| **Ευθεία** | P | Q | Η υπόθεση δίνει χρήσιμο ορισμό |
| **Έμμεση** | ¬Q | ¬P | Υπόθεση για α², 3α+2, αβ· συμπέρασμα για α |
| **Αντίφαση** (για P) | ¬P | κάτι ψευδές (R ∧ ¬R) | «δεν υπάρχει», «άρρητος», «άπειροι» |
| **Αντίφαση** (για P → Q) | **P ∧ ¬Q** | κάτι ψευδές | όπως η έμμεση, πιο ευέλικτη |
| **Περιπτώσεις** | P₁ ∨ ⋯ ∨ Pᵥ | Pⱼ → Q για κάθε j | \|·\|, max, mod, άρτιος/περιττός, πρόσημο |
| **Ισοδυναμία** P ↔ Q | — | P → Q **και** Q → P | «αν και μόνο αν» |
| **Ισοδυναμία** ν προτάσεων | — | κύκλος P₁ → P₂ → ⋯ → Pᵥ → P₁ | ν συνεπαγωγές |
| **Ύπαρξη** κατασκευαστική | — | βρες α με P(α) + επαλήθευση | «υπάρχει» |
| **Ύπαρξη** μη-κατασκευαστική | — | αντίφαση / περιπτώσεις | στοιχείο άγνωστο |
| **Μοναδικότητα** | P(x) και P(y) | x = y | «ακριβώς ένα» (+ ύπαρξη!) |
| **Κατάρριψη** ∀x P(x) | — | ένα x με ¬P(x) | «αποδείξτε ή καταρρίψτε» |

## 5. Ορισμοί (για ακέραιους)

| Έννοια | Γράψε |
|---|---|
| α άρτιος | α = 2κ, κ ακέραιος |
| α περιττός | α = 2κ + 1, κ ακέραιος |
| α ∣ β | β = κα, κ ακέραιος |
| α mod ν = υ | α = νκ + υ, 0 ≤ υ < ν |
| r ρητός | r = α/β, β ≠ 0, **χωρίς κοινό παράγοντα** |
| p πρώτος | p > 1, διαιρέτες μόνο 1 και p |
| \|γ\| | γ αν γ ≥ 0 · −γ αν γ < 0 |

**Μορφή-στόχος:** άρτιος = 2·(ακέραιος) · περιττός = 2·(ακέραιος) + 1 · πάντα γράψε «…αφού (παρένθεση) είναι ακέραιος».

## 7. Αρνήσεις (για έμμεση / αντίφαση)

| Πρόταση | Άρνηση |
|---|---|
| P → Q | P ∧ ¬Q |
| P ∨ Q | ¬P ∧ ¬Q |
| P ∧ Q | ¬P ∨ ¬Q |
| ∀x P(x) | ∃x ¬P(x) |
| ∃x P(x) | ∀x ¬P(x) |
| α > 0 | α ≤ 0 |
| x άρρητος | x = α/β ανάγωγο |

**Contrapositive** ¬Q → ¬P ≡ P → Q ✅ · **Αντίστροφη** Q → P ❌ · **Αντίθετη** ¬P → ¬Q ❌

## 8. Top-5 παγίδες

> [!warning] Τα πιο συχνά λάθη
> 1. Παράδειγμα αντί για απόδειξη σε «για κάθε».
> 2. Ίδιο γράμμα για διαφορετικούς αριθμούς (α = 2κ, β = 2κ).
> 3. Άρνηση της υπόθεσης αντί του συμπεράσματος στην έμμεση απόδειξη.
> 4. Περιπτώσεις που δεν καλύπτουν όλες τις τιμές (ξεχασμένο 0).
> 5. √(x²) = x αντί για |x|· πολλαπλασιασμός ανισότητας με αρνητικό χωρίς αλλαγή φοράς.
