# 06 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Ορισμός

**f : A → B** = ανάθεση **ακριβώς ενός** στοιχείου του B **σε κάθε** στοιχείο του A · **f(α) = β**

**Ως σύνολο ζευγών:** f = {(α, β) | α ∈ A ∧ f(α) = β} ⊆ A × B, με **∀α ∈ A ∃!β ∈ B ((α, β) ∈ f)**

| Έλεγχος «είναι συνάρτηση;» | Παραβίαση |
|---|---|
| ορίζεται για **κάθε** x ∈ A; | 1/x στο 0, √x για x < 0 |
| δίνει **μία** τιμή; | ±√x, «ένας διαιρέτης του x» |
| η τιμή **ανήκει στο B**; | x/2 με B = Z, x − 1 με B = N |

Βέλη: από **κάθε** α ∈ A βγαίνει **ακριβώς ένα**. Στο B κανένας περιορισμός.

**Ισότητα:** f = g ⇔ ίδιο πεδίο ορισμού, ίδιο πεδίο τιμών, f(x) = g(x) για κάθε x · **πλήθος συναρτήσεων A → B: |B|^|A|**

## 2. Ορολογία

| Όρος | Τι είναι |
|---|---|
| **πεδίο ορισμού** (domain) | A |
| **πεδίο τιμών** (codomain) | B |
| **πεδίο τιμών συναρτήσεως** (range) | f(A) = {f(α) \| α ∈ A} ⊆ B |
| **εικόνα** του α | f(α), **μοναδική** |
| **προεικόνα** του β | κάθε α με f(α) = β (0, 1 ή πολλές) |
| **εικόνα συνόλου** C ⊆ A | f(C) = {f(α) \| α ∈ C} · y ∈ f(C) ⇔ ∃x ∈ C (f(x) = y) |
| **αντίστροφη εικόνα** D ⊆ B | f⁻¹(D) = {x ∈ A \| f(x) ∈ D} (ορίζεται για **κάθε** f) |

f(C ∪ D) = f(C) ∪ f(D) · **f(C ∩ D) ⊆ f(C) ∩ f(D)** (= αν 1-1) · f⁻¹ σέβεται ∪, ∩, συμπλήρωμα **πάντα**

## 3. Κατηγορίες

| | Ορισμός | Άρνηση | Βέλη ανά β ∈ B |
|---|---|---|---|
| **1-1** (injective) | ∀x∀y (f(x) = f(y) → x = y) | ∃x∃y (f(x) = f(y) ∧ x ≠ y) | ≤ 1 |
| **επί** (surjective) | ∀y ∈ B ∃x ∈ A (f(x) = y) | ∃y ∈ B ∀x ∈ A (f(x) ≠ y) | ≥ 1 |
| **αντιστοιχία** (bijective) | 1-1 **και** επί | όχι 1-1 **ή** όχι επί | = 1 |

**1-1 ισοδύναμα:** ∀x∀y (x ≠ y → f(x) ≠ f(y)) (αντιθετοαντιστροφή) · **επί ισοδύναμα:** f(A) = B

| Θέλω να δείξω | Πώς |
|---|---|
| **1-1** | έστω f(x) = f(y) ⇒ άλγεβρα ⇒ x = y |
| **όχι 1-1** | **συγκεκριμένα** x ≠ y με f(x) = f(y) |
| **επί** | έστω y ∈ B· λύσε f(x) = y· **έλεγξε x ∈ A**· f(x) = y ✓ |
| **όχι επί** | **συγκεκριμένο** y ∈ B χωρίς λύση στο A |

Γνησίως μονότονη ⇒ 1-1 · τεστ οριζόντιας ευθείας: το πολύ μία τομή (1-1), τουλάχιστον μία (επί)

**Η κατηγορία εξαρτάται από τα A και B:** x² είναι Z → Z ✗✗ · N → N 1-1 · R → [0, ∞) επί · [0, ∞) → [0, ∞) αντιστοιχία

**Πεπερασμένα:** 1-1 ⇒ |A| ≤ |B| · επί ⇒ |A| ≥ |B| · **|A| = |B| ⇒ (1-1 ⇔ επί)** · **ΟΧΙ για άπειρα** (x + 1 στο N: 1-1, όχι επί)

Πλήθος: 1-1 = n(n − 1)⋯(n − m + 1) · αντιστοιχίες = n! (m = |A|, n = |B|)

## 4. Αντίστροφη

**Μόνο για αντιστοιχία f : A → B:** f⁻¹ : B → A, **f⁻¹(β) = α ⇔ f(α) = β** · f⁻¹ = {(β, α) | (α, β) ∈ f}

| Η f δεν είναι… | η «f⁻¹» παραβιάζει |
|---|---|
| 1-1 | «ακριβώς ενός» (κάποιο β με ≥ 2 εικόνες) |
| επί | «σε κάθε» (κάποιο β χωρίς εικόνα) |

**Υπολογισμός:** y = f(x) ⇒ λύσε ως προς x ⇒ f⁻¹(y) · f⁻¹ αντιστοιχία · (f⁻¹)⁻¹ = f

| f⁻¹(y) | f⁻¹(D) | 1/f(x) |
|---|---|---|
| στοιχείο του A, μόνο αν αντιστοιχία | υποσύνολο του A, πάντα | αριθμός |

## 5. Σύνθεση

f : A → B, g : B → C · **(g ∘ f)(α) = g(f(α))** · g ∘ f : A → C · **πρώτα η f** (η πιο δεξιά)

f(x) = 2x + 3, g(x) = 3x + 2: **f ∘ g = 6x + 7**, **g ∘ f = 6x + 11** · f(x) = x², g(x) = 2x + 1: **f ∘ g = (2x + 1)²**, **g ∘ f = 2x² + 1**

**Όχι αντιμεταθετική** · **προσεταιριστική** · ορίζεται αν f(A) ⊆ πεδίο ορισμού της g

**Ταυτοτική** ι_A : A → A, ι_A(α) = α · f ∘ ι_A = f = ι_B ∘ f · **f⁻¹ ∘ f = ι_A**, **f ∘ f⁻¹ = ι_B** · **(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹**

| | g ∘ f κληρονομεί | από τη g ∘ f συμπεραίνω |
|---|---|---|
| 1-1 | αν f, g 1-1 | η **f** είναι 1-1 (όχι η g) |
| επί | αν f, g επί | η **g** είναι επί (όχι η f) |

## 6. Πάτωμα και ταβάνι

**⌊x⌋** = μεγαλύτερος ακέραιος ≤ x · **⌈x⌉** = μικρότερος ακέραιος ≥ x · **⌊−0.5⌋ = −1**, **⌈−2.3⌉ = −2** · ⌊x + n⌋ = ⌊x⌋ + n για n ∈ Z

## 7. Οι 10 παγίδες

1. **Δύο α στο ίδιο β** ⇒ όχι 1-1, **όχι** «όχι συνάρτηση»
2. **α χωρίς βέλος** ⇒ **δεν είναι συνάρτηση** (το «???» των διαφανειών): 1-1 / επί δεν έχουν νόημα
3. **range ≠ codomain**: το range το **υπολογίζεις**, το codomain το **δηλώνεις**
4. **Επί χωρίς έλεγχο x ∈ A**: 7x + 4 επί στο R, όχι στο Z
5. Το **x = y ⇒ f(x) = f(y)** δεν αποδεικνύει 1-1· θέλουμε το αντίστροφο
6. **1-1 ⇔ επί μόνο για πεπερασμένα** σύνολα ίδιου μεγέθους
7. **f⁻¹ μόνο για αντιστοιχίες**· το f⁻¹(D) για όλες· **f⁻¹(x) ≠ 1/f(x)**
8. **(g ∘ f)(x) = g(f(x))**: πρώτα f· **f ∘ g ≠ g ∘ f**· **f ∘ f ≠ (f(x))²**
9. **f⁻¹ ∘ f = ι_A ≠ ι_B = f ∘ f⁻¹** όταν A ≠ B· **(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹**
10. **⚠️ Διαφάνειες:** στη 7 «πεδίο ορισμού συναρτήσεως» → **πεδίο τιμών** συναρτήσεως· στη 21 «περισσοτέρων από δύο» → **τουλάχιστον δύο**
