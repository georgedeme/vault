# 04 - Αντιστοιχία και Αντίστροφη

Όταν μια συνάρτηση είναι και ένα-προς-ένα και επί, κάθε στοιχείο του B έχει **ακριβώς μία** προεικόνα. Τότε μπορούμε να «γυρίσουμε τα βέλη ανάποδα» και να πάρουμε πάλι συνάρτηση: την αντίστροφη.

## 1. Ένα-προς-ένα αντιστοιχία

> [!note] Ένα-προς-ένα αντιστοιχία (bijective)
> Μια συνάρτηση f ονομάζεται **ένα-προς-ένα αντιστοιχία** (**bijective**) αν είναι **ένα-προς-ένα και επί**.

Σε διάγραμμα με βέλη: σε **κάθε** στοιχείο του B φτάνει **ακριβώς ένα** βέλος. Η f «ζευγαρώνει» τα στοιχεία του A με τα στοιχεία του B, χωρίς να περισσεύει κανένα (από τη μεριά του A αυτό ισχύει ήδη από τον [[01 - Ορισμός Συνάρτησης|ορισμό της συνάρτησης]]).

> [!important] Πώς αποδεικνύω ότι η f είναι αντιστοιχία
> **Δύο** αποδείξεις, με τις συνταγές του [[03 - Ένα-προς-ένα και Επί|03]]:
> 1. **1-1:** έστω f(x) = f(y) ⇒ … ⇒ x = y.
> 2. **Επί:** έστω y ∈ B· βρίσκω x ∈ A με f(x) = y.
>
> Εναλλακτικά: βρίσκω μια g : B → A με g(f(x)) = x για κάθε x ∈ A **και** f(g(y)) = y για κάθε y ∈ B. Τότε η f είναι αντιστοιχία και g = f⁻¹ (βλ. [[05 - Σύνθεση Συναρτήσεων#6. Αντίστροφη και σύνθεση|05]]).

| Συνάρτηση | Αντιστοιχία; | Γιατί |
|---|---|---|
| f : Z → Z, f(x) = x + 1 | ✓ | 1-1 και επί ([[03 - Ένα-προς-ένα και Επί#2. Ένα-προς-ένα συναρτήσεις\|03]]) |
| f : R → R, f(x) = 2x | ✓ | αντίστροφη y/2 |
| f : Z → Z, f(x) = 2x | ✗ | 1-1, όχι επί (το 1 δεν είναι άρτιος) |
| f : R → R, f(x) = x³ | ✓ | αντίστροφη ∛y |
| f : R → R, f(x) = x² | ✗ | ούτε 1-1 ούτε επί |
| f : Z → Z, f(x) = −x | ✓ | είναι η αντίστροφη του εαυτού της |
| ι_A : A → A, ι_A(x) = x | ✓ | [[05 - Σύνθεση Συναρτήσεων#5. Ταυτοτικές συναρτήσεις\|ταυτοτική]] |
| f : {1, 2, 3} → {α, β, γ}, f(1) = β, f(2) = γ, f(3) = α | ✓ | κάθε στοιχείο του B ακριβώς μία φορά |

> [!info]- 🧠 Αντιστοιχία = «ίδιο μέγεθος»
> Για πεπερασμένα σύνολα, υπάρχει αντιστοιχία A → B **ακριβώς όταν |A| = |B|** (βλ. [[03 - Ένα-προς-ένα και Επί#6. Πεπερασμένα σύνολα: το μέγεθος μετράει|03]]). Αυτή η ιδέα χρησιμοποιείται για να **ορίσουμε** «ίδιο μέγεθος» και για άπειρα σύνολα: τα N και Z έχουν τον ίδιο πληθικό αριθμό γιατί υπάρχει αντιστοιχία N → Z (0 ↦ 0, 1 ↦ 1, 2 ↦ −1, 3 ↦ 2, 4 ↦ −2, …), παρότι N ⊂ Z. Αυτό εξηγεί γιατί το «A ⊂ B ⇒ |A| < |B|» ισχύει [[Uni/ΕΠΛ111/03 - Σύνολα/03 - Πληθικός Αριθμός και Δυναμοσύνολο#2. Ιδιότητες του πληθικού αριθμού|μόνο για πεπερασμένα σύνολα]].

## 2. Αντίστροφη συνάρτηση

> [!note] Αντίστροφη (inverse)
> Έστω f : A → B μια ένα-προς-ένα αντιστοιχία. Η **αντίστροφη** (**inverse**) της f είναι η συνάρτηση από το B στο A η οποία αναθέτει σε κάθε στοιχείο β ∈ B το στοιχείο α ∈ A τέτοιο ώστε f(α) = β, και συμβολίζεται **f⁻¹**.
>
> **f⁻¹(β) = α ⇔ f(α) = β**

- Η f πηγαίνει **A → B**· η f⁻¹ πηγαίνει **B → A**.
- Κάθε βέλος α → β της f γίνεται βέλος β → α της f⁻¹.
- Ως σύνολο ζευγών: **f⁻¹ = {(β, α) | (α, β) ∈ f}**: αντιστρέφουμε τη σειρά σε κάθε ζεύγος.

> [!warning] ΠΡΟΣΟΧΗ (διαφάνειες)
> Η αντίστροφη μιας συνάρτησης που **δεν είναι** ένα-προς-ένα αντιστοιχία **δεν υπάρχει**. Γιατί;

## 3. Γιατί χρειάζεται η f να είναι αντιστοιχία

Αν αντιστρέψουμε τα βέλη μιας f που δεν είναι αντιστοιχία, το αποτέλεσμα παραβιάζει τον [[01 - Ορισμός Συνάρτησης#2. Ορισμός|ορισμό της συνάρτησης]]:

![[Αντίστροφη - Αντιστροφή των Βελών.png|800]]

1. **Η f δεν είναι ένα-προς-ένα.** Τότε υπάρχει β ∈ B το οποίο είναι η εικόνα περισσοτέρων από δύο στοιχείων του A. Επομένως, η αντίστροφη συνάρτηση θα αναθέτει περισσότερα από ένα στοιχεία του A στο β, το οποίο οδηγεί σε αντίφαση.
2. **Η f δεν είναι επί.** Τότε υπάρχει β ∈ B το οποίο δεν είναι η εικόνα κάποιου στοιχείου του A. Επομένως, η αντίστροφη συνάρτηση δεν αναθέτει κάποιο στοιχείο του A στο β, το οποίο οδηγεί σε αντίφαση.

| Η f δεν είναι… | Τι παθαίνει η «f⁻¹» | Ποιο μέρος του ορισμού παραβιάζεται |
|---|---|---|
| ένα-προς-ένα | κάποιο β παίρνει ≥ 2 εικόνες | «**ακριβώς ενός**» |
| επί | κάποιο β δεν παίρνει εικόνα | «**σε κάθε**» |

> [!warning] ⚠️ Σημείωση: «περισσοτέρων από δύο» στη διαφάνεια 21
> Η διαφάνεια γράφει ότι το β «είναι η εικόνα **περισσοτέρων από δύο** στοιχείων του A». Αρκεί να είναι εικόνα **τουλάχιστον δύο** στοιχείων (δηλαδή περισσοτέρων από **ένα**): αν f(1) = f(2) = β, η «f⁻¹(β)» θα έπρεπε να είναι και 1 και 2. Η ίδια διαφάνεια λέει σωστά, στη συνέχεια, «περισσότερα από **ένα** στοιχεία».

> [!info]- 🧠 Η συμμετρία των δύο απαιτήσεων
> Οι δύο απαιτήσεις του ορισμού της συνάρτησης («σε κάθε», «ακριβώς ενός») αφορούν τα βέλη που **βγαίνουν** από κάθε στοιχείο του πεδίου ορισμού. Όταν αντιστρέφουμε, τα βέλη που **έφταναν** στο B γίνονται βέλη που **βγαίνουν** από το B. Άρα:
> - η f⁻¹ ικανοποιεί το «σε κάθε» ⇔ σε κάθε β έφτανε τουλάχιστον ένα βέλος ⇔ η f είναι **επί**·
> - η f⁻¹ ικανοποιεί το «ακριβώς ενός» ⇔ σε κάθε β έφτανε το πολύ ένα βέλος ⇔ η f είναι **1-1**.

## 4. Υπολογισμός της αντίστροφης

### Πεπερασμένο σύνολο: αντιστρέφουμε τα ζεύγη

f : {α, β, γ} → {1, 2, 3}, f(α) = 2, f(β) = 3, f(γ) = 1

**f⁻¹(1) = γ, f⁻¹(2) = α, f⁻¹(3) = β**

### Με τύπο: λύνουμε ως προς x

**f : Z → Z, f(x) = x + 1** (διαφάνειες)

Ας υποθέσουμε ότι y είναι η εικόνα του x, δηλαδή y = x + 1. Επομένως, x = y − 1. Αυτό σημαίνει ότι ο ακέραιος y − 1 είναι το μοναδικό στοιχείο του Z το οποίο ανατίθεται στο y από τη συνάρτηση f⁻¹. Άρα, **f⁻¹(y) = y − 1**.

> [!important] Συνταγή
> 1. Βεβαιώσου ότι η f είναι **αντιστοιχία** (αλλιώς η f⁻¹ δεν υπάρχει, όσο κι αν «λύνεται» ο τύπος).
> 2. Γράψε y = f(x) και **λύσε ως προς x**.
> 3. Η f⁻¹(y) είναι η έκφραση που βρήκες, ως συνάρτηση **B → A**.
> 4. Έλεγχος: f(f⁻¹(y)) = y και f⁻¹(f(x)) = x.

> [!example]- Λυμένα παραδείγματα
> **f : R → R, f(x) = 2x + 3.** y = 2x + 3 ⇒ x = (y − 3)/2. Άρα **f⁻¹(y) = (y − 3)/2**. Έλεγχος: f((y − 3)/2) = (y − 3) + 3 = y ✓.
>
> **f : [0, ∞) → [0, ∞), f(x) = x².** y = x² με x ≥ 0 ⇒ x = √y (όχι −√y, γιατί x ∈ [0, ∞)). Άρα **f⁻¹(y) = √y**. Χωρίς τον περιορισμό x ≥ 0, η f δεν θα ήταν 1-1 και δεν θα αντιστρεφόταν.
>
> **f : R ∖ {2} → R ∖ {1}, f(x) = (x + 1)/(x − 2).** y = (x + 1)/(x − 2) ⇒ yx − 2y = x + 1 ⇒ x(y − 1) = 2y + 1 ⇒ x = (2y + 1)/(y − 1). Άρα **f⁻¹(y) = (2y + 1)/(y − 1)**, που ορίζεται ακριβώς για y ≠ 1. Γι' αυτό το πεδίο τιμών πρέπει να είναι R ∖ {1}: το 1 δεν είναι εικόνα κανενός x (θα έπρεπε x + 1 = x − 2).
>
> **f : Z → Z, f(x) = 2x.** Ο τύπος «λύνεται» (x = y/2), αλλά η f **δεν** έχει αντίστροφη: το y/2 δεν είναι ακέραιος για περιττό y, άρα η f δεν είναι επί. Η «f⁻¹(y) = y/2» δεν είναι συνάρτηση Z → Z.

## 5. Ιδιότητες της αντίστροφης

| Ιδιότητα | Γιατί |
|---|---|
| Η f⁻¹ είναι κι αυτή **αντιστοιχία** B → A | αντιστρέφοντας τα βέλη μιας αντιστοιχίας παίρνεις πάλι «ακριβώς ένα βέλος» παντού |
| **(f⁻¹)⁻¹ = f** | αντιστρέφοντας δύο φορές επιστρέφεις στα αρχικά βέλη |
| ι_A⁻¹ = ι_A | η ταυτοτική είναι η αντίστροφη του εαυτού της |
| (f⁻¹ ∘ f)(α) = α, (f ∘ f⁻¹)(β) = β | στο [[05 - Σύνθεση Συναρτήσεων#6. Αντίστροφη και σύνθεση\|05]] |
| (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹ | στο [[05 - Σύνθεση Συναρτήσεων#6. Αντίστροφη και σύνθεση\|05]] (η σειρά αντιστρέφεται) |

> [!example]- Συναρτήσεις που είναι η αντίστροφη του εαυτού τους (επέκταση)
> Μια αντιστοιχία f : A → A με **f⁻¹ = f** (ισοδύναμα f(f(x)) = x) λέγεται **ενέλιξη** (involution).
> - f : R → R, f(x) = −x: f(f(x)) = −(−x) = x.
> - f : R → R, f(x) = 1 − x: f(f(x)) = 1 − (1 − x) = x.
> - f : R ∖ {0} → R ∖ {0}, f(x) = 1/x.
> - Το NOT πάνω στα bits {0, 1}: f(0) = 1, f(1) = 0.
>
> Στο διάγραμμα με βέλη: κάθε στοιχείο είτε πάει στον εαυτό του είτε **ανταλλάσσεται** με ένα άλλο.

## 6. Τρία πράγματα με «−1»

![[Αντίστροφη - Τρία Πράγματα με -1.png|800]]

| Συμβολισμός | Τι είναι | Πότε ορίζεται |
|---|---|---|
| **f⁻¹(y)**, y ∈ B | **στοιχείο** του A: η τιμή της αντίστροφης συνάρτησης | μόνο αν η f είναι αντιστοιχία |
| **f⁻¹(D)**, D ⊆ B | **υποσύνολο** του A: η [[02 - Πεδία, Εικόνα και Προεικόνα#4. Αντίστροφη εικόνα (επέκταση, Rosen §1.8)\|αντίστροφη εικόνα]] | για **κάθε** f |
| **(f(x))⁻¹ = 1/f(x)** | **αριθμός**: ο αντίστροφος του αριθμού f(x) | όταν f(x) ≠ 0 |

> [!warning] f⁻¹(x) ≠ 1/f(x)
> Για f(x) = 2x: f⁻¹(6) = **3** (ποιο x δίνει 6;), ενώ 1/f(6) = **1/12**. Ο εκθέτης −1 στο f⁻¹ σημαίνει «**αντίστροφη ως προς τη σύνθεση**», όχι «ένα δια».

## 7. Συχνά Λάθη

> [!warning] Προσοχή στο τεστ
> - **Υπολογίζεις f⁻¹ χωρίς να ελέγξεις ότι η f είναι αντιστοιχία.** Το «λύσε ως προς x» δουλεύει και για τη 2x στο Z, αλλά η αντίστροφη δεν υπάρχει.
> - **Λάθος πεδία.** Αν f : A → B, τότε **f⁻¹ : B → A**. Το πεδίο ορισμού της f⁻¹ είναι το **πεδίο τιμών** της f.
> - **Ξεχνάς τον περιορισμό του πεδίου ορισμού.** Η √y είναι η αντίστροφη της x² **μόνο** από το [0, ∞). Η (y − 3)/2 είναι αντίστροφη στο R, όχι στο Z.
> - **f⁻¹(x) = 1/f(x).** Λάθος: δες την ενότητα 6.
> - **Σύγχυση της αντίστροφης συνάρτησης με την αντίστροφη εικόνα.** g : Z → Z, g(x) = x²: το g⁻¹({4}) = {−2, 2} υπάρχει, το g⁻¹(4) όχι.
> - **Νομίζεις ότι αρκεί 1-1.** Μια 1-1 αλλά όχι επί f δεν έχει αντίστροφη B → A (έχει μόνο από το f(A) στο A).
