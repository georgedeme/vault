# 02 - Πεδία, Εικόνα και Προεικόνα

Η ορολογία των συναρτήσεων: από πού ξεκινάμε (πεδίο ορισμού), πού επιτρέπεται να καταλήξουμε (πεδίο τιμών) και πού καταλήγουμε πραγματικά (πεδίο τιμών συναρτήσεως). Και πώς εφαρμόζουμε μια συνάρτηση σε ολόκληρο σύνολο.

## 1. Ορολογία

> [!note] Πεδίο ορισμού, πεδίο τιμών, εικόνα, προεικόνα
> - Έστω f : A → B. Ονομάζουμε το σύνολο A **πεδίο ορισμού** (**domain**) της f και το σύνολο B **πεδίο τιμών** (**codomain**) της f.
> - Αν f(α) = β, τότε λέμε ότι το β είναι η **εικόνα** (**image**) του α και το α η **προεικόνα** (**preimage**) του β.
> - Το **πεδίο τιμών συναρτήσεως** (**range**) της f είναι το σύνολο των εικόνων των στοιχείων του A.

![[Ορολογία - Πεδία, Εικόνα, Προεικόνα.png|800]]

| Όρος | Αγγλικά | Τι είναι | Στο σχήμα |
|---|---|---|---|
| Πεδίο ορισμού | domain | το A, από όπου ξεκινούν τα βέλη | {1, 2, 3, 4} |
| Πεδίο τιμών | codomain | το B, όπου **επιτρέπεται** να καταλήξουν | {α, β, γ, δ} |
| Πεδίο τιμών συναρτήσεως | range | {f(α) \| α ∈ A}, όπου **πραγματικά** καταλήγουν | {α, β, γ} |
| Εικόνα του α | image | το **μοναδικό** f(α) | εικόνα του 3: γ |
| Προεικόνα του β | preimage | **ένα** α με f(α) = β | προεικόνες του α: 1 και 2 |

> [!important] Πεδίο τιμών συναρτήσεως ⊆ πεδίο τιμών
> Πάντα **range ⊆ codomain**, δηλαδή f(A) ⊆ B. Η ισότητα f(A) = B ισχύει ακριβώς όταν η f είναι [[03 - Ένα-προς-ένα και Επί#3. Επί συναρτήσεις|επί]].

> [!warning] Δύο όροι που μοιάζουν: «πεδίο τιμών» vs «πεδίο τιμών συναρτήσεως»
> Στις διαφάνειες **πεδίο τιμών** = το B (codomain, **το δηλώνουμε** εμείς στο f : A → B) και **πεδίο τιμών συναρτήσεως** = το f(A) (range, **το υπολογίζουμε**). Το λυκειακό «σύνολο τιμών» αντιστοιχεί στο **range**. Όταν σου ζητούν «το πεδίο τιμών συναρτήσεως», μην απαντήσεις απλώς το B.

> [!info]- 🧠 Εικόνα: μία. Προεικόνες: όσες θέλουν
> - Κάθε α ∈ A έχει **ακριβώς μία** εικόνα (ορισμός συνάρτησης), γι' αυτό λέμε «**η** εικόνα του α».
> - Κάθε β ∈ B μπορεί να έχει **καμία, μία ή πολλές** προεικόνες, γι' αυτό λέμε «**μια** προεικόνα του β». Στο σχήμα, το α έχει δύο (1 και 2), το δ καμία.
> - Τα στοιχεία του B με **τουλάχιστον μία** προεικόνα σχηματίζουν το range.

## 2. Παράδειγμα συνάρτησης

**f : Z → Z, f(x) = x²**: αναθέτει σε κάθε ακέραιο το τετράγωνό του.

- Το πεδίο ορισμού και το πεδίο τιμών της f είναι οι ακέραιοι αριθμοί (Z).
- Το πεδίο τιμών συναρτήσεως της f είναι όλοι οι μη αρνητικοί ακέραιοι που είναι τέλεια τετράγωνα: **{0, 1, 4, 9, …}**.

> [!warning] ⚠️ Σημείωση: τυπογραφικό στη διαφάνεια 7
> Η διαφάνεια γράφει «Το **πεδίο ορισμού** συναρτήσεως της f είναι όλοι οι μη αρνητικοί ακέραιοι που είναι τέλεια τετράγωνα». Πρέπει να είναι «Το **πεδίο τιμών** συναρτήσεως» (range): το πεδίο ορισμού είναι όλο το Z, ενώ το {0, 1, 4, 9, …} είναι το σύνολο των τιμών που παίρνει πραγματικά η f.

Παρατήρησε: το 4 έχει **δύο** προεικόνες (−2 και 2), το 0 έχει **μία** (0), το 2 και το −1 **καμία**.

### Πώς βρίσκω το πεδίο τιμών συναρτήσεως

Για να ελέγξω αν ένα y ∈ B ανήκει στο range, λύνω την εξίσωση **f(x) = y ως προς x** και ελέγχω αν υπάρχει λύση **μέσα στο A**.

| f : A → B | Πεδίο τιμών συναρτήσεως f(A) | Σχόλιο |
|---|---|---|
| f : Z → Z, f(x) = x + 1 | Z | κάθε y έχει προεικόνα y − 1 |
| f : N → N, f(x) = x + 1 | Z⁺ = {1, 2, 3, …} | το 0 θα ήθελε προεικόνα −1 ∉ N |
| f : Z → Z, f(x) = 2x | {…, −4, −2, 0, 2, 4, …} | μόνο οι άρτιοι |
| f : R → R, f(x) = 2x | R | y έχει προεικόνα y/2 ∈ R |
| f : R → R, f(x) = x² | [0, ∞) | |
| f : R → R, f(x) = 1/(x² + 1) | (0, 1] | μέγιστο 1 στο x = 0· ποτέ 0 |
| f : R → Z, f(x) = ⌊x⌋ | Z | κάθε n ∈ Z είναι ⌊n⌋ |
| f : Z → Z, f(x) = x mod 3 | {0, 1, 2} | |
| f : A → B σταθερή, f(x) = c | {c} | (αν A ≠ ∅) |

> [!example]- Αναλυτικά: το πεδίο τιμών συναρτήσεως της f(x) = 1/(x² + 1)
> Έστω y ∈ R. Ψάχνουμε x ∈ R με 1/(x² + 1) = y.
> - Αν y ≤ 0: αδύνατο, γιατί 1/(x² + 1) > 0 πάντα.
> - Αν y > 0: x² + 1 = 1/y ⇔ x² = 1/y − 1. Έχει πραγματική λύση ⇔ 1/y − 1 ≥ 0 ⇔ 1/y ≥ 1 ⇔ y ≤ 1.
>
> Άρα f(R) = (0, 1]. Η τεχνική «λύσε ως προς x και κοίτα πότε υπάρχει λύση στο A» είναι η ίδια με την απόδειξη ότι μια συνάρτηση είναι [[03 - Ένα-προς-ένα και Επί#Πώς αποδεικνύω ότι είναι επί|επί]].

## 3. Εικόνα συνόλου

> [!note] Εικόνα υποσυνόλου
> Έστω f : A → B και C ⊆ A. Η **εικόνα του C** είναι το υποσύνολο του B το οποίο περιέχει όλες τις εικόνες των στοιχείων του C. Γράφουμε f(C) για την εικόνα του C, δηλαδή
>
> **f(C) = {f(α) | α ∈ C}**

**Παράδειγμα (διαφάνειες):** f : {α, β, γ, δ, ε} → {1, 2, 3, 4} με f(α) = 2, f(β) = 1, f(γ) = 4, f(δ) = 1, f(ε) = 1.

f({β, γ, δ}) = {f(β), f(γ), f(δ)} = {1, 4, 1} = **{1, 4}**

![[Ορολογία - Εικόνα και Αντίστροφη Εικόνα.png|800]]

> [!important] Τι γράφω για να δουλέψω με το f(C)
> **y ∈ f(C) ⇔ ∃x ∈ C (f(x) = y)**
>
> Στις αποδείξεις: «έστω y ∈ f(C)» σημαίνει «υπάρχει x ∈ C με f(x) = y», και για να δείξεις ότι y ∈ f(C) πρέπει να **βρεις** ένα τέτοιο x.

### Ιδιότητες της εικόνας (επέκταση)

| Ιδιότητα | Ισχύει; |
|---|---|
| f(∅) = ∅ | ✓ |
| f(A) = πεδίο τιμών συναρτήσεως | ✓ (ορισμός) |
| f({α}) = {f(α)} | ✓ (σύνολο ενός στοιχείου, **όχι** το f(α) το ίδιο) |
| \|f(C)\| ≤ \|C\| | ✓ (για πεπερασμένο C· ισότητα αν η f είναι 1-1) |
| C ⊆ D ⇒ f(C) ⊆ f(D) | ✓ |
| f(C ∪ D) = f(C) ∪ f(D) | ✓ |
| f(C ∩ D) ⊆ f(C) ∩ f(D) | ✓ |
| f(C ∩ D) = f(C) ∩ f(D) | ✗ γενικά (✓ αν η f είναι ένα-προς-ένα) |
| f(C ∖ D) = f(C) ∖ f(D) | ✗ γενικά (✓ αν η f είναι ένα-προς-ένα) |

Οι αποδείξεις για την ένωση και την τομή (με αντιπαράδειγμα και σχήμα) είναι στις [[Uni/ΕΠΛ111/03 - Σύνολα/10 - Λύσεις Άσκησης 4#Άσκηση 3|Λύσεις Άσκησης 4, Άσκηση 3]].

> [!example]- Αντιπαράδειγμα: f(C ∩ D) ≠ f(C) ∩ f(D)
> f : {1, 2} → {β}, f(1) = f(2) = β, C = {1}, D = {2}.
> - C ∩ D = ∅, άρα f(C ∩ D) = ∅.
> - f(C) = f(D) = {β}, άρα f(C) ∩ f(D) = {β}.
>
> Το β έχει **διαφορετική** προεικόνα σε κάθε σύνολο. Αν η f είναι ένα-προς-ένα αυτό δεν μπορεί να συμβεί, και ισχύει η ισότητα.
>
> Με το ίδιο f: f(C ∖ D) = f({1}) = {β}, ενώ f(C) ∖ f(D) = {β} ∖ {β} = ∅.

## 4. Αντίστροφη εικόνα (επέκταση, Rosen §1.8)

> [!note] Αντίστροφη εικόνα συνόλου (inverse image)
> Έστω f : A → B και D ⊆ B. Η **αντίστροφη εικόνα** του D είναι το σύνολο όλων των στοιχείων του A που η εικόνα τους ανήκει στο D:
>
> **f⁻¹(D) = {x ∈ A | f(x) ∈ D}**

Στο παράδειγμα των διαφανειών: f⁻¹({1}) = {β, δ, ε}, f⁻¹({1, 2}) = {α, β, δ, ε}, f⁻¹({3}) = **∅**, f⁻¹({1, 2, 3, 4}) = A.

> [!warning] Το f⁻¹(D) υπάρχει για ΚΑΘΕ f
> Η αντίστροφη εικόνα είναι **σύνολο** και ορίζεται για κάθε συνάρτηση, ακόμα κι αν δεν είναι ένα-προς-ένα ή επί. Η **αντίστροφη συνάρτηση** f⁻¹ (στο [[04 - Αντιστοιχία και Αντίστροφη|04]]) υπάρχει **μόνο** για ένα-προς-ένα αντιστοιχίες. Ο συμβολισμός είναι ίδιος· το αν μέσα στις παρενθέσεις έχεις **στοιχείο** ή **σύνολο** σου λέει ποιο από τα δύο είναι.

| Ιδιότητα | Ισχύει; |
|---|---|
| f⁻¹(D ∪ E) = f⁻¹(D) ∪ f⁻¹(E) | ✓ |
| f⁻¹(D ∩ E) = f⁻¹(D) ∩ f⁻¹(E) | ✓ (**πάντα**, σε αντίθεση με την εικόνα) |
| f⁻¹(B ∖ D) = A ∖ f⁻¹(D) | ✓ |
| f(f⁻¹(D)) ⊆ D | ✓ (= αν η f είναι επί) |
| C ⊆ f⁻¹(f(C)) | ✓ (= αν η f είναι ένα-προς-ένα) |

> [!example]- Γιατί η αντίστροφη εικόνα «σέβεται» την τομή και η εικόνα όχι
> | Βήμα | Αιτιολόγηση |
> |---|---|
> | x ∈ f⁻¹(D ∩ E) ⇔ f(x) ∈ D ∩ E | ορισμός αντίστροφης εικόνας |
> | ⇔ f(x) ∈ D ∧ f(x) ∈ E | ορισμός τομής |
> | ⇔ x ∈ f⁻¹(D) ∧ x ∈ f⁻¹(E) | ορισμός αντίστροφης εικόνας |
> | ⇔ x ∈ f⁻¹(D) ∩ f⁻¹(E) | ορισμός τομής |
>
> Κάθε βήμα είναι ⇔ γιατί το f(x) είναι **ένα συγκεκριμένο** στοιχείο. Στην εικόνα, το y ∈ f(C) κρύβει έναν **∃x**, και ο «μάρτυρας» x για το C μπορεί να είναι άλλος από τον μάρτυρα για το D. Ο ∃ δεν επιμερίζεται στο ∧, όπως είδαμε στους [[Uni/ΕΠΛ111/01 - Προτασιακή-Κατηγορική Λογική/05 - Κατηγορική Λογική και Ποσοδείκτες|ποσοδείκτες]]: ∃x (P(x) ∧ Q(x)) ⇒ ∃x P(x) ∧ ∃x Q(x), όχι αντίστροφα.

> [!example]- Αντιπαράδειγμα: f(f⁻¹(D)) ≠ D και f⁻¹(f(C)) ≠ C
> f : Z → Z, f(x) = x².
> - D = {−1, 4}: f⁻¹(D) = {−2, 2}, άρα f(f⁻¹(D)) = {4} ≠ D. Το −1 χάθηκε γιατί δεν έχει προεικόνα (η f δεν είναι επί).
> - C = {2}: f(C) = {4}, άρα f⁻¹(f(C)) = {−2, 2} ≠ C. Το −2 «προστέθηκε» γιατί έχει την ίδια εικόνα (η f δεν είναι ένα-προς-ένα).

## 5. Συχνά Λάθη

> [!warning] Προσοχή στο τεστ
> - **Range = codomain.** Όχι: το codomain είναι το B (δηλωμένο), το range το f(A) (υπολογισμένο). Για f : Z → Z, f(x) = x², το codomain είναι Z, το range {0, 1, 4, 9, …}.
> - **«Η εικόνα» ενός στοιχείου του B.** Τα στοιχεία του B έχουν **προ**εικόνες, όχι εικόνες. Και η προεικόνα δεν είναι απαραίτητα μοναδική.
> - **f(C) με επαναλήψεις.** f({β, δ, ε}) = {1}, όχι {1, 1, 1}: είναι σύνολο.
> - **f({α}) = f(α).** Το πρώτο είναι **σύνολο** {f(α)}, το δεύτερο **στοιχείο** του B.
> - **f(C ∩ D) = f(C) ∩ f(D).** Ισχύει μόνο ⊆, εκτός αν η f είναι ένα-προς-ένα.
> - **f⁻¹(D) μόνο όταν η f αντιστρέφεται.** Η αντίστροφη εικόνα ορίζεται πάντα (μπορεί να είναι ∅).
> - **Range του x² στους ακέραιους = {0, 1, 2, 3, …}.** Όχι: μόνο τέλεια τετράγωνα. Το 2 δεν είναι τετράγωνο ακεραίου.
