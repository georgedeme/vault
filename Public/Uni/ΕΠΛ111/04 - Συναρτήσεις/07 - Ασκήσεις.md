# 07 - Ασκήσεις

26 ασκήσεις στο ύφος των διαφανειών, από τις εύκολες στις «παγίδες». **Λύσε πρώτα, άνοιξε μετά**: κάθε λύση είναι κρυμμένη σε αναδιπλούμενο πλαίσιο.

> [!tip] Πώς να το χρησιμοποιήσεις
> Κάνε πρώτα ένα πλήρες πέρασμα χωρίς να ανοίξεις καμία λύση. Σημείωσε ποιες σε δυσκόλεψαν και γύρνα στη σχετική σημείωση, όχι στη λύση. Οι ασκήσεις με 🔴 είναι «παγίδες».

### Άσκηση 1 🔴

> [!success]- Λύση
> | | Υπολογισμός | Αποτέλεσμα |
> |---|---|---|
> | f(C ∩ D) | f({0}) | **{0}** |
> | f(C) ∩ f(D) | {0, 1, 4} ∩ {0, 1, 4} | **{0, 1, 4}** |

## Μέρος Β — Ένα-προς-ένα και επί

### Άσκηση 7

Για κάθε συνάρτηση, απαντήστε αν είναι ένα-προς-ένα και αν είναι επί:
(α) f : Z → Z, 3x − 1  (β) f : R → R, 3x − 1  (γ) f : Z → Z, x³  (δ) f : Z → Z, ⌊x/2⌋  (ε) f : N → N, x + 2  (στ) f : R → R, x² + 1  (ζ) f : R → [1, ∞), x² + 1  (η) f : [0, ∞) → [1, ∞), x² + 1  (θ) f : Z → Z, −x  (ι) 🔴 f : Z → Z, f(x) = x + 1 αν x άρτιος, x − 1 αν x περιττός

> [!success]- Λύση
> | | 1-1 | Επί | Αιτιολόγηση |
> |---|---|---|---|
> | (α) | ✓ | ✗ | 3x − 1 = 3y − 1 ⇒ x = y· το 0 θέλει x = 1/3 ∉ Z |
> | (β) | ✓ | ✓ | x = (y + 1)/3 ∈ R |
> | (γ) | ✓ | ✗ | γνησίως αύξουσα· το 2 δεν είναι κύβος ακεραίου |
> | (δ) | ✗ | ✓ | f(0) = f(1) = 0· για κάθε y, f(2y) = y |
> | (ε) | ✓ | ✗ | το 0 και το 1 χωρίς προεικόνα (θα ήθελαν −2, −1 ∉ N) |
> | (στ) | ✗ | ✗ | f(−1) = f(1)· το 0 χωρίς προεικόνα (x² + 1 ≥ 1) |
> | (ζ) | ✗ | ✓ | f(−1) = f(1)· για y ≥ 1, x = √(y − 1) |
> | (η) | ✓ | ✓ | χωρίς αρνητικούς, καμία σύγκρουση· αντίστροφη √(y − 1) |
> | (θ) | ✓ | ✓ | αντίστροφη ο εαυτός της |
> | (ι) | ✓ | ✓ | ανταλλάσσει 0 ↔ 1, 2 ↔ 3, −2 ↔ −1, …: f(f(x)) = x, άρα αντίστροφη ο εαυτός της |
>
> Στο (ι), ο «σπασμένος» τύπος δεν πρέπει να σε τρομάξει: κάνε το διάγραμμα για μερικές τιμές. Οι (στ), (ζ), (η) είναι ο ίδιος τύπος με διαφορετικά πεδία ([[03 - Ένα-προς-ένα και Επί#5. Το πεδίο τιμών μετράει|03, ενότητα 5]]).

### Άσκηση 8

Αποδείξτε ότι η f : R → R, f(x) = (x − 5)/3 είναι ένα-προς-ένα αντιστοιχία και βρείτε την αντίστροφή της.

> [!success]- Λύση
> **1-1:** Έστω x, y ∈ R με f(x) = f(y). Τότε (x − 5)/3 = (y − 5)/3 ⇒ x − 5 = y − 5 ⇒ x = y.
>
> **Επί:** Έστω y ∈ R. Θέτουμε x = 3y + 5 ∈ R. Τότε f(x) = (3y + 5 − 5)/3 = y.
>
> Άρα η f είναι αντιστοιχία. Από το βήμα «επί» βλέπουμε ότι το μοναδικό x με f(x) = y είναι το 3y + 5, άρα **f⁻¹(y) = 3y + 5**. Έλεγχος: f⁻¹(f(x)) = 3 · (x − 5)/3 + 5 = x ✓.

### Άσκηση 9 🔴

(α) f : Z × Z → Z, f(m, n) = m − n. Είναι 1-1; Επί;
(β) g : Z → Z × Z, g(n) = (n, n). Είναι 1-1; Επί;

> [!success]- Λύση
> **(α)** **Επί:** για y ∈ Z, f(y, 0) = y. **Όχι 1-1:** f(1, 0) = 1 = f(2, 1), αλλά (1, 0) ≠ (2, 1).
>
> **(β)** **1-1:** g(n) = g(m) ⇒ (n, n) = (m, m) ⇒ n = m (ισότητα ζευγών: ίσες συντεταγμένες). **Όχι επί:** το (0, 1) ∈ Z × Z δεν είναι της μορφής (n, n).
>
> **Παγίδα:** όταν το πεδίο ορισμού ή το πεδίο τιμών είναι καρτεσιανό γινόμενο, τα «στοιχεία» είναι **ζεύγη**. Ένα αντιπαράδειγμα για 1-1 χρειάζεται δύο **διαφορετικά ζεύγη**, όχι δύο αριθμούς.

### Άσκηση 10

Είναι η f : Z → Z, f(x) = ⌈x/2⌉ ένα-προς-ένα; Επί;

> [!success]- Λύση
> **Επί:** για y ∈ Z, το x = 2y ∈ Z δίνει ⌈2y/2⌉ = ⌈y⌉ = y.
>
> **Όχι 1-1:** f(1) = ⌈0.5⌉ = 1 = ⌈1⌉ = f(2).
>
> Γενικά κάθε ακέραιος y έχει **δύο** προεικόνες: 2y − 1 και 2y.

### Άσκηση 11

Γράψτε με ποσοδείκτες, χωρίς «¬» μπροστά από ποσοδείκτη: (α) «η f : A → B δεν είναι ένα-προς-ένα» (β) «η f : A → B δεν είναι επί» (γ) 🔴 «το R ⊆ A × B δεν είναι συνάρτηση από το A στο B»

> [!success]- Λύση
> - (α) ¬∀x∀y (f(x) = f(y) → x = y) ≡ ∃x∃y ¬(f(x) = f(y) → x = y) ≡ **∃x∃y (f(x) = f(y) ∧ x ≠ y)**
> - (β) ¬∀y ∈ B ∃x ∈ A (f(x) = y) ≡ **∃y ∈ B ∀x ∈ A (f(x) ≠ y)**
> - (γ) Το R είναι συνάρτηση ⇔ ∀α ∈ A [∃β ((α, β) ∈ R) ∧ ∀β∀γ ((α, β) ∈ R ∧ (α, γ) ∈ R → β = γ)]. Άρνηση:
>
>   **∃α ∈ A [∀β ((α, β) ∉ R) ∨ ∃β∃γ ((α, β) ∈ R ∧ (α, γ) ∈ R ∧ β ≠ γ)]**
>
>   «Κάποιο α δεν έχει εικόνα **ή** έχει δύο διαφορετικές.» Το ¬(p → q) ≡ p ∧ ¬q χρησιμοποιείται στο (α) και στο (γ). Βλ. [[Uni/ΕΠΛ111/01 - Προτασιακή-Κατηγορική Λογική/07 - Φωλιασμένοι Ποσοδείκτες|φωλιασμένοι ποσοδείκτες]].

### Άσκηση 12 🔴

Δώστε συνάρτηση f : N → N που είναι: (α) 1-1 αλλά όχι επί (β) επί αλλά όχι 1-1 (γ) αντιστοιχία, διαφορετική από την ταυτοτική (δ) ούτε 1-1 ούτε επί

> [!success]- Λύση
> - (α) f(x) = x + 1 (το 0 χωρίς προεικόνα) ή f(x) = 2x (οι περιττοί χωρίς προεικόνα).
> - (β) f(x) = ⌊x/2⌋ (f(0) = f(1) = 0, και κάθε n = f(2n)).
> - (γ) f(x) = x + 1 αν x άρτιος, x − 1 αν x περιττός (ανταλλάσσει 0 ↔ 1, 2 ↔ 3, …).
> - (δ) f(x) = 0 (σταθερή) ή f(x) = 2⌊x/2⌋.
>
> Τα (α) και (β) **δεν** θα υπήρχαν αν το N ήταν πεπερασμένο: εκεί 1-1 ⇔ επί. Αυτή είναι η χαρακτηριστική διαφορά των άπειρων συνόλων.

### Άσκηση 13 🔴

Υπάρχει: (α) ένα-προς-ένα f : {1, 2, 3, 4} → {α, β, γ}; (β) επί f : {1, 2} → {α, β, γ}; (γ) επί f : {1, 2, 3, 4} → {α, β, γ}; (δ) συνάρτηση f : ∅ → {α}; Αν ναι, είναι 1-1; Επί;

> [!success]- Λύση
> - (α) **Όχι:** 4 > 3, δύο στοιχεία θα συμπέσουν (περιστερώνας).
> - (β) **Όχι:** 2 εικόνες δεν καλύπτουν 3 στοιχεία.
> - (γ) **Ναι**, π.χ. f(1) = α, f(2) = β, f(3) = γ, f(4) = α. (Δεν μπορεί να είναι και 1-1.)
> - (δ) **Ναι**, ακριβώς μία: η κενή συνάρτηση f = ∅ (το «για κάθε α ∈ ∅» ισχύει κενά). Είναι **1-1** (κενά: δεν υπάρχουν x ≠ y). **Όχι επί**: το α δεν έχει προεικόνα.

## Μέρος Γ — Αντίστροφη

### Άσκηση 15

Βρείτε την αντίστροφη:
(α) f : R → R, f(x) = 5x − 2  (β) f : {1, 2, 3} → {α, β, γ}, f(1) = γ, f(2) = α, f(3) = β  (γ) f : R ∖ {0} → R ∖ {3}, f(x) = 3 + 1/x  (δ) f : Z → Z, f(x) = x + 7  (ε) f : R → R, f(x) = x³ + 1

> [!success]- Λύση
> - (α) y = 5x − 2 ⇒ **f⁻¹(y) = (y + 2)/5**.
> - (β) **f⁻¹(α) = 2, f⁻¹(β) = 3, f⁻¹(γ) = 1** (αντιστρέφουμε τα ζεύγη).
> - (γ) y = 3 + 1/x ⇒ 1/x = y − 3 ⇒ **f⁻¹(y) = 1/(y − 3)**. Ορίζεται για y ≠ 3: γι' αυτό το πεδίο τιμών είναι R ∖ {3}. Και 1/(y − 3) ≠ 0, άρα πράγματι ανήκει στο R ∖ {0}.
> - (δ) **f⁻¹(y) = y − 7** (∈ Z).
> - (ε) y = x³ + 1 ⇒ **f⁻¹(y) = ∛(y − 1)** (η κυβική ρίζα ορίζεται για κάθε πραγματικό, και για αρνητικούς).

> | | Τύπος | Στο x = 3 |
> |---|---|---|
> | (f ∘ g)(x) = f(x²) | x² + 2 | 11 |
> | (g ∘ f)(x) = g(x + 2) | (x + 2)² = x² + 4x + 4 | 25 |
> | (f ∘ f)(x) = f(x + 2) | x + 4 | 7 |
> | (g ∘ g)(x) = g(x²) | x⁴ | 81 |
>
> f ∘ g ≠ g ∘ f. Επίσης f ∘ f = x + 4, **όχι** (f(x))² = (x + 2)²: η σύνθεση μιας συνάρτησης με τον εαυτό της δεν είναι το τετράγωνό της.

### Άσκηση 19

A = {1, 2, 3}, B = {α, β, γ, δ}, C = {p, q}. f : A → B με f(1) = β, f(2) = δ, f(3) = β· g : B → C με g(α) = p, g(β) = q, g(γ) = p, g(δ) = p. (α) Βρείτε τη g ∘ f. (β) Ορίζεται η f ∘ g; (γ) Ποιες από τις f, g, g ∘ f είναι 1-1 ή επί;

> [!success]- Λύση
> - (α) (g ∘ f)(1) = g(β) = **q**, (g ∘ f)(2) = g(δ) = **p**, (g ∘ f)(3) = g(β) = **q**.
> - (β) **Όχι:** η g δίνει p ή q, που δεν ανήκουν στο πεδίο ορισμού A της f.
> - (γ) f: όχι 1-1 (1, 3 → β), όχι επί (α, γ). g: όχι 1-1, **επί**. g ∘ f: όχι 1-1, **επί** (παίρνει και το p και το q).
>
> Η g ∘ f είναι επί **παρότι η f δεν είναι**: για να είναι επί η g ∘ f χρειάζεται μόνο η g να είναι επί πάνω στο f(A) = {β, δ}.

### Άσκηση 20 🔴

f, h : R → R με f(x) = 2x + 1 και h(x) = 4x + 5. (α) Βρείτε g : R → R με g ∘ f = h. (β) Βρείτε k : R → R με f ∘ k = h.

> [!success]- Λύση
> **(α)** Θέλουμε g(2x + 1) = 4x + 5. Θέτουμε y = 2x + 1, άρα x = (y − 1)/2 και g(y) = 4 · (y − 1)/2 + 5 = 2y + 3. Άρα **g(y) = 2y + 3**. Έλεγχος: g(f(x)) = 2(2x + 1) + 3 = 4x + 5 ✓.
>
> **(β)** Θέλουμε f(k(x)) = 2k(x) + 1 = 4x + 5, άρα **k(x) = 2x + 2**. Έλεγχος: f(2x + 2) = 4x + 5 ✓.
>
> Οι g και k είναι **διαφορετικές**: η σειρά στη σύνθεση αλλάζει την εξίσωση που λύνεις. (Ισοδύναμα: g = h ∘ f⁻¹ και k = f⁻¹ ∘ h.)

### Άσκηση 21

f, g : R → R, f(x) = 3x, g(x) = x − 4. Βρείτε την (g ∘ f)⁻¹ με δύο τρόπους.

> [!success]- Λύση
> **Τρόπος 1:** (g ∘ f)(x) = 3x − 4. y = 3x − 4 ⇒ **(g ∘ f)⁻¹(y) = (y + 4)/3**.
>
> **Τρόπος 2:** f⁻¹(y) = y/3, g⁻¹(y) = y + 4. (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹, άρα (g ∘ f)⁻¹(y) = f⁻¹(y + 4) = (y + 4)/3 ✓.
>
> **Παγίδα:** η λάθος σειρά g⁻¹ ∘ f⁻¹ δίνει y/3 + 4, που **δεν** είναι η αντίστροφη (π.χ. στο y = −1: (−1 + 4)/3 = 1 και πράγματι g(f(1)) = −1, ενώ −1/3 + 4 ≠ 1).

### Άσκηση 22 🔴

Αληθές ή ψευδές;
(α) Αν η g ∘ f είναι 1-1, τότε η g είναι 1-1.
(β) Αν η g ∘ f είναι επί, τότε η g είναι επί.
(γ) Αν ορίζονται και οι δύο, f ∘ g = g ∘ f.
(δ) Η σύνθεση δύο αντιστοιχιών είναι αντιστοιχία.
(ε) Αν η f είναι 1-1 και η g επί, τότε η g ∘ f είναι αντιστοιχία.
(στ) Αν f : A → B είναι 1-1 και |A| = |B| πεπερασμένο, τότε η f έχει αντίστροφη.
(ζ) f⁻¹ ∘ f = f ∘ f⁻¹ για κάθε αντιστοιχία f : A → B.

> [!success]- Λύση
> | | Τιμή | Αιτιολόγηση |
> |---|---|---|
> | (α) | ✗ | A = {1}, B = {1, 2}, C = {1}, f(1) = 1, g(1) = g(2) = 1: g ∘ f 1-1, g όχι |
> | (β) | ✓ | κάθε z = g(f(x)) είναι εικόνα του f(x) ∈ B μέσω της g |
> | (γ) | ✗ | f(x) = x + 1, g(x) = 2x: 2x + 1 ≠ 2x + 2 |
> | (δ) | ✓ | 1-1 ∘ 1-1 = 1-1 και επί ∘ επί = επί |
> | (ε) | ✗ | A = {1}, B = C = {1, 2}, f(1) = 1, g = ι_B: η g ∘ f δεν είναι επί |
> | (στ) | ✓ | πεπερασμένα, ίδιο μέγεθος: 1-1 ⇒ επί ⇒ αντιστοιχία |
> | (ζ) | ✗ | η πρώτη είναι ι_A, η δεύτερη ι_B: διαφορετικές αν A ≠ B |
>
> Βλ. [[05 - Σύνθεση Συναρτήσεων#7. Σύνθεση και κατηγορίες (επέκταση)|05, ενότητα 7]].

### Άσκηση 23

Αποδείξτε: αν f : A → B και g : B → C είναι επί, τότε η g ∘ f είναι επί.

> [!success]- Λύση
> Έστω z ∈ C (αυθαίρετο).
> 1. Η g είναι επί, άρα υπάρχει y ∈ B με g(y) = z.
> 2. Η f είναι επί, άρα για αυτό το y υπάρχει x ∈ A με f(x) = y.
> 3. Τότε (g ∘ f)(x) = g(f(x)) = g(y) = z.
>
> Άρα για κάθε z ∈ C βρήκαμε x ∈ A με (g ∘ f)(x) = z: η g ∘ f είναι επί. ∎
>
> **Δομή:** [[Uni/ΕΠΛ111/02 - Μαθηματικός Συλλογισμός/04 - Κανόνες Συμπερασμού με Ποσοδείκτες|καθολική γενίκευση]] (αυθαίρετο z) και δύο φορές [[Uni/ΕΠΛ111/02 - Μαθηματικός Συλλογισμός/04 - Κανόνες Συμπερασμού με Ποσοδείκτες|υπαρξιακή εξειδίκευση]] (το y, μετά το x). Η σειρά μετράει: πρώτα «πηγαίνουμε πίσω» από το C στο B με τη g, μετά από το B στο A με την f.

### Άσκηση 24 🔴

Έστω f : A → A με f ∘ f = ι_A. Αποδείξτε ότι η f είναι αντιστοιχία και ότι f⁻¹ = f.

> [!success]- Λύση
> **1-1:** Έστω f(x) = f(y). Εφαρμόζοντας την f: f(f(x)) = f(f(y)), δηλαδή ι_A(x) = ι_A(y), άρα x = y.
>
> **Επί:** Έστω y ∈ A. Θέτουμε x = f(y) ∈ A. Τότε f(x) = f(f(y)) = y.
>
> **f⁻¹ = f:** Αν f(α) = β, τότε f(β) = f(f(α)) = α. Άρα f⁻¹(β) = α = f(β) για κάθε β ∈ A. ∎
>
> Παραδείγματα τέτοιων f (ενελίξεις): −x στο R, 1 − x, 1/x στο R ∖ {0}, η f της Άσκησης 7(ι).

### Άσκηση 25

Αποδείξτε ότι για κάθε f : A → B και D, E ⊆ B: f⁻¹(D ∪ E) = f⁻¹(D) ∪ f⁻¹(E).

> [!success]- Λύση
> | Βήμα | Αιτιολόγηση |
> |---|---|
> | x ∈ f⁻¹(D ∪ E) ⇔ f(x) ∈ D ∪ E | ορισμός αντίστροφης εικόνας |
> | ⇔ f(x) ∈ D ∨ f(x) ∈ E | ορισμός ένωσης |
> | ⇔ x ∈ f⁻¹(D) ∨ x ∈ f⁻¹(E) | ορισμός αντίστροφης εικόνας |
> | ⇔ x ∈ f⁻¹(D) ∪ f⁻¹(E) | ορισμός ένωσης |
>
> Μέθοδος [[Uni/ΕΠΛ111/03 - Σύνολα/06 - Αποδείξεις με Σύνολα#3. Μέθοδος 2: συμβολισμός κατασκευής συνόλου|κατασκευής συνόλου]]. Δεν χρειάστηκε καμία υπόθεση για την f (ούτε 1-1 ούτε επί).

### Άσκηση 26 🔴

Έστω f : A → B και C ⊆ A. Αποδείξτε ότι C ⊆ f⁻¹(f(C)), και δώστε παράδειγμα όπου ο εγκλεισμός είναι γνήσιος.

> [!success]- Λύση
> **Απόδειξη:** Έστω x ∈ C. Τότε f(x) ∈ f(C) (ορισμός εικόνας, με μάρτυρα το ίδιο το x). Άρα x ∈ f⁻¹(f(C)) (ορισμός αντίστροφης εικόνας). ∎
>
> **Γνήσιος εγκλεισμός:** f : Z → Z, f(x) = x², C = {2}. f(C) = {4}, f⁻¹({4}) = {−2, 2} ⊋ {2}.
>
> Η ισότητα ισχύει για κάθε C ακριβώς όταν η f είναι **ένα-προς-ένα**: τότε κανένα «ξένο» στοιχείο δεν έχει την ίδια εικόνα με στοιχείο του C.
