# 05 - Σύνθεση Συναρτήσεων

Αν η f μας πάει από το A στο B και η g από το B στο C, μπορούμε να τις εφαρμόσουμε τη μία μετά την άλλη και να πάμε κατευθείαν από το A στο C. Αυτή είναι η σύνθεση. Συνδέεται άμεσα με την αντίστροφη: μια συνάρτηση και η αντίστροφή της, συντεθειμένες, «ακυρώνουν» η μία την άλλη.

## 1. Ορισμός

> [!note] Σύνθεση (composition)
> Έστω f : A → B και g : B → C. Η **σύνθεση** (**composition**) των συναρτήσεων f και g, η οποία συμβολίζεται **(g ∘ f)**, είναι η συνάρτηση από το A στο C τ.ω., για κάθε στοιχείο α ∈ A,
>
> **(g ∘ f)(α) = g(f(α))**

![[Σύνθεση - Η Αλυσίδα.png|800]]

- Το **g ∘ f** διαβάζεται «g **μετά** f» ή «g σύνθεση f».
- Εφαρμόζεται **πρώτα η f** (αυτή που είναι πιο κοντά στο όρισμα), **μετά η g**.
- Η g ∘ f πηγαίνει **A → C**: από το πεδίο ορισμού της f στο πεδίο τιμών της g.

> [!important] Πότε ορίζεται η g ∘ f
> Η g πρέπει να μπορεί να «δεχτεί» κάθε f(α). Οι διαφάνειες απαιτούν το πεδίο τιμών της f να **συμπίπτει** με το πεδίο ορισμού της g (f : A → **B**, g : **B** → C). Αρκεί και το ασθενέστερο (Rosen): το **πεδίο τιμών συναρτήσεως** της f, δηλαδή το f(A), να είναι **υποσύνολο** του πεδίου ορισμού της g.
>
> Π.χ. f : R → R, f(x) = x² και g : [0, ∞) → R, g(x) = √x: η g ∘ f ορίζεται (f(R) = [0, ∞)), με (g ∘ f)(x) = √(x²) = |x|.

## 2. Παραδείγματα (διαφάνειες)

**f : Z → Z, f(x) = 2x + 3** και **g : Z → Z, g(x) = 3x + 2**

| Σύνθεση | Υπολογισμός |
|---|---|
| (f ∘ g)(x) | = f(g(x)) = f(3x + 2) = 2(3x + 2) + 3 = **6x + 7** |
| (g ∘ f)(x) | = g(f(x)) = g(2x + 3) = 3(2x + 3) + 2 = **6x + 11** |

**f : Z → Z, f(x) = x²** και **g : Z → Z, g(x) = 2x + 1**

| Σύνθεση | Υπολογισμός |
|---|---|
| (f ∘ g)(x) | = f(g(x)) = f(2x + 1) = **(2x + 1)²** |
| (g ∘ f)(x) | = g(f(x)) = g(x²) = **2x² + 1** |

![[Σύνθεση - Η Σειρά Μετράει.png|800]]

> [!tip] Πώς υπολογίζω τη σύνθεση χωρίς λάθος
> 1. Γράψε το εξωτερικό: (f ∘ g)(x) = f(**g(x)**).
> 2. Αντικατάστησε το **εσωτερικό** με τον τύπο του: f(3x + 2).
> 3. Στον τύπο της **εξωτερικής**, βάλε **ολόκληρη** την παρένθεση όπου υπάρχει x: 2**(3x + 2)** + 3. Οι παρενθέσεις είναι υποχρεωτικές.
> 4. Έλεγξε με έναν αριθμό: για x = 1, g(1) = 5, f(5) = 13, και 6 · 1 + 7 = 13 ✓.

> [!example]- Περισσότερα παραδείγματα (με «παγίδες»)
> **Σύνθεση με τον εαυτό της.** f : Z → Z, f(x) = 2x + 3: (f ∘ f)(x) = f(2x + 3) = 2(2x + 3) + 3 = 4x + 9. **Προσοχή:** f ∘ f ≠ f², αν f² σημαίνει (f(x))² = (2x + 3)².
>
> **Πεπερασμένα σύνολα.** f : {1, 2, 3} → {α, β, γ}, f(1) = α, f(2) = β, f(3) = β, και g : {α, β, γ} → {x, y}, g(α) = y, g(β) = x, g(γ) = y. Τότε (g ∘ f)(1) = y, (g ∘ f)(2) = x, (g ∘ f)(3) = x. Το g(γ) **δεν** χρησιμοποιείται, αφού το γ δεν είναι εικόνα της f. Η f ∘ g **δεν ορίζεται**: η g δίνει x ή y, που δεν ανήκουν στο πεδίο ορισμού της f.
>
> **Πάτωμα και ταβάνι.** f : R → Z, f(x) = ⌊x⌋, g : Z → Z, g(n) = n + 1: (g ∘ f)(x) = ⌊x⌋ + 1. Η f ∘ g ορίζεται μόνο αν δούμε το g(n) ∈ Z ⊆ R· τότε (f ∘ g)(n) = ⌊n + 1⌋ = n + 1.
>
> **Τρεις συναρτήσεις.** h(x) = x − 1, g(x) = 3x, f(x) = x² (όλες R → R): (f ∘ g ∘ h)(x) = f(g(h(x))) = f(g(x − 1)) = f(3x − 3) = (3x − 3)². Πρώτα η **h** (η πιο δεξιά).

## 3. Η σειρά μετράει

> [!warning] Η σύνθεση ΔΕΝ είναι αντιμεταθετική
> Γενικά **f ∘ g ≠ g ∘ f**. Στα παραδείγματα των διαφανειών: 6x + 7 ≠ 6x + 11 και (2x + 1)² ≠ 2x² + 1.
>
> Επιπλέον, η μία μπορεί να **ορίζεται** και η άλλη **όχι**: αν f : A → B και g : B → C με C ⊄ A, τότε υπάρχει η g ∘ f αλλά όχι η f ∘ g.

Πότε **f ∘ g = g ∘ f**; Μόνο σε ειδικές περιπτώσεις, π.χ.:
- f = g,
- η μία είναι η ταυτοτική: f ∘ ι = ι ∘ f = f,
- g = f⁻¹: f ∘ f⁻¹ και f⁻¹ ∘ f είναι και οι δύο ταυτοτικές (αλλά **σε διαφορετικά σύνολα** αν A ≠ B, άρα και πάλι όχι ίσες!),
- δύο μεταφορές: f(x) = x + 1, g(x) = x + 2 ⇒ και οι δύο συνθέσεις δίνουν x + 3.

## 4. Η σύνθεση είναι προσεταιριστική (επέκταση)

Για f : A → B, g : B → C, h : C → D:

**h ∘ (g ∘ f) = (h ∘ g) ∘ f**

Και τα δύο μέλη στέλνουν το α στο h(g(f(α))). Γι' αυτό γράφουμε απλώς **h ∘ g ∘ f** χωρίς παρενθέσεις. (Προσεταιριστική **ναι**, αντιμεταθετική **όχι**: όπως η διαφορά συνόλων [[Uni/ΕΠΛ111/03 - Σύνολα/05 - Ταυτότητες Συνόλων|δεν είναι]] ούτε το ένα ούτε το άλλο, η σύνθεση είναι μόνο το πρώτο.)

## 5. Ταυτοτικές συναρτήσεις

> [!note] Ταυτοτική συνάρτηση (identity function)
> Συναρτήσεις της μορφής f : A → A όπου f(α) = α για κάθε στοιχείο α ∈ A ονομάζονται **ταυτοτικές συναρτήσεις** (**identity functions**).

Συμβολίζεται συνήθως **ι_A** (ή id_A, 1_A). Υπάρχει **μία για κάθε σύνολο A**.

- Η ι_A είναι **ένα-προς-ένα αντιστοιχία** και **ι_A⁻¹ = ι_A**.
- Είναι το «ουδέτερο στοιχείο» της σύνθεσης: για f : A → B, **f ∘ ι_A = f** και **ι_B ∘ f = f**.

> [!warning] Η ι_A και η ι_B είναι διαφορετικές συναρτήσεις αν A ≠ B
> Ο τύπος «f(x) = x» είναι ίδιος, αλλά τα πεδία διαφέρουν, άρα (όπως είδαμε στην [[01 - Ορισμός Συνάρτησης#5. Ισότητα συναρτήσεων (επέκταση)|ισότητα συναρτήσεων]]) είναι διαφορετικές συναρτήσεις. Αυτό μετράει στην επόμενη ενότητα.

## 6. Αντίστροφη και σύνθεση

**Άσκηση διαφανειών:** Έστω f : A → B ένα-προς-ένα αντιστοιχία όπου f(α) = β. Πόσο κάνουν (f⁻¹ ∘ f)(α) και (f ∘ f⁻¹)(β);

> [!success]- Λύση
> - **(f⁻¹ ∘ f)(α) = f⁻¹(f(α)) = f⁻¹(β) = α**
> - **(f ∘ f⁻¹)(β) = f(f⁻¹(β)) = f(α) = β**
>
> Το δεύτερο βήμα κάθε γραμμής είναι ο ορισμός της αντίστροφης: f⁻¹(β) = α ⇔ f(α) = β.

![[Σύνθεση - Πήγαινε και Έλα.png|800]]

> [!important] Μια συνάρτηση και η αντίστροφή της ακυρώνονται
> **f⁻¹ ∘ f = ι_A** (A → B → A) και **f ∘ f⁻¹ = ι_B** (B → A → B)
>
> Αυτό είναι και **χαρακτηρισμός**: αν g : B → A με g ∘ f = ι_A και f ∘ g = ι_B, τότε η f είναι αντιστοιχία και g = f⁻¹. Είναι ο πιο κομψός τρόπος να αποδείξεις ότι μια f είναι αντιστοιχία **και** να βρεις την αντίστροφή της με μία κίνηση.

> [!example]- Η αντίστροφη μιας σύνθεσης: (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹ (επέκταση)
> Αν f : A → B και g : B → C είναι αντιστοιχίες, τότε και η g ∘ f : A → C είναι αντιστοιχία, και
>
> **(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹** (η σειρά **αντιστρέφεται**)
>
> **Γιατί:** (f⁻¹ ∘ g⁻¹) ∘ (g ∘ f) = f⁻¹ ∘ (g⁻¹ ∘ g) ∘ f = f⁻¹ ∘ ι_B ∘ f = f⁻¹ ∘ f = ι_A, και συμμετρικά από την άλλη πλευρά.
>
> **Διαίσθηση («κάλτσες και παπούτσια»):** φοράς πρώτα κάλτσες (f), μετά παπούτσια (g). Για να τα βγάλεις, βγάζεις **πρώτα τα παπούτσια** (g⁻¹), μετά τις κάλτσες (f⁻¹).
>
> **Παράδειγμα:** f(x) = x + 1, g(x) = 2x στο R. (g ∘ f)(x) = 2(x + 1) = 2x + 2, με αντίστροφη (y − 2)/2 = y/2 − 1. Και f⁻¹(g⁻¹(y)) = f⁻¹(y/2) = y/2 − 1 ✓. Η λάθος σειρά g⁻¹(f⁻¹(y)) = (y − 1)/2 δίνει άλλο αποτέλεσμα.

## 7. Σύνθεση και κατηγορίες (επέκταση)

Για f : A → B και g : B → C:

| Αν… | τότε… | Ισχύει; |
|---|---|---|
| f, g 1-1 | g ∘ f 1-1 | ✓ |
| f, g επί | g ∘ f επί | ✓ |
| f, g αντιστοιχίες | g ∘ f αντιστοιχία | ✓ |
| g ∘ f 1-1 | **f** 1-1 | ✓ |
| g ∘ f 1-1 | g 1-1 | ✗ |
| g ∘ f επί | **g** επί | ✓ |
| g ∘ f επί | f επί | ✗ |
| g ∘ f αντιστοιχία | f και g αντιστοιχίες | ✗ |

> [!example]- Αποδείξεις
> **f, g 1-1 ⇒ g ∘ f 1-1.** Έστω g(f(x)) = g(f(y)). Αφού η g είναι 1-1, f(x) = f(y). Αφού η f είναι 1-1, x = y. ∎
>
> **f, g επί ⇒ g ∘ f επί.** Έστω z ∈ C. Αφού η g είναι επί, υπάρχει y ∈ B με g(y) = z. Αφού η f είναι επί, υπάρχει x ∈ A με f(x) = y. Τότε (g ∘ f)(x) = g(y) = z. ∎
>
> **g ∘ f 1-1 ⇒ f 1-1.** Έστω f(x) = f(y). Εφαρμόζοντας τη g, g(f(x)) = g(f(y)). Αφού η g ∘ f είναι 1-1, x = y. ∎
>
> **g ∘ f επί ⇒ g επί.** Έστω z ∈ C. Υπάρχει x ∈ A με g(f(x)) = z, άρα το y = f(x) ∈ B ικανοποιεί g(y) = z. ∎

> [!example]- Αντιπαράδειγμα: g ∘ f αντιστοιχία, αλλά ούτε η f ούτε η g
> A = {1}, B = {1, 2}, C = {1}. f : A → B με f(1) = 1, g : B → C με g(1) = g(2) = 1.
> - Η f είναι 1-1 αλλά **όχι επί** (το 2 ∈ B δεν έχει προεικόνα).
> - Η g είναι επί αλλά **όχι 1-1** (g(1) = g(2)).
> - Η g ∘ f : {1} → {1} είναι η ταυτοτική, άρα **αντιστοιχία**.
>
> **Δίδαγμα:** η «πρώτη» συνάρτηση (f) κληρονομεί το 1-1, η «τελευταία» (g) κληρονομεί το επί. Το στοιχείο 2 ∈ B, που «χαλάει» και τις δύο, δεν χρησιμοποιείται ποτέ από τη σύνθεση.

## 8. Συχνά Λάθη

> [!warning] Προσοχή στο τεστ
> - **Λάθος σειρά.** (g ∘ f)(x) = g(f(x)): **πρώτα f**. Διαβάζεις από **δεξιά** προς τα αριστερά.
> - **f ∘ g = g ∘ f.** Γενικά όχι. Υπολόγισε και τις δύο.
> - **Ξεχνάς παρενθέσεις.** f(3x + 2) με f(x) = 2x + 3 είναι 2**(3x + 2)** + 3 = 6x + 7, όχι 2 · 3x + 2 + 3.
> - **f ∘ f = f².** Η σύνθεση f(f(x)) δεν είναι το τετράγωνο (f(x))².
> - **Σύνθεση που δεν ορίζεται.** Πριν υπολογίσεις g ∘ f, έλεγξε ότι οι τιμές της f ανήκουν στο πεδίο ορισμού της g.
> - **Πεδία της σύνθεσης.** Η g ∘ f πάει από το **πεδίο ορισμού της f** στο **πεδίο τιμών της g**: A → C.
> - **f⁻¹ ∘ f = f ∘ f⁻¹.** Και οι δύο είναι ταυτοτικές, αλλά η πρώτη στο **A** και η δεύτερη στο **B**.
> - **(g ∘ f)⁻¹ = g⁻¹ ∘ f⁻¹.** Λάθος σειρά: είναι **f⁻¹ ∘ g⁻¹**.
