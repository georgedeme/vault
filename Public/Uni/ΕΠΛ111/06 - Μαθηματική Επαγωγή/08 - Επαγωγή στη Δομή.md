# 08 - Επαγωγή στη Δομή

Για σύνολα που ορίζονται αναδρομικά (τύποι, δέντρα, συμβολοσειρές), η επαγωγή δεν γίνεται «ν → ν + 1» αλλά **ακολουθεί τον ορισμό**: δείχνουμε την πρόταση για τα βασικά στοιχεία, και ότι κάθε κανόνας κατασκευής τη «διατηρεί». (διαφάνειες 35–39)

## 1. Η μέθοδος

> [!important] Επαγωγή πάνω στη δομή (διαφάνεια 35)
> Για να αποδείξουμε προτάσεις της μορφής **∀x P(x) όπου το πεδίο ορισμού είναι ένα αναδρομικά ορισμένο σύνολο**, χρησιμοποιούμε **επαγωγή πάνω στη δομή** (structural induction):
> 1. **Βασικό Βήμα:** Δείχνουμε ότι η πρόταση P(α) είναι αληθής για **κάθε βασικό στοιχείο** του συνόλου.
> 2. **Επαγωγικό Βήμα:** Δείχνουμε ότι η πρόταση P(α) είναι αληθής για κάθε **σύνθετο** στοιχείο α του συνόλου, υποθέτοντας ότι η πρόταση P(β) είναι αληθής για κάθε **συστατικό** στοιχείο β του α.

| Αναδρομικός ορισμός ([[07 - Αναδρομικοί Ορισμοί Συνόλων\|07]]) | Επαγωγή στη δομή |
|---|---|
| Βασικό Βήμα: αρχικά στοιχεία | Βασικό Βήμα: P για **κάθε** αρχικό στοιχείο |
| Αναδρομικό Βήμα: **κάθε** κανόνας κατασκευής | Επαγωγικό Βήμα: μία περίπτωση για **κάθε** κανόνα |
| Κανόνας αποκλεισμού | εγγυάται ότι δεν ξεχάσαμε κανένα στοιχείο |

> [!info]- 🧠 Γιατί η επαγωγή στη δομή είναι ορθή
> Κάθε στοιχείο του συνόλου φτιάχνεται με **πεπερασμένες** εφαρμογές κανόνων (κανόνας αποκλεισμού). Έστω Q(ν): «η P ισχύει για κάθε στοιχείο που φτιάχνεται με ≤ ν εφαρμογές κανόνων». Το βασικό βήμα δίνει Q(0). Το επαγωγικό βήμα δίνει Q(0) ∧ ⋯ ∧ Q(κ) → Q(κ + 1), αφού τα συστατικά ενός στοιχείου με κ + 1 εφαρμογές έχουν ≤ κ. Άρα η επαγωγή στη δομή είναι [[05 - Ισχυρή Επαγωγή|ισχυρή επαγωγή]] στο «βάθος κατασκευής».
>
> Για τον N (0 ∈ N, ν ∈ N ⇒ ν + 1 ∈ N), η επαγωγή στη δομή **είναι** η απλή επαγωγή.

## 2. Παρενθέσεις στους τύπους

> [!example] Θεώρημα (διαφάνεια 36)
> Για κάθε [[07 - Αναδρομικοί Ορισμοί Συνόλων#4. Καλά ορισμένοι τύποι της προτασιακής λογικής|καλά ορισμένο τύπο]] της προτασιακής λογικής, ισχύει ότι ο αριθμός των αριστερών παρενθέσεων είναι ίδιος με τον αριθμό των δεξιών παρενθέσεων.

> [!success]- Απόδειξη (διαφάνεια 36)
> 1. **Βασικό Βήμα:** Αφού οι βασικοί τύποι **T**, **F** και P δεν περιέχουν παρενθέσεις, η πρόταση είναι τετριμμένα αληθής.
> 2. **Επαγωγικό Βήμα:** Πρέπει να δείξουμε ότι η πρόταση είναι αληθής για κάθε σύνθετο καλά ορισμένο τύπο της προτασιακής λογικής, υποθέτοντας ότι η πρόταση είναι αληθής για τα συστατικά του στοιχεία.
>    Θεωρούμε τους σύνθετους τύπους (¬P), (P ∧ Q), (P ∨ Q), (P → Q) και (P ↔ Q). **Από την επαγωγική υπόθεση, P και Q έχουν ίσο αριθμό αριστερών και δεξιών παρενθέσεων.** Επομένως, και οι πιο πάνω σύνθετοι τύποι έχουν ίσο αριθμό αριστερών και δεξιών παρενθέσεων. ∎

> [!info]- 🧠 Το «επομένως» με αριθμούς
> Έστω l(φ), r(φ) οι αριστερές/δεξιές παρενθέσεις του φ. Από την υπόθεση l(P) = r(P) και l(Q) = r(Q).
> - (¬P): l = 1 + l(P) = 1 + r(P) = r. ✓
> - (P ∘ Q) για ∘ ∈ {∧, ∨, →, ↔}: l = 1 + l(P) + l(Q) = 1 + r(P) + r(Q) = r. ✓
>
> Κάθε κανόνας προσθέτει **ακριβώς ένα** ζευγάρι. Γι' αυτό η απόδειξη πρέπει να κοιτάξει **όλους** τους κανόνες: αν υπήρχε κανόνας «αν P τύπος, τότε (P τύπος», η πρόταση θα ήταν ψευδής.

> [!example]- Ίδια μέθοδος: άτομα και δυαδικοί τελεστές (επέκταση)
> Για καλά ορισμένο τύπο φ, έστω a(φ) ο αριθμός εμφανίσεων βασικών τύπων (T, F, μεταβλητές) και b(φ) ο αριθμός εμφανίσεων **δυαδικών** τελεστών (∧, ∨, →, ↔). Τότε **a(φ) = b(φ) + 1**.
> - **Βάση:** φ βασικός: a = 1, b = 0. ✓
> - **Βήμα, φ = (¬P):** ο ¬ δεν αλλάζει κανένα από τα δύο: a(φ) = a(P) = b(P) + 1 = b(φ) + 1. ✓
> - **Βήμα, φ = (P ∘ Q):** a(φ) = a(P) + a(Q) = (b(P) + 1) + (b(Q) + 1) = (b(P) + b(Q) + 1) + 1 = b(φ) + 1. ✓
>
> Π.χ. ((P ∨ (Q ∧ R)) → ((¬R) ↔ (P ∧ Q))): a = 6, b = 5. Η περίπτωση του ¬ είναι διαφορετική από των δυαδικών τελεστών, άρα πρέπει να γραφτεί **χωριστά**.

## 3. Κόμβοι και ύψος γεμάτων δυαδικών δέντρων

> [!note] Αναδρομικοί ορισμοί πάνω στα δέντρα (διαφάνεια 37)
> Για γεμάτο δυαδικό δέντρο T, ορίζουμε αναδρομικά:
> - **Τον αριθμό των κόμβων του:** N(T) = 1 για δέντρο με ένα κόμβο, και **N(T₁ · T₂) = 1 + N(T₁) + N(T₂)**.
> - **Το ύψος του:** H(T) = 0 για δέντρο με ένα κόμβο, και **H(T₁ · T₂) = 1 + max{ H(T₁), H(T₂) }**.

Το «1 +» στο N είναι η νέα **ρίζα**. Το «1 +» στο H είναι η νέα **ακμή** από τη ρίζα προς το ψηλότερο υποδέντρο.

![[Δομή - Επαγωγή στο Δέντρο.png|800]]

### Άνω φράγμα: N(T) ≤ 2^{H(T)+1} − 1

> [!example] Θεώρημα (διαφάνεια 38)
> Για κάθε γεμάτο δυαδικό δέντρο T, N(T) ≤ 2^{H(T)+1} − 1.

> [!success]- Απόδειξη (διαφάνεια 38)
> 1. **Βασικό Βήμα:** Για το γεμάτο δυαδικό δέντρο T με ένα κόμβο, η πρόταση είναι αληθής αφού N(T) = 1 ≤ 2^{H(T)+1} − 1 = 2^{0+1} − 1 = 1.
> 2. **Επαγωγικό Βήμα:** Πρέπει να δείξουμε ότι η πρόταση είναι αληθής για κάθε σύνθετο γεμάτο δυαδικό δέντρο T = T₁ · T₂.
>    Από την επαγωγική υπόθεση, N(T₁) ≤ 2^{H(T₁)+1} − 1 και N(T₂) ≤ 2^{H(T₂)+1} − 1.
>
> | | | Αιτιολόγηση |
> |---|---|---|
> | N(T) | = 1 + N(T₁) + N(T₂) | ορισμός του N |
> | | ≤ 1 + (2^{H(T₁)+1} − 1) + (2^{H(T₂)+1} − 1) | **επαγωγική υπόθεση** |
> | | ≤ 2 · max{ 2^{H(T₁)+1}, 2^{H(T₂)+1} } − 1 | a + b ≤ 2 · max{a, b} |
> | | = 2 · 2^{max{ H(T₁), H(T₂) } + 1} − 1 | το 2^x είναι αύξουσα |
> | | = 2 · 2^{H(T)} − 1 | ορισμός του H |
> | | = 2^{H(T)+1} − 1 | ∎ |

### Κάτω φράγμα: N(T) ≥ 2 · H(T) + 1

> [!example] Θεώρημα (διαφάνεια 39)
> Για κάθε γεμάτο δυαδικό δέντρο T, N(T) ≥ 2 · H(T) + 1.

> [!success]- Απόδειξη (διαφάνεια 39)
> 1. **Βασικό Βήμα:** Για το γεμάτο δυαδικό δέντρο T με ένα κόμβο, η πρόταση είναι αληθής αφού N(T) = 1 ≥ 2 · H(T) + 1 = 2 · 0 + 1 = 1.
> 2. **Επαγωγικό Βήμα:** Πρέπει να δείξουμε ότι η πρόταση είναι αληθής για κάθε σύνθετο γεμάτο δυαδικό δέντρο T = T₁ · T₂.
>    Από την επαγωγική υπόθεση, N(T₁) ≥ 2 · H(T₁) + 1 και N(T₂) ≥ 2 · H(T₂) + 1.
>
> | | | Αιτιολόγηση |
> |---|---|---|
> | N(T) | = 1 + N(T₁) + N(T₂) | ορισμός του N |
> | | ≥ 1 + (2 · H(T₁) + 1) + (2 · H(T₂) + 1) | **επαγωγική υπόθεση** |
> | | = 1 + 2 · (H(T₁) + H(T₂)) + 2 | |
> | | ≥ 1 + 2 · max{ H(T₁), H(T₂) } + 2 | a + b ≥ max{a, b} για a, b ≥ 0 |
> | | = 1 + 2 · (max{ H(T₁), H(T₂) } + 1) | |
> | | = 1 + 2 · H(T) | ορισμός του H ∎ |

![[Δομή - Όρια του N(T).png|800]]

> [!info]- 🧠 Τα φράγματα είναι τα καλύτερα δυνατά
> - **Άνω:** το **τέλειο** δέντρο ύψους h (όλα τα φύλλα στο βάθος h) έχει 1 + 2 + 4 + ⋯ + 2^h = 2^{h+1} − 1 κόμβους: **ισότητα**.
> - **Κάτω:** η «κάμπια» ύψους h (σε κάθε επίπεδο ένας κόμβος έχει δύο παιδιά, το ένα φύλλο) έχει 2h + 1 κόμβους: **ισότητα**.
>
> Άρα για γεμάτο δυαδικό δέντρο ύψους h: **2h + 1 ≤ N ≤ 2^{h+1} − 1**. Αντίστροφα, ένα δέντρο με N κόμβους έχει ύψος τουλάχιστον log₂(N + 1) − 1: αυτή είναι η βάση για το γιατί τα ισορροπημένα δέντρα αναζήτησης έχουν λογαριθμικό ύψος.

> [!example]- Περισσότερες ιδιότητες με επαγωγή στη δομή (επέκταση)
> | Πρόταση | Βάση | Βήμα (T = T₁ · T₂) |
> |---|---|---|
> | N(T) είναι **περιττός** | 1 | 1 + περιττός + περιττός = περιττός |
> | φύλλα L(T) = εσωτερικοί I(T) + 1 | L = 1, I = 0 | L = L₁ + L₂ = (I₁ + 1) + (I₂ + 1) = (I₁ + I₂ + 1) + 1 = I + 1 |
> | L(T) ≤ 2^{H(T)} | 1 ≤ 1 | L₁ + L₂ ≤ 2^{H₁} + 2^{H₂} ≤ 2 · 2^{max} = 2^{H} |
> | ℓ(x · z) = ℓ(x) + ℓ(z) για x, z ∈ Σ* (επαγωγή στη δομή του z) | z = ε: ℓ(x) = ℓ(x) + 0 | z = w · y: ℓ(x · w · y) = ℓ(x · w) + 1 = ℓ(x) + ℓ(w) + 1 = ℓ(x) + ℓ(z) |

## 4. Γιατί όχι «απλή επαγωγή στον αριθμό κόμβων»;

> [!warning] 🔴 Η παγίδα της αφαίρεσης κόμβου
> Μια φυσική ιδέα: «επαγωγή στο N(T): πάρε δέντρο με κ + 1 κόμβους, **σβήσε ένα φύλλο**, εφάρμοσε την υπόθεση». Αλλά αν σβήσεις ένα φύλλο από γεμάτο δυαδικό δέντρο, ο γονιός του μένει με **ένα** παιδί: το αποτέλεσμα **δεν** είναι γεμάτο δυαδικό δέντρο, και η υπόθεση δεν εφαρμόζεται. (Και αφού το N(T) είναι πάντα περιττό, «δέντρο με κ κόμβων» για άρτιο κ δεν υπάρχει.)
>
> Η επαγωγή στη δομή αποφεύγει το πρόβλημα: «σπάει» το T **μόνο** με τον τρόπο που φτιάχτηκε (T₁ · T₂), οπότε τα κομμάτια είναι πάντα μέσα στο σύνολο. Αν θέλεις οπωσδήποτε επαγωγή σε αριθμό, κάνε **ισχυρή** επαγωγή στο N(T) σπάζοντας στη ρίζα (N(T₁), N(T₂) < N(T)).

## 5. Συχνά Λάθη

> [!warning] Προσοχή
> - **Ξεχνάς κανόνα.** Στους τύπους υπάρχουν **πέντε** σύνθετες μορφές· στο βασικό βήμα, **T**, **F** και **μεταβλητές**. Η απόδειξη πρέπει να τις καλύπτει όλες (μπορούν να ομαδοποιηθούν, όπως στη διαφάνεια 36, αν το επιχείρημα είναι κοινό).
> - **Υποθέτεις την πρόταση για το ίδιο το T.** Η υπόθεση είναι για τα **συστατικά** T₁, T₂ (ή P, Q).
> - **Σβήνεις κόμβους** αντί να σπας στη ρίζα (§4).
> - **H(T) για ένα κόμβο = 1.** Είναι **0** (το ύψος μετρά ακμές). Αν το μπερδέψεις, όλα τα φράγματα μετατοπίζονται.
> - **max αντί για άθροισμα, ή ανάποδα.** a + b ≤ 2 max{a, b} (άνω φράγμα) αλλά a + b ≥ max{a, b} μόνο για **μη αρνητικά** a, b (κάτω φράγμα· εδώ τα ύψη είναι ≥ 0).
> - **Αναμιγνύεις συμβολισμούς.** P στη διαφάνεια 36 είναι **τύπος**, όχι η πρόταση της επαγωγής.
