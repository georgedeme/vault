# 03 - Ανισότητες

Επαγωγή για ανισότητες: η βάση συχνά **δεν** είναι το 1, και στο επαγωγικό βήμα δεν φτάνουμε στον στόχο με ισότητες, αλλά με μια **αλυσίδα** από < και ≤. Δύο παραδείγματα των διαφανειών: 2^ν < ν! και οι αρμονικοί αριθμοί. (διαφάνειες 10–14)

## 1. Δυνάμεις του 2 και παραγοντικά

> [!example] Θεώρημα (διαφάνεια 10)
> Για κάθε ν ≥ 4, 2^ν < ν!. Αυτή είναι η P(ν).

> [!success]- Απόδειξη (διαφάνεια 10)
> 1. **Βασικό Βήμα:** P(4) είναι αληθής αφού 2⁴ = 16 < 4! = 24.
> 2. **Επαγωγικό Βήμα:** Πρέπει να δείξουμε ότι ∀x (P(x) → P(x+1)).
>    Υποθέτουμε ότι P(κ) είναι αληθής για αυθαίρετο κ ≥ 4, δηλαδή 2^κ < κ!.
>    Προχωρούμε να δείξουμε ότι η πρόταση P(κ+1) είναι αληθής. Από την επαγωγική υπόθεση,
>    2^{κ+1} = 2 · 2^κ < 2 · **κ!** < (κ + 1) · κ! = (κ + 1)!, και επομένως 2^{κ+1} < (κ + 1)!.
>
> Αφού P(4) και ∀x (P(x) → P(x+1)) είναι αληθείς, τότε ∀y P(y) είναι αληθής. ∎

> [!info]- 🧠 Τι χρησιμοποιεί κάθε κρίκος της αλυσίδας
> | Βήμα | Γιατί ισχύει |
> |---|---|
> | 2^{κ+1} = 2 · 2^κ | ορισμός της δύναμης |
> | 2 · 2^κ < 2 · κ! | **επαγωγική υπόθεση**, πολλαπλασιασμένη με 2 > 0 |
> | 2 · κ! < (κ + 1) · κ! | **2 < κ + 1**, που ισχύει αφού κ ≥ 4 (αρκεί κ ≥ 2) |
> | (κ + 1) · κ! = (κ + 1)! | ορισμός του παραγοντικού |
>
> Ο τρίτος κρίκος είναι αυτός που οι περισσότεροι ξεχνούν να δικαιολογήσουν. Το επαγωγικό βήμα ισχύει για κάθε κ ≥ 2, αλλά η **βάση** χρειάζεται ν = 4: για ν = 2, 3 έχουμε 4 > 2 και 8 > 6.

> [!important] Δύο ξεχωριστά κατώφλια
> Σε κάθε ανισότητα με επαγωγή υπάρχουν δύο ερωτήματα:
> 1. **Από πού ισχύει η βάση;** (εδώ: ν = 4)
> 2. **Από πού ισχύει το επαγωγικό βήμα;** (εδώ: κ ≥ 2)
>
> Η απόδειξη χρειάζεται τη βάση σε κάποιο ν₀ **και** το βήμα για κάθε κ ≥ ν₀. Αν το βήμα θέλει μεγαλύτερο κ από τη βάση, πρέπει να ελέγξεις «με το χέρι» τις ενδιάμεσες τιμές ή να μετακινήσεις τη βάση.

![[Ανισότητες - Πού Ξεκινά η Ανισότητα.png|800]]

> [!example]- 🔴 Επέκταση: 2^ν > ν² για ν ≥ 5
> Ισχύει για ν = 0, 1, **αποτυγχάνει** για ν = 2, 3, 4 (4 = 4, 8 < 9, 16 = 16) και ισχύει ξανά από το 5. Άρα η βάση είναι **ν = 5**: 32 > 25.
>
> **Βήμα:** υποθέτουμε 2^κ > κ² για κ ≥ 5. Τότε 2^{κ+1} = 2 · 2^κ > 2κ², και θέλουμε 2κ² ≥ (κ + 1)² = κ² + 2κ + 1, δηλαδή κ² − 2κ − 1 ≥ 0, δηλαδή (κ − 1)² ≥ 2, που ισχύει για κ ≥ 3. Άρα 2^{κ+1} > (κ + 1)². ∎
>
> Αν κάποιος «αποδείξει» το 2^ν > ν² για **κάθε** ν ≥ 0 με βάση P(0) και αυτό το βήμα, το λάθος είναι ότι το βήμα **δεν** ισχύει για κ = 0, 1, 2.

> [!example]- Επέκταση: ανισότητα του Bernoulli, (1 + x)^ν ≥ 1 + νx για x ≥ −1, ν ≥ 0
> **Βάση:** ν = 0: 1 ≥ 1. ✓
> **Βήμα:** υποθέτουμε (1 + x)^κ ≥ 1 + κx. Πολλαπλασιάζουμε και τα δύο μέλη με **1 + x ≥ 0** (γι' αυτό χρειάζεται x ≥ −1· με αρνητικό αριθμό η ανισότητα αλλάζει φορά):
> (1 + x)^{κ+1} ≥ (1 + κx)(1 + x) = 1 + (κ + 1)x + κx² ≥ 1 + (κ + 1)x, αφού κx² ≥ 0. ∎
>
> **Παγίδα:** πολλαπλασιασμός ανισότητας με ποσότητα που μπορεί να είναι αρνητική. Γράφε πάντα «πολλαπλασιάζω με … > 0».

## 2. Αρμονικοί αριθμοί

> [!note] Ορισμός (διαφάνεια 11)
> Οι **αρμονικοί αριθμοί** (harmonic numbers) ορίζονται ως H(κ) = 1 + 1/2 + 1/3 + ⋯ + 1/κ.
>
> | κ | H(κ) |
> |---|---|
> | 1 | 1 |
> | 2 | 1 + 1/2 = 3/2 |
> | 3 | 1 + 1/2 + 1/3 = 11/6 |
> | 4 | 1 + 1/2 + 1/3 + 1/4 = 25/12 |

> [!example] Θεώρημα (διαφάνεια 12)
> Για κάθε ν ≥ 0, **H(2^ν) ≥ 1 + ν/2**. Αυτή είναι η P(ν).

Η επαγωγή είναι πάνω στον **εκθέτη** ν, όχι στο όρισμα του H. Από το P(κ) στο P(κ+1) το όρισμα **διπλασιάζεται** (2^κ → 2^{κ+1}), άρα προστίθενται **2^κ** νέοι όροι, όχι ένας.

> [!success]- Απόδειξη (διαφάνειες 12–14)
> 1. **Βασικό Βήμα:** P(0) είναι αληθής αφού H(2⁰) = H(1) = 1 και 1 + 0/2 = 1.
> 2. **Επαγωγικό Βήμα:** Πρέπει να δείξουμε ότι ∀x (P(x) → P(x+1)).
>    Υποθέτουμε ότι P(κ) είναι αληθής για αυθαίρετο κ ≥ 0, δηλαδή H(2^κ) ≥ 1 + κ/2.
>    Προχωρούμε να δείξουμε την πρόταση P(κ+1): H(2^{κ+1}) ≥ 1 + (κ+1)/2.
>
> | | | Αιτιολόγηση |
> |---|---|---|
> | H(2^{κ+1}) | = 1 + 1/2 + 1/3 + ⋯ + 1/2^κ + 1/(2^κ + 1) + ⋯ + 1/2^{κ+1} | ορισμός |
> | | = H(2^κ) + 1/(2^κ + 1) + ⋯ + 1/2^{κ+1} | οι πρώτοι 2^κ όροι είναι το H(2^κ) |
> | | ≥ **(1 + κ/2)** + 1/(2^κ + 1) + ⋯ + 1/2^{κ+1} | επαγωγική υπόθεση |
> | | ≥ (1 + κ/2) + 2^κ · 1/2^{κ+1} | 2^κ όροι, ο καθένας ≥ 1/2^{κ+1} (ο μικρότερος είναι ο τελευταίος) |
> | | = (1 + κ/2) + 1/2 | |
> | | = 1 + (κ + 1)/2 | |
>
> Αφού P(0) και ∀x (P(x) → P(x+1)) είναι αληθείς, τότε ∀y P(y) είναι αληθής. ∎

![[Ανισότητες - Αρμονικοί σε Μπλοκ.png|800]]

> [!info]- 🧠 Γιατί μας ενδιαφέρει: το H(ν) δεν είναι φραγμένο
> Από το θεώρημα, H(2^ν) ≥ 1 + ν/2, και το 1 + ν/2 γίνεται όσο μεγάλο θέλουμε. Άρα η αρμονική σειρά 1 + 1/2 + 1/3 + ⋯ **αποκλίνει**, παρότι οι όροι της τείνουν στο 0. Π.χ. για να ξεπεράσει το 10 αρκεί ν = 18, δηλαδή 2¹⁸ = 262 144 όροι.
>
> **Άνω φράγμα με την ίδια ιδέα:** κάθε μπλοκ 1/(2^κ + 1) + ⋯ + 1/2^{κ+1} είναι ≤ 2^κ · 1/(2^κ + 1) < 1, άρα H(2^ν) ≤ 1 + ν. Το H(ν) μεγαλώνει περίπου όπως ο λογάριθμος.

## 3. Ενίσχυση της πρότασης (επέκταση)

> [!example]- 🔴 1 + 1/4 + 1/9 + ⋯ + 1/ν² < 2
> Η άμεση επαγωγή **κολλάει**: από S(κ) < 2 παίρνουμε S(κ+1) = S(κ) + 1/(κ + 1)² < 2 + 1/(κ + 1)², που **δεν** είναι < 2. Η υπόθεση είναι πολύ «αδύναμη»: δεν λέει πόσο κάτω από το 2 είμαστε.
>
> **Λύση:** αποδεικνύουμε κάτι **ισχυρότερο**: S(ν) ≤ 2 − 1/ν για ν ≥ 1.
> - **Βάση:** S(1) = 1 ≤ 2 − 1 = 1. ✓
> - **Βήμα:** S(κ+1) ≤ 2 − 1/κ + 1/(κ + 1)², και θέλουμε ≤ 2 − 1/(κ + 1). Αρκεί 1/(κ + 1)² + 1/(κ + 1) ≤ 1/κ, δηλαδή κ(κ + 2) ≤ (κ + 1)², δηλαδή κ² + 2κ ≤ κ² + 2κ + 1. ✓
>
> Αφού 2 − 1/ν < 2, προκύπτει το ζητούμενο. Το παράδοξο: η **ισχυρότερη** πρόταση είναι **ευκολότερη** στην απόδειξη, γιατί η επαγωγική της υπόθεση δίνει περισσότερη πληροφορία.

## 4. Τεχνική για ανισότητες

> [!tip] Βήματα
> 1. Γράψε το **αριστερό μέλος** του P(κ+1) και «σπάσ' το» ώστε να εμφανιστεί το αριστερό μέλος του P(κ) (2^{κ+1} = 2 · 2^κ, H(2^{κ+1}) = H(2^κ) + …).
> 2. Αντικατέστησε με την **επαγωγική υπόθεση**, προσέχοντας τη **φορά** (< ή ≥).
> 3. Γράψε τον **στόχο** (το δεξί μέλος του P(κ+1)) και βρες **τι μένει να ισχύει** (π.χ. 2 < κ + 1). Αυτό είναι συνήθως μια απλή ανισότητα για το κ.
> 4. Έλεγξε **για ποια κ** ισχύει αυτή η απλή ανισότητα, και ότι καλύπτει κάθε κ ≥ βάση.

## 5. Συχνά Λάθη

> [!warning] Προσοχή
> - **Λάθος βάση.** «Για ν ≥ 4» → P(4). Το P(1) του 2^ν < ν! είναι **ψευδές**.
> - **Αδικαιολόγητος κρίκος.** Το «2 · κ! < (κ + 1) · κ!» θέλει **2 < κ + 1**: γράψ' το.
> - **Ανάποδη φορά.** Από 2^κ < κ! **δεν** προκύπτει 2^{κ+1} < κάτι μικρότερο. Κάθε κρίκος πρέπει να πηγαίνει προς την ίδια κατεύθυνση (όλα <, ≤ ή όλα >, ≥).
> - **Πολλαπλασιασμός με αρνητικό.** Αλλάζει τη φορά (Bernoulli: χρειάζεται 1 + x ≥ 0).
> - **Ένας νέος όρος στους αρμονικούς.** Από H(2^κ) σε H(2^{κ+1}) προστίθενται **2^κ** όροι.
> - **Ξεκινάς από το P(κ+1) και καταλήγεις σε αληθές.** Π.χ. «2^{κ+1} < (κ + 1)! ⇒ … ⇒ 2 < κ + 1 ✓» είναι λάθος κατεύθυνση, εκτός αν κάθε βήμα είναι ⇔.
> - **Η πρόταση είναι πολύ αδύναμη για επαγωγή** (Σ 1/i² < 2): ενίσχυσέ τη.
