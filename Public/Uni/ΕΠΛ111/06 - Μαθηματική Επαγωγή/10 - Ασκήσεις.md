# 10 - Ασκήσεις

23 ασκήσεις στο ύφος των διαφανειών, από τις εύκολες στις «παγίδες». **Λύσε πρώτα, άνοιξε μετά**: κάθε λύση είναι κρυμμένη σε αναδιπλούμενο πλαίσιο.

> [!tip] Πώς να το χρησιμοποιήσεις
> Κάνε πρώτα ένα πλήρες πέρασμα χωρίς να ανοίξεις καμία λύση. Γράφε **ολόκληρη** την απόδειξη (βάση, υπόθεση, στόχος, βήμα, συμπέρασμα): στο τεστ βαθμολογείται η δομή. Οι ασκήσεις με 🔴 είναι «παγίδες». Αν δεν ξέρεις από πού να ξεκινήσεις, δες τον [[11 - Οδηγός Ασκήσεων|Οδηγό Ασκήσεων]].

## Μέρος Α — Ισότητες και διαιρετότητα

### Άσκηση 1

Δείξτε ότι για κάθε ν > 0, 2 + 4 + 6 + ⋯ + 2ν = ν(ν + 1).

> [!success]- Λύση
> P(ν): 2 + 4 + ⋯ + 2ν = ν(ν + 1).
> 1. **Βασικό Βήμα:** P(1): 2 = 1 · 2. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε ότι P(κ) είναι αληθής για αυθαίρετο κ > 0, δηλαδή 2 + 4 + ⋯ + 2κ = κ(κ + 1). Θα δείξουμε P(κ+1): 2 + 4 + ⋯ + 2κ + 2(κ + 1) = (κ + 1)(κ + 2).
>    2 + 4 + ⋯ + 2κ + 2(κ + 1) = **κ(κ + 1)** + 2(κ + 1) = (κ + 1)(κ + 2).
>
> Αφού P(1) και ∀x (P(x) → P(x+1)) είναι αληθείς, ∀y P(y) είναι αληθής. ∎
>
> (Εναλλακτικά: 2 + 4 + ⋯ + 2ν = 2(1 + ⋯ + ν) = ν(ν + 1) από τη διαφάνεια 9. Αλλά αν η άσκηση ζητά επαγωγή, γράφεις επαγωγή.)

### Άσκηση 2

Δείξτε ότι για κάθε ν ≥ 1, 1 · 2 + 2 · 3 + ⋯ + ν(ν + 1) = ν(ν + 1)(ν + 2)/3.

> [!success]- Λύση
> 1. **Βασικό Βήμα:** ν = 1: 1 · 2 = 2 και 1 · 2 · 3/3 = 2. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε $\sum_{i=1}^{\kappa} i(i+1) = \kappa(\kappa+1)(\kappa+2)/3$. Στόχος: (κ + 1)(κ + 2)(κ + 3)/3. Ο νέος όρος είναι (κ + 1)(κ + 2).
>    $$\sum_{i=1}^{\kappa+1} i(i+1) = \frac{\kappa(\kappa+1)(\kappa+2)}{3} + (\kappa+1)(\kappa+2) = \frac{(\kappa+1)(\kappa+2)(\kappa+3)}{3}. \;∎$$
>
> **Κοινός παράγοντας** (κ + 1)(κ + 2): κ/3 + 1 = (κ + 3)/3.

### Άσκηση 3 🔴

Δείξτε ότι για κάθε ν ≥ 0, 1 + 3 + 9 + ⋯ + 3^ν = (3^{ν+1} − 1)/2.

> [!success]- Λύση
> **Παγίδες:** η βάση είναι **ν = 0** (όχι 1), το άθροισμα έχει **ν + 1** όρους, και ο νέος όρος από κ σε κ + 1 είναι **3^{κ+1}**.
> 1. **Βασικό Βήμα:** ν = 0: το άθροισμα είναι μόνο το 3⁰ = 1, και (3¹ − 1)/2 = 1. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε 1 + 3 + ⋯ + 3^κ = (3^{κ+1} − 1)/2 για αυθαίρετο κ ≥ 0. Τότε
>    1 + 3 + ⋯ + 3^κ + 3^{κ+1} = **(3^{κ+1} − 1)/2** + 3^{κ+1} = (3^{κ+1} − 1 + 2 · 3^{κ+1})/2 = (3 · 3^{κ+1} − 1)/2 = (3^{κ+2} − 1)/2. ∎

### Άσκηση 4

Δείξτε ότι για κάθε ν ≥ 1,
$$\frac{1}{1\cdot 3} + \frac{1}{3 \cdot 5} + \dots + \frac{1}{(2\nu-1)(2\nu+1)} = \frac{\nu}{2\nu+1}.$$

> [!success]- Λύση
> 1. **Βασικό Βήμα:** ν = 1: 1/3 = 1/3. ✓
> 2. **Επαγωγικό Βήμα:** Ο νέος όρος για ν = κ + 1 είναι 1/((2κ + 1)(2κ + 3)). Από την υπόθεση:
>    $$\frac{\kappa}{2\kappa+1} + \frac{1}{(2\kappa+1)(2\kappa+3)} = \frac{\kappa(2\kappa+3) + 1}{(2\kappa+1)(2\kappa+3)} = \frac{2\kappa^2+3\kappa+1}{(2\kappa+1)(2\kappa+3)} = \frac{(2\kappa+1)(\kappa+1)}{(2\kappa+1)(2\kappa+3)} = \frac{\kappa+1}{2\kappa+3}.$$
>    Και (κ + 1)/(2(κ + 1) + 1) = (κ + 1)/(2κ + 3). ∎

### Άσκηση 5

Δείξτε ότι για κάθε ν ≥ 1: (α) 3 | ν³ + 2ν, (β) 8 | 9^ν − 1.

> [!success]- Λύση
> **(α)** Βάση: 1 + 2 = 3. ✓ Βήμα: υποθέτουμε 3 | κ³ + 2κ.
> (κ + 1)³ + 2(κ + 1) = κ³ + 3κ² + 3κ + 1 + 2κ + 2 = **(κ³ + 2κ)** + 3(κ² + κ + 1).
> Ο πρώτος όρος διαιρείται με 3 από την υπόθεση, ο δεύτερος είναι πολλαπλάσιο του 3. ∎
>
> **(β)** Βάση: 9 − 1 = 8. ✓ Βήμα: υποθέτουμε 9^κ − 1 = 8m.
> 9^{κ+1} − 1 = 9 · 9^κ − 9 + 8 = 9(9^κ − 1) + 8 = 9 · 8m + 8 = 8(9m + 1). ∎

### Άσκηση 6 🔴

Ένας φοιτητής «αποδεικνύει» ότι 1 + 2 + ⋯ + ν = (ν² + ν + 1)/2 ως εξής: «Υποθέτουμε ότι ισχύει για κ. Τότε 1 + ⋯ + κ + (κ + 1) = (κ² + κ + 1)/2 + (κ + 1) = (κ² + 3κ + 3)/2 = ((κ + 1)² + (κ + 1) + 1)/2. Άρα ισχύει για κάθε ν.» Είναι σωστό;

> [!success]- Λύση
> **Όχι.** Το επαγωγικό βήμα είναι **σωστό** (έλεγξε: (κ + 1)² + (κ + 1) + 1 = κ² + 3κ + 3), αλλά **λείπει η βάση**, και η βάση είναι **ψευδής**: για ν = 1, 1 ≠ 3/2.
>
> Στην πραγματικότητα ο τύπος είναι ψευδής για **κάθε** ν (το σωστό είναι ν(ν + 1)/2, που διαφέρει κατά 1/2). Η συνεπαγωγή P(κ) → P(κ+1) είναι αληθής «κενά», γιατί το P(κ) δεν ισχύει ποτέ. Τα ντόμινο είναι στημένα, αλλά κανείς δεν σπρώχνει το πρώτο. ([[01 - Η Αρχή της Επαγωγής#7. Γιατί χρειάζονται και τα δύο βήματα|01 §7]])

## Μέρος Β — Ανισότητες

### Άσκηση 7

Δείξτε ότι για κάθε ν ≥ 1, ν < 2^ν.

> [!success]- Λύση
> 1. **Βασικό Βήμα:** 1 < 2. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε κ < 2^κ για αυθαίρετο κ ≥ 1. Τότε
>    κ + 1 < 2^κ + 1 ≤ 2^κ + 2^κ = 2^{κ+1},
>    όπου ο πρώτος κρίκος είναι η **υπόθεση** και ο δεύτερος ισχύει αφού 1 ≤ 2^κ. ∎

### Άσκηση 8 🔴

Για ποια ν ≥ 1 ισχύει 3^ν < ν!; Αποδείξτε την απάντησή σας.

> [!success]- Λύση
> | ν | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
> |---|---|---|---|---|---|---|---|
> | 3^ν | 3 | 9 | 27 | 81 | 243 | 729 | 2187 |
> | ν! | 1 | 2 | 6 | 24 | 120 | 720 | 5040 |
>
> Ισχύει για **ν ≥ 7** (για ν = 6 «παραλίγο»: 729 > 720).
> 1. **Βασικό Βήμα:** P(7): 2187 < 5040. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε 3^κ < κ! για αυθαίρετο κ ≥ 7. Τότε 3^{κ+1} = 3 · 3^κ < 3 · κ! < (κ + 1) · κ! = (κ + 1)!, αφού 3 < κ + 1. ∎
>
> **Παγίδα:** το βήμα ισχύει ήδη για κ ≥ 3, αλλά αυτό **δεν** σημαίνει ότι η πρόταση ισχύει για ν ≥ 3. Η βάση καθορίζει από πού ξεκινά.

### Άσκηση 9

Δείξτε ότι για κάθε ν ≥ 3, 2ν + 1 < 2^ν.

> [!success]- Λύση
> 1. **Βασικό Βήμα:** ν = 3: 7 < 8. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε 2κ + 1 < 2^κ για αυθαίρετο κ ≥ 3. Τότε
>    2(κ + 1) + 1 = (2κ + 1) + 2 < 2^κ + 2 ≤ 2^κ + 2^κ = 2^{κ+1},
>    αφού 2 ≤ 2^κ (κ ≥ 1). ∎
>
> (Για ν = 1, 2 η πρόταση είναι ψευδής: 3 > 2, 5 > 4.)

### Άσκηση 10

Δείξτε ότι για κάθε ν ≥ 1,
$$1 + \frac{1}{\sqrt 2} + \frac{1}{\sqrt 3} + \dots + \frac{1}{\sqrt \nu} \ge \sqrt \nu.$$

> [!success]- Λύση
> 1. **Βασικό Βήμα:** ν = 1: 1 ≥ 1. ✓
> 2. **Επαγωγικό Βήμα:** Υποθέτουμε S(κ) ≥ √κ. Τότε S(κ + 1) = S(κ) + 1/√(κ + 1) ≥ √κ + 1/√(κ + 1). Αρκεί να δείξουμε
>    √κ + 1/√(κ + 1) ≥ √(κ + 1).
>    Πολλαπλασιάζουμε με √(κ + 1) > 0: √(κ(κ + 1)) + 1 ≥ κ + 1 ⇔ √(κ(κ + 1)) ≥ κ ⇔ κ(κ + 1) ≥ κ² ⇔ κ ≥ 0. ✓
>
> Κάθε βήμα της τελευταίας γραμμής είναι **⇔** (όλες οι ποσότητες είναι θετικές), άρα το να «δουλέψουμε από τον στόχο» είναι εδώ έγκυρο. ∎

## Μέρος Γ — Ισχυρή επαγωγή και «πού είναι το λάθος»

### Άσκηση 11 🔴

Αληθές ή ψευδές;
(α) Αν P(1), P(2), …, P(1000) είναι αληθή, τότε ∀ν P(ν).
(β) Αν P(5) αληθές και P(κ) → P(κ+1) για κάθε κ ≥ 1, τότε P(ν) αληθές για κάθε ν ≥ 5.
(γ) Αν P(κ) → P(κ+1) για κάθε κ ≥ 1 και P(1) ψευδές, τότε P(ν) ψευδές για κάθε ν.
(δ) Η ισχυρή επαγωγή αποδεικνύει προτάσεις που η απλή δεν μπορεί.
(ε) Στο επαγωγικό βήμα υποθέτουμε ότι P(κ) είναι αληθές για κάθε κ.

> [!success]- Λύση
> | | | Γιατί |
> |---|---|---|
> | (α) | ✗ | πεπερασμένα παραδείγματα δεν αρκούν (ν² − ν + 41: αληθές ως το 40) |
> | (β) | ✓ | βάση P(5) + βήμα για κ ≥ 5 (που καλύπτεται από το «κ ≥ 1»). Για ν < 5 **δεν** ξέρουμε τίποτα |
> | (γ) | ✗ | P(ν): «ν ≥ 2». P(1) ψευδές, P(κ) → P(κ+1) ισχύει για κάθε κ (για κ = 1 κενά), αλλά P(2), P(3), … αληθή |
> | (δ) | ✗ | οι δύο αρχές είναι **ισοδύναμες** (διαφάνεια 20). Η ισχυρή απλώς διευκολύνει |
> | (ε) | ✗ | για **ένα αυθαίρετο** κ. «Για κάθε κ» είναι αυτό που θέλουμε να αποδείξουμε (κυκλικό) |

### Άσκηση 12

Δείξτε ότι κάθε ποσό ν ≥ 8 λεπτών μπορεί να πληρωθεί με γραμματόσημα των 3 και των 5 λεπτών.

> [!success]- Λύση
> **Ισχυρή επαγωγή.** Το βήμα θα χρησιμοποιήσει το P(κ − 2) (αφαιρούμε ένα 3άρι από το κ + 1), άρα χρειάζονται **τρεις** βάσεις.
> 1. **Βασικά Βήματα:** 8 = 3 + 5, 9 = 3 + 3 + 3, 10 = 5 + 5. ✓
> 2. **Επαγωγικό Βήμα:** για αυθαίρετο κ ≥ 10, υποθέτουμε P(8) ∧ ⋯ ∧ P(κ). Αφού κ + 1 − 3 = κ − 2 ≥ 8, το κ − 2 πληρώνεται από την υπόθεση· προσθέτουμε ένα 3άρι. ∎
>
> (Το 7 **δεν** πληρώνεται: 7 − 3 = 4, 7 − 5 = 2, κανένα δεν είναι συνδυασμός. Γι' αυτό η πρόταση ξεκινά από το 8.)

### Άσκηση 13

Έστω a₁ = 1, a₂ = 2 και aᵥ = a_{ν−1} + 2a_{ν−2} για ν ≥ 3. Δείξτε ότι aᵥ = 2^{ν−1} για κάθε ν ≥ 1.

> [!success]- Λύση
> **Ισχυρή επαγωγή με δύο βάσεις** (ο κανόνας κοιτάζει δύο θέσεις πίσω).
> 1. **Βασικά Βήματα:** a₁ = 1 = 2⁰, a₂ = 2 = 2¹. ✓
> 2. **Επαγωγικό Βήμα:** για αυθαίρετο κ ≥ 2, υποθέτουμε aᵢ = 2^{i−1} για 1 ≤ i ≤ κ. Τότε
>    a_{κ+1} = a_κ + 2a_{κ−1} = 2^{κ−1} + 2 · 2^{κ−2} = 2^{κ−1} + 2^{κ−1} = 2^κ. ∎
>
> Το κ ≥ 2 εξασφαλίζει ότι κ − 1 ≥ 1, ώστε η υπόθεση να καλύπτει το a_{κ−1}.

### Άσκηση 14 🔴

Βρείτε το λάθος: «**Θεώρημα:** για κάθε ν ≥ 0, 5ν = 0. **Απόδειξη (ισχυρή επαγωγή):** Βάση: 5 · 0 = 0. Βήμα: υποθέτουμε 5j = 0 για κάθε 0 ≤ j ≤ κ. Γράφουμε κ + 1 = α + β με 0 ≤ α, β ≤ κ. Από την υπόθεση 5α = 0 και 5β = 0, άρα 5(κ + 1) = 5α + 5β = 0. ∎»

> [!success]- Λύση
> Το βήμα **δεν ισχύει για κ = 0**: τότε κ + 1 = 1, και δεν υπάρχουν α, β με 0 ≤ α, β ≤ 0 και α + β = 1. Η μόνη γραφή είναι 1 = 0 + 1 ή 1 + 0, όπου το 1 > κ. Άρα η υπόθεση δεν καλύπτει το 1, το P(0) → P(1) δεν αποδείχτηκε, και η αλυσίδα σπάει στον πρώτο κρίκο (όπως με τα άλογα).
>
> Για κ ≥ 1 το βήμα είναι πράγματι σωστό, αλλά αυτό δεν βοηθά, αφού το P(1) είναι ψευδές.

### Άσκηση 15 🔴

Βρείτε το λάθος: «**Θεώρημα:** για κάθε ν ≥ 1, 2^ν ≥ ν². **Απόδειξη:** Βάση: 2 ≥ 1. Βήμα: υποθέτουμε 2^κ ≥ κ². Τότε 2^{κ+1} = 2 · 2^κ ≥ 2κ² ≥ (κ + 1)². ∎»

> [!success]- Λύση
> Ο κρίκος **2κ² ≥ (κ + 1)²** ισχύει μόνο για κ ≥ 3 (ισοδύναμο με (κ − 1)² ≥ 2). Για κ = 1: 2 ≥ 4 ✗· για κ = 2: 8 ≥ 9 ✗. Το βήμα δεν αποδείχτηκε για κ = 1, 2.
>
> Και πράγματι το θεώρημα είναι **ψευδές**: 2³ = 8 < 9 = 3². Το σωστό: 2^ν ≥ ν² για ν = 1, 2 και για **ν ≥ 4** (βάση P(4): 16 ≥ 16, βήμα για κ ≥ 4 ≥ 3). ([[03 - Ανισότητες#1. Δυνάμεις του 2 και παραγοντικά|03 §1]])

## Μέρος Δ — Αναδρομή και επαγωγή στη δομή

### Άσκηση 16

Έστω f(0) = 2 και f(ν) = f(ν − 1)² για ν > 0. Υπολογίστε f(1), …, f(4), μαντέψτε κλειστό τύπο και αποδείξτε τον.

> [!success]- Λύση
> f(1) = 4, f(2) = 16, f(3) = 256, f(4) = 65 536. Δηλαδή 2¹, 2², 2⁴, 2⁸, 2¹⁶: **f(ν) = 2^{2^ν}**.
> 1. **Βασικό Βήμα:** f(0) = 2 = 2^{2⁰} = 2¹. ✓
> 2. **Επαγωγικό Βήμα:** αν f(κ) = 2^{2^κ}, τότε f(κ + 1) = f(κ)² = (2^{2^κ})² = 2^{2 · 2^κ} = 2^{2^{κ+1}}. ∎
>
> Πρώτα ο **κανόνας** (f(κ + 1) = f(κ)²), μετά η **υπόθεση**.

### Άσκηση 17 🔴

Ποιοι από τους παρακάτω ορίζουν σωστά συνάρτηση f : N → N;
(α) f(0) = 1, f(ν) = f(ν − 1) − 2 για ν > 0
(β) f(0) = 0, f(1) = 1, f(ν) = 2f(ν − 2) για ν ≥ 2
(γ) f(0) = 1, f(ν) = f(ν − 2) + 1 για ν ≥ 1
(δ) f(0) = 1, f(ν) = f(⌈ν/2⌉) για ν ≥ 1
(ε) f(0) = 0, f(ν) = 1 + f(⌊ν/2⌋) για ν ≥ 1

> [!success]- Λύση
> | | | Γιατί |
> |---|---|---|
> | (α) | ✗ | f(1) = −1 ∉ N (εκτός πεδίου τιμών) |
> | (β) | ✓ | δύο βάσεις για άρτιους/περιττούς: 0, 1, 0, 2, 0, 4, 0, 8, … |
> | (γ) | ✗ | f(1) = f(−1) + 1: λείπει βάση για τους περιττούς |
> | (δ) | ✗ | f(1) = f(⌈1/2⌉) = **f(1)**: κυκλικό (το ⌈1/2⌉ = 1 δεν είναι μικρότερο από 1). Δεν ορίζεται μοναδική τιμή |
> | (ε) | ✓ | ⌊ν/2⌋ < ν για ν ≥ 1. f(ν) = ο αριθμός των δυαδικών ψηφίων του ν: 0, 1, 2, 2, 3, 3, 3, 3, 4, … |
>
> Η (δ) είναι η πιο ύπουλη: το ⌈ν/2⌉ είναι μικρότερο από ν για ν ≥ 2, **αλλά όχι** για ν = 1.

### Άσκηση 18

Δώστε αναδρομικό ορισμό για: (α) την ακολουθία aᵥ = 5ν + 1, ν ≥ 0· (β) το σύνολο των θετικών περιττών· (γ) το σύνολο των συμβολοσειρών άρτιου μήκους πάνω στο Σ = {0, 1}· (δ) τα παλίνδρομα πάνω στο {a, b}.

> [!success]- Λύση
> (α) a₀ = 1, aᵥ = a_{ν−1} + 5 για ν > 0.
> (β) **Βάση:** 1 ∈ S. **Κανόνας:** x ∈ S ⇒ x + 2 ∈ S.
> (γ) **Βάση:** ε ∈ E. **Κανόνας:** x ∈ E και y, z ∈ Σ ⇒ x · y · z ∈ E. (Δύο σύμβολα κάθε φορά. Μην ξεχάσεις το ε: έχει μήκος 0, άρτιο.)
> (δ) **Βάση:** ε, a, b ∈ Pal. **Κανόνας:** x ∈ Pal ⇒ a · x · a ∈ Pal και b · x · b ∈ Pal. (Χωρίς τα a, b στη βάση, θα έπαιρνες μόνο τα παλίνδρομα **άρτιου** μήκους.)
>
> Σε όλα εννοείται ο κανόνας αποκλεισμού.

### Άσκηση 19 🔴

Με τον ορισμό της διαφάνειας 32, ποιοι είναι καλά ορισμένοι τύποι;
(α) ((P ∧ Q) → R) (β) (¬P ∧ Q) (γ) ((¬P) ∧ Q) (δ) (P) (ε) (¬(¬(¬T))) (στ) (P ∨ Q ∨ R)

> [!success]- Λύση
> | | | Γιατί |
> |---|---|---|
> | (α) | ✓ | (P ∧ Q), μετά → με το R |
> | (β) | ✗ | το ¬P χωρίς παρενθέσεις δεν παράγεται· σωστό: ((¬P) ∧ Q) |
> | (γ) | ✓ | |
> | (δ) | ✗ | κανένας κανόνας δεν βάζει παρενθέσεις γύρω από μεταβλητή |
> | (ε) | ✓ | T → (¬T) → (¬(¬T)) → (¬(¬(¬T))) |
> | (στ) | ✗ | δύο δυαδικοί τελεστές σε ένα ζευγάρι παρενθέσεων· σωστό: ((P ∨ Q) ∨ R) ή (P ∨ (Q ∨ R)) |
>
> Έλεγχος: σε κάθε καλά ορισμένο τύπο, ο αριθμός ζευγαριών παρενθέσεων = ο αριθμός τελεστών (κάθε κανόνας προσθέτει ένα από το καθένα). Το (δ) έχει 1 ζευγάρι, 0 τελεστές ✗· το (στ) 1 ζευγάρι, 2 τελεστές ✗· το (β) 1 ζευγάρι, 2 τελεστές ✗.

### Άσκηση 20

Ορίζουμε τα φύλλα ενός γεμάτου δυαδικού δέντρου αναδρομικά: L(•) = 1, L(T₁ · T₂) = L(T₁) + L(T₂). Δείξτε με επαγωγή στη δομή ότι L(T) = (N(T) + 1)/2.

> [!success]- Λύση
> 1. **Βασικό Βήμα:** T ένας κόμβος: L(T) = 1 = (1 + 1)/2. ✓
> 2. **Επαγωγικό Βήμα:** T = T₁ · T₂, με L(T₁) = (N(T₁) + 1)/2 και L(T₂) = (N(T₂) + 1)/2 από την επαγωγική υπόθεση. Τότε
>    L(T) = L(T₁) + L(T₂) = (N(T₁) + N(T₂) + 2)/2 = ((1 + N(T₁) + N(T₂)) + 1)/2 = (N(T) + 1)/2. ∎
>
> Συνέπεια: N(T) = 2L(T) − 1 είναι **περιττός**.

### Άσκηση 21 🔴

Έστω S ⊆ Z × Z με: (0, 0) ∈ S· αν (a, b) ∈ S, τότε (a + 2, b + 3) ∈ S και (a + 3, b + 2) ∈ S. (α) Δείξτε ότι 5 | a + b για κάθε (a, b) ∈ S. (β) Ισχύει το αντίστροφο, δηλαδή κάθε (a, b) με 5 | a + b ανήκει στο S;

> [!success]- Λύση
> **(α) Επαγωγή στη δομή.**
> - **Βάση:** (0, 0): 0 + 0 = 0 = 5 · 0. ✓
> - **Βήμα:** υποθέτουμε 5 | a + b. Κανόνας 1: (a + 2) + (b + 3) = (a + b) + 5. Κανόνας 2: (a + 3) + (b + 2) = (a + b) + 5. Και στους δύο, το άθροισμα διαιρείται με 5. ∎ (**Δύο** κανόνες, **δύο** περιπτώσεις.)
>
> **(β) Όχι.** Π.χ. (1, 4): 1 + 4 = 5, αλλά κάθε στοιχείο του S εκτός του (0, 0) έχει a ≥ 2 (κάθε κανόνας προσθέτει τουλάχιστον 2 στο a). Ούτε το (5, 0) ή το (−5, 10) ανήκουν. Η επαγωγή στη δομή δίνει ιδιότητες **όλων** των στοιχείων, όχι χαρακτηρισμό του συνόλου.

### Άσκηση 22 🔴

Ένας φοιτητής ισχυρίζεται ότι για κάθε γεμάτο δυαδικό δέντρο, N(T) ≤ 2H(T) + 1, και γράφει: «Βάση: 1 ≤ 1. Βήμα: N(T) = 1 + N(T₁) + N(T₂) ≤ 1 + (2H(T₁) + 1) + (2H(T₂) + 1) = 2(H(T₁) + H(T₂)) + 3 ≤ 2H(T) + 1.» Πού είναι το λάθος;

> [!success]- Λύση
> Ο τελευταίος κρίκος. 2H(T) + 1 = 2(max{H₁, H₂} + 1) + 1 = 2 max{H₁, H₂} + 3, άρα χρειάζεται H₁ + H₂ ≤ max{H₁, H₂}, που ισχύει **μόνο** αν το ένα ύψος είναι 0.
>
> Το θεώρημα είναι **ψευδές**: το τέλειο δέντρο ύψους 2 έχει N = 7 > 5. Το σωστό είναι το **αντίθετο** (N(T) ≥ 2H(T) + 1, διαφάνεια 39), και η ισότητα ισχύει μόνο για τις «κάμπιες». ([[08 - Επαγωγή στη Δομή#3. Κόμβοι και ύψος γεμάτων δυαδικών δέντρων|08 §3]])

### Άσκηση 23

Στην απόδειξη της πλακόστρωσης (διαφάνειες 17–19), έστω K(ν) ο αριθμός κομματιών Γ για τη σκακιέρα 2^ν × 2^ν. (α) Γράψτε αναδρομικό ορισμό του K από την απόδειξη. (β) Δείξτε ότι K(ν) = (4^ν − 1)/3. (γ) Πόσα κομμάτια χρειάζεται μια σκακιέρα 8 × 8;

> [!success]- Λύση
> (α) K(1) = 1 (η 2 × 2 είναι ένα Γ). K(ν) = 4K(ν − 1) + 1 για ν > 1 (τέσσερις υποσκακιέρες + το κεντρικό Γ).
>
> (β) **Βάση:** K(1) = 1 = (4 − 1)/3. ✓ **Βήμα:** K(κ + 1) = 4 · **(4^κ − 1)/3** + 1 = (4^{κ+1} − 4 + 3)/3 = (4^{κ+1} − 1)/3. ∎
>
> (γ) 8 = 2³: K(3) = (64 − 1)/3 = **21**. Έλεγχος: 21 · 3 = 63 = 64 − 1 τετράγωνα. ✓
