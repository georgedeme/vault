# 09 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι. Για την τελευταία ώρα πριν το τεστ.

## 1. Οι τρεις μορφές επαγωγής

| | Βασικό Βήμα | Επαγωγικό Βήμα | Πότε |
|---|---|---|---|
| **Απλή** | P(ν₀) | P(κ) → P(κ+1), αυθαίρετο κ ≥ ν₀ | το κ + 1 «χτίζεται» από το κ |
| **Ισχυρή** | P(ν₀) (ή περισσότερες) | P(ν₀) ∧ ⋯ ∧ P(κ) → P(κ+1) | το κ + 1 σπάει σε μικρότερα κομμάτια (α · β, κ − 1, κ − 3) |
| **Στη δομή** | P(α) για **κάθε** βασικό στοιχείο | P για **κάθε** κανόνα, υποθέτοντας P για τα συστατικά | αναδρομικά σύνολα (τύποι, δέντρα, Σ*) |

**Κανόνας συμπερασμού:** (P(1) ∧ ∀x (P(x) → P(x+1))) → ∀y P(y), στο Z⁺. **Γιατί ισχύει:** το Z⁺ είναι **καλά διατεταγμένο** (κάθε μη κενό υποσύνολο έχει ελάχιστο) ⇒ το ελάχιστο αντιπαράδειγμα β ≠ 1 έχει P(β − 1) αληθές ⇒ P(β) αληθές, αντίφαση. Ισοδύναμα: διαδοχικά **Modus Ponens**. Απλή ⇔ ισχυρή.

## 2. Το καλούπι

> **Βασικό Βήμα:** P(ν₀) είναι αληθής αφού ‹υπολογισμός›.
> **Επαγωγικό Βήμα:** Υποθέτουμε ότι P(κ) είναι αληθής για αυθαίρετο κ ≥ ν₀, δηλαδή ‹P(κ) ρητά›. Θα δείξουμε P(κ+1): ‹P(κ+1) ρητά›. ‹αριστερό μέλος του P(κ+1)› = … **(επαγωγική υπόθεση)** … = ‹δεξί μέλος›.
> Αφού P(ν₀) και ∀x (P(x) → P(x+1)) είναι αληθείς, τότε ∀y P(y) είναι αληθής. ∎

## 3. Τεχνικές για το επαγωγικό βήμα

| Είδος | «Σπάσε» το P(κ+1) σε… |
|---|---|
| Άθροισμα | Σ_{i=1}^{κ+1} = Σ_{i=1}^{κ} + (όρος κ + 1). **Νέος όρος:** βάλε ν = κ + 1 στον γενικό (περιττοί: 2κ + 1) |
| Άθροισμα με δύο κινητά άκρα | γράψε S(κ+1) ολόκληρο: τι φεύγει, τι μπαίνει |
| Διαιρετότητα | πρόσθεσε/αφαίρεσε: 7^{κ+1} − 1 = 7(7^κ − 1) + 6 |
| Ανισότητα | αλυσίδα με < / ≤, κάθε κρίκος δικαιολογημένος (2 · κ! < (κ + 1) · κ! αφού κ ≥ 2) |
| Σύνολο με κ + 1 στοιχεία | αυθαίρετο A, αυθαίρετο α ∈ A, B = A ∖ {α} |
| Σκακιέρα 2^{κ+1} | 4 υποσκακιέρες 2^κ + ένα Γ στο κέντρο |
| Αναδρομική συνάρτηση | **πρώτα** ο κανόνας (f(κ+1) = …), **μετά** η υπόθεση |
| Δέντρο / τύπος | T = T₁ · T₂ / (¬P), (P ∘ Q): υπόθεση για τα συστατικά |
| «Κολλάει» | **ενίσχυσε** την πρόταση (Σ 1/i² ≤ 2 − 1/ν, «οποιοδήποτε τετράγωνο λείπει») |

## 4. Αποτελέσματα των διαφανειών

| Θεώρημα | Βάση | Μορφή |
|---|---|---|
| 1 + 3 + ⋯ + (2ν − 1) = ν² | ν = 1 | απλή |
| Σ i = ν(ν + 1)/2 · Σ i² = ν(ν + 1)(2ν + 1)/6 · Σ i³ = ν²(ν + 1)²/4 | ν = 1 | απλή (μόνο η 1η αποδεικνύεται) |
| 2^ν < ν! | ν = **4** | απλή |
| H(2^ν) ≥ 1 + ν/2, H(κ) = 1 + 1/2 + ⋯ + 1/κ | ν = **0** | απλή· 2^κ νέοι όροι, καθένας ≥ 1/2^{κ+1} |
| \|A\| = ν ⇒ \|**P**(A)\| = 2^ν | ν = **0** | απλή· **P**(A) = **P**(B) ∪ Γ, ξένα, \|Γ\| = \|**P**(B)\| |
| A αριθμήσιμο ⇒ A^ν αριθμήσιμο | ν = 1 | απλή· A^{κ+1} ↔ A^κ × A, πίνακας |
| 2^ν × 2^ν − 1 τετράγωνο καλύπτεται με Γ | ν = 1 | απλή· 4 κομμάτια + Γ στο κέντρο |
| ν > 1 γινόμενο πρώτων | ν = **2** | **ισχυρή**· κ + 1 = α · β, 2 ≤ α ≤ β < κ + 1 |
| Fibonacci f(ν) > α^{ν−2}, α = (1 + √5)/2 | ν = **3, 4** | **ισχυρή**· α² = α + 1 |
| (παρενθέσεις αριστερές) = (δεξιές) | T, F, μεταβλητές | **στη δομή**· 5 κανόνες |
| 2H(T) + 1 ≤ N(T) ≤ 2^{H(T)+1} − 1 | ένας κόμβος | **στη δομή** |

## 5. Αναδρομικοί ορισμοί

**Συνάρτηση f : N → A:** βάση f(0) (ή f(0), …, f(κ)) + κανόνας για f(ν) από **μικρότερες** τιμές (για ν > κ).
- 2^ν: f(0) = 1, f(ν) = 2f(ν − 1) · ν!: f(0) = 1, f(ν) = ν · f(ν − 1) · f(0) = 3, f(ν) = 2f(ν − 1) + 3 → 3, 9, 21, 45, 93 (= 6 · 2^ν − 3)
- **Fibonacci:** f(0) = 0, f(1) = 1, f(ν) = f(ν − 1) + f(ν − 2) για ν > 1 → 0, 1, 1, 2, 3, 5, 8, 13, 21
- **Κακός ορισμός:** λείπει βάση (f(ν − 2) με μόνο f(0)), κοιτάζει μπροστά (f(ν + 1)), τιμή εκτός A.

**Σύνολο:** βάση + κανόνες + **κανόνας αποκλεισμού** (εννοείται πάντα).

| Σύνολο | Βάση | Κανόνας |
|---|---|---|
| {3, 6, 9, …} | 3 | α, β ∈ A ⇒ α + β |
| Σ* | ε | x ∈ Σ*, y ∈ Σ ⇒ x · y |
| τύποι | T, F, μεταβλητές | (¬P), (P ∧ Q), (P ∨ Q), (P → Q), (P ↔ Q) |
| γεμάτα δυαδικά δέντρα | ένας κόμβος | T₁ · T₂ (νέα ρίζα) |

**Δέντρα:** N(•) = 1, N(T₁ · T₂) = 1 + N(T₁) + N(T₂) · H(•) = **0**, H(T₁ · T₂) = 1 + max{H(T₁), H(T₂)}.

## 6. Οι 10 παγίδες

1. **Χωρίς βάση** «αποδεικνύεις» ψευδή (κ² + κ περιττός, 1 + ⋯ + ν = (ν + ½)²/2). **Χωρίς βήμα** επίσης (ν² − ν + 41 πρώτος ως το 40).
2. **Βάση = η μικρότερη τιμή της εκφώνησης** (ν ≥ 4 → P(4), ν ≥ 0 → P(0)).
3. **Το βήμα πρέπει να ισχύει για κάθε κ ≥ βάση**, και ιδίως το πρώτο (άλογα: P(1) → P(2) ψευδές).
4. **Επαγωγική υπόθεση για ΕΝΑ αυθαίρετο κ**, όχι «για κάθε ν».
5. **Μην ξεκινάς από το P(κ+1)** για να καταλήξεις σε αληθές· πήγαινε από το ένα μέλος στο άλλο.
6. **Νέος όρος:** 2κ + 1 (περιττοί)· 2^κ όροι (αρμονικοί)· δύο άκρα που κινούνται.
7. **Ισχυρή επαγωγή:** τόσες βάσεις όσο «πίσω» κοιτάζει το βήμα (Fibonacci: 2, γραμματόσημα 4/5: 4).
8. **Επαγωγή = κάθε πεπερασμένο ν**, όχι ν = ∞ (A^ν αριθμήσιμο, αλλά οι άπειρες ακολουθίες όχι).
9. **Τύποι:** (P), ¬P, P ∧ Q, (P → ¬R ∨ Q) **δεν** είναι καλά ορισμένοι.
10. **Δέντρα:** H(•) = 0· σπάσε στη ρίζα, μη σβήνεις φύλλα· κάλυψε **κάθε** κανόνα.
