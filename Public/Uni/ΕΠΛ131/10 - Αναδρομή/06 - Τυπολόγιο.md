# 06 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα X.

## 1. Σκελετός

```java
τύπος f(παράμετροι) {
   if (βασική περίπτωση) return άμεση απάντηση;      // τερματική
   return … f(μικρότερο πρόβλημα) …;                 // αναδρομική, ένα βήμα πιο κοντά
}
```

Έλεγχος: (1) υπάρχει βασική περίπτωση; (2) φτάνεται για **κάθε** έγκυρη είσοδο; (3) πώς συνδυάζεται το αποτέλεσμα;

| Είδος | Τελευταία ενέργεια | Παράδειγμα |
|---|---|---|
| **Στοίβας** | πράξη με το αποτέλεσμα (στην επιστροφή) | `return x * factorial(x-1);` |
| **Ουράς** | η κλήση (αποτέλεσμα αυτούσιο) · συσσωρευτής | `return factorial(x-1, res*x);` |
| **Διπλή** (δέντρο) | δύο κλήσεις | `return F(n-1) + F(n-2);` |
| **Έμμεση** | `f` → `g` → `f` | `isEven` ↔ `isOdd` |

- Ουράς: `public f(x)` → `private f(x, αρχική_τιμή_συσσωρευτή)` (overloading).
- Η Java **δεν** βελτιστοποιεί την αναδρομή ουράς: κάθε κλήση = νέο πλαίσιο → `StackOverflowError` σε μεγάλο βάθος.
- Εντολή **πριν** την κλήση → εκτελείται στην κάθοδο· **μετά** → στην επιστροφή, ανάποδα (`down(4)`: `4 3 2 1` · `up(4)`: `1 2 3 4`).

## 2. Τα παραδείγματα

| Πρόβλημα | Βασική | Αναδρομική | Κόστος |
|---|---|---|---|
| `gcd(p,q)` | `q == 0` → `p` | `gcd(q, p % q)` | λογαριθμικό (χειρότερο: διαδοχικοί Fibonacci) |
| `factorial(x)` | `x == 0 \|\| x == 1` → `1` | `x * factorial(x-1)` | `x` κλήσεις |
| `factorial(x,res)` | → `res` | `factorial(x-1, res*x)` · αρχή `res = 1` | `x` κλήσεις |
| `F(n)` | `0` → 0, `1` → 1 | `F(n-1) + F(n-2)` | **εκθετικό**: `2F(n+1)−1` κλήσεις, `F(1)` καλείται `F(n)` φορές |
| `fibTail(a,b,x)` | `x == 0` → `a` | `fibTail(b, a+b, x-1)` · αρχή `(0,1,x)` | γραμμικό |
| `fibIter` | – | `temp=a; a=b; b=b+temp; x--;` | γραμμικό |
| `Fib` με πίνακα | `F[0]=0; F[1]=1` | `F[i] = F[i-1] + F[i-2]` | γραμμικό · ✗ για `n = 0` |
| `reverse(s)` στοίβας | `length()==1` → `s` | `reverse(s.substring(1)) + s.substring(0,1)` | |
| `reverse(s,r)` ουράς | `length()==1` → `s+r` | `reverse(s.substring(1), s.substring(0,1)+r)` · αρχή `""` | |
| `compute_element(row,elem)` | `elem==1 \|\| elem==row` → 1 | `ce(row-1,elem) + ce(row-1,elem-1)` | εκθετικό (`2τ−1` κλήσεις) |
| + memo | `if (memo[row][elem]!=0) return …` | `return (memo[row][elem]=x+y);` | κάθε στοιχείο μία φορά |

## 3. Memoization / δυναμικός προγραμματισμός

- Πίνακας-**μεταβλητή κλάσης** (`private static int[][] memo`), δημιουργείται όταν είναι γνωστό το `N`: `new int[N+1][N+1]` (δείκτες από 1).
- `0` = «δεν υπολογίστηκε» (ασφαλές όταν καμία αποθηκευμένη τιμή δεν είναι 0).
- Αποθήκευσε **πριν** επιστρέψεις· έλεγξε τον πίνακα **πρώτο**.
- Εναλλακτικά «από κάτω προς τα πάνω»: πίνακας γεμίζει με βρόχο (X-17, ακανόνιστο τρίγωνο).

## 4. Όρια

| | `int` | `long` |
|---|---|---|
| Παραγοντικό | ως `12!` (`13!` → `1932053504`, λάθος θετικό) | ως `20!` |
| Fibonacci | ως `F(46)` | ως `F(92)` |
| Pascal | ως σειρά 34 | ως σειρά 67 |

| Είσοδος | Αποτέλεσμα |
|---|---|
| `factorial(-1)` (αναδρομικό) · `fibTail(-1)` · `fibStack(-1)` · `isEven(-2)` | `StackOverflowError` |
| `factorial(-3)` (επαναληπτικό) | `1` (σιωπηλά) |
| `fibIter(-1)` | ≈ 4,3·10⁹ επαναλήψεις, τιμή χωρίς νόημα |
| `Fib(0)` (πίνακας X-17) | `ArrayIndexOutOfBoundsException` |
| `gcd(4, -6)` | `-2` (πρόσημο του `%`) · `gcd(0,0)` → `0` |
| `reverse("")` | `""` (επαναληπτικό) · `null` (αναδρομικά X-27/28) |
| `compute_element(3,4)` | χωρίς memo `StackOverflowError` · με memo `ArrayIndexOutOfBoundsException` |

## 5. Παγίδες των διαφανειών

- X-17: 49 (όχι 50) προσθήκες · `Fib(0)` σκάει.
- X-27, X-28: `reverse("")` → `null`, ενώ η X-26 δίνει `""`.
- X-31: η πραγματική έξοδος είναι με `%10d` (στήλες πλάτους 10) και κενή πρώτη γραμμή.
- X-36: λείπει το `{` της `Pascal`· X-37 … X-52 λείπουν από το PDF.
