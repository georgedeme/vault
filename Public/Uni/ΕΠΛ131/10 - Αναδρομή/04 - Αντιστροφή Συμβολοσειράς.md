# 04 - Αντιστροφή Συμβολοσειράς

Το ίδιο πρόβλημα – `"Hello!"` → `"!olleH"` – με τρεις τρόπους: **επαναληπτικά**, με **αναδρομή ουράς** (συσσωρευτική παράμετρος) και με **αναδρομή στοίβας**. Ο ίδιος σκελετός με το παραγοντικό, αλλά με `String` (διαφάνειες X-25 … X-28).

| Είσοδος | Συνάρτηση | Έξοδος |
|---|---|---|
| `String` – `Hello!` | `reverse` | `String` – `!olleH` |

## 1. Επαναληπτικός ορισμός (X-26)

```java
// Αρχίζουμε με ένα επαναληπτικό ορισμό
public static String reverse (String s){
   String r = "";
   for (int i = 0; i < s.length(); i++)
      r = s.substring(i,i+1) + r;
   return r;
}
```

`reverse("Hello!")` – διαδοχικές τιμές της μεταβλητής `r`:

| `i` | `r` | Υπολογισμός |
|---|---|---|
| – | `""` | |
| 0 | `H` | `"H" + ""` |
| 1 | `eH` | `"e" + "H"` |
| 2 | `leH` | `"l" + "eH"` |
| 3 | `lleH` | `"l" + "leH"` |
| 4 | `olleH` | `"o" + "lleH"` |
| 5 | `!olleH` | `"!" + "olleH"` |

Κάθε χαρακτήρας μπαίνει **μπροστά** από ό,τι έχει μαζευτεί. (Το `s.substring(i,i+1)` είναι ο χαρακτήρας `i` ως `String`· ισοδύναμα `s.charAt(i) + r`.)

## 2. Αναδρομή ουράς (X-27)

```java
// Προχωρούμε με τον δεύτερο αναδρομικό ορισμό
public static String reverse (String s){
   if (s == null || s.length() == 0) return null;
   return reverse(s,"");
}

private static String reverse (String s, String r){
   if (s.length() == 1) return s+r;
   return reverse(s.substring(1,s.length()), s.substring(0,1)+r);
}
```

```
reverse("Hello!")
⇒ reverse("Hello!", "")
⇒ reverse("ello!", "H")
⇒ reverse("llo!", "eH")
⇒ reverse("lo!", "leH")
⇒ reverse("o!", "lleH")
⇒ reverse("!", "olleH")
⇒ "!olleH"
```

> [!important] Ίδιο σχήμα με το `factorial(x, res)`
> - **Function overloading**: η `public` εκδοχή ελέγχει την είσοδο και ξεκινά τον συσσωρευτή με `""`· η `private` κάνει τη δουλειά.
> - **Συσσωρευτική παράμετρος** `r`: ο πρώτος χαρακτήρας του `s` μεταφέρεται **μπροστά** στο `r` **πριν** την κλήση. Το `s` μικραίνει κατά έναν χαρακτήρα κάθε φορά.
> - «Ισοδύναμη» με επανάληψη: `s` και `r` είναι ακριβώς οι δύο «μεταβλητές» του βρόχου της X-26.
> - Βασική περίπτωση: `s.length() == 1` → `s + r` (ο τελευταίος χαρακτήρας μπαίνει μπροστά).

## 3. Αναδρομή στοίβας (X-28)

```java
// Συνεχίζουμε με τον πρώτο αναδρομικό ορισμό
public static String reverse (String s)
{
   if (s == null || s.length() == 0) return null;
   if (s.length() == 1) return s;
   return reverse(s.substring(1,s.length())) +
          s.substring(0,1);
}
```

```
reverse("Hello!")
⇒ reverse("ello!") + "H"
⇒ reverse("llo!") + "e" + "H"
⇒ reverse("lo!") + "l" + "e" + "H"
⇒ reverse("o!") + "l" + "l" + "e" + "H"
⇒ reverse("!") + "o" + "l" + "l" + "e" + "H"
⇒ "!" + "o" + "l" + "l" + "e" + "H"
⇒ "!olleH"
```

> [!important] Η ιδέα
> «Το αντίστροφο του `s` = το αντίστροφο του **υπόλοιπου** (χωρίς τον πρώτο χαρακτήρα), **ακολουθούμενο** από τον πρώτο χαρακτήρα.» Η συνένωση `… + s.substring(0,1)` μένει **σε εκκρεμότητα** σε κάθε πλαίσιο και εκτελείται στην **επιστροφή** – όπως ο πολλαπλασιασμός στο `x * factorial(x-1)`.

![[Αναδρομή - reverse Στοίβας και Ουράς.png|800]]

> [!tip] Πού είναι η «μνήμη» σε κάθε λύση
> | | Τι κρατά τους χαρακτήρες μέχρι να μπουν στη σωστή θέση |
> |---|---|
> | Επαναληπτική | η μεταβλητή `r` |
> | Ουράς | η παράμετρος `r` (μεγαλώνει στην κάθοδο) |
> | Στοίβας | τα **πλαίσια** της στοίβας: κάθε ένα θυμάται «τον δικό του» πρώτο χαρακτήρα – όπως ο `rev` της [[02 - Διαδραστική Είσοδος και Αναδρομή|Ενότητας VII]] θυμόταν «τον δικό του» αριθμό |

## 4. ➕ Οριακές περιπτώσεις και ασυνέπειες (ελέγχθηκαν)

> [!warning] ⚠️ Το κενό string
> | Κλήση | Επαναληπτική | Ουράς | Στοίβας |
> |---|---|---|---|
> | `reverse("Hello!")` | `!olleH` | `!olleH` | `!olleH` |
> | `reverse("a")` | `a` | `a` | `a` |
> | `reverse("")` | **`""`** | **`null`** | **`null`** |
> | `reverse(null)` | `NullPointerException` | `null` | `null` |
>
> Οι τρεις εκδοχές **δεν** είναι ισοδύναμες στις άκρες. Το αντίστροφο του κενού string είναι το κενό string – η επιστροφή `null` για `""` (X-27, X-28) είναι αμφιλεγόμενη επιλογή, που αναγκάζει τον καλούντα να ελέγχει για `null` (π.χ. `reverse("").length()` → `NullPointerException`).

> [!example]- Γιατί χρειάζεται ο έλεγχος `s.length() == 0`
> Χωρίς αυτόν, η εκδοχή στοίβας με είσοδο `""` θα έφτανε στο `s.substring(1, 0)` → `StringIndexOutOfBoundsException` (begin 1 > end 0). Ένας πιο απλός σχεδιασμός ενώνει τις δύο βασικές περιπτώσεις:
> ```java
> public static String reverse(String s){
>    if (s.length() <= 1) return s;                     // "" → "", "a" → "a"
>    return reverse(s.substring(1)) + s.charAt(0);
> }
> ```
> Το `s.substring(1)` είναι το ίδιο με `s.substring(1, s.length())`. Το `"Hello!".substring(6)` (στο τέλος) δίνει `""`, όχι σφάλμα.

> [!warning] Κόστος
> - Κάθε `substring` και κάθε `+` φτιάχνει **νέο** `String` ([[02 - Συμβολοσειρές ως Δείκτες και Σύγκριση|αμεταβλητότητα, VI – 02]]): για μήκος `n` αντιγράφονται συνολικά ≈ `n²/2` χαρακτήρες – και στις τρεις εκδοχές.
> - Οι αναδρομικές έχουν βάθος `n`: για string εκατοντάδων χιλιάδων χαρακτήρων → `StackOverflowError`.

> [!example]- ➕ Ίδιο μοτίβο: παλινδρομικό με αναδρομή (ελέγχθηκε)
> ```java
> static boolean pal(String s){
>    if (s.length() <= 1) return true;
>    return s.charAt(0) == s.charAt(s.length()-1)
>        && pal(s.substring(1, s.length()-1));
> }
> ```
> `pal("racecar")` → `true` · `pal("abca")` → `false`. Το `&&` κάνει short-circuit: αν τα άκρα διαφέρουν, δεν γίνεται αναδρομική κλήση. Επαναληπτική εκδοχή: [[03 - Standard Είσοδος και Επεξεργασία Αρχείων|VI – 03]].

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - `reverse(s.substring(1)) + s` (ολόκληρο το `s` αντί για τον πρώτο χαρακτήρα).
> - `s.substring(0,1) + reverse(s.substring(1))` → ξαναφτιάχνει το **ίδιο** string `"Hello!"` (ο πρώτος μένει πρώτος σε κάθε επίπεδο).
> - Στην εκδοχή ουράς: `r + s.substring(0,1)` αντί για `s.substring(0,1) + r` → ο συσσωρευτής χτίζεται με την **αρχική** σειρά και μόνο ο τελευταίος χαρακτήρας πάει μπροστά: `"!Hello"` (ελέγχθηκε).
> - Ξεχασμένη βασική περίπτωση για `""` → `StringIndexOutOfBoundsException`.
> - Πίστη ότι οι τρεις εκδοχές συμπεριφέρονται ίδια για `""` και `null`.
