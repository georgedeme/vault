# 07 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα VIII.

## 1. Σύνταξη

```java
public static <τύπος|void> όνομα(τύπος p1, …, τύπος pn) { … return τιμή; }
```

| Κομμάτι | Κανόνας |
|---|---|
| `public` / `private` | `private` = μόνο από την ίδια κλάση (βοηθητικές) |
| τύπος επιστροφής | **υποχρεωτικός** (`void` αν δεν επιστρέφει) |
| παράμετροι | κάθε μία με **δικό της** τύπο · `()` αν καμία |
| signature | **όνομα + τύποι παραμέτρων** (όχι τύπος επιστροφής, όχι ονόματα) |
| κλήση | `Κλάση.όνομα(ορίσματα)` · ίδια κλάση: `όνομα(ορίσματα)` |
| σειρά μεθόδων | αδιάφορη · μέθοδος μέσα σε μέθοδο ✗ |

## 2. Είσοδοι / έξοδοι

| Είδος | Παράδειγμα |
|---|---|
| είσοδοι + έξοδος | `int negative(int[] table)` |
| μόνο είσοδοι (διευθύνσεις → έμμεσες έξοδοι) | `void sort(int[] table)` · `void initializeTable(double[] t, int v)` |
| μόνο έξοδος | `double[] create()` |
| τίποτα | `void displayMenu()` |

## 3. return

| Κώδικας | |
|---|---|
| `if (c) return 1;` (χωρίς `else`) σε `int` | ✗ `missing return statement` |
| `if … return; else if … return;` | ✗ ίδιο (ο μεταγλωττιστής δεν αποτιμά συνθήκες) |
| εντολή μετά από `return` | ✗ `unreachable statement` |
| `return x;` σε `void` · `return;` σε `int` | ✗ |
| `return;` σε `void` | ✓ πρόωρος τερματισμός |
| χρήση τιμής `void` (`x = d();`, `println(d())`) | ✗ |
| `min2(1,2);` standalone | ✓ αλλά παράλογο (εκτός αν υπάρχει παρενέργεια, π.χ. `swap`) |

## 4. Κλήση και binding

1. έλεγχος → συνάρτηση · 2. **αντιγραφή** ορισμάτων σε παραμέτρους (σειρά, ένα-προς-ένα) · 3. εκτέλεση · 4. τιμή στη θέση της κλήσης · 5. επιστροφή. = **πέρασμα δια τιμής**.

| Αντιστοιχία | |
|---|---|
| πλήθος | ίδιο |
| σειρά | 1ο όρισμα → 1η παράμετρος, … (τα ονόματα **δεν** παίζουν ρόλο) |
| τύπος | διεύρυνση ✓ (`byte→short→int→long→float→double`, `char→int`) · στένωση ✗ χωρίς cast · `int[]` → `double[]` ✗ |
| αποτίμηση | ορίσματα **αριστερά → δεξιά**, εσωτερικές κλήσεις πρώτα |

| Μέσα στη μέθοδο | Ο καλών το βλέπει; |
|---|---|
| `a = 5;` (παράμετρος `int`) | όχι |
| `t[0] = 5;` (παράμετρος πίνακας) | **ναι** |
| `t = new int[3];` | όχι (μόνο το τοπικό αντίγραφο της διεύθυνσης) |
| `return t;` + `x = f(x);` | ναι |

## 5. Εμβέλεια

- Μεταβλητή: από τη δήλωση έως το τέλος του **μπλοκ** της. Παράμετρος: όλο το σώμα.
- Ό,τι δεν περνά ως παράμετρος **δεν υπάρχει** μέσα στη συνάρτηση (εκτός από `static` μεταβλητές κλάσης).
- Ίδιο όνομα σε **φωλιασμένο** μπλοκ ✗ · σε **διαδοχικά** μπλοκ ✓ · σε άλλη μέθοδο ✓.
- Καλή πρακτική: δήλωση στο μικρότερο δυνατό μπλοκ.

## 6. Υπερφόρτωση

- Ίδιο όνομα, **διαφορετικό** πλήθος/τύπους/σειρά παραμέτρων. Μόνο διαφορετικός τύπος επιστροφής ✗.
- Επιλογή στη **μεταγλώττιση**: σωστό πλήθος → ακριβές ταίριασμα → λιγότερη διεύρυνση → αλλιώς `ambiguous`.
- `f(int)`+`f(double)`: `f('A')`→int · `f(3L)`→double · `f(3.0f)`→double.
- `Math.min` (`int`, `long`, `float`, `double`): `Math.min(5, 2.5f)` → `2.5f` · `Math.min(5/2, 2.4)` → `2.0`.

## 7. Μοτίβα

| Σκοπός | Πυρήνας |
|---|---|
| Τυχαίος στο `[a,b]` | `a + (int)(Math.random() * (b-a+1))` (υποθέτει `a ≤ b`) |
| Ελάχιστο πίνακα | `res = Double.POSITIVE_INFINITY; for (double n : t) if (n < res) res = n;` (κενός → `Infinity`) |
| Μέγιστο | `M = Double.NEGATIVE_INFINITY; … if (M < ys[i]) M = ys[i];` |
| min τριών | `min2(a, min2(b, c))` |
| Ταξινομημένος; | `for (i = 0; i < n-1; i++) if (t[i] > t[i+1]) return false; return true;` |
| Insertion sort | `for i=1..n-1: for (j=i; !stop && j>0; j--) if (t[j]<t[j-1]) swap else stop=true;` |
| Bubble sort | `index=n; do { sorted=true; index--; for (i<index) if (t[i]>t[i+1]) {swap; sorted=false;} } while (index>0 && !sorted);` |
| Χρόνος | `long s = System.nanoTime(); …; long dt = System.nanoTime() - s;` |

| Αλγόριθμος | Πολυπλοκότητα | Καλύτερη (ταξινομημένος) |
|---|---|---|
| bubble, insertion, selection | **O(n²)** | O(n) για bubble/insertion με τις σημαίες τους |
| merge, quick | **O(n log n)** | – |
