# 08 - Ασκήσεις

22 ασκήσεις στο ύφος των διαφανειών της Ενότητας VIII. **Λύσε πρώτα, άνοιξε μετά.** Όλες οι απαντήσεις ελέγχθηκαν με `javac`/`java` 17.

> [!tip] Πώς να το χρησιμοποιήσεις
> Σε κάθε κλήση ρώτα: **τι αντιγράφεται** στην παράμετρο (τιμή ή διεύθυνση;) και **ποια εκδοχή** διαλέγει ο μεταγλωττιστής. Στα ίχνη γράψε ένα πλαίσιο ανά κλήση, με τις δικές του μεταβλητές.

## Μέρος Α — Διεπαφή και return

### Άσκηση 1

Ποιες κάνουν compile; Για όσες όχι, γιατί;
(α) `public static f(int x) { }`
(β) `public static int f(int x, y) { return x; }`
(γ) `public static void g() { return; }`
(δ) `public static double[] f(double[] a, int n) { return a; }`
(ε) `static int h(int x) { if (x > 0) return x; }`
(στ) `static int k(int x) { if (x > 0) return 1; else return 0; x++; }`

> [!success]- Λύση
> (α) ✗ `return type required` – λείπει ο τύπος (`void`). (β) ✗ – το `y` θέλει δικό του τύπο: `int x, int y`. (γ) ✓ (δ) ✓ – επιστρέφει διεύθυνση πίνακα. (ε) ✗ `missing return statement` – για `x ≤ 0`. (στ) ✗ `unreachable statement` – μετά το `if/else` και οι δύο δρόμοι έχουν ήδη επιστρέψει.

### Άσκηση 2

Για καθεμία, πες σε ποια από τις τέσσερις κατηγορίες της VIII-6 ανήκει (είσοδοι/έξοδος) και γράψε την επικεφαλίδα της:
(α) τυπώνει «Καλημέρα» (β) επιστρέφει πίνακα `n` τυχαίων ακεραίων στο `[1, 6]` (γ) μηδενίζει τα αρνητικά στοιχεία ενός πίνακα (δ) επιστρέφει τον μέσο όρο ενός πίνακα.

> [!success]- Λύση
> (α) ούτε είσοδοι ούτε έξοδος: `public static void hello()`
> (β) είσοδος και έξοδος (διεύθυνση): `public static int[] dice(int n)`
> (γ) μόνο είσοδος, που είναι διεύθυνση → έμμεση έξοδος: `public static void clearNegatives(int[] t)`
> (δ) είσοδος και έξοδος: `public static double mean(double[] t)`
>
> Το (γ) **δεν** χρειάζεται να επιστρέψει πίνακα: αλλάζει τον πίνακα του καλούντα.

### Άσκηση 3

Γράψε `isPrime(int n)` με **πρόωρες** `return`. Τι επιστρέφει για `-7, 0, 1, 2, 9, 29, 2147483647`;

> [!success]- Λύση
> ```java
> public static boolean isPrime(int n){
>    if (n < 2) return false;                 // φύλακας
>    for (int d = 2; d * d <= n; d++)
>       if (n % d == 0) return false;         // βρέθηκε διαιρέτης → φεύγω
>    return true;                             // κανένας διαιρέτης
> }
> ```
> `false false false true false true false`. Το `2147483647` είναι πρώτος, αλλά η συνθήκη `d * d <= n` **υπερχειλίζει** όταν `d` πλησιάζει το `46341` (`d*d` γίνεται αρνητικό), ο βρόχος συνεχίζει και κάποια στιγμή βρίσκει `n % d == 0` για `d == n` → `false`. Ασφαλής εκδοχή: `d <= n / d`.

### Άσκηση 4

Τι κάνει λάθος η VIII-17 και πώς διορθώνεται; Γράψε `drawRect(int w, int h)` που τυπώνει ορθογώνιο από `#` πλάτους `w` και ύψους `h`, και δεν κάνει τίποτα αν κάποια διάσταση είναι `< 1`.

> [!success]- Λύση
> Στη VIII-17 το `println()` είναι πριν από τα αστέρια κάθε γραμμής: βγαίνει μια κενή γραμμή στην αρχή και η τελευταία γραμμή δεν κλείνει.

> ```

## Μέρος Β — Κλήση, binding και εμβέλεια

### Άσκηση 5

Τι τυπώνει;
```java
static int f(int x, int y) { x = x + y; y = x - y; return x * y; }

int x = 2, y = 3;
int z = f(y, x);
System.out.println(x + " " + y + " " + z);
```

> [!success]- Λύση
> `2 3 15`. Η κλήση `f(y, x)` δίνει στην παράμετρο `x` την τιμή **3** (το `y` του καλούντα) και στην `y` την **2**. Μέσα: `x = 5`, `y = 5 - 2 = 3`, `return 15`. Τα `x`, `y` της `main` δεν αλλάζουν – η `f` είχε αντίγραφα.

### Άσκηση 6

Η `min2` τυπώνει `min2(a,b) ` κάθε φορά που καλείται. Τι τυπώνουν;
(α) `System.out.println("-> " + min3(7, 1, 4));`
(β) `System.out.println("-> " + min2(min3(5,6,7), min2(8, 2)));`
με `min3(a,b,c) { return min2(a, min2(b,c)); }`.

> [!success]- Λύση
> (α) `min2(1,4) min2(7,1) -> 1` – πρώτα η εσωτερική `min2(b,c)`.
> (β) `min2(6,7) min2(5,6) min2(8,2) min2(5,2) -> 2` – ορίσματα αριστερά → δεξιά: πρώτα ολόκληρη η `min3(5,6,7)` (με τις δύο δικές της κλήσεις), μετά `min2(8,2)`, και τελευταία η εξωτερική `min2(5,2)`.
>
> Το `"-> "` τυπώνεται **στο τέλος**: η `println` καλείται αφού αποτιμηθεί όλο το όρισμά της.

### Άσκηση 7

Με `static double avg(int a, double b) { return (a+b)/2; }`, ποιες κλήσεις κάνουν compile και τι επιστρέφουν;
(α) `avg(1, 2)` (β) `avg(1.0, 2)` (γ) `avg('a', 2.5f)` (δ) `avg(1L, 2)` (ε) `avg(1, 2L)`

> [!success]- Λύση
> (α) ✓ `1.5` – το `2` γίνεται `2.0`. (β) ✗ `double` σε `int`. (γ) ✓ `49.75` – `'a'` = 97, `2.5f` → `2.5`. (δ) ✗ `long` σε `int`. (ε) ✓ `1.5` – `long → double` επιτρέπεται.

### Άσκηση 8

Ποια γραμμή δεν κάνει compile, και γιατί; Μετά τη διόρθωσή της, τι τυπώνει η `main` αν αντικατασταθεί από τη δεύτερη;
```java
public class M{
  static int k = 5;
  static int f(int a){ int b = a + k; return b; }
  public static void main(String[] args){
    int a = 1;
    for (int i = 0; i < 3; i++) { int b = i; }
    System.out.println(b);
  }
}
```
```java
  static int g(int k){ return k * 2; }
  public static void main(String[] args){ int k = 100; System.out.println(f(1) + " " + g(3) + " " + k); }
```

> [!success]- Λύση
> Η `System.out.println(b);` – `cannot find symbol`: το `b` υπάρχει μόνο μέσα στο σώμα του `for` (και ένα **άλλο** `b` μέσα στην `f`). Το `int a = 1;` της `main` **δεν** συγκρούεται με την παράμετρο `a` της `f`: άλλη μέθοδος.
>
> Δεύτερη `main`: `6 6 100`. Η `f` βλέπει τη **στατική** `k = 5` (το `k = 100` είναι τοπικό στη `main`, αόρατο για την `f`): `1 + 5`. Η `g` έχει παράμετρο `k = 3` που επισκιάζει τη στατική: `6`.

### Άσκηση 9

Γιατί αυτό δεν κάνει compile, ενώ σε C θα έκανε;
```java
static int f(int a){ int a2 = a; for (int a = 0; a < 2; a++) {} return a2; }
```

> [!success]- Λύση
> `variable a is already defined in method f(int)`. Η παράμετρος `a` είναι τοπική μεταβλητή όλης της μεθόδου, και η Java **απαγορεύει** να δηλωθεί ξανά το ίδιο όνομα σε εσωτερικό μπλοκ (εδώ ο `for`). Η C επιτρέπει την επισκίαση.

## Μέρος Γ — Πίνακες ως παράμετροι

### Άσκηση 10

Τι τυπώνει;
```java
static void m(int[] a, int b) { a[0] = 10; b = 20; a = new int[]{30, 40}; a[1] = 50; }

int[] t = {1, 2}; int v = 3;
m(t, v);
System.out.println(t[0] + " " + t[1] + " " + v);
```

> [!success]- Λύση
> `10 2 3`.
> - `a[0] = 10` γράφει στον πίνακα του `t` (ίδια διεύθυνση) → `t[0] = 10`.
> - `b = 20` αλλάζει μόνο το αντίγραφο → `v` μένει `3`.
> - `a = new int[]{30, 40}` κάνει το **τοπικό** `a` να δείχνει σε νέο πίνακα· το `a[1] = 50` γράφει σε **αυτόν**, όχι στον `t` → `t[1]` μένει `2`.

### Άσκηση 11

Γράψε δύο συναρτήσεις: `reverse(int[] t)` που αντιστρέφει **επί τόπου**, και `reversed(int[] t)` που **επιστρέφει νέο** αντεστραμμένο πίνακα χωρίς να αλλάξει τον αρχικό. Τι τυπώνει `int[] c = {1,2}; reversed(c); System.out.println(Arrays.toString(c));`;

> [!success]- Λύση
> ```java
> public static void reverse(int[] t){
>    for (int i = 0, j = t.length - 1; i < j; i++, j--){
>       int tmp = t[i]; t[i] = t[j]; t[j] = tmp;
>    }
> }
> public static int[] reversed(int[] t){
>    int[] r = new int[t.length];
>    for (int i = 0; i < t.length; i++) r[i] = t[t.length - 1 - i];
>    return r;
> }
> ```
> `[1, 2]`: η `reversed` φτιάχνει **νέο** πίνακα και τον επιστρέφει· η κλήση τον αγνοεί (standalone κλήση συνάρτησης με τιμή – παράλογη, VIII-12). Κενός πίνακας και πίνακας ενός στοιχείου δουλεύουν και στις δύο (το `i < j` είναι ψευδές από την αρχή).

### Άσκηση 12

Τι τυπώνει;
```java
static void sums(int[] a, int[] b){ for (int i = 1; i < a.length; i++) b[i] = a[i-1] + a[i]; }

int[] t = {1,2,3,4}, u = {1,2,3,4}, w = new int[4];
sums(t, w); sums(u, u);
System.out.println(Arrays.toString(w) + " " + Arrays.toString(u));
```

> [!success]- Λύση
> `[0, 3, 5, 7] [1, 3, 6, 10]`.
> - `w`: το `w[0]` δεν γράφεται ποτέ (ο βρόχος ξεκινά από 1) → μένει `0`. Μετά `1+2, 2+3, 3+4`.
> - `sums(u, u)`: είσοδος και έξοδος είναι ο **ίδιος** πίνακας. Στο `i = 2` το `a[1]` είναι ήδη `3` (γράφτηκε στο `i = 1`), άρα `3+3 = 6`· στο `i = 3`: `6+4 = 10`. Βγαίνουν **αθροίσματα προθέματος** αντί για αθροίσματα γειτόνων.

### Άσκηση 13

Με την `initializeTable` της VIII-28, τι τυπώνουν;
(α) `double[] T = new double[2]; initializeTable(T, 7/2); displayTable(T);`
(β) `initializeTable(new double[2], 3.5);`

> [!success]- Λύση
> (α) `0 : 3.0` και `1 : 3.0`. Το `7/2` είναι **ακέραια** διαίρεση → `3`, και η ανάθεση σε `double` δίνει `3.0`.

## Μέρος Δ — Υπερφόρτωση

### Άσκηση 14

Δίνονται `f(int)`, `f(double)`, `f(int,int)`, `f(double,double)`. Ποια εκδοχή καλείται;
(α) `f(1)` (β) `f(1.5f)` (γ) `f('c')` (δ) `f(1, 2.0)` (ε) `f(1L, 2)` (στ) `f(1, 2)` (ζ) `f('a', 'b')`

> [!success]- Λύση
> (α) `f(int)` (β) `f(double)` (γ) `f(int)` – `char → int` (δ) `f(double,double)` – το `1` διευρύνεται (ε) `f(double,double)` – `long → int` δεν επιτρέπεται (στ) `f(int,int)` (ζ) `f(int,int)`.

### Άσκηση 15

Ποια ζεύγη μπορούν να συνυπάρχουν στην ίδια κλάση;
(α) `int g(int a, double b)` και `int g(double b, int a)`
(β) `int g(int a, double b)` και `double g(int x, double y)`
(γ) `int g(int[] a)`, `int g(int a)` και `int g()`

> [!success]- Λύση
> (α) ✓ – διαφορετική **σειρά** τύπων (αλλά η κλήση `g(1, 1)` θα ήταν `ambiguous`). (β) ✗ – ίδιο signature `g(int,double)`· τύπος επιστροφής και ονόματα δεν μετράνε. (γ) ✓ – τρία διαφορετικά signatures.

### Άσκηση 16

Τι τυπώνουν;
(α) `Math.min(7, 3.0)` (β) `Math.min(5/2, 2.4)` (γ) `Math.min(1, 2) / 2` (δ) `Math.max(-0.0, 0.0) + " " + Math.min(-0.0, 0.0)`

> [!success]- Λύση
> (α) `3.0` – εκδοχή `double`. (β) `2.0` – `5/2 = 2` (ακέραια), μετά `min(2.0, 2.4)`. (γ) `0` – εκδοχή `int`, `1/2 = 0`. (δ) `0.0 -0.0` – η `Math` ξεχωρίζει το `-0.0` από το `0.0`.

## Μέρος Ε — Βιβλιοθήκες και ταξινόμηση

### Άσκηση 17

Για καθέναν από τους πίνακες `{3,1,2}`, `{1,2,3,4}`, `{4,3,2,1}`: πόσες αντιμεταθέσεις κάνουν η `insertionSort` και η `bubbleSort` της `SortLib`; Πόσα περάσματα (`do`) κάνει η `bubbleSort`;

> [!success]- Λύση
>
> | Πίνακας | Αντιμεταθέσεις (και οι δύο) | Περάσματα bubble |
> |---|---|---|
> | `{3,1,2}` | 2 | 2 |
> | `{1,2,3,4}` | 0 | 1 – διαπιστώνει ότι είναι ταξινομημένος |
> | `{4,3,2,1}` | 6 = 4·3/2 | 4 – το τελευταίο με `index = 0` |
>
> Οι δύο αλγόριθμοι κάνουν **πάντα** ίδιο πλήθος αντιμεταθέσεων: όσα είναι τα ζεύγη στοιχείων σε λάθος σειρά (inversions). Διαφέρουν στις συγκρίσεις και στη σειρά.

### Άσκηση 18

Τι αλλάζεις στην `insertionSort` για να ταξινομεί σε **φθίνουσα** σειρά; Τι δίνει για `{5,2,4,6,1,3}`;

> [!success]- Λύση
> Μία σύγκριση: `if (table[j] > table[j-1])` αντί για `<`. Αποτέλεσμα `[6, 5, 4, 3, 2, 1]`. (Η `sorted` πρέπει επίσης να αλλάξει σε `table[i] < table[i+1]` για να την ελέγξει.)

### Άσκηση 19

Δύο «μικρές» αλλαγές στη `bubbleSort`. Τι κάνει η καθεμία με `{3,1,2}`;
(α) `for (int i = 0; i <= index; i++)` αντί για `<`.
(β) `while (index > 0 && !sorted) { … }` στη θέση του `do { … } while (…)`, με την ίδια αρχικοποίηση `boolean sorted = true;`.

> [!success]- Λύση
> (α) `ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3`: στο πρώτο πέρασμα `index = 2`, άρα `i = 2` και `table[i+1] = table[3]`.
> (β) Ο πίνακας μένει **`{3,1,2}`**: το `sorted` είναι `true` πριν τον πρώτο έλεγχο, άρα το `while` δεν εκτελείται ποτέ. Γι' αυτό χρειάζεται `do-while` ([[07 - Εντολή do-while και Ισοδυναμίες Βρόχων|III – 07]]).

### Άσκηση 20

Τι θα κάνει η `DrawGraph.plot(ys1, ys2)` της **πρώτης** εκδοχής (VIII-41) με `ys1` μήκους 10 και `ys2` μήκους 5; Και η δεύτερη (VIII-42) με `ys1` μήκους 5 και `ys2` μήκους 10;

> [!success]- Λύση
> - Πρώτη: ο κοινός βρόχος πάει μέχρι `i = 8`· στο `i = 4` διαβάζει `ys2[5]` → `ArrayIndexOutOfBoundsException`.

### Άσκηση 21

Γράψε τη `max(double[] ys)` της `DrawGraph` και εξήγησε γιατί είναι `private`. Τι επιστρέφει για κενό πίνακα, και γιατί αυτό κάνει την `plot` να αποτύχει;

> [!success]- Λύση
> Η υλοποίηση της VIII-38 (`M = Double.NEGATIVE_INFINITY; … if (M < ys[i]) M = ys[i];`). Είναι `private` γιατί είναι **βοηθητική** της `plot`, όχι μέρος του API· η βιβλιοθήκη μπορεί να την αλλάξει χωρίς να επηρεάσει τους clients. ### Άσκηση 22

Γράψε βιβλιοθήκη `Stats` με `private double sum(double[])` και **υπερφορτωμένη** `mean`: για `double[]`, για `int[]` (χωρίς να ξαναγράψεις το άθροισμα) και για δύο `double`. Τι τυπώνει `mean(new int[0])`;

> [!success]- Λύση
> ```java
> public class Stats {
>    private static double sum(double[] xs){ double s = 0.0; for (double x : xs) s += x; return s; }
>    public static double mean(double[] xs){ return sum(xs) / xs.length; }
>    public static double mean(int[] xs){
>       double[] d = new double[xs.length];
>       for (int i = 0; i < xs.length; i++) d[i] = xs[i];
>       return mean(d);                  // επαναχρησιμοποίηση της εκδοχής double[]
>    }
>    public static double mean(double a, double b){ return (a + b) / 2; }
> }
> ```
> `mean(new double[]{1,2,4})` → `2.3333333333333335` · `mean(new int[]{1,2})` → `1.5` · `mean(3, 4)` → `3.5` · `mean(new int[0])` → **`NaN`** (`0.0/0`). Η εκδοχή `int[]` χρειάζεται γιατί το `int[]` **δεν** περνά αυτόματα σε `double[]`.
