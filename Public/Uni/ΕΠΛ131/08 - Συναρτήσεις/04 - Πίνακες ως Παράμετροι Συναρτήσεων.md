# 04 - Πίνακες ως Παράμετροι Συναρτήσεων

Όταν το όρισμα είναι πίνακας, αντιγράφεται η **διεύθυνσή** του: η συνάρτηση δουλεύει πάνω στον **ίδιο** πίνακα με τον καλούντα, άρα ο πίνακας μπορεί να λειτουργήσει και ως **παράμετρος εξόδου** (διαφάνειες VIII-25 … VIII-32).

## 1. Συναρτήσεις χρήστη με παραμέτρους πίνακες (VIII-25, VIII-26)

```java
public class MinTableDoubles{

    //function that returns min value in a table of doubles
    public static double minTable (double[] table){
      double res = Double.POSITIVE_INFINITY;
      for (int i=0;i<table.length;++i){
         if (table[i] < res) res = table[i];
      }
      return res;
    }
    // function that prints the min value in a table of doubles
    // uses minTable, does not return anything void
    public static void displayMinTable (double[] array){
      System.out.println(minTable(array));
    }

    public static void main(String[] args){
      double[] T = {5.9, 1.0, 7.9, 10, 3.1};
      displayMinTable(T); // function call
    }
}
```

> [!important] Τι περνά στη συνάρτηση (VIII-26)
> - Η `main` περνάει τον `T` **by reference** (αναφορά, pointer, διεύθυνση) στη συνάρτηση `displayMinTable`.
> - Ο `array` στη `displayMinTable`, μετά την κλήση από τη `main`, **δείχνει στον ίδιο πίνακα** όπως η `main`, δηλαδή τον πίνακα `T`.
> - Ο `table` στη `minTable`, μετά την κλήση από τη `displayMinTable`, δείχνει **στον ίδιο πίνακα** όπως η `main`, δηλαδή τον `T`.
>
> Τρεις μεταβλητές (`T`, `array`, `table`) σε τρία διαφορετικά πλαίσια στη στοίβα – **ένας** πίνακας στη μνήμη με `length 5` και στοιχεία `5.9, 1.0, 7.9, 10.0, 3.1`.

## 2. Είδη παραμέτρων και τύπων επιστροφής (VIII-27)

> [!note] Τιμές και αναφορές
> - Οι τιμές που λαμβάνει (παράμετροι) μπορεί να είναι τιμές έκφρασης (**δια τιμής / by value**), ή **αναφορές** (διευθύνσεις, π.χ. σε πίνακες ή αντικείμενα – **references**).
> - Μια συνάρτηση **επιστρέφει τιμή ή αναφορά**.
> - Εάν λαμβάνει τιμές που είναι αναφορές, τότε **έμμεσα** μπορεί να συνιστούν και (επιπρόσθετες) **εξόδους**.

> [!warning] ➕ Στη Java όλα περνούν δια τιμής – και η διεύθυνση
> Ακριβέστερα: η Java περνά **πάντα** αντίγραφο. Όταν το όρισμα είναι πίνακας, αντιγράφεται η **διεύθυνση** (η τιμή της μεταβλητής `T`), όχι ο πίνακας. Συνέπεια:
>
> | Μέσα στη συνάρτηση | Επηρεάζει τον καλούντα; |
> |---|---|
> | `t[0] = 0;` – αλλαγή **περιεχομένου** | **Ναι**: το αντίγραφο της διεύθυνσης δείχνει στον ίδιο πίνακα |
> | `t = new int[]{0, 0};` – αλλαγή της **ίδιας της παραμέτρου** | **Όχι**: τώρα μόνο το τοπικό `t` δείχνει αλλού· ο πίνακας του καλούντα μένει ίδιος |
>
> (ελέγχθηκε: με `int[] a = {5, 6};`, η `reset(a)` αφήνει `a[0] == 5`, η `zero(a)` το κάνει `0`). Για να «αλλάξει» ο καλών ολόκληρο πίνακα, η συνάρτηση πρέπει να **επιστρέψει** τον νέο και ο καλών να αναθέσει: `xs = add(xs, num);` ([[02 - Διαδραστική Είσοδος και Αναδρομή#6. Αντίστροφη σειρά με πίνακα ως στοίβα (VII-31 … VII-33)|VII – 02]]).

## 3. Πίνακας σαν παράμετρος εξόδου (VIII-28 … VIII-32)

```java
public class InitializeTableDoubles{

    //function that initializes a table of doubles
    public static void initializeTable (double[] table, int v){
       for (int i=0;i<table.length;++i)
         table[i] = v;
    }
    // function that display contents of a table of doubles
    public static void displayTable(double[] array){
      for(int i=0;i<array.length;++i) System.out.println(i + " : " + array[i]);
    }

    public static void main(String[] args){
      double[] T = new double[Integer.parseInt(args[0])];
      initializeTable(T, Integer.parseInt(args[1])); // function call
      displayTable(T);
    }
}
```

```
java InitializeTableDoubles 3 436
0 : 436.0
1 : 436.0
2 : 436.0
```

Οι διαφάνειες VIII-28 … VIII-32 δείχνουν την ίδια εκτέλεση βήμα-βήμα στη μνήμη:

| Διαφάνεια | Στοίβα | Πίνακας στη μνήμη |
|---|---|---|
| VIII-29 | `main`: `args`, `T` → πίνακας | `length 3` · `0.0 0.0 0.0` (προεπιλεγμένες τιμές) |
| VIII-30 | + `initializeTable`: `table` → **ίδιος** πίνακας, `v = 436` | `0.0 0.0 0.0` |
| VIII-31 | (ο βρόχος γράφει μέσω `table`) | `436.0 436.0 436.0` |
| VIII-32 | η `initializeTable` τελείωσε· + `displayTable`: `array` → ίδιος πίνακας | `436.0 436.0 436.0` – τυπώνονται |

![[Συναρτήσεις - Πίνακας ως Παράμετρος Εξόδου.png|800]]

> [!important] Γιατί λέγεται «παράμετρος εξόδου»
> Η `initializeTable` είναι `void` – δεν επιστρέφει τίποτα. Κι όμως, ο καλών **παίρνει αποτέλεσμα**: τον γεμάτο πίνακα `T`. Η «έξοδος» περνά μέσα από την παράμετρο, επειδή η παράμετρος είναι διεύθυνση.

> [!warning] ⚠️ Σημείωση για τις VIII-28 … VIII-32
> - Η `main` γράφεται `public static main(String[] args)` – **λείπει το `void`**: δεν κάνει compile (`invalid method declaration; return type required`, ελέγχθηκε).
> - Η έξοδος στη διαφάνεια είναι `0 : 436`, ενώ στην πράξη είναι **`0 : 436.0`**: τα στοιχεία είναι `double`, και το `int v` μετατρέπεται σε `436.0` κατά την ανάθεση `table[i] = v;` (ελέγχθηκε). Ομοίως, στο σχήμα της VIII-26 γράφεται `10.0`, σωστά, ενώ στον κώδικα είναι `10`.

## 4. ➕ Πίνακας ως τιμή επιστροφής και άλλες περιπτώσεις

> [!example]- Πότε επιστρέφουμε πίνακα και πότε γράφουμε σε παράμετρο
>
> | Μοτίβο | Παράδειγμα | Πότε |
> |---|---|---|
> | Γράφει σε πίνακα του καλούντα | `initializeTable(T, v)`, `sort(table)` | ο πίνακας υπάρχει ήδη, με σωστό μέγεθος |
> | Φτιάχνει και επιστρέφει νέο | `double[] r = create(n);` | ο πίνακας δεν υπάρχει ή αλλάζει μέγεθος |
> | Και τα δύο | `xs = add(xs, x)` | το μέγεθος μεγαλώνει: νέος πίνακας, άρα πρέπει να επιστραφεί |

> [!warning] Παγίδες με πίνακες-παραμέτρους (ελέγχθηκαν)
> - **`null`**: `negative(null)` → `NullPointerException` στο `table.length`. Αν μια συνάρτηση δέχεται `null`, πρέπει να το ελέγχει (`if (table == null) …`).
> - **Κυριολεκτικό πίνακα** δεν μπορείς να δώσεις σκέτο: `minTable({1.0, 2.0})` ✗ – γράφεις `minTable(new double[]{1.0, 2.0})` ✓.
> - **Ίδιος πίνακας δύο φορές** (aliasing): με `shiftRight(int[] from, int[] to)` που κάνει `to[i] = from[i-1]` για `i = 1, 2, …`, η κλήση `shiftRight(b, b)` με `b = {1,2,3,4}` δίνει **`{1,1,1,1}`** αντί για `{1,1,2,3}`: κάθε εγγραφή χαλάει την τιμή που θα διαβαστεί στο επόμενο βήμα. Η `shiftLeft(a, a)` (από αριστερά, `to[i] = from[i+1]`) δουλεύει κατά τύχη: `{2,3,4,4}`.
> - Το `int[]` δεν περνά σε παράμετρο `double[]` ([[03 - Κλήση, Ορίσματα, Binding και Εμβέλεια#5. Αντιστοιχία ορισμάτων με παραμέτρους (VIII-22)|03 §5]]).
> - Ο πίνακας που φτιάχνεται **μέσα** σε συνάρτηση **δεν** χάνεται με το τέλος της, αν επιστραφεί η διεύθυνσή του. Χάνεται μόνο όταν καμία μεταβλητή δεν δείχνει πια σε αυτόν.

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - «Η Java περνά τους πίνακες by reference, άρα το `t = new …` μέσα στη μέθοδο αλλάζει τον πίνακα του καλούντα» – **όχι**: αλλάζει μόνο το τοπικό αντίγραφο της διεύθυνσης.
> - Αναμονή ότι η `initializeTable` χρειάζεται `return` για να «φανεί» η αλλαγή.
> - Λάθος έξοδος σε ερωτήσεις ίχνους: στοιχείο `double` τυπώνεται **με** `.0`.
> - Κλήση με τον ίδιο πίνακα ως είσοδο και έξοδο χωρίς να σκεφτείς τη σειρά εγγραφών.
> - `minTable({…})` χωρίς `new double[]`.
