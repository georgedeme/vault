# 02 - Πράξεις Πινάκων και Διάσπαση ανά Διάσταση

Πρόσθεση και πολλαπλασιασμός τετραγωνικών πινάκων, και η μέθοδος `sum` για τρεις διαστάσεις γραμμένη με τρεις τρόπους – ο τελευταίος **διασπά** το πρόβλημα **ανά διάσταση** με υπερφόρτωση (διαφάνειες IX-10, IX-11, IX-18 … IX-20).

## 1. Πρόσθεση τετραγωνικών πινάκων N × N (IX-10)

```java
double[][] c = new double[N][N];     // όλες οι τιμές αρχικοποιούνται στο 0
for (int i = 0; i < N; i++)
   for (int j = 0; j < N; j++)
      c[i][j] = a[i][j] + b[i][j];
```

| `a` | `b` | `c = a + b` |
|---|---|---|
| `.70 .20 .10` | `.80 .30 .50` | `1.5 .50 .60` |
| `.30 .60 .10` | `.10 .40 .10` | `.40 1.0 .20` |
| `.50 .10 .40` | `.10 .30 .40` | `.60 .40 .80` |

`c[1][2] = a[1][2] + b[1][2] = .10 + .10 = .20`. Κάθε στοιχείο του αποτελέσματος εξαρτάται μόνο από **ένα** στοιχείο κάθε πίνακα, στην **ίδια** θέση: δύο βρόχοι, `N²` προσθέσεις.

## 2. Πολλαπλασιασμός τετραγωνικών πινάκων N × N (IX-11)

```java
double[][] c = new double[N][N];     // όλες οι τιμές αρχικοποιούνται στο 0
for (int i = 0; i < N; i++)
   for (int j = 0; j < N; j++)
      for (int k = 0; k < N; k++)
         c[i][j] += a[i][k] * b[k][j];
```

> [!important] Σειρά × στήλη
> Το `c[i][j]` είναι το **εσωτερικό γινόμενο** της **σειράς `i`** του `a` με τη **στήλη `j`** του `b`. Ο δείκτης `k` «τρέχει» κατά μήκος της σειράς (`a[i][k]`) και κατά μήκος της στήλης (`b[k][j]`) ταυτόχρονα.
>
> `c[1][2] = .3·.5 + .6·.1 + .1·.4 = .15 + .06 + .04 = .25`

![[Πίνακες 2Δ - Πολλαπλασιασμός.png|800]]

| `c = a · b` (ελέγχθηκε) | | |
|---|---|---|
| `.59` | `.32` | `.41` |
| `.31` | `.36` | **`.25`** |
| `.45` | `.31` | `.42` |

**Ερώτηση (IX-11):** Πόσες φορές εκτελείται ο τελεστής `*` για το γινόμενο δύο πινάκων; **A.** N **B.** N² **C.** N³ **D.** N⁴

> [!success]- Απάντηση
> **C. N³.** Τρεις φωλιασμένοι βρόχοι των `N` επαναλήψεων, ένας `*` στον εσωτερικό: `N · N · N`. Για `N = 3`: 27 (ελέγχθηκε με μετρητή). Ο πολλαπλασιασμός πινάκων με αυτόν τον αλγόριθμο είναι O(N³) – διπλασιασμός του `N` → οκταπλασιασμός του χρόνου.

> [!warning] ➕ Παγίδες του πολλαπλασιασμού (ελέγχθηκαν)
> - **`=` αντί για `+=`**: `c[i][j] = a[i][k] * b[k][j];` κρατά μόνο τον **τελευταίο** όρο (`k = N-1`). Για το `c[1][2]` δίνει `.1·.4 = .04` αντί για `.25`.
> - Το `+=` βασίζεται στο ότι το `c` ξεκινά από `0.0`. Αν το `c` ήταν ήδη γεμάτο (π.χ. ξαναχρησιμοποιείς πίνακα), πρέπει να μηδενιστεί πρώτα – ή να χρησιμοποιηθεί τοπικό `double sum = 0;` μέσα στον `j`.
> - `a[i][k] * b[j][k]` (λάθος σειρά δεικτών στο `b`) πολλαπλασιάζει σειρά με **σειρά** – είναι το γινόμενο με τον **ανάστροφο** του `b`.
> - Ο πολλαπλασιασμός **δεν** είναι αντιμεταθετικός: `a·b ≠ b·a` γενικά.
> - Μη τετραγωνικοί: `a` διαστάσεων `m × n` επί `b` διαστάσεων `n × p` δίνει `m × p`. Οι βρόχοι: `i < m` (`a.length`), `j < p` (`b[0].length`), `k < n` (`a[0].length` = `b.length`).

## 3. Η μέθοδος sum για τρεις διαστάσεις (IX-18, IX-19)

**Με δείκτες (IX-18):**
```java
public static double sum (double[][][] xsss){
 double s = 0.0;
 for (int i = 0; i < xsss.length; i++)             // for each plane
   for (int j = 0; j < xsss[0].length; j++)        // for each row
     for (int k = 0; k < xsss[0][0].length; k++)   // for each col
       s += xsss[i][j][k];
 return s;
}
```

**Με for-each (IX-19):**
```java
public static double sum (double[][][] xsss){
 double s = 0.0;
 for (double[][] xss : xsss)   // for each plane
   for (double[] xs : xss)     // for each row
     for (double x : xs)       // for each col
       s += x;
 return s;
}
```

> [!note] Ο κύβος γίνεται επίπεδα, σειρές, στοιχεία
> Το σχήμα των διαφανειών: **κύβος** (`double[][][]`) → **επίπεδο** (`double[][]`) → **σειρά** (`double[]`) → **στοιχείο** (`double`). Κάθε επίπεδο βρόχου «ξεφλουδίζει» μία διάσταση. Στο for-each ο **τύπος** της μεταβλητής κάθε βρόχου έχει ένα `[]` λιγότερο από τον προηγούμενο.

> [!warning] ➕ Οι δύο εκδοχές δεν είναι ισοδύναμες (ελέγχθηκε)
> Η εκδοχή με δείκτες χρησιμοποιεί `xsss[0].length` και `xsss[0][0].length` για **όλα** τα επίπεδα και σειρές: υποθέτει **κανονικό** (ορθογώνιο) πίνακα. Με τον ακανόνιστο `{{{1,2},{3}},{{4,5,6}}}`:
> - for-each: `21.0` ✓
> - με δείκτες: `ArrayIndexOutOfBoundsException` (η σειρά `{3}` έχει μήκος 1, όχι 2).
>
> Η σωστή γενική εκδοχή με δείκτες: `j < xsss[i].length`, `k < xsss[i][j].length`. Το for-each είναι ασφαλέστερο **όταν χρειάζεσαι μόνο τις τιμές**.

## 4. Τρεις εκδοχές της sum: διάσπαση ανά διάσταση (IX-20)

```java
public static double sum (double[] xs){
 double s = 0.0;
 for (double x : xs)
    s += x;
 return s;
}

public static double sum (double[][] xss){
 double s = 0.0;
 for (double[] xs : xss)
    s += sum(xs);
 return s;
}

public static double sum (double[][][] xsss){
 double s = 0.0;
 for (double[][] xss : xsss)
    s += sum(xss);
 return s;
}
```

> [!important] Τι κερδίζουμε
> - Κάθε εκδοχή έχει **έναν** βρόχο και ξέρει μόνο **μία** διάσταση. Το «άθροισμα επιπέδου» ορίζεται ως «άθροισμα των αθροισμάτων των σειρών του».
> - Τρεις μέθοδοι με το **ίδιο όνομα**: [[05 - Υπερφόρτωση Συναρτήσεων|υπερφόρτωση]]. Η `sum(xs)` μέσα στη 2Δ εκδοχή καλεί την 1Δ, επειδή το `xs` είναι `double[]`.
> - Είναι η **«ανάλυση πινάκων πολλαπλών διαστάσεων σε σχέση με την κάθε διάσταση»** της σύνοψης (IX-44): διάσπαση σε πολλά επίπεδα σύμφωνα με τις διαστάσεις του πίνακα.
> - Δουλεύει και για ακανόνιστους πίνακες (`21.0` στο παραπάνω παράδειγμα).

![[Πίνακες 2Δ - sum ανά Διάσταση.png|800]]

> [!tip] Δεν είναι αναδρομή
> Η 3Δ `sum` καλεί τη 2Δ, που καλεί την 1Δ: **τρεις διαφορετικές** μέθοδοι. Αναδρομή θα ήταν αν μια μέθοδος καλούσε **τον εαυτό της** ([[Uni/ΕΠΛ131/10 - Αναδρομή/00 - Ευρετήριο|Ενότητα X]]).

## 5. ➕ Κλασικές διασχίσεις δισδιάστατου πίνακα

> [!example]- Αθροίσματα σειρών και στηλών, ανάστροφος, διαγώνιος (ελέγχθηκαν)
> ```java
> // άθροισμα κάθε σειράς: σειρά = μονοδιάστατος πίνακας → for-each
> double[] rowSums = new double[a.length];
> for (int i = 0; i < a.length; i++)
>    for (double x : a[i]) rowSums[i] += x;
>
> // άθροισμα κάθε στήλης: ΔΕΝ υπάρχει πίνακας-στήλη → δείκτες, εξωτερικός βρόχος οι στήλες
> double[] colSums = new double[a[0].length];
> for (int j = 0; j < a[0].length; j++)
>    for (int i = 0; i < a.length; i++) colSums[j] += a[i][j];
>
> // ανάστροφος m×n → n×m
> int[][] tr = new int[m[0].length][m.length];
> for (int i = 0; i < m.length; i++)
>    for (int j = 0; j < m[0].length; j++) tr[j][i] = m[i][j];
>
> // κύρια διαγώνιος (τετραγωνικός): a[i][i] · αντιδιαγώνιος: a[i][N-1-i]
> ```
> Ανάστροφος του `{{1,2,3},{4,5,6}}` → `[[1, 4], [2, 5], [3, 6]]`.

> [!warning] for-each και αλλαγές (ελέγχθηκαν)
> Με `g = {{1,2,3},{4,5,6}}`:
> - `for (int[] row : g) for (int v : row) v = 0;` → **καμία αλλαγή**: το `v` είναι αντίγραφο της τιμής.
> - `for (int[] row : g) row[0] = 0;` → `[[0, 2, 3], [0, 5, 6]]` ✓: το `row` είναι αντίγραφο της **διεύθυνσης** της σειράς.
> - `for (int[] row : g) row = new int[3];` → καμία αλλαγή: αλλάζει μόνο το τοπικό `row`.
>
> Ίδιος κανόνας με τις παραμέτρους ([[04 - Πίνακες ως Παράμετροι Συναρτήσεων|VIII – 04]]).

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - `=` αντί για `+=` στον πολλαπλασιασμό.
> - Πολλαπλασιασμός «στοιχείο-στοιχείο» (`c[i][j] = a[i][j] * b[i][j]`) αντί για σειρά × στήλη.
> - Απάντηση N² στην ερώτηση της IX-11: οι **τρεις** βρόχοι δίνουν N³.
> - `xsss[0].length` σε ακανόνιστο πίνακα.
> - Προσπάθεια for-each πάνω σε **στήλη**.
> - Αλλαγή της μεταβλητής του for-each με την ελπίδα να αλλάξει ο πίνακας.
