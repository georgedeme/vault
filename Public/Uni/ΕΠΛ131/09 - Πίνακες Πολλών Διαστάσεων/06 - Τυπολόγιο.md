# 06 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα IX.

## 1. Δήλωση και αρχικοποίηση

| Κώδικας | |
|---|---|
| `double[][] a = new double[M][N];` | M σειρές, N στήλες, όλα `0.0` |
| `char[][] t = {{'X','O','X'},{'O','X','O'},{'O','X','X'}};` | ρητή – **μόνο** στη δήλωση |
| `a = new int[][]{{1,2},{3,4}};` | ρητή σε ανάθεση |
| `int[][] r = new int[3][];` | μόνο ο πίνακας σειρών· `r[i] == null` |
| `double[][][] t = new double[7][5][6];` | 210 στοιχεία, δείκτες `0..6`, `0..4`, `0..5` |
| `new int[][3]` · `new int[3,3]` · `int a[3][3]` | ✗ |

| Προεπιλογές | `int` `0` · `double` `0.0` · `boolean` `false` · `char` `'\u0000'` · `String` `null` (≠ `""`) |
|---|---|

## 2. Μνήμη και τύποι

| `int[][] table` | Τύπος | |
|---|---|---|
| `table` | `int[][]` | διεύθυνση του πίνακα **σειρών** |
| `table[i]` | `int[]` | διεύθυνση της σειράς `i` (ίδιος τύπος με κάθε `int[]`) |
| `table[i][j]` | `int` | στοιχείο σειράς `i`, στήλης `j` |
| `table.length` | | πλήθος **σειρών** |
| `table[i].length` | | πλήθος στοιχείων της σειράς `i` (= στήλες αν ορθογώνιος) |

- **Απευθείας πρόσβαση μόνο στις σειρές**· στήλη/διαγώνιος → βρόχος με δείκτες ή αντιγραφή.
- `new int[1][5]`: 1 σειρά × 5 · `new int[5][1]`: 5 σειρές × 1 («στήλη») · `tabA[0]` και `tabB` είναι `int[]`.
- ⚠️ `table`, `table[0]`, `table[0][0]` **δεν** ταυτίζονται (IX-15, IX-48 – αυτό ισχύει στη C).
- Σειρές διαφορετικού μήκους (ragged) επιτρέπονται → `j < a[i].length`.

## 3. Βρόχοι

| Σκοπός | Πυρήνας |
|---|---|
| όλα, σειρά-σειρά | `for (i < a.length) for (j < a[i].length) … a[i][j]` |
| μόνο τιμές | `for (double[] row : a) for (double x : row) …` |
| στήλη `j` | `for (i < a.length) … a[i][j]` |
| κύρια / αντιδιαγώνιος | `a[i][i]` · `a[i][N-1-i]` |
| ανάστροφος | `tr[j][i] = m[i][j]` (`tr = new int[n][m]`) |
| 3Δ | `for (double[][] xss : xsss) for (double[] xs : xss) for (double x : xs)` |

## 4. Πράξεις

| Πράξη | Κώδικας | Κόστος |
|---|---|---|
| `c = a + b` | `c[i][j] = a[i][j] + b[i][j]` | N² |
| `c = a · b` | `c[i][j] += a[i][k] * b[k][j]` (σειρά `i` × στήλη `j`) | **N³** πολλαπλασιασμοί |
| `m×n · n×p` | `i < m`, `j < p`, `k < n` → `m×p` | |

`=` αντί για `+=` → μόνο ο τελευταίος όρος.

## 6. Τα παραδείγματα σε μία γραμμή

| Παράδειγμα | Ιδέα |
|---|---|
| `filled` / `empty` | `∀`: πρώτο αντιπαράδειγμα → `return false`· `return true` μετά τους βρόχους |
| `win` | `rWin(b) \|\| cWin(b) \|\| dWin(b)` · βάση: `same_elem`, `copy_col`, `copy_diag1/2` · μόνο η `win` `public` |
| `TicTacToe` είσοδος | `board[i][j] = args[0].charAt(i*3+j)` · ελέγχει `!= 'E'` · σταματά στην πρώτη νίκη |
| Self-avoiding walk | `while (x>0 && x<N-1 && y>0 && y<N-1)` · εγκλωβισμός: 4 γείτονες `true` → `deadEnds++; break;` · `100*deadEnds/T` |
| Ζωή – γείτονες | 3×3 γύρω, `count--` για τον εαυτό, έλεγχος ορίων **πριν** το `Gen[i][j]` |
| Ζωή – κανόνες | επόμενο = `n == 3 \|\| (ζωντανό && n == 2)` |
| Ζωή – γενιά | **νέος** πίνακας `NGen`· `Gen = nextGen(Gen);` · λείπει η έξοδος (IX-42) |

## 7. Παγίδες των διαφανειών

- IX-9: λείπει ένα `}` στον τριπλό βρόχο.
- IX-15, IX-48: «`table` = διεύθυνση του `table[0][0]`» – λάθος για Java.
- IX-17: «`tabA[0]` και `tabB` δεν είναι ίδιου τύπου» – είναι και οι δύο `int[]`.
- IX-28: η έξοδος είναι `wins on colum 1`, `antidiagonal`, `winner!!`.
- IX-35: καμία από τις 6 τιμές του `r` δεν προκαλεί κίνηση.
