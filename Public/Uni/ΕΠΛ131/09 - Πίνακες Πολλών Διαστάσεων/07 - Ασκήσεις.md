# 07 - Ασκήσεις

20 ασκήσεις στο ύφος των διαφανειών της Ενότητας IX. **Λύσε πρώτα, άνοιξε μετά.** Όλες οι απαντήσεις ελέγχθηκαν με `javac`/`java` 17.

> [!tip] Πώς να το χρησιμοποιήσεις
> Για κάθε δισδιάστατο πίνακα σχεδίασε τον πίνακα **σειρών** με βελάκια προς τις σειρές. Τα περισσότερα «κόλπα» (aliasing, `clone`, ragged, for-each) λύνονται μόλις δεις ποια βελάκια δείχνουν στο ίδιο κουτί.

## Μέρος Α — Δήλωση, μνήμη, τύποι

### Άσκηση 1

Με `int[][] q = new int[3][4];`, πόσο είναι: (α) `q.length` (β) `q[0].length` (γ) το πλήθος στοιχείων (δ) ο τύπος του `q[2]` (ε) η τιμή του `q[2][3]` (στ) τι κάνει το `q[3][0]`;

> [!success]- Λύση
> (α) `3` σειρές (β) `4` στήλες (γ) `12` (δ) `int[]` (ε) `0` (στ) `ArrayIndexOutOfBoundsException` – οι σειρές είναι `0..2`.

### Άσκηση 2

Ποιες κάνουν compile;
(α) `int[][] a = new int[3][];` (β) `int[][] a = new int[][3];` (γ) `int a[3][3];` (δ) `int[] a[] = new int[2][2];` (ε) `int[][] a; a = {{1},{2}};` (στ) `double[][] p = { {.1, .2}, {.3}, };`

> [!success]- Λύση
> (α) ✓ – οι σειρές `null` (β) ✗ – η πρώτη διάσταση είναι υποχρεωτική (γ) ✗ – σύνταξη C (δ) ✓ – ισοδύναμο με `int[][] a` (ε) ✗ – το `{…}` μόνο στη δήλωση· `a = new int[][]{{1},{2}};` (στ) ✓ – ακανόνιστος πίνακας 2 σειρών, το τελικό κόμμα επιτρέπεται.

### Άσκηση 3

Τι τυπώνει;
```java
int x = 0;
int[][] g = new int[3][3];
for (int i = 0; i < 3; i++)
   for (int j = 0; j < 3; j++) g[i][j] = x++;
System.out.println(g[2][1] + " " + g[1][2]);
```

> [!success]- Λύση
> `7 5`. Γέμισμα σειρά-σειρά: `g[i][j] = 3i + j`. `g[2][1] = 7`, `g[1][2] = 5`. Αν οι βρόχοι ήταν ανάποδα (`j` έξω, `i` μέσα) με `x++`, θα έβγαινε ο **ανάστροφος** (`g[i][j] = 3j + i`).

### Άσκηση 4

Τι τυπώνει;
```java
int[][] r = new int[3][];
r[0] = new int[2];
r[2] = r[0];
r[2][1] = 5;
System.out.println(Arrays.deepToString(r));
```

> [!success]- Λύση
> `[[0, 5], null, [0, 5]]`. Το `r[1]` δεν δημιουργήθηκε ποτέ → `null`. Τα `r[0]` και `r[2]` δείχνουν στον **ίδιο** πίνακα: η αλλαγή μέσω του ενός φαίνεται και στον άλλον.

### Άσκηση 5

Γράψε `deepCopy(int[][] a)` που επιστρέφει πλήρες αντίγραφο (δουλεύει και για ακανόνιστους). Γιατί δεν αρκεί το `a.clone()`;

> [!success]- Λύση
> ```java
> static int[][] deepCopy(int[][] a){
>    int[][] c = new int[a.length][];
>    for (int i = 0; i < a.length; i++) c[i] = a[i].clone();   // νέα κάθε σειρά
>    return c;
> }
> ```
> Το `a.clone()` αντιγράφει μόνο τον πίνακα των **αναφορών** των σειρών: `c[0] == a[0]`, άρα `c[0][0] = 9` αλλάζει και το `a[0][0]`. Με το `deepCopy` το `a[0][0]` μένει `1`.

### Άσκηση 6

Τι τυπώνει;
```java
int[][] m2 = {{1,2},{3,4}};
for (int[] row : m2) { int t = row[0]; row[0] = row[1]; row[1] = t; }
System.out.println(Arrays.deepToString(m2));

int[][] g = {{1,2,3},{4,5,6}};
for (int[] row : g) for (int v : row) v = 0;
System.out.println(Arrays.deepToString(g));
```

> [!success]- Λύση
> `[[2, 1], [4, 3]]` – το `row` είναι αντίγραφο της διεύθυνσης κάθε σειράς, άρα οι αντιμεταθέσεις γίνονται στις πραγματικές σειρές.
> `[[1, 2, 3], [4, 5, 6]]` – το `v` είναι αντίγραφο της **τιμής**· η ανάθεση δεν αγγίζει τον πίνακα.

## Μέρος Β — Πράξεις και διασχίσεις

### Άσκηση 7

Γράψε `int[][] mult(int[][] a, int[][] b)` για `a` διαστάσεων `m × n` και `b` διαστάσεων `n × p`. Τι επιστρέφει για `{{1,2,3},{4,5,6}}` επί `{{1,0},{0,1},{1,1}}`; Πόσοι πολλαπλασιασμοί γίνονται;

> [!success]- Λύση
> ```java
> static int[][] mult(int[][] a, int[][] b){
>    int m = a.length, n = b.length, p = b[0].length;
>    int[][] c = new int[m][p];
>    for (int i = 0; i < m; i++)
>       for (int j = 0; j < p; j++)
>          for (int k = 0; k < n; k++)
>             c[i][j] += a[i][k] * b[k][j];
>    return c;
> }
> ```
> `[[4, 5], [10, 11]]` (π.χ. `c[0][0] = 1·1 + 2·0 + 3·1 = 4`). Πολλαπλασιασμοί: `m·p·n = 2·2·3 = 12`. Για τετραγωνικούς N × N: N³.

### Άσκηση 8

Στον πολλαπλασιασμό της IX-11 κάποιος γράφει `c[i][j] = a[i][k] * b[k][j];`. Ποια τιμή παίρνει το `c[1][2]` με τους πίνακες της διαφάνειας (σωστή: `.25`);

> [!success]- Λύση
> `.04` – κρατά μόνο τον τελευταίο όρο (`k = 2`): `a[1][2] · b[2][2] = .1 · .4`.

### Άσκηση 9

Γράψε κώδικα που υπολογίζει τα αθροίσματα κάθε **σειράς** και κάθε **στήλης** του `{{1,2,3},{4,5,6}}`. Γιατί μόνο το ένα μπορεί να γραφτεί με for-each;

> [!success]- Λύση
> Σειρές `[6.0, 15.0]`, στήλες `[5.0, 7.0, 9.0]` (κώδικας στο [[02 - Πράξεις Πινάκων και Διάσπαση ανά Διάσταση#5. ➕ Κλασικές διασχίσεις δισδιάστατου πίνακα|02 §5]]). Κάθε σειρά **είναι** μονοδιάστατος πίνακας (`a[i]`), άρα `for (double x : a[i])`. Μια στήλη δεν υπάρχει ως πίνακας – μόνο ως δείκτης `j` σε κάθε σειρά.

### Άσκηση 10

Για `{{1,2,3},{4,5,6},{7,8,9}}`, τι δίνουν τα αθροίσματα της κύριας διαγωνίου και της αντιδιαγωνίου; Γράψε τον βρόχο.

> [!success]- Λύση
> `for (int i = 0; i < 3; i++) { tr += z[i][i]; anti += z[i][2-i]; }` → `15 15` (`1+5+9` και `3+5+7`).

### Άσκηση 11

Γράψε `boolean isSymmetric(int[][] a)` (τετραγωνικός, `a[i][j] == a[j][i]` για όλα). Γιατί ο εσωτερικός βρόχος αρκεί να πάει μέχρι `j < i`;

> [!success]- Λύση
> ```java
> static boolean isSymmetric(int[][] a){
>    for (int i = 0; i < a.length; i++)
>       for (int j = 0; j < i; j++)
>          if (a[i][j] != a[j][i]) return false;
>    return true;
> }
> ```
> Κάθε ζεύγος `(i,j)`/`(j,i)` ελέγχεται μία φορά (το κάτω τρίγωνο)· η διαγώνιος ταιριάζει πάντα με τον εαυτό της. `{{1,2},{2,3}}` → `true` · `{{1,2},{0,3}}` → `false`.

### Άσκηση 12

Με την `sum(double[][][])` **με δείκτες** της IX-18 και με την εκδοχή **for-each** της IX-19, τι δίνει ο πίνακας `{{{1,2},{3}},{{4,5,6}}}`; Πώς διορθώνεται η πρώτη;

> [!success]- Λύση
> for-each: `21.0`. Με δείκτες: `ArrayIndexOutOfBoundsException` – χρησιμοποιεί `xsss[0].length` (=2) και `xsss[0][0].length` (=2) για όλα, αλλά η σειρά `{3}` έχει μήκος 1. Διόρθωση: `j < xsss[i].length` και `k < xsss[i][j].length`.

### Άσκηση 13

Γράψε το τρίγωνο του Pascal με **ακανόνιστο** πίνακα: η σειρά `i` έχει `i+1` στοιχεία, άκρα `1`, και κάθε εσωτερικό = άθροισμα των δύο από πάνω. Τι δίνει για 5 σειρές;

> [!success]- Λύση
> ```java
> static int[][] pascal(int n){
>    int[][] t = new int[n][];
>    for (int i = 0; i < n; i++){
>       t[i] = new int[i+1];
>       t[i][0] = t[i][i] = 1;
>       for (int j = 1; j < i; j++) t[i][j] = t[i-1][j-1] + t[i-1][j];
>    }
>    return t;
> }
> ```
> `[[1], [1, 1], [1, 2, 1], [1, 3, 3, 1], [1, 4, 6, 4, 1]]`. Είναι η **επαναληπτική** λύση του προβλήματος που η [[05 - Τρίγωνο του Pascal και Memoization|Ενότητα X]] λύνει αναδρομικά.

## Μέρος Γ — Tic-tac-toe

### Άσκηση 14

Τι τυπώνει η `TicTacToe` (IX-25 … IX-28) για (α) `EEEEEEEEE` (β) `OOOXXXEEE` (γ) `XOEOXEEEX` (δ) `xxxeeeeee` (ε) `XX`;

> [!success]- Λύση
> (α) `Nobody wins!` – όλες οι γραμμές είναι «ίδιες» αλλά `'E'`.
> (β) `Player O wins on row 1` · `Thus there is a winner!!` – το X έχει επίσης σειρά, αλλά η `rWin` σταματά στην πρώτη.
> (γ) `Player X wins on diagonal` · `Thus there is a winner!!` (`[0][0]`, `[1][1]`, `[2][2]`).
> (δ) `Player x wins on row 1` – το `'e'` δεν είναι `'E'`, άρα θεωρείται παίκτης.
> (ε) `StringIndexOutOfBoundsException` στην `charAt(2)`.

### Άσκηση 15

Γενίκευσε την `dWin` για πίνακα N × N. Ποιες άλλες μέθοδοι του `TicTacToe` υποθέτουν 3 × 3;

> [!success]- Λύση
> ```java
> private static boolean dWin(char[][] ttt){
>    int N = ttt.length;
>    char[] d1 = new char[N], d2 = new char[N];
>    for (int i = 0; i < N; i++){ d1[i] = ttt[i][i]; d2[i] = ttt[i][N-1-i]; }
>    if (d1[0] != 'E' && same_elem(d1)) { System.out.println("Player " + d1[0] + " wins on diagonal"); return true; }
>    if (d2[0] != 'E' && same_elem(d2)) { System.out.println("Player " + d2[0] + " wins on antidiagonal"); return true; }
>    return false;
> }
> ```
> Υποθέτουν 3 × 3: η `copy_diag2` (`2-i`), η `cWin` (`new char[3]`), η `main` (`i*3+j`, βρόχοι `< 3`). Η `copy_col` χρησιμοποιεί `table[0].length` ως πλήθος σειρών – σωστό μόνο για τετραγωνικό.

## Μέρος Δ — Περίπατος και ζωή

### Άσκηση 16

Στο `SelfAvoidingWalk` τι γίνεται αν: (α) ο πίνακας `a` δηλωθεί **πριν** τον `for` των προσπαθειών; (β) ο έλεγχος εγκλωβισμού γραφτεί με `||`; (γ) η συνθήκη του `while` γίνει `x >= 0 && x < N && y >= 0 && y < N`;

> [!success]- Λύση
> (α) Οι προσπάθειες «μοιράζονται» το πλέγμα: από τη 2η και μετά ξεκινάς από σημείο ήδη επισκεπτόμενο, με τα ίχνη των προηγούμενων → πολύ περισσότεροι (ψεύτικοι) εγκλωβισμοί (≈ 99% για N = 20, αντί για 32%).
> (β) «Εγκλωβίζομαι» μόλις **ένας** γείτονας είναι επισκεπτόμενος. Μετά την πρώτη κίνηση, ο γείτονας από τον οποίο ήρθα είναι πάντα `true` → **100%** dead ends για N = 20 (ελέγχθηκε).
> (γ) Στο ακραίο σημείο ο βρόχος συνεχίζει και ο έλεγχος `a[x-1][y]` με `x = 0` → `ArrayIndexOutOfBoundsException`.

### Άσκηση 17

Γράψε τον περίπατο σε **τρεις** διαστάσεις (`boolean[N][N][N]`, 6 κατευθύνσεις). Τι ποσοστό εγκλωβισμού περιμένεις σε σχέση με τις δύο διαστάσεις για το ίδιο N;

> [!success]- Λύση
> Συνθήκη `while`: και οι τρεις συντεταγμένες στο `1 … N-2`. Εγκλωβισμός: `a[x±1][y][z] && a[x][y±1][z] && a[x][y][z±1]` (έξι όροι). Κίνηση: `int r = (int)(Math.random() * 6);` και έξι κλάδοι. Προσομοίωση με 5000 προσπάθειες: N = 10 → `0%`, N = 20 → `≈ 1%`, N = 40 → `≈ 5%` (έναντι 5%, 32%, 77% στις δύο διαστάσεις). Με 6 γείτονες είναι πολύ πιο δύσκολο να «κλείσεις» όλες τις εξόδους.

### Άσκηση 18

Σε πλέγμα 3 × 3 όπου **όλα** τα κελιά είναι ζωντανά: πόσους ζωντανούς γείτονες βρίσκει η `live_neighbors` για (α) `[1][1]` (β) `[0][0]` (γ) `[0][1]`; Ποια είναι η επόμενη γενιά;

### Άσκηση 19

Γράψε μία εντολή που αντικαθιστά τους τρεις κλάδους της `nextGen` (IX-41). Πώς θα έλεγχες ότι είναι ισοδύναμη;

> [!success]- Λύση
> `NGen[i][j] = (n == 3) || (Gen[i][j] && n == 2);`

### Άσκηση 20

Γράψε `int[] maxPos(double[][] a)` που επιστρέφει `{σειρά, στήλη}` του μεγαλύτερου στοιχείου (σε ισοπαλία, το πρώτο σε σειρά-σειρά διάσχιση). Τι δίνει για `{{1,7},{7,3},{2}}`;

> [!success]- Λύση
> ```java
> static int[] maxPos(double[][] a){
>    int bi = 0, bj = 0;
>    for (int i = 0; i < a.length; i++)
>       for (int j = 0; j < a[i].length; j++)          // a[i].length: δουλεύει και για ragged
>          if (a[i][j] > a[bi][bj]) { bi = i; bj = j; }
>    return new int[]{bi, bj};                        // δύο έξοδοι → πίνακας
> }
> ```
> `[0, 1]` – το `7` στο `[1][0]` δεν το αντικαθιστά επειδή η σύγκριση είναι αυστηρή (`>`). Με `>=` θα έδινε `[1, 0]`.
