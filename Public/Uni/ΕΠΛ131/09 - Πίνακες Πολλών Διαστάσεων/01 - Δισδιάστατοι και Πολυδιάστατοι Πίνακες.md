# 01 - Δισδιάστατοι και Πολυδιάστατοι Πίνακες

Δήλωση, αρχικοποίηση και πρόσβαση σε πίνακες δύο και τριών διαστάσεων, και το πιο σημαντικό: **πώς είναι στη μνήμη**. Στη Java ένας δισδιάστατος πίνακας είναι **πίνακας από πίνακες** – απευθείας πρόσβαση έχουμε στις **σειρές**, όχι στις στήλες (διαφάνειες IX-1 … IX-9, IX-15 … IX-17, IX-45 … IX-48).

## 1. Από τη μία στις πολλές διαστάσεις (IX-2 … IX-4)

Έχουμε ήδη συζητήσει πίνακες μιας διάστασης ([[Uni/ΕΠΛ131/04 - Πίνακες Μιας Διάστασης/00 - Ευρετήριο|Ενότητα IV]]):
- οι πίνακες αντιπροσωπεύονται από τις **διευθύνσεις** τους,
- λαμβάνονται ως ορίσματα από κλήσεις συναρτήσεων ή/και επιστρέφονται από αυτές ως διευθύνσεις ([[04 - Πίνακες ως Παράμετροι Συναρτήσεων|VIII – 04]]),
- είδαμε παραδείγματα **παράλληλων** πινάκων.

> [!example]- Εφαρμογή: τεχνητή νοημοσύνη βάσει νευρωνικών δικτύων (IX-3, IX-4)
> Ένα απλό νευρωνικό δίκτυο υπολογίζει σε κάθε κόμβο εξόδου `a = f(Σᵢ wᵢ·xᵢ + b)`. Με 4 εισόδους και 3 εξόδους:
> - **πολυδιάστατοι** πίνακες για την αναπαράσταση **βαρών**: `w[3][4]` – το `w[i][j]` είναι το βάρος από την είσοδο `j` στον κόμβο `i`,
> - **μονοδιάστατοι** πίνακες για **διανύσματα**: `x[4]` (είσοδος), `b[3]`, `a[3]` (έξοδος).
>
> Ο υπολογισμός όλων των εξόδων είναι ένας πολλαπλασιασμός πίνακα με διάνυσμα ([[02 - Πράξεις Πινάκων και Διάσπαση ανά Διάσταση|02]]).

## 2. Ορισμός και ρητή αρχικοποίηση (IX-5)

> [!note] Πολυδιάστατος πίνακας
> Ένας πίνακας είναι **πολυδιάστατος** αν έχει δύο ή περισσότερες διαστάσεις. Κάθε διάσταση προσθέτει ένα ζεύγος `[]` στον τύπο.

```java
char[][] tictac = { {'X','O','X'},     // ρητή στατική αρχικοποίηση 3x3
                    {'O','X','O'},
                    {'O','X','X'}
                  };
```

| | Στήλη 0 | Στήλη 1 | Στήλη 2 |
|---|---|---|---|
| **Σειρά 0** | X | O | X |
| **Σειρά 1** | O | X | **O** ← `tictac[1][2]` |
| **Σειρά 2** | O | X | X |

Κάθε εσωτερικό `{…}` είναι **μία σειρά**. Ο **πρώτος** δείκτης διαλέγει σειρά, ο **δεύτερος** στήλη.

## 3. Πρόσβαση: a[i][j] (IX-6)

Χρησιμοποιούμε την έκφραση `a[i][j]` για πρόσβαση στο στοιχείο που βρίσκεται στη **σειρά `i`** και στη **στήλη `j`**. Η αρίθμηση των σειρών και στηλών αρχίζει από το **0**.

```java
int M = 10;
int N = 3;
double[][] a = new double[M][N];
for (int i = 0; i < M; i++) {
   for (int j = 0; j < N; j++) {
      a[i][j] = 0.0;
   }
}
```

Πίνακας **10-επί-3** (10 σειρές, 3 στήλες): `a[0][0]` … `a[9][2]`. Η `a[5]` είναι ολόκληρη η σειρά 5 (`a[5][0]`, `a[5][1]`, `a[5][2]`). Ο διπλός βρόχος είναι εδώ περιττός – το `new double[M][N]` ήδη βάζει `0.0` – αλλά δείχνει το μοτίβο **σειρά-σειρά**: εξωτερικός βρόχος για τις σειρές, εσωτερικός για τις στήλες.

## 4. Αρχικοποίηση καταγράφοντας ρητά τις τιμές (IX-7)

```java
double[][] p =
{
   { .92, .02, .02, .02, .02 },
   { .02, .02, .32, .32, .32 },
   { .02, .02, .02, .92, .02 },
   { .92, .02, .02, .02, .02 },
   { .47, .02, .47, .02, .02 },
};
```

`p[1][3]` = `.32` (σειρά 1, στήλη 3). Το κόμμα μετά την τελευταία σειρά (`},` πριν το `}`) **επιτρέπεται** στη Java.

> [!warning] ➕ Το `{…}` μόνο στη δήλωση (ελέγχθηκε)
> `int[][] a = new int[2][2]; a = {{1,2},{3,4}};` ✗ – η σύντομη μορφή επιτρέπεται **μόνο** στη δήλωση. Μετά γράφεις `a = new int[][]{{1,2},{3,4}};`.

## 5. Τρεις διαστάσεις και προεπιλεγμένες τιμές (IX-8, IX-9)

```java
double[][][] table = new double[7][5][6];
```

1. Ο πίνακας `table` έχει **τρεις διαστάσεις** και σύνολο **210** στοιχεία (`7·5·6`). Οι δείκτες της πρώτης διάστασης είναι `0..6`, της δεύτερης `0..4` και της τρίτης `0..5`.
2. `table[2][3][4]` σημαίνει το στοιχείο με δείκτη 2 στην πρώτη διάσταση (δηλαδή το **τρίτο** σε σειρά), δείκτη 3 στη δεύτερη και δείκτη 4 στην τρίτη.
3. Όλα τα στοιχεία αρχικοποιούνται αυτόματα στην τιμή `0.0`.

```java
int N = 5;
String[][][] a = new String[N][N][N];
//default value for string table element is null
// null is a literal
```

```java
int N = 5;
String[][][] a = new String[N][N][N];

for (int i = 0; i < N; i++) {
   for (int j = 0; j < N; j++) {
      for (int k = 0; k < N; k++) {
         a[i][j][k]= ""; //empty string is not same as a[i][j][k]=null;
      }
   }
}
```

| Τύπος στοιχείων | Προεπιλεγμένη τιμή |
|---|---|
| `int`, `long`, … | `0` |
| `double` | `0.0` |
| `boolean` | `false` |
| `char` | `'\u0000'` (ο χαρακτήρας με κωδικό 0 – **όχι** κενό, **όχι** `'E'`) |
| `String` (κάθε αναφορά) | **`null`** |

> [!warning] `""` ≠ `null`
> `""` είναι **υπαρκτό** `String` μήκους 0: `a[i][j][k].length()` → `0`. `null` σημαίνει «καμία συμβολοσειρά»: `a[i][j][k].length()` → `NullPointerException`. Και `"".equals(null)` → `false` (ελέγχθηκε) ([[02 - Συμβολοσειρές ως Δείκτες και Σύγκριση|VI – 02]]).

> [!warning] ⚠️ Σημείωση για τη IX-9
> Στον δεύτερο κώδικα της διαφάνειας λείπει ένα `}`: ανοίγουν τρία μπλοκ `for` και κλείνουν δύο. Ο κώδικας παραπάνω έχει το τρίτο `}`.

## 6. Πώς είναι στη μνήμη: πίνακας από πίνακες (IX-15, IX-45 … IX-48)

```java
int[][] table = new int[3][3];
```

![[Πίνακες 2Δ - Πίνακας από Πίνακες.png|800]]

> [!important] Η δομή
> - Η μεταβλητή `table` περιέχει τη **διεύθυνση** ενός μονοδιάστατου πίνακα **3 αναφορών**.
> - Καθεμία από τις `table[0]`, `table[1]`, `table[2]` περιέχει τη διεύθυνση μιας **σειράς**: ενός μονοδιάστατου `int[]` με 3 στοιχεία.
> - Τα `table[i][j]` είναι οι ακέραιοι.
>
> | Έκφραση | Τύπος | Τι είναι |
> |---|---|---|
> | `table` | `int[][]` | διεύθυνση του πίνακα των σειρών |
> | `table[i]` | `int[]` | διεύθυνση της σειράς `i` |
> | `table[i][j]` | `int` | ο ακέραιος |
> | `table.length` | `int` | **πλήθος σειρών** |
> | `table[0].length` | `int` | **πλήθος στηλών** (της σειράς 0) |

Για τρεις διαστάσεις (IX-46), `int[][][] table = new int[3][3][3];`:

| Στοιχεία | Τύπος | Μήκος |
|---|---|---|
| πρώτης διάστασης (`table[i]`) | `int[][]` – πίνακες δύο διαστάσεων (**συστάδες**) | `table.length` = πλήθος συστάδων |
| δεύτερης (`table[i][j]`) | `int[]` – πίνακες μιας διάστασης | `table[0].length` = σειρές κάθε συστάδας |
| τρίτης (`table[i][j][k]`) | `int` – ατομικά στοιχεία | `table[0][0].length` = στήλες κάθε συστάδας |

> [!warning] ⚠️ Σημείωση για τις IX-15 και IX-48
> Οι διαφάνειες γράφουν ότι το `table` «ισοδυναμεί με τη διεύθυνση του πρώτου στοιχείου (`table[0][0]`)» και ότι οι τιμές των `table`, `table[0]` και `table[0][0]` «ταυτίζονται». Αυτό ισχύει για τους πίνακες της **C**, όπου ο δισδιάστατος πίνακας είναι ένα συνεχές μπλοκ μνήμης. **Στη Java όχι**: το `table` δείχνει στον πίνακα των **αναφορών** των σειρών, το `table[0]` δείχνει στη **σειρά 0** – δύο διαφορετικά αντικείμενα σε διαφορετικές θέσεις – και το `table[0][0]` (για `int`) δεν είναι καν διεύθυνση, είναι ο ακέραιος. Τα σχήματα της IX-45 και IX-47, με τα ξεχωριστά κουτιά αναφορών, είναι τα σωστά. Η ουσία της διαφάνειας («η πρόσβαση γίνεται σειρά-σειρά») ισχύει.

## 7. Σειρές και στήλες: επισημάνσεις για τους τύπους (IX-16, IX-17)

```java
int[][] tabA = new int[1][5];
int[] tabB = new int[5];
```

> [!note] Διαφορετικοί τύποι
> - Ο `tabA` είναι **δύο** διαστάσεων αλλά περιέχει μόνο **μία σειρά** με πέντε στοιχεία.
> - Ο `tabB` είναι **μιας** διάστασης και περιέχει πέντε στοιχεία (είναι μια ατομική σειρά με πέντε στοιχεία).
> - Όμως ο (μονοδιάστατος) πίνακας **`tabA[0]` έχει τον ίδιο τύπο με τον `tabB`**: `tabB = tabA[0];` κάνει compile.
>
> **Σημ.:** Βεβαίως θα πρέπει να υπάρχει ειδικός λόγος για να οριστεί πίνακας δύο διαστάσεων όπου η εξωτερική διάσταση είναι μόνο ένα (1) στοιχείο.

```java
int[][] tabA = new int[5][1];
int[] tabB = new int[5];
```

> [!note] Πέντε σειρές με ένα στοιχείο
> - Ο `tabA` έχει **πέντε σειρές**, όπου η κάθε σειρά έχει **ένα μόνο** στοιχείο: ουσιαστικά είναι μια **στήλη**.
> - **Απευθείας πρόσβαση έχουμε μόνο στις σειρές**: δεν υπάρχει έκφραση που να δίνει «τη στήλη 0» ως πίνακα.
> - Ο `tabB` είναι όπως προηγουμένως: μιας διάστασης, πέντε στοιχεία (ουσιαστικά μια σειρά).
> - Οι πίνακες `tabA[0]` (σειρά από **ένα** στοιχείο) και `tabB` (σειρά από **πέντε**) δεν έχουν την ίδια μορφή.
>
> **⚠️ Σημείωση:** η IX-17 γράφει ότι `tabA[0]` και `tabB` «δεν είναι του ίδιου τύπου». Για τη Java **είναι** (και οι δύο `int[]`)· ο τύπος δεν περιλαμβάνει το μήκος, άρα `tabB = tabA[0];` κάνει compile και εδώ (ελέγχθηκε). Διαφέρουν μόνο στο **μήκος** (1 έναντι 5).

![[Πίνακες 2Δ - tabA και tabB.png|800]]

| Δήλωση | `.length` | `[0].length` | Σχήμα |
|---|---|---|---|
| `new int[1][5]` | 1 | 5 | μία σειρά |
| `new int[5][1]` | 5 | 1 | μία «στήλη» από 5 σειρές |
| `new int[5]` | 5 | – | μονοδιάστατος |

## 8. ➕ Ακανόνιστοι (ragged) πίνακες

Αφού κάθε σειρά είναι ξεχωριστός πίνακας, οι σειρές **δεν** χρειάζεται να έχουν ίδιο μήκος.

```java
int[][] r = { {1}, {2, 3}, {4, 5, 6} };   // τριγωνικός
int[][] t = new int[3][];                 // μόνο ο πίνακας των σειρών· t[0] == null
for (int i = 0; i < 3; i++) t[i] = new int[i + 1];
```

![[Πίνακες 2Δ - Ακανόνιστος Πίνακας και clone.png|800]]

> [!warning] Παγίδες (ελέγχθηκαν)
> - `r.length` → `3`, `r[0].length` → `1`, `r[2].length` → `3`: το `[0].length` **δεν** είναι το πλήθος στηλών όλου του πίνακα. Σε ακανόνιστο πίνακα ο εσωτερικός βρόχος πρέπει να γράφεται `j < r[i].length`.
> - `new int[3][]`: οι σειρές είναι **`null`** μέχρι να φτιαχτούν· `t[1].length` → `NullPointerException`.
> - `int[][] w = {{1,2},{3}}; w[1][1]` → `ArrayIndexOutOfBoundsException: Index 1 out of bounds for length 1`.
> - `new int[][3]` ✗ – η **πρώτη** διάσταση δίνεται πάντα· οι επόμενες μπορούν να λείπουν. Ούτε `new int[3,3]` ούτε `int a[3][3];` (σύνταξη C) επιτρέπονται.
> - `int[] x[]` είναι νόμιμο (= `int[][] x`) αλλά μπερδευτικό.

## 9. ➕ Εκτύπωση, σύγκριση, αντιγραφή

> [!warning] Ό,τι ίσχυε για τις αναφορές ισχύει σε κάθε επίπεδο (ελέγχθηκαν)
>
> | Κώδικας | Αποτέλεσμα |
> |---|---|
> | `System.out.println(r)` | `[[I@1b6d3586` – η διεύθυνση, όχι τα στοιχεία |
> | `Arrays.toString(r)` | `[[I@…, [I@…, [I@…]` – τυπώνει τις διευθύνσεις των σειρών |
> | `Arrays.deepToString(r)` | `[[1], [2, 3], [4, 5, 6]]` ✓ |
> | `Arrays.equals(h, new int[2][3])` | `false` – συγκρίνει τις **αναφορές** των σειρών |
> | `Arrays.deepEquals(h, new int[2][3])` | `true` ✓ |
> | `int[][] c = r.clone(); c[0][0] = 99;` | **αλλάζει και το `r[0][0]`**: το `clone` αντιγράφει μόνο τον πίνακα των σειρών (ρηχό αντίγραφο), `c[0] == r[0]` |
> | `int[] tmp = r[0]; r[0] = r[2]; r[2] = tmp;` | αντιμετάθεση **σειρών** σε O(1): αλλάζουν μόνο δύο αναφορές |
> | `p[1] = p[0]; p[1][1] = 9;` με `p = {{1,2},{3,4}}` | `[[1, 9], [1, 9]]` – δύο σειρές δείχνουν στον **ίδιο** πίνακα |
>
> Πλήρες (βαθύ) αντίγραφο: νέος πίνακας σειρών **και** νέα κάθε σειρά: `c[i] = r[i].clone();` για κάθε `i`.

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Σύγχυση σειράς/στήλης: `a[i][j]` = σειρά `i`, στήλη `j`· `a.length` = σειρές.
> - `a[0].length` ως πλήθος στηλών σε ακανόνιστο πίνακα.
> - `new int[][3]`, `new int[3,3]`, `int a[3][3]`.
> - Πίστη ότι `table`, `table[0]` και `&table[0][0]` είναι η ίδια διεύθυνση (ισχύει στη C, όχι στη Java).
> - Ρηχό αντίγραφο με `clone()` και έκπληξη όταν αλλάζει το πρωτότυπο.
> - `""` αντί για `null` (ή αντίστροφα) στους πίνακες `String`.
> - `println(a)` για εκτύπωση των στοιχείων.
