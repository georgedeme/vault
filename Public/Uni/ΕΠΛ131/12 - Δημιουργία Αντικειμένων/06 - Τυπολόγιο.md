# 06 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την **Ενότητα XII – Δημιουργία Αντικειμένων**.

## 1. Ανατομία κλάσης & Κατασκευαστές (XII-2, XII-18 … XII-28)

```java
public class MyClass {
    private int x;                        // instance variable (private → ενθυλάκωση)
    public static final double K = 8.99;  // static σταθερά (κοινή σε όλα τα αντικείμενα)

    public MyClass()        { this(0); }  // no-args constructor καλεί άλλον (1η εντολή!)
    public MyClass(int x)   { this.x = x; } // this.x ξεχωρίζει πεδίο από παράμετρο
    public MyClass(MyClass o){ x = o.x; } // copy constructor (πρόσβαση σε o.x επιτρέπεται!)
}
```

- **Κατασκευαστής**: όνομα == όνομα κλάσης, **χωρίς return type (ούτε `void`)**.
- **Default no-args constructor** (`ClassName() { }`): δίνεται αυτόματα **μόνο** αν ΔΕΝ ορίσεις κανέναν κατασκευαστή. Μόλις ορίσεις έστω έναν με ορίσματα → **χάνεται**!
- **Overloading** (μέθοδοι & κατασκευαστές ίδιας κλάσης): ίδιο όνομα, **διαφορετικός αριθμός ή/και τύποι παραμέτρων**. Μόνο διαφορετικός τύπος επιστροφής (`returnType`) ή `public`/`private` **ΔΕΝ** είναι overloading → compile error.
- **Τελεστής `new`**: δεσμεύει μνήμη, καλεί κατασκευαστή, επιστρέφει **αναφορά (διεύθυνση)**.
- **Java style**: `camelCase`, ρήματα, `get...()` (accessor), `set...(...)` (mutator).

## 2. `static` (Class) vs Non-Static (`Instance`) (XII-29 … XII-35)

| Χαρακτηριστικό | `static` (κλάσης) | Non-static (`instance`) |
|---|---|---|
| Αντίγραφα στη μνήμη | **1** (με τον κώδικα της κλάσης) | **1 ανά αντικείμενο** |
| Κλήση / πρόσβαση | `ClassName.member` | `objName.member` |
| Πρόσβαση σε `static` μέλη | ✓ ΝΑΙ | ✓ ΝΑΙ |
| Πρόσβαση σε `instance` μέλη / `this` | **✗ ΟΧΙ (Compile Error!)** | ✓ ΝΑΙ |

- Η `main` είναι **`static`** → δεν βλέπει non-static πεδία/μεθόδους χωρίς `new` (`MyClass m = new MyClass(); m.run();`).
- Κλάσεις μόνο με `static` μέλη (`Math`, `System`): δεν έχουν `public` κατασκευαστή (`new Math()` → error).

## 3. Ενθυλάκωση, `private` & `this` (XII-36 … XII-40)

- **Ενθυλάκωση**: πεδία και βοηθητικές μέθοδοι **`private`** · διεπαφή (κατασκευαστές + βασικές μέθοδοι) **`public`**.
- **Κανόνας `private`**: ισχύει ανά **κλάση**, όχι ανά αντικείμενο! Μέσα στη `Fraction.multiply(Fraction other)` επιτρέπεται το `other.num`.
- **Οι 3 χρήσεις του `this`** (μόνο σε non-static μεθόδους / κατασκευαστές):
  1. `this.field` (διάκριση από παράμετρο ίδιου ονόματος — shadowing).
  2. `this(...)` (κλήση άλλου κατασκευαστή — **πρέπει να είναι η 1η εντολή**).
  3. `this` ως όρισμα (π.χ. `System.out.println(this)` → καλεί αυτόματα `toString()`).

## 4. Αναφορές, Aliasing, Πίνακες Αντικειμένων & `PassByValue` (XII-48, XII-57 … XII-73)

- **Aliasing**: `b2 = b1;` αντιγράφει τη **διεύθυνση**, όχι το αντικείμενο → `b1 == b2` είναι `true`, και `b2.move()` μετακινεί **και** το `b1`. Το παλιό αντικείμενο του `b2` συλλέγεται από τον **Garbage Collector**.
- **Πίνακας αντικειμένων** (2 βήματα!):
  ```java
  Ball[] a = new Ball[N];                 // 1. N αναφορές null
  for (int i = 0; i < N; i++) a[i] = new Ball(); // 2. N αντικείμενα (αλλιώς NullPointerException!)
  ```
- **Πέρασμα δια τιμής (`PassByValue`, XII-73)** — **πάντα** pass-by-value:

| Τύπος ορίσματος | Τι περνάει | Αλλαγή μέσα στη μέθοδο | Φαίνεται στον καλούντα; |
|---|---|---|---|
| Βασικός (`int a`) | αντίγραφο τιμής | `a = 7;` | **ΟΧΙ** |
| Πίνακας/αντικείμενο (`int[] b`) | αντίγραφο διεύθυνσης | `b[3] = 7;` (περιεχόμενο) | **ΝΑΙ** |
| Πίνακας/αντικείμενο (`String c`) | αντίγραφο διεύθυνσης | `c = "seven";` (ανακατεύθυνση) | **ΟΧΙ** |

## 5. Immutability, `toString()` & `equals()` (XII-5, XII-6, XII-42 … XII-46)

- **Immutable αντικείμενο** (`Charge`, `String`, `Color`): `private final` πρωτογενή πεδία, χωρίς mutators.
- **`toString()`**: καλείται αυτόματα από `println(obj)` και `"" + obj`. Πρέπει να **επιστρέφει** `String`. Χωρίς αυτή τυπώνει `ClassName@hex`.
- **`equals()`**: συγκρίνει περιεχόμενο (ενώ `==` συγκρίνει διευθύνσεις).

## 6. Παγίδες των διαφανειών (⚠️)

- **XII-8**: επιπλέον `}` στη `GLife.toString()`. · **XII-13/14**: `'O’` και κεφαλαίο `Player` στη `TicTacToe`.
- **XII-28**: `Fraction f;` είναι `null` μόνο ως **πεδίο**, όχι ως τοπική μεταβλητή.
- **XII-32**: `System.exit(0);` (όχι `System.exit();`).
- **XII-44**: `Charge` έχει `8.9e9`, `pottentialAt`, παρενθέσεις στη `Euclidean`, `System.println` στη `toString()`, και `static` αντί **`final`** στο σχόλιο immutability (σωστή εκδοχή: **XII-46**).
- **XII-68**: `rx == bs[i].rx` συγκρίνει `double` με `==`.
