# 07 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα VI.

## 1. Το `String`

| Έννοια | Σε μία γραμμή |
|---|---|
| ΑΤΔ | γνωρίζουμε μόνο το **«τι»** (διεπαφή), όχι το «πώς» · απόκρυψη πληροφοριών → ευελιξία |
| Τύπος δεδομένων | σύνολο τιμών + λειτουργίες |
| Μέθοδος αναφοράς | `s.length()` ✓ · `String.length()` ✗ |
| Κατασκευαστής | `new String("foo")` → **νέο** αντικείμενο, επιστρέφει διεύθυνση |
| Μεταβλητή `String` | **δείκτης** (όπως οι πίνακες) |
| Αμετάβλητο | καμία μέθοδος δεν αλλάζει το string· `s += t` → **νέο** αντικείμενο |

## 2. Μέθοδοι (με `s = "hello"`)

| Κλήση | Τιμή | Προσοχή |
|---|---|---|
| `s.length()` | `5` | **με** `()` – πίνακας: `a.length` |
| `s.charAt(1)` | `'e'` | `charAt(5)` → `StringIndexOutOfBoundsException` |
| `s.substring(1, 3)` | `"el"` | **χωρίς** το `3` · `substring(5)` → `""` |
| `s.indexOf("l")` / `indexOf("l", 3)` | `2` / `3` | δεν βρέθηκε → **`-1`** |
| `s.contains("ell")` | `true` | `contains("")` → `true` |
| `s.startsWith("he")` / `endsWith("lo")` | `true` / `true` | διάκριση κεφαλαίων |
| `s.equals("hello")` | `true` | `s.equals(null)` → `false` |
| `s.compareTo(t)` | `<0`, `0`, `>0` | πρώτη διαφορά: διαφορά κωδικών · πρόθεμα: διαφορά μηκών |
| `s.toUpperCase()` | `"HELLO"` | **επιστρέφει** νέο – `s` ίδιο |
| `s.concat("!")` | `"hello!"` | `concat(null)` → NPE · `s + null` → `"hellonull"` |
| `s.repeat(2)` | `"hellohello"` | Java 11+ |
| `"a,b".split(",")` | `{"a", "b"}` | **regex**: `split(".")` → `{}` |
| `"a.b".replaceAll(".", "-")` | `"---"` | regex · `replace` όχι regex |
| `" x ".strip()` / `"  ".isBlank()` | `"x"` / `true` | `"  ".isEmpty()` → `false` |

## 3. Σύγκριση

| Κώδικας | Ελέγχει |
|---|---|
| `s1 == s2` | ίδιο **αντικείμενο** (δείκτης) |
| `s1.equals(s2)` | ίδιοι **χαρακτήρες** |
| `s1.compareTo(s2) < 0` | `s1` πριν το `s2` λεξικογραφικά (`s1 < s2` ✗ compile) |
| `"lit".equals(s)` | ασφαλές αν `s == null` |

| Δημιουργία | `== "java"` |
|---|---|
| `"java"`, `"ja" + "va"` | `true` (κυριολεκτικά/σταθερές) |
| `new String("java")`, `e += "va"`, `substring(…)` | `false` |

Σειρά: `"" < "Zebra" < "apple"` · `"10" < "9"` · `"abc" < "abcd"` · `"b" > "aaaa"`

## 4. Δείκτες και `null`

| Κώδικας | Αποτέλεσμα |
|---|---|
| `s2 = new String(s1)` | 2 αντικείμενα · `==` false · `equals` true |
| `s2 = s1` | 1 αντικείμενο · `==` true |
| τοπική `String s; s += "x";` | ✗ compile: might not have been initialized |
| `String s = null; s += "x";` | `"nullx"` |
| `s.equals(…)` με `s == null` | `NullPointerException` |
| `a = "x"; b = a; a += "y";` | `a = "xy"`, `b = "x"` |

## 5. Είσοδος/Έξοδος

| `StdIn` | Διαβάζει |
|---|---|
| `isEmpty()` | `true` αν δεν απομένει **λέξη** |
| `readString()` | επόμενη λέξη (μη κενοί χαρακτήρες) |
| `readLine()` | υπόλοιπο γραμμής, χωρίς `'\n'` |
| `readAll()` | υπόλοιπο κειμένου, με τα `'\n'` |
| `readInt()` … | τιμή του τύπου · μετά από αυτή η `readLine()` → `""` |

`java Prog arg1 arg2 < in.txt > out.txt` · `java A | java B` · `StdOut` ≡ `System.out` · όλα `static`

## 6. Αλγόριθμοι – μοτίβα

| Πρόγραμμα | Πυρήνας | Παγίδα |
|---|---|---|
| Παλινδρομικό | `for (i < N/2) if (s.charAt(i) != s.charAt(N-1-i)) return false;` | κεφαλαία, κενά |
| Επέκταση | `dot = s.indexOf("."); s.substring(0, dot); s.substring(dot+1)` | `-1` · πρώτη τελεία |
| Γραμμές | `while (!StdIn.isEmpty()) { StdIn.readLine(); count++; }` | κενές γραμμές στο **τέλος** δεν μετράνε |
| Λέξεις | `beg` = μέσα σε λέξη · `beg && κενό` → `wordCount++` · στο τέλος `if (beg) wordCount++` | η τελευταία λέξη της γραμμής |
| Γονίδιο | `for (i < len-2) codon = substring(i, i+3)` · start → `beg = i` · stop && `beg != -1` → `gene = substring(beg+3, i)`, αν `% 3 == 0` τύπωσε, `beg = -1` | `equals` όχι `==` · μη πολλ. του 3 → `beg` μένει · κενό γονίδιο τυπώνεται |
| Πυραμίδα | γραμμή `i`: `h−i` κενά + `2i−1` χαρ. (+ `h−i` κενά) · βάση `2h−1` | `s += ' ' + c` → αριθμός |
| `add` | νέος πίνακας `length+1`, `nts[0] = s`, `nts[i+1] = ts[i]` | `tab = add(tab, s)` · αντίστροφη σειρά |
| `select`/`remove` | `contains` / `!contains` → `add` | επιστρέφει `null` αν δεν βρει |
| `reverse` | `for (i=0, j=len-1; i < j; i++, j--) swap` | `void`, επιτόπου |

> [!warning] Οι «παγίδες» σε μια ματιά
> - `==` σε `String` → πάντα `equals` (το `==` «πετυχαίνει» μόνο με κυριολεκτικά)
> - `s.toUpperCase();` χωρίς `s =` → τίποτα
> - `s.charAt(0) = 'x'` ✗ · `String.length()` ✗ · `s.length` ✗ · `s1 < s2` ✗
> - `substring(i, j)` δεν περιλαμβάνει το `j` · `"Another string".substring(0,8)` = `"Another "` (με κενό)
> - `indexOf` → `-1` → `substring(0, -1)` → exception
> - `split(".")` → κενός πίνακας
> - `' ' + 'x'` = `152`
> - τυπογραφικά εισαγωγικά `“ ”` στις διαφάνειες ✗ compile
> - η `substring` στη σημερινή Java αντιγράφει (⚠️ VI-15)
> - `TabLib`: `tab` ανάποδα, `select` ξανά-αντιστρέφει → σωστή σειρά στην έξοδο
