# 05 - Διακριτά Σχήματα και Αρθρωτότητα

Πυραμίδες από χαρακτήρες: το ίδιο πρόγραμμα γραμμένο αρθρωτά (με μεθόδους που επιστρέφουν `String`) και μη αρθρωτά, και γιατί η αρθρωτή εκδοχή επεκτείνεται ευκολότερα (διαφάνειες VI-26 … VI-31).

## 1. Το πρόβλημα (VI-26)

```
$ java Pyramid 5 x
    x
   xxx
  xxxxx
 xxxxxxx
xxxxxxxxx
```
```
$ java Pyramid 7 o                $ java Pyramid 9 p
      o                                   p
     ooo                                 ppp
    ooooo                               ppppp
   ooooooo                             ppppppp
  ooooooooo                           ppppppppp
 ooooooooooo                         ppppppppppp
ooooooooooooo                       ppppppppppppp
                                   ppppppppppppppp
                                  ppppppppppppppppp
```

Ορίσματα: `args[0]` = ύψος `h`, `args[1]` = ο χαρακτήρας.

> [!important] Η γεωμετρία μιας πυραμίδας ύψους `h`
> Στη γραμμή `i` (από `1` έως `h`):
> - **`h − i`** κενά,
> - **`2i − 1`** χαρακτήρες.
>
> Η βάση (γραμμή `h`) έχει **`2h − 1`** χαρακτήρες.

![[Πυραμίδα - Γραμμή r.png|800]]

| `h = 5`, γραμμή `i` | κενά `h − i` | χαρακτήρες `2i − 1` |
|---|---|---|
| 1 | 4 | 1 |
| 2 | 3 | 3 |
| 3 | 2 | 5 |
| 4 | 1 | 7 |
| 5 | 0 | 9 |

## 2. Αρθρωτή λύση (VI-27)

```java
public class Pyramid {

 public static String line (int len, char c){
   String s = "";
   for (int i = 1; i <= len; i++) s += c;
   return s;
 }

 public static String pyrRow (int h, int r, char c){
  return line(h-r, ' ') + line(2*r - 1, c) + line(h-r, ' ');
 }

 public static String drawPyr (int h, char c){
  String s = "";
  for (int i = 1; i <= h; i++) s += pyrRow(h,i,c) + "\n";
  return s;
 }

 public static void main (String[] args){
  int h = Integer.parseInt(args[0]);
  char c = args[1].charAt(0);
  System.out.println(drawPyr(h,c));
 }
}
```

| Μέθοδος | Επιστρέφει | Παράδειγμα (`·` = κενό) |
|---|---|---|
| `line(len, c)` | `len` φορές τον χαρακτήρα `c` | `line(3, 'x')` → `"xxx"` · `line(0, 'x')` → `""` |
| `pyrRow(h, r, c)` | τη γραμμή `r`: κενά + χαρακτήρες + κενά | `pyrRow(4, 2, '*')` → `"··***··"` |
| `drawPyr(h, c)` | ολόκληρη την πυραμίδα, γραμμές χωρισμένες με `"\n"` | `drawPyr(2, 'o')` → `"·o·\nooo\n"` |
| `main` | – (τυπώνει) | διαβάζει `h` και `c` από τα `args` |

> [!note] Σημεία στον κώδικα
> - `s += c` με `s` τύπου `String` και `c` τύπου `char`: συνένωση, το `c` γίνεται string. Δουλεύει επειδή ο **αριστερός** τελεστέος είναι ήδη `String`.
> - `args[1].charAt(0)`: τα ορίσματα είναι `String`· παίρνουμε τον πρώτο χαρακτήρα (`java Pyramid 3 xyz` → χρησιμοποιεί μόνο το `'x'`).
> - `Integer.parseInt(args[0])`: μετατροπή `String` → `int` (στατική μέθοδος της `Integer`).
> - Καμία μέθοδος εκτός της `main` δεν τυπώνει: **κατασκευάζουν** strings και τα **επιστρέφουν**. Αυτό τις κάνει επαναχρησιμοποιήσιμες (§5).

> [!warning] Η κενή γραμμή στο τέλος της εξόδου
> Η `drawPyr` βάζει `"\n"` μετά από **κάθε** γραμμή, και η `println` προσθέτει άλλη μία αλλαγή γραμμής. Άρα η έξοδος τελειώνει με μια **κενή γραμμή** (ελέγχθηκε). Με `System.out.print(drawPyr(h, c))` δεν θα υπήρχε.

## 3. Ιεραρχική δομή (VI-28)

![[Πυραμίδα - Ιεραρχία Μεθόδων.png|800]]

> [!important] Οι έννοιες της διαφάνειας
> | Έννοια | Στο `Pyramid` |
> |---|---|
> | **Ανάλυση Προβλήματος** | «πυραμίδα» = `h` γραμμές· γραμμή = κενά + χαρακτήρες + κενά |
> | **Διάσπαση και σύνθεση** | `drawPyr` σπάει το πρόβλημα σε γραμμές και τις **συνθέτει** με `+` |
> | **Διαίρει και Βασίλευε** | κάθε μέθοδος λύνει ένα **μικρότερο** υποπρόβλημα (πυραμίδα → γραμμή → ακολουθία χαρακτήρων) |
> | **Ιεραρχική Δομή** | `main` → `drawPyr` → `pyrRow` → `line` |
> | **Επαναχρησιμοποίηση** | η `line` καλείται για κενά **και** για χαρακτήρες (3 φορές ανά γραμμή) |
>
> Σύνδεση με τις [[01 - Αφαιρετικότητα, DRY και Απλότητα|αρχές της Ενότητας V]]: Abstraction, DRY, Single Responsibility.

## 4. Το ίδιο πρόγραμμα χωρίς άρθρωση (VI-29, VI-30)

**Τυπώνει απευθείας (VI-29):**
```java
public class Pyramid {

 public static void main (String[] args){
   int h = Integer.parseInt(args[0]);
   char c = args[1].charAt(0);

   for (int r = 1; r <= h; r++){
     for (int j = 1; j <= h-r; j++) System.out.print(' ');
     for (int j = 1; j <= 2*r-1; j++) System.out.print(c);
     System.out.print('\n');
   }
 }
}
```

**Χτίζει ένα `String` και το τυπώνει μία φορά (VI-30):**
```java
public class Pyramid {

 public static void main (String[] args){
   int h = Integer.parseInt(args[0]);
   char c = args[1].charAt(0);
   String s = "";
   for (int r = 1; r <= h; r++){
     for (int j = 1; j <= h-r; j++) s += ' ';
     for (int j = 1; j <= 2*r-1; j++) s += c;
     s +='\n';
   }
   System.out.print(s);
 }
}
```

> [!warning] ⚠️ Σημείωση
> Στη VI-30 οι γραμμές `String s = “”;` και ``s += ` `;`` είναι γραμμένες με τυπογραφικά εισαγωγικά/backticks. Σωστά: `String s = "";` και `s += ' ';`.

| | Αρθρωτό (VI-27) | Μη αρθρωτό (VI-29) | Μη αρθρωτό με `String` (VI-30) |
|---|---|---|---|
| Τυπώνει | μία φορά, στη `main` | χαρακτήρα-χαρακτήρα | μία φορά, στο τέλος |
| Κενά **δεξιά** | ναι (`line(h-r, ' ')` στο τέλος) | όχι | όχι |
| Κενή γραμμή στο τέλος | ναι (`println`) | όχι | όχι (`print`) |
| Επαναχρησιμοποίηση | `line`, `pyrRow` χρησιμοποιούνται αλλού | καμία | καμία |
| Ορατή έξοδος | ίδια | ίδια | ίδια |

> [!warning] Παγίδα: `char + char` στην «κατασκευή με `String`»
> ```java
> String s = "";
> char c = 'x';
> s += ' ' + c;          // s = "152"  (!)  – ' ' + 'x' = 32 + 120 = 152, int
> s += " " + c;          // ✓ " x"
> s += ' '; s += c;      // ✓ " x"
> System.out.print(' ' + c);   // τυπώνει 152
> ```
> Το `+=` αποτιμά πρώτα το δεξί μέλος· εκεί δεν υπάρχει `String`, άρα γίνεται αριθμητική πρόσθεση κωδικών ([[05 - String και char#6. «Αριθμητική» με χαρακτήρες ➕|II – 05 §6]]).

> [!warning] Τι γίνεται με «περίεργα» ορίσματα (ελέγχθηκε)
> | Εντολή | Αποτέλεσμα |
> |---|---|
> | `java Pyramid 3` | ✗ `ArrayIndexOutOfBoundsException: Index 1 out of bounds for length 1` (λείπει το `args[1]`) |
> | `java Pyramid 0 x` | μόνο μια κενή γραμμή (`drawPyr` → `""`, η `println` αλλάζει γραμμή) |
> | `java Pyramid 3 xyz` | πυραμίδα από `x` |
> | `java Pyramid x 3` | ✗ `NumberFormatException: For input string: "x"` |
> | `java Pyramid -2 x` | καμία πυραμίδα: ο βρόχος `i <= h` δεν εκτελείται |

> [!info]- ➕ Κόστος του `s += …` σε βρόχο
> Επειδή τα strings είναι [[02 - Συμβολοσειρές ως Δείκτες και Σύγκριση#1. Δημιουργία αλλά όχι τροποποίηση (VI-6)|αμετάβλητα]], κάθε `s += c` φτιάχνει **νέο** string αντιγράφοντας όλους τους χαρακτήρες του παλιού. Για μια πυραμίδα με συνολικά N χαρακτήρες αυτό κάνει περίπου N²/2 αντιγραφές. Για τα μεγέθη του μαθήματος δεν φαίνεται. Η Java έχει για τον σκοπό αυτό την κλάση `StringBuilder` (μεταβλητό «string» με `append`), εκτός ύλης εδώ.

## 5. Ποιο επεκτείνεται ευκολότερα; (VI-31)

> [!question] Η ερώτηση της διαφάνειας
> Ποιο από τα δύο προγράμματα (αρθρωτό ή μη αρθρωτό) θα μπορούσε πιο εύκολα να επεκταθεί/τροποποιηθεί για να μπορεί να κάνει τα ακόλουθα διακριτά σχήματα, **ή οποιοδήποτε συνδυασμό αυτών**;
> ```
>    x      x      x      x
>   xxx    xxx    xxx    xxx
>  xxxxx  xxxxx  xxxxx  xxxxx
> xxxxxxxxxxxxxxxxxxxxxxxxxxxx
>
> ooooooooo     o     ooooooooo
>  ooooooo     ooo     ooooooo
>   ooooo     ooooo     ooooo
>    ooo     ooooooo     ooo
>     o     ooooooooo     o
>
>       +      +++++++++++++      +      +++++++++++++
>      + +      +         +      + +      +         +
>     +   +      +       +      +   +      +       +
>    +     +      +     +      +     +      +     +
>   +       +      +   +      +       +      +   +
>  +         +      + +      +         +      + +
> +++++++++++++      +      +++++++++++++      +
> ```

> [!success]- Απάντηση
> Το **αρθρωτό**. Κάθε σχήμα είναι γραμμές που **συντίθενται οριζόντια** από γραμμές πυραμίδων (κανονικών, ανεστραμμένων, κούφιων). Επειδή η `pyrRow` επιστρέφει κάθε γραμμή ως `String` **σταθερού πλάτους** `2h − 1` (με κενά **και δεξιά**), οι γραμμές «κολλάνε» σωστά με απλό `+`. Στο μη αρθρωτό πρόγραμμα η εκτύπωση είναι μπλεγμένη με τον υπολογισμό, οπότε κάθε νέο σχήμα σημαίνει νέους φωλιασμένους βρόχους από την αρχή.
>
> ![[Πυραμίδα - Οριζόντια Σύνθεση.png|800]]

> [!example]- Λύση και των τριών σχημάτων (ελέγχθηκε – δίνει ακριβώς την παραπάνω έξοδο)
> Προσθέτουμε στην κλάση `Pyramid` τρεις μικρές μεθόδους που ξαναχρησιμοποιούν τις `line` και `pyrRow`:
> ```java
> public static String invRow(int h, int r, char c) {          // ανεστραμμένη: η γραμμή r είναι η h−r+1 της κανονικής
>     return pyrRow(h, h - r + 1, c);
> }
>
> public static String hollowRow(int h, int r, char c) {       // κούφια: μόνο το περίγραμμα
>     if (r == 1 || r == h) return pyrRow(h, r, c);             // κορυφή και βάση γεμάτες
>     return line(h - r, ' ') + c + line(2 * r - 3, ' ') + c + line(h - r, ' ');
> }
>
> public static String hollowInvRow(int h, int r, char c) {
>     return hollowRow(h, h - r + 1, c);
> }
>
> public static void main(String[] args) {
>     for (int r = 1; r <= 4; r++)                              // σχήμα 1: 4 πυραμίδες h = 4
>         System.out.println(pyrRow(4, r, 'x').repeat(4));
>     System.out.println();
>     for (int r = 1; r <= 5; r++)                              // σχήμα 2: ανάποδη, κανονική, ανάποδη
>         System.out.println(invRow(5, r, 'o') + " " + pyrRow(5, r, 'o') + " " + invRow(5, r, 'o'));
>     System.out.println();
>     for (int r = 1; r <= 7; r++)                              // σχήμα 3: κούφιες, εναλλάξ
>         System.out.println(hollowRow(7, r, '+') + hollowInvRow(7, r, '+')
>                          + hollowRow(7, r, '+') + hollowInvRow(7, r, '+'));
> }
> ```
> Παρατηρήσεις:
> - Στο σχήμα 1 οι βάσεις των 4 πυραμίδων (πλάτος 7 η καθεμία) ενώνονται σε μία συνεχή γραμμή 28 `x`.
> - Στην κούφια γραμμή `r`: συνολικά `2r − 1` θέσεις = 1 χαρακτήρας + `2r − 3` κενά + 1 χαρακτήρας.
> - Χωρίς `repeat` (Java 11): `String row = ""; for (int k = 0; k < 4; k++) row += pyrRow(4, r, 'x');`.

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Λάθος τύπος για τα κενά/χαρακτήρες: `h − i` και `2i − 1` (με `i` από **1**). Με `i` από 0: `h − i − 1` και `2i + 1`.
> - `s += ' ' + c;` → αριθμός αντί για κενό + χαρακτήρας.
> - `char c = args[1];` ✗ compile (`String` σε `char`) – χρειάζεται `.charAt(0)`.
> - `int h = args[0];` ✗ compile – χρειάζεται `Integer.parseInt`.
> - Παραλείπεις τα δεξιά κενά και μετά προσπαθείς να βάλεις πυραμίδες δίπλα-δίπλα.
> - Μέθοδος που **τυπώνει** αντί να **επιστρέφει** – δεν μπορεί να συντεθεί με άλλες.
