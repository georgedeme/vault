# 06 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα VII.

## 1. Οι έξι τρόποι

| Τρόπος | Κώδικας | Εκτέλεση | Ποιος συνδέει |
|---|---|---|---|
| Ορίσματα | `args[i]`, `args.length`, `Double.parseDouble(args[i])` | `java P 45 67` | shell → `main` |
| Διαδραστικά | `while (!StdIn.isEmpty()) … StdIn.readDouble()` + prompts | `java P` (τέλος: `Ctrl-D` / `Ctrl-Z, Enter`) | πληκτρολόγιο |
| Ανακατεύθυνση | ίδιος κώδικας, **χωρίς** prompts | `java P < in.txt > out.txt` | λειτουργικό σύστημα |
| Σωλήνωση | ίδιος κώδικας | `java A \| java B` | λειτουργικό σύστημα |
| Αρχεία | `In f = new In(args[0]); f.readDouble(); f.close();` | `java P in.txt` | το πρόγραμμα |
| Γραφικά | `StdDraw.circle(x, y, r)` | `java P` | παράθυρο |

## 2. Βιβλιοθήκες

| | Μέθοδοι | Είδος |
|---|---|---|
| `StdIn` | `isEmpty` `readInt` `readDouble` `readLong` `readBoolean` `readChar` `readString` `readLine` `readAll` | **στατικές**: `StdIn.readInt()` |
| `StdOut` ≡ `System.out` | `print` `println` `printf` | στατικές |
| `In` | ίδιες με `StdIn` + `close` · κατασκευαστές `In()` (std είσοδος), `In(String)` (αρχείο/URL) | **αναφοράς**: `f.readInt()` |
| `Out` | ίδιες με `StdOut` + `close` · `Out(String)` – **σβήνει** το αρχείο | αναφοράς |
| `Scanner` | `new Scanner(System.in)` · `hasNext` `nextInt` `nextDouble` `next` `nextLine` | αναφοράς · `import java.util.Scanner;` |
| `StdDraw` | `line` `point` `text` `circle` `filledCircle` `square` `filledSquare` `polygon` `setXscale` `setYscale` `setPenRadius` `setPenColor` `clear` `show` `save` | στατικές · `import java.awt.Color;` |

| Μετατροπή `String` → | Μέθοδος | `"3.5"` | `" 7 "` | `"abc"` |
|---|---|---|---|---|
| `int` | `Integer.parseInt` | ✗ | ✗ | ✗ `NumberFormatException` |
| `double` | `Double.parseDouble` | `3.5` | `7.0` | ✗ |
| `boolean` | `Boolean.parseBoolean` | `false` | `false` | `false` (ποτέ εξαίρεση) |

## 3. `printf`

`%[-][πλάτος][.ακρίβεια]κωδικός` · `d` ακέραιος · `f` πραγματικός · `e` εκθετικός · `s` String · `c` char · `b` boolean · `%%` · `%n`

| Κλήση | Έξοδος |
|---|---|
| `printf("%8.4f", 84.6)` | `" 84.6000"` |
| `printf("%6.2f", 3.14159)` | `"  3.14"` |
| `printf("%-5d\|", 42)` | `"42   \|"` |
| `printf("%3d", 12345)` | `"12345"` (δεν κόβει) |
| `printf("%.0f", 2.5)` | `"3"` |
| `printf("%f", 84.6)` | `"84.600000"` (6 δεκαδικά) |
| `printf("%d", 3.0)` · `printf("%f", 3)` | ✗ `IllegalFormatConversionException` (στην εκτέλεση) |

## 4. Μοτίβα

| Σκοπός | Πυρήνας |
|---|---|
| Μέσος όρος από είσοδο | `while (!StdIn.isEmpty()) { sum += StdIn.readDouble(); cnt++; }` → `sum/cnt` (κενή είσοδος → `NaN`) |
| Αντίστροφη σειρά (αναδρομή) | `rev(i) { n = readInt(); if (n == 0) return; rev(i+1); print(n); }` |
| Αντίστροφη σειρά (πίνακας) | `xs = add(xs, num);` – νέος πίνακας `length+1`, `xs[0] = x`, `xs[i+1] = temp[i]` |
| Τυχαίος στο `[base, limit]` | `base + (int)(Math.random()*(limit-base+1))` |
| Αλλαγή γραμμής ανά 10 | `for (i = 1; …) { …; if (i % 10 == 0) println(); }` |
| Κεφαλαίο | `(char)(c - 'a' + 'A')` αν `'a' <= c && c <= 'z'` |
| Κεντράρισμα σε `N` | `left = (N-len)/2; right = N - (len+left);` |
| Συνένωση αρχείων | `for (String name : args) print(new In(name).readAll());` |
| Συγχώνευση γραμμών | `while (!f1.isEmpty() && !f2.isEmpty()) { println(f1.readLine()); println(f2.readLine()); }` + `readAll` του υπολοίπου |
| Προσθήκη σε αρχείο | **πρώτα** `s = new In(x).readAll()`, **μετά** `new Out(x)`, `print(s)` + νέα |
| Σκακιέρα | `if ((ri + cj) % 2 == 0) filledSquare(ri - 0.5, cj - 0.5, 0.5);` |

## 5. Συμπεριφορά που ρωτιέται

| Κατάσταση | Αποτέλεσμα |
|---|---|
| `java P` χωρίς ορίσματα | `args.length == 0` (όχι `null`) · `args[0]` → `ArrayIndexOutOfBoundsException` |
| `java P "a b" c` | 2 ορίσματα |
| `java P < f > g`, `\|` | **δεν** μπαίνουν στο `args` |
| `isEmpty()` | `true` όταν απομένουν **μόνο κενοί χαρακτήρες** → κενές γραμμές/κενά στο τέλος «δεν υπάρχουν» |
| `isEmpty()` + `readChar()` σε `"ab\n"` | μετρά **2** |
| `readInt()` σε `"abc"` | `InputMismatchException` · τέλος εισόδου → `NoSuchElementException` |
| `new In("ανύπαρκτο")` | `IllegalArgumentException` |
| `new Out(x)` | σβήνει το `x` αμέσως |
| `println(f.readAll())` | επιπλέον κενή γραμμή – θέλει `print` |
| αρχείο χωρίς τελικό `\n` στην `Append` | κολλάει με το επόμενο |
| `file*.txt` | αλφαβητικά: `file1, file10, file2` |
| `square(x, y, r)` | κέντρο `(x, y)`, πλευρά `2r` · y προς τα **πάνω** · αρχικά 0…1 |

| Σωλήνωση (VII-49) | Ίδιο με το αρχικό; |
|---|---|
| `Centralize \| DoubleSpace \| Caps` | ✓ |
| `DoubleSpace \| Caps \| Centralize` | ✗ κενές γραμμές = 60 κενά, χάνεται η τελευταία |
| `Centralize \| Centralize` · `Caps \| Caps` | = μία φορά (ταυτοδύναμα) |
| `DoubleSpace \| DoubleSpace` | ✗ 3 κενές γραμμές ανάμεσα, 1 στο τέλος |

> [!warning] Οι «παγίδες» σε μια ματιά
> - `args[0] + args[1]` = συνένωση · `Integer.parseInt("3.5")` ✗
> - `0.0/0` = `NaN` χωρίς σφάλμα (κενή είσοδος)
> - `Scanner(System.in)` χωρίς `new` ✗ · `nextString()` δεν υπάρχει (⚠️ VII-15)
> - `In.readInt()` ✗ (αναφοράς) · `StdIn` / `In` / `StdDraw` δεν είναι μέρος της Java
> - `add(xs, x);` χωρίς `xs =` → τίποτα
> - η εντολή **μετά** την αναδρομική κλήση εκτελείται **στην επιστροφή** (αντίστροφα)
> - prompts + ανακατεύθυνση → «σκουπίδια» στην έξοδο
> - `"  " + base + r` → συνένωση ψηφίων (`"205"`)
> - `java Average Data.txt` (V3) / `java Average < Data.txt` (V5) → λάθος πρόγραμμα για τον τρόπο
> - `java Concatenate d.txt d.txt` → διπλασιάζει · `java Merge a b a` → χάνεται το `a`
> - `(-5)/2 = -2` (στο `Centralize`)
> - `printf` χωρίς `\n` · `%d` με `double`
> - τυπογραφικά εισαγωγικά `“ ”` (VII-56) ✗
