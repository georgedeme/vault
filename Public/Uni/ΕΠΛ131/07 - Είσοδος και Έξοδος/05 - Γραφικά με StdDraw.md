# 05 - Γραφικά με StdDraw

Έξοδος σε **παράθυρο** αντί για κείμενο: η βιβλιοθήκη `StdDraw`, οι συντεταγμένες της, και το παράδειγμα του εμβλήματος των Ολυμπιακών Αγώνων (διαφάνειες VII-75 … VII-97).

## 1. Απλά γραφικά για visual output (VII-75)

> [!note] Τι προσφέρει
> - Θα γίνει χρήση της βιβλιοθήκης **`StdDraw`**.
> - Με απλά σχήματα μπορούν να δημιουργηθούν εντυπωσιακά γραφικά και να αποθηκευτούν σε δευτερεύουσα μνήμη (π.χ. αρχεία τύπου jpg) για μόνιμη αξιοποίηση.
>   - Σε τελική ανάλυση κάθε ψηφιακό/ή σχήμα/εικόνα είναι ένα **σύνολο σημείων** (ή εικονοστοιχείων) ή ένα **σύνολο γραμμών** (όπου κάθε γραμμή ενώνει δύο σημεία).
>   - **Ανάλυση και σύνθεση**: σπάμε την εικόνα σε απλά σχήματα, και τη χτίζουμε ξανά από αυτά.
> - Υπάρχει η δυνατότητα για **χρώματα** και **κίνηση** (animation).

## 2. Η βιβλιοθήκη `StdDraw` (VII-76, VII-77)

> [!important] Στατικές μέθοδοι
> Όπως και για τις βιβλιοθήκες `StdIn`, `StdOut` και `System.out`: `StdDraw.line(…)`, χωρίς αντικείμενο. Υπάρχει **ένας** καμβάς (παράθυρο) ανά πρόγραμμα.

| Σχεδίαση | Τι σχεδιάζει |
|---|---|
| `void line(double x0, double y0, double x1, double y1)` | ευθύγραμμο τμήμα από `(x0, y0)` σε `(x1, y1)` |
| `void point(double x, double y)` | σημείο |
| `void text(double x, double y, String s)` | κείμενο **κεντραρισμένο** στο `(x, y)` |
| `void circle(double x, double y, double r)` | κύκλος (περίγραμμα), κέντρο `(x, y)`, ακτίνα `r` |
| `void filledCircle(double x, double y, double r)` | γεμάτος κύκλος |
| `void square(double x, double y, double r)` | τετράγωνο, **κέντρο** `(x, y)`, **μισή** πλευρά `r` |
| `void filledSquare(double x, double y, double r)` | γεμάτο τετράγωνο |
| `void polygon(double[] x, double[] y)` | πολύγωνο με κορυφές `(x[i], y[i])` |
| `void filledPolygon(double[] x, double[] y)` | γεμάτο πολύγωνο |

| Ρυθμίσεις | |
|---|---|
| `void setXscale(double x0, double x1)` | reset x range to `(x0, x1)` |
| `void setYscale(double y0, double y1)` | reset y range to `(y0, y1)` |
| `void setPenRadius(double r)` | set pen radius to `r` (πάχος γραμμής) |
| `void setPenColor(Color c)` | set pen color to `c` |
| `void setFont(Font f)` | set text font to `f` |
| `void setCanvasSize(int w, int h)` | set canvas to w-by-h window (σε pixels) |
| `void clear(Color c)` | clear the canvas; color it `c` |
| `void show(int dt)` | show all; pause `dt` milliseconds (για κίνηση) |
| `void save(String filename)` | save to a `.jpg` or `.png` file |

> [!warning] ➕ Συντεταγμένες: όπως στα μαθηματικά, όχι όπως στην οθόνη
> - Εξ ορισμού και οι δύο άξονες πάνε από **0 έως 1**: `(0, 0)` κάτω αριστερά, `(1, 1)` πάνω δεξιά. Με `setXscale`/`setYscale` αλλάζει το εύρος.
> - Το **y μεγαλώνει προς τα πάνω** (στις περισσότερες βιβλιοθήκες γραφικών και στις γραμμές ενός πίνακα, προς τα κάτω).
> - Όλες οι μέθοδοι παίρνουν **`double`**· ένα `int` όρισμα μετατρέπεται αυτόματα.
> - Το `r` στα `square`/`filledSquare` είναι η **μισή** πλευρά: `square(0.5, 0.5, 0.5)` με τις αρχικές κλίμακες σχεδιάζει το περίγραμμα **όλου** του καμβά.
> - Τα χρώματα είναι αντικείμενα της κλάσης `Color` της Java: χρειάζεται **`import java.awt.Color;`** (VII-79) και γράφονται `Color.RED`, `Color.GRAY`, …

> [!note] ⚠️ Σημείωση για το `show(int dt)`
> Σε νεότερες εκδόσεις της `StdDraw` του βιβλίου η κίνηση γίνεται με `StdDraw.enableDoubleBuffering()`, `StdDraw.show()` και `StdDraw.pause(dt)`· το `show(int)` της VII-77 είναι της παλιότερης έκδοσης. Η ιδέα είναι ίδια: σχεδίασε το επόμενο «καρέ», δείξ' το, περίμενε `dt` ms.

## 3. Παράδειγμα: Έμβλημα Ολυμπιακών Αγώνων (VII-78 … VII-93)

Πέντε δακτύλιοι (τρεις πάνω, δύο κάτω) πάνω σε φόντο-σκακιέρα 100 × 100.

```java
/* Πρόγραμμα που ζωγραφίζει το έμβλημα των
   Ολυμπιακών Αγώνων */

import java.awt.Color;

public class Olympic_Rings {

  public static void main(String[] args) {
     // Βήμα 1, Βήμα 2, Βήμα 3
  }
}
```

### Βήμα 1: Πλαίσιο 100 × 100 και πλέγμα-φόντο (VII-80 … VII-87)

```java
/* Βήμα 1: Προσδιορίζουμε το μέγεθος του πλαισίου (100 x 100)
           και δημιουργούμε το πλέγμα που αποτελεί το φόντο
           του εμβλήματος */

    StdDraw.setXscale(0.0, 100.0);
    StdDraw.setYscale(0.0, 100.0);
    StdDraw.clear(Color.WHITE);

    StdDraw.setPenColor(Color.GRAY);
    . . . . . . . . . . . . . .
```

**Τι παρατηρούμε (VII-82, VII-83);**
- Το κάθε τετραγωνάκι προσδιορίζεται από τη **σειρά (i)** και τη **στήλη (j)** που βρίσκεται.
- Για κάθε γκρίζο τετραγωνάκι: **είτε** το `i` και το `j` είναι και τα δύο **ζυγοί** αριθμοί, **είτε** είναι και τα δύο **περιττοί**.

**Ποια είναι η κατάλληλη αλγοριθμική δομή (VII-84);** Διπλή απαριθμητή επανάληψη:

```
Επανέλαβε για κάθε σειρά i
    Επανέλαβε για κάθε στήλη j
        Εάν i και j είναι και οι δύο είτε ζυγοί, είτε περιττοί αριθμοί
            Ζωγράφισε στην εν λόγω θέση ένα γκρίζο τετραγωνάκι μεγέθους 1
```

```java
for (int ri = 1; ri <= 100; ri++)              // for every row ri
   for (int cj = 1; cj <= 100; cj++)           // for every col cj
      if ((ri % 2 == 1 && cj % 2 == 1) ||      // both odd?
          (ri % 2 == 0 && cj % 2 == 0))        // both even?
         StdDraw.filledSquare
            ((ri - 1) + 0.5,                   // x coordinate
             (cj - 1) + 0.5,                   // y coordinate
             0.5);                             // radius r
```

![[StdDraw - Σκακιέρα.png|800]]

> [!important] Γιατί `(ri - 1) + 0.5` και `0.5`
> - Το κελί `ri` πιάνει το διάστημα `[ri − 1, ri]` στον άξονα. Το **κέντρο** του είναι στο `ri − 0.5` = `(ri - 1) + 0.5`.
> - Η `filledSquare` θέλει κέντρο και **μισή** πλευρά: `r = 0.5` → πλευρά 1, ακριβώς ένα κελί.
> - Συνθήκη: «ίδια ισοτιμία» ⇔ **`(ri + cj) % 2 == 0`** (άρτιος + άρτιος και περιττός + περιττός δίνουν άρτιο). Ισοδύναμα `ri % 2 == cj % 2`.
> - 100 × 100 = 10 000 επαναλήψεις του εσωτερικού σώματος, 5 000 τετράγωνα.

> [!warning] ⚠️ Σημειώσεις για τις VII-85, VII-86
> - Τα σχόλια λένε «row» για το `ri`, αλλά το `ri` χρησιμοποιείται ως συντεταγμένη **x** (στήλη στην οθόνη) και το `cj` ως **y**. Επειδή το μοτίβο είναι συμμετρικό, η εικόνα βγαίνει ίδια.
> - Στη VII-86 το `(double)(ri - 1) + 0.5` δεν χρειάζεται cast: `int + 0.5` είναι ήδη `double`.

**Γιατί το βήμα 1 να μην κωδικοποιηθεί ως ξεχωριστή μέθοδος; Άρθρωση (VII-85):**

```java
public static void draw_background_grid() {

   StdDraw.setXscale(0.0, 100.0);
   StdDraw.setYscale(0.0, 100.0);
   StdDraw.clear(Color.WHITE);

   StdDraw.setPenColor(Color.GRAY);
   for (int ri = 1; ri <= 100; ri++)
      for (int cj = 1; cj <= 100; cj++)
         if ((ri % 2 == 1 && cj % 2 == 1) ||
             (ri % 2 == 0 && cj % 2 == 0))
            StdDraw.filledSquare
               ((double)(ri - 1) + 0.5,
                (double)(cj - 1) + 0.5,
                0.5);
}
```

```java
/* Βήμα 1: … */
   draw_background_grid();
```

Η `main` γίνεται μια σειρά από **βήματα με όνομα** – ο αναγνώστης βλέπει **τι** γίνεται, όχι **πώς** ([[01 - Αφαιρετικότητα, DRY και Απλότητα|V – 01]]).

### Βήμα 2: Οι πάνω δακτύλιοι (VII-88 … VII-90)

```java
/* Βήμα 2: Ζωγραφίζουμε τους πάνω δακτύλιους */

    StdDraw.setPenRadius(0.030);

    StdDraw.setPenColor(Color.BLUE);
    StdDraw.circle(15.0, 60.0, 14.0);

    StdDraw.setPenColor(Color.BLACK);
    StdDraw.circle(50.0, 60.0, 14.0);

    StdDraw.setPenColor(Color.RED);
    StdDraw.circle(85.0, 60.0, 14.0);
```

### Βήμα 3: Οι κάτω δακτύλιοι (VII-91 … VII-93)

```java
/* Βήμα 3: Ζωγραφίζουμε τους κάτω δακτύλιους */

    StdDraw.setPenColor(Color.YELLOW);
    StdDraw.circle(33.0, 45.0, 14.0);

    StdDraw.setPenColor(Color.GREEN);
    StdDraw.circle(68.0, 45.0, 14.0);
```

![[StdDraw - Ολυμπιακοί Κύκλοι.png|800]]

| Δακτύλιος | Χρώμα | Κέντρο | Ακτίνα |
|---|---|---|---|
| πάνω αριστερά | μπλε | (15, 60) | 14 |
| πάνω μέση | μαύρο | (50, 60) | 14 |
| πάνω δεξιά | κόκκινο | (85, 60) | 14 |
| κάτω αριστερά | κίτρινο | (33, 45) | 14 |
| κάτω δεξιά | πράσινο | (68, 45) | 14 |

> [!tip] Πώς βγαίνουν οι αριθμοί (και τι ρωτιέται)
> - Πάνω κέντρα ανά **35** στον άξονα x, στο ίδιο ύψος 60. Κάτω κέντρα **15** μονάδες χαμηλότερα και περίπου στη μέση των πάνω (32.5 → 33, 67.5 → 68).
> - Δύο κύκλοι ακτίνας `r` τέμνονται όταν η απόσταση των κέντρων είναι **< 2r** = 28. Πάνω–πάνω: 35 → δεν ακουμπούν. Πάνω–κάτω: √(18² + 15²) ≈ 23.4 → τέμνονται.
> - Το `setPenColor` ισχύει για **όλα** τα επόμενα σχήματα μέχρι να αλλάξει: γι' αυτό καλείται πριν από κάθε κύκλο. Το `setPenRadius(0.030)` μία φορά, για όλους.
> - Ό,τι σχεδιάζεται **μετά** βγαίνει **από πάνω**: οι κάτω δακτύλιοι καλύπτουν τους πάνω στα σημεία τομής (στο πραγματικό σήμα οι κύκλοι «πλέκονται», εδώ όχι).
> - Αν έμπαινε πρώτα το Βήμα 2 και **μετά** το `draw_background_grid()`, το φόντο θα έσβηνε τους δακτυλίους (`clear` + τετράγωνα από πάνω).

## 4. Σύνοψη της ενότητας (VII-94 … VII-97)

> [!note] Σύνοψη
> - Τα προγράμματά μας πρέπει να **επικοινωνούν με τον έξω κόσμο**:
>   - Πλήθος μονάδων εισόδου και εξόδου.
>   - Standard κανάλι εισόδου το πληκτρολόγιο και standard κανάλι εξόδου η οθόνη.
>   - Βιβλιοθήκες `StdIn`, `StdOut`, `System.out` – **στατικές μέθοδοι**.
> - **Ορίσματα από γραμμή εντολής** (ως strings): διασύνδεση της `main` με το λειτουργικό σύστημα.
> - **Διαδραστική** εισαγωγή δεδομένων: βιβλιοθήκη `StdIn`.
> - **Ανακατεύθυνση** standard input/output σε αρχεία: σε επίπεδο λειτουργικού συστήματος.
> - **Σωλήνωση** διεργασιών: σε επίπεδο λειτουργικού συστήματος · αρχιτεκτονική στρώσεων.
> - **Ρητή αναφορά σε αρχεία**: πολλαπλά κανάλια εισόδου/εξόδου ταυτόχρονα · βιβλιοθήκες `In`/`Out` – αντικείμενα, **μέθοδοι αναφοράς**.
> - **Γραφικά** για visual output: βιβλιοθήκη `StdDraw` – στατικές μέθοδοι · χρώματα και κίνηση · ψηφιακά σχήματα/εικόνες ως σύνολα σημείων ή γραμμών.
>
> **Σημ.:** Δεν ασχοληθήκαμε με τον (σημασιολογικό και άλλο) **έλεγχο εγκυρότητας** δεδομένων (είτε αυτά προέρχονται από γραμμή εντολής, ή διαλογικά ή από αρχεία) – σημαντικό ζήτημα σε ρεαλιστικά προγράμματα, ως προς την **ανθεκτικότητά** τους.
>
> **Στο βιβλίο:** Ενότητα 3.1 · Ενότητα 1.5 (γραφικά).

> [!tip] Ο «έλεγχος εγκυρότητας» που λείπει, σε μια ματιά
> Όλα τα προγράμματα της ενότητας σκάνε με κακή είσοδο: `NumberFormatException` (ορίσματα), `InputMismatchException` (`StdIn`), `ArrayIndexOutOfBoundsException` (λίγα ορίσματα), `IllegalArgumentException` (ανύπαρκτο αρχείο), `NaN` (κενή είσοδος). Ένα ανθεκτικό πρόγραμμα ελέγχει **πριν** διαβάσει: `args.length`, `cnt > 0`, `do { … } while (άκυρο);` ([[07 - Εντολή do-while και Ισοδυναμίες Βρόχων|III – 07]]).

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Ξεχνάς `import java.awt.Color;` → `cannot find symbol: Color`.
> - Νομίζεις ότι `(x, y)` στο `square` είναι η κάτω αριστερή γωνία – είναι το **κέντρο**· και ότι `r` είναι η πλευρά – είναι η **μισή**.
> - Ξεχνάς `setXscale`/`setYscale` → συντεταγμένες 0…100 πέφτουν **έξω** από τον καμβά 0…1 (δεν φαίνεται τίποτα, χωρίς σφάλμα).
> - Περιμένεις το y να μεγαλώνει προς τα κάτω.
> - `filledSquare(ri, cj, 0.5)` → η σκακιέρα μετατοπίζεται κατά μισό κελί.
> - `setPenColor` μετά το σχήμα → το χρώμα ισχύει για το **επόμενο**.
> - Σειρά σχεδίασης: το φόντο **πρώτα**.
