# 01 - Ορίσματα Γραμμής Εντολής και printf

Πώς ένα πρόγραμμα παίρνει δεδομένα από τη γραμμή εντολής (`args`), πώς τα μετατρέπει σε αριθμούς, και πώς μορφοποιεί την έξοδο με `printf` (διαφάνειες VII-1 … VII-12).

## 1. Τρόποι επικοινωνίας με τον έξω κόσμο (VII-1 … VII-4)

> [!note] Στόχος της ενότητας
> Τα προγράμματά μας σε Java να **επικοινωνούν με τον έξω κόσμο**: μονάδες εισόδου (πληκτρολόγιο, ποντίκι, σκληρός δίσκος, διαδίκτυο, κάμερα, μικρόφωνο) και μονάδες εξόδου (οθόνη, ηχεία, σκληρός δίσκος, διαδίκτυο, εκτυπωτής).

| # | Τρόπος | Αγγλικά | Σημείωση |
|---|---|---|---|
| 1 | Ορίσματα από γραμμή εντολής | Command line arguments | αυτή η σημείωση |
| 2 | Διαδραστικά | Interactively with user | [[02 - Διαδραστική Είσοδος και Αναδρομή\|02]] |
| 3 | Με ανακατεύθυνση | File redirection | [[03 - Ανακατεύθυνση και Σωλήνωση\|03]] |
| 4 | Σωλήνωση διεργασιών | Process piping | [[03 - Ανακατεύθυνση και Σωλήνωση\|03]] |
| 5 | Με ρητή αναφορά σε αρχεία | File Input/Output | [[04 - Αρχεία με In και Out\|04]] |
| 6 | Απλά γραφικά | visual output | [[05 - Γραφικά με StdDraw\|05]] |

> [!note] Standard Input/Output (VII-3)
> - **Standard Input channel** (κανάλι εισόδου): εξ ορισμού το **πληκτρολόγιο**.
> - **Standard Output channel** (κανάλι εξόδου): εξ ορισμού η **οθόνη**.
>
> «Εξ ορισμού» γιατί το λειτουργικό σύστημα μπορεί να τα συνδέσει και με αρχεία ή με άλλα προγράμματα ([[03 - Ανακατεύθυνση και Σωλήνωση|03]]).

## 2. Ορίσματα από γραμμή εντολής (VII-5)

> [!note] Τι είναι
> - **Διοχέτευση δεδομένων προς τη συνάρτηση `main`**: `public static void main(String[] args){…}`
> - **Διασύνδεση** του προγράμματος με το λειτουργικό σύστημα.
> - Για **μικρό, αλλά μεταβλητό**, πλήθος δεδομένων: `args.length` δίνει το τρέχον πλήθος.
> - Τα δεδομένα εισάγονται **ως strings**, άρα χρειάζεται να μετασχηματιστούν στους σχετικούς βασικούς τύπους: **wrapper classes**.

![[Ορίσματα - args στη Μνήμη.png|800]]

> [!important] Τα ορίσματα είναι πάντα `String`
> `java Average 23` δεν δίνει τον αριθμό 23 αλλά τη **συμβολοσειρά** `"23"`. Για να κάνεις πράξεις καλείς μια μέθοδο μετατροπής από μια **wrapper class** (κλάση-«περιτύλιγμα» για κάθε βασικό τύπο):
>
> | Wrapper class | Βασικός τύπος | Μετατροπή από `String` |
> |---|---|---|
> | `Integer` | `int` | `Integer.parseInt(s)` |
> | `Double` | `double` | `Double.parseDouble(s)` |
> | `Long` | `long` | `Long.parseLong(s)` |
> | `Boolean` | `boolean` | `Boolean.parseBoolean(s)` |
> | `Character` | `char` | (δεν υπάρχει `parseChar` – `s.charAt(0)`) |

> [!example]- Τι δέχονται και τι όχι οι μέθοδοι μετατροπής (ελέγχθηκε)
>
> | `s` | `Double.parseDouble(s)` | `Integer.parseInt(s)` |
> |---|---|---|
> | `"23"` | `23.0` | `23` |
> | `"3.5"` | `3.5` | ✗ `NumberFormatException` |
> | `"1e2"` | `100.0` | ✗ `NumberFormatException` |
> | `" 7 "` (με κενά) | `7.0` (αγνοεί τα κενά) | ✗ `NumberFormatException` |
> | `"+7"`, `"007"` | `7.0` | `7` |
> | `"3,5"` (κόμμα) | ✗ `NumberFormatException` | ✗ |
> | `"abc"`, `""` | ✗ `NumberFormatException` | ✗ |
> | `"NaN"`, `"Infinity"` | `NaN`, `Infinity` | ✗ |
> | `"2147483648"` | `2.147483648E9` | ✗ (εκτός ορίων `int`) |
>
> `Boolean.parseBoolean` **δεν** πετάει ποτέ εξαίρεση: `"true"`, `"TRUE"`, `"True"` → `true`, οτιδήποτε άλλο (`"yes"`, `"1"`) → `false`.

## 3. Μέσος όρος – Version 1: από τη γραμμή εντολής (VII-6 … VII-9)

```java
// Computing the average of a list of numbers
// Version 1: Input from command line

public class Average {

 public static void main(String[] args) {
  double sum = 0.0;
  int cnt = 0;
  for (String s : args) {
     sum += Double.parseDouble(s);
     cnt++;
  }
  double average = sum/cnt;
  System.out.println("Average is " + average);
 }

}
```

| Εντολή | `args` | Έξοδος |
|---|---|---|
| `java Average 23` | `{"23"}` | `Average is 23.0` |
| `java Average 45 67 2 109 200` | `{"45", "67", "2", "109", "200"}` | `Average is 84.6` |
| `java Average` | `{}` (μήκος 0) | `Average is NaN` |
| `java Average 10 abc` | `{"10", "abc"}` | ✗ `NumberFormatException: For input string: "abc"` |

> [!warning] Γιατί `NaN` και όχι σφάλμα;
> Χωρίς ορίσματα ο βρόχος δεν εκτελείται: `sum = 0.0`, `cnt = 0`. Η διαίρεση `0.0/0` είναι **πραγματική** (το `sum` είναι `double`), άρα δίνει `NaN` σιωπηλά ([[04 - Πραγματικοί Τύποι και Βιβλιοθήκη Math|II – 04]]). Αν και τα δύο ήταν `int`, θα είχαμε `ArithmeticException`.

> [!important] Χωρίς ορίσματα το `args` **δεν** είναι `null`
> Είναι **κενός πίνακας**: `args.length == 0`. Άρα `args.length` είναι πάντα ασφαλές, ενώ `args[0]` πετάει `ArrayIndexOutOfBoundsException` (VII-9).

### Πώς χωρίζονται τα ορίσματα

| Εντολή | `args.length` | Περιεχόμενο |
|---|---|---|
| `java P a b c` | 3 | `"a"`, `"b"`, `"c"` |
| `java P "a b" c` | 2 | `"a b"`, `"c"` – τα εισαγωγικά ενώνουν, **δεν** μπαίνουν στο string |
| `java P` | 0 | – |
| `java P 1 2 < in.txt > out.txt` | 2 | `"1"`, `"2"` – τα `<`, `>`, `\|` τα χειρίζεται το shell |
| `java P file*.txt` | όσα αρχεία ταιριάζουν | το shell επεκτείνει το `*` πριν τρέξει η Java ([[04 - Αρχεία με In και Out\|04]]) |

Το **όνομα της κλάσης** (`P`) **δεν** μπαίνει στο `args` (αντίθετα με τη C, όπου `argv[0]` είναι το όνομα του προγράμματος).

## 4. Αντιστροφή ορισμάτων (VII-10)

```java
// Reversing the list of arguments from command line

public class ReverseArgs {

 public static void main(String[] args) {
   if (args.length == 0)
      System.out.print("Nothing to reverse ...");
   for (int i = args.length - 1; i >= 0; i--)
      System.out.print(args[i] + " ");
   System.out.print("\n\n");
 }
}
```

```
$ java ReverseArgs one two three
three two one

$ java ReverseArgs This is a working day
day working a is This

$ java ReverseArgs
Nothing to reverse ...
```

> [!tip] Λεπτομέρειες που ρωτιούνται
> - Δεν χρειάζεται `else`: όταν `args.length == 0`, ο `for` ξεκινά με `i = -1` και δεν εκτελείται.
> - Μετά την τελευταία λέξη τυπώνεται **κενό** (`"one "`), και στο τέλος **δύο** αλλαγές γραμμής.
> - `java ReverseArgs "a b" c` → `c a b ` – φαίνονται 3 λέξεις αλλά ήταν 2 ορίσματα.
> - Αντιστρέφεται η σειρά των **ορισμάτων**, όχι οι χαρακτήρες: `java ReverseArgs abc` → `abc`.

## 5. Μορφοποίηση εξόδου με `printf` (VII-11, VII-12)

```java
public class Average {

 public static void main(String[] args) {
  double sum = 0.0;
  if (args.length == 0)
     System.out.print("Nothing to average ...");
  else {
     for (String s : args) {
        sum += Double.parseDouble(s);
     }
     double average = sum/args.length;
     System.out.printf("Average is %8.4f\n", average);
  }
 }
}
```

```
$ java Average 45 67 2 109 200
Average is  84.6000
```

Αυτή η εκδοχή διορθώνει το `NaN` της Version 1 (ελέγχει πρώτα το `args.length`) και δεν χρειάζεται μετρητή `cnt`: το πλήθος είναι το `args.length`.

> [!note] Η σύνταξη του `printf`
> `System.out.printf(String μορφοποίησης, λίστα εκφράσεων εξόδου);`
> - Το **String μορφοποίησης** (format string) έχει κανονικό κείμενο και **προσδιοριστές** (specifiers) που αρχίζουν με `%`.
> - Κάθε προσδιοριστής αντιστοιχεί, με τη σειρά, σε μία έκφραση της λίστας.
> - Γενική μορφή: `%[πλάτος πεδίου][.ακρίβεια]κωδικός μετατροπής` (field width, precision, conversion code).
> - Το `printf` **δεν** αλλάζει γραμμή μόνο του: χρειάζεται `\n` (ή `%n`).

![[printf - Ανατομία Προσδιοριστή.png|800]]

| Τύπος | Κωδικός | Τυπική τιμή | Format | Έξοδος |
|---|---|---|---|---|
| `int` | `d` | `512` | `"%14d"` | `"           512"` |
| | | | `"%-14d"` | `"512           "` |
| `double` | `f` | `1595.1680010754388` | `"%14.2f"` | `"       1595.17"` |
| | | | `"%.7f"` | `"1595.1680011"` |
| | `e` | | `"%14.4e"` | `"    1.5952e+03"` |
| `String` | `s` | `"Hello, World"` | `"%14s"` | `"  Hello, World"` |
| | | | `"%-14s"` | `"Hello, World  "` |

Ο πίνακας είναι της διαφάνειας VII-12 (όλες οι έξοδοι ελέγχθηκαν).

> [!important] Κανόνες
> - **Πλάτος** = **ελάχιστο** πλήθος χαρακτήρων. Αν η τιμή χωράει, συμπληρώνονται κενά **αριστερά** (δεξιά στοίχιση). Αν δεν χωράει, τυπώνεται **ολόκληρη** – το πλάτος δεν κόβει ποτέ.
> - `-` πριν το πλάτος → **αριστερή** στοίχιση (κενά δεξιά).
> - **Ακρίβεια** στο `f`/`e` = δεκαδικά ψηφία, με **στρογγυλοποίηση**. Στο `s` = μέγιστο πλήθος χαρακτήρων (`"%.3s"` → `"Hel"`).
> - Χωρίς ακρίβεια, το `%f` δίνει **6** δεκαδικά: `printf("%f", 84.6)` → `84.600000`.
> - `%%` τυπώνει το σύμβολο `%` · `%n` αλλαγή γραμμής · `%c` χαρακτήρας · `%b` boolean.

> [!example]- Περισσότερες περιπτώσεις (ελέγχθηκαν)
>
> | Κλήση | Έξοδος | Σχόλιο |
> |---|---|---|
> | `printf("[%6.2f]", 3.14159)` | `[  3.14]` | 4 χαρακτήρες + 2 κενά |
> | `printf("[%8.4f]", 123456.789)` | `[123456.7890]` | 11 > 8: δεν κόβεται |
> | `printf("[%3d]", 12345)` | `[12345]` | |
> | `printf("[%.0f][%.0f]", 2.5, 3.5)` | `[3][4]` | στρογγυλοποίηση «μισό προς τα πάνω» |
> | `printf("[%.2f]", 2.675)` | `[2.68]` | |
> | `printf("[%5.1f]", -2.25)` | `[ -2.3]` | το `-` πιάνει θέση |
> | `printf("%d%%", 50)` | `50%` | |
> | `printf("[%s]", 3.0)` | `[3.0]` | το `%s` δέχεται τα πάντα |
> | `printf("[%08.3f]", 3.14159)` | `[0003.142]` | `0` → συμπλήρωση με μηδενικά |
> | `printf("[%,d]", 1234567)` | `[1,234,567]` | διαχωριστικό χιλιάδων |
> | `printf("[%e]", 0.000123)` | `[1.230000e-04]` | εκθετική, 6 δεκαδικά |
> | `printf("%d", 3, 4)` | `3` | τα επιπλέον ορίσματα αγνοούνται |
> | `String.format("%5.2f", Math.PI)` | `" 3.14"` | ίδιο format, **επιστρέφει** String αντί να τυπώνει |

> [!warning] Λάθος τύπος → εξαίρεση **κατά την εκτέλεση**
> Ο μεταγλωττιστής **δεν** ελέγχει το format string. Όλα αυτά κάνουν compile και σκάνε όταν τρέξουν:
> - `printf("%d", 3.0)` → `IllegalFormatConversionException` (`d` θέλει ακέραιο)
> - `printf("%f", 3)` → `IllegalFormatConversionException` (`f` θέλει πραγματικό – **δεν** γίνεται αυτόματη μετατροπή `int`→`double`)
> - `printf("%d %d", 3)` → `MissingFormatArgumentException`

> [!warning] ⚠️ Σημείωση για τη VII-11
> Η διαφάνεια δείχνει `Average is 84.6000`. Στην πραγματικότητα τυπώνεται `Average is  84.6000` (**δύο** κενά): το `84.6000` έχει 7 χαρακτήρες, άρα το πλάτος 8 προσθέτει ένα κενό μπροστά, εκτός από το κενό του κειμένου `"is "`. Τα βελάκια «8» και «4» της διαφάνειας αφορούν αυτό ακριβώς.

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - `sum += args[i];` → δεν κάνει compile (`String` σε `double`): λείπει το `Double.parseDouble`.
> - `args[0] + args[1]` με `"1"`, `"2"` → `"12"` (συνένωση), όχι `3`.
> - `Integer.parseInt("3.5")` → `NumberFormatException` – για πραγματικούς `Double.parseDouble`.
> - Χρήση του `args[0]` χωρίς έλεγχο `args.length` → `ArrayIndexOutOfBoundsException`.
> - Νομίζεις ότι χωρίς ορίσματα `args == null` – είναι κενός πίνακας.
> - Διαίρεση με `args.length` όταν είναι 0 → `NaN` (με `double` άθροισμα).
> - `printf("%d", x)` με `double x` → εξαίρεση· `printf` χωρίς `\n` → η επόμενη έξοδος κολλάει στην ίδια γραμμή.
> - Το πλάτος του `printf` **δεν** κόβει αριθμούς – μόνο η ακρίβεια στρογγυλοποιεί δεκαδικά.
