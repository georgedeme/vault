### Άσκηση 10

Γράψε τη μέθοδο `append(int[] xs, int x)` ώστε το πρόγραμμα με πίνακα να τυπώνει τους αριθμούς στην **αρχική** σειρά. Πρέπει να δουλεύει και για `xs == null`.

> [!success]- Λύση
> ```java
> public static int[] append(int[] xs, int x) {
>    int len = (xs == null) ? 0 : xs.length;
>    int[] nxs = new int[len + 1];
>    for (int i = 0; i < len; i++) nxs[i] = xs[i];
>    nxs[len] = x;
>    return nxs;
> }
> ```
> Με `34 89 56 0` → `34 89 56`. Το `len = 0` για `null` αποφεύγει τη διπλή περίπτωση της `add`: με `len = 0` ο βρόχος δεν εκτελείται και το `xs[i]` (που θα έδινε `NullPointerException`) δεν αποτιμάται ποτέ.

> StdDraw.filledSquare(1.5, 1.5, 0.5);
> ```
> 9 κλήσεις `square` (μία ανά κελί) και 1 `filledSquare`. Τα κελιά εδώ αριθμούνται από **0** (κέντρο `i + 0.5`), ενώ στη διαφάνεια από **1** (κέντρο `(ri - 1) + 0.5`) – ίδιο αποτέλεσμα, προσοχή να μην ανακατέψεις τις δύο συμβάσεις.
