# 01 - Συμπυκνωμένη Ύλη

Όλη η ύλη του ΕΠΛ 131 (Ενότητες II, III, IV, VI, VII) σε μία σημείωση, για επανάληψη πριν την εξέταση. Οι **Αρχές Ορθού Προγραμματισμού** (Ενότητα V) δεν περιλαμβάνονται. Κάθε ενότητα παραπέμπει στις αναλυτικές σημειώσεις για ό,τι θέλει περισσότερο βάθος.

> [!tip] Πώς να τη χρησιμοποιήσεις
> - Διάβασε μία ενότητα και κάλυψε τον κώδικα: μπορείς να τον γράψεις από μνήμης;
> - Τα κουτιά **«Παγίδες»** στο τέλος κάθε ενότητας είναι αυτά που πέφτουν στις πολλαπλές επιλογές.
> - Για τα θέματα των παλαιών ενδιάμεσων και πώς λύνεται κάθε είδος: [[02 - Οδηγός Ενδιάμεσης Εξέτασης]].

## 1. Δομή προγράμματος

```java
public class Hello {                          // όνομα αρχείου = Hello.java
   public static void main(String[] args) {   // εδώ ξεκινά η εκτέλεση
      System.out.println("Hello");            // κάθε εντολή τελειώνει με ;
   }
}
```

| Βήμα | Εντολή | Παράγει |
|---|---|---|
| Μεταγλώττιση | `javac Hello.java` | `Hello.class` (bytecode) |
| Εκτέλεση | `java Hello arg1 arg2` | – (`args = {"arg1", "arg2"}`) |

| Είδος σφάλματος | Πότε | Παράδειγμα |
|---|---|---|
| Συντακτικό / μεταγλώττισης | `javac` | λείπει `;`, `int x = 2.5;`, `if (x = 5)`, μη αρχικοποιημένη τοπική μεταβλητή |
| Εκτέλεσης (εξαίρεση) | `java` | `ArrayIndexOutOfBoundsException`, `ArithmeticException` (`/ 0`), `NumberFormatException`, `NullPointerException` |
| Λογικό | ποτέ – λάθος αποτέλεσμα | `1/2*x`, `<=` αντί `<`, `==` σε `String` |

Έξοδος: `print` (χωρίς αλλαγή γραμμής), `println` (με), `printf` (μορφοποίηση, [[#9. Είσοδος και Έξοδος (Ενότητα VII)|§9]]). Σχόλια `//` και `/* … */`.

## 2. Βασικοί τύποι και αριθμητική (Ενότητα II)

> [!note] Ορισμοί
> - **Τύπος δεδομένων** = σύνολο **τιμών** + σύνολο **λειτουργιών** πάνω σε αυτές.
> - **Βαθμωτοί** (scalar) τύποι: οι τιμές δεν διασπώνται. **Απαριθμητοί**: έχουν προκάτοχο/διάδοχο (`int`, `char`, όχι `double`).
> - **Μεταβλητή**: όνομα για μια θέση μνήμης με τύπο. **Κυριολεκτικό** (literal): τιμή γραμμένη στον κώδικα (`17`, `3.14`, `'A'`, `"Hi"`).

| Τύπος | Μέγεθος | Πεδίο / ακρίβεια | Κυριολεκτικά |
|---|---|---|---|
| `byte` / `short` | 8 / 16 bit | −128…127 / −32.768…32.767 | |
| `int` | 32 bit | −2³¹ … 2³¹−1 (≈ ±2,1 δισ.) | `17`, `-32` |
| `long` | 64 bit | ≈ ±9,2 × 10¹⁸ | `3000000000L` |
| `float` | 32 bit | ~6 ψηφία | `1.5f` |
| `double` | 64 bit | ~15 ψηφία, έως 10³⁰⁸ | `3.14`, `6.022e23` |
| `char` | 16 bit | χαρακτήρας Unicode | `'A'`, `'\n'` |
| `boolean` | – | `true`, `false` | |
| `String` | κλάση | ακολουθία χαρακτήρων | `"Hi"`, `""` |

| Κανόνας | Παράδειγμα |
|---|---|
| `int / int` = **ακέραιο πηλίκο**, κόβει προς το 0 | `7/2 = 3`, `-7/2 = -3`, `1/2 = 0` |
| `%` παίρνει το πρόσημο του **αριστερού** | `-7 % 2 = -1`, `7 % -2 = 1` |
| Ταυτότητα | `a == (a/b)*b + a%b` |
| Ένας τελεστέος `double` → αποτέλεσμα `double` | `7/2.0 = 3.5` |
| `int` ÷ 0 | `ArithmeticException` |
| `double` ÷ 0 | `Infinity` · `0.0/0` = `NaN` · `Math.sqrt(-1)` = `NaN` · `NaN == NaN` → `false` |
| Υπερχείλιση `int` | **σιωπηλά** τυλίγεται: `Integer.MAX_VALUE + 1 == Integer.MIN_VALUE` |
| Περιττός | `n % 2 != 0` (όχι `== 1` – αρνητικοί!) |
| Ψηφία αριθμού | `d = n % 10; n = n / 10;` όσο `n != 0` |

**Προτεραιότητα** (υψηλότερη πρώτα): `()` κλήσεις › μοναδιαίοι `+ - ! ++ --` και cast › `* / %` › `+ -` › `< <= > >=` › `== !=` › `&&` › `||` › `= += -= …`. Δυαδικοί από **αριστερά** προς δεξιά, ανάθεση και μοναδιαίοι από **δεξιά**.

### Μετατροπές τύπων

| Θέλω | Γράφω | Προσοχή |
|---|---|---|
| `int` → `double` | αυτόματα (διεύρυνση) | `byte → short → int → long → float → double`, `char → int` |
| `double` → `int` | `(int) x` | **κόβει**: `(int) 3.9 = 3`, `(int) -2.7 = -2` |
| στρογγυλοποίηση | `(int) Math.round(x)` | `round` → `long` |
| πραγματική διαίρεση ακεραίων | `(double) a / b` | ✗ `(double)(a / b)` – έχει ήδη κοπεί |
| `String` → αριθμός | `Integer.parseInt(s)`, `Double.parseDouble(s)` | `NumberFormatException` |
| αριθμός → `String` | `"" + x` | |
| `char` ↔ `int` | `(int) 'A' = 65`, `(char) 65 = 'A'` | `'a' + 1` είναι `int` (98) |
| ψηφίο-χαρακτήρας → αριθμός | `c - '0'` | `'7' - '0' = 7` |
| τυχαίος ακέραιος στο `[a, b]` | `a + (int)(Math.random() * (b - a + 1))` | ✗ `(int) Math.random() * N` = 0 |

`int x = 2.5;` ✗ · `float f = 1.5;` ✗ · `long L = 3000000000;` ✗ · `char c = 'a'; c = c + 1;` ✗ · αλλά `c += 1;` ✓ (σιωπηρό cast).

### `String`, `char`, `boolean`, `Math`

| Έκφραση | Τιμή | Γιατί |
|---|---|---|
| `"1" + 2 + 3` | `"123"` | από αριστερά: `String` + … = συνένωση |
| `1 + 2 + "3"` | `"33"` | πρώτα `1+2 = 3` |
| `"x" + 2` | `"x2"` | |
| `'a' + 'b'` | `195` | `char + char` = `int` |
| `"" + 'a' + 'b'` | `"ab"` | |
| `'x' + 2` | `122` | |

ASCII: `' '` = 32 · `'0'` = 48 · `'A'` = 65 · `'a'` = 97 · κεφαλαία **πριν** τα μικρά · `'a' - 'A'` = 32.

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
|---|---|---|---|---|
| F | F | F | F | T |
| F | T | F | T | T |
| T | F | F | T | F |
| T | T | **T** | T | F |

Δίσεκτο: `(y % 4 == 0 && y % 100 != 0) || y % 400 == 0`. **`Math`**: `abs max min sqrt pow` (→ `double`) `exp log` (= ln) `sin cos` (ακτίνια) `round` (→ `long`) `random` ([0, 1)) `floor ceil`, `Math.PI`. Δεν υπάρχει τελεστής δύναμης: `^` είναι XOR (`6 ^ 4 = 2`).

| Ανακρίβεια | Παράδειγμα |
|---|---|
| Στρογγυλοποίηση | `0.1 + 0.2 != 0.3` → σύγκρινε με `Math.abs(a - b) < 1e-9` |
| Ακύρωση | `1 + 1e-17 == 1` |
| Υπορροή | `1e-200 * 1e-200 = 0.0` |
| Υπερχείλιση | `1e308 * 10 = Infinity` · `int`: τυλίγεται |

> [!warning] Παγίδες της Ενότητας II
> - `1/2*x` = 0 · `(a + b)/2` με ints κόβει · `5/2*2.0` = `4.0`
> - `"Sum: " + a + b` → συνένωση (`"Sum: 12"`), όχι άθροισμα
> - `010` = 8 (οκταδικό) · `6 ^ 4` = 2
> - `Math.round(2.5)` = 3, `Math.round(-2.5)` = −2
> - `int` 13! υπερχειλίζει σιωπηλά
> - `1 <= x <= 10` ✗ compile → `1 <= x && x <= 10`

## 3. Συνθήκες και επιλογή (Ενότητα III)

| Κανόνας | Παράδειγμα |
|---|---|
| **Short-circuit**: `false && E` και `true \|\| E` δεν αποτιμούν το `E` | `x != 0 && y / x > 2` – ασφαλές |
| Φρουρός **πρώτος** | `pos < n && a[pos] != item` (ανάποδα → εκτός ορίων) |
| `&&` πριν `\|\|` | `a \|\| b && c` = `a \|\| (b && c)` |
| De Morgan | `!(A && B)` = `!A \|\| !B` · `!(A \|\| B)` = `!A && !B` |
| Συμπλήρωμα | `!(x < 5)` = `x >= 5` · `!(x == 5)` = `x != 5` |
| Πραγματικοί: ποτέ `==` | `Math.abs(a - b) < EPS` |

| Εντολή | Σύνταξη | Σημείωση |
|---|---|---|
| `if` / `if-else` | `if (C) S1 else S2` | χωρίς `{}` το σώμα είναι **μία** εντολή |
| Αλυσίδα | `if (C1) … else if (C2) … else …` | η **πρώτη** αληθής κερδίζει |
| `switch` | `switch (e) { case 'A': case 'a': …; break; default: … }` | `int`/`char`/`String`/`byte`/`short` ✓ · `double`/`long`/`boolean` ✗ · χωρίς `break` → **fall-through** |

Το `else` ανήκει στο **πλησιέστερο** `if` χωρίς `else` (κρεμάμενο else) – η εσοχή δεν μετράει.

> [!example]- Μέση τιμή τριών (ενδιάμεση 2023, Ε.5)
> ```java
> if ((x >= y && y >= z) || (x <= y && y <= z)) f = y;
> else if ((x >= z && z >= y) || (x <= z && z <= y)) f = z;
> else f = x;
> ```
> Με `>=`/`<=` (όχι `>`/`<`) για να δουλεύουν οι ισοπαλίες: `(5, 5, 1)` → 5. Ολόκληρη η συνθήκη του `if` μέσα σε **μία** εξωτερική παρένθεση.

> [!warning] Παγίδες επιλογής
> - `if (x > 0);` → κενή εντολή, το σώμα εκτελείται **πάντα**
> - `if (x = 5)` ✗ compile (`int` δεν είναι `boolean`)
> - Ανεξάρτητα `if` αντί για `else if` → μπορεί να εκτελεστούν πολλά
> - `switch` χωρίς `break` → εκτελεί και τα επόμενα `case`
> - `switch (c):` ✗ – η σύνταξη είναι `switch (c) { … }`

## 4. Επανάληψη (Ενότητα III)

| Βρόχος | Σύνταξη | Σώμα εκτελείται |
|---|---|---|
| `while` | `while (C) S` | 0 ή περισσότερες |
| `do-while` | `do S while (C);` ← **με `;`** | **τουλάχιστον 1** |
| `for` | `for (αρχ; συνθ; βήμα) S` | 0 ή περισσότερες · σειρά: αρχ, συνθ, S, βήμα, συνθ, S, βήμα, …, συνθ (ψευδής) |
| for-each | `for (int v : a) S` | μία ανά στοιχείο, **χωρίς** δείκτη, δεν αλλάζει τον πίνακα |

**Ισοδυναμίες:** `for (α; σ; ε) β` ≡ `α; while (σ) { β; ε; }` · `do β while (σ);` ≡ `β; while (σ) β`.

**Πλήθος επαναλήψεων:** `i = 0; i < N` → N · `i = 0; i <= N` → N+1 · `i = 1; i <= N; i += 2` → ⌈N/2⌉ · φωλιασμένοι ανεξάρτητοι N·M · `j` από `i` έως `N-1` → N(N+1)/2.

| Τελεστής | Σημαίνει |
|---|---|
| `x += e` | `x = x + (e)` (με σιωπηρό cast) · `a *= b + c` = `a = a * (b + c)` |
| `++x` / `x++` | αύξησε και **μετά** δώσε / δώσε και **μετά** αύξησε |
| `i = i++` | το `i` **δεν** αλλάζει |
| `x =+ 3` | `x = +3` – typo που κάνει compile |

| Μοτίβο | Αρχική τιμή | Σώμα |
|---|---|---|
| Άθροισμα | `sum = 0` | `sum += …` |
| Γινόμενο / παραγοντικό | `prod = 1` | `prod *= i` |
| Μέτρηση | `count = 0` | `if (…) count++;` |
| Μέγιστο | `max = a[0]` ή `-∞` | `if (v > max) max = v;` |
| Ψηφία | – | `while (n != 0) { d = n % 10; n /= 10; }` |
| Έλεγχος εγκυρότητας | – | `do { διάβασε } while (άκυρο);` |
| Δυνάμεις/όροι σειράς με έναν βρόχο | `num = 1, den = 1` | `num *= x; den *= (i+1);` → `xⁿ/n!` |
| Monte Carlo | `wins = 0` | `for` πειράματα { `while` ένα πείραμα } |

Καταστροφή του τζογαδόρου (III-68): P(νίκη) = stake/goal · αναμενόμενα στοιχήματα = stake × (goal − stake).

> [!warning] Παγίδες επανάληψης
> - `for (…);` ή `while (…);` → **κενό σώμα**: `for (int i = N; i > 0; --N);` με σταθερό `i` → **άπειρος** βρόχος
> - Λάθος μεταβλητή στο βήμα (`--N` αντί για `--i`) → άπειρος
> - `while (x != 0.0)` με `double` → μπορεί να μη σταματήσει ποτέ
> - Η μεταβλητή του `for (int i …)` δεν υπάρχει μετά τον βρόχο
> - `while (false) S` → compile error (unreachable)
> - `do … while (C)` χωρίς `;` ✗

## 5. Μέθοδοι (στατικές)

```java
public static int sumDigit(int x) {      // επιστρέφει int
   int sum = 0;
   while (x != 0) { sum += x % 10; x = x / 10; }
   return sum;
}
public static void show(int[] a) { … }   // void: δεν επιστρέφει
```

- `return` τερματίζει τη μέθοδο αμέσως· σε `void` γράφεται χωρίς τιμή (`return;`).
- Οι παράμετροι παίρνουν **αντίγραφο** της τιμής του ορίσματος (για πίνακα/String: αντίγραφο της **αναφοράς**) – [[#6. Πίνακες μιας διάστασης (Ενότητα IV)|§6]].
- `private` = μόνο μέσα στην κλάση · `public` = και από άλλες κλάσεις (`Κλάση.μέθοδος(…)`).
- Τοπικές μεταβλητές: δεν έχουν προεπιλεγμένη τιμή – χρήση πριν την ανάθεση → compile error. Μια μεταβλητή που αρχικοποιείται **μόνο μέσα σε `if`** μετράει ως μη αρχικοποιημένη.
- **Αναδρομή**: μέθοδος που καλεί τον εαυτό της· χρειάζεται **βασική περίπτωση** και **πρόοδο** ([[02 - Διαδραστική Είσοδος και Αναδρομή|VII – 02]]).
- Java **δεν** έχει `unsigned` – όλοι οι ακέραιοι τύποι έχουν πρόσημο.

## 6. Πίνακες μιας διάστασης (Ενότητα IV)

| Βήμα | Κώδικας |
|---|---|
| Δήλωση + υλοποίηση | `double[] a = new double[N];` – μέγεθος **σταθερό** μετά |
| Με τιμές | `int[] x = {6, 2, 7};` (μόνο στη δήλωση) · αλλιώς `x = new int[] {6, 2, 7};` |
| Μέγεθος | `a.length` (**πεδίο**, χωρίς `()`) · `s.length()` για `String` |
| Δείκτες | `0 … a.length − 1` · εκτός → `ArrayIndexOutOfBoundsException` |
| Προεπιλογές | `0`, `0.0`, `false`, `'\u0000'`, `null` (για `String`) |

| Σκοπός | Κώδικας |
|---|---|
| Μέσος όρος | `for (…) sum += a[i];` → `sum / a.length` (με `int` πίνακα: `(double) sum / a.length`) |
| Αντιγραφή | `b = new int[N]; for (…) b[i] = a[i];` (✗ `b = a`) |
| Αντιστροφή | `for (i = 0; i < N/2; i++) { t = a[i]; a[i] = a[N-1-i]; a[N-1-i] = t; }` – **μέχρι τη μέση** |
| Ανταλλαγή | `t = a[i]; a[i] = a[j]; a[j] = t;` – και οι **τρεις** εντολές |
| Ανακάτεμα (Fisher–Yates) | `r = i + (int)(Math.random() * (N - i));` και ανταλλαγή `a[i]`, `a[r]` |
| Ολίσθηση δεξιά | **από το τέλος**: `for (i = N-1; i > 0; i--) a[i] = a[i-1];` |
| «Μεγάλωμα» | νέος πίνακας `length + 1`, αντιγραφή, επιστροφή: `a = add(a, x);` |
| Αραιός → πυκνός | μέτρα μη μηδενικά `c`, `B = new int[2*c]`, τιμές στις θέσεις `0..c-1`, δείκτες στις `c..2c-1` |

| Κώδικας | Αποτέλεσμα |
|---|---|
| `int[] b = a;` | **ίδιος** πίνακας (alias) |
| `a == b` | ίδια **διεύθυνση**; · περιεχόμενα: `Arrays.equals(a, b)` |
| `System.out.println(a)` | `[I@1b6d…` (διεύθυνση) |
| `void f(int[] t) { t[0] = 9; }` | ο καλών **βλέπει** την αλλαγή |
| `void f(int[] t) { t = new int[3]; }` | ο καλών **δεν** βλέπει |
| `void f(int n) { n++; }` | ο καλών **δεν** βλέπει |

### Αλγόριθμοι

```java
// Γραμμική αναζήτηση – φρουρός πρώτα
for (pos = 0; pos < x.length && item != x[pos]; ++pos) ;
if (pos == x.length) /* not found */;

// Δυαδική αναζήτηση – ΜΟΝΟ σε ταξινομημένο πίνακα, ~log₂N βήματα
int Min = 0, Max = table.length - 1, pos;
while (Min <= Max) {
   pos = (Min + Max) / 2;
   if (item > table[pos])      Min = pos + 1;
   else if (item < table[pos]) Max = pos - 1;
   else break;                                  // βρέθηκε
}

// Κόσκινο του Ερατοσθένη
boolean[] isPrime = new boolean[N+1];
for (int i = 2; i <= N; i++) isPrime[i] = true;
for (int i = 2; i*i <= N; i++)
   if (isPrime[i])
      for (int j = i; i*j <= N; j++) isPrime[i*j] = false;

// Συλλέκτης κουπονιών – ~N ln N κάρτες
boolean[] found = new boolean[N];
while (valcnt < N) {
   int val = (int)(Math.random() * N);
   cardcnt++;
   if (!found[val]) { valcnt++; found[val] = true; }
}

// Ταξινόμηση με εισαγωγή (ενδιάμεση 2022, Ε.13)
for (int i = 1; i < t.length; i++) {
   boolean stop = false;
   for (int j = i; j > 0 && !stop; --j)
      if (t[j] < t[j-1]) { double temp = t[j]; t[j] = t[j-1]; t[j-1] = temp; }
      else stop = true;
}
```

Έλεγχος πρώτου: `for (i = 2; i*i <= N; i++) if (N % i == 0) break;` → πρώτος αν `i*i > N` (⚠️ λάθος για N ≤ 1). `break` βγαίνει μόνο από τον **πιο εσωτερικό** βρόχο/`switch`. Τράπουλα: θέση = `εξωτερικός * (μέγεθος εσωτερικού) + εσωτερικός`.

> [!warning] Παγίδες πινάκων
> - `i <= a.length` → εκτός ορίων · `a.length()` ✗ · `s.length` ✗
> - `max = 0` με αρνητικά στοιχεία → λάθος · αρχικοποίησε με `a[0]`
> - Αντιστροφή έως `N` (όχι `N/2`) → ο πίνακας μένει **ίδιος**
> - Ανταλλαγή με λάθος τελευταία εντολή (`x[i] = temp` αντί `x[n-1-i] = temp`) → ο πίνακας μένει **ίδιος** (2022, Ε.2)
> - `b = a` δεν αντιγράφει · `a == b` δεν συγκρίνει περιεχόμενα
> - Αλλαγή στοιχείων μέσα σε for-each → χωρίς αποτέλεσμα
> - Δυαδική αναζήτηση σε αταξινόμητο πίνακα → σιωπηλά λάθος
> - `r = i + (int) Math.random() * (N-i)` → κανένα ανακάτεμα

## 7. Συμβολοσειρές (Ενότητα VI)

> [!note] Ορισμοί
> - **Αφηρημένος Τύπος Δεδομένων (ΑΤΔ)**: ξέρουμε **«τι»** κάνει (διεπαφή/API), όχι **«πώς»** (υλοποίηση) – απόκρυψη πληροφοριών.
> - Το `String` είναι **«ενσωματωμένο» αντικείμενο**: μεταβλητή `String` = **δείκτης** σε αντικείμενο. **Αμετάβλητο** (immutable): καμία μέθοδος δεν το αλλάζει, επιστρέφουν **νέο**.
> - **Μέθοδος αναφοράς**: καλείται πάνω σε αντικείμενο (`s.length()`), όχι πάνω στην κλάση. **Κατασκευαστής**: `new String("x")`.

| Κλήση (`s = "hello"`) | Τιμή | Προσοχή |
|---|---|---|
| `s.length()` | `5` | |
| `s.charAt(1)` | `'e'` | `charAt(5)` → `StringIndexOutOfBoundsException` |
| `s.substring(1, 3)` | `"el"` | **χωρίς** το τέλος · `substring(5)` = `""` |
| `s.indexOf("l")` | `2` | δεν βρέθηκε → **`-1`** · `indexOf("l", 3)` = `3` |
| `s.contains("ell")` · `startsWith` · `endsWith` | `true` | διάκριση κεφαλαίων |
| `s.equals("hello")` | `true` | **ποτέ** `==` για περιεχόμενα |
| `s.compareTo(t)` | `<0`, `0`, `>0` | `"Zebra" < "apple"` · `"10" < "9"` · `s1 < s2` ✗ compile |
| `s.toUpperCase()` | `"HELLO"` | το `s` μένει ίδιο – θέλει `s = s.toUpperCase();` |
| `s.split(",")` · `s.replace(a, b)` · `s.trim()` | | `split(".")` → κενός πίνακας (regex) |

| Δημιουργία | `== "java"` | `equals("java")` |
|---|---|---|
| `"java"`, `"ja" + "va"` (σταθερές) | `true` | `true` |
| `new String("java")`, `x += "va"`, `substring(…)` | **`false`** | `true` |

| Πρόγραμμα | Πυρήνας | Παγίδα |
|---|---|---|
| Παλινδρομικό | `for (i < N/2) if (s.charAt(i) != s.charAt(N-1-i)) return false;` | κεφαλαία, κενά |
| Επέκταση αρχείου | `dot = s.indexOf("."); s.substring(dot+1)` | `-1` · **πρώτη** τελεία |
| Μέτρηση γραμμών/λέξεων | `while (!StdIn.isEmpty()) { readLine(); count++; }` · σημαία `beg` | τελευταία λέξη γραμμής · κενές γραμμές στο τέλος |
| Γονίδιο | `codon = s.substring(i, i+3)` · start → `beg = i` · stop → `gene = s.substring(beg+3, i)`, αν μήκος `% 3 == 0` | `equals`, όχι `==` |
| Πυραμίδα ύψους `h` | γραμμή `i`: `h−i` κενά + `2i−1` χαρακτήρες | `' ' + 'x'` = 152 |
| `TabLib` | `add` (νέος πίνακας, θέση 0), `select`, `remove`, `reverse` | `tab = add(tab, s)` |

> [!warning] Παγίδες συμβολοσειρών
> - `==` σε `String` → πάντα `equals`
> - `s.toUpperCase();` χωρίς ανάθεση → τίποτα · `s.charAt(0) = 'x'` ✗
> - `String.length()` ✗ (μέθοδος αναφοράς) · `s.length` ✗
> - `"Another string".substring(0, 8)` = `"Another "` (με κενό)
> - `String s; s += "x";` (τοπική) ✗ compile · `String s = null; s += "x";` → `"nullx"`
> - τυπογραφικά εισαγωγικά `“ ”` ✗ compile

## 8. Οι βιβλιοθήκες του βιβλίου

| Κλάση | Ρόλος | Μέθοδοι |
|---|---|---|
| `StdIn` | standard είσοδος | **στατικές**: `isEmpty readInt readDouble readString readLine readAll readChar` |
| `StdOut` ≡ `System.out` | standard έξοδος | στατικές: `print println printf` |
| `In` / `Out` | αρχεία | **αναφοράς**: `new In(name)`, `f.readInt()`, `f.close()` · `new Out(name)` **σβήνει** |
| `StdDraw` | γραφικά | στατικές: `line circle square filledSquare setXscale setPenColor …` |
| `Scanner` (Java) | είσοδος | `new Scanner(System.in)`, `hasNext nextInt nextDouble next nextLine` |

`isEmpty()` = «δεν απομένει **λέξη**» → κενοί χαρακτήρες στο τέλος «δεν υπάρχουν». `readString()` = λέξη · `readLine()` = υπόλοιπο γραμμής χωρίς `\n` · `readAll()` = όλο το υπόλοιπο με τα `\n`. Μετά από `readInt()`, η `readLine()` δίνει `""` (το υπόλοιπο της ίδιας γραμμής).

## 9. Είσοδος και Έξοδος (Ενότητα VII)

![[Επανάληψη - Πηγές Εισόδου και Εξόδου.png|800]]

| Version του `Average` | Πηγή | Εκτέλεση |
|---|---|---|
| 1 | ορίσματα: `for (String s : args) sum += Double.parseDouble(s);` | `java Average 45 67 2` |
| 2 | `while (!StdIn.isEmpty()) sum += StdIn.readDouble();` + prompts | `java Average`, τέλος `Ctrl-D` / `Ctrl-Z, Enter` |
| 3 | ίδιο χωρίς prompts | `java Average < Data.txt` |
| σωλήνας | ίδιο | `java RandomSeq 50 20 40 \| java Average` |
| 5 | `In f = new In(args[0]); … f.readDouble()` | `java Average Data.txt` |

- **Ορίσματα**: πάντα `String`· χωρίς ορίσματα `args.length == 0` (όχι `null`)· `"a b"` = ένα όρισμα· `<`, `>`, `|` **δεν** μπαίνουν στο `args`.
- **`printf`**: `%[-][πλάτος][.ακρίβεια]κωδικός` · `%8.4f` → `" 84.6000"` · `%-5d` αριστερή στοίχιση · το πλάτος δεν κόβει · `%d` με `double` → εξαίρεση στην εκτέλεση.
- **Αναδρομή – `Reverse`**: `n = readInt(); if (n == 0) return; rev(i+1); println(n);` → η στοίβα κρατά τα `n`, τυπώνονται ανάποδα (LIFO).
- **Πίνακας-στοίβα**: `xs = add(xs, num);` – νέο στοιχείο στη θέση 0.
- **Ανακατεύθυνση** `<` `>` και **σωλήνωση** `|`: τις κάνει το λειτουργικό σύστημα· ο κώδικας ίδιος.
- **Caps** `(char)(c - 'a' + 'A')` · **Centralize** `left = (N-len)/2; right = N-(len+left)` · **DoubleSpace** `print(s + "\n\n")`. Σειρά σε σωλήνα: `Caps`/`Centralize` αντιμετατίθενται και είναι ταυτοδύναμα, το `DoubleSpace` όχι.
- **Αρχεία**: `Append` (όλα με σειρά στο `System.out`), `Merge` (γραμμή-γραμμή όσο έχουν **και τα δύο**, μετά `readAll` του υπολοίπου), `Concatenate` (**πρώτα** `readAll`, **μετά** `new Out`).
- **StdDraw**: αρχικά άξονες 0…1, **y προς τα πάνω**· `square(x, y, r)` → κέντρο, **μισή** πλευρά· σκακιέρα: `if ((ri + cj) % 2 == 0) filledSquare(ri - 0.5, cj - 0.5, 0.5)`.

> [!warning] Παγίδες της Ενότητας VII
> - `args[0] + args[1]` = συνένωση · `Integer.parseInt("3.5")` ✗
> - κενή είσοδος → `sum/cnt` = `NaN`
> - `isEmpty()` + `readChar()` δεν μετρά το τελικό `\n`
> - `new Out(x)` πριν διαβαστεί το `x` → χάνεται · `java Concatenate d d` → διπλασιάζει
> - `In.readInt()` ✗ (αναφοράς) · `Scanner(System.in)` χωρίς `new` ✗
> - prompts + ανακατεύθυνση → σκουπίδια στην έξοδο

## 10. Οι 25 πιο συχνές παγίδες

> [!important] Έλεγξε κάθε απάντηση απέναντι σε αυτή τη λίστα
> 1. `int / int` κόβει: `1/x` με `x = 2` → `0`
> 2. `String +` από αριστερά: `"x" + 2 + 3` = `"x23"`, `2 + 3 + "x"` = `"5x"`
> 3. `char + int` = `int`: `'x' + 2` = `122`
> 4. `;` μετά από `for`/`while`/`if` → κενό σώμα
> 5. Μετρητής βρόχου που δεν αλλάζει (λάθος μεταβλητή στο βήμα) → άπειρος βρόχος
> 6. `=` αντί για `==` σε συνθήκη → compile error
> 7. Σειρά στο `&&`: ο φρουρός ορίων **πρώτος**
> 8. `||` αντί `&&` σε συνθήκη συνέχισης → ο βρόχος δεν σταματά / εκτός ορίων
> 9. `i <= a.length`, `charAt(s.length())` → εκτός ορίων
> 10. `a.length` (πίνακας) vs `s.length()` (String)
> 11. `==` σε `String`/πίνακες συγκρίνει διευθύνσεις
> 12. `max = 0` με αρνητικά
> 13. Αντιστροφή μέχρι το `N` ή λάθος ανταλλαγή → ίδιος πίνακας
> 14. Πέρασμα `int` σε μέθοδο: η αλλαγή δεν επιστρέφει (2022, Ε.4)
> 15. Μέθοδος που επιστρέφει νέο πίνακα/String χωρίς ανάθεση
> 16. Τοπική μεταβλητή αρχικοποιημένη μόνο σε `if` → compile error (2022, Ε.6)
> 17. `switch` χωρίς `break` · `switch (c):` ✗
> 18. `%` πριν το `-`: `i - 10000 % N` = `i - (10000 % N)` (2022, Ε.5)
> 19. `i < 20000` όταν ζητείται «έως 20000» → χάνεται το τελευταίο
> 20. Μεταβλητή βρόχου χωρίς δήλωση (`for (i = 0; …)` χωρίς `int i`) ✗
> 21. `(int) y / x` = `((int) y) / x` – το cast δένει πιο σφιχτά από τη διαίρεση
> 22. `double` σε συνθήκη ισότητας
> 23. Υπερχείλιση `int` σιωπηλά (παραγοντικό)
> 24. `args` κενό → `args[0]` εξαίρεση· `NaN` από `0.0/0`
> 25. `isEmpty()` αγνοεί κενούς χαρακτήρες στο τέλος
