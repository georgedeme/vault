# 02 - Βασική Επεξεργασία Πινάκων

Τα τυπικά «μοτίβα» επεξεργασίας πινάκων με βρόχους, και η νέα μορφή `for` (for-each) (διαφάνειες IV-8 … IV-10, IV-27).

> [!important] Κατάλληλη αλγοριθμική δομή: **επανάληψη**
> Επεξεργασία πίνακα = βρόχος πάνω στους δείκτες `0 … a.length − 1`. Γράφε **πάντα** `i < a.length` (όχι σταθερές όπως `i < 10` – «αποφυγή hardwired σταθερών», IV-24).

## 1. Παραδείγματα επεξεργασίας πινάκων (IV-9)

| Σκοπός | Κώδικας |
|---|---|
| Δημιουργία πίνακα με τυχαίες τιμές | `double[] a = new double[N];`<br>`for (int i = 0; i < N; i++)`<br>`    a[i] = Math.random();` |
| Εκτύπωση τιμών, μία ανά γραμμή | `for (int i = 0; i < N; i++)`<br>`    System.out.println(a[i]);` |
| Εύρεση μέγιστου | `double max = Double.NEGATIVE_INFINITY;`<br>`for (int i = 0; i < N; i++)`<br>`    if (a[i] > max) max = a[i];` |
| Μέσος όρος | `double sum = 0.0;`<br>`for (int i = 0; i < N; i++)`<br>`    sum += a[i];`<br>`double average = sum / N;` |
| Αντιγραφή σε άλλο πίνακα | `double[] b = new double[N];`<br>`for (int i = 0; i < N; i++)`<br>`    b[i] = a[i];` |
| Αντιστροφή στοιχείων | `for (int i = 0; i < N/2; i++) {`<br>`    double temp = b[i];`<br>`    b[i] = b[N-1-i];`<br>`    b[N-i-1] = temp;`<br>`}` |

### Μέγιστο – γιατί `NEGATIVE_INFINITY`;

> [!warning] Η παγίδα του `max = 0` ➕
> ```java
> int[] d = {-5, -2, -9};
> int max = 0;
> for (int i = 0; i < d.length; i++) if (d[i] > max) max = d[i];
> // max == 0  ✗  – το 0 δεν υπάρχει καν στον πίνακα!
> ```
> Η αρχική τιμή πρέπει να είναι **μικρότερη ή ίση από κάθε στοιχείο**:
> - `Double.NEGATIVE_INFINITY` (για `double`) ή `Integer.MIN_VALUE` (για `int`) – όπως η διαφάνεια
> - ή **το πρώτο στοιχείο**: `max = a[0];` και βρόχος από `i = 1` (προϋποθέτει `a.length > 0`)

> [!example]- Θέση (δείκτης) του μέγιστου και ελάχιστο ➕
> ```java
> int maxPos = 0;
> for (int i = 1; i < a.length; i++)
>     if (a[i] > a[maxPos]) maxPos = i;      // > κρατά την ΠΡΩΤΗ εμφάνιση, >= την ΤΕΛΕΥΤΑΙΑ
>
> double min = Double.POSITIVE_INFINITY;
> for (int i = 0; i < a.length; i++)
>     if (a[i] < min) min = a[i];
> ```

### Μέσος όρος

> [!warning] Ακέραιος πίνακας → ακέραια διαίρεση ➕
> ```java
> int[] v = {1, 2, 3, 4};
> int sum = 0;
> for (int i = 0; i < v.length; i++) sum += v[i];
> double avg1 = sum / v.length;            // 2.0  ✗
> double avg2 = (double) sum / v.length;   // 2.5  ✓
> ```
> Και: μέσος όρος **κενού** πίνακα → `0.0 / 0` = `NaN` (double) ή `ArithmeticException` (int).

## 2. Αντιστροφή – δύο εκδοχές (IV-9, IV-10)

**Με έναν δείκτη** (IV-9): ανταλλάσσεις το `b[i]` με το «συμμετρικό» `b[N-1-i]`, για τη μισή μόνο διαδρομή.

**Με δύο δείκτες** (IV-10):
```java
for (int i = 0, j = N-1; i < j; i++, j--) {
    double temp = b[i];
    b[i] = b[j];
    b[j] = temp;
}
```

| i | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| πριν | 4 | 5 | −1 | 2 | 2 | 8 |
| μετά | 8 | 2 | 2 | −1 | 5 | 4 |

> [!warning] Γιατί **μέχρι τη μέση**; ➕
> Αν ο βρόχος πάει μέχρι `i < N` (ολόκληρο τον πίνακα), κάθε ζεύγος ανταλλάσσεται **δύο φορές** → ο πίνακας μένει **ίδιος**!
> - Για **περιττό** N, το μεσαίο στοιχείο μένει στη θέση του (`i < N/2` το παραλείπει σωστά, π.χ. N = 5 → i = 0, 1).
> - Στη διαφάνεια γράφεται `b[N-1-i]` και `b[N-i-1]` – είναι **το ίδιο** (αντιμεταθετικότητα).

## 3. Εσωτερικό γινόμενο – Vector Dot Product (IV-8)

Το άθροισμα των γινομένων αντίστοιχων στοιχείων δύο διανυσμάτων `x[]` και `y[]`:

```java
double[] x = { 0.3, 0.6, 0.1 };
double[] y = { 0.5, 0.1, 0.4 };
double sum = 0.0;
for (int i = 0; i < N; i++) {
    sum += x[i]*y[i];
}
```

| i | x[i] | y[i] | x[i]·y[i] | sum |
|---|---|---|---|---|
| 0 | 0.3 | 0.5 | 0.15 | 0.15 |
| 1 | 0.6 | 0.1 | 0.06 | 0.21 |
| 2 | 0.1 | 0.4 | 0.04 | **0.25** |

⚠️ *Σημείωση: στη διαφάνεια το `N` δεν ορίζεται πουθενά· σωστά `i < x.length` (και οι δύο πίνακες πρέπει να έχουν ίδιο μήκος).*

## 4. Η «νέα» μορφή `for` – for-each (IV-27)

```java
public static void displayDeck(String[] deck) {
    for (String s : deck)            // Νέα μορφή for –
        System.out.println(s);       // διέρχεται των στοιχείων του πίνακα
}
```
Διαβάζεται: «**για κάθε** `s` **στον** `deck`». Η μεταβλητή `s` παίρνει διαδοχικά τις τιμές `deck[0]`, `deck[1]`, …

> [!warning] Περιορισμοί του for-each ➕
> - **Δεν** έχεις πρόσβαση στον **δείκτη** `i` (π.χ. για «θέση του μέγιστου» ή σύγκριση γειτονικών).
> - **Δεν** μπορείς να **αλλάξεις** στοιχεία πίνακα βασικού τύπου:
>   ```java
>   int[] a = {1, 2, 3};
>   for (int v : a) v = 0;         // αλλάζει μόνο το αντίγραφο v
>   // a == {1, 2, 3}  – αμετάβλητος!
>   ```
> - Διατρέχει **πάντα όλο** τον πίνακα, από την αρχή προς το τέλος.
> - Ιδανικό για: άθροισμα, εκτύπωση, μέτρηση, «υπάρχει κάποιο…;» (IV-36: `for (int x : cs) if (x == 0) return false;`).

## 5. Εκτύπωση πίνακα ➕

> [!warning] `System.out.println(a)` **δεν** τυπώνει τα στοιχεία
> ```java
> double[] a = {1.0, 2.0};
> System.out.println(a);                    // [D@1b6d3586  (τύπος + διεύθυνση)
> System.out.println(java.util.Arrays.toString(a));   // [1.0, 2.0]
> ```
> Εξαίρεση-παγίδα: για `char[]` το `println(cs)` **τυπώνει** τους χαρακτήρες (`hi`), αλλά το `"cs=" + cs` τυπώνει πάλι διεύθυνση.
> Στις εξετάσεις, γράψε τον **βρόχο** εκτύπωσης· το `Arrays.toString` είναι βολικό για αποσφαλμάτωση.

## 6. Άλλα κλασικά μοτίβα ➕

| Σκοπός | Κώδικας |
|---|---|
| Μέτρηση στοιχείων με ιδιότητα | `int c = 0; for (int i = 0; i < a.length; i++) if (a[i] > 0) c++;` |
| Υπάρχει στοιχείο ίσο με `k`; | `boolean found = false; for (int i = 0; i < a.length && !found; i++) if (a[i] == k) found = true;` |
| Όλα θετικά; | `boolean all = true; for (int v : a) if (v <= 0) { all = false; break; }` |
| Ολίσθηση αριστερά κατά 1 | `for (int i = 0; i < a.length - 1; i++) a[i] = a[i+1];` |
| Ολίσθηση δεξιά κατά 1 | `for (int i = a.length - 1; i > 0; i--) a[i] = a[i-1];` ← **από το τέλος**! |
| Ιστόγραμμα / μετρητές ανά τιμή | `int[] count = new int[10]; for (int d : digits) count[d]++;` |
| Ταξινομημένος; | `for (int i = 1; i < a.length; i++) if (a[i-1] > a[i]) return false;` ← ξεκινά από `i = 1` |

> [!example]- Γιατί η ολίσθηση δεξιά πάει ανάποδα
> Με `a = {1, 2, 3, 4}` και `for (int i = 1; i < a.length; i++) a[i] = a[i-1];` (από την αρχή):
> `a[1] = a[0] = 1` → `a[2] = a[1] = 1` → `a[3] = a[2] = 1` → **{1, 1, 1, 1}** ✗ – κάθε τιμή «πατάει» την επόμενη πριν μετακινηθεί.
> Από το τέλος: `a[3] = 3`, `a[2] = 2`, `a[1] = 1` → **{1, 1, 2, 3}** ✓.

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - `max = 0` για πίνακα που μπορεί να έχει αρνητικά.
> - Ακέραια διαίρεση στον μέσο όρο.
> - Αντιστροφή μέχρι το `N` αντί για `N/2`.
> - Αλλαγή στοιχείων μέσα σε for-each.
> - `println(a)` για εκτύπωση.
> - Σύγκριση γειτονικών `a[i]` με `a[i+1]` με συνθήκη `i < a.length` → εκτός ορίων στο τελευταίο· θέλει `i < a.length - 1`.
