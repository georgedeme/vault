# 07 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα IV.

## 1. Δημιουργία

| Βήμα | Κώδικας |
|---|---|
| Δήλωση | `double[] a;` (ή `double a[];`) |
| Υλοποίηση | `a = new double[N];` — το `N` μπορεί να είναι μεταβλητή, μετά το μέγεθος **μένει σταθερό** |
| Αρχικοποίηση | `for (int i = 0; i < N; i++) a[i] = 0.0;` |
| Όλα μαζί | `double[] a = new double[N];` |
| Λίστα τιμών | `int[] x = {6, 2, 7};` (**μόνο** στη δήλωση) · αλλιώς `x = new int[] {6, 2, 7};` |

**Προεπιλογές στοιχείων:** αριθμοί `0` / `0.0` · `boolean` `false` · `char` `'\u0000'` · `String` `null`
**Δείκτες:** `0 … a.length − 1` · τύπος δείκτη `int` (ή `char`/`short`/`byte`) · εκτός ορίων → `ArrayIndexOutOfBoundsException`
**Μέγεθος:** `a.length` (πεδίο, **χωρίς** `()`) — `s.length()` για `String`

## 2. Μοτίβα

| Σκοπός | Κώδικας |
|---|---|
| Διάσχιση | `for (int i = 0; i < a.length; i++) … a[i] …` |
| Διάσχιση (for-each) | `for (double v : a) … v …` — χωρίς δείκτη, **δεν** αλλάζει στοιχεία |
| Άθροισμα | `double sum = 0.0; for (…) sum += a[i];` |
| Μέσος όρος | `sum / a.length` — με `int` πίνακα: `(double) sum / a.length` |
| Μέγιστο | `max = Double.NEGATIVE_INFINITY` (ή `a[0]`) · `if (a[i] > max) max = a[i];` |
| Αντιγραφή | `b = new double[N]; for (…) b[i] = a[i];` |
| Αντιστροφή | `for (int i = 0; i < N/2; i++) swap(a[i], a[N-1-i])` — **μέχρι τη μέση** |
| Εσωτερικό γινόμενο | `sum += x[i]*y[i];` |
| Ανταλλαγή | `t = a[i]; a[i] = a[j]; a[j] = t;` |
| Ανακάτεμα (Fisher–Yates) | `r = i + (int) (Math.random() * (N-i));` και ανταλλαγή `a[i]`, `a[r]` |
| 2 βρόχοι → 1 πίνακας | θέση = `εξωτερικός * (μέγεθος εσωτερικού) + εσωτερικός` |
| Ολίσθηση δεξιά | από το **τέλος**: `for (i = N-1; i > 0; i--) a[i] = a[i-1];` |

## 3. Αναφορές

| Κώδικας | Αποτέλεσμα |
|---|---|
| `int[] b = a;` | **ίδιος** πίνακας (alias) — αλλαγή στο `b` φαίνεται στο `a` |
| `a == b` | ίδια **διεύθυνση**; (όχι ίδια περιεχόμενα) |
| `Arrays.equals(a, b)` | ίδια περιεχόμενα |
| `System.out.println(a)` | `[I@…` (διεύθυνση) — εκτός από `char[]` |
| μέθοδος `void f(int[] a) { a[0] = 9; }` | **αλλάζει** τον πίνακα του καλούντα |
| μέθοδος `void f(int[] a) { a = new int[3]; }` | **δεν** επηρεάζει τον καλούντα |
| μέθοδος `void f(int x) { x++; }` | **δεν** επηρεάζει τον καλούντα |

## 4. Αλγόριθμοι

| Αλγόριθμος | Ιδέα | Κόστος | Προσοχή |
|---|---|---|---|
| Γραμμική αναζήτηση | σάρωση από την αρχή | N | φρουρός πρώτα: `pos < n && x[pos] != item` |
| Δυαδική αναζήτηση | μέσο, κράτα το μισό | log₂N | **ταξινομημένος** · `while (Min <= Max)` · `pos ± 1` |
| Κόσκινο Ερατοσθένη | σημείωσε πολλαπλάσια πρώτων | — | `new boolean[N+1]` · `i*i <= N` · `j` από `i` |
| Συλλέκτης κουπονιών | `found[val]`, μετρητής διαφορετικών | ~N ln N κάρτες | μέτρα νέο είδος μόνο αν `!found[val]` |
| Έλεγχος πρώτου | διαιρέτης έως √N, `break` | √N | `if (i*i > N)` → πρώτος · ⚠️ N ≤ 1 |

**`break`** = άμεση έξοδος από τον **πιο εσωτερικό** βρόχο/`switch`.

> [!warning] Οι «παγίδες» σε μια ματιά
> - `i <= a.length` → εκτός ορίων στο τέλος
> - `int[] a = {…}` μόνο στη δήλωση · `new int[3] {1,2,3}` ✗
> - `a.length()` ✗ · `s.length` ✗
> - `max = 0` με αρνητικά στοιχεία → λάθος
> - Αντιστροφή μέχρι `N` → ο πίνακας μένει ίδιος
> - `b = a` δεν αντιγράφει · `a == b` δεν συγκρίνει περιεχόμενα
> - `x == t + " " + x.length == t.length` → **δεν κάνει compile** (⚠️ IV-75)
> - `r = i + (int) Math.random() * (N-i)` → κανένα ανακάτεμα
> - `r = (int) (Math.random() * N)` → μεροληπτικό ανακάτεμα
> - Αλλαγή στοιχείων μέσα σε for-each → χωρίς αποτέλεσμα
> - `x[i] - 1 = x[i]` ✗ compile
> - Δυαδική αναζήτηση σε αταξινόμητο πίνακα → σιωπηλά λάθος αποτέλεσμα
