# 09 - Τυπολόγιο

Μία σελίδα, όλα όσα χρειάζεσαι από την Ενότητα III.

## 1. Συνθήκες

| Κανόνας | Παράδειγμα |
|---|---|
| Short-circuit: `false && E` → δεν αποτιμάται η `E` | `x != 0 && y % x > 2` |
| Short-circuit: `true \|\| E` → δεν αποτιμάται η `E` | `x == 0 \|\| y / x > 1` |
| Φρουρός **πρώτα**, φθηνή συνθήκη **πρώτα** | `pos < n && x[pos] != item` |
| Πραγματικοί: ποτέ `==` | `Math.abs(a - b) < 0.0001` |
| `&&` πριν `\|\|` | `a \|\| b && c` = `a \|\| (b && c)` |

**Προτεραιότητα:** κλήσεις μεθόδων › `! + -` (μοναδιαίοι) › `* / %` › `+ -` › `< <= >= >` › `== !=` › `&&` › `||` › `=`

## 2. Άρνηση

| Συνθήκη | Συμπλήρωμα |
|---|---|
| `<` / `<=` | `>=` / `>` |
| `>` / `>=` | `<=` / `<` |
| `==` / `!=` | `!=` / `==` |
| `!(E1 && E2)` | `!E1 \|\| !E2` |
| `!(E1 \|\| E2)` | `!E1 && !E2` |

## 3. Επιλογή

| Εντολή | Σύνταξη | Πότε |
|---|---|---|
| `if` | `if (C) S` | εκτέλεσε S αν C |
| `if-else` | `if (C) S1 else S2` | ακριβώς ένα από τα δύο |
| αλυσίδα | `if (C1) S1 else if (C2) S2 … else Sn` | αμοιβαία αποκλειόμενες περιπτώσεις – η **πρώτη** αληθής κερδίζει |
| `switch` | `switch (e) { case k: … break; default: … }` | μία τιμή vs πολλές σταθερές |

- `if (C); else S` ≡ `if (!C) S` · `if (C) S else;` ≡ `if (C) S`
- Το `else` ανήκει στο **πλησιέστερο** `if` χωρίς `else` (κρεμάμενο else).
- `switch`: `char`/`byte`/`short`/`int`/`String` ✓ · `long`/`double`/`boolean` ✗ · ετικέτες = **σταθερές**, μοναδικές · χωρίς `break` → fall-through.

## 4. Επανάληψη

| Βρόχος | Σύνταξη | Εκτελέσεις σώματος |
|---|---|---|
| `while` | `while (C) S` | **0** ή περισσότερες |
| `do-while` | `do S while (C);` ← **με `;`** | **1** ή περισσότερες |
| `for` | `for (α; σ; ε) S` | 0 ή περισσότερες · σειρά: α σ S ε σ S ε … σ |

| Ισοδυναμία | |
|---|---|
| `while (σ) {β}` | ≡ `if (σ) do {β} while (σ);` ≡ `for (;σ;) {β}` |
| `do {β} while (σ);` | ≡ `{β} while (σ) {β}` |
| `for (α;σ;ε) {β}` | ≡ `α; while (σ) {β; ε}` (⚠️ εκτός αν το `β` έχει `continue`) |

**Πλήθος επαναλήψεων:** `i = 0; i < N` → N · `i = 0; i <= N` → N+1 · `i = 1; i <= N` → N · φωλιασμένοι N×M · τριγωνικοί N(N+1)/2

## 5. Τελεστές

| Τελεστής | Σημαίνει |
|---|---|
| `x += e` | `x = x + (e)` (με σιωπηρό cast) |
| `a *= b + c` | `a = a * (b + c)` — **όχι** `a*b + c` |
| `++x` | αύξησε, **μετά** δώσε την τιμή |
| `x++` | δώσε την τιμή, **μετά** αύξησε |
| `i = i++` | το `i` **δεν** αλλάζει |
| `x =+ 3` | `x = +3` (typo που κάνει compile!) |

## 6. Μοτίβα

| Σκοπός | Αρχική τιμή | Σώμα |
|---|---|---|
| Άθροισμα | `sum = 0` | `sum += i` |
| Γινόμενο / παραγοντικό | `prod = 1` | `prod *= i` (`int` υπερχειλίζει στο 13!) |
| Μέτρηση | `count = 0` | `if (…) count++` |
| Ψηφία | — | `d = n % 10; n /= 10;` όσο `n > 0` |
| Έλεγχος εγκυρότητας | — | `do { διάβασε } while (άκυρο);` |
| Monte Carlo | `wins = 0` | `for` πειράματα { `while` ένα πείραμα } |
| Νόμισμα | — | `Math.random() < 0.5` |

Τζογαδόρος: P(νίκη) = stake / goal · E[στοιχήματα] = stake × (goal − stake)

> [!warning] Οι «παγίδες» σε μια ματιά
> - `;` μετά από `if (…)`, `while (…)`, `for (…)` → κενό σώμα
> - Χωρίς `{ }` το σώμα είναι **μία** εντολή – η εσοχή δεν μετράει
> - `while (false) …` και `for (;false;) …` → **compile error** (unreachable) · ⚠️ η III-41 το λέει «null statement»
> - Εντολή μετά από `while (true)` / `do … while (true);` χωρίς `break` → compile error
> - `while (x != 0.0)` με `double` → άπειρος βρόχος
> - Ανεξάρτητα `if` σε αύξουσα σειρά ορίων → κερδίζει το τελευταίο (φορολογικός συντελεστής)
> - `>` αντί `>=` → λάθος στις ισοπαλίες (μέγιστο τριών, III-31)
> - Μεταβλητή του `for` δεν υπάρχει μετά τον βρόχο
> - `switch` χωρίς `break` → fall-through
> - `1 <= x <= 10` ✗ · `!x > 5` ✗ · `x == 1 || 2` ✗
