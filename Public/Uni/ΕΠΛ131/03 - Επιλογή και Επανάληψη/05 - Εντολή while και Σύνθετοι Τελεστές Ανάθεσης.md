# 05 - Εντολή while και Σύνθετοι Τελεστές Ανάθεσης

Η βασική εντολή επανάληψης υπό συνθήκη και οι συντομογραφίες `+=`, `*=` κτλ. (διαφάνειες III-36 … III-43).

## 1. Μορφές επανάληψης (III-36)

> [!note] Δύο μορφές
> - **Απροσδιόριστη** επανάληψη ή επανάληψη **υπό συνθήκη** → εντολές `while` και `do-while`
>   (δεν ξέρουμε από πριν πόσες φορές)
> - **Απαριθμητή** επανάληψη → εντολή `for`
>   (γνωστός αριθμός επαναλήψεων, μετρητής)

## 2. Εντολή `while` (III-37)

> [!note] Σύνταξη
> ```
> while (συνθήκη) εντολή
> ```
> ```
>        ┌──────────────┐
>        ▼              │
>  ──► ┌────┐  ναι   ┌───┐
>      │ C? │ ─────► │ S │
>      └────┘        └───┘
>        │ όχι
>        ▼
> ```

> [!important] Σημασιολογία
> - Εάν **από την αρχή** δεν ευσταθεί η συνθήκη `C`, η εντολή `S` **δεν θα εκτελεστεί καθόλου** (0 φορές).
> - Διαφορετικά η `S` εκτελείται και αυτό **επαναλαμβάνεται μέχρις ότου η `C` να μην ευσταθεί**.
> - Για να μη δημιουργηθεί **βρόχος άπειρης διάρκειας** (infinite loop), η διεργασία της `S` πρέπει να οδηγεί κάποτε σε κατάσταση όπου η `C` **δεν ευσταθεί** – άρα η `S` πρέπει να **αλλάζει** κάτι από το οποίο εξαρτάται η `C`.

## 3. Παράδειγμα: Άθροισμα 1 + 2 + … + n (III-38)

```java
public class ComputeSum {
    public static void main(String[] args) {
        int n = Integer.parseInt(args[0]);
        int count = 1, sum = 0;
        while (count <= n) {
            sum = sum + count;
            count = count + 1;
        }
        System.out.println("The sum is " + sum);
    }
}
```

> [!example]- Ίχνος για n = 4
>
> | Έλεγχος `count <= n` | `sum` (μετά) | `count` (μετά) |
> |---|---|---|
> | *(αρχή)* | 0 | 1 |
> | 1 ≤ 4 ✓ | 1 | 2 |
> | 2 ≤ 4 ✓ | 3 | 3 |
> | 3 ≤ 4 ✓ | 6 | 4 |
> | 4 ≤ 4 ✓ | 10 | 5 |
> | 5 ≤ 4 ✗ | — έξοδος — | |
>
> Έξοδος: `The sum is 10`. Η συνθήκη ελέγχεται **n + 1** φορές, το σώμα εκτελείται **n** φορές. Για `n = 0` (ή αρνητικό) το σώμα δεν εκτελείται → `0`.

## 4. Παράδειγμα: Δυνάμεις του 2 (III-39)

Να παραχθεί ο πίνακας `x` και `2^x` για `x = 0 … 6`:

```java
public class PowersOfTwo {
    public static void main(String[] args) {
        int count = 0, res = 1;
        while (count <= 6) {
            System.out.println(count + " " + res);
            count = count + 1;
            res = res * 2;
        }
    }
}
```
```
0 1
1 2
2 4
3 8
4 16
5 32
6 64
```

### Υπάρχει κάτι λάθος; (III-40)

```java
int count = 0, res = 1;
while (count <= 6)
    System.out.println(count + " " + res);
    count = count + 1;
    res = res * 2;
```

> [!success]- Απάντηση
> **Ναι.** Χωρίς `{ }`, το σώμα του `while` είναι **μόνο** το `println`. Το `count` δεν αλλάζει ποτέ μέσα στον βρόχο → **άπειρος βρόχος** που τυπώνει `0 1` για πάντα. Οι δύο επόμενες εντολές (παρά την εσοχή) δεν εκτελούνται ποτέ.

## 5. Ακραίες περιπτώσεις (III-41)

```java
/* infinite loop */
while (true) System.out.println("I cannot stop!");

/* null statement */
while (false) System.out.println("????");
while (false);
```

> [!warning] ⚠️ Σημείωση: το `while (false) …` ΔΕΝ κάνει compile
> Η διαφάνεια το χαρακτηρίζει «null statement» (δεν κάνει τίποτα). Στη Java όμως, όταν η συνθήκη είναι η **σταθερά** `false`, το σώμα είναι **απρόσιτος κώδικας** και το `javac` δίνει:
> `error: unreachable statement` – και για τα **δύο** (ακόμη και για το `while (false);` με κενό σώμα).
> Αντίθετα, `while (x > 10) …` με `x = 0` κάνει compile κανονικά και απλά δεν εκτελεί το σώμα – ο compiler δεν «ξέρει» την τιμή του `x`.
> Ομοίως, **μετά** από `while (true) …` (χωρίς `break`) οποιαδήποτε εντολή είναι απρόσιτη → compile error.

> [!warning] Το «αθώο» ερωτηματικό ➕
> ```java
> int i = 0;
> while (i < 10);      // ← σώμα = κενή εντολή, το i δεν αλλάζει ποτέ
> {
>     i++;
> }
> ```
> **Άπειρος βρόχος** – το πρόγραμμα «κολλάει» χωρίς έξοδο.

## 6. Σύνθετοι τελεστές ανάθεσης (III-42, III-43)

> [!note] Σύνταξη και σημασιολογία
> ```
> μεταβλητή τελεστής= έκφραση;
> ```
> σημαίνει
> ```
> μεταβλητή = μεταβλητή τελεστής (έκφραση);
> ```
> Σύνθετοι τελεστές: **`+=`, `-=`, `*=`, `/=`, `%=`**

| Αναλυτικά | Συντομογραφία |
|---|---|
| `count = count + 1;` | `count += 1;` |
| `res = res * 2;` | `res *= 2;` |
| `sum = sum + count;` | `sum += count;` |
| `x = x - 3;` | `x -= 3;` |
| `n = n * (x+1);` | `n *= (x+1);` |

Οι προηγούμενοι βρόχοι γίνονται:
```java
int count = 1, sum = 0;
while (count <= n) {
    sum += count;
    count += 1;
}

int count = 0, res = 1;
while (count <= 6) {
    System.out.println(count + " " + res);
    count += 1;
    res *= 2;
}
```

> [!warning] Κοινό λάθος: παρερμήνευση των σύνθετων τελεστών (III-77)
> `M τ= E` σημαίνει **`M = M τ (E)`** και **όχι** `M = M τ E`. Οι παρενθέσεις γύρω από την `E` είναι **αναγκαίο** στοιχείο.
>
> | Γράφεις | Σημαίνει | ΟΧΙ |
> |---|---|---|
> | `a *= b + c;` | `a = a * (b + c);` | `a = a * b + c;` |
> | `x -= y - 1;` ➕ | `x = x - (y - 1);` | `x = x - y - 1;` |
> | `n /= 2 + 3;` ➕ | `n = n / 5;` | `n = n / 2 + 3;` |
>
> Για το `a = (a * b) + c;` **δεν υπάρχει** συντομογραφία – θέλει δύο εντολές: `a *= b; a += c;`.

> [!warning] Ειδικές περιπτώσεις ➕
> - **`x =+ 3;`** κάνει compile! Σημαίνει `x = +3;` (ανάθεση του +3), όχι `x += 3`. Ύπουλο typo.
> - Οι σύνθετοι τελεστές κάνουν **σιωπηρό cast**: `int i = 5; i += 2.7;` → `i = 7` (ενώ `i = i + 2.7;` δεν κάνει compile).
> - `s += "!"` δουλεύει και σε `String` (συνένωση).

## 7. Κλασικά μοτίβα με `while` ➕

> [!example]- Μέγιστη δύναμη του 2 που δεν ξεπερνά το N (III-78)
> ```java
> int v = 1;
> while (v <= N/2)
>     v = 2*v;
> System.out.println(v);
> ```
> Για `N = 100` → `64`. Η συνθήκη `v <= N/2` (και όχι `2*v <= N`) αποφεύγει την υπερχείλιση για πολύ μεγάλα `N`.

> [!example]- Ψηφία αριθμού (αριθμός επαναλήψεων άγνωστος εκ των προτέρων)
> ```java
> int n = 1234, digits = 0;
> while (n != 0) {
>     n /= 10;
>     digits++;
> }
> // digits = 4.   Προσοχή: για n = 0 δίνει 0 ψηφία (θέλει ειδικό χειρισμό)
> ```

## Συχνά Λάθη

> [!warning] Συχνά Λάθη (III-73 … III-76)
> - **Σύγχυση `if` και `while`**: `if (συνθήκη) εντολή` εκτελεί **το πολύ μία** φορά, `while (συνθήκη) εντολή` **όσο** ισχύει η συνθήκη.
> - **Παράλειψη των παρενθέσεων** γύρω από τη συνθήκη: `while x > 0` ✗.
> - **Παράλειψη των `{ }`** όταν επαναλαμβάνεται ακολουθία εντολών – το σώμα θεωρείται **μία** εντολή:
>   ```java
>   while (x > x_big) x -= z; ++x_big;      // σώμα: μόνο το x -= z;
>   while (x > x_big) { x -= z; ++x_big; }  // σώμα: και οι δύο
>   ```
> - Ξεχνάς να **ενημερώσεις** τη μεταβλητή της συνθήκης → άπειρος βρόχος.
> - `!=` σε `double` ως συνθήκη: `while (balance != 0.0)` → πιθανός άπειρος βρόχος· `while (balance > 0.0)` ✓.
> - `;` αμέσως μετά το `while (…)`.
