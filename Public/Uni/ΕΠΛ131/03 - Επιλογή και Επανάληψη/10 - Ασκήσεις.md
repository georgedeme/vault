# 10 - Ασκήσεις

30 ασκήσεις στο ύφος των διαφανειών της Ενότητας III. **Λύσε πρώτα, άνοιξε μετά.** Όλες οι απαντήσεις ελέγχθηκαν με `javac`/`java` 17.

> [!tip] Πώς να το χρησιμοποιήσεις
> Για κάθε βρόχο κάνε **ίχνος** σε πίνακα (μία γραμμή ανά επανάληψη). Στα «τι τυπώνει;» πρώτα έλεγξε αν κάνει compile.

## Μέρος Α — Συνθήκες

### Άσκηση 1

Με `int x = 0, y = 10;` ποιες εκφράσεις προκαλούν `ArithmeticException`;
(α) `x != 0 && y / x > 1` (β) `y / x > 1 && x != 0` (γ) `x == 0 || y / x > 1` (δ) `x == 0 | y / x > 1`

> [!success]- Λύση
> (α) ✓ ασφαλής → `false` (short-circuit: το `y / x` δεν αποτιμάται)
> (β) ✗ **exception** – η διαίρεση γίνεται πρώτη
> (γ) ✓ ασφαλής → `true`
> (δ) ✗ **exception** – το `|` (ένα) **δεν** κάνει short-circuit

### Άσκηση 2

Γράψε το συμπλήρωμα **χωρίς** `!`:
(α) `!(x > 5)` (β) `!(a == b && c < d)` (γ) `!(ch < 'a' || ch > 'z')` (δ) `!((x > 0 && x < 10) || y == 0)`

> [!success]- Λύση
> (α) `x <= 5`
> (β) `a != b || c >= d` (De Morgan + συμπλήρωμα)
> (γ) `ch >= 'a' && ch <= 'z'` (δηλ. «είναι μικρό γράμμα»)
> (δ) `(x <= 0 || x >= 10) && y != 0`

| Βήμα (δ) | Κανόνας |
|---|---|
| `!((x > 0 && x < 10) \|\| y == 0)` | αρχική |
| `!(x > 0 && x < 10) && !(y == 0)` | De Morgan (`\|\|`) |
| `(!(x > 0) \|\| !(x < 10)) && y != 0` | De Morgan (`&&`), συμπλήρωμα |
| `(x <= 0 \|\| x >= 10) && y != 0` | συμπλήρωμα |

### Άσκηση 3

Με `boolean a = true, b = false, c = true;` αποτίμησε:
(α) `a || b && !c` (β) `(a || b) && !c` (γ) `!a || !b && c` (δ) `a && !b == c`

> [!success]- Λύση
> (α) `a || (b && !c)` = `true || …` = **`true`**
> (β) `true && false` = **`false`**
> (γ) `false || (true && true)` = **`true`**
> (δ) `a && ((!b) == c)` = `true && (true == true)` = **`true`** (`!` → `==` → `&&`)

### Άσκηση 4

Τιμή: (α) `'a' < 'B'` (β) `'5' < 'A'` (γ) `' ' < '0'` (δ) `'Z' + 1 == '['`

> [!success]- Λύση
> (α) `false` (97 < 66 ψευδές) (β) `true` (53 < 65) (γ) `true` (32 < 48) (δ) `true` (91 == 91)

## Μέρος Β — Επιλογή

### Άσκηση 5

Τι τυπώνει για `x = 7` και για `x = 3`;
```java
String out = "";
if (x > 5)
    if (x > 10) out = "big";
else
    out = "medium";
System.out.println("[" + out + "]");
```

> [!success]- Λύση
> `x = 7` → `[medium]` · `x = 3` → `[]`
> Το `else` ανήκει στο **εσωτερικό** `if (x > 10)`, παρά την εσοχή. Για `x = 3` το εξωτερικό `if` είναι ψευδές και δεν έχει `else`.

### Άσκηση 6

Τι αφήνει στο `s` για `n = 1, 2, 3, 4`;
```java
String s = "";
switch (n) {
    case 1: s += "a";
    case 2: s += "b"; break;
    case 3: s += "c";
    default: s += "d";
}
```

> [!success]- Λύση
>
> | `n` | `s` | Γιατί |
> |---|---|---|
> | 1 | `"ab"` | fall-through από `case 1` στο `case 2`, μετά `break` |
> | 2 | `"b"` | |
> | 3 | `"cd"` | fall-through στο `default` |
> | 4 | `"d"` | καμία ετικέτα → `default` |

### Άσκηση 7

Κάνουν compile;
(α) `double d = 1; switch (d) { case 1: … }` (β) `switch (x > 0) { case true: … }` (γ) `String s = "a"; switch (s) { case "a": … }` (δ) `int k = 3; switch (x) { case k: … }` (ε) `switch (x) { case 1: … case 1: … }`

> [!success]- Λύση
> (α) ✗ `double` · (β) ✗ `boolean` (III-19) · (γ) ✓ · (δ) ✗ «constant expression required» (✓ αν `final int k = 3`) · (ε) ✗ «duplicate case label»

### Άσκηση 8

Για τον **λάθος** κώδικα της III-33 (ανεξάρτητα `if` σε **αύξουσα** σειρά), τι `rate` βγαίνει για εισόδημα 10.000, 100.000, 200.000, 400.000; Ποιο είναι το σωστό;

> [!success]- Λύση
>
> | Εισόδημα | Λάθος κώδικας | Σωστό |

> | 10.000 | 0.33 | 0.22 |
> | 100.000 | 0.33 | 0.25 |
> | 200.000 | 0.33 | 0.33 ✓ (τυχαία σωστό) |

> Κάθε `if` με αληθή συνθήκη ξαναγράφει το `rate`· κερδίζει το **τελευταίο** αληθές, δηλ. το `income < 311950` για όλα τα εισοδήματα κάτω από 311.950.

### Άσκηση 9

Ο κώδικας της III-31 για το μέγιστο τριών:
```java
if      (x > z && x > y) res = x;
else if (y > x && y > z) res = y;
else                     res = z;
```
Βρες είσοδο για την οποία δίνει λάθος αποτέλεσμα και διόρθωσέ τον.

> [!success]- Λύση
> `x = 5, y = 5, z = 1` → και οι δύο συνθήκες ψευδείς (λόγω `>` με ισότητα) → `res = 1` ✗.
> Διόρθωση: `if (x >= y && x >= z) res = x; else if (y >= z) res = y; else res = z;`
> (Στο `else if` ξέρουμε ήδη ότι το `x` δεν είναι μέγιστο, οπότε αρκεί σύγκριση `y` με `z`.)

### Άσκηση 10

Τι τυπώνει για `x = -5`;
```java
if (x > 0);
{
    System.out.println("positive");
}
System.out.println("done");
```

> [!success]- Λύση
> ```
> positive
> done
> ```
> Το `;` είναι το σώμα του `if` (κενή εντολή). Το μπλοκ `{ … }` είναι ανεξάρτητο και εκτελείται πάντα.

### Άσκηση 11

Ξαναγράψε χωρίς κενή εντολή/κενό `else`: (α) `if (x == 0); else y = 1/x;` (β) `if (a > b) m = a; else ;` (γ) `if (!(n % 2 == 0)); else count++;`

> [!success]- Λύση
> (α) `if (x != 0) y = 1/x;` (β) `if (a > b) m = a;` (γ) `if (!C); else S` ≡ `if (C) S` → `if (n % 2 == 0) count++;` (διπλή άρνηση)

### Άσκηση 12

Ξαναγράψε με αλυσίδα `else if`, **χωρίς** περιττές συνθήκες (III-31):

else if (weighted_aver < 8.5 && weighted_aver >= 6.5) System.out.println("Very Good");
else if (weighted_aver < 6.5 && weighted_aver > 5.0) System.out.println("Good");

```

> [!success]- Λύση

> else if (weighted_aver >= 6.5) System.out.println("Very Good");
> else if (weighted_aver >  5.0) System.out.println("Good");
> else                           System.out.println("Failure");

## Μέρος Γ — Βρόχοι: ίχνη και έξοδος

### Άσκηση 13

Πόσες φορές εκτελείται το σώμα;
(α) `for (int i = 0; i < 10; i++)` (β) `for (int i = 1; i <= 10; i += 2)` (γ) `for (int i = 10; i > 0; i -= 3)` (δ) `for (int i = 0; i <= 10; i++)` (ε) `int i = 100; while (i > 1) i /= 2;` (στ) `int k = 0; do k++; while (k < 0);` (ζ) `for (int i = 0; i < 5; i++) for (int j = i; j < 5; j++)` (εσωτερικό σώμα)

> [!success]- Λύση
> (α) 10 (β) 5 (1, 3, 5, 7, 9) (γ) 4 (10, 7, 4, 1) (δ) **11** (ε) 6 (100→50→25→12→6→3→1) (στ) **1** (do-while τουλάχιστον μία) (ζ) 5+4+3+2+1 = **15**

### Άσκηση 14

Τι τυπώνει;
```java
int i = 0;
while (i < 5) {
    i++;
    if (i == 3) continue;
    System.out.print(i);
}
```

> [!success]- Λύση
> `1245` – το `continue` παραλείπει την εκτύπωση όταν `i == 3`. Εδώ το `i++` είναι **πριν** το `continue`, οπότε δεν κολλάει.

### Άσκηση 15

Τιμές μετά από κάθε γραμμή (ανεξάρτητα):
(α) `int a = 5; int b = a++ + ++a;` (β) `int c = 5; c = c++ * 2;` (γ) `int x = 3; int y = x-- - --x;` (δ) `int i = 5; i = i++;`

> [!success]- Λύση
> (α) `b = 5 + 7 = 12`, `a = 7`
> (β) `c = 5 * 2 = 10` (η αύξηση του `c++` χάνεται από την ανάθεση)
> (γ) `y = 3 - 1 = 2`, `x = 1`
> (δ) `i = 5`

### Άσκηση 16

Κάνε το ίχνος του `Ruler` (III-52) για `N = 3` και δώσε το μήκος του `ruler` για `N = 10`.

> [!success]- Λύση
>
> | `i` | `ruler` |
> |---|---|
> | — | `" "` |
> | 1 | `" 1 "` |
> | 2 | `" 1 2 1 "` |
> | 3 | `" 1 2 1 3 1 2 1 "` |
>
> Αν `L(i)` το μήκος μετά την επανάληψη `i` (με ψηφία ενός χαρακτήρα): `L(i) = 2·L(i−1) + 1`, `L(0) = 1` → `L(i) = 2^(i+1) − 1`. Για `N = 10` το «10» έχει 2 χαρακτήρες, οπότε `L(10) = 2·L(9) + 2 = 2·1023 + 2 = 2048`. Διπλασιασμός σε κάθε βήμα → `OutOfMemoryError` για μεγάλα `N`.

### Άσκηση 17

Στο `Gambler` (III-70) μετακινούμε το `int t = stake;` **πριν** το `for`. Τι αλλάζει;

> [!success]- Λύση
> Μετά το 1ο πείραμα το `t` είναι `0` ή `goal`. Στα επόμενα πειράματα η `t > 0 && t < goal` είναι ψευδής από την αρχή → το `while` δεν εκτελείται, και το `if (t == goal) wins++` δίνει το **ίδιο** αποτέλεσμα με το 1ο πείραμα. Άρα `wins` = `0` ή `trials` – άχρηστη προσομοίωση.

### Άσκηση 18

Τερματίζει; `double balance = 1.0; while (balance != 0.0) balance -= 0.1;`

> [!success]- Λύση
> **Όχι** – άπειρος βρόχος. Μετά από 10 αφαιρέσεις το `balance` είναι ≈ 1.39 × 10⁻¹⁶, όχι 0.0, και συνεχίζει στα αρνητικά. Διόρθωση (III-76): `while (balance > 0.0)` – ή καλύτερα ακέραιος μετρητής.

### Άσκηση 19

Κάνουν compile;
(α) `while (false) x++;` (β) `for (;;) ; System.out.println("end");` (γ) `do x++; while (x < 5)` (δ) `for (int i = 0, j = 0; i < 5; i++, j++) ;` (ε) `for (int i = 0, long j = 0; i < 5; i++) ;` (στ) `for (int n = 1; n == 10; n++) x++;`

> [!success]- Λύση
> (α) ✗ unreachable statement (⚠️ η III-41 το παρουσιάζει ως «null statement»)
> (β) ✗ το `println` είναι απρόσιτο μετά από άπειρο βρόχο χωρίς `break`
> (γ) ✗ λείπει το `;` μετά το `while (x < 5)`
> (δ) ✓
> (ε) ✗ διαφορετικοί τύποι στην αρχικοποίηση
> (στ) ✓ (0 επαναλήψεις – η συνθήκη δεν είναι σταθερά)

### Άσκηση 20

Μετάτρεψε σε `while`: `for (int i = 0; i < n; i++) sum += i;` και σε `while`: `do { x = in.nextInt(); } while (x < 0);`

> [!success]- Λύση
> ```java
> int i = 0;
> while (i < n) { sum += i; i++; }
>
> x = in.nextInt();              // { β }
> while (x < 0) { x = in.nextInt(); }   // while (σ) { β }
> ```

### Άσκηση 21

Γιατί η παρακάτω «μετατροπή» του `for (int i = 0; i < 5; i++) { if (i == 2) continue; System.out.print(i); }` **δεν** είναι ισοδύναμη;
```java
int i = 0;
while (i < 5) { if (i == 2) continue; System.out.print(i); i++; }
```

> [!success]- Λύση
> Στο `for`, το `continue` μεταφέρει τον έλεγχο στην **ενημέρωση** `i++`. Στο `while`, το `continue` παρακάμπτει το `i++` που βρίσκεται στο τέλος του σώματος → όταν `i == 2` το `i` δεν αλλάζει ποτέ → **άπειρος βρόχος** (τυπώνει `01` και κολλάει). Το `for` τυπώνει `0134`.

### Άσκηση 23

Μέγιστος κοινός διαιρέτης με τον αλγόριθμο του Ευκλείδη. Δώσε ψευδοκώδικα και Java. Υπολόγισε `gcd(48, 18)`.

> [!success]- Λύση
> ```
> while q ≠ 0:
>     r ← p mod q
>     p ← q
>     q ← r
> return p
> ```
> ```java
> int p = 48, q = 18;
> while (q != 0) {
>     int r = p % q;
>     p = q;
>     q = r;
> }
> System.out.println(p);   // 6
> ```
>
> | `p` | `q` | `r` |
> |---|---|---|
> | 48 | 18 | 12 |
> | 18 | 12 | 6 |
> | 12 | 6 | 0 |
> | 6 | 0 | — |

### Άσκηση 24

Γράψε κώδικα που ελέγχει αν ο `m` είναι πρώτος. Χειρίσου σωστά τα `m = 0, 1, 2`. Γιατί αρκεί `d * d <= m`;

> [!success]- Λύση
> ```java
> boolean prime = m > 1;              // 0, 1 και αρνητικοί ΔΕΝ είναι πρώτοι
> for (int d = 2; d * d <= m; d++)
>     if (m % d == 0) { prime = false; break; }
> ```
> - `m = 2`: `2*2 <= 2` ψευδές → ο βρόχος δεν τρέχει → `prime = true` ✓
> - `m = 91 = 7·13` → `false`
> - Αν `m = a·b` με `a ≤ b`, τότε `a·a ≤ m`: αρκεί να ψάξεις διαιρέτες μέχρι √m.

### Άσκηση 27

Monte Carlo: ρίξε ένα ζάρι `N` φορές και τύπωσε το ποσοστό των εξαριών. Τι περιμένεις για μεγάλο `N`;

> [!success]- Λύση
> ```java
> int N = Integer.parseInt(args[0]);
> int sixes = 0;
> for (int i = 0; i < N; i++) {
>     int die = 1 + (int) (Math.random() * 6);
>     if (die == 6) sixes++;
> }
> System.out.println((double) sixes / N);   // ≈ 0.1667
> ```
> Το `(double)` χρειάζεται – αλλιώς `sixes / N` = 0 (ακέραια διαίρεση).

### Άσκηση 29

Βρες το λάθος: υπολογισμός `n!`.
```java
int product = 0;
for (int i = 1; i <= n; i++)
    product *= i;
```

> [!success]- Λύση
> Αρχική τιμή **0** → το γινόμενο μένει πάντα 0. Σωστά `product = 1`. Επιπλέον, για `n ≥ 13` το `int` υπερχειλίζει → `long`.

### Άσκηση 30

Βρες **όλα** τα λάθη:
```java
int sum = 0
for (int i = 0, i < 10, i++);
    sum =+ i;
System.out.println(i + " " + sum);
```

> [!success]- Λύση
> 1. Λείπει `;` μετά το `int sum = 0`.
> 2. Κόμματα αντί για `;` στο `for`.
> 3. `;` μετά την παρένθεση του `for` → κενό σώμα.
> 4. `sum =+ i` σημαίνει `sum = +i` (όχι `+=`).
> 5. Το `i` δεν υπάρχει εκτός `for` (και στη γραμμή `sum =+ i` επίσης, λόγω του λάθους 3).
>
> Διορθωμένο:
> ```java
> int sum = 0;
> for (int i = 0; i < 10; i++)
>     sum += i;
> System.out.println(sum);   // 45
> ```
