# 06 - Εντολή for και Τελεστές ++ --

Η απαριθμητή επανάληψη (`for`), οι τελεστές αύξησης/μείωσης και τα παραδείγματα Ruler και PrintChars (διαφάνειες III-44 … III-58).

## 1. Εντολή `for` (III-44)

> [!note] Σύνταξη
> ```
> for (έκφραση-αρχικοποίησης ; συνθήκη ; έκφραση-ενημέρωσης)
>     εντολή
> ```

> [!important] Γενική σημασιολογία
> 1. Καταρχήν αποτιμάται η **έκφραση-αρχικοποίησης** (μία φορά).
> 2. Δοκιμάζεται η **συνθήκη**. Αν **δεν** ευσταθεί, ο έλεγχος μεταφέρεται **εκτός** της `for`.
> 3. Διαφορετικά εκτελείται η **εντολή**, αποτιμάται η **έκφραση-ενημέρωσης**, και ο έλεγχος επιστρέφει στο βήμα 2.
>
> Η εκτέλεση της εντολής και η αποτίμηση της έκφρασης-ενημέρωσης επαναλαμβάνονται **ενόσω** η συνθήκη ευσταθεί.

### Τυπική εφαρμογή (III-45)

```
  αρχικοποίηση μεταβλητής ελέγχου
               │
               ▼
          ┌─────────┐  όχι
    ┌────►│συνθήκη? │──────► (έξοδος)
    │     └─────────┘
    │          │ ναι
    │          ▼
    │       εντολή
    │          │
    │          ▼
    └── ενημέρωση μεταβλητής ελέγχου
```

> [!tip] Σειρά εκτέλεσης σε μία γραμμή
> `for (A; B; C) D` → **A B D C B D C B D C B** (έξοδος όταν το B είναι ψευδές).
> Το A εκτελείται **1** φορά, το B **n + 1** φορές, τα D και C **n** φορές.

## 2. Άπειροι βρόχοι και «κενές» επαναλήψεις (III-46)

```java
/* Examples of infinite loops */
for (int n = 1; true; n += 1)
    System.out.println("I cannot stop!");
for ( ; true; )
    System.out.println("I cannot stop!");

/* Examples of null statements */
for (int n = 1; n == 10; n += 1)
    System.out.println("???");           // 0 επαναλήψεις: n == 10 ψευδές από την αρχή
for ( ; false; )
    System.out.println("???");           // -- Unreachable code – compile error
```

> [!note] Παρατηρήσεις
> - Και τα **τρία** μέρη του `for` είναι προαιρετικά: `for (;;)` = `while (true)`. Χωρίς συνθήκη, θεωρείται `true`.
> - Το `for ( ; false; )` είναι **compile error** («unreachable statement») επειδή η συνθήκη είναι η **σταθερά** `false`. Το `n == 10` δεν είναι σταθερά, οπότε κάνει compile και απλώς εκτελεί 0 φορές.
> - ⚠️ Η διαφάνεια γράφει `System.out.printnl` στο πρώτο παράδειγμα – typo (`println`).

## 3. Παραδείγματα (III-47, III-48)

```java
// Άθροισμα 1 + 2 + … + n
int sum = 0;
for (int count = 1; count <= n; count += 1)
    sum = sum + count;
System.out.println("The sum is " + sum);
```

```java
// Δυνάμεις του 2
public class PowersOfTwo {
    public static void main(String[] args) {
        int res = 1;
        for (int count = 0; count <= 6; count += 1) {
            System.out.println(count + " " + res);
            res *= 2;
        }
    }
}
```
⚠️ *Σημείωση: ο τίτλος της III-48 λέει «για x από το 1 μέχρι το 6», αλλά ο κώδικας ξεκινά από `count = 0` και τυπώνει και τη γραμμή `0 1` (όπως και η εκδοχή με `while`).*

## 4. Εμβέλεια της μεταβλητής ελέγχου ➕

> [!warning] Η μεταβλητή που δηλώνεται στο `for` ζει **μόνο** μέσα στο `for`
> ```java
> for (int i = 0; i < 10; i++) { … }
> System.out.println(i);          // ✗ cannot find symbol
> ```
> Αν χρειάζεσαι την τελική τιμή (π.χ. στη γραμμική αναζήτηση, IV-53), δήλωσέ την **έξω**:
> ```java
> int pos;
> for (pos = 0; pos < x.length; ++pos) …
> // εδώ το pos είναι διαθέσιμο
> ```
> Επίσης `int i = 0; for (int i = 0; …)` ✗ «already defined».

> [!note] Πολλές μεταβλητές με κόμμα ➕
> ```java
> for (int i = 0, j = N-1; i < j; i++, j--) { … }   // αντιστροφή πίνακα, IV-10
> ```
> - Στην αρχικοποίηση επιτρέπονται πολλές δηλώσεις του **ίδιου** τύπου: `int i = 0, j = N-1`.
> - `for (int i = 0, double d = 0; …)` ✗ – δεν επιτρέπονται διαφορετικοί τύποι.
> - Στην ενημέρωση, το κόμμα χωρίζει εκφράσεις: `i++, j--`.

## 5. Τελεστές αύξησης και μείωσης `++`, `--` (III-49 … III-51)

> [!note] Increment and Decrement Operators
> ```java
> count = count + 1;   ≡   count += 1;   ≡   ++count;
> ```
> - Ο τελεστής αύξησης `++` λαμβάνει **μία μοναδική μεταβλητή** ως τελεστέο.
> - Το **πλευρικό φαινόμενο** (παρενέργεια) της εφαρμογής του είναι ότι η τιμή του τελεστέου **αυξάνεται κατά ένα**.
> - Συνήθως χρησιμοποιείται **απλά για αυτή την παρενέργεια**: `for (int count = 1; count <= n; ++count) sum += count;`

> [!important] Προ- και μετα-σημειογραφική μορφή (III-50)
> Η τιμή μιας έκφρασης με `++` εξαρτάται από τη **θέση** του τελεστή:
>
> | Μορφή | Όνομα | Τιμή της έκφρασης |
> |---|---|---|
> | `++count` | προ-σημειογραφική αύξηση (**prefix**) | η τιμή **μετά** την αύξηση |
> | `count++` | μετα-σημειογραφική αύξηση (**postfix**) | η τιμή **πριν** την αύξηση |
>
> Ομοίως ο `--` μειώνει κατά ένα και επιστρέφει την τιμή μετά (`--x`) ή πριν (`x--`) τη μείωση.

### Παράδειγμα (III-51) – με αρχικό `i = 2`

| Εντολή | Εξήγηση | `i` | `j` |
|---|---|---|---|
| `j = ++i;` | Πρώτα **αυξάνεται** η `i` και μετά χρησιμοποιείται η τιμή της | 3 | **3** |
| `j = i++;` | Πρώτα **χρησιμοποιείται** η τιμή της `i` και μετά γίνεται η αύξηση | 3 | **2** |

> [!warning] Ειδικές περιπτώσεις ➕
>
> | Κώδικας | Αποτέλεσμα | Γιατί |
> |---|---|---|
> | `int i = 5; i = i++;` | `i == 5` (!) | το `i++` επιστρέφει 5, αυξάνει σε 6, και μετά η ανάθεση ξαναγράφει 5 |
> | `int i = 2; int j = i++ * 10 + i;` | `j = 23`, `i = 3` | το `i++` δίνει 2, αλλά το επόμενο `i` διαβάζεται ήδη 3 |
> | `int i = 2; i = ++i + i++;` | `i == 6` | 3 + 3 (και η αύξηση του `i++` χάνεται στην ανάθεση) |
> | `5++`, `(a+b)++`, `x++ ++` | ✗ compile | ο τελεστέος πρέπει να είναι **μεταβλητή** |
> | `double d = 1.5; d++;` | `2.5` | δουλεύει και σε `double` |
> | `char ch = 'x'; ch++;` | `'y'` | και σε `char` (χωρίς cast) |
> | `x[i++]` με `i = 5` | στοιχείο `x[5]`, μετά `i = 6` | IV-13 |
>
> Κανόνας επιβίωσης: **μη** χρησιμοποιείς `++`/`--` σε μεταβλητή που εμφανίζεται **ξανά** στην ίδια έκφραση. Ως αυτόνομη εντολή (`i++;`) prefix και postfix είναι **ίδια**.

## 6. Επιστροφή στις Υποδιαιρέσεις μιας Ρήγας (III-52, III-53)

```java
public class Ruler {
    public static void main(String[] args) {
        int N = Integer.parseInt(args[0]);
        String ruler = " ";
        for (int i = 1; i <= N; i++) {
            ruler = ruler + i + ruler;
        }
        System.out.println(ruler);
    }
}
```

| `i` | `ruler` |
|---|---|
| — | `" "` |
| 1 | `" 1 "` |
| 2 | `" 1 2 1 "` |
| 3 | `" 1 2 1 3 1 2 1 "` |

```
% java Ruler 1     →  1
% java Ruler 2     →  1 2 1
% java Ruler 3     →  1 2 1 3 1 2 1
% java Ruler 4     →  1 2 1 3 1 2 1 4 1 2 1 3 1 2 1
% java Ruler 100   →  Exception in thread "main" java.lang.OutOfMemoryError
```

> [!info]- Γιατί `OutOfMemoryError`;
> Σε κάθε επανάληψη το μήκος του `ruler` **διπλασιάζεται** (περίπου). Μετά από `N` επαναλήψεις έχει ~2ᴺ χαρακτήρες: για `N = 30` είναι ήδη ~1 δισ. χαρακτήρες, για `N = 100` περίπου 10³⁰ – δεν χωράει σε καμία μνήμη. Εκθετική αύξηση!

## 7. Παράδειγμα: Εκτυπώσιμοι χαρακτήρες με τους κωδικούς τους (III-54 … III-58)

```java
public class PrintChars {
    public static void newLine() {
        System.out.println();
    }

    public static void main(String[] args) {
        char START_CHAR = ' ';
        char END_CHAR = '~';
        int per_line = 5;
        newLine();
        System.out.println("Displaying Print Characters with their Codes");
        for (char c = START_CHAR; c <= END_CHAR; c++) {
            if ((c - START_CHAR) % per_line == 0)
                newLine();
            System.out.print(" " + c + " " + (int) c);
        }
    }
}
```

> [!note] Τι να προσέξεις
> - Μεταβλητή ελέγχου τύπου **`char`** – επιτρέπεται γιατί ο `char` είναι απαριθμητός τύπος (έχει διάδοχο: `c++`).
> - `(c - START_CHAR) % per_line == 0` → αλλαγή γραμμής **πριν** από κάθε 5ο χαρακτήρα (0ός, 5ος, 10ος…).
> - `(int) c` τυπώνει τον **κωδικό**· σκέτο `c` τον **χαρακτήρα**.
> - Με `System.out.printf("\t%c%4d", c, (int) c);` οι στήλες ευθυγραμμίζονται (III-56).
> - Η `newLine()` είναι μια απλή **μέθοδος** – αφαιρετικότητα (Ενότητα V).

### Χαρακτήρες από τη γραμμή εντολής (III-57, III-58)

```java
String s1 = args[0];
String s2 = args[1];
char START_CHAR = s1.charAt(0);     // args[0].charAt(0);
char END_CHAR   = s2.charAt(0);     // args[1].charAt(0);
if (START_CHAR > END_CHAR) {        // εναλλαγή αν δόθηκαν ανάποδα
    char temp = START_CHAR; START_CHAR = END_CHAR; END_CHAR = temp;
}
```

> [!example]- Τι γίνεται με `java PrintChars a A`;
> - **Χωρίς** την εναλλαγή (III-57): `START_CHAR = 'a'` (97) > `END_CHAR = 'A'` (65) → η συνθήκη `c <= END_CHAR` είναι ψευδής από την αρχή → τυπώνεται μόνο η επικεφαλίδα, **κανένας** χαρακτήρας.
> - **Με** την εναλλαγή (III-58): τυπώνονται οι χαρακτήρες από `A` (65) μέχρι `a` (97).

> [!warning] Παγίδες βρόχων με μικρούς τύπους ➕
> - `for (char c = 0; c <= '￿'; c++)` → **άπειρος**: κάθε `char` είναι ≤ `'￿'`, και μετά το `'￿'` το `c++` «τυλίγεται» στο 0.
> - `for (byte b = 0; b < 200; b++)` → **άπειρος**: το `byte` δεν φτάνει ποτέ το 200 (μέγιστο 127, μετά −128).

## 8. Φωλιασμένοι βρόχοι ➕

Βρόχος μέσα σε βρόχο: για **κάθε** επανάληψη του εξωτερικού, ο εσωτερικός εκτελείται **ολόκληρος**.

```java
for (int i = 0; i < 3; i++) {
    for (int j = 0; j <= i; j++)
        System.out.print("*");
    System.out.println();
}
```
```
*
**
***
```

> [!tip] Μέτρηση επαναλήψεων
> - `for i in 0..N-1 { for j in 0..M-1 }` → **N·M** εκτελέσεις του εσωτερικού σώματος.
> - `for (i = 0; i < N; i++) for (j = i; j < N; j++)` → N + (N−1) + … + 1 = **N(N+1)/2** (για N = 5: 15).
> - Κλασική χρήση: κατασκευή τράπουλας (IV-16, IV-24), κόσκινο του Ερατοσθένη (IV-49).

## 9. `break` και `continue` ➕

| Εντολή | Τι κάνει |
|---|---|
| `break;` | **Τερματίζει αμέσως** τον βρόχο που την περιέχει (τον πιο εσωτερικό) – αναλυτικά στο [[06 - Αναζήτηση και break\|IV – 06]] |
| `continue;` | Παραλείπει το **υπόλοιπο της τρέχουσας** επανάληψης και πάει στην επόμενη (στο `for`: στην έκφραση-ενημέρωσης) |

```java
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;     // παράλειψε τα πολλαπλάσια του 3
    System.out.print(i + " ");
}
// 1 2 4 5 7 8 10
```

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Παράλειψη του `;` μετά την αρχικοποίηση ή μετά τη συνθήκη (III-73). Κόμμα αντί για `;`: `for (i = 0, i < n, i++)` ✗.
> - **`;` μετά την παρένθεση**: `for (int i = 0; i < 10; i++);` → το σώμα είναι κενό, το «σώμα» από κάτω εκτελείται **μία** φορά.
> - **Off-by-one**: `i <= N` εκτελεί N+1 φορές (από 0)· `i < N` εκτελεί N. Πίνακας μεγέθους N: `i < N`, **όχι** `i <= N`.
> - Αλλαγή της μεταβλητής ελέγχου **μέσα** στο σώμα (`i++` και στο σώμα) → παραλείπονται επαναλήψεις (π.χ. τυπώνει `0 2 4`).
> - Χρήση της μεταβλητής του `for` μετά τον βρόχο.
> - Μετρητής `double` σε `for` → βλ. [[09 - Ανακρίβειες Αναπαράστασης|II – 09 Ανακρίβειες]].
