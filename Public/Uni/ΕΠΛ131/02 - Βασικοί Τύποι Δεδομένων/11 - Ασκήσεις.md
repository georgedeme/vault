# 11 - Ασκήσεις

30 ασκήσεις στο ύφος των διαφανειών της Ενότητας II. **Λύσε πρώτα, άνοιξε μετά** – κάθε λύση είναι κρυμμένη σε αναδιπλούμενο πλαίσιο. Όλες οι απαντήσεις ελέγχθηκαν με `javac`/`java` 17.

> [!tip] Πώς να το χρησιμοποιήσεις
> Λύσε **με χαρτί και μολύβι**, χωρίς υπολογιστή. Σε κάθε «τι τυπώνει;» ρώτα πρώτα «κάνει compile;». Αν κάνεις λάθος, γύρνα στη σχετική σημείωση, όχι στη λύση.

## Μέρος Α — Αποτίμηση εκφράσεων

### Άσκηση 1

Δώσε την τιμή: `17 / 5`, `17 % 5`, `-17 / 5`, `-17 % 5`, `17 % -5`, `5 % 17`

> [!success]- Λύση
>
> | Έκφραση | Τιμή | Γιατί |
> |---|---|---|
> | `17 / 5` | `3` | ακέραια διαίρεση |
> | `17 % 5` | `2` | 17 = 3·5 + 2 |
> | `-17 / 5` | `-3` | κόβει προς το 0 |
> | `-17 % 5` | `-2` | πρόσημο του αριστερού· −17 = (−3)·5 + (−2) |
> | `17 % -5` | `2` | πρόσημο του αριστερού (17) |
> | `5 % 17` | `5` | όταν `a < b` (θετικά), `a % b = a` |

### Άσκηση 2

Δώσε τιμή **και τύπο**: `7 / 2 * 2.0`, `7 / 2.0 * 2`, `(double) (7 / 2)`, `(double) 7 / 2`, `7 / (double) 2`

> [!success]- Λύση
>
> | Έκφραση | Τιμή | Τύπος | Βήματα |
> |---|---|---|---|
> | `7 / 2 * 2.0` | `6.0` | `double` | `7/2 = 3` → `3 * 2.0` |
> | `7 / 2.0 * 2` | `7.0` | `double` | `3.5 * 2` |
> | `(double) (7 / 2)` | `3.0` | `double` | η διαίρεση έγινε πρώτα |
> | `(double) 7 / 2` | `3.5` | `double` | cast στο 7 → πραγματική διαίρεση |
> | `7 / (double) 2` | `3.5` | `double` | |

### Άσκηση 3

Τι τυπώνει η καθεμία (ξεχωριστά); `1 + 2 + "3"` · `"1" + 2 + 3` · `"1" + (2 + 3)` · `1 + '2'` · `"" + 1 + '2'` · `'1' + '2'`

> [!success]- Λύση
>
> | Έκφραση | Έξοδος | Γιατί |
> |---|---|---|
> | `1 + 2 + "3"` | `33` | `3 + "3"` |
> | `"1" + 2 + 3` | `123` | String από την αρχή |
> | `"1" + (2 + 3)` | `15` | παρένθεση πρώτα |
> | `1 + '2'` | `51` | `'2'` = 50 → `int` |
> | `"" + 1 + '2'` | `12` | |
> | `'1' + '2'` | `99` | 49 + 50 |

### Άσκηση 4

Τιμή: `(int) 7.9` · `(int) -7.9` · `Math.round(7.5)` · `Math.round(-7.5)` · `(int) Math.round(-7.51)` · `Math.sqrt(16)` · `Math.pow(2, 3)`

> [!success]- Λύση
> `7` · `-7` (κόβει προς το 0) · `8` · **`-7`** (το .5 πάει προς +∞) · `-8` · **`4.0`** (`double`!) · **`8.0`** (`double`!)

### Άσκηση 5

Τιμή ή σφάλμα: `10.0 / 0` · `10 / 0.0` · `10 / 0` · `0.0 / 0.0` · `10 % 3.0`

> [!success]- Λύση
> `Infinity` · `Infinity` · **`ArithmeticException`** (runtime – και οι δύο ακέραιοι) · `NaN` · `1.0`
> Κανόνας: αρκεί **ένας** τελεστέος `double` για να γίνει η πράξη σε `double`, όπου η διαίρεση με 0 δεν «σκάει».

### Άσκηση 6

Βάλε πλήρεις παρενθέσεις και σχεδίασε το δέντρο: `a - b * c / d + e % f`

> [!success]- Λύση
> **`(a - ((b * c) / d)) + (e % f)`**
> ```
>            +
>          /   \
>         -     %
>        / \   / \
>       a   / e   f
>          / \
>         *   d
>        / \
>       b   c
> ```
> Τα `*`, `/`, `%` πρώτα (αριστερά → δεξιά: `b*c` πριν το `/d`), μετά `-` και `+` αριστερά → δεξιά.

### Άσκηση 7

Τιμή: `(char) ('A' + 2)` · `'z' - 'a'` · `(int) '0'` · `'9' - '0' + 1` · `(char) ('m' - 32)`

> [!success]- Λύση
> `'C'` · `25` · `48` · `10` · `'M'` (μικρό − 32 = κεφαλαίο)

### Άσκηση 8

Με `int x = 5, y = 10;` αποτίμησε: (α) `x < y && y < 20` (β) `!(x > 3) || y == 10` (γ) `x == 5 && !(y != 10)` (δ) `x > 3 == true`

> [!success]- Λύση
> (α) `true` (β) `false || true` = `true` (γ) `true && true` = `true` (δ) το `>` προηγείται του `==`: `(x > 3) == true` = `true` (κάνει compile, αλλά είναι κακό στυλ).

## Μέρος Β — Κάνει compile;

### Άσκηση 9

Για καθεμία: κάνει compile; Αν ναι, ποια η τιμή;

(α) `int x = 3.0;` (β) `double d = 3;` (γ) `float f = 3.0;` (δ) `long L = 5000000000;` (ε) `char c = 'ab';` (στ) `char c = 65;` (ζ) `char c = 'a'; c = c + 1;` (η) `char c = 'a'; c += 1;` (θ) `boolean b = 0;` (ι) `int n = Math.round(2.5);` (ια) `String s = 5;` (ιβ) `String s = "" + 5;` (ιγ) `int x = (int) "5";` (ιδ) `int z = 6 ^ 2;`

> [!success]- Λύση
>
> | | Compile; | Γιατί / τιμή |
> |---|---|---|
> | α | ✗ | `double` → `int` χρειάζεται cast |
> | β | ✓ | `3.0` (διεύρυνση) |
> | γ | ✗ | το `3.0` είναι `double` · θέλει `3.0f` |
> | δ | ✗ | «integer number too large» · θέλει `L` |
> | ε | ✗ | ένας μόνο χαρακτήρας σε `'…'` |
> | στ | ✓ | `'A'` |
> | ζ | ✗ | `c + 1` είναι `int` |
> | η | ✓ | `'b'` (σιωπηρό cast) |
> | θ | ✗ | `int` ≠ `boolean` |
> | ι | ✗ | `Math.round(double)` → `long` |
> | ια | ✗ | `int` δεν γίνεται `String` με ανάθεση |
> | ιβ | ✓ | `"5"` |
> | ιγ | ✗ | cast δεν μετατρέπει `String`· θέλει `Integer.parseInt` |
> | ιδ | ✓ | **`4`** – XOR: `110 ^ 010 = 100` |

### Άσκηση 10

Δίνονται `int k = 5, m = 4, n; double x = 1.5, y = 2.1, z;` (όπως στη II-47). Ποιες εντολές κάνουν compile και τι τιμή αναθέτουν;
(α) `z = k / m;` (β) `n = x * y;` (γ) `n = (int) x * y;` (δ) `n = (int) (x * y);` (ε) `z = k + x;` (στ) `n = k % m + (int) y;`

> [!success]- Λύση
>
> | | Compile; | Τιμή |
> |---|---|---|
> | α | ✓ | `z = 1.0` (ακέραια διαίρεση, μετά διεύρυνση) |
> | β | ✗ | ⚠️ η διαφάνεια λέει `n = 3`, αλλά η Java απαιτεί cast |
> | γ | ✗ | το cast πιάνει μόνο το `x` → `1 * 2.1` είναι `double` |
> | δ | ✓ | `n = 3` |
> | ε | ✓ | `z = 6.5` |
> | στ | ✓ | `1 + 2 = 3` |

### Άσκηση 11

Ποια είναι έγκυρα κυριολεκτικά `double`; `1e10` · `1.e5` · `e5` · `1e5.0` · `-.5` · `1_000.5` · `34,5` · `2.5E-3`

> [!success]- Λύση
> ✓ `1e10` · ✓ `1.e5` (=100000.0) · ✗ `e5` (είναι **όνομα** μεταβλητής!) · ✗ `1e5.0` (ο εκθέτης ακέραιος) · ✓ `-.5` (μοναδιαίο `-` και `.5`) · ✓ `1_000.5` · ✗ `34,5` (κόμμα) · ✓ `2.5E-3` (=0.0025)

### Άσκηση 12

Ποια είναι έγκυρα ονόματα μεταβλητών; `_count` · `2nd` · `my_var` · `my-var` · `$price` · `class` · `Class` · `αριθμός` · `is prime`

> [!success]- Λύση
> ✓ `_count` · ✗ `2nd` (αρχίζει με ψηφίο) · ✓ `my_var` · ✗ `my-var` (είναι `my - var`) · ✓ `$price` · ✗ `class` (δεσμευμένη) · ✓ `Class` (case-sensitive – έγκυρο αλλά κακή ιδέα) · ✓ `αριθμός` (Unicode επιτρέπεται· στα Windows χρειάζεται `javac -encoding UTF-8`) · ✗ `is prime` (κενό)

### Άσκηση 13

Κάνουν compile; (α) `if (1 <= x <= 10) …` (β) `int y = 5 --x;` (γ) `int y = 5 - -x;` (δ) `System.out.println(10 - 2 + " " + 10 - 2);`

> [!success]- Λύση
> (α) ✗ `boolean <= int` · (β) ✗ το `--` διαβάζεται ως μείωση · (γ) ✓ `5 + x` · (δ) ✗ μετά το `" "` έχουμε `String - int`.

## Μέρος Γ — Ίχνη και έξοδος

### Άσκηση 14

Κάνε το ίχνος. Τι κάνει ο κώδικας;
```java
int a = 7, b = 3;
a = a + b;
b = a - b;
a = a - b;
```

> [!success]- Λύση
>
> | Εντολή | `a` | `b` |
> |---|---|---|
> | αρχή | 7 | 3 |
> | `a = a + b;` | 10 | 3 |
> | `b = a - b;` | 10 | **7** |
> | `a = a - b;` | **3** | 7 |
>
> **Ανταλλάσσει** τις τιμές χωρίς βοηθητική μεταβλητή. (Δουλεύει ακόμη και με υπερχείλιση, λόγω του «τυλίγματος» – αλλά η εκδοχή με `temp` είναι πιο καθαρή: *Don't make me think*, Ενότητα V.)

Τι τυπώνει;

System.out.println("i = " + (i + 1));

> 2.5

> 11 = i+1
> ```

### Άσκηση 16

Τι τυπώνει;
```java
int big = Integer.MAX_VALUE;
System.out.println(big + 1);
System.out.println(big + 1L);
System.out.println((long) big + 1);
System.out.println((long) (big + 1));
```

> [!success]- Λύση
> ```
> -2147483648     ← υπερχείλιση int
> 2147483648      ← το 1L κάνει την πράξη long
> 2147483648      ← cast ΠΡΙΝ την πρόσθεση
> -2147483648     ← cast ΜΕΤΑ – πολύ αργά
> ```

### Άσκηση 17

Τι τυπώνουν; Ποιο είδος ανακρίβειας δείχνει το καθένα;
(α) `System.out.println(0.1 + 0.2 == 0.3);` (β) `System.out.println(Math.abs(0.1 + 0.2 - 0.3) < 1e-9);` (γ) `System.out.println(1.0 + 1e-17 == 1.0);` (δ) `System.out.println(1e-200 * 1e-200);`

> [!success]- Λύση
> (α) `false` – λάθος **αναπαράστασης** · (β) `true` – η σωστή σύγκριση με ανοχή · (γ) `true` – λάθος **ακύρωσης** · (δ) `0.0` – **υπορροή**

### Άσκηση 18

Τι τυπώνει; `System.out.println('a' + 'b' + "c" + 'a' + 'b');`

> [!success]- Λύση
> `195cab` – αριστερά `97 + 98 = 195` (αριθμητική), μετά από το `"c"` όλα συνένωση.

### Άσκηση 19

Τι γίνεται με `java IntOps -17 5`; Και με `java IntOps 5 0`; (πρόγραμμα της II-13)

> [!success]- Λύση
> ```
> -17 + 5 = -12
> -17 * 5 = -85
> -17 / 5 = -3
> -17 % 5 = -2
> ```
> Με `5 0`: **δεν τυπώνεται τίποτα** – μόνο `ArithmeticException: / by zero`. Το `int quot = a / b;` εκτελείται **πριν** από οποιοδήποτε `println`.

### Άσκηση 20

Για το πρόγραμμα `Quadratic` (II-21): δώσε ορίσματα που προκαλούν (α) έξοδο `NaN NaN`, (β) `NumberFormatException`, (γ) `ArrayIndexOutOfBoundsException`, (δ) διπλή ρίζα.

> [!success]- Λύση

## Μέρος Δ — Γράψε κώδικα

### Άσκηση 21

Γράψε σε Java: (α) (x + y) / 2z (β) ⅓πr³ (γ) |x − y| / √(x² + y²) (δ) a^(b+c) (ε) (−b + √d) / 2a

> [!success]- Λύση
> (α) `(x + y) / (2 * z)`
> (β) `(1.0 / 3) * Math.PI * r * r * r` — ✗ `1 / 3 * …` δίνει **0**
> (γ) `Math.abs(x - y) / Math.sqrt(x*x + y*y)`
> (δ) `Math.pow(a, b + c)`
> (ε) `(-b + Math.sqrt(d)) / (2 * a)` — ✗ `/ 2 * a` σημαίνει `(… / 2) * a`

### Άσκηση 22

Γράψε πρόγραμμα `Time` που δέχεται δευτερόλεπτα από τη γραμμή εντολής και τυπώνει ώρες:λεπτά:δευτερόλεπτα. `java Time 3725` → `01:02:05`

> [!success]- Λύση
> ```java
> public class Time {
>     public static void main(String[] args) {
>         int s = Integer.parseInt(args[0]);
>         int hours   = s / 3600;
>         int minutes = s % 3600 / 60;   // % και / ίδια προτεραιότητα → (s % 3600) / 60
>         int seconds = s % 60;
>         System.out.printf("%02d:%02d:%02d%n", hours, minutes, seconds);
>     }
> }
> ```
> Το `%02d` = πλάτος 2 με αρχικά μηδενικά.

### Άσκηση 23

Χωρίς βρόχο: άθροισμα ψηφίων ενός 4ψήφιου ακεραίου `n`. Για `n = 4567` → `22`.

> [!success]- Λύση
> ```java
> int sum = n / 1000 + n / 100 % 10 + n / 10 % 10 + n % 10;
> ```
> `4 + 5 + 6 + 7 = 22`. (Με βρόχο για οποιοδήποτε πλήθος ψηφίων → [[03 - Ακέραιοι Τύποι]].)

### Άσκηση 24

Γράψε πρόγραμμα `Dice` που τυπώνει το άθροισμα δύο τυχαίων ζαριών (1…6 το καθένα). Γιατί **δεν** είναι το ίδιο με `2 + (int)(Math.random() * 11)`;

> [!success]- Λύση
> ```java
> public class Dice {
>     public static void main(String[] args) {
>         int d1 = 1 + (int) (Math.random() * 6);
>         int d2 = 1 + (int) (Math.random() * 6);
>         System.out.println(d1 + d2);
>     }
> }
> ```
> Το `2 + (int)(Math.random() * 11)` δίνει 2…12 με **ίση** πιθανότητα (1/11). Με δύο ζάρια το 7 είναι 6 φορές πιθανότερο από το 2 (6/36 vs 1/36).

### Άσκηση 25

Βρες το λάθος: `java Celsius 100` τυπώνει `132.0` αντί `212.0`.
```java
double C = Double.parseDouble(args[0]);
double F = 9 / 5 * C + 32;
System.out.println(F);
```

> [!success]- Λύση
> `9 / 5` είναι **ακέραια** διαίρεση = `1` → `F = C + 32`. Διόρθωση: `9.0 / 5 * C + 32` ή `9 * C / 5 + 32` (εδώ το `9 * C` είναι ήδη `double`).

### Άσκηση 26

Βρες το λάθος: `java Avg 3 4` τυπώνει `Average: 3.0`.
```java
int a = Integer.parseInt(args[0]);
int b = Integer.parseInt(args[1]);
double avg = (a + b) / 2;
System.out.println("Average: " + avg);
```

> [!success]- Λύση
> Ακέραια διαίρεση `7 / 2 = 3` **πριν** την ανάθεση. Διόρθωση: `(a + b) / 2.0`. (Το `(double) ((a + b) / 2)` **δεν** διορθώνει τίποτα.)

### Άσκηση 27

Γράψε εκφράσεις `boolean` για `char ch`: (α) είναι ψηφίο (β) είναι γράμμα (μικρό ή κεφαλαίο) (γ) είναι κενός χαρακτήρας (space, tab ή newline).

> [!success]- Λύση
> (α) `'0' <= ch && ch <= '9'`
> (β) `('a' <= ch && ch <= 'z') || ('A' <= ch && ch <= 'Z')`
> (γ) `ch == ' ' || ch == '\t' || ch == '\n'`
> (Ίδιες με τη διαφάνεια III-10.)

Τι επιστρέφει η `isLeapYear` (II-33) για 1600, 1700, 2024, 2100; Τι θα επέστρεφε η λανθασμένη εκδοχή `year % 4 == 0 && year % 100 != 0`;

### Άσκηση 29

Τι μπορεί να τυπώσει καθεμία; (α) `(int) (Math.random() * 10)` (β) `(int) Math.random() * 10` (γ) `1 + (int) (Math.random() * 10)` (δ) `(int) (Math.random() * 10) * 2`

> [!success]- Λύση

### Άσκηση 30

Γράψε την **άρνηση** της `month >= 1 && month <= 12` χωρίς `!`. (Γέφυρα προς την Ενότητα III.)

> [!success]- Λύση
> De Morgan: `!(A && B) ≡ !A || !B` → **`month < 1 || month > 12`**.
> ✗ Συχνό λάθος: `month < 1 && month > 12` (πάντα `false`!) – το `&&` πρέπει να γίνει `||`.
