# 03 - Ακέραιοι Τύποι

Ο τύπος `int`, η ακέραια διαίρεση και το υπόλοιπο, και οι υπόλοιποι ακέραιοι τύποι (διαφάνειες II-11 … II-14, II-25).

## 1. Ο τύπος `int`

> [!note] Τύπος Δεδομένων `int` (II-11)
> - Αναπαριστά **ακέραιους** αριθμούς.
> - Μέγεθος **4 bytes** (32 bit), πεδίο τιμών **−2³¹ … +2³¹ − 1** = −2.147.483.648 … 2.147.483.647.
> - Κυριολεκτικές τιμές: `-2189` `0` `50` `+28` `-32` `1027`
> - Πράξεις: πρόσθεση `+`, αφαίρεση `-`, πολλαπλασιασμός `*`, διαίρεση `/`, υπόλοιπο `%`.

⚠️ *Σημείωση: στις διαφάνειες το πεδίο τιμών εμφανίζεται ως «-231 … +231 - 1» λόγω μορφοποίησης· εννοείται 2 εις την 31.*

## 2. Πράξεις – ο πίνακας της διαφάνειας II-12

| Έκφραση | Τιμή | Σχόλιο |
|---|---|---|
| `5 + 3` | `8` | |
| `5 - 3` | `2` | |
| `5 * 3` | `15` | |
| `5 / 3` | `1` | **χωρίς κλασματικό μέρος** |
| `5 % 3` | `2` | υπόλοιπο |
| `1 / 0` | — | **σφάλμα εκτέλεσης** (`ArithmeticException`) |
| `3 * 5 - 2` | `13` | το `*` έχει προτεραιότητα |
| `3 + 5 / 2` | `5` | το `/` έχει προτεραιότητα (`5/2 = 2`) |
| `3 - 5 - 2` | `-4` | αριστερή εταιρικότητα: `(3-5)-2` |
| `( 3 - 5 ) - 2` | `-4` | καλύτερο στυλ |

> [!important] Ακέραια διαίρεση
> Όταν **και οι δύο** τελεστέοι είναι ακέραιοι, το `/` δίνει ακέραιο πηλίκο – το δεκαδικό μέρος **κόβεται** (δεν στρογγυλοποιείται): `7 / 2 = 3`, `99 / 100 = 0`, `2 / 4 = 0`.
> Για κάθε `a`, `b` (με `b ≠ 0`): **`a == (a / b) * b + a % b`**.

## 3. Παράδειγμα: IntOps (II-13, II-14)

```java
public class IntOps {
    public static void main(String[] args) {
        int a = Integer.parseInt(args[0]);   // ορίσματα γραμμής εντολής
        int b = Integer.parseInt(args[1]);
        int sum  = a + b;
        int prod = a * b;
        int quot = a / b;
        int rem  = a % b;
        System.out.println(a + " + " + b + " = " + sum);   // η Java μετατρέπει αυτόματα
        System.out.println(a + " * " + b + " = " + prod);  // ακεραίους σε συμβολοσειρές
        System.out.println(a + " / " + b + " = " + quot);
        System.out.println(a + " % " + b + " = " + rem);
    }
}
```

```
% javac IntOps.java
% java IntOps 1234 99
1234 + 99 = 1333
1234 * 99 = 122166
1234 / 99 = 12
1234 % 99 = 46          ← 1234 = 12*99 + 46
```

## 4. Αρνητικοί αριθμοί ➕

> [!important] Κανόνες για αρνητικά
> - Το `/` **κόβει προς το μηδέν**: `-7 / 2 = -3` (όχι −4).
> - Το `%` παίρνει το **πρόσημο του διαιρετέου** (αριστερού τελεστέου): `-7 % 2 = -1`, `7 % -2 = 1`, `-7 % -2 = -1`.
> - Η ταυτότητα `a == (a/b)*b + a%b` ισχύει πάντα: `-7 == (-3)*2 + (-1)` ✓

> [!warning] Παγίδα: έλεγχος περιττού αριθμού
> `n % 2 == 1` είναι **λάθος** για αρνητικούς: για `n = -3`, `-3 % 2 = -1` → `false`!
> Σωστά: **`n % 2 != 0`** (περιττός) ή `n % 2 == 0` (άρτιος).

## 5. Χρήσιμα «κόλπα» με `/` και `%` ➕

| Σκοπός | Κώδικας | Παράδειγμα (`n = 1234`) |
|---|---|---|
| Τελευταίο ψηφίο | `n % 10` | `4` |
| Αφαίρεση τελευταίου ψηφίου | `n / 10` | `123` |
| Διαιρείται το `n` με το `k`; | `n % k == 0` | `1234 % 2 == 0` → `true` |
| Δευτερόλεπτα → λεπτά:δευτ. | `s / 60`, `s % 60` | `125` → `2`, `5` |
| Κυκλικός δείκτης 0…N−1 | `(i + 1) % N` | |

> [!example]- Άθροισμα ψηφίων (με βρόχο – βλ. Ενότητα III)
> ```java
> int n = 1234, sum = 0;
> while (n > 0) {
>     sum += n % 10;   // πάρε το τελευταίο ψηφίο
>     n = n / 10;      // πέτα το
> }
> // sum = 10
> ```
>
> | Επανάληψη | `n % 10` | `sum` | `n` |
> |---|---|---|---|
> | αρχή | | 0 | 1234 |
> | 1 | 4 | 4 | 123 |
> | 2 | 3 | 7 | 12 |
> | 3 | 2 | 9 | 1 |
> | 4 | 1 | 10 | 0 |

## 6. Άλλοι ακέραιοι τύποι (II-25)

| Τύπος | Πεδίο τιμών |
|---|---|
| `byte` (8 bit) | −128 … 127 |
| `short` (16 bit) | −32.768 … 32.767 |
| `int` (32 bit) | −2.147.483.648 … 2.147.483.647 |
| `long` (64 bit) | −9.223.372.036.854.775.808 … 9.223.372.036.854.775.807 |

> [!warning] Παγίδες με `long` ➕
> - Ένα ακέραιο κυριολεκτικό είναι **`int`** εκτός αν έχει `L`: `long big = 3000000000;` ✗ compile «integer number too large». Σωστά: `3000000000L`.
> - `long x = 2147483647 + 1;` → **−2147483648**! Η πρόσθεση γίνεται σε `int` (υπερχειλίζει) **πριν** τη μετατροπή σε `long`. Σωστά: `2147483647L + 1` → 2147483648.
> - `20!` χωράει σε `long` (2432902008176640000) αλλά ήδη το `13!` **δεν** χωράει σε `int` (βγαίνει 1932053504 – λάθος, χωρίς κανένα μήνυμα).

> [!warning] `byte`/`short` στις πράξεις ➕
> Κάθε αριθμητική πράξη σε `byte`/`short`/`char` γίνεται σε **`int`**:
> ```java
> short s = 10;
> s = s + 5;     // ✗ compile: possible lossy conversion from int to short
> s += 5;        // ✓ οι σύνθετοι τελεστές κάνουν σιωπηρό cast
> ```

## 7. Υπερχείλιση (overflow)

> [!important] Οι ακέραιοι «γυρίζουν»
> Αν το αποτέλεσμα ξεπεράσει το πεδίο τιμών, **δεν** βγαίνει σφάλμα – η τιμή «τυλίγεται» (wraps around):
> `Integer.MAX_VALUE + 1` → `-2147483648` (II-53). Λεπτομέρειες: [[09 - Ανακρίβειες Αναπαράστασης]].

> [!info]- Γιατί «τυλίγεται»; (συμπλήρωμα ως προς 2)
> Οι ακέραιοι αποθηκεύονται σε **συμπλήρωμα ως προς 2** (two's complement). Το `01111…1` (32 bit) είναι το μέγιστο θετικό· αν προσθέσεις 1 γίνεται `10000…0`, που σε συμπλήρωμα ως προς 2 είναι το **ελάχιστο αρνητικό**. Γι' αυτό και `Math.abs(Integer.MIN_VALUE)` επιστρέφει… `-2147483648` (το +2³¹ δεν χωράει).
> Ομοίως `(byte) 200` → `-56` (200 − 256).

## Συχνά Λάθη

> [!warning] Συχνά Λάθη
> - Να περιμένεις `5 / 2 = 2.5` → είναι `2`.
> - Μέσος όρος ακεραίων: `double avg = (a + b) / 2;` → η διαίρεση γίνεται σε `int` **πριν** την ανάθεση. Σωστά: `(a + b) / 2.0`.
> - Διαίρεση/υπόλοιπο με **0** σε ακεραίους → `ArithmeticException` (ενώ σε `double` βγαίνει `Infinity` – βλ. [[04 - Πραγματικοί Τύποι και Βιβλιοθήκη Math]]).
> - Κυριολεκτικό με **αρχικό 0**: `010` είναι **8** (οκταδικό!), και `08` δεν κάνει compile.
> - Κόμματα σε αριθμούς: `34,500` ✗. (Επιτρέπεται `34_500` ➕.)
